# 流程中心

流程中心（顶部导航「流程中心」）是柠檬ERP 的审批平台，承担两类审批：

- **通用审批**：出差申请、用印申请、物品领用、通用审批等不对应具体业务单据的申请。管理员在「流程模型」中设计表单和审批流程，员工在「发起申请」中填写提交。
- **业务单据审批**：[采购订单](../scm/purchase)、[销售订单](../scm/sales)、[凭证](../fin/voucher)、[付款单](../fin/settlement)、[请假](../hr/leave)、[人事异动](../hr/employee#人事异动)、[盘点差异](../wms/check)等业务单据。管理员为这些单据设计并发布审批流程后，单据的「审核」「提交」等操作会改为提交审批，审批通过后单据才生效。详见[业务单据审批](./business)。

审批人通过「我的待办」处理审批，发起人在「我的申请」中跟踪进度，管理员在「流程实例」中监控所有流程。

## 功能清单

左侧菜单分为两组：

| 分组 | 菜单 | 用途 |
| --- | --- | --- |
| 我的事务 | [我的待办](./todo) | 待我审批的任务，同意、拒绝、转交 |
| 我的事务 | [发起申请](./start) | 选择流程、填写表单、提交申请 |
| 我的事务 | [我的申请](./mine) | 我发起的流程，查看进度、撤回 |
| 我的事务 | [我的已办](./done) | 我审批过的任务 |
| 我的事务 | [抄送我的](./copy) | 抄送给我的流程 |
| 流程管理 | [流程模型](./model) | 新建流程，设计表单与审批流程，发布版本 |
| 流程管理 | [流程实例](./instance) | 查看全部流程，终止流程 |
| — | [流程设计器](./designer) | 审批人、抄送人、条件分支、并行分支的详细配置说明 |
| — | [业务单据审批](./business) | 已接入审批的业务单据清单、条件变量和状态变化 |

## 典型业务流程

### 通用审批

| 步骤 | 角色 | 操作 |
| --- | --- | --- |
| 1 | 管理员 | 在[流程模型](./model)中新建流程，设计表单和审批流程，保存并发布 |
| 2 | 员工 | 在[发起申请](./start)中选择流程，填写表单后提交 |
| 3 | 审批人 | 收到站内消息「待审批：……」，在[我的待办](./todo)中同意、拒绝或转交 |
| 4 | 抄送人 | 流程经过抄送节点时，在[抄送我的](./copy)中看到该流程 |
| 5 | 员工 | 在[我的申请](./mine)中查看进度，审批中可以撤回；流程通过或被拒绝时收到站内消息 |

### 业务单据审批

| 步骤 | 角色 | 操作 |
| --- | --- | --- |
| 1 | 管理员 | 在[流程模型](./model)中找到带「业务单据」标签的内置流程，按企业实际调整审批人并发布 |
| 2 | 业务人员 | 在业务页面点「审核」或「提交审批」，单据变为「审批中」 |
| 3 | 审批人 | 在[我的待办](./todo)中审批，详情页的「业务信息」显示单据金额、单号等 |
| 4 | 系统 | 审批通过后单据自动生效（例如订单变为已审核）；拒绝、撤回或终止后单据恢复为提交前的状态 |

## 流程状态

| 状态 | 说明 |
| --- | --- |
| 审批中 | 流程正在流转，有待处理的审批任务 |
| 已通过 | 所有审批节点都已同意，流程正常结束 |
| 已拒绝 | 任一审批人拒绝，流程立即结束（包括其他并行分支） |
| 已撤销 | 发起人撤回或管理员终止 |

## 相关角色与权限

| 菜单 / 按钮 | 说明 |
| --- | --- |
| 发起申请、我的待办（含同意 / 拒绝 / 转交）、我的申请、我的已办、抄送我的 | 一般员工都应具备。内置「普通用户」角色可以使用流程中心发起、审批自己的流程 |
| 流程模型：模型新增、模型修改（含设计）、模型发布、模型删除 | 流程管理员 |
| 流程实例：终止流程 | 流程管理员。有「流程实例」权限的用户可以查看所有流程的详情 |

流程详情只有发起人、审批人（包括转交过的人）、抄送人和有「流程实例」权限的用户可以查看；审批任务只能由当前审批人处理。

::: tip 提示
审批人为「指定角色」时，需要在「[用户管理](../system/user#分配角色)」中为对应人员分配角色（总经理、会计、人事专员等内置角色）；审批人为「部门主管」时，需要在「[部门管理](../system/dept#部门负责人与审批中的「部门主管」)」中设置各部门的负责人。
:::
