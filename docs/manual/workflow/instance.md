# 流程实例

流程实例是流程管理员的监控页面，列出系统中所有人发起的流程（每发起一次申请就是一个流程实例），可以查看任意流程的详情和审批进度，并终止审批中的流程。

## 页面入口

流程中心 → 流程管理 → 流程实例

![流程实例](/images/manual/workflow/instance.jpg)

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 标题 | 按流程标题或名称模糊查询 |
| 状态 | 审批中、已通过、已拒绝、已撤销 |

## 列表字段

| 列 | 说明 |
| --- | --- |
| 标题 | 流程标题，点击查看详情 |
| 流程 | 流程名称 |
| 分类 | 流程模型的分类 |
| 发起人 | 发起流程的用户 |
| 状态 | 审批中、已通过、已拒绝、已撤销 |
| 当前节点 | 审批中的流程所在的节点（多个节点用顿号分隔），已结束显示「-」 |
| 发起时间 / 结束时间 | 流程发起和结束的时间 |
| 操作 | 「查看」；审批中的流程另有「终止」（需要「终止流程」权限） |

列表按发起时间倒序排列。

## 查看详情（进度图与审批记录）

点「查看」或标题打开流程详情，与[我的待办](./todo#审批详情)相同：

- 「审批详情」页签：业务信息或表单信息，以及完整的审批记录时间线（发起、同意、拒绝、转交、撤回、终止、抄送、待审批）。
- 「流程图」页签：进度图，已完成的节点为绿色、进行中为蓝色、被拒绝为红色、未开始为灰色；条件分支中走过的分支同样标为已完成。

有「流程实例」权限的用户可以查看所有流程的详情；如果当前用户恰好是某个任务的审批人，详情页底部同样会显示同意、拒绝、转交按钮。

## 终止流程

当流程因人员变动、业务取消等原因需要强制结束时，管理员可以终止：

1. 在审批中的流程行点「终止」。
2. 在「终止流程：标题」对话框中填写终止原因（**必填**，最多 500 字）。
3. 对话框提示「终止后流程立即结束，不可恢复。」，点「终止」确认，提示「流程已终止」。

![终止流程](/images/manual/workflow/instance-terminate.jpg)

终止后：

- 流程状态变为「已撤销」，审批记录中增加一条「终止」记录（含原因），所有待审批任务取消。
- 业务单据的流程被终止时，单据与撤回、拒绝时一样恢复为提交前的状态，详见[业务单据审批](./business)。
- 终止不会给发起人发送通知，请另行告知发起人。

::: warning 注意
已结束的流程不能终止。如果只是需要换人审批，建议由当前审批人使用「转交」，而不是终止流程。
:::
