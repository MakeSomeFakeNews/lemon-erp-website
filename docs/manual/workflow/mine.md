# 我的申请

我的申请列出我发起的所有流程，包括在「发起申请」中提交的申请和从业务单据提交的审批。发起人在这里跟踪审批进度，并可以撤回审批中的申请。

## 页面入口

流程中心 → 我的事务 → 我的申请

![我的申请](/images/manual/workflow/mine.jpg)

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 标题 | 按流程标题或名称模糊查询 |
| 状态 | 审批中、已通过、已拒绝、已撤销 |

## 列表字段

| 列 | 说明 |
| --- | --- |
| 标题 | 流程标题（如「超级管理员的销售订单审批」），点击查看详情 |
| 流程 | 流程名称 |
| 分类 | 流程模型的分类 |
| 状态 | 审批中、已通过、已拒绝、已撤销 |
| 当前节点 | 审批中的流程显示当前所在的审批节点（并行时用顿号分隔），已结束显示「-」 |
| 发起时间 / 结束时间 | 流程发起和结束的时间 |
| 操作 | 「查看」 |

列表按发起时间倒序排列。

## 查看详情

详情页与[我的待办](./todo#审批详情)相同，包含「审批详情」（业务信息或表单信息、审批记录）和「流程图」两个页签。

![申请详情](/images/manual/workflow/mine-detail.jpg)

## 撤回申请

审批中的流程，发起人在详情页底部可以看到「撤回」按钮：

1. 点「撤回」，弹出「撤回申请」对话框。
2. 填写撤回原因（选填，最多 500 字）。
3. 点「撤回」确认，提示「已撤回」。

撤回后：

- 流程立即结束，状态变为「已撤销」，审批记录中增加一条「撤回」记录；所有待审批的任务取消。
- 如果是业务单据的审批，单据恢复为提交前的状态（通常是草稿），可以修改后重新提交，详见[业务单据审批](./business)。

::: warning 注意
只有发起人可以撤回，且只能撤回「审批中」的流程；已结束的流程提示「流程已结束」。
:::

## 结果通知

流程审批通过或被拒绝时，发起人会收到站内消息「「流程标题」已审批通过」或「「流程标题」已被拒绝」，点击进入本页面。撤回、终止不发送通知。
