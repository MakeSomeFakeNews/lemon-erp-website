# 我的待办

我的待办列出当前分配给我、等待我处理的审批任务。审批人在这里查看申请内容和审批记录，然后同意、拒绝或转交。

## 页面入口

流程中心 → 我的事务 → 我的待办

另外，有待办时[首页](../guide/home#待我审批)「待办」中会显示「待我审批」的数量；任务分配给你时（包括别人转交给你）会收到站内消息「待审批：流程标题」，点击消息可直接进入本页面。

![我的待办](/images/manual/workflow/todo.jpg)

## 查询条件与列表

| 项目 | 说明 |
| --- | --- |
| 流程名称（查询条件） | 按流程名称（如「招聘需求审批」）模糊查询 |
| 待我审批 | 标题旁的红色数字为待办总数 |
| 流程名称 | 流程标题，如「陈静的招聘需求审批」，点击打开审批详情 |
| 当前节点 | 任务所在的审批节点名称（橙色标签） |
| 发起人 / 发起时间 | 流程的发起人和发起时间 |
| 到达时间 | 任务分配给我的时间 |
| 操作 | 「审批」，打开审批详情 |

列表按到达时间倒序排列。工具栏可以显示 / 隐藏查询条件、刷新、调整行高和显示的列。

## 审批详情

![审批详情](/images/manual/workflow/todo-detail.jpg)

审批详情以子页面打开，标题为流程标题，右上角显示流程状态。顶部显示发起人、流程名称、发起时间（已结束的流程还显示结束时间）。

**「审批详情」页签：**

- **业务信息**：业务单据发起的流程显示发起时的业务数据，如订单金额、订单号、请假天数等。
- **表单信息**：通过「发起申请」发起的流程显示申请人填写的表单内容。
- **审批记录**：按时间线列出发起、同意、拒绝、转交、撤回、终止、抄送等记录，包括处理人、处理结果、时间和意见；尚未处理的任务显示为「待审批」（时钟图标），多人审批时每个待审批人各占一行。

**「流程图」页签：** 以只读方式显示流程设计图，并用颜色标出进度：已完成（绿）、进行中（蓝）、已拒绝（红）、未开始（灰）。可以缩放。

![流程图](/images/manual/workflow/todo-flow.jpg)

## 审批操作

当前用户是该流程的待审批人时，详情页底部显示操作按钮：

| 按钮 | 弹窗字段 | 结果 |
| --- | --- | --- |
| 「同意」 | 审批意见（选填，最多 500 字） | 完成本人的审批任务。是否进入下一节点取决于节点的多人审批方式（见下表） |
| 「拒绝」 | 拒绝理由（**必填**，最多 500 字） | 整个流程立即结束，状态为「已拒绝」，其他并行分支上的待办同时取消 |
| 「转交」 | 转交给（必选，点「选择」从人员列表中选一人，不能选自己）；转交说明（选填） | 任务改由被转交人处理，审批记录中记为「转交给「某某」：说明」，被转交人收到待审批消息 |

![转交](/images/manual/workflow/todo-transfer.jpg)

处理完成后提示「已同意」「已拒绝」或「已转交」，详情页自动刷新为最新进度，待办列表同步刷新。

### 多人审批时「同意」的效果

| 审批方式 | 说明 |
| --- | --- |
| 或签 | 任意一人同意，该节点即通过，其他人的待办自动取消 |
| 会签 | 所有审批人都同意后，该节点才通过 |
| 依次审批 | 按顺序逐个审批，前一人同意后下一人才收到待办，全部同意后节点通过 |

无论哪种方式，任一审批人「拒绝」都会立即结束整个流程。

## 注意事项

::: warning 注意
- 只能处理分配给自己的任务。如果提示「任务不存在或已处理」，说明任务已被他人处理（例如或签中别人先同意了）或流程已被撤回 / 终止，刷新列表即可。
- 被转交人必须是启用状态的用户，否则提示「转交人不存在或已停用」。
- 员工离职时，如果在[离职交接](../hr/employee#人事异动)中指定了交接人，其名下未处理的审批任务会自动转交给交接人，审批记录中注明「离职交接，转交给新的负责人」。
:::

::: tip 提示
业务单据的审批通过后，系统会自动执行单据的生效逻辑（例如订单变为已审核、付款单核销应付单）。如果此时业务校验不通过（例如会计期间已结账），审批操作会失败并提示原因，任务仍保留在待办中。
:::
