# 我的已办

我的已办列出我已经处理（同意或拒绝）过的审批任务，便于回顾审批历史、查看流程后续结果。

## 页面入口

流程中心 → 我的事务 → 我的已办

![我的已办](/images/manual/workflow/done.jpg)

::: tip 微信小程序
在[微信小程序](../miniapp/approval)「审批」页的「已办」分段中也可以查看。
:::

## 查询条件与列表

| 项目 | 说明 |
| --- | --- |
| 流程名称（查询条件） | 按流程名称模糊查询 |
| 流程名称 | 流程标题，点击查看详情 |
| 审批节点 | 我处理的节点名称 |
| 处理结果 | 同意、拒绝 |
| 流程状态 | 流程当前的状态：审批中、已通过、已拒绝、已撤销 |
| 发起人 / 发起时间 | 流程的发起人和发起时间 |
| 处理时间 | 我完成审批的时间 |
| 操作 | 「查看」，打开流程详情（只读） |

列表按处理时间倒序排列。

## 哪些任务会出现在已办中

- 出现：我点了「同意」或「拒绝」完成的任务。
- 不出现：我转交给别人的任务（任务由被转交人继续处理，转交记录可以在流程详情的审批记录中看到）；或签中别人先同意、流程被撤回或终止等原因自动取消的任务。

详情页的内容见[我的待办](./todo#审批详情)。
