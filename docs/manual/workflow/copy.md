# 抄送我的

当流程经过设计中的「抄送人」节点时，系统把流程抄送给节点配置的人员。被抄送人在「抄送我的」中查看这些流程，抄送只用于知会，不需要审批。

## 页面入口

流程中心 → 我的事务 → 抄送我的

![抄送我的](/images/manual/workflow/copy.jpg)

## 查询条件与列表

| 项目 | 说明 |
| --- | --- |
| 流程名称（查询条件） | 按流程名称模糊查询 |
| 流程名称 | 流程标题，点击查看详情 |
| 抄送节点 | 抄送人节点的名称，如「抄送会计」 |
| 发起人 | 流程的发起人 |
| 流程状态 | 流程当前的状态：审批中、已通过、已拒绝、已撤销 |
| 抄送时间 | 流程到达抄送节点的时间 |
| 操作 | 「查看」，打开流程详情（只读） |

## 说明

- 抄送在流程**到达抄送节点时**立即发生。抄送节点放在流程最后时，相当于审批通过后知会；放在中间时，流程还在审批中就会抄送。
- 被抄送人可以查看该流程的完整详情（业务信息或表单信息、审批记录、流程图），审批记录中会显示一条「抄送」记录。
- 抄送对象可以是指定成员、指定角色、部门主管或发起人自己，停用的用户不会收到抄送，配置方法见[流程设计器](./designer#抄送人节点)。
