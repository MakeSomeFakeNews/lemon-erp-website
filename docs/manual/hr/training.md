# 培训管理

培训管理登记培训计划（主题、讲师、时间、学时、费用），维护参训学员，记录出勤、成绩和是否通过。员工可以在 [员工自助](./self) 的「我的培训」中查看本人的培训，人事可以在员工档案详情中查看员工的培训记录。

## 页面入口

人力资源 → 招聘培训 → 培训管理

![培训管理](/images/manual/hr/training-list.jpg)

## 列表

- **查询条件**：培训（主题或讲师）、类别、状态、年度。
- **列表列**：培训（主题、讲师、地点）、类别、日期、课时、学员（人数；已结束的显示出勤人数和通过人数）、费用、状态、操作。
- 工具栏支持列设置和导出。

## 新增 / 编辑培训

点击 **新增培训**，或在「更多」中点击「编辑」：

| 字段 | 说明 |
| --- | --- |
| 培训主题 | 必填 |
| 类别 | 入职培训、技能培训（默认）、安全培训、质量培训、管理培训 |
| 讲师 | 选填 |
| 开始日期、结束日期 | 必填，结束日期不能早于开始日期 |
| 课时 | 小时，默认 2 |
| 费用 | 元，默认 0。培训结束时有费用的会生成培训费凭证 |
| 地点 | 选填 |
| 培训内容 | 最多 1000 字 |

已结束或已取消的培训不能修改。

## 状态与操作

| 状态 | 操作 |
| --- | --- |
| 计划中 | 学员与成绩（添加 / 移除学员）、开始、编辑、取消培训、删除 |
| 进行中 | 学员与成绩（添加 / 移除学员，录入出勤和成绩）、结束、编辑、取消培训 |
| 已结束 | 学员与成绩（可继续修改出勤和成绩） |
| 已取消 | 学员与成绩（只读）、删除 |

只能删除计划中或已取消的培训。

## 学员与成绩

点击培训主题或 **学员与成绩** 打开子页面：

![学员与成绩](/images/manual/hr/training-records.jpg)

- **添加学员**：计划中、进行中的培训，在右上角搜索员工（可多选）后点击「添加」，已在名单中的员工自动跳过。点击行尾删除按钮移除学员。
- **录入出勤和成绩**：培训开始后（进行中、已结束）才能录入。每位学员可设置出勤 / 缺勤、成绩（0-100）、结果（通过 / 未通过）、评价；缺勤的学员不能填写成绩和结果。录入后点击底部「保存出勤与成绩」。
- 计划中的培训提示「培训开始后可以录入出勤、成绩和评价」。

## 与其他模块的联动

- **财务**：培训「结束」时，费用大于 0 的培训自动生成一张未审核的培训费[凭证](../fin/voucher#业务生成的凭证)：借 管理费用 - 培训费，贷 其他应付款，凭证日期为培训结束日期。凭证在财务中被删除后，培训与凭证的关联自动解除。
- **员工自助**：员工本年已结束、且本人出勤的培训学时汇总显示在员工自助的「本年培训」中。

## 注意事项

::: tip 提示
结束培训前请先录入出勤和成绩；结束后仍可修改出勤和成绩，但不能再调整学员名单。
:::
