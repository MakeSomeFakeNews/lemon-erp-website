# 薪资档案

薪资档案记录每位员工的工资标准：基本工资、岗位津贴、其他补贴、绩效奖金基数、社保方案与社保公积金基数、工资卡。每次建立或调整都按生效日期记录薪资历史，工资表按月末生效的薪资计算。没有薪资档案的员工不参与工资核算。

## 页面入口

人力资源 → 薪酬福利 → 薪资档案

![薪资档案](/images/manual/hr/salary-list.jpg)

## 列表

- **查询条件**：员工（工号或姓名）、部门（含下级部门）、档案（选择「未建立薪资档案」只显示还没有薪资档案的员工）。
- **列表列**：员工（姓名、状态、工号、部门、职位）、基本工资、岗位津贴、其他补贴、绩效基数、社保方案（未选择显示「默认比例」）、社保基数、公积金基数、公积金比例、月度人工成本（下方显示时薪成本）、工资卡（开户行、账号只显示前 4 位和后 4 位）、操作。
- 没有薪资档案的员工各金额列显示「-」，月度人工成本显示「未建立」，操作列为「建立档案」；已建立的为「调整」。
- 列表按[数据权限](../guide/permission#数据权限的-5-种范围)显示；工具栏支持列设置和导出。

月度人工成本 = 基本工资 + 岗位津贴 + 其他补贴 + 社保基数 × 单位社保比例 + 公积金基数 × 公积金比例；时薪成本 = 月度人工成本 ÷ 174 小时（21.75 天 × 8 小时）。

## 建立档案 / 调整

点击 **建立档案** 或 **调整**（需要「薪资档案维护」权限）：

![调整薪资档案](/images/manual/hr/salary-edit.jpg)

| 字段 | 说明 |
| --- | --- |
| 基本工资 | 必填，元/月。修改基本工资会记录一条「调薪」异动 |
| 岗位津贴 | 元/月，默认 0。与基本工资一起作为日工资的计算基数 |
| 其他补贴 | 元/月，默认 0。餐补、交通等，不参与缺勤扣款计算 |
| 绩效奖金基数 | 默认 0。绩效奖金 = 基数 × 绩效系数（S 1.5 / A 1.2 / B 1.0 / C 0.8 / D 0） |
| 社保方案 | 按 [社保方案](./social) 的缴费比例和基数上下限计算社保；不选按默认比例（个人 10.5%、单位 26%） |
| 社保基数 | 不填按基本工资 + 岗位津贴 |
| 公积金基数 | 不填按基本工资 + 岗位津贴 |
| 公积金比例 | 5%-12%，默认 7%。个人和单位按相同比例缴纳 |
| 工资卡开户行、工资卡账号 | 选填 |
| 生效日期 | 不填时默认今天（新建档案默认为入职日期）。晚于今天的调整到期后才计入工资 |
| 备注 | 选填，记录到薪资历史的说明中 |

表单底部实时估算「个人社保公积金约 X 元/月，单位人工成本约 X 元/月（项目工时按 X 元/小时计算）」。已建立档案的员工下方显示 **薪资历史**：生效日期、基本工资、岗位津贴、社保基数、说明。

## 调薪生效规则

- 每次保存都按生效日期记录一条薪资历史（同一生效日期只保留最后一次）。
- 生效日期不晚于今天：立即更新薪资档案。
- 生效日期晚于今天：只记录薪资历史和调薪异动，列表仍显示当前薪资；到生效日当天，[定时任务](../monitor/job#内置任务)「调薪生效」（每天 0:05）把新薪资更新到薪资档案。
- 生成工资表时，每位员工按该月最后一天已生效的薪资计算，因此补算历史月份也正确。
- 也可以在 [员工档案](./employee) 中通过「异动 - 调薪」调整基本工资（可接入审批）。

## 与其他模块的联动

- **薪酬核算**：工资表的基本工资、津贴、日工资、加班费、绩效奖金、社保公积金都来自薪资档案，见 [薪酬核算](./payroll)。
- **项目管理**：员工的小时人工成本 =（基本工资 + 津贴 + 单位社保公积金）÷ 174，用于计算[项目工时](../pm/timesheet)的人工成本。
- **生产制造**：生产岗位在职员工的平均小时人工成本可作为[工作中心](../mes/work-center)人工费率的参考。
- **招聘管理**：录用时填写试用期基本工资，会自动建立薪资档案。

## 注意事项

::: warning 注意
调整社保方案、基数、比例等其他字段不会记录调薪异动，但同样按生效日期记录到薪资历史。已经确认的工资表不受之后调整的影响。
:::
