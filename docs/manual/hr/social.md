# 社保方案

社保方案按参保城市设置社保、公积金的缴费基数上下限和各险种的个人、单位缴费比例。在 [薪资档案](./salary) 中为员工选择方案后，工资核算按方案计算社保公积金。

## 页面入口

人力资源 → 薪酬福利 → 社保方案

![社保方案](/images/manual/hr/social-list.jpg)

截图中的演示数据还没有设置社保方案，所有员工按默认比例计算。

## 列表

列表不分页，显示全部方案：方案（名称、参保城市）、社保基数（下限 ~ 上限，上限为 0 显示「不限」）、养老 / 医疗 / 失业（个人 / 单位）、工伤（单位）、个人合计、单位合计、公积金基数（下限 ~ 上限）、状态（启用 / 停用）、备注、操作。

## 新增 / 编辑方案

点击 **新增方案** 或 **编辑**（需要「方案维护」权限）：

![新增社保方案](/images/manual/hr/social-add.jpg)

| 字段 | 说明 |
| --- | --- |
| 方案名称 | 必填，如「上海社保 2026」 |
| 参保城市 | 选填 |
| 社保基数下限、上限 | 元，默认 0；上限为 0 表示不限，上限不能小于下限 |
| 缴费比例 | 养老、医疗、失业保险的个人和单位比例，工伤保险只有单位比例，0-100%。默认：养老 8% / 16%，医疗 2% / 8%，失业 0.5% / 0.5%，工伤 0.2%；表格底部合计个人、单位比例 |
| 公积金基数下限、上限 | 元，0 表示不限。公积金比例在薪资档案中设置 |
| 状态 | 启用 / 停用。停用的方案不能在薪资档案中选择，已选择的员工不受影响 |
| 备注 | 选填 |

## 计算规则

| 项目 | 有社保方案 | 没有社保方案（默认） |
| --- | --- | --- |
| 社保缴费基数 | 薪资档案的社保基数，低于下限按下限、高于上限按上限 | 薪资档案的社保基数 |
| 个人社保 | 基数 × 养老、医疗、失业个人比例之和 | 基数 × 默认个人社保比例（默认 10.5%，见[业务参数](../system/biz-rule#人力资源)） |
| 单位社保 | 基数 × 养老、医疗、失业、工伤单位比例之和 | 基数 × 默认单位社保比例（默认 26%） |
| 公积金 | 公积金基数按方案上下限截取 × 薪资档案中的公积金比例，个人、单位相同 | 公积金基数 × 公积金比例，个人、单位相同 |

个人社保、公积金从应发工资中扣除并减少个税的应纳税所得额；单位社保、公积金计入人工成本，工资表确认时一并计提。

## 删除

已被薪资档案使用的方案不能删除，提示「社保方案已被薪资档案使用，不能删除」，可以改为停用。
