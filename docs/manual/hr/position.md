# 职位管理

职位管理维护公司的岗位、类别、职级和编制人数。员工档案、招聘需求选择职位；职位的类别还决定工资计提时计入哪个费用科目。

## 页面入口

人力资源 → 员工管理 → 职位管理

![职位管理](/images/manual/hr/position-list.jpg)

## 列表

- **查询条件**：职位（编码或名称）、类别、状态。
- **列表列**：职位（名称、编码）、类别、职级、在职 / 编制（在职人数超过编制时标红，没有编制显示「不限」）、职责说明、排序、状态、操作。
- **状态**：列表中的开关直接启用或停用职位（需要「职位修改」权限）。停用的职位不能再被员工、招聘需求选择，已有员工不受影响。
- 工具栏支持列设置和导出。

## 新增 / 编辑职位

点击 **新增职位** 或操作列的 **编辑**：

![新增职位](/images/manual/hr/position-add.jpg)

| 字段 | 说明 |
| --- | --- |
| 职位编码 | 必填，只能包含字母、数字、下划线和短横线，最多 32 位，不能重复 |
| 职位名称 | 必填 |
| 类别 | 管理、技术、生产、销售、职能 |
| 职级 | 如 P5、M3，最多 16 位，仅作记录 |
| 排序 | 下拉选择时的顺序 |
| 编制人数 | 为空表示不限；招聘需求审核时校验 |
| 职责说明 | 选填，最多 255 字 |

## 职位类别的作用

工资表确认时生成[计提凭证](../fin/voucher#业务生成的凭证)，人工成本按员工职位的类别计入不同的费用科目：

| 类别 | 计提科目 |
| --- | --- |
| 生产 | 制造费用（[成本核算](../fin/cost#工单成本)时按工时分配到生产工单） |
| 销售 | 销售费用 |
| 管理、技术、职能，或员工没有设置职位 | 管理费用 - 工资 |

## 编制控制

设置了编制人数的职位，[招聘管理](./recruit) 中审核招聘需求时校验：在职人数 + 该职位其他审批中、招聘中需求的剩余名额 + 本次招聘人数，不能超过编制，否则提示「超出职位的编制」并列出各项人数。

## 删除

已有员工（包括离职员工）的职位不能删除，提示「已有员工，不能删除，可以停用」。
