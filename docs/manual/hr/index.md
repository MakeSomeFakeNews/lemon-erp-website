# 人力资源概述

人力资源模块管理员工从入职到离职的全过程，以及每月从考勤到发放工资的薪酬核算。人事专员维护组织与员工档案、组织招聘培训、管理考勤与绩效、核算发放工资；员工本人通过「员工自助」打卡、请假加班、查看工资条和参与绩效考核；部门负责人负责给下属评分。

## 页面入口

顶部导航「人力资源」，侧边栏分为四组：

| 分组 | 页面 | 说明 |
| --- | --- | --- |
| 员工管理 | [员工自助](./self) | 员工本人打卡、查看考勤日历、申请请假加班、查看工资条和培训、绩效自评与评分 |
| | [员工档案](./employee) | 办理入职，转正、调岗、调薪、离职等人事异动，关联登录账号，Excel 导入 |
| | [劳动合同](./contract) | 新签、续签、终止劳动合同，到期提醒 |
| | [职位管理](./position) | 职位、类别、职级、编制人数 |
| 招聘培训 | [招聘管理](./recruit) | 招聘需求（可审批）→ 录入简历 → 面试 → 发 Offer → 录用入职 |
| | [培训管理](./training) | 培训计划、学员、出勤与成绩 |
| 考勤绩效 | [考勤管理](./attendance) | 考勤记录与补卡、月度汇总、班次与节假日 |
| | [假勤审批](./leave) | 请假、加班申请的查询与审批 |
| | [绩效考核](./perf) | 考核方案、发起考核、自评与评分、归档 |
| 薪酬福利 | [薪资档案](./salary) | 员工的基本工资、津贴、绩效基数、社保公积金基数、工资卡，调薪按生效日期 |
| | [薪酬核算](./payroll) | 月度工资表的生成、调整、确认（计提凭证）、发放（发放凭证） |
| | [社保方案](./social) | 各城市社保公积金的基数上下限和缴费比例 |
| | [专项附加扣除](./deduction) | 个税专项附加扣除（子女教育、住房贷款利息等） |

把月末汇总考勤到发放工资的完整步骤串起来的说明见 [月度发薪操作指引](./monthly-payroll)。

## 典型业务流程

### 入职到离职

| 步骤 | 操作 | 页面 |
| --- | --- | --- |
| 1 | 维护职位（类别、职级、编制） | [职位管理](./position) |
| 2 | 用人部门提交招聘需求，审核（或走审批流程）后开始招聘 | [招聘管理](./recruit) |
| 3 | 录入简历、安排面试、填写面试结果，至少一轮通过后发 Offer | [招聘管理](./recruit) |
| 4 | 录用：自动生成试用期员工档案，可同时建立薪资档案、开通登录账号 | [招聘管理](./recruit) |
| 4' | 也可以不经过招聘，直接「办理入职」或 Excel 导入 | [员工档案](./employee) |
| 5 | 签订劳动合同；安排入职培训 | [劳动合同](./contract)、[培训管理](./training) |
| 6 | 试用期到期前系统提醒，办理「转正」 | [员工档案](./employee) |
| 7 | 在职期间按需办理「调岗」「调薪」（可接入审批） | [员工档案](./employee)、[薪资档案](./salary) |
| 8 | 办理「离职」：账号停用并强制下线，工作移交给交接人，劳动合同自动终止 | [员工档案](./employee) |

### 月度考勤到发薪

| 步骤 | 操作 | 页面 |
| --- | --- | --- |
| 1 | 员工每天在员工自助打卡，提交请假、加班申请 | [员工自助](./self) |
| 2 | 人事或审批人审批请假加班；人事为漏打卡的员工补卡 | [假勤审批](./leave)、[考勤管理](./attendance) |
| 3 | 月末核对月度汇总（出勤、迟到早退、旷工、请假、加班） | [考勤管理](./attendance) |
| 4 | 绩效考核归档，奖金计入指定的发放月份 | [绩效考核](./perf) |
| 5 | 生成当月工资表，必要时调整其他奖金、其他扣款 | [薪酬核算](./payroll) |
| 6 | 确认工资表（可接入审批）：锁定当月考勤，员工可看工资条，生成计提凭证 | [薪酬核算](./payroll) |
| 7 | 发放：选择付款账户，生成发放凭证 | [薪酬核算](./payroll) |

## 与其他模块的联动

- **财务**：工资表确认生成计提凭证、发放生成发放凭证；有费用的培训结束时生成培训费凭证。凭证都是未审核状态，由财务在 [凭证管理](../fin/voucher) 中审核过账。
- **系统管理**：员工档案关联[登录账号](../system/user)后才能使用员工自助；调岗同步登录账号的部门（审批人、数据权限按新部门）；离职停用账号并强制下线。
- **客户关系、项目管理、流程中心**：员工离职时，负责的客户、线索、商机、服务工单、项目、未完成任务和[审批待办](../workflow/todo)移交给交接人，没有交接人时客户[退回公海](../crm/customer#员工离职)。
- **生产制造**：[生产报工](../mes/wo#报工)的计件工资按报工人关联的员工计入当月工资表的「计件工资」。
- **项目管理**：薪资档案折算的小时人工成本用于[项目工时](../pm/timesheet)的人工成本；请假、加班记录用于工时填报校验。
- **流程中心**：请假加班（hr_leave）、招聘需求（hr_recruit）、人事异动（hr_change）、工资表（hr_payroll）四类业务可接入审批流程，见 [流程中心](../workflow/business#人力资源)。在流程中心发布了对应流程标识的流程后自动走审批，否则按各页面说明直接处理。
- **商务智能**：[数据仓库](../bi/etl)按部门、岗位类别汇总月末人数、入职、离职、应发工资和人工成本，可在 [商务智能](../bi/) 中分析。
- **首页待办与消息**：[首页待办](../guide/home#待办事项)显示「请假加班待审批」「15 天内试用期到期」；[定时任务](../monitor/job#内置任务)「试用期到期提醒」「劳动合同到期提醒」向人事发送站内消息。

## 相关角色

| 角色 | 主要工作 |
| --- | --- |
| 人事专员 | 内置角色，拥有人力资源全部功能：员工、合同、招聘培训、考勤、绩效、薪酬社保 |
| 部门负责人 | 招聘需求的用人部门；绩效考核的评分人（员工所在部门的负责人）；接收下属试用期到期提醒 |
| 全体员工 | 通过「员工自助」打卡、请假加班、查看工资条和培训、绩效自评 |
| 财务人员 | 审核工资计提、发放凭证和培训费凭证 |

::: tip 提示
员工档案、请假、考勤、薪资档案按部门做数据权限：用户只能看到数据权限范围内部门的员工。数据权限在「系统管理 - [角色管理](../system/role#数据权限页签)」中设置。
:::
