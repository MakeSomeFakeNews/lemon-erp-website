# 绩效考核

绩效考核按「考核方案（指标 + 权重）→ 发起考核 → 员工自评 → 负责人评分 → 归档」进行。归档后的考核等级按奖金系数计算绩效奖金，计入指定发放月份的工资表。

## 页面入口

人力资源 → 考勤绩效 → 绩效考核

![绩效考核](/images/manual/hr/perf-list.jpg)

## 列表

- **查询条件**：考核名称、状态。
- **列表列**：考核（名称、周期、起止日期）、奖金发放月份（未设置显示「不发放」）、评分进度（已完成 / 考核人数，未发起显示「未发起」）、状态、创建人、操作。

## 状态与操作

| 状态 | 说明 | 操作 |
| --- | --- | --- |
| 草稿 | 新建的考核方案 | 发起、编辑、删除 |
| 考核中 | 已生成考核表，员工自评、负责人评分 | 考核结果、归档、编辑（只能改名称、说明、奖金发放月份） |
| 已归档 | 全部评分完成后归档 | 考核结果 |

## 新建考核

点击 **新建考核**：

![新建考核](/images/manual/hr/perf-add.jpg)

| 字段 | 说明 |
| --- | --- |
| 考核名称 | 必填，如「2026 年第三季度绩效考核」 |
| 考核周期 | 月度、季度（默认）、年度 |
| 开始日期、结束日期 | 必填，默认本季度，结束日期不能早于开始日期 |
| 奖金发放月份 | 归档后绩效奖金计入该月工资，不选不发放 |
| 说明 | 选填 |
| 考核指标 | 指标名称、权重（1-100%）、评分标准。默认三项：工作业绩 60%、工作能力 20%、工作态度 20%。可以「添加指标」或删除，权重合计必须为 100%（不等于 100 时标红） |

## 发起考核

草稿状态点击 **发起**，选择考核范围（部门，可多选，含下级部门；不选为全部在职员工）：

1. 为范围内每位在职员工生成一张考核表。
2. 评分人为员工所在部门的负责人；员工本人就是部门负责人时，向上级部门查找负责人；都没有时评分人为发起人。
3. 关联了登录账号的员工的考核表为「待自评」；没有关联账号的员工跳过自评，直接「待评分」。
4. 提示「已发起，生成 X 张考核表」。范围内没有在职员工时不能发起。

## 自评与评分

考核表状态：待自评 → 待评分 → 已完成。

- **自评**：员工在 [员工自助](./self) 的「绩效考核 - 我的考核」中点击「自评」，为每个指标打 0-100 分，填写自评总结。只能填写自己的自评。
- **评分**：评分人在员工自助的「待我评分」中，或在本页面「考核结果」中点击「评分」。评分时可以看到员工的各指标自评分和自评总结，为每个指标打分（每个指标都必须打分），填写评语。员工没有自评时也可以直接评分；不能给自己评分。
- **代为评分**：有「代为评分」权限的用户（如人事）可以为任何考核表评分。

总分 = Σ 指标得分 × 权重 ÷ 100。等级与奖金系数：

| 等级 | 分数 | 奖金系数 |
| --- | --- | --- |
| S 卓越 | 90 分及以上 | 1.5 |
| A 优秀 | 80-89 分 | 1.2 |
| B 良好 | 70-79 分 | 1.0 |
| C 合格 | 60-69 分 | 0.8 |
| D 待改进 | 60 分以下 | 0（无绩效奖金） |

## 考核结果

点击考核名称或 **考核结果** 打开子页面：

![考核结果](/images/manual/hr/perf-result.jpg)

- 左侧为已完成考核表的等级分布环形图，右侧显示状态、完成进度、指标及权重、奖金发放月份。
- 下方列表可按考核表状态、工号或姓名筛选，显示员工、评分人、自评、得分、等级、状态、评语（含自评总结）。
- 考核中时，评分人本人或有「代为评分」权限的用户可以对未完成的考核表点击「评分」；有「代为评分」权限的用户可以对已完成的考核表点击「退回重评」，考核表回到待评分。

## 归档

考核中的方案在所有考核表都完成评分后点击 **归档**；还有未完成的考核表时提示「还有 X 张考核表没有完成评分」。归档后不能再评分。

## 与薪酬的联动

生成某月工资表时，取「奖金发放月份」为该月、已归档的考核中已完成的考核表等级：

绩效奖金 = 薪资档案中的「绩效奖金基数」× 等级对应的奖金系数

绩效奖金计入应发工资，工资表和工资条中同时显示等级。详见 [薪酬核算](./payroll)。

::: tip 提示
如果工资表已经生成后才归档考核，请在 [薪酬核算](./payroll) 中对草稿工资表点击「重新计算」，绩效奖金才会计入。
:::
