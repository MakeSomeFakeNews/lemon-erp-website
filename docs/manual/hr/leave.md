# 假勤审批

假勤审批页面查询全部请假、加班申请，并由人事审批没有走审批流程的申请。申请由员工在 [员工自助](./self) 中提交。

## 页面入口

人力资源 → 考勤绩效 → 假勤审批

![假勤审批](/images/manual/hr/leave-list.jpg)

## 列表

- **查询条件**：申请（单号、工号或姓名）、种类（请假 / 加班）、假期类型、状态（点「展开」显示）、开始日期范围。
- **列表列**：单号、员工（姓名、工号、部门）、种类（请假 + 假期类型，或加班 + 补偿方式「加班费 / 转调休」）、时间、时长（8 小时及以上同时显示天数，固定按每天 8 小时折算显示，不随业务参数中的「每日工时」变化）、事由、状态（走审批流程的显示「审批流程中」）、审批（审批人、审批时间、审批意见）、操作。
- 列表按[数据权限](../guide/permission#数据权限的-5-种范围)显示（按申请员工的部门和申请人）；工具栏支持列设置和导出。

## 假期类型

| 类型 | 工资处理 | 余额校验 |
| --- | --- | --- |
| 年假 | 带薪 | 不能超过年假余额（法定年假天数 × 班次标准工时 − 本年已用，已用含审批中） |
| 事假 | 按小时工资扣发 | 无 |
| 病假 | 按小时工资的病假扣发比例扣发（默认 40%，见[业务参数](../system/biz-rule#人力资源)） | 无 |
| 婚假 | 带薪 | 无 |
| 产假 / 陪产假 | 带薪 | 无 |
| 调休 | 带薪 | 不能超过调休余额（已批准的转调休加班 − 已申请的调休） |
| 本企业新增的类型 | 带薪（按普通带薪假处理，与婚假、产假相同） | 无 |

假期类型是[业务字典](../system/biz-dict)「假期类型」，企业可以新增类型（如育儿假、丧假）或停用不用的类型。年假、事假、病假、调休是内置类型，余额校验和扣款规则如上表；新增的类型不校验余额、不扣工资，已通过的请假在考勤汇总中同样不计旷工。

加班的补偿方式：

- **加班费**：按日期类型计算加班费，默认工作日 1.5 倍、休息日 2 倍、法定节假日 3 倍小时工资（倍数可在[业务参数](../system/biz-rule#人力资源)中修改）。
- **转调休**：不发加班费，批准后计入调休余额，员工可以申请「调休」假。

## 状态

| 状态 | 说明 |
| --- | --- |
| 审批中 | 员工提交后的状态 |
| 已通过 | 审批同意；请假在考勤汇总中不计旷工，加班计入加班 |
| 已拒绝 | 审批拒绝 |
| 已撤销 | 员工撤销（审批中，或已通过但尚未开始），或审批流程被撤销 |

## 审批

### 人事审批

没有走审批流程的「审批中」申请，在操作列显示 **审批**（需要「假勤审批」权限）：

1. 点击「审批」，弹窗显示种类、时间、时长、事由。
2. 选择「同意」或「拒绝」，填写审批意见（选填）。
3. 点击确定，申请变为「已通过」或「已拒绝」，员工在员工自助中可以看到审批意见。

不能审批自己提交的申请。

### 接入审批流程

在[流程中心](../workflow/business#人力资源)发布了「请假加班审批」（流程标识 hr_leave）流程后，员工提交的申请自动发起流程，由流程中的审批人在 [流程中心](../workflow/todo) 处理，审批结束后自动更新申请状态。这类申请在本页面只能查看，不显示「审批」按钮（直接处理会提示「该申请正在走审批流程，请在流程中心处理」）。

流程[条件分支](../workflow/designer#条件分支)可以使用以下变量：申请种类（请假 / 加班）、请假类型（加班为 OVERTIME）、天数（小时数 ÷ 每日工时，保留 1 位小数；每日工时默认 8 小时，可在[业务参数](../system/biz-rule#人力资源)中修改）、小时数、加班补偿方式。例如「请假超过 3 天由部门经理和总经理审批」。

## 注意事项

::: warning 注意
某月的工资表确认（或提交审批）后，该月的请假加班不能再提交、审批或撤销。需要调整时先在 [薪酬核算](./payroll) 中取消确认。
:::

::: tip 提示
[首页待办](../guide/home#待办事项)的「请假加班待审批」显示待人事审批的申请数量，点击进入本页面。
:::
