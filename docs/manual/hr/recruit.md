# 招聘管理

招聘管理覆盖从提出招聘需求到新员工入职的全过程：招聘需求（可接入审批）→ 录入简历 → 安排面试 → 发 Offer → 录用入职。录用时自动生成员工档案，招满后需求自动关闭。

## 页面入口

人力资源 → 招聘培训 → 招聘管理

页面顶部用「招聘需求 / 应聘者」切换两个列表。

## 招聘需求

![招聘需求](/images/manual/hr/recruit-list.jpg)

- **查询条件**：单号或岗位、状态。
- **列表列**：岗位（岗位名称、需求单号）、用人部门 / 职位、招聘进度（已录用 / 招聘人数）、应聘者人数（点击切换到应聘者列表并按该需求筛选）、薪资范围、期望到岗、状态、申请人、操作。

### 新增招聘需求

点击 **新增招聘需求**：

![新增招聘需求](/images/manual/hr/recruit-add.jpg)

| 字段 | 说明 |
| --- | --- |
| 岗位名称 | 必填，如「嵌入式软件工程师」 |
| 用人部门 | 必填 |
| 职位 | 选填，选择后审核时校验职位编制 |
| 招聘人数 | 必填，1-999，默认 1 |
| 薪资范围 | 选填文字，如「15-25K」 |
| 期望到岗 | 选填日期 |
| 招聘原因 | 选填，如新增编制、离职补缺、业务扩展 |
| 任职要求 | 选填，最多 1000 字 |

保存后为「草稿」，单号按[编码规则](../system/code-rule)自动生成。

### 状态与操作

| 状态 | 说明 | 操作 |
| --- | --- | --- |
| 草稿 | 新建的需求 | 审核、编辑、删除 |
| 审批中 | 已提交审批流程 | 撤回（回到草稿，同时撤销流程） |
| 招聘中 | 可以录入应聘者、录用 | 录入简历、关闭 |
| 已关闭 | 招满后自动关闭，或手工关闭 | 无 |

**审核**：

- 选择了职位且职位设置了编制时，先校验编制：在职人数 + 该职位其他审批中、招聘中需求的剩余名额 + 本次招聘人数不能超过编制。
- [流程中心](../workflow/business#人力资源)发布了「招聘需求审批」（流程标识 hr_recruit）流程时，提示「已提交审批，审批通过后开始招聘」，状态为「审批中」；审批通过后变为「招聘中」，被拒绝或撤销时回到「草稿」。流程条件可以使用招聘人数等变量。
- 没有发布流程时，提示「审核通过，开始招聘」，直接变为「招聘中」。

**关闭**：停止招聘，不再录入应聘者，未结束的应聘者不受影响（但需求关闭后不能再录用）。

## 应聘者

![应聘者](/images/manual/hr/recruit-candidate.jpg)

- **查询条件**：招聘需求、姓名 / 手机号 / 院校；下方的阶段标签（全部、新简历、面试中、已发 Offer、已入职、已淘汰）快速筛选。
- **列表列**：姓名（性别、手机号）、应聘岗位、学历 / 经验（学历、院校、工作年限）、来源、期望月薪、面试（轮数和最近一轮结果）、阶段（已入职的显示工号）、录入时间、操作。

### 录入简历

点击 **录入简历**（或在招聘需求的操作列点击「录入简历」）：

| 字段 | 说明 |
| --- | --- |
| 招聘需求 | 必填，只能选择招聘中的需求，保存后不能修改 |
| 姓名 | 必填 |
| 性别、手机号 | 选填 |
| 邮箱 | 选填，需符合邮箱格式 |
| 学历、毕业院校、工作年限 | 选填 |
| 简历来源 | 招聘网站、内部推荐、猎头、校园招聘、其他 |
| 期望月薪 | 选填 |
| 简历摘要 | 工作经历、项目经验、技能，最多 2000 字 |
| 备注 | 选填 |

新录入的应聘者阶段为「新简历」。

### 应聘阶段

| 阶段 | 进入方式 | 可执行的操作 |
| --- | --- | --- |
| 新简历 | 录入简历 | 面试（安排面试）、编辑、淘汰、删除 |
| 面试中 | 第一次安排面试后自动进入 | 面试、发 Offer、编辑、淘汰、删除 |
| 已发 Offer | 点击「发 Offer」 | 录用、编辑、淘汰、删除 |
| 已入职 | 录用后 | 只能查看，不能修改、删除 |
| 已淘汰 | 点击「更多 - 淘汰」，可填写淘汰原因 | 只能查看 |

### 面试

点击应聘者姓名或 **面试** 打开面试记录：

![面试记录](/images/manual/hr/recruit-interview.jpg)

- 上方显示应聘岗位、阶段、学历、期望月薪和简历摘要。
- **简历附件**：上传简历文件（需要「应聘者管理」权限）。
- **面试安排**：新简历和面试中的应聘者可以点击「安排面试」，填写面试时间（必填）、方式（现场 / 视频 / 电话）、面试官、结果（待面试 / 通过 / 未通过）、评分（0-100）、面试评价。轮次自动递增。
- 面试记录按时间线显示，点击「填写结果」补充面试结果、评分和评价。

### 发 Offer

面试中的应聘者至少有一轮面试结果为「通过」时，才能点击 **发 Offer**，否则提示「还没有通过的面试，不能发 Offer」。

### 录用入职

已发 Offer 的应聘者点击 **录用**：

![录用入职](/images/manual/hr/recruit-hire.jpg)

| 字段 | 说明 |
| --- | --- |
| 工号 | 必填，字母、数字、下划线和短横线，不能与已有员工重复 |
| 入职日期 | 必填，默认 7 天后 |
| 职位 | 不选使用招聘需求的职位 |
| 用工类型 | 默认全职 |
| 预计转正日期 | 默认入职 3 个月后 |
| 试用期基本工资 | 填写后同时建立 [薪资档案](./salary)，社保、公积金基数默认为基本工资，从入职日期生效 |
| 登录账号 | 「暂不开通」「开通新账号」「关联已有账号」三选一 |
| 登录名 | 开通新账号时必填，2-30 位字母、数字、下划线、点或短横线。新账号的初始密码为「系统管理 - [参数设置](../system/config)」中配置的初始密码，首次登录后请修改 |
| 已有账号 | 关联已有账号时选择 |

确认后：

1. 生成试用期员工档案，部门为招聘需求的用人部门，姓名、性别、手机号、邮箱、学历取自应聘者，并记录入职异动。
2. 应聘者阶段变为「已入职」，列表显示工号。
3. 招聘需求的已录用人数加 1，达到招聘人数时需求自动变为「已关闭」。

只有招聘中的需求可以录用，需求已关闭时提示「不在招聘中，不能录用」。

## 注意事项

::: tip 提示
- 只有草稿状态的招聘需求可以编辑、删除和审核；已入职的应聘者不能修改或删除。
- 录用后请到 [劳动合同](./contract) 签订合同，到 [培训管理](./training) 安排入职培训。
:::
