# 专项附加扣除

专项附加扣除登记员工申报的个人所得税专项附加扣除项目和每月扣除金额。工资核算时，在起止期间内的扣除按月合计，从个税的应纳税所得额中扣除。

## 页面入口

人力资源 → 薪酬福利 → 专项附加扣除

![专项附加扣除](/images/manual/hr/deduction-list.jpg)

截图中的演示数据还没有登记专项附加扣除。

## 列表

- **查询条件**：员工（工号或姓名）、扣除类型。
- **列表列**：员工（姓名、工号、部门）、扣除类型、每月金额、起止期间（结束月份为空显示「长期」，已过结束月份显示「已结束」）、备注、操作。
- 工具栏：「新增扣除」「批量删除」（勾选多行后删除）、列设置、导出。

## 新增 / 编辑扣除

点击 **新增扣除** 或 **编辑**（需要「扣除维护」权限）：

![新增专项附加扣除](/images/manual/hr/deduction-add.jpg)

| 字段 | 说明 |
| --- | --- |
| 员工 | 必填，编辑时不能修改 |
| 扣除类型 | 必填，选择后自动带出标准金额并显示标准说明 |
| 每月扣除金额 | 必填，元/月，可以修改 |
| 开始月份 | 必填，默认本年 1 月 |
| 结束月份 | 不填为长期，不能早于开始月份 |
| 备注 | 如子女姓名、扣除比例、住房地址等 |

扣除类型与选择时带出的标准金额：

| 扣除类型 | 默认金额（元/月） | 标准说明 |
| --- | --- | --- |
| 子女教育 | 2000 | 每个子女每月 2000 元，父母可选择一方全额扣除或双方各扣 50% |
| 继续教育 | 400 | 学历（学位）继续教育每月 400 元，最长 48 个月；职业资格证书在取得当年按 3600 元一次扣除 |
| 住房贷款利息 | 1000 | 首套住房贷款利息每月 1000 元，最长 240 个月 |
| 住房租金 | 1500 | 直辖市、省会等城市 1500 元；市辖区户籍人口超过 100 万的城市 1100 元，其余 800 元 |
| 赡养老人 | 3000 | 独生子女每月 3000 元；非独生子女与兄弟姐妹分摊，每人不超过 1500 元 |
| 婴幼儿照护 | 2000 | 3 岁以下婴幼儿每个每月 2000 元 |

一名员工可以登记多条扣除（例如两个子女各一条），同一月份的扣除金额合计计算。

## 与个税计算的关系

个税按累计预扣法计算：

- 本年累计应纳税所得额 = 本年各月（应发工资 − 个人社保公积金 − 专项附加扣除 − 基本减除费用）之和（基本减除费用默认 5000，见[业务参数](../system/biz-rule#人力资源)）
- 本月个税 = 按累计应纳税所得额查预扣率表计算的累计应纳税额 − 本年此前已预扣的个税（不小于 0）

计算细节和预扣率表见 [薪酬核算](./payroll)。

::: tip 提示
专项附加扣除在生成工资表时读取。工资表生成后新增或修改的扣除，需要对草稿工资表「重新计算」才会生效；已确认的工资表不受影响。
:::
