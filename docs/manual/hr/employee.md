# 员工档案

员工档案记录每位员工的基本信息、任职信息和登录账号，入职、转正、调岗、调薪、离职通过「异动」办理并保留历史记录。员工档案是考勤、请假、工资、绩效、培训的基础。

## 页面入口

人力资源 → 员工管理 → 员工档案

![员工档案列表](/images/manual/hr/employee-list.jpg)

## 列表

- **概况卡片**：在职员工、试用期、本月入职、本月离职人数。
- **部门树**（左侧）：点击部门只显示该部门及下级部门的员工，可以点击工具栏右侧的按钮隐藏或显示部门树。
- **查询条件**：员工（工号、姓名或手机号）、状态（不选时显示在职员工，不含离职）、职位、用工类型（点「展开」显示）。
- **列表列**：员工（姓名、工号、性别）、部门 / 职位、用工类型、状态（试用期员工显示计划转正日期，离职员工显示离职日期）、入职日期、手机号、学历、登录账号（未关联时显示「未关联」）、操作。
- **工具栏**：「办理入职」「导入」，以及列设置、导出、刷新、表格密度等[通用按钮](../guide/common#表格工具栏)。导出按当前查询条件导出全部数据。

列表按[数据权限](../guide/permission#数据权限的-5-种范围)显示：用户只能看到数据权限范围内部门的员工。

## 办理入职

点击 **办理入职**，在子页面中填写员工档案：

![办理入职](/images/manual/hr/employee-add.jpg)

**基本信息**

| 字段 | 说明 |
| --- | --- |
| 工号 | 必填，只能包含字母、数字、下划线和短横线，最多 32 位，不能重复 |
| 姓名 | 必填 |
| 性别 | 男 / 女，默认男 |
| 出生日期、手机号、学历 | 选填 |
| 身份证号 | 选填，18 位（最后一位可以是 X）。没有「员工修改」权限的用户查看详情时，身份证号只显示前 6 位和后 4 位 |
| 邮箱 | 选填，需符合邮箱格式 |

**任职信息**

| 字段 | 说明 |
| --- | --- |
| 部门 | 必填。在左侧选中部门后办理入职会自动带入 |
| 职位 | 选填，从 [职位管理](./position) 中启用的职位选择。职位的类别决定工资计提的费用科目 |
| 用工类型 | 全职（默认）、兼职、实习、劳务派遣 |
| 入职日期 | 必填，默认今天 |
| 参加工作日期 | 选填，不能晚于入职日期。法定年假按累计工作年限计算，不填按入职日期 |
| 入职状态 | 「试用期」（默认）或「直接转正」 |
| 计划转正日期 | 试用期时显示，不填为入职日期 + 默认试用期（默认 3 个月，见[业务参数](../system/biz-rule#人力资源)） |
| 班次 | 不选使用默认班次，班次在 [考勤管理](./attendance) 中维护 |
| 登录账号 | 选择已有的系统用户，一个账号只能关联一名员工。关联后员工可以使用 [员工自助](./self) |

**其他**：住址、紧急联系人、紧急联系电话、备注。

保存后生成员工档案，并记录一条「入职」异动。

::: tip 提示
通过 [招聘管理](./recruit) 录用的应聘者会自动生成员工档案，并可以同时开通新的登录账号；在这里办理入职只能关联已有账号，新账号需要先在「系统管理 - [用户管理](../system/user)」中创建。
:::

## 编辑

点击 **编辑** 修改基本信息、用工类型、参加工作日期、班次、登录账号和其他信息；试用期员工还可以修改计划转正日期。部门、职位、入职日期不能直接修改（显示为灰色），部门和职位通过「异动 - 调岗」调整。编辑会记录字段变更历史，在详情的「变更记录」中查看。

## 人事异动

在职员工的操作列有 **异动** 下拉菜单：

![异动菜单](/images/manual/hr/employee-change.jpg)

| 异动 | 填写内容 | 生效后的结果 |
| --- | --- | --- |
| 转正 | 生效日期、说明（只有试用期员工显示该项） | 状态改为正式，转正日期为生效日期 |
| 调岗 | 生效日期、调入部门（必填）、新职位、说明。部门和职位都没有变化时不能提交 | 修改员工的部门和职位；关联的登录账号同步调整部门，部门负责人审批和数据权限按新部门生效 |
| 调薪 | 生效日期、调整后基本工资（必填）、说明。员工必须先有 [薪资档案](./salary) | 按生效日期记录薪资历史；生效日期不晚于今天的同时更新薪资档案，未来日期的到期后由定时任务「调薪生效」更新 |
| 离职 | 生效日期、离职原因、工作交接人 | 员工状态改为离职，不再参与考勤和工资核算；登录账号停用并强制下线；生效中的劳动合同自动终止；交接见下文 |

离职时的「工作交接人」：员工负责的客户、线索、商机、服务工单、项目、未完成任务和审批待办移交给交接人；不选交接人时客户[退回公海](../crm/customer#员工离职)。交接人不能是离职员工本人。

通用规则：

- 生效日期不能早于入职日期；已离职员工不能再办理异动。
- **接入审批**：在[流程中心](../workflow/business#人力资源)发布了「人事异动审批」（流程标识 hr_change）流程时，提交后提示「已提交审批，审批通过后生效」，异动记录显示审批状态；审批通过后才生效，拒绝或撤销则作废。员工有审批中的异动时，不能再办理新的异动。流程条件可以使用异动类型、调整后薪资、调薪幅度等变量。
- 没有发布流程时提交即生效，提示「已办理」。

## 员工详情

点击员工姓名打开详情子页面，上方显示档案信息，下方有以下页签：

| 页签 | 内容 |
| --- | --- |
| 异动记录 | 入职、转正、调岗（原部门 / 职位 → 新部门 / 职位）、调薪（原基本工资 → 新基本工资）、离职的时间线，审批中或被拒绝的异动显示审批状态 |
| 劳动合同 | 员工的劳动合同、类型、期限、状态，30 天内到期的提示剩余天数。有劳动合同权限时可点击链接到 [劳动合同](./contract) 中签订、续签或终止 |
| 培训记录 | 参加的培训、日期、课时、出勤、成绩、结果 |
| 附件 | 上传身份证复印件、学历证书等附件，需要「员工修改」权限 |
| 变更记录 | 编辑档案时各字段的修改历史 |

## 导入

点击 **导入** 批量导入员工档案：

![导入员工档案](/images/manual/hr/employee-import.jpg)

1. 点击「下载导入模板」，按模板填写。带 * 的列必填：工号、姓名、部门、入职日期。
2. 其他列：性别（男 / 女）、出生日期、身份证号、手机号、邮箱、学历、职位、用工类型、状态、计划转正日期、参加工作日期、住址、紧急联系人、紧急联系电话、备注。部门、职位填写名称，学历、用工类型、状态填写字典中的名称。
3. 上传 .xlsx 文件，系统先检查每一行，有错误的行列出行号和原因。
4. 没有错误时点击「导入」。每一行按办理入职的规则校验，任何一行有错误时整批不导入。

## 删除

只有没有考勤、请假加班、工资记录的员工可以删除（用于删除录入错误的档案），删除时同时删除其异动记录和薪资档案。已有记录的员工提示「已有考勤或工资记录，不能删除，可以办理离职」。

## 注意事项

::: tip 提示
- [定时任务](../monitor/job#内置任务)「试用期到期提醒」每天提醒人事（有人事异动权限的用户）和员工所在部门的负责人：15 天内试用期到期的员工，请办理转正或延长试用（在编辑中修改计划转正日期）。[首页待办](../guide/home#待办事项)也显示「15 天内试用期到期」的人数。
- 员工状态、部门变化以异动为准，不要通过编辑档案绕过异动，否则异动记录不完整。
:::

::: warning 注意
离职立即停用登录账号并强制下线，请在确认后再办理。员工离职后其历史考勤、工资记录保留，可以在状态中选择「离职」查询。
:::
