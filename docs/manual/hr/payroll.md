# 薪酬核算

薪酬核算按月生成工资表：根据薪资档案、当月考勤汇总、请假加班、绩效等级、计件工资、销售提成、社保方案和专项附加扣除计算每位员工的应发、扣款、个税和实发工资。工资表经过「草稿 → 已确认 → 已发放」，确认时生成计提凭证，发放时生成发放凭证。

完整的月末操作顺序见 [月度发薪操作指引](./monthly-payroll)。

## 页面入口

人力资源 → 薪酬福利 → 薪酬核算

![薪酬核算](/images/manual/hr/payroll.jpg)

## 页面布局

- **左侧**：选择年份，列出该年的工资表（月份、状态、人数、实发合计），点击查看；「生成」按钮生成工资表。
- **右侧上方**：工资表标题、状态、单号、制表人，操作按钮，以及汇总：人数、应发合计、个人社保公积金、个人所得税、实发合计、单位社保公积金。下方显示计提凭证号、发放凭证号和发放日期、确认人和确认时间。
- **右侧明细**：可按工号或姓名搜索，每位员工一行，底部合计行。

明细列：

| 列 | 说明 |
| --- | --- |
| 员工 | 姓名、工号、部门 |
| 出勤 / 工作日 | 应出勤天数（在职期间的工作日）/ 本月工作日 |
| 基本工资 | 基本工资 × 在职折算 |
| 津贴补贴 | （岗位津贴 + 其他补贴）× 在职折算 |
| 加班费 | 金额和加班小时 |
| 计件工资 | 当月[生产报工](../mes/wo#报工)的计件工资 |
| 销售提成 | 当月已确认的[销售提成](../scm/commission)中该员工的应发提成 |
| 绩效奖金 | 等级和金额 |
| 其他奖金 | 手工调整 |
| 考勤扣款 | 鼠标悬停显示旷工天数、迟到早退次数、事假小时、病假小时 |
| 应发工资 | 加粗显示 |
| 个人社保、个人公积金 | 从应发中扣除 |
| 专项附加扣除 | 当月合计，用于计算个税 |
| 个税 | 本月预扣的个人所得税 |
| 其他扣款 | 手工调整 |
| 实发工资 | 加粗显示 |
| 单位社保、单位公积金 | 单位承担部分，计入人工成本 |
| 累计应纳税所得额、累计已扣个税 | 本年累计值 |
| 备注 | 调整时填写 |

## 计算规则

### 参与核算的员工

该月任职过（入职日期不晚于月末、未在月初前离职）且在月末有已生效薪资档案的员工。没有薪资档案的员工不在工资表中；全部员工都没有薪资档案时提示「本月没有建立薪资档案的在职员工，请先在「薪资档案」中维护」。

### 应发工资

| 项目 | 公式 |
| --- | --- |
| 在职折算 | 应出勤天数 ÷ 本月工作日（月中入职、离职的员工按比例发放） |
| 基本工资 | 薪资档案基本工资 × 在职折算 |
| 津贴补贴 | （岗位津贴 + 其他补贴）× 在职折算 |
| 日工资 | （基本工资 + 岗位津贴）÷ 月计薪天数（默认 21.75）；小时工资 = 日工资 ÷ 每日工时（默认 8）。两者都可在[业务参数](../system/biz-rule#人力资源)中修改 |
| 小时工资 | 日工资 ÷ 8 |
| 加班费 | Σ 加班小时 × 小时工资 × 倍数（默认工作日 1.5、休息日 2、法定节假日 3，可在[业务参数](../system/biz-rule#人力资源)中修改）；只计「加班费」方式的已通过加班，「转调休」的不计 |
| 绩效奖金 | 绩效奖金基数 × 等级系数（S 1.5、A 1.2、B 1.0、C 0.8、D 0），取奖金发放月份为本月的已归档考核 |
| 计件工资 | 当月生产报工中计件工资的合计（按报工人关联的员工） |
| 销售提成 | 当月**已确认**的[销售提成](../scm/commission)表中，员工档案关联的登录账号（即业务员）的应发提成；该月提成表未确认或未计算时为 0 |
| 考勤扣款 | 旷工天数 × 日工资 + 事假小时 × 小时工资 + 病假小时 × 小时工资 × 病假扣发比例（默认 40%）+ 迟到早退次数 × 每次扣款（默认 50 元）；比例和金额在[业务参数](../system/biz-rule#人力资源)中设置 |
| 应发工资 | 基本工资 + 津贴补贴 + 加班费 + 绩效奖金 + 计件工资 + 销售提成 + 其他奖金 − 考勤扣款（不小于 0） |

年假、婚假、产假 / 陪产假、调休为带薪假，不扣款。

### 社保公积金

- 有 [社保方案](./social) 的：社保基数按方案上下限截取，乘以方案的个人、单位比例；公积金基数按方案上下限截取，乘以薪资档案的公积金比例。
- 没有社保方案的：个人社保 = 社保基数 × 默认个人社保比例（默认 10.5%），单位社保 = 社保基数 × 默认单位社保比例（默认 26%），两个比例在[业务参数](../system/biz-rule#人力资源)中设置；公积金 = 公积金基数 × 公积金比例。
- 单位公积金与个人公积金相同。

### 个人所得税（累计预扣法）

1. 本月应纳税所得额 = 应发工资 − 个人社保 − 个人公积金 − 专项附加扣除 − 基本减除费用（默认 5000，可在[业务参数](../system/biz-rule#人力资源)中修改）
2. 本年累计应纳税所得额 = 本年此前各月累计 + 本月应纳税所得额
3. 累计应纳税额 = 累计应纳税所得额 × 预扣率 − 速算扣除数（累计应纳税所得额不大于 0 时为 0）
4. 本月个税 = 累计应纳税额 − 本年此前已预扣的个税（不小于 0）

预扣率表（默认值；税法调整时可在[业务参数](../system/biz-rule#人力资源)的「个税累计预扣率表」中修改）：

| 累计预扣预缴应纳税所得额 | 预扣率 | 速算扣除数 |
| --- | --- | --- |
| 不超过 36,000 元 | 3% | 0 |
| 36,000 - 144,000 元 | 10% | 2,520 |
| 144,000 - 300,000 元 | 20% | 16,920 |
| 300,000 - 420,000 元 | 25% | 31,920 |
| 420,000 - 660,000 元 | 30% | 52,920 |
| 660,000 - 960,000 元 | 35% | 85,920 |
| 超过 960,000 元 | 45% | 181,920 |

### 实发工资

实发工资 = 应发工资 − 个人社保 − 个人公积金 − 个税 − 其他扣款

## 操作

### 生成工资表

点击左侧 **生成**（需要「生成工资表」权限）：

![生成工资表](/images/manual/hr/payroll-generate.jpg)

选择工资月份（每月 15 日前默认上个月，之后默认本月），点击确定。

- 不能生成未来月份的工资表。
- 该月还没有工资表时新建（单号按[编码规则](../system/code-rule)生成），状态为「草稿」。
- 该月已有草稿时重新计算（手工调整会丢失）；已确认、审批中或已发放的不能重新生成。

### 重新计算

草稿状态点击 **重新计算**，按最新的考勤、请假加班、绩效、计件、已确认的销售提成、薪资档案、专项附加扣除重新计算，手工调整的其他奖金、其他扣款会丢失。

### 调整

草稿状态在明细行点击 **调整**（需要「工资调整」权限）：

![调整工资](/images/manual/hr/payroll-adjust.jpg)

填写其他奖金、其他扣款（均不小于 0）和备注，保存后重新计算该员工的应发、个税和实发，工资表合计同步更新。

### 确认

草稿状态点击 **确认**（需要「工资确认」权限）。

- 没有发布审批流程时，直接变为「已确认」，并生成计提凭证，提示「已确认，计提凭证已生成」。
- [流程中心](../workflow/business#人力资源)发布了「工资表审批」（流程标识 hr_payroll）流程时，提示「已提交审批，审批通过后确认并生成计提凭证」，状态为「审批中」；审批通过后确认，被拒绝或撤销时回到草稿。流程条件可以使用应发合计、人数、工资月份。
- 确认（或提交审批）后：员工可以在 [员工自助](./self) 查看本月工资条；该月的考勤补录和删除、请假加班的提交、审批、撤销都被锁定。

**计提凭证**（未审核，凭证日期为工资月份最后一天）：

| 方向 | 科目 | 金额 |
| --- | --- | --- |
| 借 | 按部门和职位类别：生产 → 制造费用，销售 → 销售费用，其他 → 管理费用 - 工资（辅助核算部门） | 应发工资 + 单位社保 + 单位公积金 |
| 贷 | 应付职工薪酬 | 合计 |

### 取消确认

已确认（尚未发放）的工资表点击 **取消确认**：删除未审核的计提凭证，工资表回到草稿，解除考勤锁定，可以修改考勤后重新计算。计提凭证已审核或所在会计期间[已结账](../fin/period#结账后的限制)时无法删除，取消确认会失败，需先在财务中处理。

### 发放

已确认的工资表点击 **发放**（需要「工资发放」权限），填写：

| 字段 | 说明 |
| --- | --- |
| 发放日期 | 必填，默认今天，不能早于工资月份的第一天 |
| 付款账户 | 必填，选择库存现金或银行存款科目 |

确认后状态变为「已发放」，生成发放凭证（未审核，日期为发放日期）：

| 方向 | 科目 | 金额 |
| --- | --- | --- |
| 借 | 应付职工薪酬 | 应发合计 + 单位社保公积金合计 |
| 贷 | 所选付款账户（银行存款等） | 实发合计 |
| 贷 | 应交税费 - 应交个人所得税 | 个税合计 |
| 贷 | 其他应付款 | 个人社保公积金 + 单位社保公积金 + 其他扣款 |

金额为 0 的分录不生成。

### 生成计提凭证

计提凭证在财务中被删除后，已确认或已发放的工资表会显示 **生成计提凭证** 按钮，点击重新生成。

### 打印工资条

点击 **打印工资条**，为当前明细列表中的每位员工打印一张工资条（可先按工号或姓名搜索筛选）。工资条包含姓名、工号、部门、出勤 / 工作日、各项收入、扣款、个税和实发工资。工资条版式可以在「系统管理 - [打印模板](../system/print-template)」中调整。

### 删除

只能删除草稿状态的工资表（需要「工资表删除」权限）。

## 状态

| 状态 | 说明 | 可执行的操作 |
| --- | --- | --- |
| 草稿 | 生成后的状态，可以反复计算 | 重新计算、调整、确认、删除、打印工资条 |
| 审批中 | 已提交工资表审批流程，考勤已锁定 | 在流程中心审批 |
| 已确认 | 计提凭证已生成，员工可看工资条 | 发放、取消确认、打印工资条 |
| 已发放 | 发放凭证已生成 | 打印工资条 |

发放凭证在财务中被删除后，工资表自动回到「已确认」，可以重新发放。

## 注意事项

::: warning 注意
- 重新生成或重新计算草稿工资表会覆盖手工调整，请在调整前完成考勤、请假加班、绩效的核对。
- 确认后员工即可查看工资条，请核对无误后再确认。
:::

::: tip 提示
计提、发放凭证都是未审核状态，由财务人员在 [凭证管理](../fin/voucher) 中审核、过账。
:::
