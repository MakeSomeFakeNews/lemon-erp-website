# 劳动合同

劳动合同页面登记员工的劳动合同、实习协议和劳务协议，跟踪合同期限，到期前提醒人事续签或终止。

## 页面入口

人力资源 → 员工管理 → 劳动合同

![劳动合同列表](/images/manual/hr/contract-list.jpg)

截图中的演示数据还没有登记合同，列表为空。

## 列表

- **查询条件**：关键字（合同编号、工号或姓名）、状态、合同类型。
- **快捷筛选**：「全部」/「即将到期（30 天内）」，后者只显示 30 天内到期的生效中合同。从到期提醒消息跳转过来时自动筛选即将到期的合同。
- **列表列**：合同编号、员工（姓名、员工状态、工号、部门）、合同类型、签订日期、合同期限（开始 ~ 结束，无固定期限合同显示「无固定期限」，有试用期时显示试用期月数）、剩余天数、状态、终止（终止日期和原因）、备注、操作。
- **剩余天数**：只对生效中的合同显示，30 天内到期为橙色，已过期显示「已过期 X 天」为红色，当天到期显示「今天到期」。
- 工具栏支持列设置和导出。

## 合同类型与状态

合同类型：固定期限、无固定期限、以完成一定工作任务为期限、实习协议、劳务协议。合同类型是[业务字典](../system/biz-dict)，企业可以新增类型；只有「无固定期限」不填结束日期，其他类型（包括新增的）都必须填写结束日期。

| 状态 | 说明 | 可执行的操作 |
| --- | --- | --- |
| 生效中 | 新签或续签后的合同 | 编辑、续签、终止、删除 |
| 已到期 | 结束日期已过，由定时任务每天更新 | 续签 |
| 已续签 | 已经续签了新合同的原合同 | 无 |
| 已终止 | 手工终止，或员工离职时自动终止 | 无 |

## 新签合同

点击 **新签合同**：

![新签劳动合同](/images/manual/hr/contract-add.jpg)

| 字段 | 说明 |
| --- | --- |
| 员工 | 必填，按工号或姓名搜索 |
| 合同编号 | 不填按[编码规则](../system/code-rule)自动生成，不能重复，保存后不能修改 |
| 合同类型 | 必填，默认固定期限 |
| 签订日期 | 必填，默认今天 |
| 开始日期 | 必填，默认今天 |
| 结束日期 | 除无固定期限合同外必填，不能早于开始日期。新签默认 3 年（开始日期 + 3 年 − 1 天）；选择「无固定期限」时清空并禁用 |
| 试用期 | 0-6 个月，新签默认 3 个月 |
| 备注 | 选填 |

## 续签

生效中或已到期的合同可以点击 **续签**，打开「续签劳动合同」表单：

- 员工和合同类型沿用原合同（员工不能修改）。
- 开始日期默认为原合同结束日期的次日，结束日期默认沿用原合同的期限年数，试用期默认 0。
- 保存后生成一份新的生效中合同，原合同变为「已续签」。

## 终止

生效中的合同点击 **终止**，填写终止日期（必填，默认今天）和终止原因（必填，如「协商一致解除」「员工主动辞职」），合同变为「已终止」。

员工在 [员工档案](./employee) 中办理离职时，生效中的劳动合同自动终止，终止日期为离职日期，原因为「员工离职」。

## 编辑与删除

- 只能编辑生效中的合同；员工和合同编号不能修改。
- 只能删除生效中的合同，用于删除录入错误的合同；已到期、已续签、已终止的合同保留作为记录。

## 注意事项

::: tip 提示
定时任务「劳动合同到期提醒」每天上午运行：把结束日期已过的生效中合同改为「已到期」，并向有劳动合同查看权限的人事发送消息，提醒 30 天内到期的合同（每份合同只提醒一次）。提醒天数可以在「系统监控 - [定时任务](../monitor/job#修改任务)」中通过参数 days 调整。
:::

员工的劳动合同也显示在 [员工档案](./employee) 详情的「劳动合同」页签中。
