# 考勤管理

考勤管理查看员工每天的打卡记录、为漏打卡的员工补卡，按月汇总出勤、迟到早退、旷工、请假和加班（工资计算直接使用月度汇总），并维护班次与节假日日历。

## 页面入口

人力资源 → 考勤绩效 → 考勤管理

页面顶部用「考勤记录 / 月度汇总 / 班次与节假日」切换三个页签。

## 考勤记录

![考勤记录](/images/manual/hr/attendance-records.jpg)

- **查询条件**：工号或姓名、部门（含下级部门）、状态（正常、迟到、早退、迟到早退、缺卡）、日期范围（默认本月 1 日到今天）。
- **列表列**：员工（姓名、工号、部门）、日期（含星期）、上班（迟到时显示迟到分钟数）、下班（早退时显示早退分钟数）、出勤时长、状态、来源（打卡 / 补录，补录的显示补录说明）、操作。
- 工具栏支持导出；列表按[数据权限](../guide/permission#数据权限的-5-种范围)显示。

### 考勤结果的计算

员工在 [员工自助](./self) 打卡，当天第一次为上班卡，之后为下班卡（以最后一次为准）。系统按员工的班次计算：

| 结果 | 规则 |
| --- | --- |
| 迟到 | 工作日上班时间晚于「班次上班时间 + 宽限分钟」，迟到分钟从班次上班时间算起 |
| 早退 | 工作日下班时间早于「班次下班时间 − 宽限分钟」，早退分钟算到班次下班时间 |
| 迟到早退 | 同时迟到和早退 |
| 缺卡 | 只有上班卡或只有下班卡，出勤时长为 0 |
| 正常 | 其他情况 |
| 出勤时长 | 下班时间 − 上班时间，超过 5 小时扣除 1 小时午休 |

非工作日（周末、法定节假日）打卡不计迟到早退。

### 补录考勤 / 补卡

点击工具栏的 **补录考勤**，或某条记录的 **补卡**：

![补录考勤](/images/manual/hr/attendance-manual.jpg)

| 字段 | 说明 |
| --- | --- |
| 员工 | 必填（从记录进入时自动带出） |
| 日期 | 必填，不能选未来日期，也不能早于员工的入职日期 |
| 上班时间、下班时间 | 至少填写一个；都填写时下班时间必须晚于上班时间。新增默认 09:00 和 18:00 |
| 补录说明 | 必填，如「外出拜访客户」「忘记打卡」 |

补录覆盖当天的打卡时间并重新计算考勤结果，来源显示为「补录」。

**删除**：删除某天的考勤记录（删除后该工作日如果没有请假，会被计为旷工）。

补录、补卡、删除需要「考勤补录」权限。

## 月度汇总

![月度汇总](/images/manual/hr/attendance-summary.jpg)

选择月份、部门（含下级部门）、工号或姓名后查询，每位在该月任职过的员工一行：

| 列 | 说明 |
| --- | --- |
| 工作日 | 本月的工作日天数 |
| 应出勤 | 员工在职期间（入职日期之后、离职日期之前）的工作日天数 |
| 实际出勤 | 有考勤记录的工作日天数 |
| 迟到、早退 | 次数，「迟到早退」同时计入两项 |
| 缺卡 | 次数，只统计今天以前的日期 |
| 旷工(天) | 今天以前的工作日既没有考勤记录、也没有已通过的请假，大于 0 时标红 |
| 各假期类型(时) | 已通过的年假、事假、病假、婚假、产假 / 陪产假、调休小时数，按开始时间归属月份 |
| 加班(时) | 已通过的「加班费」加班小时数；「转调休」的加班不计入（不发加班费） |

月度汇总是工资计算的依据：旷工、事假、病假、迟到早退计算考勤扣款，加班计算加班费，应出勤 / 工作日计算在职折算。详见 [薪酬核算](./payroll)。

## 班次与节假日

![班次与节假日](/images/manual/hr/attendance-config.jpg)

工作日 = 周一至周五 + 调休上班日 − 法定节假日。员工未指定班次时使用默认班次。维护需要「班次与节假日」权限。

### 班次

列表显示班次名称（默认班次带「默认」标记）、上下班时间、宽限分钟、标准工时。点击 **新增班次** 或 **编辑**：

| 字段 | 说明 |
| --- | --- |
| 班次名称 | 必填 |
| 上班时间、下班时间 | 必填，下班时间必须晚于上班时间（暂不支持跨天班次） |
| 迟到 / 早退宽限 | 0-120 分钟 |
| 标准工时 | 1-12 小时，请假按此折算天数（例如年假余额） |
| 设为默认班次 | 勾选后成为默认班次 |

默认班次不能删除（请先把其他班次设为默认）；已分配给员工的班次不能删除。没有配置任何班次时按 9:00-18:00 计算。员工的班次在 [员工档案](./employee) 中设置。

### 节假日与调休

选择年份查看当年设置的日期。点击 **新增**：

| 字段 | 说明 |
| --- | --- |
| 日期 | 必填，同一日期只能设置一次 |
| 类型 | 法定节假日（不上班）或调休上班（周末上班） |
| 名称 | 必填，如「国庆节」「国庆节调休」 |

节假日影响：工作日的计算（应出勤、旷工）、加班费倍数（工作日 1.5 倍、休息日 2 倍、法定节假日 3 倍），以及员工自助考勤日历的显示。每年初请按国家公布的放假安排维护。

## 注意事项

::: warning 注意
某月的工资表确认（或提交审批）后，该月的考勤不能再补录或删除，提示「X 年 X 月的工资表已确认，不能再补录考勤」。需要调整时先在 [薪酬核算](./payroll) 中取消确认。
:::
