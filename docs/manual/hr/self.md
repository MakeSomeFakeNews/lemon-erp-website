# 员工自助

员工自助是每位员工处理个人人事事务的页面：上下班打卡、查看本月考勤、申请请假和加班、查看工资条和培训记录、填写绩效自评；部门负责人还在这里给下属评分。员工只能看到和操作自己的数据。

## 页面入口

人力资源 → 员工管理 → 员工自助

![员工自助](/images/manual/hr/self.jpg)

::: warning 注意
当前登录账号必须在「[员工档案](./employee)」中关联到一名员工，才能打卡、请假、查看工资条。没有关联时页面提示「当前账号没有关联员工档案」，只显示「绩效考核」页签中的「待我评分」（例如没有员工档案的管理人员也可以作为评分人）。
:::

::: tip 微信小程序
打卡、考勤、请假加班、工资条和绩效自评 / 评分也可以在[微信小程序](../miniapp/self)中处理，数据与本页相同。
:::

## 页面内容

### 个人信息卡片

显示姓名、员工状态（试用期 / 正式）、工号、部门、职位、入职日期，以及：

| 指标 | 说明 |
| --- | --- |
| 年假余额 | 本年法定年假天数减去已用天数（已用包含审批中的年假），下方显示「共 X 天，已用 Y」和「调休余额 X 小时」 |
| 本年培训 | 本年已结束且本人出勤的培训累计学时 |
| 待我自评 | 需要本人填写自评的考核表数量，大于 0 时橙色显示 |
| 待我评分 | 需要本人作为评分人评分的考核表数量 |

年假天数按累计工作年限计算：满 1 年不满 10 年 5 天，满 10 年不满 20 年 10 天，满 20 年 15 天，不满 1 年没有年假。工作年限从员工档案的「参加工作日期」算起（没有填写时按入职日期），截至当年 12 月 31 日。

### 打卡

右侧卡片显示当前时间、今天的上班和下班打卡时间以及考勤状态。

- 当天第一次点击为「上班打卡」，之后按钮变为「下班打卡」。下班卡可以多次打，以最后一次为准。
- 打卡后按员工的班次自动判断：上班时间晚于「上班时间 + 宽限分钟」为迟到，下班时间早于「下班时间 - 宽限分钟」为早退；只有上班卡或只有下班卡为缺卡。
- 周末、法定节假日打卡视为加班，不计迟到早退。
- 有上下班卡后计算出勤时长：打卡间隔超过午休扣除阈值（默认 5 小时）时扣除午休时长（默认 1 小时），两个值由管理员在[业务参数](../system/biz-rule#人力资源)中设置，见[考勤管理](./attendance#考勤结果的计算)。
- 已离职员工不能打卡。

## 页签说明

### 考勤日历

按月显示考勤日历，可以用左右箭头切换月份（不能切换到未来月份）。顶部汇总当月「应出勤、实际出勤、迟到、早退、旷工、加班」。

- 每天显示上下班打卡时间；状态不是「正常」时显示迟到、早退、缺卡等标签。
- 灰色底为休息日，红字为节假日或调休名称（如「国庆节」「国庆节调休」），蓝框为今天。
- 请假、加班显示类型和小时数，审批中的显示为橙色。
- 工作日没有打卡记录、也没有已通过的请假时显示红色「旷工」（仅限今天以前的日期）。

### 请假加班

![请假加班](/images/manual/hr/self-leave.jpg)

列表显示本人最近的申请：单号、种类（请假 + 假期类型 / 加班）、时间、时长、事由、状态和审批意见。

**申请请假** / **申请加班** 打开申请弹窗：

![申请请假](/images/manual/hr/self-leave-apply.jpg)

| 字段 | 说明 |
| --- | --- |
| 假期类型 | 请假必填：年假（显示剩余天数）、事假、病假、婚假、产假 / 陪产假、调休。选择调休时显示调休余额 |
| 补偿方式 | 加班时选择：「发加班费」（默认）或「转调休」 |
| 时间 | 必填，开始和结束时间，分钟按 30 分钟步进。请假默认明天 9:00-18:00，加班默认明天 18:30 起 2 小时 |
| 时长 | 必填，单位小时，按 0.5 递增。请假跨天时按日期内的工作日（周一至周五）× 每日工时自动估算；同一天内按时间差计算，时间差超过「午休扣除阈值」时扣除「午休时长」，最多一天的工时。每日工时、午休扣除阈值、午休时长取[业务参数](../system/biz-rule#人力资源)（默认 8 小时、5 小时、1 小时），与考勤计算一致。估算值可以修改，请半天填每日工时的一半；加班按起止时间差计算 |
| 事由 | 选填，最多 255 字 |

::: tip 提示
弹窗中的提示会显示当前的参数值，例如「按工作日每天 8 小时自动计算（同一天超过 5 小时扣午休 1 小时），可以修改；请半天填 4 小时」。提交后，审批流程中的「天数」按业务参数的每日工时折算（小时数 ÷ 每日工时），工资表的事假、病假扣款按小时工资（日工资 ÷ 每日工时）× 请假小时数计算。
:::

提交时的校验：

- 结束时间必须晚于开始时间，时长不能超过开始到结束的时间。
- 同一时间段不能重复提交请假（或加班）申请。
- 年假不能超过年假余额；调休不能超过调休余额。调休余额 = 已批准的「转调休」加班小时 − 已申请（审批中、已通过）的调休小时。
- 该月的工资表已确认时，不能再提交该月的申请。

提交后状态为「审批中」。如果[流程中心](../workflow/business#人力资源)发布了请假加班审批流程，按流程审批；否则由人事在 [假勤审批](./leave) 中审批。

**撤销**：审批中的申请，或已通过但还没有开始的申请，可以点击「撤销」，撤销后状态为「已撤销」，走审批流程的同时撤回流程。

### 工资条

![工资条](/images/manual/hr/self-payslip.jpg)

左侧按月份列出已确认（或已发放）的工资条和实发金额，点击查看明细：基本工资、津贴补贴、加班费（含加班小时）、绩效奖金（含等级）、计件工资、销售提成（有金额时显示）、其他奖金、考勤扣款（旷工天数、迟到早退次数）、应发工资、个人社保、个人公积金、个人所得税、其他扣款、实发工资、专项附加扣除、本年累计应纳税所得额、本年累计已扣个税、状态。

草稿状态的工资表员工看不到。还没有已确认的工资条时显示「还没有已确认的工资条」。

### 我的培训

列出本人参加的培训：培训、类别、日期、课时、状态。培训结束后在「结果」列显示出勤或缺勤、成绩以及「通过 / 未通过」。

### 绩效考核

![绩效考核](/images/manual/hr/self-perf.jpg)

- **我的考核**：本人的考核表，显示考核、评分人、自评分、得分、等级、状态。状态为「待自评」且考核进行中时，点击「自评」填写；已完成的点击「查看」查看各指标得分、等级、评分人和评语。
- **待我评分**：本人作为评分人的考核表，显示被考核人、部门、自评、得分、等级、状态。未完成且考核进行中时点击「评分」。

自评和评分弹窗中，每个指标打 0-100 分，按权重加权得到总分；评分时可以看到员工的自评分和自评总结，并实时显示对应的等级（S ≥ 90、A ≥ 80、B ≥ 70、C ≥ 60、D）。每个指标都必须打分，总结 / 评语选填（最多 500 字）。评分规则见 [绩效考核](./perf)。

## 注意事项

::: tip 提示
员工自助对所有登录用户开放，菜单是否显示由[角色的菜单权限](../system/role#菜单权限页签)决定，内置角色默认都已授权。
:::

::: warning 注意
工资表确认后，该月的请假加班不能再提交、审批或撤销。需要调整时请联系人事在「薪酬核算」中取消确认。
:::
