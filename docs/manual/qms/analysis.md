# 质量分析

质量分析按检验数据汇总各类检验的批次合格率、月度趋势、主要不良类型和供应商来料质量，帮助质量工程师找出主要问题、锁定需要重点改进的供应商和工序。页面只读，数据来自[质量检验](./inspection)。

## 页面入口

质量 → 质量分析 → 质量分析

![质量分析](/images/manual/qms/analysis.jpg)

## 统计范围

页面顶部的日期范围默认为近 12 个月（11 个月前的月初到今天），按检验单的检验日期筛选，修改后全部图表重新统计。合格率汇总、趋势和柏拉图只统计**已确认**的检验单。

## 合格率汇总

日期范围下方按检验类型（来料、过程、成品、首件）各显示一张卡片：

- **批次合格率** = 合格批数 / 总批数，让步接收计为合格；低于 95% 时标红。
- 下方显示总批数和不合格批数。

期间内没有某类检验时不显示该类卡片；全部没有时显示「期间内没有已确认的检验单」。

## 批次合格率趋势

折线图，横轴为月份，每种检验类型一条线，纵轴为当月的批次合格率（0 ~ 100%）。可以看出合格率是在改善还是恶化。

## 不良类型柏拉图

统计期间内结论为不合格的检验单，按检验单上的「主要不良类型」汇总：

- **柱形**：各不良类型的不良数量合计，从多到少排列；没有填写不良类型的计入「其他」。
- **折线**：累计占比，图中虚线标出 80%。

按照「二八原则」，累计占比达到 80% 之前的几类不良就是需要优先解决的主要问题。期间内没有不合格检验时显示「期间内没有不合格检验」。

::: tip 提示
柏拉图依赖检验单上的「主要不良类型」，检验不合格时请选择不良类型，否则都会归入「其他」。
:::

## 供应商来料质量排名

![供应商来料质量排名](/images/manual/qms/analysis-supplier.jpg)

按供应商汇总期间内填写了采购入库单号的来料检验，**合格率低的排在前面**（合格率相同时批次多的在前），便于重点关注：

| 列 | 说明 |
| --- | --- |
| 排名 | |
| 供应商 | 供应商名称和编码 |
| 来料批次 | 总批数：合格、不合格、让步的批数 |
| 批次合格率 | 结论为「合格」的批数 / 总批数（此处让步接收不计为合格）；低于 95% 显示为红色 |
| 抽样不良率 | 抽样不良数合计 / 抽样数合计，大于 1% 标红；下方显示不良数 / 抽样数 |

## 使用建议

1. 每月查看合格率卡片和趋势图，发现合格率下降的检验类型。
2. 用柏拉图确定主要不良类型，对排在前面的问题发起[纠正预防](./capa)。
3. 对排名靠前（合格率低）的供应商，结合[不合格品处理](./ncr)和[供应商索赔](./claim)记录进行约谈或评估；[供应商评估](../scm/supplier-eval)的质量得分也会默认取来料批次合格率。
4. 对关键尺寸、参数，用 [SPC 控制图](./spc)进一步分析过程稳定性。

## 权限

需要「质量分析」菜单权限。
