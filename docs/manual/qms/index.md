# 质量管理

质量管理覆盖从来料、生产过程到成品的检验，以及发现不合格后的评审处置、纠正预防和供应商索赔，并用统计图表持续监控质量水平，形成「检验 → 处置 → 改进 → 监控」的质量闭环。

质量管理在顶部导航中显示为「质量」，与[生产制造](../mes/)、采购、仓库、财务等模块紧密联动：来料检验决定[采购入库](../scm/purchase-in)的物料能否使用，首件检验和成品检验控制[工单](../mes/wo)的报工和完工入库，不合格处置会自动冻结或放行库存、生成报废出库单或返工工单，供应商索赔会冲减应付款。

## 功能清单

| 菜单分组 | 页面 | 说明 |
| --- | --- | --- |
| 检验管理 | [检验方案](./plan) | 按检验类型和物料（或物料分类）定义检验项目（定量 / 定性）和抽样方式（全检、固定数量、AQL 抽样） |
| 检验管理 | [质量检验](./inspection) | 来料、过程、成品、首件检验；有方案时自动计算抽样数量和判定标准，逐项录入后自动判定 |
| 不良处理 | [不合格品处理](./ncr) | 检验不合格自动生成处理单，也可手工登记；MRB 评审选择退货、返工、报废、让步接收、挑选，联动库存和工单 |
| 不良处理 | [纠正预防](./capa) | 按 8D 方法（D1 ~ D8）逐步分析和整改，全部完成后做效果验证 |
| 不良处理 | [供应商索赔](./claim) | 向供应商索赔质量损失，确认后自动生成红字应付单冲减应付款 |
| 质量分析 | [质量分析](./analysis) | 各类检验的批次合格率、月度趋势、不良类型柏拉图、供应商来料质量排名 |
| 质量分析 | [SPC 控制图](./spc) | 定量检验项目的控制图和过程能力指数 Cp / Cpk |

## 典型业务流程

### 来料检验闭环

1. 在「仓库 → [物料管理](../wms/material)」中为需要检验的物料勾选「来料检验」，在[检验方案](./plan)中为该物料建立来料检验方案。
2. 仓库办理采购入库后，这些物料的入库数量自动冻结为「待检」，不能出库、调拨或领料。
3. 质检员在[质量检验](./inspection)中新增来料检验，填写采购入库单号（自动带出供应商），按方案逐项录入检验结果，系统自动判定合格或不合格。
4. 确认检验单：
   - 合格或让步接收：冻结的库存自动放行，可以正常使用。
   - 不合格：库存保持冻结，系统通知有采购退货权限的人员，同时自动生成[不合格品处理单](./ncr)。
5. 质量工程师对处理单进行评审处置（退货、报废、让步接收、挑选），系统按处置方式放行冻结库存、生成[报废出库单](../wms/out)或通知[采购退货](../scm/purchase-in#新增采购退货)。
6. 如需追究供应商责任，在处理单详情中点击「供应商索赔」，确认后冲减该供应商的应付款；如需彻底解决问题，点击「发起 8D」进入[纠正预防](./capa)。

### 生产过程质量控制

1. 在[物料清单](../mes/bom)的工艺路线中为关键工序勾选「首件检验」，工单下达时带入工单工序。
2. 车间对该工序报工 1 件后，质检员新增首件检验（填写工单号、选择工序）并确认合格，之后该工序才能继续报工。
3. 生产过程中可随时做过程检验（物料可以是工单产品或工单用料）。
4. 在物料的生产计划属性中勾选「完工需成品检验」的产品，完工入库前必须先做成品检验，累计完工入库数量不能超过已确认的成品检验合格数量。
5. 过程、成品、首件检验不合格时同样自动生成不合格品处理单，可评审为返工（生成[返工工单](../mes/wo#返工工单)）、报废等。

### 持续改进

1. 质量工程师定期查看[质量分析](./analysis)中的合格率趋势、不良柏拉图和供应商排名，找出主要问题。
2. 对有实测数据的定量项目，用 [SPC 控制图](./spc)判断过程是否稳定、过程能力是否充足。
3. 对重复发生或严重的问题发起 8D，按 D1 ~ D8 完成整改，并通过效果验证关闭。

## 单据状态一览

| 单据 | 状态流转 |
| --- | --- |
| 检验单 | 草稿 → 已确认（确认后不能修改、删除） |
| 不合格品处理单 | 待评审 → （审批中）→ 已处置；待评审时可取消 |
| 纠正预防 | 处理中 → 待验证 → 已关闭（验证无效时退回处理中） |
| 供应商索赔 | 待确认 → 已确认 → 已取消 |

## 相关角色

| 角色 | 在质量管理中的工作 |
| --- | --- |
| 质量工程师 | 质量管理的全部功能：维护检验方案、检验、不合格品评审、8D、供应商索赔、质量分析与 SPC；可查看物料、供应商、工单 |
| 车间主管 | 质量检验、登记不合格品（生产中发现的问题） |
| 采购员 | 收到来料不合格、评审为退货的通知后办理采购退货 |
| 仓库管理员 | 确认报废出库单；在「[库存冻结](../wms/hold)」中查看待检和不合格冻结的库存 |
| 总经理 | 启用不合格品处置审批时，审批让步接收、报废或数量较大的处置 |

[首页待办](../guide/home#待办事项)会提醒：检验单待确认、不合格品待评审、纠正预防逾期。

::: tip 提示
质量检验的单号以 ZJ 开头，不合格品处理单以 NC 开头，纠正预防以 CP 开头，供应商索赔以 SZ 开头，编号规则可在「系统管理 → [编码规则](../system/code-rule)」中调整。
:::
