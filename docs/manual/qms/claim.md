# 供应商索赔

供应商索赔用于向供应商追讨因来料质量问题造成的损失（材料报废、停线、返工费用等）。索赔确认后，财务自动生成一张红字应付单冲减该供应商的应付款，供应商也能在[供应商门户](../portal/supplier)中看到索赔。

质量工程师登记，由有确认权限的人员确认。

## 页面入口

质量 → 不良处理 → 供应商索赔

![供应商索赔列表](/images/manual/qms/claim-list.jpg)

## 列表

**查询条件**：状态（待确认、已确认、已取消）、供应商、索赔单号 / 供应商关键字。

| 列 | 说明 |
| --- | --- |
| 索赔单号 | 关联了不合格品处理单时，下方显示处理单号 |
| 供应商 | |
| 索赔日期 | |
| 索赔金额 | |
| 索赔原因 | |
| 状态 / 冲减应付 | 状态；已确认的下方显示生成的应付单号 |
| 操作 | 待确认：「编辑」「确认」「删除」；已确认：「取消」 |

右上角按钮：「新增索赔」。

## 新增索赔

点击「新增索赔」，在右侧抽屉中填写。也可以在已处置且有供应商的[不合格品处理单](./ncr)详情中点击「供应商索赔」，系统自动预填供应商、关联处理单，并把不合格描述作为索赔原因。

![新增供应商索赔](/images/manual/qms/claim-add.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 供应商 | 是 | 被索赔的供应商 |
| 关联不合格品处理单 | 否 | 可按处理单号、供应商搜索，只列出有供应商且未取消的处理单；选择后若还没有选供应商，会自动带出处理单的供应商 |
| 索赔日期 | 是 | 默认今天；也是红字应付单的业务日期 |
| 索赔金额 | 是 | 大于 0，最多 2 位小数 |
| 索赔原因 | 是 | 最多 500 个字符，例如「来料尺寸超差报废，按合同索赔材料费与停线损失」 |

校验规则：关联的不合格品处理单不能是已取消的；处理单有供应商时，索赔供应商必须与之一致，否则提示「索赔供应商与不合格品处理单的供应商不一致」。

## 确认索赔

在列表中点击「确认」，提示「确认索赔？将生成红字应付单冲减该供应商的应付款」，确认后：

1. 索赔单状态变为「已确认」，记录确认时间。
2. 财务自动生成一张该供应商的**红字应付单**（金额为负的索赔金额，来源为质量索赔），冲减应付款，列表中显示应付单号；财务可在「财务 → [应付管理](../fin/ar-ap)」中查看，并可[生成凭证](../fin/ar-ap#生成凭证)：借 应付账款，贷 营业外收入。
3. 给该供应商的门户账号发送站内消息「质量索赔」，供应商在门户的「[质量索赔](../portal/supplier#质量索赔)」中查看；冲减的应付单会进入后续的[供应商对账单](../fin/statement)。

## 取消索赔

已确认的索赔点击「取消」，提示「取消索赔？红字应付单一并删除（已核销或已生成凭证的不能取消）」。确认后状态变为「已取消」，对应的红字应付单被删除。

## 单据状态

| 状态 | 可以做的操作 |
| --- | --- |
| 待确认 | 编辑、确认、删除 |
| 已确认 | 取消 |
| 已取消 | 只能查看 |

## 注意事项

::: warning 注意
- 红字应付单已经核销或已经生成凭证时，不能取消索赔。需要先由财务处理核销或凭证。
- 只有待确认的索赔可以编辑和删除。
:::

::: tip 提示
关联不合格品处理单是选填的，没有处理单的质量损失（例如客户退回后确认为供应商原因）也可以直接登记索赔。
:::

## 权限

| 操作 | 需要的菜单 / 按钮权限 |
| --- | --- |
| 查看 | 「供应商索赔」菜单 |
| 新增索赔、编辑 | 索赔登记 |
| 确认、取消 | 索赔确认 |
| 删除 | 索赔删除 |
