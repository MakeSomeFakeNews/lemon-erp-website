# 检验方案

检验方案规定了「某类检验、某个物料（或某类物料）要检哪些项目、抽多少样、不良多少件判不合格」。建好方案后，新建[质量检验](./inspection)单时系统会自动匹配方案，按送检数量算出抽样数量和判定标准，检验员只需逐项录入结果，系统自动给出结论。

检验方案由质量工程师维护，通常在物料首次需要检验之前建立。

## 页面入口

质量 → 检验管理 → 检验方案

![检验方案列表](/images/manual/qms/plan-list.jpg)

## 新增 / 编辑检验方案

点击「新增方案」或行上的「编辑」，以子页面打开方案表单。

![编辑检验方案](/images/manual/qms/plan-edit.jpg)

### 基本信息

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 方案名称 | 是 | 最多 64 个字符，例如「外壳来料检验」 |
| 检验类型 | 是 | 来料检验 / 过程检验 / 成品检验 / 首件检验，默认来料检验。方案只会被同类型的检验单使用 |
| 启用 | 否 | 默认启用；停用后不再被新的检验单匹配 |
| 适用范围 | 是 | 「指定物料」或「物料分类」二选一，默认指定物料 |
| 物料 | 指定物料时必填 | 方案适用的物料 |
| 物料分类 | 按物料分类时必填 | 方案适用于该分类下的全部物料 |
| 备注 | 否 | 最多 255 个字符 |

### 抽样方式

| 抽样方式 | 需要填写 | 判定规则 |
| --- | --- | --- |
| 全检 | 无 | 送检数量全部检验，Ac = 0、Re = 1，有 1 件不合格即判整批不合格 |
| 固定数量 | 「抽样数量」（必填，正整数）、「允收不良数 Ac」（默认 0） | 每批固定抽取该数量（大于送检数量时全检）；不合格数 ≤ Ac 合格，≥ Ac + 1 不合格 |
| AQL 抽样 | 「AQL」（必填，默认 1.0）、「检验水平」（必填，默认 II） | 按 GB/T 2828.1 正常检验一次抽样方案，送检时按批量计算样本量和 Ac / Re |

新建方案时抽样方式默认为「AQL 抽样」。

### 检验项目

点击「添加项目」增加一行，点击行尾的删除图标删除。至少要有一个检验项目，最多 100 项。

| 列 | 说明 |
| --- | --- |
| 检验项目 | 必填，最多 64 个字符，例如「输出电压」「外观」 |
| 判定方式 | **定量**：录入实测值，与规格限比较；**定性**：按标准目视或功能判定，录入不合格件数 |
| 标准 / 说明 | 定性项目填写判定标准，如「无划伤、无毛刺」；定量项目可填补充说明 |
| 规格限 | 只有定量项目可填：下限 ~ 上限，**至少填一个**；只填上限表示「≤ 上限」，只填下限表示「≥ 下限」；下限不能大于上限 |
| 单位 | 定量项目的单位，如 mm、V、mA |
| 关键 | 勾选后为关键项目：关键项目只要有 1 件不合格，整批直接判不合格 |

### 操作步骤

1. 进入「检验方案」页面，点击「新增方案」。
2. 填写方案名称，选择检验类型。
3. 选择适用范围：针对具体物料选「指定物料」并选择物料；对一类物料通用选「物料分类」并选择分类。
4. 选择抽样方式并填写参数。
5. 逐行添加检验项目，定量项目填写规格限和单位，重要项目勾选「关键」。
6. 点击「保存」（或按 Ctrl / Command + Enter）。

## 方案详情

点击方案名称打开详情，显示检验类型、适用范围、抽样说明，以及各检验项目的判定方式、规格 / 标准和说明，关键项目标有红色「关键」标签。

## 方案如何匹配到检验单

新建或编辑检验单时，选好检验类型、物料并填写送检数量后，系统按以下顺序查找**启用**的方案：

1. 先找同一检验类型、**指定了该物料**的方案；
2. 没有时再找同一检验类型、适用于**该物料所属分类**的方案；
3. 同一层有多个方案时，使用最新建立的一个。

找不到方案时，检验单改为手工填写抽检数量、不良数量和结论。

## 抽样知识：AQL 与检验水平

**AQL（接收质量限）**是可以接受的平均不合格品率上限（百分比）。AQL 越小，要求越严格。可选值：0.040、0.065、0.10、0.15、0.25、0.40、0.65、1.0、1.5、2.5、4.0、6.5。

**检验水平**决定抽样多少：

| 检验水平 | 适用场景 |
| --- | --- |
| I、II、III（一般检验水平） | 常规检验；**一般用 II**，需要更少样本用 I，需要更严格区分用 III |
| S-1、S-2、S-3、S-4（特殊检验水平） | 样本量小，适用于破坏性检验或检验费用很高的场合 |

**系统的计算过程**（GB/T 2828.1 正常检验一次抽样）：

1. 按送检数量（批量）和检验水平查出「样本量字码」（A ~ R）；
2. 按字码和 AQL 查出样本量、接收数 Ac 和拒收数 Re。标准表中带箭头（↑ / ↓）的格子会沿用上方或下方的方案，因此最终样本量可能与字码本身对应的样本量不同，例如批量 100、检验水平 II、AQL 1.0 时字码为 F，但实际抽样 13 件、Ac 0 / Re 1；
3. 样本量大于批量时全检；批量小于 2 时也全检。

判定：样本中不合格数 ≤ Ac 判合格，≥ Re 判不合格。

## 注意事项

::: tip 提示
- 一个物料同时有「指定物料」方案和「物料分类」方案时，优先使用指定物料的方案，可以用分类方案做通用规则、用物料方案做特殊要求。
- 想在 [SPC 控制图](./spc) 中分析某个尺寸或参数，需要把它设为**定量**项目，并在检验时录入每个样本的实测值。
:::

::: warning 注意
- 修改或删除方案不影响已经保存的检验单：检验单保存时已记录了当时的检验项目、规格限和逐项结果。
- 删除方案前请确认没有正在使用该方案的草稿检验单，否则这些检验单再编辑时需要重新匹配方案。
:::
