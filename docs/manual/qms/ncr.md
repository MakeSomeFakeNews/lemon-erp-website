# 不合格品处理

不合格品处理（MRB，物料评审）用于对检验不合格或生产、客户反馈中发现的不合格品进行评审，决定如何处置（退货、返工、报废、让步接收、挑选）以及由谁承担责任。处置结果会自动联动库存冻结、报废出库和返工工单；处理完成后还可以直接发起 8D 或向供应商索赔。

质量工程师负责评审处置，车间主管等可以登记生产中发现的不合格品。

## 页面入口

质量 → 不良处理 → 不合格品处理

![不合格品处理列表](/images/manual/qms/ncr-list.jpg)

::: tip 微信小程序
发现不合格品时可以在[微信小程序](../miniapp/quality#不合格品)中现场登记；评审处置仍在本页面进行。
:::

## 处理单的来源

| 来源 | 产生方式 |
| --- | --- |
| 检验不合格 | [质量检验](./inspection)确认为不合格时**自动生成**：来料、成品检验按送检数量，过程、首件检验按不良数量（没有不良数量时按送检数量）；自动带入物料、批次、供应商、工单、来源单号、不良类型和描述 |
| 生产发现 | 手工登记 |
| 客户投诉 | 手工登记 |
| 其他 | 手工登记 |

自动生成时，系统会给有「评审处置」权限的人员发送「待评审的不合格品」消息；[首页待办](../guide/home#待办事项)也会显示待评审数量。

## 列表

**查询条件**：状态（待评审、审批中、已处置、已取消）；单号、来源单号、物料、供应商关键字。

| 列 | 说明 |
| --- | --- |
| 处理单号 | 点击查看详情；下方为来源标签 |
| 来源单据 | 来源单号（采购入库单号或工单号）；下方显示供应商或工单号 |
| 物料 | 物料编码、名称；数量、单位和批次 |
| 不合格描述 | 不良类型和描述 |
| 处置 / 责任 | 已评审的显示处置方式和责任方，未评审显示「待评审」 |
| 状态 | 待评审 / 审批中 / 已处置 / 已取消 |
| 操作 | 「查看」；待评审的还有「评审处置」 |

右上角按钮：「登记不合格」。

## 登记不合格品

点击「登记不合格」，在右侧抽屉中填写：

![登记不合格品](/images/manual/qms/ncr-add.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 来源 | 是 | 生产发现（默认）/ 客户投诉 / 其他。「检验不合格」在下拉中置灰并注明「（由检验单自动生成）」，手工登记不能选择 |
| 物料 | 是 | 不合格的物料或产品 |
| 数量 | 是 | 必须大于 0 |
| 生产工单号 | 否 | 填写后校验工单是否存在；**返工处置需要关联工单** |
| 批次号 | 否 | |
| 供应商 | 否 | 供应商原因时填写，便于后续索赔 |
| 不良类型 | 否 | 外观不良、尺寸偏差、功能失效、焊接不良、来料不良、其他 |
| 不合格描述 | 是 | 最多 500 个字符 |

## 评审处置

在列表或详情中点击「评审处置」，弹出评审对话框：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 处置方式 | 是 | 退货、返工、报废、让步接收、挑选（不适用的选项置灰，见下表） |
| 返工完工入库仓库 | 返工时必填 | 返工工单完工后入库的仓库 |
| 责任方 | 是 | 供应商 / 生产 / 设计 / 其他（[业务字典](../system/biz-dict)，可新增）；来料不合格默认选中「供应商」 |
| 评审意见 | 否 | 最多 500 个字符 |

### 处置方式与联动

| 处置方式 | 适用范围 | 系统执行的动作 |
| --- | --- | --- |
| 退货 | 只适用于**来料不合格**（有供应商和采购入库单号、没有关联工单） | 冻结的库存保持冻结，给有采购退货权限的人员发送消息，请其办理[采购退货](../scm/purchase-in#新增采购退货) |
| 返工 | 只适用于**关联了生产工单**的不合格品 | 按不合格数量为该产品生成一张**草稿[返工工单](../mes/wo#返工工单)**（入库仓库为评审时选择的仓库），处置结果中显示返工工单号；返工工单下达、生产后重新完工入库 |
| 报废 | 全部 | 来料：放行冻结库存，并按仓库生成**[报废出库单](../wms/out)草稿**，由仓库确认后出库；序列号管理的物料不自动生成出库单，提示手工办理报废出库。非来料只记录「已判定报废」 |
| 让步接收 | 全部 | 来料：放行冻结库存，可正常使用。非来料只记录 |
| 挑选 | 全部 | 只记录处置结果（全检挑出不良品后，合格品按让步或重新检验处理） |

处置执行后，详情的「处置结果」中会写明执行情况，例如「冻结库存保持冻结，已通知采购办理退货」「已放行冻结库存，报废出库单 xxx（草稿，请仓库确认）」「已生成返工工单（草稿）」。

### 处置审批

系统内置了「不合格品处置审批」流程（流程标识 qms_ncr，默认未发布）：

- **未发布**时，提交评审后立即执行处置，状态变为「已处置」。
- 在「流程中心 → 流程管理 → [流程模型](../workflow/model)」中**发布**该流程后，提交评审进入「审批中」，审批通过后自动执行处置；审批拒绝或撤回时退回「待评审」，可以重新评审。
- 内置流程：质量工程师审核 → 处置方式为让步接收、报废，或数量 ≥ 100 时由总经理审批。可在[流程设计器](../workflow/designer#条件分支)中按处置方式、数量、责任方设置条件分支。

审批中的处理单在详情右上角有「审批记录」按钮，可查看审批进度。

## 处理单详情

![不合格品处理详情](/images/manual/qms/ncr-detail.jpg)

详情显示来源（检验单号）、状态、物料、数量、批次、来源单据、供应商 / 工单、不合格描述、登记人和时间、处置完成时间；评审后显示「评审处置」：处置方式、责任方、评审意见、处置结果（含返工工单号）。

详情右上角的按钮：

| 按钮 | 出现条件 | 作用 |
| --- | --- | --- |
| 评审处置 | 待评审 | 打开评审对话框 |
| 取消 | 待评审，且来源为检验不合格 | 检验误判时取消处理单 |
| 删除 | 手工登记的，且状态为待评审或已取消 | 删除处理单 |
| 审批记录 | 提交过审批 | 查看审批流程 |
| 发起 8D | 已处置 | 跳转到[纠正预防](./capa)并预填来源为该处理单 |
| 供应商索赔 | 已处置且有供应商 | 跳转到[供应商索赔](./claim)，预填供应商、关联处理单和索赔原因 |

## 单据状态

| 状态 | 说明 | 可以做的操作 |
| --- | --- | --- |
| 待评审 | 新生成或审批被退回 | 评审处置、取消（检验生成的）、删除（手工登记的） |
| 审批中 | 已提交处置审批 | 查看审批记录，等待审批结果 |
| 已处置 | 处置已执行 | 发起 8D、供应商索赔 |
| 已取消 | 误判或误登记 | 删除（手工登记的） |

## 注意事项

::: warning 注意
- 检验不合格自动生成的处理单**不能删除**，检验误判时请「取消」。
- 已提交评审（审批中、已处置）的处理单不能删除、取消。
- 选择退货后，库存仍是冻结状态，需要采购人员在采购模块办理采购退货才会真正出库。
- 报废生成的出库单是草稿，仓库确认后才会扣减库存。
:::

::: tip 提示
来料让步接收、报废会放行冻结库存；如果该批库存已经通过采购退货退回，处置结果会显示「没有冻结库存」。
:::
