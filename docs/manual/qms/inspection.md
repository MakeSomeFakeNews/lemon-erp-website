# 质量检验

质量检验用于记录来料、生产过程、成品和首件的检验结果。有[检验方案](./plan)时，系统按送检数量自动计算抽样数量和判定标准，检验员逐项录入后系统实时给出合格 / 不合格结论；没有方案时手工填写抽检数、不良数和结论。检验单确认后会联动库存冻结、首件报工、成品完工入库和不合格品处理。

质检员、车间主管和质量工程师使用本页面。

## 页面入口

质量 → 检验管理 → 质量检验

![质量检验列表](/images/manual/qms/inspection-list.jpg)

::: tip 微信小程序
质量人员可以在[微信小程序](../miniapp/quality#质量检验)中新增检验单、按检验方案逐项录入实测值并确认。
:::

## 检验类型

| 类型 | 用途 | 关联单据 | 物料要求 |
| --- | --- | --- | --- |
| 来料检验 | 采购到货后检验 | [采购入库](../scm/purchase-in)单号（选填），填写后自动带出供应商 | 必须是该采购入库单中的物料，送检数量不能超过该物料的入库数量 |
| 过程检验 | 生产过程中抽检 | 生产工单号（选填） | 填写工单号时，物料必须是工单产品或工单用料 |
| 成品检验 | 工单完工前检验 | 生产工单号（选填） | 填写工单号时，物料必须是工单产品 |
| 首件检验 | 关键工序首件确认 | 生产工单号（**必填**）+ 工序（必填） | 物料必须是工单产品 |

## 列表

**查询条件**：检验类型、检验结论（合格 / 不合格 / 让步接收）、单号 / 来源单号 / 物料关键字、检验日期范围。

| 列 | 说明 |
| --- | --- |
| 检验单号 / 类型 | 单号（点击查看详情）、检验类型标签和使用的检验方案名称 |
| 来源 | 来源单号；下方显示供应商（来料）、工序名称（首件）或「生产工单」 |
| 物料 | 物料编码和名称，有批次时显示批次号 |
| 数量 | 送检数量、抽检数量；不良数量（大于 0 时标红），按方案检验时显示 Ac / Re |
| 结论 | 合格 / 不合格 / 让步接收；未确认的显示橙色「草稿」标签；有主要不良类型时一并显示 |
| 检验日期 | 检验日期和检验人 |
| 操作 | 草稿：「编辑」「确认」「删除」；已确认：「查看」 |

右上角按钮：「新增检验」。

## 新增检验单

点击「新增检验」，以子页面打开检验单表单。

![新增检验单（手工判定）](/images/manual/qms/inspection-add.jpg)

### 基本信息

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 检验类型 | 是 | 默认来料检验 |
| 采购入库单号 / 生产工单号 | 首件检验必填，其他选填 | 来料检验显示为「采购入库单号」，其他类型显示为「生产工单号」 |
| 工序 | 首件检验必填 | 填写工单号后自动加载该工单的工序，要求首件检验的工序标有「（要求首件）」；若物料还没选，会自动带出工单产品 |
| 物料 | 是 | 被检验的物料 |
| 批次号 | 否 | 来料检验填写批次时，确认后只放行或冻结该批次的库存 |
| 送检数量 | 是 | 必须大于 0；即检验批的批量，用于计算抽样数量 |
| 检验日期 | 是 | 默认今天 |
| 主要不良类型 | 否 | 外观不良、尺寸偏差、功能失效、焊接不良、来料不良、其他；用于[质量分析](./analysis)中的不良柏拉图 |
| 不良描述 | 否 | 最多 255 个字符；不合格时会作为不合格品处理单的描述 |

### 按方案逐项录入

选好检验类型、物料并填写送检数量后，系统自动匹配检验方案。匹配到方案时，表单下方出现蓝色提示条，显示方案名称、抽样方式、样本量字码、**抽样件数**和 **Ac / Re**，并列出方案的检验项目：

![按检验方案逐项录入](/images/manual/qms/inspection-add-plan.jpg)

| 项目类型 | 录入方式 | 判定 |
| --- | --- | --- |
| 定量项目 | 录入各样本的实测值，用逗号、空格或换行分隔（提示中显示应录入的个数） | 超出规格上下限的实测值计为不合格，「判定」列显示录入个数和超差个数 |
| 定性项目 | 录入不合格件数（不能超过抽样数量） | 不合格件数大于 0 显示「不合格」 |

表格下方实时显示「不合格合计」和**判定结果**：

- 任一**关键项目**有不合格，判**不合格**；
- 或各项目不合格数合计 ≥ Re，判**不合格**；
- 否则判**合格**。

每个定量项目至少要录入一个实测值才能保存。点击提示条中的「不按方案，手工判定」可改为手工填写；之后可点击「按方案逐项录入」切换回来。

### 手工判定

没有匹配的方案或选择手工判定时，填写：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 抽检数量 | 是 | 大于 0，不能大于送检数量 |
| 不良数量 | 否 | 默认 0，不能大于抽检数量 |
| 检验结论 | 是 | 合格 / 不合格 / 让步接收，默认合格 |

### 操作步骤

1. 点击「新增检验」，选择检验类型。
2. 来料检验填写采购入库单号；过程、成品检验可填写生产工单号；首件检验填写生产工单号并选择工序。
3. 选择物料，填写批次号、送检数量、检验日期。
4. 按方案逐项录入实测值或不合格数（或手工填写抽检数、不良数和结论），不合格时选择主要不良类型、填写不良描述。
5. 点击「保存」，检验单为草稿。
6. 核对无误后在列表中点击「确认」。

## 检验单详情

点击单号或「查看」打开详情，显示检验类型、来源（含供应商）、结论、物料、批次、工序、数量、检验方案（含样本量字码、Ac / Re）、检验日期和检验人、不良信息；按方案检验的还列出各项目的规格、全部实测值（超出规格的标红）和不合格数。

![检验单详情](/images/manual/qms/inspection-detail.jpg)

## 单据状态

| 状态 | 可以做的操作 |
| --- | --- |
| 草稿 | 编辑、确认、删除 |
| 已确认 | 只能查看，不能修改、删除 |

确认时的提示：结论为不合格时提示「确认后生成不合格品处理单，检验单不能再修改或删除」。

## 确认后的联动

| 场景 | 系统自动处理 |
| --- | --- |
| 来料检验（填写了采购入库单号）合格 / 让步接收 | 放行该采购入库单中该物料（填写批次时只处理该批次）冻结的待检库存，可正常出库、领料 |
| 来料检验不合格 | 库存保持冻结；给有采购退货权限的人员发送站内消息「来料检验不合格」 |
| 任意类型检验不合格 | 自动生成[不合格品处理单](./ncr)（来料、成品按送检数量，过程、首件按不良数量），并通知有评审权限的人员 |
| 首件检验确认且结论不是不合格 | 该工单工序解除「只能报工 1 件」的限制 |
| 成品检验确认且结论不是不合格 | 计入工单的成品检验合格数，用于完工入库控制 |
| 来料检验结果 | 计入[供应商绩效](../scm/supplier-eval#供应商绩效)的来料批次合格率；供应商评估时质量得分默认取该合格率 |

### 来料冻结与放行

在「仓库 → [物料管理](../wms/material)」中勾选了「来料检验」的物料，采购入库后入库数量自动冻结为待检，出库、调拨、领料只能使用未冻结的数量。冻结和放行记录可在仓库的「[库存冻结](../wms/hold)」页面查看。来料检验不合格的库存一直保持冻结，直到不合格品处理单评审为让步接收或报废时放行，或者通过[采购退货](../scm/purchase-in#新增采购退货)退回（采购退货优先退冻结的不合格品）。

### 首件检验限制报工

在[物料清单](../mes/bom)的工艺路线中勾选「首件检验」的工序，工单下达时会带入该要求。该工序在首件检验确认且结论不是不合格之前，累计报工（合格 + 报废）只能 1 件，超出时提示「需首件检验合格后才能继续报工，请先报工 1 件并提交首件检验」。

### 完工需成品检验

在物料的生产计划属性中勾选「完工需成品检验」的产品，[生产工单](../mes/wo)完工入库的累计数量不能超过该工单已确认、结论不是不合格的成品检验的送检数量合计，否则提示「该产品完工需成品检验……请先做成品检验」。

## 注意事项

::: tip 提示
- 让步接收视同合格：放行库存、计入合格率、解除首件限制、计入成品检验合格数。
- 检验员可以先保存草稿，等组长复核后再确认；[首页待办](../guide/home#待办事项)会显示待确认的检验单数量。
:::

::: warning 注意
- 检验单一旦确认就不能修改或删除。来料误判为不合格时，可在不合格品处理中「取消」处理单，或评审为让步接收以放行库存。
- 来料检验不填写采购入库单号时只记录检验结果，不会放行或冻结库存，也不会带出供应商、不计入供应商排名。
- 修改送检数量、物料或检验类型时会重新匹配方案、重新计算抽样数量，已录入的同一项目结果会保留。
:::
