# 纠正预防

纠正预防（CAPA）用 8D 方法系统地解决质量问题：从组建团队、描述问题、临时围堵，到分析根本原因、制定并验证永久措施、防止再发，最后总结关闭。每张纠正预防单包含 D1 ~ D8 八个步骤，全部完成后提交效果验证，验证有效才能关闭。

质量工程师发起和验证，各步骤的负责人填写内容。

## 页面入口

质量 → 不良处理 → 纠正预防

![纠正预防列表](/images/manual/qms/capa-list.jpg)

## 列表

**查询条件**：状态（处理中、待验证、已关闭）；单号、标题关键字。

| 列 | 说明 |
| --- | --- |
| 单号 | 点击打开详情；下方为来源标签，来源为不合格品时显示处理单号 |
| 问题标题 | |
| 负责人 | |
| 进度 | 已完成步骤数 / 8 的进度条 |
| 要求完成 | 要求完成日期；未关闭且已过期的标红并显示「已逾期」 |
| 状态 | 处理中 / 待验证 / 已关闭 |
| 登记时间 | |
| 操作 | 处理中显示「处理」，其他显示「查看」 |

右上角按钮：「新增 8D」。

## 新增纠正预防

点击「新增 8D」，在右侧抽屉中填写。也可以在已处置的[不合格品处理单](./ncr)详情中点击「发起 8D」，自动打开本表单并选好来源处理单。

![新增纠正预防](/images/manual/qms/capa-add.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 来源 | 是 | 不合格品 / 客户投诉 / 内部发现（默认）/ 审核发现 |
| 不合格品处理单 | 来源为不合格品时必填 | 可按处理单号、物料搜索 |
| 问题标题 | 是 | 最多 128 个字符 |
| 问题描述 | 否 | 最多 1000 个字符 |
| 负责人 | 是 | 默认当前用户；同时作为各步骤的默认负责人 |
| 要求完成日期 | 是 | 默认 30 天后 |

保存后系统自动生成 D1 ~ D8 八个步骤，并给负责人发送「纠正预防待处理」消息。

## 8D 步骤

| 步骤 | 名称 | 填写要点（页面上的提示） |
| --- | --- | --- |
| D1 | 组建团队 | 成立跨部门小组，明确组长与成员分工 |
| D2 | 问题描述 | 用 5W2H 描述问题：什么产品、什么不良、数量、何时何地发现 |
| D3 | 临时措施 | 围堵措施：隔离、挑选在库与在途产品，防止不良流出 |
| D4 | 根本原因 | 用鱼骨图、5Why 分析产生原因与流出原因，并验证 |
| D5 | 永久措施 | 针对根本原因制定永久纠正措施，评估风险 |
| D6 | 实施验证 | 实施永久措施并跟踪效果，撤销临时措施 |
| D7 | 预防再发 | 更新作业指导书、FMEA、控制计划，横向展开到类似产品与工序 |
| D8 | 总结表彰 | 总结经验，认可团队贡献，关闭问题 |

## 处理步骤

在列表中点击「处理」打开详情。详情上方显示来源、负责人、要求完成日期、状态、登记人、进度和问题描述，下方以时间线列出 D1 ~ D8，已完成的步骤为绿色并显示负责人和完成日期。

![纠正预防详情](/images/manual/qms/capa-detail.jpg)

### 填写步骤

1. 点击步骤下方的「填写」，展开编辑区域。
2. 填写内容（最多 2000 个字符），可以修改该步骤的负责人。
3. 完成时勾选「已完成」，点击「保存」；点击「取消」放弃修改。

![填写 8D 步骤](/images/manual/qms/capa-step.jpg)

勾选「已完成」时内容不能为空，否则提示「请先填写内容再标记完成」。完成日期自动记为第一次标记完成的日期；取消勾选后完成日期清空。

### 提交效果验证

D1 ~ D8 全部标记完成后，详情右上角的「提交验证」按钮变为可用（未完成时鼠标悬停会提示还有几个步骤未完成），点击后状态变为「待验证」，步骤不能再修改。

### 效果验证

待验证的单据由有验证权限的人员点击「效果验证」：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 验证结论 | 是 | 「有效，关闭」或「无效，退回继续处理」 |
| 验证说明 | 是 | 最多 500 个字符，例如「连续 3 批来料检验无同类不良」 |

验证有效时状态变为「已关闭」；无效时退回「处理中」，验证说明保留在详情中，可继续修改步骤后再次提交验证。

## 单据状态

| 状态 | 可以做的操作 |
| --- | --- |
| 处理中 | 编辑基本信息、填写步骤、提交验证（全部步骤完成后）、删除 |
| 待验证 | 效果验证 |
| 已关闭 | 只能查看 |

## 逾期提醒

系统定时任务「纠正预防逾期提醒」默认每天 9:20 运行，超过要求完成日期仍未关闭的纠正预防单，会给负责人发送「纠正预防已逾期」消息（同一单据每天只提醒一次）。运行时间可在「系统监控 → [定时任务](../monitor/job)」中调整。[首页待办](../guide/home#待办事项)也会显示逾期数量。

## 注意事项

::: tip 提示
- 详情右上角的「编辑」可修改来源、标题、描述、负责人和要求完成日期，只在处理中可用；修改负责人不会改变各步骤已设置的负责人。
- 8D 的效果验证建议由发起人或质量主管完成，而不是步骤负责人本人。
:::

::: warning 注意
只有处理中的纠正预防单可以删除，删除后步骤内容一并删除。
:::
