# 员工自助

小程序中的员工自助与电脑端「人力资源 → [员工自助](../hr/self)」功能相同：打卡、查看考勤和假期余额、申请和撤销请假加班、查看工资条、绩效自评和评分。员工只能看到和操作自己的数据。

## 页面入口

工作台「办公」分组：**打卡**、**考勤**、**请假加班**、**工资条**、**绩效**。「我的」页面的常用入口中也有打卡、请假加班、工资条，「年假（天）」统计点击进入考勤。

这些入口登录即可使用，不需要额外授权。

::: warning 注意
当前账号必须在「[员工档案](../hr/employee)」中关联了员工，才能打卡、请假、查看考勤和工资条。没有关联时页面显示「当前账号没有关联员工档案」和「请联系人事在「员工档案」中为你关联登录账号，关联后可以打卡、请假、查看工资条和参与绩效考核。」。绩效中的「待我评分」不需要员工档案。
:::

## 打卡

![打卡](/images/manual/miniapp/clock.jpg)

- 顶部显示员工姓名和工号、当前时间（每秒刷新）和日期；
- 中间的大圆按钮：当天还没有打卡时为「**上班打卡**」，打过上班卡后变为「**下班打卡**」（橙色），按钮上显示当前时间。点击后立即打卡，成功时手机振动并提示「上班打卡成功 08:58」或「下班打卡成功 18:05」；
- 规则说明：「当天第一次打卡为上班卡，之后每次打卡更新下班卡」，下班卡以最后一次为准；
- 下方卡片显示今天的上班、下班打卡时间（未打卡时显示「未打卡」）、考勤状态（正常、迟到、早退、缺卡等）和出勤时长；
- 「查看考勤」进入考勤页面。

迟到、早退、缺卡和出勤时长的判断规则与电脑端相同，见[员工自助 - 打卡](../hr/self#打卡)和[考勤管理](../hr/attendance)。

::: tip 提示
小程序打卡不采集定位，与电脑端「员工自助」中的打卡是同一份记录。
:::

## 考勤

![考勤](/images/manual/miniapp/attendance.jpg)

- **月历**：用「‹」「›」切换月份（不能切换到未来月份）。休息日为灰色，节假日和调休日显示名称（如「国庆节」「国庆节调休」），今天有蓝色边框。日期下方的圆点：绿色正常、橙色异常（迟到、早退、缺卡）、红色旷工、蓝色有请假或加班；底部有图例；
- **某天详情**：点击日期显示当天的上班、下班时间、出勤时长和状态，以及当天的请假 / 加班（类型、小时数、审批状态）；没有记录时显示「没有打卡记录」或「旷工」；
- **月度汇总**：应出勤、实际出勤（天）、迟到、早退、缺卡（次）、旷工（天）、请假、加班（小时）；有迟到、早退、缺卡时数字为橙色，有旷工时为红色；
- **假期余额**：年假余额（天）及「共 N 天，已用 M 天」，调休余额（小时）。

## 请假加班

![请假加班](/images/manual/miniapp/leave.jpg)

列表显示本人的请假加班申请：种类（请假显示假期类型；加班显示「加班」或「加班（转调休）」）、状态、起止时间、单号、时长、事由和审批意见。

- **撤销**：审批中的申请，或已通过但还没有开始的申请显示「撤销」，确认「撤销该申请？」后提示「已撤销」；
- 底部「**申请请假**」「**申请加班**」打开申请页。

### 申请请假 / 申请加班

![申请请假](/images/manual/miniapp/leave-apply.jpg)

| 字段 | 说明 |
| --- | --- |
| 假期类型 | 请假必填，默认事假；年假显示剩余天数（如「年假（余 5 天）」），选择调休时显示「调休余额 N 小时」 |
| 补偿方式 | 加班时选择「发加班费」（默认）或「转调休」 |
| 开始时间 / 结束时间 | 必填，分别选择日期和时间。请假默认明天 09:00 至 18:00；加班默认明天 18:30 至 20:30。修改开始日期时，结束日期早于开始日期会自动调整 |
| 时长（小时） | 必填，0.5 的倍数。修改时间后自动估算：请假同一天按时间差（跨 13:00 扣 1 小时午休，最多 8 小时），跨天按工作日每天 8 小时；加班按起止时间差。提示「按工作日每天 8 小时自动计算，可以修改；请半天填 4 小时」，加班提示「加班费默认工作日 1.5 倍、休息日 2 倍、法定节假日 3 倍」 |
| 事由 | 选填，最多 255 字 |

点击「**提交**」：结束时间不晚于开始时间时提示「结束时间要晚于开始时间」；时长不是 0.5 的倍数时提示「时长须为 0.5 小时的倍数，最少 0.5 小时」。成功后提示「已提交，等待审批」并返回列表。

年假、调休余额、重复申请、工资表已确认等后端校验与电脑端相同，见[员工自助 - 请假加班](../hr/self#请假加班)。提交后如果企业发布了请假加班审批流程，审批人会在[审批](./approval)中收到待办；否则由人事在电脑端[假勤审批](../hr/leave)中审批。

::: tip 提示
时长估算固定按每天 8 小时计算，企业在[业务参数](../system/biz-rule)中修改了每日工时或午休时长时，请按实际应请的小时数修改「时长」。
:::

## 工资条

![工资条](/images/manual/miniapp/payslip.jpg)

按月份列出已确认（或已发放）的工资条，每期显示月份和实发工资，默认展开最近一期，点击月份展开或收起明细：

- **收入**：基本工资、津贴补贴、加班费（含加班小时）、绩效奖金（含等级）、计件工资和销售提成（有金额时显示）、其他奖金、考勤扣款（旷工天数、迟到早退次数）、应发工资；
- **扣除**：个人社保、个人公积金、个人所得税、其他扣款、实发工资；
- **个税**：专项附加扣除、本年累计应纳税所得额、本年累计已扣个税、状态。

还没有已确认的工资条时显示「还没有已确认的工资条」。草稿状态的工资表员工看不到。

## 绩效

![绩效考核](/images/manual/miniapp/appraisal.jpg)

两个分段，数字角标为待处理的数量：

- **我的考核**：本人的考核表，显示考核名称、状态、评分人、自评分、得分、等级。待自评且考核进行中的显示「去自评」，已完成的显示「查看结果」；
- **待我评分**：本人作为评分人的考核表，显示被考核人（工号、姓名）、部门、自评分、得分、等级。未完成且考核进行中的显示「去评分」。

首次进入时，有待你评分的考核表默认显示「待我评分」，否则显示「我的考核」。没有员工档案的账号只看「待我评分」。

点击考核表打开评分页：

- 上方为考核、被考核人、评分人、状态（查看结果时还显示自评分、得分、等级）；
- 每个指标显示名称、说明、权重，在右侧输入 0 - 100 分；评分时显示员工的自评分（「自评 N」）；
- 底部实时显示「加权得分」，评分时同时显示对应等级（S ≥ 90、A ≥ 80、B ≥ 70、C ≥ 60、D）；
- 自评可填写自评总结，评分可填写评语（选填，最多 500 字），评分时可以看到员工的自评总结；
- 点击「**提交**」：有指标没打分或超出范围时提示「请为每个指标评分（0 - 100）」。自评需确认「提交后不能修改，确定提交吗？」，成功提示「自评已提交」；评分成功提示「评分已保存」。

评分规则见[绩效考核](../hr/perf)。
