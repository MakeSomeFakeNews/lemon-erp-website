# 项目工时

项目成员在小程序中按周填报本人工时，项目经理批量审核成员的工时。与电脑端「项目管理 → [工时管理](../pm/timesheet)」的「我的工时」「工时审批」是同一份数据，填报校验和审批规则完全相同。

## 我的工时

工作台「办公 → **填工时**」，登录即可使用（只能为你参与的项目填报）。

![我的工时](/images/manual/miniapp/timesheet.jpg)

- **周切换**：顶部显示本周起止日期和「本周合计 N 小时」（不含已驳回的工时），「‹」「›」切换上一周 / 下一周，不能切换到本周之后；
- **日期条**：周一到周日每天一格，显示当天已填工时（超过 8 小时数字为醒目颜色），点击选中某一天，今天有特殊标记；
- **当天工时**：列出选中日期的工时记录：项目、任务、工时、工作内容、状态（待审批、已通过、已驳回，驳回的显示「驳回原因：…」）。没有记录时显示「当天没有填报工时」；
- 没有通过审批的记录显示「编辑」「删除」：点击记录或「编辑」进入修改；「删除」需确认「确定删除这条工时？」，提示「已删除」；已通过的记录不能修改；
- 底部「**填报工时**」为选中的日期填报（选中的是未来日期时按钮不可用）。

### 填报 / 修改工时

![填报工时](/images/manual/miniapp/timesheet-edit.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 项目 | 是 | 「只能选择你参与的、未完成的项目」；只参与一个项目时自动选中。没有可选项目时显示「你还没有参与任何进行中的项目」 |
| 任务 | 否 | 该项目的末级任务（没有任务查看权限时为分配给你的任务），默认「不指定任务」 |
| 日期 | 是 | 默认为列表中选中的日期，不能选择未来日期 |
| 工时 | 是 | 默认 8，「－」「＋」按 0.5 小时调整，也可以直接输入；0.5 ~ 24 小时，最多 1 位小数 |
| 工作内容 | 否 | 最多 255 字 |

点击「**保存并提交**」，保存后状态为「待审批」。校验提示：「工时须在 0.5 ~ 24 小时之间」「工时最多 1 位小数」「不能填报未来日期的工时」。修改已驳回的工时时页面下方显示驳回原因，保存后重新变为待审批。

当天工时超过考勤出勤时长等情况可以保存，但会弹出「已保存，但……」的提示，规则见[工时管理 - 填报校验](../pm/timesheet#填报校验)。

## 工时审核

工作台「办公 → **工时审核**」，需要工时查看权限；批量通过、驳回还需要工时审批权限。

![工时审核](/images/manual/miniapp/timesheet-review.jpg)

- 顶部「待审批」「已通过」「已驳回」三个分段；
- 每条显示成员和工时、状态、日期、项目 / 任务、工作内容，已驳回的显示驳回原因，已审批的显示审批人；
- 「待审批」分段中，点击记录勾选或取消（其他状态不能勾选）；底部显示「已选 N 项，X 小时」，点击左侧圆圈可全选当前已加载的记录；
- 「**通过**」：确认「确定通过选中的 N 条工时？」后提示「已通过 N 条」；
- 「**驳回**」：在弹窗中填写驳回原因（必填，最多 255 字）后确定，提示「已驳回 N 条」。

只有项目经理（或拥有全部数据权限的管理员）可以审批该项目的工时，且不能审批自己的工时，规则见[工时管理 - 审批规则](../pm/timesheet#审批规则)。
