# 工作台与消息

工作台是小程序的首页，汇总经营数据、待办事项和全部功能入口；消息页面集中查看系统发给你的站内消息；通知公告查看发给你的公司公告。两者都是登录即可使用，显示的内容按你的权限而定，与电脑端[工作台首页](../guide/home)和[个人中心与消息](../guide/profile)的数据一致。

## 工作台

底部导航第一个「**工作台**」。

![工作台](/images/manual/miniapp/workbench.jpg)

页面从上到下依次是：

| 区域 | 说明 |
| --- | --- |
| 问候语 | 「你好，姓名」，下方显示所属企业（租户）和部门 |
| 经营概览 | 本月销售额、本月采购额、应收余额、应付余额、待发货订单、在制工单等卡片，与电脑端首页的「经营概览」相同。只显示你有权限查看的指标（例如没有财务权限时不显示应收、应付余额）；金额以「万」为单位简写；能和上月同期比较的指标显示「较上月同期 +x%」（上涨绿色、下降红色） |
| 待办事项 | 各模块汇总的待处理事项及数量，例如「待我审批」「请假加班待审批」「工单逾期未完工」「采购订单逾期未到货」「设备保养到期」「库存低于安全库存」「触发中的经营预警」等，圆点颜色表示紧急程度（红色为预警，橙色为提醒）。没有待办时显示「暂无待办」 |
| 功能入口 | 按「办公」「销售与服务」「仓储生产」「设备与质量」四组显示你有权限的功能，点击进入 |

下拉页面可以刷新数据；每次回到工作台也会自动刷新，并更新底部导航「消息」上的未读数。

### 点击待办事项

点击待办事项时，小程序会把它转到对应的小程序页面，例如：

| 待办 / 消息指向的电脑端页面 | 小程序中打开 |
| --- | --- |
| 我的待办、我的已办、我的申请、抄送我的 | 审批（自动切到对应分段） |
| 发起申请 | 发起申请 |
| 全部公告（公告消息） | 通知公告（直接打开该公告） |
| 员工自助 | 打卡 |
| 工时 | 工时审核 |
| 客户、跟进记录 | 跟进（今日待跟进） |
| 商机、线索、服务工单 | 对应的列表 |
| 销售订单 | 销售订单 |
| 库存查询 | 库存查询 |
| 采购入库、移动作业 - 收货 | 扫码收货 |
| 发货通知、移动作业 - 拣货 | 拣货 |
| 移动作业 - 上架 | 上架 |
| 盘点单、移动作业 - 盘点 | 盘点 |
| 生产工单 | 报工 |
| 设备台账、设备维护、检验单、不合格品处理 | 对应的列表 |

待办链接中的筛选条件会一起带到小程序页面，与电脑端相同：例如「库存低于安全库存」打开库存查询时自动打开「只看低于安全库存」，「检验单待确认」打开质量检验时只显示草稿，「我处理中的服务工单」只显示指派给我的工单。

小程序中没有对应页面、或你没有该入口权限的事项（例如「请假加班待审批」「补料待发料」「触发中的经营预警」），点击后提示「**该事项请在电脑端处理**」，请到电脑端处理。

::: tip 提示
点击待办事项时，小程序会顺便申请[审批提醒](./approval#审批提醒)的订阅授权（微信弹出授权框时可以选择「允许」）。
:::

## 消息

底部导航「**消息**」。未读消息的数量显示在导航图标的红色角标上（超过 99 显示「99+」）。

![消息](/images/manual/miniapp/message.jpg)

- 有未读的[通知公告](#通知公告)时，页面顶部显示橙色提示条「通知公告　N 条未读　›」，点击进入公告列表；
- 顶部「**未读**」「**全部**」切换，默认显示未读消息；
- 每条消息显示标题（未读的前面有蓝色圆点）、类别标签（如审批、提醒、预警、公告）、内容和时间；
- 点击消息：标为已读，并按消息中的链接打开对应的小程序页面（规则同上面的待办事项）；没有对应页面时提示「该事项请在电脑端处理」，消息本身仍会标为已读；
- 「**全部已读**」：确认「将全部消息标为已读？」后，把全部消息标为已读；
- 下拉刷新，上拉加载更多。

消息与电脑端顶部铃铛、[我的消息](../guide/profile)是同一份数据，在任一端读过的消息另一端也显示为已读。

::: tip 提示
小程序只在打开时显示站内消息。希望有新的审批待办时在微信中收到通知，请开启[审批提醒](./approval#审批提醒)。
:::

## 通知公告

工作台「办公」分组中的「**通知公告**」入口，或消息页顶部的未读公告提示条进入。所有登录用户都可以使用，只显示发给你、已发布且未过期的公告，与电脑端[工作台的通知公告](../guide/home#通知公告)是同一份数据。

![通知公告](/images/manual/miniapp/notice.jpg)

**公告列表**：

- 顶部「**全部**」「**未读**」切换；
- 置顶的公告排在最前，每条显示标题（未读的加粗、前面有圆点）、「置顶」标签、类型标签，下方为发布时间和发布人；
- 下拉刷新，上拉加载更多；从详情返回时自动刷新未读标记。

**公告详情**：点击公告打开，显示标题、置顶和类型标签、发布时间、发布人、有效期和正文。**打开即标记为已读**，对应的「公告」类消息也一并变为已读，在电脑端同样显示为已读。

- 有附件时下方列出「附件」，点击下载后打开：图片直接预览，Word、Excel、PDF 等文档用微信内置的文档查看器打开（右上角菜单可转发或用其他应用打开）；无法打开的文件提示「无法打开该文件，请在电脑端下载」；
- 正文中的图片不显示，链接不能点击，需要时请到电脑端查看；
- 公告已被撤回或已过期时，打开会提示「公告不存在、已撤回或已过期」并自动返回。

点击消息页中的「公告」类消息，同样直接打开该公告的详情。
