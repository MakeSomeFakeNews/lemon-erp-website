# 我的

底部导航「**我的**」显示个人资料和常用数据，并提供语言、审批提醒、修改密码、切换账号、解除绑定和退出登录等设置。

![我的](/images/manual/miniapp/mine.jpg)

## 个人卡片

- 右上角显示当前企业（租户）名称；
- 头像（没有上传头像时显示姓名首字）、姓名、账号、部门，以及最多 3 个角色标签。头像在电脑端[个人中心](../guide/profile)上传。

## 个人数据

卡片下方的统计，点击进入对应页面；没有权限或不适用的项目不显示：

| 统计 | 说明 | 点击后 |
| --- | --- | --- |
| 待我审批 | 我的待办数量，大于 0 时醒目显示 | [审批](./approval)的「待办」 |
| 审批中 | 我发起的、还在审批中的流程数量 | 审批的「我发起的」 |
| 未读消息 | 未读站内消息数量 | [消息](./workbench#消息) |
| 年假（天） | 年假余额（需要关联员工档案） | [考勤](./self#考勤) |

## 常用

按入口权限显示：**我的申请**（打开审批的「我发起的」）、**打卡**、**请假加班**、**工资条**。

## 账号资料

部门、角色、手机号、邮箱。修改手机号、邮箱、头像请在电脑端[个人中心](../guide/profile)中操作。

## 设置

| 设置项 | 说明 |
| --- | --- |
| **语言** | 选择「简体中文」或「English」，界面、页面标题、底部导航和字典标签立即切换。首次使用时按手机系统语言自动选择（英文系统为 English，其他为简体中文）。只影响小程序，不影响电脑端的语言设置 |
| **审批提醒** | 「有新待办时微信通知」，点击申请微信订阅消息授权，见[审批提醒](./approval#审批提醒)。管理员没有配置订阅消息时不显示 |
| **修改密码** | 输入原密码、新密码、确认新密码后保存，提示「密码已修改」。修改的是系统账号的密码，电脑端同样生效 |
| **切换账号** | 退出当前账号并回到登录页，不自动登录，用另一个账号的账号密码登录后，当前微信改为绑定新账号，见[使用其他账号登录](./login#使用其他账号登录) |
| **解除微信绑定** | 确认「解除后，下次需要输入账号密码才能登录，确定解除吗？」后解除当前账号与微信的绑定并退出，见[解除微信绑定](./login#解除微信绑定) |

「审批提醒」「切换账号」「解除微信绑定」只在微信小程序中显示（本页截图来自浏览器预览，没有这三项）。

## 退出登录

点击「**退出登录**」，确认「确定退出登录吗？」后退出并回到登录页。退出后不会自动重新登录，但微信绑定仍然保留，点击「微信一键登录」即可再次登录。

页面底部显示小程序版本号。
