# 仓储与报工

工作台「**仓储生产**」分组提供库存查询（含经营历史）、[积压分析](#积压分析)和仓库、车间的扫码作业：扫码收货、[快速入库](#快速入库)、上架、拣货、盘点和生产报工。收货、上架、拣货、盘点的处理逻辑与电脑端[移动作业](../mobile/)完全相同，生成的单据也一样；区别是小程序可以直接用手机摄像头扫码，并用微信登录。

## 扫码方式

每个作业页面顶部都有扫码框：

- 点击右侧「**扫码**」调用手机摄像头扫描条码或二维码（也可以从相册选择图片识别）；
- 使用带扫码头的 PDA 时，在输入框中扫描，扫码头输入后自动「回车」提交；
- 也可以手工输入条码后点键盘上的「搜索」。

提交后输入框自动清空，可以连续扫描。扫码结果显示在扫码框下方，成功为绿色并短振一次，失败为红色并长振。

**条码识别规则**（与移动作业相同）：先按当前仓库的库位编码匹配库位，再按物料条码、包装（辅助单位）条码、物料编码匹配物料；都不匹配时，作为当前选中的序列号物料的序列号处理，否则提示「未识别的条码 …」。扫描包装条码时按换算率累计数量（例如 1 箱 = 20 个，扫一次加 20）。多规格物料请扫描 SKU 的条码或编码。详见[移动作业 - 通用操作](../mobile/#通用操作)。

点击某一行的卡片可把它设为当前行（蓝色边框），序列号会扫入当前行。

## 库存查询

需要库存查询权限。对应电脑端[库存查询](../wms/stock)。

![库存查询](/images/manual/miniapp/stock.jpg)

- 扫描物料条码 / 包装条码，或输入物料编码、名称：精确匹配到物料时只显示该物料，否则按编码、名称模糊查询；查询条件显示为蓝色标签，点「清除」恢复全部；
- 「**低于下限**」「**高于上限**」两个开关：只显示库存低于安全库存（库存下限）或高于库存上限的物料，两个都打开时都显示；从工作台待办「库存低于安全库存」「库存高于库存上限」进入时自动打开对应的开关；
- 按物料汇总显示：物料设置了[商品图片](../wms/material#商品图片)时左侧显示主图缩略图（点击查看大图），以及编码名称、规格、库存（含单位）、可用（库存 − 冻结）、「下限 ~ 上限」（没有设置的一项显示「-」，都没有设置时显示「-」；[分仓库预警](../wms/material#库存预警)的物料标注「（分仓库合计）」，为各仓库之和）；
- 预警口径与电脑端[库存查询](../wms/stock#库存上下限预警)相同：按总库存的物料比较所有仓库的合计，低于下限的库存标红并显示「低于下限」，高于上限的标橙并显示「高于上限」；分仓库的物料按各仓库判断，显示「N 个仓库低于下限」（红色）或「N 个仓库高于上限」（橙色）；
- 有「**查看成本金额**」权限时，每个物料下方还显示「**均价**」（当前的库存平均成本单价）和库存「**金额**」；没有该权限时不显示；
- 点击物料展开各仓库、库位、批次的库存明细：仓库 · 库位（未指定库位显示「未指定」）、数量、批次、生产日期（批次登记了时）、有效期（已过期标红）、冻结数量。查询结果只有一个物料时自动展开；
- 展开后右下角有「**经营历史 ›**」，查看该物料的进出流水，见下文。

可查看的仓库和数据范围与电脑端相同。「查看成本金额」是电脑端[库存查询](../wms/stock)下的按钮权限，在「系统管理 → [角色管理](../system/role)」中授权。

### 经营历史

在库存查询中展开物料，点「经营历史 ›」进入。按时间顺序列出该物料在一段时间内的期初、每条出入库流水和结余，用于回答「这个货什么时候进的、卖给了谁、还剩多少」。数据与电脑端库存查询中的经营历史相同。

![经营历史](/images/manual/miniapp/stock-history.jpg)

| 区域 | 说明 |
| --- | --- |
| 筛选 | 「仓库」默认「全部仓库」，可选择某个仓库；「从」「至」默认本月 1 日到今天，结束日期不能早于开始日期。修改后自动刷新，也可以下拉刷新 |
| 说明文字 | 全部仓库时提示「全部仓库：全公司的进出与结余，不含仓库之间的调拨和供应商寄售仓；日期为单据的业务日期」；选择仓库时提示「所选仓库的进出与结余（含调拨）；日期为单据的业务日期」 |
| 期初 | 开始日期当天的期初数量；有查看成本金额权限时显示期初的「结余金额」 |
| 流水 | 每条一张卡片：单号、业务类型标签（如采购入库、销售出库、生产领料，入库为绿色、出库为橙色）、业务日期、往来单位、仓库（选择全部仓库时）、批次、来源单号；「入库 / 出库」数量（入库带「+」）、「结余数量」。有查看成本金额权限时还显示「结余金额」以及「业务价」「成本价」「金额」 |
| 结余 | 结束日期的结余数量（和结余金额） |

期间内没有出入库时显示「期间内没有流水」，期初和结余相同。

::: tip 提示
启用实时库存成本之前的历史流水，成本是按当时的成本核算单价或参考成本价回填的近似值：这类流水标注「升级前的流水，成本为近似值」，期初金额包含这部分时标注「期初金额含升级前的近似成本」，仅供参考。日期范围内的流水超过 5000 条时提示「日期范围内的流水超过 5000 条，请缩小日期范围或选择仓库」。
:::

## 积压分析

需要「积压分析」菜单权限（电脑端「供应链 → 进销存报表 → 积压分析」的权限）。与电脑端[积压分析](../scm/jxc-overstock)使用同一套口径，列出截至某一天库存超过积压基数的商品。

- 顶部搜索框输入编码、名称、规格或简拼，点键盘上的「搜索」查询；
- 分段选择积压基数：「近 N 天销量」（默认，N 为下方填写的天数）、「上月销量」、「库存上限」；
- 「仓库」默认「全部仓库」；「截至」默认今天，不能选今天之后的日期；选择近 N 天销量时可以修改「天数」（1～366，默认 60，超出时提示「天数须在 1 到 366 之间」）。修改后自动刷新，也可以下拉刷新；
- 条件下方的灰色说明：按销量时显示「积压基数为 开始日期 ~ 结束日期 的净销量（销售出库 − 退货）」，按库存上限时提示「积压基数取库存上限（分仓库时为所选仓库的上限，不选仓库为各仓库之和），没有设置上限的商品不参与」；
- 列表上方显示「N 个商品积压 数量」，有「查看成本金额」权限时还显示资金占用合计；
- 每个商品一张卡片：编码名称、积压系数（橙色标签，基数为 0 时不显示）、规格；「库存」「积压基数」「积压数量」三个数字；「在库 N 天 · 最新进货 日期 · 最新出库 日期」（没有时显示「无」）；有「查看成本金额」权限时显示「资金占用」；
- 有库存查询权限时，点击卡片进入该商品的[经营历史](#经营历史)。

列表按资金占用（有成本权限时）或积压数量从大到小排序，上拉加载更多。

## 扫码收货

需要采购入库新增权限。对应[移动作业 - 扫码收货](../mobile/receive)，生成[采购入库单](../scm/purchase-in)。

![扫码收货](/images/manual/miniapp/receive.jpg)

1. 页面列出已审核、部分入库的采购订单（订单号、状态、供应商、订单日期），可以扫描或输入采购订单号查找，只有一张时直接进入；没有时显示「没有待入库的采购订单」；
2. 选择订单后，显示待入库的明细行（已完成的行不显示），「收货仓库」默认订单的仓库，可以更改；订单没有待入库明细时提示「订单没有待入库的明细」；
3. 逐个扫描物料条码，累计到对应行的数量（显示「本次 / 待入库」），超过待入库数量时提示「… 已超过待入库数量」；扫描不在订单中的物料提示「… 不在该订单中」；
4. 先扫描库位条码可设定「当前库位」，之后扫描的物料收到该库位；也可以在每行的「库位」中选择，留空时按上架策略推荐（「空则推荐」）；
5. 批次管理的物料填写批次；序列号管理的物料选中该行后扫描序列号，数量等于序列号个数；
6. 底部显示「本次收货」合计，点击「**确认入库**」：没有选择仓库时提示「请选择收货仓库」，批次物料没填批次时提示「…：请填写批次号」。成功提示「已审核记账」，回到订单列表，并询问是否[打印 / 分享 PDF](./sales#打印-分享-pdf)。

[业务参数](../system/biz-rule#进销存单据先存草稿)开启「进销存单据先存草稿」时，底部改为「存草稿」+「保存并审核」（有「采购入库审核」权限时）或只有「存草稿」，规则见[保存方式](./sales#保存方式)。存草稿时提示「已存草稿，待审核」，库存和应付暂不变化，由有审核权限的人在小程序[单据草稿](./sales#单据草稿)或电脑端[采购入库](../scm/purchase-in#草稿与审核)中审核后才入库。

## 快速入库

快速入库就是在手机上做采购入库的「直接开单」：不引用采购订单，选供应商、扫商品后直接入库，适合零星采购、到货后补单等场景。与电脑端[采购入库 - 直接开单](../scm/purchase-in#直接开单)使用同一套规则；引用采购订单收货请用上面的[扫码收货](#扫码收货)。

需要采购入库新增权限，并且[业务参数](../system/biz-rule#允许直接开单)「允许直接开单」处于开启状态（默认开启）；参数关闭时工作台不显示该入口，已打开的页面提示「直接开单已关闭（业务参数「允许直接开单」），请在电脑端按采购订单入库，或用「扫码收货」」。

**表头**

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 供应商 | 是 | 点击后在「选择供应商」弹层中搜索（边输入边查询，上拉加载更多）。更换供应商后，没有手工改过的单价按新供应商重新带出 |
| 仓库 | 是 | 入库仓库，选过的仓库记在本机，下次打开默认选中 |
| 发票类型 | 否 | 默认「不指定」，选择后已有明细的税率统一调整为该类型的税率，用法同[快速开单](./sales#表头) |
| 入库日期 | 是 | 默认今天，用于带出默认进价 |

**添加商品**：在扫码框中扫描商品条码、包装条码，或输入编码、名称搜索，也可以点「搜索」在「选择商品」弹层中查找；扫描库位条码时设为「当前库位」，之后加入的商品入到该库位（点「清除」取消）。同一商品再次扫描时累加数量，包装条码按换算率累加。没有商品时提示「扫描或搜索商品开始入库」。

**明细行**

| 内容 | 说明 |
| --- | --- |
| 数量 | 商品设置了辅助单位时可以切换录入单位，下方显示折算后的基本单位数量和单价，折算规则同快速开单 |
| 含税单价 | 选择供应商后自动带出默认进价，下方显示来源，按 合同价 → 供货价 → 最近进价 → 参考成本价 的顺序取价，规则与电脑端[开单默认价](../scm/price-list#开单默认价)相同；手工修改后不再自动更新 |
| 税率 | 每行可以修改，清空时按发票类型的税率或默认税率 |
| 库位 | 可以选择；不选时保存前按上架策略推荐库位 |
| 批次、有效期 | 批次管理的商品必须填写批次号，可填写有效期 |
| 序列号 | 序列号管理的商品点击该行设为当前行后逐个扫描序列号，数量等于序列号个数 |

底部显示「应付」合计，可以填写备注。点击保存按钮（按[保存方式](./sales#保存方式)显示「确认入库」，或「存草稿」/「保存并审核」）：没有选供应商提示「请选择供应商」，没有选仓库提示「请先选择仓库」，数量、单价为空或批次物料没填批次号时分别提示。

直接审核成功后提示「已审核记账」：与电脑端直接开单一样自动生成已审核的采购订单（来源「直接开单」）和采购入库单，增加库存、生成应付单；然后询问是否[打印 / 分享 PDF](./sales#打印-分享-pdf)。保存后明细清空，供应商、仓库保留，方便连续录入。存草稿时提示「已存草稿，待审核」，库存和应付暂不变化。

## 上架

需要调拨单新增权限；有调拨单确认权限时直接完成上架。对应[移动作业 - 上架](../mobile/putaway)。

![上架](/images/manual/miniapp/putaway.jpg)

1. 选择**仓库**，扫描**来源库位**（如收货暂存区），列出该库位上的可用库存（「来源库位 …，N 条库存」）；没有库存时显示「该库位没有可上架的库存」，「更换」可以重新扫描来源库位；
2. 扫描物料选中要上架的行（「已选中 …，请扫描目标库位」），再扫描**目标库位**；目标库位不能与来源库位相同。也可以在每行的「目标库位」中选择；
3. 「上架数量」默认等于可用数量，可以改小；序列号物料选中后扫描序列号；
4. 「**推荐库位**」：为还没有目标库位的行按上架策略推荐库位（提示「已推荐 N 条」或「没有可推荐的库位」）；
5. 点击「**确认上架（N）**」（N 为已填数量和目标库位的行数）。系统生成同仓库的调拨单（备注「移动上架」）：有调拨单确认权限时立即确认并提示「已上架」；否则保存为草稿并提示「已生成调拨单」，由有权限的人在电脑端[调拨单](../wms/transfer)中确认。

## 拣货

需要发货通知拣货权限。对应[移动作业 - 拣货](../mobile/pick)。

![拣货](/images/manual/miniapp/pick.jpg)

1. 页面列出待拣货的[发货通知](../scm/delivery)（通知号、波次号、客户、仓库、发货日期），可以扫描或输入发货通知号查找；没有时显示「没有待拣货的发货通知」；
2. 选择后按库位顺序列出拣货建议：库位、物料、批次、「已拣 / 应拣」数量。拣货建议不足时显示「… 拣货建议不足，请在电脑端调整后再拣货」，此时不能确认；
3. 扫描库位设定当前库位，自动选中该库位第一条未拣完的行（库位上没有待拣物料时提示「… 没有待拣的物料」）；再扫描物料累计已拣数量，也可以直接修改「已拣」数量。扫描的物料不在当前库位时提示「请到库位 … 拣货」，不需要拣货或已拣完时提示「… 不需要拣货或已拣完」，超过应拣数量时提示「… 超过应拣数量」；序列号物料扫描序列号，序列号必须在该库位 / 批次中；
4. 全部行拣完后点击「**确认拣货**」，有未拣完的行时提示「库位 物料：已拣 X，应拣 Y」。成功提示「拣货完成」。

拣货确认后请在电脑端继续[装箱、出库](../scm/delivery)。

## 盘点

需要盘点单修改权限。对应[移动作业 - 盘点](../mobile/check)。

![盘点](/images/manual/miniapp/check.jpg)

页面提示「在电脑端按库存生成盘点单（草稿）后，在这里扫码录入实盘数量」，并列出草稿状态的[盘点单](../wms/check)（单号、日期、仓库、备注）；没有时显示「没有待盘点的盘点单」。

1. 选择盘点单，顶部显示「已盘 N / M 行」；
2. 扫描库位条码，设定当前库位（「库位 …，N 行」）；打开「只看当前库位」时只显示该库位的明细；
3. 扫描物料累计实盘数量（包装条码按换算率），也可以直接输入「实盘」数量；实盘与账面一致显示为绿色，不一致为橙色；
4. 扫描到账面上没有的物料时自动新增一行「盘盈」，批次物料需要填写批次号；
5. 序列号物料选中后扫描序列号，实盘数量等于序列号个数；
6. 实盘大于账面（盘盈）的行显示「**成本价**」输入框，用于确定盘盈入库的成本：有「查看成本金额」权限时输入框中提示「默认均价 X」（该物料当前的均价），没有该权限或物料没有均价时提示「默认按确认时的当前均价」。不填时按确认盘点时的当前均价入账；在电脑端已填写的成本价会带出并保留；
7. 底部显示「差异行」数量，点击「**保存实盘**」提示「已保存」。

保存只更新盘点单中的实盘数量和盘盈成本价，盘点单仍为草稿；全部盘完后回到电脑端[盘点单](../wms/check)确认盘点，生成盘盈盘亏。

## 报工

需要工单报工权限，并同时有工单查看权限。对应电脑端[生产工单](../mes/wo)的报工。

![报工](/images/manual/miniapp/report.jpg)

1. 页面列出已下达、生产中的工单（工单号、状态、产品、计划数量、计划起止日期），可以扫描或输入工单号查找，只有一张时直接进入；找不到时提示「没有可报工的工单 …」；
2. 选择工单后列出工序：工序号和名称、工作中心、「合格 X，报废 Y，计划 Z」、累计工时；要求首件检验的工序有「首件检验」标签。点击要报工的工序；该工序首件检验还没有合格时，工序信息下方以橙色提示「首件检验合格前，该工序累计只能报工 1 件」；
3. 填写报工信息：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 报工日期 | 是 | 默认今天 |
| 合格数量 | 是 | 默认为该工序还可报工的数量：上道工序的累计合格数（第一道工序为工单数量）− 本工序已报合格和报废，与报工校验一致；首件检验合格前累计不超过 1 件，即默认 1（已报过 1 件时为 0） |
| 报废数量 | 否 | 默认 0，不能小于 0 |
| 实际工时（小时） | 是 | 默认按默认合格数量 × 标准工时计算 |
| 生产设备 | 否 | 点击打开「生产设备」搜索弹层：工序所在工作中心的设备排在最前，也可以输入编码、名称搜索其他设备，上拉加载更多；第一项「不指定」可清空。默认选中模具所在的设备，没有时工作中心只有一台设备则自动选中 |
| 模具 | 否 | 工单产品有可用模具时显示（「编码 名称（N 穴）」），并提示「本次 N 模次，累计 M / 设计寿命」 |
| 备注 | 否 | 最多 255 字 |

4. 点击「**提交报工**」，成功提示「报工成功」并刷新工序进度。

报工的操作员为本人（页面提示「操作员为本人；代他人报工请在电脑端操作」）。首件检验合格前累计超过 1 件、超过上道工序合格数等校验由系统判断并提示，规则见[生产工单](../mes/wo)。
