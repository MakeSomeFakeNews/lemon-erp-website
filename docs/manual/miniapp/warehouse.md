# 仓储与报工

工作台「**仓储生产**」分组提供库存查询和仓库、车间的扫码作业：扫码收货、上架、拣货、盘点和生产报工。收货、上架、拣货、盘点的处理逻辑与电脑端[移动作业](../mobile/)完全相同，生成的单据也一样；区别是小程序可以直接用手机摄像头扫码，并用微信登录。

## 扫码方式

每个作业页面顶部都有扫码框：

- 点击右侧「**扫码**」调用手机摄像头扫描条码或二维码（也可以从相册选择图片识别）；
- 使用带扫码头的 PDA 时，在输入框中扫描，扫码头输入后自动「回车」提交；
- 也可以手工输入条码后点键盘上的「搜索」。

提交后输入框自动清空，可以连续扫描。扫码结果显示在扫码框下方，成功为绿色并短振一次，失败为红色并长振。

**条码识别规则**（与移动作业相同）：先按当前仓库的库位编码匹配库位，再按物料条码、包装（辅助单位）条码、物料编码匹配物料；都不匹配时，作为当前选中的序列号物料的序列号处理，否则提示「未识别的条码 …」。扫描包装条码时按换算率累计数量（例如 1 箱 = 20 个，扫一次加 20）。多规格物料请扫描 SKU 的条码或编码。详见[移动作业 - 通用操作](../mobile/#通用操作)。

点击某一行的卡片可把它设为当前行（蓝色边框），序列号会扫入当前行。

## 库存查询

需要库存查询权限。对应电脑端[库存查询](../wms/stock)。

![库存查询](/images/manual/miniapp/stock.jpg)

- 扫描物料条码 / 包装条码，或输入物料编码、名称：精确匹配到物料时只显示该物料，否则按编码、名称模糊查询；查询条件显示为蓝色标签，点「清除」恢复全部；
- 「**只看低于安全库存**」开关：只显示库存低于安全库存的物料；从工作台待办「库存低于安全库存」进入时自动打开；
- 按物料汇总显示：编码名称、规格、库存（含单位）、可用（库存 − 冻结）、安全库存；低于安全库存的标红并显示「低于安全库存」；
- 点击物料展开各仓库、库位、批次的库存明细：仓库 · 库位（未指定库位显示「未指定」）、数量、批次、有效期（已过期标红）、冻结数量。查询结果只有一个物料时自动展开。

可查看的仓库和数据范围与电脑端相同。

## 扫码收货

需要采购入库新增权限。对应[移动作业 - 扫码收货](../mobile/receive)，生成[采购入库单](../scm/purchase-in)。

![扫码收货](/images/manual/miniapp/receive.jpg)

1. 页面列出已审核、部分入库的采购订单（订单号、状态、供应商、订单日期），可以扫描或输入采购订单号查找，只有一张时直接进入；没有时显示「没有待入库的采购订单」；
2. 选择订单后，显示待入库的明细行（已完成的行不显示），「收货仓库」默认订单的仓库，可以更改；订单没有待入库明细时提示「订单没有待入库的明细」；
3. 逐个扫描物料条码，累计到对应行的数量（显示「本次 / 待入库」），超过待入库数量时提示「… 已超过待入库数量」；扫描不在订单中的物料提示「… 不在该订单中」；
4. 先扫描库位条码可设定「当前库位」，之后扫描的物料收到该库位；也可以在每行的「库位」中选择，留空时按上架策略推荐（「空则推荐」）；
5. 批次管理的物料填写批次；序列号管理的物料选中该行后扫描序列号，数量等于序列号个数；
6. 底部显示「本次收货」合计，点击「**确认入库**」：没有选择仓库时提示「请选择收货仓库」，批次物料没填批次时提示「…：请填写批次号」。成功提示「已入库」，回到订单列表。

## 上架

需要调拨单新增权限；有调拨单确认权限时直接完成上架。对应[移动作业 - 上架](../mobile/putaway)。

![上架](/images/manual/miniapp/putaway.jpg)

1. 选择**仓库**，扫描**来源库位**（如收货暂存区），列出该库位上的可用库存（「来源库位 …，N 条库存」）；没有库存时显示「该库位没有可上架的库存」，「更换」可以重新扫描来源库位；
2. 扫描物料选中要上架的行（「已选中 …，请扫描目标库位」），再扫描**目标库位**；目标库位不能与来源库位相同。也可以在每行的「目标库位」中选择；
3. 「上架数量」默认等于可用数量，可以改小；序列号物料选中后扫描序列号；
4. 「**推荐库位**」：为还没有目标库位的行按上架策略推荐库位（提示「已推荐 N 条」或「没有可推荐的库位」）；
5. 点击「**确认上架（N）**」（N 为已填数量和目标库位的行数）。系统生成同仓库的调拨单（备注「移动上架」）：有调拨单确认权限时立即确认并提示「已上架」；否则保存为草稿并提示「已生成调拨单」，由有权限的人在电脑端[调拨单](../wms/transfer)中确认。

## 拣货

需要发货通知拣货权限。对应[移动作业 - 拣货](../mobile/pick)。

![拣货](/images/manual/miniapp/pick.jpg)

1. 页面列出待拣货的[发货通知](../scm/delivery)（通知号、波次号、客户、仓库、发货日期），可以扫描或输入发货通知号查找；没有时显示「没有待拣货的发货通知」；
2. 选择后按库位顺序列出拣货建议：库位、物料、批次、「已拣 / 应拣」数量。拣货建议不足时显示「… 拣货建议不足，请在电脑端调整后再拣货」，此时不能确认；
3. 扫描库位设定当前库位，自动选中该库位第一条未拣完的行（库位上没有待拣物料时提示「… 没有待拣的物料」）；再扫描物料累计已拣数量，也可以直接修改「已拣」数量。扫描的物料不在当前库位时提示「请到库位 … 拣货」，不需要拣货或已拣完时提示「… 不需要拣货或已拣完」，超过应拣数量时提示「… 超过应拣数量」；序列号物料扫描序列号，序列号必须在该库位 / 批次中；
4. 全部行拣完后点击「**确认拣货**」，有未拣完的行时提示「库位 物料：已拣 X，应拣 Y」。成功提示「拣货完成」。

拣货确认后请在电脑端继续[装箱、出库](../scm/delivery)。

## 盘点

需要盘点单修改权限。对应[移动作业 - 盘点](../mobile/check)。

![盘点](/images/manual/miniapp/check.jpg)

页面提示「在电脑端按库存生成盘点单（草稿）后，在这里扫码录入实盘数量」，并列出草稿状态的[盘点单](../wms/check)（单号、日期、仓库、备注）；没有时显示「没有待盘点的盘点单」（截图中当前没有草稿盘点单）。

1. 选择盘点单，顶部显示「已盘 N / M 行」；
2. 扫描库位条码，设定当前库位（「库位 …，N 行」）；打开「只看当前库位」时只显示该库位的明细；
3. 扫描物料累计实盘数量（包装条码按换算率），也可以直接输入「实盘」数量；实盘与账面一致显示为绿色，不一致为橙色；
4. 扫描到账面上没有的物料时自动新增一行「盘盈」，批次物料需要填写批次号；
5. 序列号物料选中后扫描序列号，实盘数量等于序列号个数；
6. 底部显示「差异行」数量，点击「**保存实盘**」提示「已保存」。

保存只更新盘点单中的实盘数量，盘点单仍为草稿；全部盘完后回到电脑端[盘点单](../wms/check)确认盘点，生成盘盈盘亏。

## 报工

需要工单报工权限，并同时有工单查看权限。对应电脑端[生产工单](../mes/wo)的报工。

![报工](/images/manual/miniapp/report.jpg)

1. 页面列出已下达、生产中的工单（工单号、状态、产品、计划数量、计划起止日期），可以扫描或输入工单号查找，只有一张时直接进入；找不到时提示「没有可报工的工单 …」；
2. 选择工单后列出工序：工序号和名称、工作中心、「合格 X，报废 Y，计划 Z」、累计工时；要求首件检验的工序有「首件检验」标签。点击要报工的工序；
3. 填写报工信息：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 报工日期 | 是 | 默认今天 |
| 合格数量 | 是 | 默认为该工序的剩余数量（计划 − 已合格 − 已报废） |
| 报废数量 | 否 | 默认 0，不能小于 0 |
| 实际工时（小时） | 是 | 默认按剩余数量 × 标准工时计算 |
| 生产设备 | 否 | 工序所在工作中心的设备排在前面；只有一台时自动选中 |
| 模具 | 否 | 工单产品有可用模具时显示（「编码 名称（N 穴）」），并提示「本次 N 模次，累计 M / 设计寿命」 |
| 备注 | 否 | 最多 255 字 |

4. 点击「**提交报工**」，成功提示「报工成功」并刷新工序进度。

报工的操作员为本人（页面提示「操作员为本人；代他人报工请在电脑端操作」）。首件检验未合格不能报工、超计划报工等校验由系统判断并提示，规则见[生产工单](../mes/wo)。
