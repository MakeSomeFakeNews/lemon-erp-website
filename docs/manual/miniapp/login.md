# 登录与账号绑定

小程序使用电脑端的系统账号。第一次使用时输入账号和密码登录，系统把账号与当前微信绑定；以后打开小程序即自动登录，不用再输入密码。

## 首次登录：绑定微信

1. 打开小程序，进入登录页。小程序会自动尝试用当前微信登录；当前微信还没有绑定账号时，显示账号密码表单，提示「首次使用请输入系统账号和密码，登录后自动绑定当前微信」；
2. SaaS 模式下先填写**租户**（企业名称，与电脑端登录时填写的相同，填过一次后会自动带出），再填写**账号**和**密码**；
3. 管理员开启了登录验证码时，还要填写**验证码**（点击图片可以换一张）；
4. 点击「**登录并绑定**」。校验通过后进入工作台，当前微信与该账号绑定完成。

![首次登录绑定](/images/manual/miniapp/login.jpg)

账号密码的校验规则与电脑端[登录](../guide/login)完全相同：密码错误会累计失败次数，次数过多账号会被锁定；开启了「失败后需要验证码」时，输错一次后会出现验证码；每次登录都会记入[登录日志](../monitor/loginlog)（登录方式记为「微信小程序登录」）。

未填写必填项时分别提示「请填写租户」「请填写账号」「请填写密码」「请填写验证码」。

## 之后的登录

- 打开小程序时自动用微信登录，直接进入工作台；
- 登录页也有「**微信一键登录**」按钮，点击后重新用微信登录（同时会申请审批提醒的授权，见[审批提醒](./approval#审批提醒)）；
- 登录有效期（[参数设置](../system/config#登录与会话)中的「登录有效期」，默认 12 小时）到期或被管理员强制下线后，操作时会提示「登录已过期，请重新登录」并回到登录页，登录页会自动用微信重新登录；未成功时点击「微信一键登录」即可。

### 一个微信绑定了多个企业的账号

SaaS 模式下，同一个微信可以分别绑定不同租户（企业）中的账号，例如同时在两家使用柠檬ERP 的公司任职。打开小程序时：

- 只有一个可用的绑定：直接登录；
- 有多个可用的绑定：显示「**选择要进入的租户**」，点击租户名称进入。下方的「使用其他账号登录」可以改为输入账号密码，绑定另一个账号。

租户已停用或过期、账号已停用的绑定不会出现在可选列表中。

## 使用其他账号登录

在登录页点击「**使用其他账号登录**」，或在「[我的](./mine)」中点击「**切换账号**」，小程序不会自动登录，而是显示账号密码表单。输入另一个账号登录后：

- 当前微信改为绑定这个新账号（在同一个租户内，一个微信只能绑定一个账号；一个账号也只能绑定一个微信）；
- 新账号如果之前绑定在别的微信上，原来的绑定会被替换。

因此换了手机或微信号时，只要在新微信中用账号密码登录一次，旧微信就不能再免密登录该账号了。

## 解除微信绑定

在「[我的](./mine)」中点击「**解除微信绑定**」，确认「解除后，下次需要输入账号密码才能登录，确定解除吗？」后，提示「已解除绑定」并退出到登录页。之后在这个微信中打开小程序需要重新输入账号密码。

把手机交给他人、或不再使用这个微信时，建议先解除绑定。

## 退出登录

「我的」页面底部的「**退出登录**」：确认后退出并回到登录页，但**不会解除绑定**，也不会立即自动登录；下次点击「微信一键登录」或重新打开小程序时仍会自动登录。

## 必须先修改密码的情况

以下情况登录后会先进入「修改密码」页，顶部提示「你的密码由管理员设置或已过期，请修改后继续使用」：

- 账号由管理员新建，或管理员[重置了密码](../system/user#重置密码)（初始密码）；
- 密码超过了[参数设置](../system/config)中的密码有效期。

填写原密码、新密码和确认新密码后点「保存」，提示「密码已修改」后进入工作台。新密码要满足管理员设置的密码策略（长度、复杂度等，不满足时提示具体原因）；两次输入不一致时提示「两次输入的新密码不一致」。

![修改密码](/images/manual/miniapp/password.jpg)

平时也可以在「我的 → 修改密码」中主动修改，修改后在电脑端同样生效。

## 不能登录的账号

| 情况 | 提示 |
| --- | --- |
| 供应商、经销商门户账号 | 门户账号不能使用微信小程序登录（门户请在电脑端使用，见[供应商与经销商门户](../portal/)） |
| 账号已停用 | 账号已停用 |
| 租户不存在、已停用或已过期 | 与电脑端登录相同，例如「租户已过期，请联系平台续费」 |
| 账号被锁定、密码错误 | 与电脑端登录相同，见[常见问题](../faq/#登录) |

管理员在电脑端停用账号、重置密码或[强制下线](../monitor/online)后，小程序中的登录会立即失效。

## 常见提示

| 提示 | 原因与处理 |
| --- | --- |
| 登录已过期，请重新进入小程序 | 打开登录页后超过约 10 分钟才提交账号密码或选择租户。关闭小程序重新进入即可 |
| 该微信没有绑定此租户的账号 | 选择租户时绑定已被解除（例如在别处解除了绑定）。改用「使用其他账号登录」重新绑定 |
| 未配置微信小程序 | 部署方没有配置小程序的 AppID / AppSecret，请联系管理员 |
| 微信接口调用失败，请检查网络 / 微信返回错误 | 服务器访问微信接口失败，稍后重试；持续出现请联系管理员 |
| 网络异常，请检查网络 | 手机网络不通或服务器不可达 |

::: tip 提示
小程序的登录状态与电脑端相互独立：在小程序中退出登录不会影响电脑端，反之亦然。在电脑端的[在线用户](../monitor/online)中可以看到小程序的登录会话。

如果管理员开启了「同一账号只允许一处登录」，小程序和电脑端也算两处登录：在小程序中登录会使电脑端的登录下线，反之亦然。
:::
