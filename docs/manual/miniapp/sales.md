# 销售与服务

销售与服务分组面向外勤销售和客服：随时查看客户和联系人、一键拨号、拜访后写跟进并拍照、录入和转化线索、推进商机阶段、查询销售订单的发货和收款进度，现场受理和处理服务工单，在门店、车销现场扫码[快速开单](#快速开单)直接出库，接待客户时用[商品速查](#商品速查)查库存和价格，以及审核手机上存的[单据草稿](#单据草稿)、[打印 / 分享 PDF](#打印-分享-pdf)。数据与电脑端[客户关系](../crm/)、[销售订单](../scm/sales)、[销售出库](../scm/sales-out)相同，数据范围按角色的数据权限控制。

入口在工作台「**销售与服务**」分组：客户、跟进、商机、销售订单、线索、服务工单、快速开单、商品速查、单据草稿。

## 客户

需要客户查看权限。对应电脑端[客户管理](../crm/customer)。

![客户](/images/manual/miniapp/customer.jpg)

- 顶部「**我的**」（我负责的客户）、「**团队**」（数据权限范围内的客户）两个分段；公海客户的领取、分配请在电脑端操作；
- 搜索框按客户名称、编码、联系人搜索；
- 每个客户显示名称、阶段（潜在客户 / 意向客户 / 成交客户等）、编码、等级、负责人、主要联系人和电话、下次跟进时间。

### 客户详情

![客户详情](/images/manual/miniapp/customer-detail.jpg)

| 区域 | 内容 |
| --- | --- |
| 标题 | 客户名称、阶段、等级 |
| 经营概况 | 近一年销售（不含税，销售出库减退货，与电脑端客户详情同一口径）、订单数、应收余额、赢单金额 |
| 基本信息 | 客户编码、负责人、行业、地区、地址、最近跟进、下次跟进、信用额度、账期（天）。有销售订单查看权限时有「销售订单 查看全部」，打开该客户的订单列表 |
| 联系人 | 姓名、职务、「主要」标签、电话和微信；有电话的显示「**拨打**」，点击直接拨号 |
| 商机 | 该客户的商机：名称、金额、预计成交日期、阶段（有商机查看权限时显示） |
| 最近跟进 | 最近 10 条跟进记录：方式、时间、记录人、内容、现场照片（点击可放大），针对商机的跟进注明商机名称 |

有跟进新增权限时，底部有「**写跟进**」按钮。从写跟进页返回后，最近跟进、下次跟进时间自动刷新。

## 跟进

需要跟进记录查看或客户查看权限。对应电脑端[跟进记录](../crm/followup)。

![跟进](/images/manual/miniapp/followup.jpg)

- **今日待跟进**（有客户查看权限时显示）：我负责的、下次跟进时间已到（今天或更早）的客户，显示客户名称、下次跟进时间、联系人和电话，右侧「写跟进」直接为该客户写跟进，点击客户进入详情。没有时显示「今天没有需要跟进的客户」；
- **我的跟进**：我写的跟进记录，显示对象（客户；线索、商机会注明类型和名称）、方式、内容、现场照片、跟进时间和「下次 …」时间；
- 底部「**写跟进**」（需要跟进新增权限）：先搜索并选择客户，再填写跟进。

电脑端首页的「今日待跟进客户」待办、跟进提醒消息，在小程序中都会打开本页面。

### 写跟进

可以从客户详情、今日待跟进、线索详情、商机进入（跟进对象自动带出且不能更换），或从跟进页底部进入后选择客户。

![写跟进](/images/manual/miniapp/followup-edit.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 跟进对象 | 是 | 「客户 · 名称」「线索 · 名称」或「商机 · 名称」。从跟进页进入时点「请选择」 / 「更换」，按客户名称、编码搜索团队范围内的客户 |
| 跟进方式 | 是 | 电话、微信、拜访、会议等（业务字典），默认电话 |
| 跟进时间 | 是 | 日期 + 时间，默认当前时间 |
| 跟进内容 | 是 | 「沟通情况、客户需求、下一步安排」，最多 1000 字 |
| 下次跟进时间 | 否 | 日期 + 时间（默认 09:00），点「清除」取消；必须晚于本次跟进时间，否则提示「下次跟进时间要晚于本次跟进时间」 |
| 下次跟进计划 | 否 | 最多 255 字 |
| 现场照片 | 否 | 点「+ 拍照」拍照或从相册选择，最多 9 张（显示「现场照片（N/9）」），点缩略图放大，点「×」移除 |

点击「**保存**」：先保存跟进记录，再逐张上传照片（显示「上传照片 i/n」）。全部成功提示「跟进已保存」；有照片上传失败时提示「跟进已保存，N 张照片上传失败」，跟进记录本身不受影响，可以在电脑端跟进记录的附件中补传。

保存后客户的「最近跟进」「下次跟进」随之更新，规则与电脑端[跟进记录](../crm/followup)相同。照片作为跟进记录的附件保存，电脑端也能查看。

## 商机

需要商机查看权限。对应电脑端[销售机会](../crm/opportunity)。

![商机](/images/manual/miniapp/opportunity.jpg)

- 「**我的**」「**全部**」分段，搜索框按商机名称、编号搜索；
- 每条显示商机名称、阶段、编号、客户、负责人、预计金额、预计成交日期、赢单概率；已生成销售订单的显示「销售订单 订单号」。

点击商机弹出操作菜单（按权限显示）：

| 操作 | 说明 |
| --- | --- |
| 推进阶段 | 需要商机修改权限，赢单的商机不显示。选择新的阶段后提示「阶段已更新」，赢单概率随阶段自动变化；选择「输单」时必须填写输单原因 |
| 写跟进 | 为该商机写跟进记录 |
| 客户详情 | 打开商机所属客户的详情 |

::: tip 提示
小程序中只能推进阶段，商机的金额、产品明细等请在电脑端修改。赢单后「生成销售订单」「创建项目」也请在电脑端的商机详情中操作，赢单要生成销售订单时商机必须有产品明细。
:::

## 销售订单

需要销售订单查看权限。用于随时查询订单的发货、开票和收款进度，不能新增或修改订单（订单录入请在电脑端[销售订单](../scm/sales)中操作；不下订单直接出库可以用[快速开单](#快速开单)）。

![销售订单](/images/manual/miniapp/order.jpg)

- 状态分段：全部、已审核、部分完成、已完成；
- 搜索：左侧下拉切换「**订单号**」或「**客户**」，客户按往来单位名称或编码搜索；从客户详情进入时只显示该客户的订单，只能按订单号搜索；
- 每张订单显示订单号、状态、客户、业务员、订单金额、订单日期，以及发货进度条「已发 X / Y」。

### 订单详情

![订单详情](/images/manual/miniapp/order-detail.jpg)

| 区域 | 内容 |
| --- | --- |
| 基本信息 | 客户、订单日期、交货日期、业务员、发货仓库、订单金额、整单优惠（有整单优惠或抹零时显示，订单金额是优惠后的金额）、税额、发货进度、备注 |
| 明细 | 每行物料名称、编码规格、数量与单位、已发数量、退货数量（有退货时）、单价、金额（整单优惠只在合计处扣减，明细为优惠前的单价和金额，与电脑端一致）；赠品有「赠品」标签 |
| 出库记录 | 该订单的出库单号、类型、日期、金额 |
| 应收 | 应收单号、日期、金额、已收金额、状态，标题右侧汇总「应收 X，已收 Y」 |
| 物流 | 发运单号、承运商、运单号、发运日期、状态 |

出库记录、应收、物流按你的权限显示，没有相关数据或没有权限时不显示该区域。数据来源与电脑端[销售订单详情](../scm/sales#订单详情)中的「单据追溯」页签相同。

## 线索

需要线索查看权限。对应电脑端[线索管理](../crm/lead)。

![线索](/images/manual/miniapp/lead.jpg)

- 「**我的**」「**全部**」分段，搜索框按编号、公司、联系人、电话搜索；
- 每条显示公司名称、状态（待跟进、跟进中、已转化、无效）、联系人和电话、来源、负责人、最近跟进时间；
- 底部「**新增线索**」（需要线索新增权限）。

### 新增 / 编辑线索

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 公司名称 | 是 | 最多 128 字 |
| 联系人、职务 | 否 | |
| 电话、邮箱 | 否 | |
| 来源、行业 | 否 | 业务字典 |
| 地区 | 否 | 从地区字典中选择 |
| 需求描述 | 否 | 「客户的需求、预算、时间等」，最多 500 字 |

新增时负责人为本人；编辑时保留原来的负责人和市场活动。保存后提示「已保存」。

### 线索详情

![线索详情](/images/manual/miniapp/lead-detail.jpg)

显示线索编号、状态和线索信息（联系人、电话（点击拨号）、邮箱、来源、行业、地区、负责人、市场活动、需求描述；无效的显示无效原因；已转化的显示转化客户，点击进入客户详情），以及最近 20 条跟进记录。

待跟进、跟进中的线索底部有操作按钮（按权限显示）：

| 按钮 | 权限 | 说明 |
| --- | --- | --- |
| 更多 → 编辑 | 线索修改 | 打开编辑页 |
| 更多 → 标记无效 | 线索修改 | 填写无效原因（如「联系方式错误、没有需求」，选填），提示「已标记为无效」 |
| 写跟进 | 跟进新增 | 为线索写跟进 |
| 转化 | 线索转化 | 打开转化页 |

### 转化线索

页面提示「生成客户（意向客户，负责人沿用线索负责人）和首要联系人，可以同时生成商机」。

| 字段 | 说明 |
| --- | --- |
| 客户编码 | 选填，「留空按编码规则自动生成」；只能包含字母、数字、下划线和短横线，最多 32 位 |
| 同时生成商机 | 开关，默认开启 |
| 商机名称 | 开启时必填，默认「公司名称 商机」 |
| 预计金额 | 选填，不能为负数 |
| 预计成交 | 选填，不早于今天 |

点击「**转化**」提示「线索已转化」，有客户查看权限时直接进入新客户的详情。转化规则见[线索管理 - 转化线索](../crm/lead#转化线索)。

## 服务工单

需要服务工单查看权限。对应电脑端[服务工单](../crm/ticket)。

![服务工单](/images/manual/miniapp/ticket.jpg)

- 状态分段：待处理（默认）、处理中、已解决、全部；
- 搜索框按工单号、标题、客户搜索；「**只看我的**」开关默认开启，只显示处理人是我的工单，关闭后显示数据权限范围内的全部工单；
- 每条显示标题、状态、工单号、客户、优先级、类型、处理人（未指派时显示「未指派」），超时的显示红色「已超时」，未超时的进行中工单显示「… 前处理」；
- 底部「**受理工单**」（需要服务工单新增权限）。

### 受理工单

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 客户 | 是 | 搜索选择客户 |
| 联系人 | 否 | 选择客户后可选，默认客户的主要联系人 |
| 类型 | 是 | 报修、咨询、投诉、退换货、建议等（业务字典） |
| 优先级 | 是 | 默认「中」 |
| 标题 | 是 | 「简要描述问题」，最多 128 字 |
| 问题描述 | 否 | 最多 2000 字 |
| 序列号 | 否 | 点「扫码」扫描产品上的序列号条码，或手工输入 |

点击「**提交**」后进入新工单的详情。处理时限、序列号保修判断等规则与电脑端相同，见[服务工单 - 受理工单](../crm/ticket#受理工单)。

### 工单详情与处理

![工单详情](/images/manual/miniapp/ticket-detail.jpg)

详情显示标题、状态、优先级、是否超时；工单信息（工单号、客户（点击进入客户详情）、联系人和电话（点击拨号）、类型、受理渠道、产品、序列号、处理人、受理时间、处理时限、解决时间、满意度）；问题描述、解决方案和处理记录时间线。

有服务工单处理权限时，底部按状态显示操作：

| 工单状态 | 可用操作 | 需要填写 |
| --- | --- | --- |
| 待处理、处理中 | 添加处理记录、解决 | 处理记录（「本次处理的情况」）/ 解决方案（「问题原因和解决办法」），必填 |
| 已解决 | 重新打开、关闭 | 重新打开的原因（必填）；关闭时选择满意度（1 - 5 星，默认 5 星）并填写备注（「客户反馈（选填）」） |
| 已关闭 | 重新打开 | 重新打开的原因（必填） |

提交后提示「操作成功」并返回详情。指派处理人、领用备件、服务收费请在电脑端操作，见[服务工单 - 处理工单](../crm/ticket#处理工单)。

## 商品速查

商品速查用于接待客户、电话报价时快速查商品的库存和价格，与电脑端[商品速查](../scm/quick-lookup)使用同一套数据和同一份价格设置（在手机上选的价格，电脑端也按它显示）。需要「商品速查」菜单权限（内置角色中普通用户、总经理、采购员、销售员、仓库管理员、销售经理有）。

### 搜索

顶部搜索框提示「名称 / 规格 / 简拼，可用键盘语音输入」：输入商品名称、规格、编码、条码、拼音首字母或去掉分隔符的缩写，停顿片刻自动搜索，也可以点键盘上的「搜索」；点「×」清空。上拉加载更多。

**语音输入**：小程序本身没有语音识别功能，默认使用输入法自带的语音输入，即点击搜索框后用微信键盘或手机输入法上的麦克风说出商品名称，不需要任何设置。部署方在小程序后台添加了微信官方的「同声传译」插件时，搜索框右侧还会出现「**按住说话**」按钮：按住说话、松开结束（按钮显示「松开结束」），识别出的文字自动填入搜索框并搜索；没有识别到内容时提示「没有识别到内容」，未授权麦克风时提示「请允许使用麦克风」。没有添加插件时不显示该按钮，仍可用输入法语音输入。

### 结果列表

每行显示序号、商品（名称，下方为规格和编码；有[商品图片](../wms/material#商品图片)的显示主图缩略图）、库存（全部仓库的可用数量，库存 − 冻结，带单位，为 0 时灰色）和一种价格。选择「不显示价格」时没有价格列。

### 查询价格

点击右上角的「**价格名称 ▾**」（如「最新售价 ▾」）打开「查询价格」，按进货类（参考进货价、最新进价）、成本（库存均价）、销售类（最新售价、零售价、批发价1～8，只列出启用的价格列）、其他（不显示价格）分组，选择一种显示在速查结果中，提示「已保存」。灰色、标「无权限」的价格没有查看权限，不能选。之前选的价格后来没有权限时只显示数量，并提示「所选价格没有查看权限，只显示数量」。

各价格的含义和需要的权限见电脑端[商品速查 - 查询价格](../scm/quick-lookup#查询价格)：销售员、销售经理只能看销售类价格，采购员只能看进货类价格，总经理、仓库管理员全部可看。

### 点击与长按

小程序没有双击，列表上方提示「点击商品看图片、点击库存看分布、点击价格看历史；长按更多」：

| 操作 | 打开 |
| --- | --- |
| 点击商品 | 商品图片：显示全部图片，点击放大；没有图片时提示在电脑端「物料管理」的商品图片中上传 |
| 点击库存 | 库存分布：顶部为合计，下面列出各仓库、库位的数量，以及批次、有效期、冻结数量；有库存查询权限时可转到「[经营历史](./warehouse#经营历史)」 |
| 点击价格 | 价格历史参考：价格为进货类或库存均价时默认显示进价，其他显示售价 |
| 长按一行 | 弹出全部联查：商品图片、库存分布、售价历史参考、进价历史参考、经营历史（进销存），按权限列出 |

**价格历史参考**列出最近第 1 / 2 / 3 次、系统最新价、系统最高价、系统最低价（同价取最近一次），每项带日期、往来单位、数量，没有记录时显示「暂无记录」。售价、进价都能看的用户可以在顶部切换「售价」「进价」。按看得到的单据统计，单价为优惠前含税单价，不含赠品。底部有两个按钮：

- **更多交易历史**：「售价交易历史」或「进价交易历史」，可按开始日期、结束日期和单位编号、名称或电话筛选，每条显示日期、单号、往来单位（名称、编号）、数量、单价、制单人和复核（审核）人，上拉加载更多；
- **更多内容**：「价格参考」，与电脑端销售单明细上的[价格参考](../scm/price-list#价格参考)相同，分「报价」「销售」「进货」「客户」「供货商」，客户、供货商页签列出各往来单位的最新、最低、最高价及日期，可按往来单位编码或名称筛选；只能看售价的用户没有进货、供货商页签。

## 快速开单

快速开单就是在手机上做销售出库的「直接开单」：不用先下销售订单，选客户、扫商品、确认价格后直接出库，适合门店零售、批发门市、车销送货等现场开单。与电脑端[销售出库 - 直接开单](../scm/sales-out#直接开单)使用同一套规则。

需要销售出库新增权限，并且[业务参数](../system/biz-rule#允许直接开单)「允许直接开单」处于开启状态（默认开启）；参数关闭时工作台不显示该入口，已打开的页面提示「直接开单已关闭（业务参数「允许直接开单」），请在电脑端按销售订单出库」。

![快速开单](/images/manual/miniapp/quick-sale.jpg)

### 表头

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 客户 | 是 | 点击后在「选择客户」弹层中搜索，边输入边查询，可按编码、名称、联系人、电话或拼音首字母查找，上拉加载更多。选择或更换客户后，没有手工改过的单价按新客户重新带出 |
| 仓库 | 是 | 出库仓库。只有一个仓库时自动选中；选过的仓库会记在本机，下次打开默认选中。更换仓库后，沿用表头仓库的行重新选择库位批次，已扫的序列号清空 |
| 业务员 | 否 | 默认显示「默认（客户负责人，没有时为本人）」；点击可在「选择业务员」中按账号或姓名搜索其他人，选第一项恢复默认 |
| 发票类型 | 否 | 默认「不指定」；点击从[业务字典](../system/biz-dict#发票类型)「发票类型」中选择，每项后面显示税率，如「增值税普票 3%（3%）」。选择后已有明细（赠品行除外）的税率统一调整为该税率，提示「已将 N 行税率调整为 X%」，之后每行仍可修改；选了发票类型时默认价带出的税率不再覆盖明细税率。发票类型随单据提交，记在自动生成的销售订单上；出库后保留，方便连续开单 |
| 出库日期 | 是 | 默认今天，用于带出默认价和判断促销是否有效 |

### 添加商品

- 在扫码框中扫描商品条码、包装条码，或输入编码、名称后搜索；也可以点右侧「**搜索**」在「选择商品」弹层中查找（边输入边查询，支持规格、拼音首字母和去掉分隔符的缩写，上拉加载更多；商品设置了[商品图片](../wms/material#商品图片)时显示主图缩略图）。输入的内容与某个商品编码完全一致或只搜到一个时直接加入，搜到多个时弹出列表选择，搜不到时提示「未识别的条码 …」；
- 同一商品再次扫描时累加数量，扫码框下方提示「名称 +数量，共 合计」；扫描包装条码按换算率累加（例如 1 箱 = 20 个，扫一次加 20 个）；
- 序列号管理的商品加入后提示「…：请扫描序列号」，点击该行设为当前行（蓝色边框）后逐个扫描序列号，数量等于序列号个数；点击序列号可移除；
- 点击行右上角「删除」移除该行。

### 明细行

| 内容 | 说明 |
| --- | --- |
| 数量 | 商品设置了辅助单位时，数量右侧可以切换录入单位（如「箱（=20个）」），下方显示折算后的基本单位数量和单价「= X 个，单价 Y」；扫包装条码新加的行默认按该包装单位录入。序列号商品只按基本单位 |
| 含税单价 | 选择客户后自动带出默认价，下方显示来源「默认价：客户执行价 / 价目表 / 等级价 / 零售价 / 合同价 / 最近价 / 参考成本」，取价规则与电脑端开单相同。手工修改后不再自动更新 |
| 价格参考 | 打开「价格参考」弹层，见下文 |
| 促销价 | 命中折扣、满减促销时显示「促销价 X（促销名称）」 |
| 仓库 | [业务参数](../system/biz-rule#销售出库明细可选仓库)「销售出库明细可选仓库」开启时显示，默认「同表头仓库」，可以让这一行从其他仓库出库 |
| 库位批次 | 按本行仓库的可用库存列出「库位 · 批次 · 可用 N」，先到期的排在前面（已过期的排最后），默认第一项，可以改选。数量超过所选库位批次的可用数量时标红；本仓库没有可用库存时显示「该仓库没有可用库存」 |
| 税率、金额 | 「税率 [ X ] %」输入框，每行可以修改（0 ~ 100，最多 2 位小数，超出范围视为清空）。新加的行为发票类型的税率，没有选择发票类型时为业务参数「[默认税率](../system/biz-rule#默认税率)」（默认 13%）；没有选择发票类型时，默认价（客户执行价、价目表等）带出的税率优先。清空时显示「税率按默认」，保存时按发票类型的税率、默认税率补上。右侧为本行含税金额 |

### 价格参考

点击行上的「价格参考」，弹层列出该商品的历史售价（含税、基本单位，「点击价格使用」）：

- **该客户历史售价**：已选客户时显示，该客户最近 10 次的出库日期、价格、单号、数量；
- **最近售价**：全部客户最近 10 次的售价，并显示客户名称。

点击某个价格即填入本行单价（按本行的录入单位折算）。需要销售订单、销售出库或报价单的查看权限之一，否则提示「没有查看价格参考的权限」。

### 促销与赠品

选好客户、每行都填了数量和单价后，系统自动按出库日期计算有效的[促销活动](../scm/promotion)：

- 折扣、满减：行上显示促销价，合计下方显示「促销优惠」金额；
- 买赠：自动在明细下方加入赠品行，带绿色「赠品」标签和「买赠：促销名称」，单价为 0，数量由促销规则决定、不能修改。赠品行同样要选择库位批次，序列号赠品要扫描与赠品数量相同的序列号。

![赠品与整单优惠](/images/manual/miniapp/quick-sale-gift.jpg)

赠品所选库位批次不够时提示「所选库位批次不足，保存时按先到期先出从其他库位批次补足」；整个仓库都不够时提示「本仓库存不足」。明细可选仓库时，赠品行右上角有「**拆分**」：在下面加一行同一赠品（数量为本仓库的缺口），新行选择其他仓库出库；拆分后各行数量可以调整，合计必须等于赠品数量，删除拆分出来的行时数量并回第一行。修改数量、单价后会重新计算促销，计算完成前点确认出库会提示「正在计算促销，请稍候」。

### 整单优惠与抹零

| 内容 | 说明 |
| --- | --- |
| 合计 | 各行金额合计 |
| 促销优惠 | 有折扣、满减时显示 |
| 整单优惠 | 含税金额，抹零也填在这里；不能超过扣除促销优惠后的合计 |
| 抹分 / 抹角 / 抹元 | 把应收金额向下取整到角 / 元 / 十元，差额累加到整单优惠；「清除」取消整单优惠 |
| 备注 | 选填，最多 255 字 |

底部显示「**应收**」= 合计 − 促销优惠 − 整单优惠。整单优惠按金额分摊到各行，规则同电脑端[销售出库 - 直接开单](../scm/sales-out#直接开单)。

### 运费

添加商品后，明细下方有「**运费**」卡片，规则与电脑端[销售出库的运费](../scm/sales-out#销售出库的运费)相同。填写金额后才显示下面几项：

| 内容 | 说明 |
| --- | --- |
| 运费 | 选填，金额 |
| 运费承担 | 「本公司承担」（默认）或「代垫运费（客户承担）」 |
| 付给承运商 | 「现付」（默认）或「月结」 |
| 付款账户 | 只在现付时显示，必填，从现金、银行账户中选择 |
| 承运商 | 点击在弹层中搜索物流公司（边输入边查询，上拉加载更多）。月结时必填；现付时选填，弹层第一项「不选承运商」可清空 |

卡片底部按选择提示入账方式：

| 情况 | 提示 |
| --- | --- |
| 本公司承担、现付 | 生成费用支出单（销售运费），出纳确认后入账 |
| 本公司承担、月结 | 生成承运商的应付单（销售运费） |
| 代垫运费、现付 | 客户应收 = 货款 + 代垫运费；付给承运商的运费生成费用支出单 |
| 代垫运费、月结 | 客户应收 = 货款 + 代垫运费；付给承运商的运费生成承运商应付单 |

「应收」金额只是货款，不含运费；代垫运费另生成一张客户的应收单。

### 确认出库

点击「**确认出库**」，先检查：没选客户提示「请选择客户」，没选仓库提示「请先选择仓库」，数量、单价为空提示「…：请填写数量」「…：请填写单价」，所选仓库没有库存提示「…：所选仓库没有可用库存」，赠品库存不足、赠品序列号数量不对、拆分后赠品数量合计不对时分别提示；填写了运费时，现付没选付款账户提示「运费现付时请选择付款账户」，月结没选承运商提示「运费月结时请选择承运商」。

底部的保存按钮按「[保存方式](#保存方式)」显示。直接审核成功后提示「**已审核记账**」：系统与电脑端直接开单一样，自动生成一张已审核的销售订单（来源「直接开单」）和已确认的销售出库单，扣减库存、生成应收单，填写了运费时同时生成费用支出单、承运商应付单或代垫运费应收单；最低销售价、客户信用额度等校验不通过（现付运费时出库日期所在的会计期间已结账也不能保存）时整单不保存，并提示原因。保存后明细、整单优惠、运费和备注清空，客户、仓库、业务员保留，方便连续开单。

点击「存草稿」时保存为销售出库草稿，提示「**已存草稿，待审核**」：不生成订单、不扣库存、不生成应收，审核后才出库，可以在小程序的[单据草稿](#单据草稿)或电脑端[销售出库](../scm/sales-out#草稿与审核)的「草稿」页签中审核；库存、信用额度、最低售价、促销等在审核时校验。

直接审核成功后会询问是否打印或分享这张单据，见[打印 / 分享 PDF](#打印-分享-pdf)。

### 保存方式

快速开单、[快速入库](./warehouse#快速入库)、[扫码收货](./warehouse#扫码收货)的保存按钮统一按[业务参数](../system/biz-rule#进销存单据先存草稿)「进销存单据先存草稿」和审核权限显示，与电脑端出入库单相同：

| 情况 | 按钮 | 说明 |
| --- | --- | --- |
| 参数关闭（默认） | 只有一个按钮（「确认出库」「确认入库」） | 保存即审核：出入库、扣减或增加库存、生成应收应付 |
| 参数开启，有该单据的审核权限（如「销售出库审核」「采购入库审核」） | 「存草稿」+「保存并审核」 | 可以先存草稿，也可以直接保存并审核 |
| 参数开启，没有审核权限 | 只有「存草稿」 | 由有审核权限的人在[单据草稿](#单据草稿)或电脑端审核 |

::: tip 提示
小程序只做销售出库。出库录错时请在电脑端[销售出库](../scm/sales-out)中做销售退货冲回。
:::

## 单据草稿

「单据草稿」列出手机或电脑端保存的销售出库、采购入库草稿，供有审核权限的人在手机上审核记账。只在[业务参数](../system/biz-rule#进销存单据先存草稿)「进销存单据先存草稿」开启时显示入口，需要销售出库或采购入库的查看权限。

- 顶部按「销售出库」「采购入库」分段（只有其中一种查看权限时不分段），可以搜索单据号，下拉刷新、上拉加载更多；没有草稿时显示「没有待审核的草稿」；
- 点击进入「草稿详情」：单据号、往来单位（客户 / 供应商）、仓库、业务日期、订单号（引用订单时）、发票类型、整单优惠、运费、价税合计（估算）、制单、备注，以及明细（物料、规格、数量 × 单价、库位、批次、序列号，赠品带「赠品」标记）；
- 「**审核记账**」（需要该单据的审核权限）：确认「审核草稿 …？审核后出入库并生成应收应付」后审核，库存、信用额度等按审核时的数据校验，不通过时草稿不变并提示原因；成功后询问是否[打印 / 分享 PDF](#打印-分享-pdf)；
- 「**删除**」（需要该单据的新增权限）：确认「删除草稿 …？」后删除。

草稿的修改仍在电脑端[销售出库](../scm/sales-out#草稿与审核)、[采购入库](../scm/purchase-in)的「草稿」页签中进行。

## 打印 / 分享 PDF

快速开单、快速入库、扫码收货「保存并审核」（或保存即审核）成功，以及在单据草稿中审核记账成功后，弹出「是否打印或分享这张单据（PDF）？」：

1. 点击「**打印 / 分享**」，提示「正在生成 PDF」，服务器按电脑端[打印模板](../system/print-template)中该单据的默认格式（字段、列、名称、纸张；上传了 JRXML 或启用套打的同样生效）生成销售出库单或采购入库单的 PDF，内容与电脑端打印相同；
2. 小程序用微信的文件预览打开 PDF；
3. 点击右上角「…」菜单，可以转发给微信好友或文件传输助手，或「用其他应用打开」，在打印机厂商的 App、WPS 等应用中打印。

点「暂不」跳过；以后需要打印时请在电脑端单据详情中打印。

::: warning 限制
- 小程序不能直接连接打印机，只能生成 PDF 后转发或用其他应用打印；
- 需要该单据的查看权限（销售出库或采购入库的查看权限），没有时不询问；
- 只能打印本次保存或审核的单据，不能按格式选择，按[默认格式](../system/print-template#多份打印格式)打印；需要选择其他格式（如不含价格的发货单）或补打以前的单据时，在电脑端打印。
:::
