# 缓存监控

缓存监控显示缓存服务（Redis）的运行指标和命令统计，并可以按类别查看、删除、清空系统缓存，例如解除账号锁定、让权限修改立即生效。

::: warning 平台专属
缓存监控是平台专属功能，SaaS 模式下只有平台租户的管理员可以使用。
:::

## 页面入口

系统监控 → 缓存监控

![缓存监控](/images/manual/monitor/cache.jpg)

标题下方显示 Redis 版本、运行模式和更新时间，右侧「刷新」按钮重新加载。

::: tip 内存缓存模式
如果系统配置为使用内存缓存（适用于本地体验和测试），页面会提示「当前使用内存缓存，Redis 运行指标不可用」，只显示下方的缓存管理。生产环境请使用 Redis。
:::

## 运行指标

| 指标 | 说明 |
| --- | --- |
| Key 总数 | 缓存中的键数量，下方显示已过期的数量 |
| 已用内存 | Redis 当前占用内存，下方为峰值 |
| 客户端连接 | 当前连接数，下方为被拒绝的连接数 |
| 每秒操作 | 当前每秒处理的命令数，下方为累计命令数 |
| 命中率 | 读取缓存的命中比例，下方为命中 / 未命中次数 |
| 运行时长 | Redis 已运行的时间，下方为端口 |

**基本信息**：版本、运行模式、端口、角色、操作系统、运行时长、已用内存、内存峰值、内存上限（0 显示「不限制」）、碎片率、淘汰策略、AOF 是否开启、RDB 最近保存状态、网络流量（入 / 出）、过期 Key、淘汰 Key。

**命令统计**：按调用次数显示各类命令（get、set、scan、del 等）的占比图，可在图表和表格之间切换。

## 缓存管理

页面下方分为三栏：「缓存列表」「键名列表」「缓存内容」。

**缓存列表**：系统中的各类缓存。

| 缓存 | 说明 |
| --- | --- |
| 登录会话 | 在线用户的登录会话，清空后所有用户需重新登录 |
| 用户权限 | 登录用户的角色与权限，清空后下次请求自动重新加载 |
| 字典数据 | 按字典类型缓存的字典数据 |
| 登录失败 | 按用户名记录的连续登录失败次数，达到上限时锁定账号；清空即解除锁定 |
| 登录验证码 | 验证码答案，2 分钟内有效，校验一次后作废 |
| 系统参数 | [参数设置](../system/config)中修改过的参数，保存时自动清理 |

**操作步骤**：

1. 在「缓存列表」点击一类缓存，「键名列表」显示该类缓存下的所有键（可输入关键字筛选）。
2. 点击某个键，「缓存内容」显示键名、过期时间和内容（格式化显示）。
3. 键名右侧的删除按钮删除单个缓存，确认「确定删除该缓存？」。
4. 缓存列表中的清空按钮清空该类的全部缓存，确认「确定清空『xxx』的全部缓存？」。

删除和清空需要「清除缓存」权限，操作会记录到[操作日志](./operlog)。

## 常见用法

| 需求 | 做法 |
| --- | --- |
| 解除某个账号的登录锁定 | 打开「登录失败」，找到以该用户名结尾的键删除（SaaS 模式下键名中带租户编号）；或清空整类 |
| 修改了数据库中的权限、角色，用户仍看不到 | 清空「用户权限」，用户下次请求时自动重新加载 |
| 让所有人重新登录（如安全事件） | 清空「登录会话」 |
| [字典](../system/dict)修改后页面仍显示旧值 | 清空「字典数据」，并让用户刷新页面 |

::: warning 注意
清空「登录会话」会让所有在线用户（包括你自己）立即下线，正在编辑未保存的内容会丢失，请在业务低峰期操作并提前通知。
:::
