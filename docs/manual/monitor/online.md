# 在线用户

在线用户列出当前所有有效的登录会话，管理员可以查看谁在什么地方、用什么设备登录，并强制下线指定会话。

## 页面入口

系统监控 → 在线用户

![在线用户](/images/manual/monitor/online.jpg)

## 页面说明

工具栏左侧可以「按用户名搜索」，旁边的标签显示「当前在线 N 个会话」。同一个账号在多个浏览器或设备上登录时，每次登录是一个独立的会话，会分别列出。

| 列 | 说明 |
| --- | --- |
| 用户名 | 登录账号；当前登录的自己带「我」标记 |
| 会话编号 | 本次登录的唯一编号，过长时省略，鼠标悬停查看完整内容 |
| 登录 IP | 客户端 IP 地址 |
| 登录地点 | 根据 IP 解析的归属地（离线库解析，不调用外部接口），内网地址显示「内网IP」 |
| 浏览器、操作系统 | 根据浏览器信息识别 |
| 登录时间 | 本次登录的时间，列表按登录时间倒序 |
| 操作 | 「强退」 |

列表每页 20 条，可通过工具栏刷新、调整列和密度。

## 强制下线

1. 找到要下线的会话，点击「强退」。
2. 在确认框「确定将『xxx』强制下线？」中确认。
3. 该会话立即失效，对方下一次操作时会跳转到登录页。

强退只结束当前这一次登录，账号仍可以重新登录。要彻底阻止登录，请到[用户管理](../system/user)停用该账号或重置密码。强退操作会记录到[操作日志](./operlog)（操作类型「强退」）。

## 会话何时自动结束

- 用户点击「退出登录」；
- 超过「[参数设置](../system/config) → [登录有效期](../system/config#登录与会话)」（默认 12 小时）；
- 管理员停用、删除该账号或重置其密码，该账号的所有会话立即失效；
- 开启「同一账号只允许一处登录」时，账号在别处登录后，之前的会话自动下线；
- SaaS 模式下租户被停用、删除或到期，该租户的所有会话失效。

## 注意事项

::: tip 关于 IP 地址
系统部署在 Nginx 等反向代理之后时，需要代理正确传递客户端地址，否则所有人显示为代理服务器的 IP。在本机访问时显示 127.0.0.1 或内网 IP 属于正常现象。
:::
