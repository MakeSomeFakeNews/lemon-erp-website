# 登录日志

登录日志记录每一次登录尝试，无论成功还是失败，包括账号、IP 及归属地、浏览器、操作系统和提示信息，用于排查登录问题和发现异常登录。

## 页面入口

系统监控 → 登录日志

![登录日志](/images/manual/monitor/loginlog.jpg)

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 用户名 | 登录时填写的账号 |
| 登录 IP | 客户端 IP |
| 登录地点 | IP 归属地，如「广东」「深圳」「内网IP」 |
| 状态 | 成功 / 失败 |
| 登录时间 | 日期范围 |

## 列表字段

| 列 | 说明 |
| --- | --- |
| 编号 | 日志编号 |
| 用户名 | 登录时填写的账号（包括不存在的账号）；用钉钉、企业微信、飞书登录时为绑定的系统账号，成员未绑定时记为「平台:成员 userid」，如「钉钉:zhangsan」 |
| 登录 IP | 客户端 IP |
| 登录地点 | 根据 IP 解析的归属地 |
| 浏览器、操作系统 | 识别不出时显示「未知」（如命令行工具调用） |
| 状态 | 成功 / 失败 |
| 提示信息 | 登录结果说明，如「用户名或密码错误」「用户名或密码错误，再错 2 次将锁定账号」「验证码错误」「账号已停用」「租户已停用」「租户已过期，请联系平台续费」，以及[第三方登录](../guide/login#钉钉-企业微信-飞书登录)的「钉钉登录成功」「企业微信登录成功」「飞书登录成功」「该钉钉账号未绑定系统用户」等 |
| 登录时间 | |
| 操作 | 「删除」 |

## IP 归属地

归属地使用系统内置的离线 IP 地址库解析，不调用任何外部接口：

- 公网 IPv4 地址显示到省份、城市；
- 内网地址（10.x、172.16～31.x、192.168.x、127.x 等）显示「内网IP」；
- 公网 IPv6 地址目前显示「未知」。

::: tip 多语言
登录日志中的提示信息（如「登录成功」「钉钉登录成功」「用户名或密码错误」）和 IP 归属地始终以中文记录，不随界面语言变化。
:::

## 删除与清空

- 工具栏「删除」：删除勾选的日志；
- 「清空」：清空全部登录日志，不可恢复（SaaS 模式下只清空本租户的）；
- 行内「删除」：删除单条；
- 「导出」：按当前条件导出 Excel。

删除和清空需要「日志删除」权限。

## 常见问题

**员工说密码没错却登不上？** 按用户名查询失败记录，看「提示信息」：

| 提示 | 处理 |
| --- | --- |
| 用户名或密码错误 | 确认账号（SaaS 模式下还要确认租户名称）；忘记密码由管理员[重置密码](../system/user#重置密码) |
| 用户名或密码错误，账号已锁定；密码错误次数过多，账号已锁定，请 N 分钟后再试或联系管理员重置密码 | 连续输错达到[锁定次数](../system/config#登录与会话)。等待锁定时长结束，或由管理员重置密码 / 在[缓存监控](./cache)中清空「登录失败」缓存解锁 |
| 验证码错误、验证码已过期，请刷新 | 刷新验证码重新输入，算术题填写计算结果 |
| 账号已停用 | 在[用户管理](../system/user)中启用 |
| 租户已停用、租户已过期，请联系平台续费 | SaaS 模式下由平台管理员在[租户管理](../system/tenant)中启用或延长到期时间 |

**发现陌生地点的成功登录？** 立即在[在线用户](./online)中强制下线该会话，并重置该账号的密码。
