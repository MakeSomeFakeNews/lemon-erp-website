# 系统监控概述

「系统监控」帮助系统管理员掌握系统的运行状况和使用情况：谁在线、谁做了什么、谁登录过，服务器和缓存是否健康，以及各项定时任务是否按时执行。

## 页面入口

顶部导航「系统监控」，侧边栏包含以下菜单：

| 菜单 | 用途 | 说明 |
| --- | --- | --- |
| [在线用户](./online) | 查看当前登录的会话，强制下线 | |
| [操作日志](./operlog) | 查询新增、修改、删除、审核等操作记录，查看请求参数和结果 | 带 IP 归属地 |
| [登录日志](./loginlog) | 查询登录成功和失败记录 | 带 IP 归属地 |
| [服务监控](./server) | CPU、内存、JVM、磁盘和服务器信息 | 平台专属 |
| [缓存监控](./cache) | 缓存运行指标、命令统计、缓存内容管理 | 平台专属 |
| [定时任务](./job) | 调整任务的执行时间与参数，启停、立即执行、查看执行日志 | 平台专属 |

::: tip 多租户说明
开启 SaaS 模式时，在线用户、操作日志、登录日志按租户隔离，每个租户的管理员只能看到本租户的数据；服务监控、缓存监控、定时任务是平台专属功能，只有平台租户的管理员可以使用。
:::

## 典型使用场景

| 场景 | 做法 |
| --- | --- |
| 员工反馈账号被锁定 | 在[登录日志](./loginlog)中查看失败原因；在[用户管理](../system/user)中重置密码，或在[缓存监控](./cache)中清空「登录失败」缓存解锁 |
| 发现可疑登录 | 在[登录日志](./loginlog)按用户名、IP、地点排查，在[在线用户](./online)中强制下线，再停用账号或重置密码 |
| 追查数据被谁修改 | 在[操作日志](./operlog)按模块、操作人、时间查询，打开详情查看请求参数 |
| 系统变慢 | 在[服务监控](./server)查看 CPU、内存、JVM 使用率；在[操作日志](./operlog)中查看耗时较长（标红）的请求 |
| 到期提醒没有收到 | 在[定时任务](./job)中查看对应任务的状态、最近执行结果和执行日志，必要时点击「执行」立即运行一次 |
| 修改权限后用户仍看不到菜单 | 让用户刷新页面；仍不生效时在[缓存监控](./cache)中清空「用户权限」缓存 |

## 相关角色

| 角色 | 权限 |
| --- | --- |
| 超级管理员 | 全部功能 |
| 租户管理员（SaaS 模式） | 本租户的在线用户、操作日志、登录日志 |
| 普通用户 | 只读查看在线用户、操作日志、登录日志 |

各页面的按钮权限：强制退出（在线用户）、日志删除（操作日志、登录日志）、清除缓存（缓存监控）、任务修改和立即执行（定时任务），可在[角色管理](../system/role)中分配。
