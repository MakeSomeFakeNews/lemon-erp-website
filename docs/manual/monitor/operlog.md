# 操作日志

操作日志自动记录用户在系统中的新增、修改、删除、授权、导入、导出、强退、清空等操作，包括操作人、时间、IP 和归属地、请求参数、返回结果、耗时和是否成功，用于审计和问题追查。查询类操作不记录。

## 页面入口

系统监控 → 操作日志

![操作日志](/images/manual/monitor/operlog.jpg)

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 操作模块 | 如「用户管理」「采购订单」，模糊查询 |
| 操作人 | 操作人账号 |
| 操作类型 | 其他、新增、修改、删除、授权、导出、强退、清空、导入 |
| 操作状态 | 成功 / 失败 |
| 操作时间 | 日期范围 |

查询栏默认只显示前几个条件，点击「展开」显示全部。

## 列表字段

| 列 | 说明 |
| --- | --- |
| 编号 | 日志编号 |
| 操作模块 | 被操作的功能，如「参数设置」「采购销售出入库」 |
| 操作类型 | 带颜色的标签 |
| 操作人 | 操作人账号 |
| 请求 | 请求方式（POST 新增、PUT 修改、DELETE 删除等）和请求地址 |
| 操作 IP、操作地点 | 客户端 IP 及其归属地 |
| 状态 | 成功 / 失败 |
| 耗时 | 毫秒；超过 1000 ms 的标红，便于发现慢操作 |
| 操作时间 | |
| 操作 | 「详情」「删除」 |

## 查看详情

点击「详情」打开「操作日志详情」抽屉：

![操作日志详情](/images/manual/monitor/operlog-detail.jpg)

- 操作模块、操作类型、操作人、操作 IP（含归属地）、操作时间、耗时、状态、请求、方法；
- **请求参数**：提交的数据（格式化显示）；
- **返回结果**：系统返回的结果；
- **异常信息**：操作失败时显示失败原因。

::: tip 敏感信息脱敏
日志中的密码、薪资类金额，以及[第三方集成](../system/im)的应用密钥、群机器人 Webhook 地址和加签密钥完全隐藏；身份证号、银行卡号、手机号只保留前 3 位和后 4 位。
:::

## 删除与清空

| 按钮 | 说明 |
| --- | --- |
| 删除（工具栏） | 删除勾选的日志 |
| 清空 | 清空全部操作日志，此操作不可恢复（SaaS 模式下只清空本租户的日志） |
| 删除（行内） | 删除单条日志 |
| 导出 | 按当前条件导出 Excel |

删除和清空需要「日志删除」权限。清空操作本身也会作为一条「清空」类型的日志记录下来。

## 常见用法

- **查某张单据是谁删的**：操作类型选「删除」，操作模块填单据名称，限定时间范围，打开详情查看请求中的单据 ID。
- **查参数被谁改过**：操作模块填「参数设置」，详情的请求参数中可以看到改了哪些参数。
- **排查报错**：操作状态选「失败」，在详情的「异常信息」中查看原因。

::: warning 注意
操作日志会持续增长，建议定期导出归档后清理。审计要求较严格的企业应限制「日志删除」权限的分配。
:::
