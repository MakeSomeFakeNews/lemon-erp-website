# 服务监控

服务监控实时显示运行柠檬ERP 的服务器和 Java 虚拟机的资源使用情况，帮助运维人员判断系统变慢、内存不足、磁盘将满等问题。

::: warning 平台专属
服务监控是平台专属功能，SaaS 模式下只有平台租户的管理员可以使用。
:::

## 页面入口

系统监控 → 服务监控

![服务监控](/images/manual/monitor/server.jpg)

## 顶部信息与刷新

标题下方显示主机名、服务器 IP 和最近更新时间。右侧：

- **自动刷新**开关：开启时每 5 秒刷新一次（浏览器标签页不在前台时暂停）；
- **刷新**按钮：立即刷新一次。

## 使用率卡片

使用率进度条按阈值提示：达到 70% 显示「偏高」，达到 90% 显示「告警」，同时用图标和文字标注。

| 卡片 | 内容 |
| --- | --- |
| CPU | 使用率；总使用率进度条及其中用户、系统、IO 等待的占比；CPU 型号；物理核心 / 逻辑核心数；1 / 5 / 15 分钟平均负载（操作系统不支持时显示「不支持」） |
| 内存 | 已用 / 总内存；物理内存使用率和可用内存；交换空间使用情况 |
| JVM 内存 | 堆内存已用 / 最大，使用率和已提交内存；非堆内存、已加载类数、当前线程数、峰值线程数 |

## 服务器信息

主机名、服务器 IP、操作系统、系统架构、系统版本、系统运行时长、时区、进程 ID、项目路径。

## Java 虚拟机

名称、版本、厂商、启动时间、运行时长、垃圾回收（各回收器的次数和累计耗时）、安装路径、启动参数。

## 磁盘

列出服务器的各个磁盘分区：挂载点、名称、文件系统、可用空间、使用情况（已用 / 总量及使用率进度条）。附件、上传文件、数据库所在的磁盘需要重点关注。

## 如何判断问题

| 现象 | 可能原因与建议 |
| --- | --- |
| CPU 长时间「告警」 | 有大量计算任务（如 [MRP 运算](../mes/mrp)、[成本计算](../fin/cost)、[数据仓库同步](../bi/etl)）在运行，或并发用户过多；可结合[定时任务](./job)的执行时间排查，必要时扩容 |
| 物理内存「告警」 | 服务器上其他程序占用过多，或需要增加内存 |
| JVM 堆内存持续接近最大值、垃圾回收次数快速增加 | JVM 最大内存设置偏小，请部署人员调整启动参数中的内存配置 |
| 磁盘使用率「告警」 | 清理旧的日志和备份，或扩容磁盘；附件目录过大时考虑迁移存储 |

::: tip 提示
本页只显示当前时刻的数据，不保存历史曲线。需要长期监控和告警时，建议接入专业的运维监控系统。
:::
