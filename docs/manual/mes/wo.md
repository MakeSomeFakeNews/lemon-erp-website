# 生产工单

生产工单是车间生产的执行单据：一张工单生产一种产品，保存时按物料清单生成用料和工序，下达后车间按工单领料、报工，最后完工入库。工单的领料、报工、完工数据也是[成本核算](../fin/cost)、[计件工资](../hr/payroll)和设备 OEE 的来源。

## 页面入口

生产制造 → 车间执行 → 生产工单

![生产工单列表](/images/manual/mes/wo-list.jpg)

::: tip 微信小程序
车间人员可以在[微信小程序](../miniapp/warehouse#报工)中扫描工单号为本人报工（选择工序，填写合格、报废数量和工时，可选设备和模具）。
:::

## 新增 / 编辑工单

点击「新增工单」（或草稿工单的「编辑」），右侧打开表单抽屉。

![新增工单](/images/manual/mes/wo-form.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 产品 | 是 | 搜索物料编码、名称或扫码 |
| BOM | 否 | 选择产品后列出它的 BOM 版本，默认版本标「（默认）」；不选时使用默认 BOM。产品没有默认 BOM、BOM 不属于该产品或已停用时不能保存 |
| 生产数量 | 是 | 产品启用了序列号管理时必须为整数 |
| 计划开工 | 否 | 默认今天 |
| 计划完工 | 否 | 不能早于计划开工 |
| 完工入库仓库 | 否 | 完工入库时默认选中该仓库；不能选择已停用的仓库 |
| 备注 | 否 | 最多 255 个字 |

保存后：

- **用料**：按 BOM 生成，需求数量 = 生产数量 × 用量 × (1 + 损耗率)；子件是虚拟件时展开为虚拟件的子件（用量相乘）；同一物料合并为一行；序列号物料向上取整。
- **工序**：按 BOM 的工艺路线生成，带出工作中心、标准工时、计件单价和「首件检验」标记。
- 保存后修改 BOM 不会影响已有工单。编辑草稿工单（例如换了 BOM 或改了数量）时，用料和工序会按新的 BOM 重新生成。

工单也可以由 [生产计划](./plan) 转工单、[MRP 运算](./mrp) 下达、[齐套分析](./kit) 缺料下单、拆分生成，这些都是草稿工单，需要在这里下达。

## 操作步骤

### 下达

在列表或详情中点击「下达」，确认提示「下达后车间可以领料、报工，工单不能再修改」。下达后状态变为「已下达」。

### 领料

1. 在详情底部点击「领料」，打开领料页面，明细自动列出所有还有未领数量的用料。
2. 选择**仓库**（必填）和**业务日期**（必填，默认今天），可填备注。
3. 每行选择**库位 / 批次**（必填，从所选仓库的现有库存中选择，下方显示可用数量），确认**数量**（默认为未领数量）；序列号物料需要扫码或输入序列号，数量与序列号个数一致。
4. 同一物料需要从多个库位、批次领用时，点击行尾的拆分按钮复制一行；不需要领的物料点击删除按钮移除。
5. 点击「确认领料」。

![领料](/images/manual/mes/wo-issue.jpg)

「未领数量」列 = 需求 + 已补料 - 已领，下方显示需求、补料和已领数量。

**超领控制**：每个物料累计领料不能超过

**领料上限 = 需求 × (1 + 允许超领比例) + 已补料**

允许超领比例在物料的[生产计划属性](../wms/material#生产计划-需要生产计划属性修改权限)中设置（未设置为 0）。超出时提示「领料超过上限：需求 x，允许超领 y%，已补料 z，已领 w，最多还能领 n；超出部分请提交补料申请」，请通过 [补料申请](./supplement) 处理。只能领工单用料中的物料。

### 退料

点击「退料」，明细列出已领数量大于 0 的用料（「已领数量」列）。选择仓库、业务日期，每行填写**库位**、**批次号**（启用批次管理的物料必填）、**数量**和序列号，点击「确认退料」。退料数量不能超过已领数量，生成「生产退料」入库单，已领数量相应减少。

### 报工

1. 在「工序」页签中点击某道工序的「报工」。
2. 填写报工信息：

![报工](/images/manual/mes/wo-report.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 报工日期 | 是 | 默认今天 |
| 实际工时 | 是 | 默认 = 本工序剩余数量 × 标准工时 |
| 合格数量 | 是 | 默认为本工序剩余数量（工单数量 - 已报合格 - 已报报废） |
| 报废数量 | 否 | 默认 0 |
| 生产设备 | 否 | 用于 [设备 OEE](./oee)。工序所在工作中心的设备排在前面；只有一台时自动选中 |
| 模具工装 | 否 | 只能选择已在 [模具工装](./mold) 中领用到本工单的模具，下方提示本次模次和累计模次 / 设计寿命 |
| 操作员 | 否 | 不填为本人；工序设置了计件单价时提示「计件单价 ¥x / 件，计入操作员的计件工资」 |
| 备注 | 否 | |

3. 点击「确定」。

报工校验：

- 合格、报废、工时不能全部为 0。
- 本工序累计（合格 + 报废）不能超过工单数量。
- **工序顺序**：本工序累计（合格 + 报废）不能超过上一道工序的累计合格数。
- **首件检验**：标有「首件」的工序，在该工序的首件检验确认且结论不是不合格之前，累计只能报工 1 件。超过时提示「需首件检验合格后才能继续报工，请先报工 1 件并提交首件检验」。首件检验在 [质量检验](../qms/inspection) 中新增。
- 选择的设备不能是已报废的设备。
- 报工日期所在期间已[结账](../fin/period)或已核算成本时不能报工。

报工后：计件工资 = 合格数量 × 计件单价，计入操作员当月工资表；选择模具时按「(合格 + 报废) / 模穴数，向上取整」累计模具的模次。

### 完工入库

1. 点击「完工入库」，明细为工单产品，「未完工数量」= 工单数量 - 已完工。
2. 仓库默认为工单的完工入库仓库；填写业务日期、库位、批次号（启用批次管理时必填，还可以填写生产日期、有效期至）、数量、序列号。
3. 点击「确认完工入库」，生成「生产入库」入库单。

![完工入库](/images/manual/mes/wo-finish.jpg)

完工入库的累计数量受以下限制：

- 不超过工单数量；
- 工单已经报过工的，不超过**末道工序的累计合格数**，否则提示「完工数量超过末道工序的累计合格数，请先报工」；
- 产品的生产计划属性勾选了「完工需成品检验」时，不超过已确认的成品检验合格数，否则提示「请先做成品检验」。

累计完工数量达到工单数量时，工单自动变为「已完工」。

### 报废入库

报工时报废的产品可以入到不良品仓，便于后续处理：点击「报废入库」，**仓库只能选择[仓库类型](../wms/warehouse#仓库类型)为「不良品仓」的仓库**，数量累计不超过各工序报工报废数合计（明细下方显示「报工报废 x，已入库 y」），生成「报废入库」入库单。报废入库不计入完工数量。

### 改量

已下达、生产中的工单点击「改量」，填写新的**生产数量**（下方提示当前数量和已完工数量）。新数量不能少于已完工数量和各工序已报工（合格 + 报废）的数量；序列号产品必须为整数。用料需求按新数量重新计算（已领超出的部分可以退料）。改量后的数量如果不大于已完工数量，工单自动完工。改量会记录变更日志。

### 拆分

点击「拆分」，填写**拆分数量**（必填）和新工单的计划开工、计划完工（默认与原工单相同）。拆分数量必须大于 0、小于工单数量，并且不超过未开工的数量（工单数量 - 已完工与已报工数量中的较大者）。系统生成一张同产品、同 BOM 的草稿工单（来源「拆分」，备注「拆分自 原工单号」，详情中显示「拆分自」链接），原工单数量相应减少、用料重算。完成后可选择「打开新工单」或「留在本页」。

### 返工工单

用于对已入库或待返工的产品重新加工：

- 从列表点击「新建返工工单」，选择产品；或在生产中、已完工工单的详情中点击「新建返工工单」，自动带出产品、完工入库仓库和来源工单。
- 填写**返工数量**（必填）、完工入库仓库、计划开工、计划完工、备注（如返工原因）。
- 返工工单的**用料是产品本身**（领出待返工的产品，单位用量 1），**工序取产品的默认 BOM**，完工后重新入库；保存为草稿，下达后才能领料、报工。

[不合格品处理](../qms/ncr) 的处置方式选择「返工」时，也会按工单产品自动生成草稿返工工单。

### 关闭

已下达、生产中的工单不再继续生产时点击「关闭」，确认提示「未完工部分不再生产，已领未用的物料请先退料」。关闭后：

- 工单不能再领料、报工、入库；
- 该工单审批中、待发料的补料申请自动撤销；
- 成本核算时，关闭工单剩余的在产品成本转为生产损失。

### 打印

点击详情右上角的「打印」，打印「生产任务单」：表头为产品、BOM 版本、计划数量、计划开工、计划完工、完工入库仓库；明细为用料（单位用量、需求数量、补料、已领）；附工序表（工序号、工序、工作中心，以及留空的合格数、报废数、操作员供车间手工填写）；签字栏为制单、生产主管、仓库。打印格式可在「系统管理 → [打印模板](../system/print-template)」中调整。

## 单据状态

草稿 → 已下达 → 生产中 → 已完工；已下达、生产中的工单可以关闭。

| 状态 | 说明 | 可用操作 |
| --- | --- | --- |
| 草稿 | 新建或由计划、MRP、缺料下单、拆分、不合格品返工生成 | 编辑、下达、排程、拆分 |
| 已下达 | 车间可以开始生产 | 领料、退料、报工、补料申请、完工入库、报废入库、改量、拆分、排程、关闭 |
| 生产中 | 首次领料、报工或完工入库后自动变为生产中 | 同已下达，另可新建返工工单 |
| 已完工 | 完工入库累计达到工单数量时自动变为已完工 | 查看、打印、新建返工工单 |
| 已关闭 | 手工关闭 | 查看、打印 |

## 与其他模块的联动

| 业务 | 联动 |
| --- | --- |
| 领料 | 生成并确认「生产领料」[出库单](../wms/out)，扣减库存（批次、序列号同步） |
| 退料 | 生成并确认「生产退料」[入库单](../wms/in) |
| 完工入库 | 生成并确认「生产入库」入库单；工单关联生产计划时，计划下全部工单完工数量达到计划数量后计划自动关闭 |
| 报废入库 | 生成并确认「报废入库」入库单，入不良品仓 |
| 补料发料 | 生成「补料」工单单据和「生产领料」出库单，计入已领和已补料 |
| 报工 | 工时用于[成本核算](../fin/cost#工单成本)的直接人工和制造费用（按工作中心费率）；计件工资计入[工资表](../hr/payroll)；设备、模具数据用于设备 OEE 和模具寿命 |
| 成本核算 | 月末按领料、工时计算工单成本，完工按比例结转，关闭工单的剩余在产品转生产损失 |
| 质量 | [首件检验](../qms/inspection#首件检验限制报工)控制报工；[成品检验](../qms/inspection#完工需成品检验)控制完工入库；[不合格品](../qms/ncr#处置方式与联动)返工生成返工工单 |

领料、退料、完工入库、报废入库都是**保存即确认**，不能修改或删除；数量有误时通过退料、其他出入库等反向业务冲回。库存不足、序列号不在库等错误会使整张单据保存失败。

## 注意事项

::: tip 提示
- 车间一般按「下达 → 领料 → 逐道工序报工 → 完工入库」操作。启用了报工的工单，完工入库前末道工序必须先报工。
- 领料不够时先看「齐套分析」是否缺料；超出领料上限的损耗请走补料申请，便于追溯原因。
:::

::: warning 注意
- 工单下达后不能再编辑，数量变化请用「改量」，需要分批生产请用「拆分」。
- 关闭工单前请先把已领未用的物料退回仓库。
:::
