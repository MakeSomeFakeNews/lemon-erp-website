# 生产看板

生产看板用一个页面回答车间最常被问的几个问题：每张在制工单走到了哪道工序、还剩几道、预计哪天完工、会不会误了交期；每条产线（工作中心）今天做了多少、忙不忙、手上排了哪些活、预计哪天做完。数据全部来自工单的工序和报工记录，打开即是最新情况，不需要录入任何东西。

适合生产计划员、车间主管每天开工前和交班时查看，也可以全屏放在车间办公室的电脑上。需要挂在车间电视上免登录投屏时，使用[数据大屏](../bi/screen#生产进度)的「生产进度」大屏，数据与本页相同。

## 页面入口

生产制造 → 车间执行 → 生产看板

![生产看板](/images/manual/mes/board.jpg)

需要「生产看板」菜单权限。初始数据中授权给普通用户、总经理、生产计划员、车间主管角色。

## 统计范围

- **工单**：状态为「已下达」「生产中」的[生产工单](./wo)（草稿、已完工、已关闭的不显示）。
- **今日数据**：报工日期为今天的[报工](./wo#报工)记录（合格数、报废数、工时），按工序所属的工作中心归到产线。
- **产线**：全部启用的[工作中心](./work-center)；已停用的工作中心只有在还有未完成工序或今天有报工时才显示。
- 页面只读取数据，不会修改工单的计划日期，也不会产生任何单据。

## 工具栏

| 控件 | 说明 |
| --- | --- |
| 产线下拉（默认「全部产线」） | 选择某个工作中心后：在制工单只列出**有工序在这条产线上**的工单；产线状态只显示这一条；今日合格、报工工时、今日完工、剩余工时等指标只统计这条产线。预计完工日期仍按全部工单推演（产能是各工单共用的） |
| 搜索框「工单号、产品、客户」 | 在当前结果中按工单号、产品名称、物料编码、客户名称、销售订单号筛选，输入即生效 |
| 全部 / 生产中 / 交期风险 / 待入库 | 按工单状态快速筛选，按钮上显示数量。「交期风险」包括「预计延期」和「已逾期」两种 |
| 更新于 HH:mm:ss | 最近一次取数的时间 |
| 自动刷新 | 默认打开，每 30 秒刷新一次；浏览器标签页切到后台时暂停 |
| 刷新 | 立即重新取数 |
| 全屏 / 退出全屏 | 看板占满整个屏幕（不显示菜单和标签栏），适合放在车间电脑上；按 Esc 或再点一次退出 |

## 指标卡

| 指标 | 主数字 | 下方说明 |
| --- | --- | --- |
| **在制工单** | 已下达、生产中的工单数（选择产线时为有工序在该产线的工单数） | 生产中 N、待开工 N；有停滞的工单时另显示「停滞 N」 |
| **运行产线** | 今天有报工的产线数 / 显示的产线数 | 「今天有报工的产线 / 全部产线」 |
| **今日合格** | 今天报工的合格数量合计 | 报废数量；有报工时显示良率 = 合格 ÷（合格 + 报废）× 100% |
| **今日报工工时** | 今天报工的工时合计（小时） | 今日完工 N 单：今天完工（工单完工时间为今天）的工单数 |
| **交期风险** | 预计延期 + 已逾期的工单数，有风险时显示为红色 | 预计延期 N、已逾期 N |
| **预计全部完工** | 所有在制工单中最晚的预计完工日期（月-日）；有任何一张工单「无法估算」时显示「-」 | 今天 / 明天 / N 天后（没有在制工单时显示「没有在制工单」）；剩余 N 工时 |

「剩余工时」：显示全部产线时为全部在制工单的剩余工时合计；选择了产线时为这条产线上未完成工序的剩余工时。

::: tip 数量的口径
今日合格、报废、工时按报工日期统计，包括今天报工后已经完工的工单；同一工序的多次报工累加。今天没有任何报工时这几项都为 0，这是正常的（例如周末、节假日）。
:::

## 产线状态

每个工作中心一张卡片，右上角的图例说明颜色含义。

| 状态 | 判断条件 |
| --- | --- |
| **运行中**（绿色，圆点闪烁） | 今天这条产线有报工（合格、报废或工时任一不为 0） |
| **休息**（灰色） | 今天没有报工，且今天的可用工时为 0（非工作日或工厂日历设为休息） |
| **待开工**（橙色） | 今天没有报工，但还有未完成的工序排在这条产线上 |
| **空闲**（蓝色） | 今天没有报工，也没有待生产的工序 |

卡片内容：

| 项目 | 说明 |
| --- | --- |
| 今日合格 | 这条产线今天报工的合格数量 |
| 在排工单 | 在这条产线上还有工序没完成的工单数 |
| 剩余工时 | 这条产线上未完成工序的剩余工时合计 |
| 利用率进度条 | 今日报工工时 ÷ 今天的可用工时 × 100%，悬停显示「今日报工 X / 可用 Y 工时」；今天可用工时为 0 时显示「今日休息」 |
| 预计 MM-DD 做完（N 天后） | 这条产线上所有未完成工序中最晚的预计完成日期；没有待生产工序时显示「没有待生产的工序」 |
| 工序清单 | 排在这条产线上的工序，今天有报工的排在前面，其余按预计完成日期排序。每行显示工单号、工序号和工序名称，右侧为「今日 N」（今天已有报工）或预计完成日期。卡片最多列出 4 道，更多的显示「还有 N 道工序」 |

可用工时 = 每个资源当天的工时 × 资源数，按「工作中心的工厂日历设置 → 全厂工厂日历设置 → 工作中心的工作日和每日工时」的顺序取值，与[产能排程](./capacity#基本概念)一致。

## 在制工单

![在制工单与工序明细](/images/manual/mes/board-orders.jpg)

列表排序：交期有风险的在前（已逾期 → 预计延期 → 无法估算 → 按期），同一风险内按预计完工日期从早到晚。每页 20 条，可切换每页条数。

| 列 | 说明 |
| --- | --- |
| 工单 / 产品 | 工单号；产品名称和规格 |
| 客户 / 销售订单 | 工单来自由销售订单生成的[生产计划](./plan)时，显示客户和销售订单号；否则显示「非订单生产」 |
| 工序进度 | 每道工序一个色块：绿色已完成、蓝色进行中、灰色未开始，今天有报工的色块带标记。悬停色块显示「工序号 工序名 · 工作中心 · 状态 · 合格 X / 计划数量 · 报废 · 今日合格 · 预计完成日期」。下方文字为当前工序「第 i/n 道：工序名 · 工作中心」；工序全部完成时为「工序已完成，待完工入库」，没有工序的工单为「没有工序」 |
| 完成进度 | 按工时加权的完成百分比（见下文），已逾期的工单进度条为红色；下方为「已入库 X / 数量 单位」 |
| 剩余 | 「剩 N 道工序」和剩余工时 |
| 预计完工 | 预计完工日期，下方为今天 / 明天 / N 天后；预计延期显示为橙色、已逾期为红色。无法估算时显示「-」和「产能不足，无法估算」 |
| 交期 | 有需求日期时显示需求日期（下方注明「需求日期」）；否则显示工单的计划完工日期（注明「计划完工」）；都没有时为「-」 |
| 状态 | 两个标签：工单状态（生产中 / 停滞 / 待开工 / 待入库）和交期风险（按期 / 预计延期 / 已逾期 / 无法估算） |

点击行首的「+」展开工序明细：工序（工序号 + 名称）、工作中心、状态（已完成 / 进行中 / 未开始）、合格 / 计划（报废数另行红字标出）、今日合格、剩余工时、预计完成。已完成的工序剩余工时和预计完成显示「-」。自动刷新后展开状态保持不变。

### 工单状态

| 状态 | 判断条件 |
| --- | --- |
| **生产中** | 今天有报工 |
| **停滞** | 已经有过报工，但今天没有报工 |
| **待开工** | 还没有任何报工 |
| **待入库** | 全部工序都已完成（每道工序的合格 + 报废达到工单数量），只剩完工入库。没有工序的工单也显示为待入库 |

### 工序状态

| 状态 | 判断条件 |
| --- | --- |
| 已完成 | 合格 + 报废 ≥ 工单数量 |
| 进行中 | 未完成，但已有合格或报废报工 |
| 未开始 | 还没有报工 |

当前工序是第一道未完成的工序。

### 交期与交期风险

**交期**：工单来自生产计划时，取计划的需求日期；计划没有需求日期时取销售订单的交货日期；都没有时取工单的计划完工日期。

| 风险 | 判断条件 |
| --- | --- |
| **已逾期** | 交期早于今天，工单仍未完工 |
| **无法估算** | 产能不足，推演不出预计完工日期（见下文） |
| **预计延期** | 预计完工日期晚于交期 |
| **按期** | 其余情况（包括没有交期的工单） |

### 完成进度与剩余工时

- 每道工序的**单件工时**取工艺路线带到工单上的标准工时；没有设置标准工时的，按该工序已报工的实际工时 ÷ 已报工数量折算；两者都没有时按 0 计。
- 工序**剩余工时** =（工单数量 − 合格 − 报废）× 单件工时；工单剩余工时为各工序之和。
- **完成进度** =（全部工序总工时 − 剩余工时）÷ 全部工序总工时，总工时 = 工单数量 × 各工序单件工时之和。全部工序都没有工时时，按已完成工序数 ÷ 工序数计算；没有工序的工单按已入库数量 ÷ 工单数量计算。

### 预计完工日期怎么算

预计完工按**有限产能**推演，思路与[产能排程](./capacity#排程)的「全部排程」相同（各工单共享工作中心产能，先排的优先），但只用于显示，不回写工单的计划日期：

1. 所有已下达、生产中的工单按计划开工日期（没有的排在最后）、再按创建顺序依次排队；
2. 生产中的工单、计划开工日期早于今天或没有计划开工日期的工单从今天开始排；其余从计划开工日期开始；
3. 每道未完成工序按顺序占用所在工作中心每天的可用工时（今天已报工的工时先从今天的产能中扣除），排在前面的工单先占用；后一道工序不早于前一道工序完成的日期开始；
4. 工序占满剩余工时的那一天就是它的预计完成日期，最后一道未完成工序的日期就是工单的预计完工日期；工序已全部完成、只剩入库的工单按今天计；
5. 从今天起推演超过 366 天仍排不完时（例如工作中心长期没有可用工时、工序没有指定工作中心），该工序及其后续工序显示「产能不足，无法估算」。

因此调整工作中心的资源数、每日工时，或在[产能排程](./capacity#工厂日历)的工厂日历中安排加班、放假，都会立即反映到预计完工日期上。

## 与数据大屏的区别

| | 生产看板 | 数据大屏「生产进度」 |
| --- | --- | --- |
| 打开方式 | 系统内菜单，需要登录和菜单权限，不要求「全部数据」的数据权限 | [数据大屏](../bi/screen#生产进度)中打开（要求「全部数据」的数据权限），或用投屏链接在电视上免登录打开 |
| 数据 | 相同：指标、产线状态、在制工单与预计完工 | 相同，另有「今日每小时产出」图表 |
| 交互 | 按产线、关键字、状态筛选，展开工序明细，表格分页 | 只看不操作：工单列表自动滚动，可与其他大屏轮播 |
| 显示 | 普通页面（支持深色模式），可全屏 | 1920 × 1080 深色大屏，自动缩放铺满屏幕 |

数据大屏中的「生产车间」大屏侧重今日产量、设备状态、工作中心负荷和停机原因，与本页的工单进度视角不同。

## 常见问题

**为什么所有产线都显示「休息」？**
今天是这些工作中心的非工作日（例如周末），或工厂日历中把今天设为了休息，且今天没有报工。有报工时会显示为「运行中」。

**预计完工日期比计划完工日期晚很多？**
推演按实际产能逐日排队：前面的工单占用了产能，或工作中心的资源数、每日工时偏小。可在[产能排程](./capacity#负荷分析)中查看各工作中心的负荷，调整工作日历或资源数，或调整工单的计划开工日期改变排队顺序。

**为什么某张工单显示「产能不足，无法估算」？**
工序所在的工作中心在一年内都没有可用工时（例如资源数为 0、工作日为空、工厂日历全部设为休息），或工序没有指定工作中心。检查该工序的工作中心设置。

**工序没有标准工时会怎样？**
未报工前单件工时按 0 计，该工序不占用产能、剩余工时为 0；报工后按实际工时折算。建议在物料清单的工艺路线中维护标准工时，推演结果才准确。

::: warning 注意
看板显示全部已下达、生产中的工单，不按数据权限过滤；有本页菜单权限的用户都可以看到全部工单和产线的生产情况。
:::
