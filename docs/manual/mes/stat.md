# 生产统计

生产统计把车间的报工、完工入库、领料数据实时汇总成 5 张报表：**人员计件统计**、**工序产量统计**、**工单完成情况**、**产品产量汇总**、**用料差异分析**。车间主管用它看产量和效率，计划员看工单按期完成情况，人事、会计用它核对计件工资和用料损耗。报表只读，不修改任何单据，数据随报工、入库实时变化，不需要等月末。

## 页面入口

生产制造 → 生产统计 → 人员计件统计 / 工序产量统计 / 工单完成情况 / 产品产量汇总 / 用料差异分析

每张报表是一个单独的菜单，可以分别授权，见下文[权限](#权限)。

![人员计件统计](/images/manual/mes/mes-stat-piece.jpg)

## 页面的共同用法

5 张报表的页面结构相同：上方是查询条件和「汇总方式」，下方是指标、口径说明和汇总表格。

### 查询条件

| 条件 | 说明 |
| --- | --- |
| 日期范围 | 必填，默认本月（月初到今天）；快捷选项有「本月」「上月」「本年」「近 12 个月」，最长 366 天（超出时提示「日期范围不能超过 366 天」）。各报表按不同的日期筛选，见各报表的说明 |
| 全部人员 | 人员计件统计、工序产量统计：选择一个操作员 |
| 全部工作中心 | 人员计件统计、工序产量统计：选择一个工作中心 |
| 全部状态 | 工单完成情况：按工单状态筛选 |
| 全部分类 | 产品产量汇总：按产品的物料分类筛选 |
| 关键字 | 输入后按回车查询。人员计件、工序产量、工单完成情况按「产品编码 / 名称、工单号」，产品产量按「产品编码 / 名称」，用料差异按「物料、产品编码 / 名称、工单号」模糊匹配 |

修改日期范围或「汇总方式」会立即刷新；修改其他条件后点「**查询**」。

### 汇总方式、指标与合计

- 「**汇总方式**」决定按什么分行，默认取第一个选项；各汇总方式的排序见各报表的说明。
- 表格上方显示合计指标（人员计件统计、工序产量统计、工单完成情况、产品产量汇总），下方一行灰色文字说明本报表的计算口径，与本页的说明一致。
- 表格底部固定显示「**合计**」行，合计的是全部数据，不只是当前页。比率类指标的合计按合计数重新计算（例如合计的良品率 = 合计合格 ÷ (合计合格 + 合计报废)），不是各行比率的平均。
- 汇总行最多显示 2000 行，超过时表格上方提示「汇总行数较多，只显示前 2000 行（合计为全部数据）」。超过 50 行时分页显示，每页 50 行。

### 导出

- 「**导出**」把当前汇总方式下的全部汇总行（含合计行）导出为 Excel，文件名为「报表名_汇总方式_开始日期_结束日期」。数量、金额、比率导出为数值，便于再计算。
- 人员计件统计、工序产量统计的报工明细页另有「**导出明细**」，见下文[报工明细](#报工明细)。

### 数据范围

生产统计按**生产工单**的数据权限过滤：只统计用户有权查看的工单（工单的部门、制单人在角色的[数据权限](../guide/permission#数据权限的-5-种范围)范围内）上的报工、入库和用料。工单的部门取第一道工序工作中心的[所属车间](./work-center#所属车间与工单的数据权限)，因此「本部门」的车间主管看到的就是本车间的统计。

## 人员计件统计

按报工统计每个人的产量、工时和计件工资，用来核对计件工资、评比个人效率。

**统计范围**：报工日期在日期范围内的[报工记录](./wo#报工)。人员取报工时填写的「操作员」，没有填写时为报工人本人（与[工资表](../hr/payroll)中计件工资的归属一致）。

**汇总方式**：

| 汇总方式 | 分行依据 | 排序 |
| --- | --- | --- |
| 人员 | 操作员，另显示人员所在部门 | 计件工资从高到低，相同时合格数量从多到少 |
| 人员 × 工序 | 操作员 + 工作中心 + 工序名称 | 同上 |
| 人员 × 日期 | 操作员 + 报工日期 | 按人员、日期 |

**列与口径**：

| 列 | 口径 |
| --- | --- |
| 合格数量 / 报废数量 | 报工的合格数、报废数合计 |
| 良品率 | 合格 ÷ (合格 + 报废) |
| 实际工时 | 报工填写的实际工时合计 |
| 标准工时 | (合格 + 报废) × 工序的标准工时 |
| 效率 | 标准工时 ÷ 实际工时；没有标准工时时显示「-」 |
| 计件工资 | 各次报工的计件工资合计，每次报工的计件工资 = 合格数 × 工序计件单价（工艺路线中设置，下达工单时带入）；与工资表的计件工资**同一口径** |
| 报工次数 / 工单数 | 报工记录的条数、涉及的工单数 |

顶部指标：人数、合格数量、报废数量、良品率、实际工时、计件工资。

::: tip 与工资表核对
工资表的计件工资按自然月取当月报工。把日期范围选为同一个月、汇总方式选「人员」，每个人的计件工资应与当月工资表中的「计件工资」一致（工资表不受数据权限限制，核对时请使用能看到全部工单的账号）；不一致时通常是报工的操作员账号没有关联员工档案，这部分计件工资不会进入工资表。
:::

## 工序产量统计

按工作中心、工序统计产量、报废、工时和效率，用来看各产线、各工序的产出和瓶颈。

![工序产量统计](/images/manual/mes/mes-stat-output.jpg)

**统计范围**：与人员计件统计相同，报工日期在日期范围内的报工记录。

**汇总方式**：

| 汇总方式 | 分行依据 | 说明 |
| --- | --- | --- |
| 工作中心 | 工序所在的工作中心 | 工序没有设置工作中心的归入「未设置工作中心」 |
| 工序 | 工作中心 + 工序名称 | 同名工序在不同工作中心分开统计 |
| 产品 | 工单产品 | 另显示单位 |
| 日 / 月 | 报工日期 / 所在月份 | 按日期从早到晚排列 |

**列与口径**：合格数量、报废数量、良品率、实际工时、标准工时、效率的口径与人员计件统计相同；另有「**人数**」（参与报工的操作员人数）、报工次数、工单数。不显示计件工资。

顶部指标：合格数量、报废数量、良品率、实际工时、标准工时、效率。

## 报工明细

人员计件统计、工序产量统计可以查看组成某个数字的每一条报工：

- 点击汇总行（第一列显示为链接），打开「**报工明细 - 行名称**」子页，只列出该行对应的报工，例如某个人在某道工序上的报工、某工作中心在某一天的报工；
- 点击表格上方的「**全部明细**」，列出当前查询条件下的全部报工。

![报工明细](/images/manual/mes/mes-stat-detail.jpg)

明细按报工日期从新到旧排列，列有：报工日期、工单号、产品、工序（工序号 + 名称）、工作中心、人员、合格数量、报废数量、实际工时、计件单价、计件工资、生产设备、备注。子页顶部显示日期范围。

点击子页右上角的「**导出明细**」导出 Excel，最多导出 5000 行，超过时提示「数据较多，只导出了前 5000 行」，可以缩小日期范围后分批导出。

## 工单完成情况

统计一段时间内**计划完工**的工单完成了多少、是否按期，用来考核计划达成率和交期。

![工单完成情况](/images/manual/mes/mes-stat-wo.jpg)

**统计范围**：计划完工日期在日期范围内的生产工单，不含草稿（已下达、生产中、已完工、已关闭）。没有填写计划完工日期的工单不在统计中。

**汇总方式**：

| 汇总方式 | 分行依据 |
| --- | --- |
| 工单 | 每张工单一行，按计划完工日期排列 |
| 产品 | 工单产品 |
| 车间 | 工单的部门（第一道工序工作中心的所属车间） |
| 月 | 计划完工日期所在月份 |

**按工单列出**时的列：工单号、产品、状态、计划完工、完工 / 关闭日期、交期、延期天数、计划数量、完工数量、报废数量、完成率、良品率、车间。

| 列 | 口径 |
| --- | --- |
| 计划数量 / 完工数量 | 工单数量 / 累计完工入库数量 |
| 报废数量 | 各工序报工报废的合计 |
| 完成率 | 完工 ÷ 计划 |
| 良品率 | 完工 ÷ (完工 + 报废) |
| 交期 | 「按期完工」：已完工，完工日期不晚于计划完工日期；「延期完工」：已完工，完工日期晚于计划完工日期；「逾期未完工」：已下达或生产中，计划完工日期已过（早于今天）；「进行中」：还没有到计划完工日期；「已关闭」：已关闭的工单 |
| 延期天数 | 延期完工为完工日期比计划完工日期晚的天数，逾期未完工为今天比计划完工日期晚的天数 |

**按产品、车间、月汇总**时的列：工单数、计划数量、完工数量、报废数量、完成率、良品率，以及各交期状态的工单数（已完工、按期完工、延期完工、逾期未完工、已关闭）和**按期完工率** = 按期完工 ÷ 已完工。

顶部指标：工单数、完成率、良品率、按期完工率、延期完工、逾期未完工（大于 0 时红色显示）。

::: tip 提示
工单在「完工数量 + 报工报废达到工单数量」时也会完工（见[生产工单 - 完工条件](./wo#完工条件)），这类工单的完成率可能低于 100%，报废的部分体现在报废数量和良品率中。
:::

## 产品产量汇总

按产品、分类、车间统计完工入库和报废入库的数量，以及完工入库的成本。

![产品产量汇总](/images/manual/mes/mes-stat-product.jpg)

**统计范围**：业务日期在日期范围内的[完工入库](./wo#完工入库)和[报废入库](./wo#报废入库)单。

**汇总方式**：

| 汇总方式 | 分行依据 | 说明 |
| --- | --- | --- |
| 产品 | 工单产品 | 另显示规格、单位、产品分类 |
| 产品分类 | 产品的物料分类 | 没有分类的归入「未设置」 |
| 车间 | 工单的部门 | 没有部门的归入「未设置」 |
| 日 / 月 | 入库单的业务日期 / 所在月份 | 按日期从早到晚排列 |

**列与口径**：

| 列 | 口径 |
| --- | --- |
| 完工入库数量 / 报废入库数量 | 完工入库单、报废入库单的数量合计 |
| 完工入库次数 | 完工入库单的张数 |
| 工单数 | 涉及的工单数 |
| 完工入库成本 | 完工入库时转入产品的料工费合计（见[完工入库的成本](./wo#完工入库的成本)），需要「查看成本金额」权限，没有时不显示该列和对应指标 |
| 单位成本 | 完工入库成本 ÷ 完工入库数量，只在按产品汇总时显示 |

顶部指标：完工入库数量、报废入库数量、完工入库次数、工单数、完工入库成本（需要「查看成本金额」权限）。

完工入库成本是业务参考成本，财务记账以月末[成本核算](../fin/cost)为准。

## 用料差异分析

比较工单的标准用量与实际领用，找出超耗、节约的物料。

![用料差异分析](/images/manual/mes/mes-stat-usage.jpg)

**统计范围**：在日期范围内**完工**（按完工时间）或**关闭**（按关闭时间）的工单的全部用料。还在生产中的工单不统计，因为它们的领料还没有结束。

**汇总方式**：

| 汇总方式 | 分行依据 | 说明 |
| --- | --- | --- |
| 物料 | 用料物料，另显示涉及的工单数 | 按物料编码排列 |
| 工单 × 物料 | 每张工单的每个用料一行，另显示工单号、状态、产品、完工 / 计划 | 按工单号、物料编码排列 |

**列与口径**：

| 列 | 口径 |
| --- | --- |
| 标准用量 | 完工数量 × 单位用量（含损耗）。关闭时没有完工的工单，标准用量为 0 |
| 实际用量 | 净领料 = 领料 + 补料 − 退料 |
| 差异数量 | 实际用量 − 标准用量；正数为超耗（红色），负数为节约（绿色） |
| 差异率 | 差异数量 ÷ 标准用量 |

不同物料的单位不同，本报表没有合计行，顶部显示「**超耗行数**」「**节约行数**」。

::: tip 超耗不一定是浪费
- 报废品耗用的物料没有对应的完工数量，会体现为超耗；可以结合工单完成情况中的报废数量一起看。
- 关闭的工单只按已完工的数量计算标准用量，未完工部分已领未退的物料都算作超耗，关闭前应先把多领的物料退回仓库。
:::

## 权限

| 报表 | 菜单权限 | 内置角色 |
| --- | --- | --- |
| 人员计件统计 | 人员计件统计 | 普通用户、总经理、生产计划员、车间主管、会计、人事专员 |
| 工序产量统计 | 工序产量统计 | 普通用户、总经理、生产计划员、车间主管、质量工程师 |
| 工单完成情况 | 工单完成情况 | 普通用户、总经理、生产计划员、车间主管、质量工程师 |
| 产品产量汇总 | 产品产量汇总 | 普通用户、总经理、生产计划员、车间主管、仓库管理员、会计 |
| 用料差异分析 | 用料差异分析 | 普通用户、总经理、生产计划员、车间主管、会计 |

- 报工明细只要有人员计件统计或工序产量统计其中一个权限即可查看。
- 产品产量汇总的成本金额另需库存的「查看成本金额」按钮权限。
- 可在「系统管理 → [角色管理](../system/role)」中调整。SaaS 模式下，生产统计与生产工单同属「生产管理」功能，按行业模板开通生产功能的租户一并开通。
