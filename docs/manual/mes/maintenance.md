# 设备维护

设备维护用于登记和处理设备的故障维修与定期保养：报修或安排保养生成维护单，处理人开始处理、完成后填写结果和费用。系统自动联动设备状态、保养日期、停机记录（用于 OEE）和维护费用[凭证](../fin/voucher#业务生成的凭证)。通常由车间主管、设备管理员使用。

## 页面入口

生产制造 → 工艺与设备 → 设备维护

也可以在 [设备台账](./equipment) 的行操作中点击「维护」，直接为该设备打开报修 / 保养弹窗。

![设备维护列表](/images/manual/mes/maintenance-list.jpg)

## 列表

**查询条件**：关键字（维护单号、设备编码或名称）、类型（故障维修、定期保养）、状态（待处理、处理中、已完成）。从设备台账进入时自动按该设备筛选，点击「重置」清除。

| 列 | 说明 |
| --- | --- |
| 维护单号 | WX 开头 |
| 设备 | 设备名称，下方显示编码 |
| 类型 | 故障维修 / 定期保养 |
| 内容 | 故障现象或保养内容 |
| 计划日期 | |
| 状态 | 待处理、处理中、已完成 |
| 处理人 | |
| 处理时间 | 开始时间，下方显示完成时间 |
| 处理结果 | 处理结果，下方显示停机时长（故障维修）和费用 |
| 操作 | 待处理：「开始」「删除」；处理中：「完成」 |

工具栏支持导出当前查询结果。

## 报修 / 保养

点击「报修 / 保养」打开弹窗。

![报修 / 保养](/images/manual/mes/maintenance-form.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 设备 | 是 | 可搜索，只列出未报废的设备 |
| 类型 | 是 | 故障维修（默认）/ 定期保养 |
| 故障现象 / 保养内容 | 是 | 标签随类型变化，最多 255 个字符 |
| 计划日期 | 否 | 默认今天 |
| 处理人 | 否 | 文本，最多 64 个字符 |

确定后生成待处理的维护单。已报废的设备不能报修，提示「设备已报废」。

## 处理维护单

### 开始

点击「开始」并确认。故障维修会提示「故障维修开始后，设备状态变为「维修中」」。开始后：

- 维护单变为处理中，记录开始时间；
- 故障维修：设备状态变为「维修中」，并记住维修前的状态；
- 定期保养：设备状态不变。

### 完成

点击「完成」，在弹窗中填写：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 处理结果 | 是 | 最多 255 个字符 |
| 费用 | 否 | 维修 / 保养费用（元） |
| 处理人 | 否 | 默认带出维护单的处理人 |

完成后系统自动：

1. 维护单变为已完成，记录完成时间、结果、费用；
2. **故障维修**：计算停机时长（开始到完成的小时数），设备恢复为维修前的状态（原来闲置的仍为闲置，原来就是维修中或没有记录的恢复为运行）；
3. **定期保养**：设备的上次保养日期更新为今天，下次保养日期 = 今天 + 保养周期；
4. **停机记录**：开始到完成的时间自动记为设备停机，故障维修计为「故障」（非计划停机，影响 OEE 可用率），定期保养计为「计划保养」（计划停机，从计划时间中扣除）。这些记录在 [设备 OEE](./oee) 的「停机记录」中显示为「自动记录」，不能修改或删除；
5. **费用凭证**：填写了大于 0 的费用时，财务自动生成费用凭证：借 制造费用 / 贷 其他应付款，摘要为「设备维护费 维护单号 设备名称」。

## 单据状态

| 状态 | 允许的操作 |
| --- | --- |
| 待处理 | 开始、删除 |
| 处理中 | 完成 |
| 已完成 | 只读 |

只能删除待处理的维护单。

## 与其他模块的联动

- [设备台账](./equipment)：维修改变设备状态，保养更新保养日期；「设备保养提醒」[定时任务](../monitor/job)提醒有维护处理权限的人员安排保养。
- [设备 OEE](./oee)：维护单自动生成停机记录。
- 财务：维护费用生成[凭证](../fin/voucher#业务生成的凭证)（计入制造费用，月末随[成本核算](../fin/cost)分配）；删除该凭证后，维护单与凭证解除关联。

## 注意事项

::: tip 提示
- 有维护处理权限的用户，[首页待办](../guide/home#待办事项)中显示「设备保养到期」的数量，站内消息也会提醒即将到期的保养，点击可直接进入本页面。
- 停机时长按「开始」到「完成」的实际时间计算，请在实际开始处理时点击「开始」，处理完毕及时点击「完成」，以保证 OEE 数据准确。
:::
