# 模具工装

模具工装台账管理模具、工装夹具、检具：登记模穴数、设计寿命和适用产品，领用到生产工单、报工时按产出自动累计模次，接近或达到设计寿命时提醒，并记录领用、归还、使用、送修、修复、报废的完整履历。

## 页面入口

生产制造 → 工艺与设备 → 模具工装

![模具工装列表](/images/manual/mes/mold-list.jpg)

## 基本概念

| 概念 | 说明 |
| --- | --- |
| 模穴数 | 每一模次产出的产品数量 |
| 模次 | 模具的使用次数。报工时模次 = ⌈（合格数 + 报废数）/ 模穴数⌉，向上取整 |
| 设计寿命 | 模具允许使用的总模次，不填为不限寿命 |
| 预警比例 | 累计模次达到「设计寿命 × 预警比例」时提醒，默认 90% |
| 适用产品 | 模具可以用于哪些产品，不选时不限制；领用时校验工单产品 |

## 列表

**查询条件**：关键字（编码、名称）、类型（模具、工装夹具、检具）、状态（在库、使用中、维修中、报废），勾选「只看寿命预警」只显示累计模次已达到预警比例且未报废的模具。

| 列 | 说明 |
| --- | --- |
| 模具 | 编码名称（点击打开详情），下方显示规格 |
| 类型 | 模具、工装夹具、检具 |
| 适用产品 | 未设置时显示「不限」 |
| 寿命 | 有设计寿命时显示进度条和「已用 / 设计寿命 模次 · N 穴」，达到预警比例时进度条变为提醒样式，达到寿命时显示为异常（红色）；不限寿命时显示累计模次和「不限寿命」 |
| 状态 | 使用中的下方显示工单号和安装设备，其他状态显示存放位置 |
| 操作 | 「查看」；在库的显示「领用」，使用中的显示「归还」 |

## 新增 / 编辑模具

点击「新增模具」打开抽屉。

![新增模具工装](/images/manual/mes/mold-form.jpg)

| 字段 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 编码 | 是 | | 只能包含字母、数字、下划线和短横线，最多 32 个字符，不能重复 |
| 类型 | 是 | 模具 | 模具、工装夹具、检具 |
| 名称 | 是 | | 最多 64 个字符 |
| 规格 | 否 | | |
| 模穴数 | 是 | 1 | 每模次产出的数量，至少为 1 |
| 设计寿命 | 否 | | 模次，不填不限寿命 |
| 预警比例 | 是 | 90% | 1 ~ 100% |
| 已用模次 | 否 | 0 | 只在新增时显示，用于登记上线前已经使用过的模具 |
| 存放位置 | 否 | | |
| 适用产品 | 否 | | 可多选（最多 50 个），搜索物料编码或名称；不选时不限制 |
| 备注 | 否 | | |

## 模具详情

![模具详情](/images/manual/mes/mold-detail.jpg)

详情显示类型、状态、规格、寿命（已用 / 设计寿命 模次、百分比和预警比例）、模穴数、存放位置、当前使用（工单和设备）、适用产品、备注，下方为**履历**：日期、动作（领用、归还、使用、送修、修复、报废）、工单 / 设备、模次、说明、经办人和时间。

右上角按钮随状态变化：

| 状态 | 按钮 |
| --- | --- |
| 在库 | 「领用」「送修」「报废」「编辑」「删除」 |
| 使用中 | 「归还」「编辑」 |
| 维修中 | 「修复」「报废」「编辑」「删除」 |
| 报废 | 「删除」 |

## 操作步骤

所有动作都在弹窗中填写**日期**（必填，默认今天）和**说明**，并记入履历。

### 领用

1. 在列表或详情中点击「领用」；
2. 选择**工单**（必填，只能选择已下达、生产中的工单，可搜索工单号）和**安装设备**（可选）；
3. 确定后模具变为「使用中」。

领用时校验：

- 设置了适用产品时，工单产品必须在适用产品中，否则提示「模具不适用于工单 xx 的产品」；
- 累计模次已达到设计寿命的不能领用，提示「已达到设计寿命 N 模次，不能再领用」。

### 报工累计模次

在 [生产工单](./wo) 报工时选择领用到该工单的模具，系统按 ⌈（合格数 + 报废数）/ 模穴数⌉ 累计模次，并在履历中记录一条「使用」。模具没有领用到该工单时不能选择（提示「模具没有领用到该工单」）。

累计模次跨过预警线时，给有模具编辑权限的人员发送[站内提醒](../guide/profile#我的消息)「模具「…」即将到达寿命」；达到设计寿命时发送警告「模具「…」已达到设计寿命」，提示归还后不能再领用，请安排维修或报废。

### 归还

使用中的模具点击「归还」，可填写**存放位置**（不填保持原位置），模具变为「在库」。

### 送修、修复

- 在库的模具点击「送修」变为「维修中」（使用中的须先归还）；
- 维修中的点击「修复」恢复为「在库」，可填写新的存放位置。

### 报废

在库或维修中的模具点击「报废」。使用中的模具须先归还，提示「模具正在使用，请先归还」。

## 状态流转

在库 → 领用 → 使用中 → 归还 → 在库

在库 → 送修 → 维修中 → 修复 → 在库

在库 / 维修中 → 报废

## 注意事项

::: warning 注意
- 正在使用或已有使用记录（报工累计过模次）的模具不能删除，提示改为报废。
- 编辑模具时不能修改累计模次；已报废的模具不能编辑。
:::
