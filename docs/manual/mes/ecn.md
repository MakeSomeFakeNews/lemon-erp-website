# 工程变更

工程变更（ECN）用于受控地修改产品结构：以现有 BOM 为基准复制出新版本，在新版本上修改子件和工序，经审批后在生效日期自动启用新版本并接替默认 BOM，同时可同步草稿工单。适用于设计改进、降本、质量问题、客户要求、物料替代等场景，通常由工艺 / 研发工程师发起。

## 页面入口

生产制造 → 工艺与设备 → 工程变更

也可以在 [物料清单](./bom) 列表中点击某个版本的「发起变更」，系统会跳转到本页并以该版本为基准打开新增表单。

![工程变更列表](/images/manual/mes/ecn-list.jpg)

## 列表

**查询条件**：状态下拉框、关键字（变更单号、标题、产品），选择或回车后立即查询。

| 列 | 说明 |
| --- | --- |
| 变更单号 / 标题 | 单号以 ECN 开头，点击打开详情 |
| 产品 / 版本 | 产品编码名称，下方显示「原版本 → 新版本」 |
| 原因 | 设计改进、降本、质量问题、客户要求、物料替代、其他 |
| 生效日期 | |
| 状态 | 草稿、审批中、待生效、已生效、已取消 |
| 发起人 | |
| 操作 | 「查看」 |

## 新增工程变更

点击「新增工程变更」，抽屉顶部提示：保存后把基准 BOM 复制为新版本（停用），在物料清单中修改新版本的子件和工序，再回到这里提交。

![新增工程变更](/images/manual/mes/ecn-form.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 变更标题 | 是 | 最多 128 个字符；从物料清单发起时默认为「产品名称 变更」 |
| 基准 BOM（变更前） | 是 | 搜索产品编码、名称，只列出启用的 BOM，默认版本带「（默认）」。保存后不能修改 |
| 新版本号 | 是 | 选择基准 BOM 后自动建议：末尾数字加 1（V1.0 → V1.1，V2 → V3），否则加「-1」后缀；可修改，不能与该产品已有版本重复。保存后不能修改 |
| 变更原因 | 是 | 默认「设计改进」 |
| 生效日期 | 是 | 默认今天。批准后到这一天自动切换默认 BOM |
| 生效时同步使用原版本的草稿工单 | 否 | 默认勾选。生效时把使用原版本的草稿工单改为新版本，并按新版本重新生成用料和工序 |
| 变更说明 | 否 | 变更内容、原因、对库存和在制品的处理意见，最多 1000 个字符 |

保存时系统校验：

- 基准 BOM 本身如果还在另一张工程变更中（尚未生效），提示「该版本还在工程变更中，不能作为变更的基准」；
- 同一个基准 BOM 已有草稿、审批中或待生效的变更时，提示「该 BOM 已有未完成的工程变更」。

保存成功后自动打开变更详情；同时在物料清单中生成新版本（停用、非默认，带「变更中」标签）。

## 修改变更后的 BOM

在变更详情中点击「修改变更后的 BOM」，跳转到物料清单并打开新版本的编辑页面，修改子件（用量、损耗率、位号）和工艺路线后保存，再回到工程变更提交。新版本只在变更为草稿时可以修改。

## 变更详情

![工程变更详情](/images/manual/mes/ecn-detail.jpg)

- **基本信息**：产品、版本（原 → 新）、状态、原因、生效日期、同步草稿工单、发起人和时间、批准时间、生效时间及结果说明（如「新版本已启用，同步草稿工单 2 张」）、变更说明。
- **子件变化**：按物料对比新旧版本，标记「新增」「删除」「修改」，显示用量、损耗率、位号的前后变化（原值带删除线，新值加粗）；没有变化时显示「子件没有变化」。
- **工序变化**：按工序号对比，显示工序名称、工作中心、标准工时、计件单价、首件检验的前后变化。
- **附件（变更通知、图纸等）**：可上传变更通知、图纸等附件（需要编辑权限）。

详情右上角的按钮随状态变化：

| 状态 | 可用按钮 |
| --- | --- |
| 草稿 | 「修改变更后的 BOM」「编辑」「删除」（变更后的 BOM 版本一并删除）、「提交」 |
| 审批中 | 「审批记录」 |
| 待生效 | 「取消变更」（新版本删除）、「立即生效」（不等生效日期，立即切换默认 BOM） |
| 已生效 / 已取消 | 只能查看；接入审批的变更可查看「审批记录」 |

## 提交与审批

点击「提交」后变更后的 BOM 不能再修改。提交时如果新版本与原版本完全相同，提示「变更后的 BOM 与变更前相同，请先在物料清单中修改版本 xx」。

- **未发布审批流程**：提交即批准（提示「已批准」），状态变为待生效。
- **已在[流程中心](../workflow/business)发布「工程变更审批」流程**：提交后进入审批中（提示「已提交审批」）。系统内置的流程模板为：部门主管审批 → 质量工程师审核 → 抄送生产计划员，可在流程中心调整后发布。流程条件可使用变更原因、产品编码。审批通过后变为待生效；被拒绝或撤回后退回草稿，可修改后重新提交。

批准时如果生效日期是今天或之前，立即生效；生效日期在将来的，由「工程变更生效」[定时任务](../monitor/job)（默认每天 0:05 运行）在当天自动生效，也可以在详情中点击「立即生效」。

## 生效的结果

1. 新版本启用；如果原版本是默认 BOM，新版本接替为默认；
2. 原版本停用；
3. 勾选了同步草稿工单时，使用原版本的**草稿**工单改用新版本，并按新版本重新生成用料和工序。已下达、生产中的工单不受影响，继续按原用料生产；
4. 变更状态变为已生效，记录生效时间和结果说明。

## 单据状态

草稿 → （提交）审批中 → 待生效 → 已生效

- 草稿：可编辑、修改新版本、删除、提交；
- 审批中：等待审批，拒绝或撤回后回到草稿；
- 待生效：等待生效日期，可立即生效或取消；
- 已生效：新版本已启用，不能再操作；
- 已取消：草稿或待生效时取消，新版本 BOM（没有被工单使用时）删除。

## 与其他模块的联动

- **物料清单**：新建变更时复制新版本，生效时切换启用和默认版本；有工程变更记录的 BOM 不能删除。
- **生产工单**：生效时可同步草稿工单的 BOM、用料和工序。
- **MRP**：生效后 MRP 按新的默认 BOM 展开。
- **[流程中心](../workflow/business)**：发布「工程变更审批」流程后提交需要审批。

## 注意事项

::: warning 注意
- 每个 BOM 同一时间只能有一张未完成的工程变更。
- 工程变更创建的新版本在生效前不能在物料清单中启用、设为默认。
- 已下达的工单不会随变更切换 BOM，如需按新结构生产，可关闭旧工单后重新建立工单。
:::
