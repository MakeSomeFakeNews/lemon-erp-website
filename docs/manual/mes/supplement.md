# 补料申请

工单领料有上限（需求 × (1 + 允许超领比例) + 已补料）。生产中因报废、损耗超标、来料不良等原因需要超出上限领料时，由车间提交补料申请，经审批（可选）后由仓库发料。补料单独记录原因和数量，便于追溯损耗。

## 页面入口

生产制造 → 车间执行 → 补料申请

也可以在 [生产工单](./wo) 详情底部点击「补料申请」，此时工单自动带出。

![补料申请列表](/images/manual/mes/supplement-list.jpg)

## 列表说明

**查询条件**：单号（申请单号或工单号）、状态、原因。

| 列 | 说明 |
| --- | --- |
| 申请单号 | 前缀 BS，点击打开详情 |
| 工单 / 产品 | 工单号，下方为产品 |
| 原因 | 生产报废、损耗超标、来料不良、其他 |
| 数量 | 各物料申请数量合计 |
| 状态 | 审批中、待发料、已发料、已拒绝、已撤销；走审批流程的申请旁有流程图标 |
| 申请人 | 申请人和申请时间 |
| 补料单 | 发料后生成的补料单号（前缀 BL） |
| 说明 | |
| 操作 | 「查看」；待发料的申请有「发料」（需要发料权限）；申请人本人的审批中、待发料申请有「撤销」 |

工具栏有「补料申请」按钮和导出、刷新等工具按钮。

列表按申请人部门和申请人做数据权限控制；有发料权限的仓库人员发料、查看明细时不受此限制。

## 提交补料申请

点击「补料申请」，打开申请页面。

![补料申请](/images/manual/mes/supplement-form.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 工单 | 是 | 搜索已下达或生产中的工单号；从工单详情进入时自动带出且不可修改 |
| 补料原因 | 是 | 生产报废、损耗超标、来料不良、其他 |
| 说明 | 否 | 如「焊接不良报废 3 件」，最多 255 个字 |
| 明细：物料 | 是 | 只能选择该工单的用料 |
| 明细：领料情况 | — | 自动显示该物料的需求、已领和已补料 |
| 明细：补料数量 | 是 | 序列号物料必须为整数 |

点击「添加物料」增加行，同一物料不能重复。点击「提交申请」。

提交后：

- 如果[流程中心](../workflow/business)已发布流程标识为「mes_supplement」（补料申请审批）的流程，申请进入「审批中」，由审批人在流程中心处理。设计流程条件时可以使用补料原因、补料总数量、工单号这些变量。
- 没有发布该流程时，提交即通过，直接变为「待发料」，详情中显示「未配置审批流程，提交即通过」。

## 审批结果

| 审批结果 | 申请状态 |
| --- | --- |
| 通过 | 待发料 |
| 拒绝 | 已拒绝 |
| 撤回、终止 | 已撤销 |

## 发料

仓库人员对「待发料」的申请发料：

1. 在列表操作列或详情底部点击「发料」，打开补料发料页面，明细列出每个物料的「未发数量」。
2. 选择**仓库**、**业务日期**，每行选择**库位 / 批次**、填写**数量**（默认未发数量）和序列号；可以拆分到多个库位、批次。
3. 点击「确认补料发料」，提示「发料成功，补料单 BL...」。

发料规则：

- 各物料发料数量不超过未发数量，物料必须在申请中；
- 补料发料**不受领料上限限制**，同时计入工单用料的「已领」和「已补料」（已补料会相应提高之后的领料上限）；
- 可以分次发料，全部发完后申请变为「已发料」；
- 每次发料生成一张「补料」工单单据（BL）和「生产领料」出库单，在工单的「领料 / 完工记录」中可以看到。

## 补料详情

![补料申请详情](/images/manual/mes/supplement-detail.jpg)

显示工单、产品、原因、申请人和时间、审批方式（审批流程或提交即通过）及审批时间、补料单号、说明，以及物料、规格、申请数量、已发数量。

## 单据状态

| 状态 | 说明 | 可用操作 |
| --- | --- | --- |
| 审批中 | 已提交审批流程 | 申请人撤销 |
| 待发料 | 审批通过或无需审批 | 仓库发料；申请人撤销 |
| 已发料 | 全部物料发完 | 查看 |
| 已拒绝 | 审批被拒绝 | 查看 |
| 已撤销 | 申请人撤销、流程撤回 / 终止，或工单关闭 | 查看 |

只能撤销自己提交的申请，且只能撤销审批中或待发料的申请。

## 与其他模块的联动

- **生产工单**：发料计入工单用料的已领和已补料；工单关闭时，审批中、待发料的补料申请自动撤销（同时撤销审批流程）。
- **齐套分析**：待发料的数量计入工单用料的待领。
- **仓库**：发料生成生产领料[出库单](../wms/out)，扣减库存。
- **[成本核算](../fin/cost#工单成本)**：补料按领料处理，计入工单成本。
