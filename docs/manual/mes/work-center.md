# 工作中心

工作中心是执行工序的生产单元，例如一条 SMT 贴片线、一个装配班组、一组测试设备。工作中心定义了费率（用于[成本核算](../fin/cost)）和产能（用于产能排程和设备 OEE），工艺路线的每道工序都要指定工作中心。

## 页面入口

生产制造 → 工艺与设备 → 工作中心

![工作中心列表](/images/manual/mes/work-center-list.jpg)

## 列表

**查询条件**：工作中心（编码或名称）、状态（启用 / 停用）。

| 列 | 说明 |
| --- | --- |
| 工作中心 | 名称，下方显示编码 |
| 人工费率 | 元 / 工时 |
| 制造费用率 | 元 / 工时 |
| 日产能 | 每资源每日工时 × 资源数，下方显示「8 工时 × 1 个资源」这样的明细 |
| 工作日 | 如「周一、周二、周三、周四、周五」 |
| 状态 | 启用 / 停用开关，有编辑权限时可直接切换 |
| 备注 | |
| 操作 | 「编辑」「删除」 |

工具栏支持导出（按当前查询条件导出，日产能和工作日按显示内容导出）、刷新、列设置等。

## 新增 / 编辑工作中心

点击「新增工作中心」打开抽屉，顶部提示「成本核算按报工工时 × 费率计算工单的直接人工和制造费用」。

![编辑工作中心](/images/manual/mes/work-center-form.jpg)

| 字段 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 编码 | 是 | | 只能包含字母、数字、下划线和短横线，最多 32 个字符，不能重复，如 WC01 |
| 名称 | 是 | | 最多 64 个字符，如「SMT 贴片线」 |
| 人工费率 | 是 | 0 | 每工时的直接人工成本（元），两位小数。已建立人力资源[薪资档案](../hr/salary)时，下方显示「参考：生产岗位平均人工成本 ¥xx / 小时」，点击「使用」填入该值 |
| 制造费用率 | 是 | 0 | 每工时分摊的制造费用（元） |
| 每资源每日工时 | 是 | 8 | 0 ~ 24 小时 |
| 资源数 | 是 | 1 | 设备台数或班组人数，正整数 |
| 工作日 | 是 | 周一至周五 | 至少选择一天；下方实时显示日产能 |
| 备注 | 否 | | 最多 255 个字符 |

**日产能 = 每资源每日工时 × 资源数**。工作日以外的日期产能为 0；节假日放假、周末加班等特殊日期在 [产能排程](./capacity) 的「工厂日历」中按日期单独设置，工作中心的日历设置优先于全厂设置。

## 与其他模块的联动

| 模块 | 用途 |
| --- | --- |
| [物料清单](./bom) | 工艺路线的每道工序选择工作中心 |
| [产能排程](./capacity) | 按工作中心的日产能和工作日排程、做负荷分析 |
| [设备台账](./equipment) | 设备归属到工作中心；[设备 OEE](./oee) 按设备所属工作中心的日历计算计划时间（每台设备按一个资源） |
| [成本核算](../fin/cost#工单成本) | 工单的直接人工 = 报工工时 × 人工费率，制造费用 = 报工工时 × 制造费用率 |

## 注意事项

::: warning 注意
- 已被工艺路线或设备使用的工作中心不能删除，提示「已被工艺路线或设备使用，不能删除，可以停用」。
- 成本核算时按当时的费率计算，修改费率后需要重新核算对应期间才会反映到工单成本。
:::
