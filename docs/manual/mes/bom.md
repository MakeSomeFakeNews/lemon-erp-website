# 物料清单

物料清单（BOM）描述一个产品由哪些子件组成、每个产品各用多少，以及按什么工艺路线加工。MRP 运算、生产工单的用料和工序、[成本核算](../fin/cost)、齐套分析都以 BOM 为基础，通常由工艺工程师或生产计划员维护。

## 页面入口

生产制造 → 工艺与设备 → 物料清单

![物料清单列表](/images/manual/mes/bom-list.jpg)

## 基本概念

| 概念 | 说明 |
| --- | --- |
| 版本 | 同一个产品可以有多个 BOM 版本（如 V1.0、V1.1），版本号在同一产品内不能重复 |
| 默认 BOM | 每个产品只有一个默认版本，MRP 运算和新建生产工单都使用默认且启用的 BOM。产品的第一个 BOM 自动成为默认；把某个版本设为默认时，同一产品其他版本自动取消默认 |
| 单位用量 | 生产 1 个产品需要的子件数量，最多 6 位小数，必须大于 0 |
| 损耗率 | 生产过程中的损耗百分比（0 ~ 100）。工单需求数量 = 工单数量 × 单位用量 ×（1 + 损耗率） |
| 位号 | 电子类产品中子件在电路板上的位置，如 R1,R2，连续的写成区间 C1-C8 |
| 工艺路线 | 产品的加工工序，每道工序指定工作中心、标准工时、计件单价和是否需要首件检验 |
| 生产提前期 | 生产这个产品需要的天数，MRP 用它倒推开工日期（物料计划属性中设置了提前期时，以物料的为准） |

## 列表

**查询条件**：产品（物料编码或名称）、状态（启用 / 停用）。

**列表列**：

| 列 | 说明 |
| --- | --- |
| 产品 | 产品编码和名称，下方显示规格，点击打开 BOM 详情 |
| 版本 | 版本号；默认版本带「默认」标签；由工程变更创建、尚未生效的版本带「变更中」标签（鼠标悬停显示对应的变更单号） |
| 提前期 | 生产提前期（天） |
| 结构 | 子件数量和工序数量，如「5 个子件 · 2 道工序」 |
| 状态 | 启用 / 停用开关，有编辑权限时可直接切换；「变更中」的版本不能切换 |
| 备注、更新时间 | |

**行操作**：

- 「查看」：打开 BOM 详情。
- 「编辑」：修改 BOM。「变更中」的版本只有在对应工程变更还是草稿时才显示。
- 「设为默认」：非默认、非「变更中」的版本显示。
- 「发起变更」：跳转到 [工程变更](./ecn)，自动以该版本为基准 BOM 打开新增表单（需要工程变更新增权限）。
- 删除（垃圾桶图标）：确认后删除。

工具栏右侧有导出、显示 / 隐藏查询区、刷新、表格密度、列设置按钮，导出按当前查询条件导出列表。

## 新增 / 编辑 BOM

点击「新增 BOM」打开表单，表单占满内容区，下方分为基本信息、子件、工艺路线三部分。

![编辑 BOM](/images/manual/mes/bom-form.jpg)

### 基本信息

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 产品 | 是 | 选择启用的物料。工程变更创建的版本不能修改产品 |
| 版本号 | 是 | 最多 16 个字符，默认 V1.0，同一产品内不能重复 |
| 生产提前期 | 否 | 0 ~ 365 天，默认 0 |
| 备注 | 否 | 最多 255 个字符 |
| 设为默认 BOM | 否 | 新增时默认勾选；工程变更创建的版本不显示此项 |

### 子件

标题「子件（单位用量：生产 1 个产品的用量）」，点击「添加子件」增加一行，行末删除图标删除该行。至少要有 1 行子件，最多 500 行。

| 列 | 必填 | 说明 |
| --- | --- | --- |
| 子件 | 是 | 选择启用的物料，选中后自动带出规格和单位 |
| 规格 | | 只读 |
| 单位用量 | 是 | 大于 0，最多 6 位小数，右侧显示单位 |
| 损耗率 | 否 | 0 ~ 100%，默认 0 |
| 位号 | 否 | 如 R1,R2 或 C1-C8，最多 1000 个字符，下方提示展开后共多少个 |
| 备注 | 否 | 最多 255 个字符 |

**位号规则**：

- 每个位号为「字母 + 数字」，多个位号用逗号、分号、顿号或空格分隔，系统自动转为大写；
- 连续的位号写成区间，如 C1-C8（也可简写为 C1-8，波浪线 C1~C8 同样识别），区间前后的字母必须一致、结束编号不能小于起始编号，一个区间不超过 5000 个；
- 同一个 BOM 内所有子件的位号展开后不能重复，重复时提示「位号 xx 与其他子件重复」；
- 位号数量与整数用量不一致时（例如用量 4、位号 5 个）只以橙色文字提示「共 5 个，与用量 4 不一致」，不会阻止保存。按盘、按 kg 计量的物料用量与位号数无关，可忽略该提示。

### 工艺路线

标题「工艺路线（工序按工序号执行，标准工时为每个产品的工时）」，点击「添加工序」增加一行，工序号自动取当前最大工序号 + 10。工艺路线可以为空，最多 50 道工序。

| 列 | 必填 | 说明 |
| --- | --- | --- |
| 工序号 | 是 | 大于 0 的整数，同一 BOM 内不能重复，工单按工序号从小到大执行 |
| 工序名称 | 是 | 最多 64 个字符 |
| 工作中心 | 是 | 选择 [工作中心](./work-center) |
| 标准工时 | 否 | 每个产品的工时（小时），最多 4 位小数，用于产能排程、OEE 性能率 |
| 计件单价 | 否 | 每个合格品的计件工资（元），不填为不计件 |
| 首件检验 | 否 | 勾选「需首件检验」后，工单该工序在首件检验合格前只能报工 1 件，见 [质量检验](../qms/inspection) |

### 保存校验

保存时系统会校验：

- 子件不能是产品本身；同一子件不能重复出现（提示「子件重复：编码 名称」）；
- 工序号不能重复，工作中心必须存在；
- **循环引用**：从各子件出发沿已有 BOM 向下查找，如果某个子件的下层（无论多少层）用到了产品本身，提示「BOM 存在循环引用：子件的下层用到了产品「…」」，不能保存；
- 同一产品版本号不能重复。

::: tip 提示
修改 BOM 时子件和工序整体替换。已经下达的生产工单使用下达时的用料和工序，不受 BOM 修改影响；草稿工单保存时会按 BOM 重新生成用料。
:::

## BOM 详情

点击产品名称或「查看」打开详情。

![BOM 详情](/images/manual/mes/bom-detail.jpg)

- **物料清单**：逐层展开的 BOM 树。子件本身有 BOM（自制件）时带「自制」标签，点击行首的展开按钮可查看它的下层子件。列包括物料、规格、单位用量、损耗率、**累计用量（每个产品）**、位号（下方显示个数）、备注。累计用量 = 上层累计用量 × 单位用量 ×（1 + 损耗率），即生产 1 个顶层产品需要该物料的数量。
- **工艺路线**：工序号、工序名称、工作中心、标准工时、计件单价、首件检验标签。
- **技术文档**：有技术文档查看权限时，列出产品和各子件已发布的 [技术文档](./doc)（物料、文档名称与编号、文件数、类型、版本、发布时间），点击文档名称跳转到技术文档详情。

## 状态与默认版本

| 操作 | 说明 |
| --- | --- |
| 启用 / 停用 | 停用的 BOM 不参与 MRP，也不能用于新建工单；被工单使用过的 BOM 不能删除，可以停用 |
| 设为默认 | 同一产品其他版本自动取消默认 |
| 删除 | 已被生产工单使用、或有工程变更记录的 BOM 不能删除，提示改为停用 |

## 变更中的版本

通过 [工程变更](./ecn) 创建的新版本在变更生效之前：

- 列表带「变更中」标签，保持停用、非默认；
- 不能启用、停用、设为默认，也不显示「发起变更」；
- 只有在工程变更为草稿时可以编辑（编辑页顶部提示「该版本由工程变更 xx 创建：修改子件和工序后在工程变更中提交，生效后自动启用并接替默认」）；变更提交后不能再修改；
- 变更生效后自动启用，若原版本是默认则接替默认，原版本停用。

## 与其他模块的联动

- **MRP 运算**：按默认 BOM 多级展开计算需求，见 [MRP 运算](./mrp)。
- **生产工单**：新建工单时带出默认 BOM，保存时按 BOM 生成用料（虚拟件展开为子件、同一物料合并）和工序，下达时把工序的计件单价、首件检验带入工单，见 [生产工单](./wo)。
- **[成本核算](../fin/cost#工单成本)**：工艺路线的工作中心费率 × 报工工时计入工单的直接人工和制造费用。
- **委外加工**：委外[采购订单](../scm/purchase)按委外件的默认 BOM 生成需要提供给加工商的委外用料。
- **[物料管理](../wms/material#物料详情)**：物料详情中可以查看该物料被哪些 BOM 使用。

## 注意事项

::: warning 注意
- BOM 中的产品和子件必须是启用状态的物料。
- 物料计划属性为「采购」的物料即使有 BOM，MRP 也不会展开；属性为「虚拟件」的中间组件，MRP 和工单会把需求直接传给它的子件。
- 修改了正在用于生产的产品结构，建议通过工程变更，以便审批、留痕并同步草稿工单。
:::
