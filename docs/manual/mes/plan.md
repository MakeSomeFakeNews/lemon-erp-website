# 生产计划

生产计划（主生产计划）记录「什么产品、要多少、什么时候要」，是 MRP 运算和生产工单的起点。生产计划员可以手工新增计划，也可以由[销售订单](../scm/sales)一键生成；确认后的计划参与 [MRP 运算](./mrp)，或直接「转工单」。

## 页面入口

生产制造 → 生产计划 → 生产计划

![生产计划列表](/images/manual/mes/plan-list.jpg)

## 列表说明

**查询条件**

| 条件 | 说明 |
| --- | --- |
| 关键字 | 按计划号、产品编码或名称模糊查询 |
| 状态 | 草稿、已确认、已关闭 |

**列表列**

| 列 | 说明 |
| --- | --- |
| 计划号 | 系统自动生成，前缀 JH |
| 产品 | 产品编码、名称，下方灰字为规格 |
| 数量 | 计划数量及单位 |
| 工单进度 | 已转工单的数量和这些工单的完工数量；还没有工单时显示「-」 |
| 需求日期 | 产品需要完成的日期 |
| 来源 | 「手工」或「销售订单 XS...」 |
| 状态 | 草稿 / 已确认 / 已关闭 |
| 制单人、备注 | |

列表上方右侧的工具按钮可以导出、显示 / 隐藏查询区、刷新、调整表格密度和显示的列。

**工具栏按钮**

| 按钮 | 作用 |
| --- | --- |
| 「新增计划」 | 手工新增一条草稿计划 |
| 「由销售订单生成」 | 选择一张销售订单，按订单中的自制、委外件生成草稿计划 |
| 「确认（n）」 | 批量确认勾选的草稿计划，括号内为勾选中草稿计划的数量 |
| 「MRP 运算（n）」 | 对勾选的已确认计划发起 MRP 运算，括号内为勾选中已确认计划的数量（没有勾选时不显示数字） |

已关闭的计划不能勾选。

## 新增 / 编辑计划

点击「新增计划」，或在草稿计划的操作列点击「编辑」，弹出计划表单。

![新增计划](/images/manual/mes/plan-form.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 产品（需有默认 BOM） | 是 | 只能选择有启用的默认物料清单的产品，否则保存时提示「产品没有默认 BOM，不能排生产计划」。物料清单在 [物料清单](./bom) 中维护 |
| 数量 | 是 | 计划生产数量 |
| 需求日期 | 是 | 默认为今天 |
| 备注 | 否 | 最多 255 个字 |

## 由销售订单生成

1. 点击「由销售订单生成」。
2. 在下拉框中搜索订单号，只列出已审核或部分出库的销售订单，显示订单号、客户和交货日期。
3. 点击「确定」，系统提示生成了几个草稿计划。

生成规则：

- 只处理订单中物料属性为「自制」或「委外」的物料（物料属性未设置时，有启用的默认 BOM 视为自制）。
- 每个物料生成的数量 = 订单未出库数量 - 该订单已生成计划的数量，因此重复生成不会重复计划。
- 需求日期取订单明细的交货日期；明细没有时取订单交货日期，都没有时取今天。
- 计划的来源显示为「销售订单 订单号」，备注自动填写订单号。
- 如果订单中的自制、委外件都已生成过计划，或订单中没有自制件，会提示「订单中没有需要计划的物料」。

## 操作说明

| 状态 | 可用操作 |
| --- | --- |
| 草稿 | 「编辑」「确认」「删除」；可以批量确认 |
| 已确认 | 「转工单」（还有未转工单的数量时显示）、「关闭」；可以勾选后发起 MRP 运算 |
| 已关闭 | 无，只能查看 |

### 确认

单条点击「确认」，或勾选多条草稿计划后点击「确认（n）」。确认后计划不能再修改、删除。

### 转工单

已确认的计划可以不经 MRP，直接生成生产工单：

1. 在操作列点击「转工单」。
2. 在弹窗中填写：
   - **工单数量**：默认为「计划数量 - 已转工单数量」，下方提示计划数量和已转工单数量；不能超过未转工单的数量。
   - **计划开工**：默认今天。
   - **计划完工**：默认计划的需求日期。
   - **完工入库仓库**：选填。
3. 点击「确定」，系统生成一张草稿工单（来源标记为「计划」，备注「计划 计划号」），提示「已生成草稿工单，请到「生产工单」中下达」。

一个计划可以分多次转工单，直到数量全部转完。工单使用产品的默认 BOM。

### 关闭

点击「关闭」并确认（提示「关闭后不再参与 MRP 运算」）。关闭后的计划不能再转工单，也不能勾选参与 MRP。

### 发起 MRP 运算

1. 勾选一个或多个已确认的计划（也可以不勾选）。
2. 点击「MRP 运算」，弹出运算选项：

![MRP 运算选项](/images/manual/mes/plan-mrp.jpg)

| 选项 | 说明 |
| --- | --- |
| 生产计划 | 显示已勾选几个已确认的计划；没有勾选时提示「没有勾选计划」 |
| 计入销售订单的未计划需求 | 把已审核、未完成的销售订单中还没有生成生产计划的未出库数量也作为需求。没有勾选计划时默认勾选 |
| 计入销售预测 | 从本月起计入几个月（0 ~ 12）的销售预测，0 表示不计入；预测会扣减同月已有的销售订单，预测在 [MRP 运算](./mrp) 页面维护 |

3. 点击「确定」。三种需求来源至少要选一种，否则提示「请勾选已确认的计划，或计入销售订单、销售预测」。
4. 运算完成后自动跳转到「MRP 运算」页面并显示本次结果。

## 单据状态

草稿 → 已确认 → 已关闭

| 状态 | 说明 |
| --- | --- |
| 草稿 | 新建或由销售订单生成，可以修改、删除 |
| 已确认 | 参与 MRP 运算，可以转工单 |
| 已关闭 | 手工关闭，或自动关闭，不再参与 MRP |

**自动关闭**：计划下全部工单的完工数量合计达到计划数量时（完工入库时判断），计划自动关闭。

## 与其他模块的联动

- **[销售订单](../scm/sales)**：由销售订单生成的计划关联该订单。销售订单已生成生产计划时不能反审核，需要先删除或关闭计划；销售订单关闭时，它生成的草稿、已确认计划一并关闭。
- **生产工单**：转工单、MRP 下达（只有一个计划参与运算时）生成的工单关联计划，计划的「工单进度」取这些工单的数量和完工数量。
- **MRP 运算**：只有已确认的计划能参与运算。

## 注意事项

::: tip 提示
没有默认 BOM 的产品不能排计划。如果物料是外购件，应直接走采购；如果是自制件，请先在「物料清单」中建立 BOM 并设为默认。
:::

::: warning 注意
计划确认后不能修改。数量或日期有误时，请关闭该计划后重新新增。
:::
