# 产能排程

产能排程用来回答两个问题：各工作中心在未来一段时间里忙不忙（负荷分析），以及工单的各道工序应该排在哪几天做（排程）。另外通过「工厂日历」设置放假、加班等特殊日期的可用工时。

## 页面入口

生产制造 → 生产计划 → 产能排程

页面有两个页签：「负荷分析」和「工厂日历」。

## 基本概念

| 概念 | 说明 |
| --- | --- |
| 产能 | 工作中心某天可用的工时 = 当天每个资源的可用工时 × 资源数。每资源每日工时、资源数、工作日在 [工作中心](./work-center) 中设置；工作日以外的日期产能为 0 |
| 工厂日历 | 对具体日期单独设置每个资源的可用工时（0 为休息，可大于平时工时表示加班）。工作中心自己的设置优先，其次全厂设置，最后才是工作中心的工作日设置 |
| 负荷 | 各工序剩余工时 = (工单数量 - 该工序已报工的合格 + 报废数) × 标准工时，平均分摊到该工序计划日期区间内的工作日 |
| 利用率 | 负荷 / 产能 |

工序没有计划日期时，取工单的计划开工 / 完工日期；工单也没有时按今天计算。只统计草稿、已下达、生产中的工单和启用的工作中心。

## 负荷分析

![负荷分析](/images/manual/mes/capacity-load.jpg)

**工具栏**

| 控件 | 说明 |
| --- | --- |
| 日期范围 | 默认今天起 14 天，最长 92 天 |
| 工作中心 | 不选为全部工作中心 |
| 「刷新」 | 重新计算 |
| 「全部排程」 | 对全部未结束工单重新排程（见下文），需要产能排程的修改权限 |

**表格**

- 左侧为工作中心（名称、编码、涉及的工序数）和区间合计利用率（负荷 / 产能 工时）。
- 右侧每天一列，表头显示日期和星期（周末标橙色），格子里是「负荷 / 产能」，鼠标移上去显示具体工时。
- 颜色含义：空闲（有产能、无负荷）、不超过 85%（绿色）、85% ~ 100%（橙色）、超负荷（红色，超过 100%，或没有产能却有负荷）、休息（灰色「休」）。
- 点击行首的「+」展开该工作中心的工序明细：工单（点击跳转到工单详情）、工单状态、工序、计划日期（未排程的显示「未排程」）、剩余工时。

## 排程

排程是按工作中心的产能，从计划开工日起向后逐日安排各道工序，写入每道工序的计划开始、结束日期，并更新工单的计划开工、完工日期。

| 方式 | 入口 | 规则 |
| --- | --- | --- |
| 单个工单排程 | [生产工单](./wo) 详情底部的「排程」 | 从工单的计划开工日（早于今天按今天）起，按工序顺序逐日占用工作中心的产能；只考虑本工单，不考虑其他工单的占用（无限产能） |
| 全部排程 | 本页「全部排程」 | 全部未结束的工单按计划开工日、工单号依次排，共享工作中心的产能，先排的优先（有限产能） |

两种方式都会**覆盖**已有的工序计划日期，操作前会弹出确认。全部排程完成后提示排程了多少张工单。如果某个工作中心在很长一段时间内都没有可用产能（例如工作日、每日工时没设置），排程会提示「工作中心在 730 天内没有足够的产能，请检查工作日和每日工时」。

## 工厂日历

![工厂日历](/images/manual/mes/capacity-calendar.jpg)

1. 在左上角选择范围：「全厂」或某个工作中心。
2. 日历中显示每天的特殊设置：「x 小时」或「休息」，以及备注；选择工作中心时，继承自全厂的设置会标注「全厂」。
3. 点击某个日期，弹出设置框：
   - **每资源可用工时**（必填）：0 ~ 24 小时，0 表示休息，加班时可以大于工作中心的每日工时；
   - **备注**：如「国庆节」「周六加班」。
4. 点击「保存」。同一范围同一天只有一条设置，再次保存会覆盖。
5. 已有设置的日期再次打开时，可以点击「删除设置」；右侧「本月设置」列表也可以删除。删除后该日恢复按工作日计算。

## 权限

查看本页需要产能排程的查看权限；「全部排程」、修改工厂日历需要产能排程的修改权限。工单详情中的「排程」按钮有产能排程修改权限或工单修改权限即可使用。

## 注意事项

::: tip 提示
排程以天为单位，不考虑工序之间的转运时间和换线准备时间。建议先在工作中心设置好每日工时、资源数和工作日，并在工厂日历中登记法定节假日，再进行排程。
:::

::: warning 注意
「全部排程」会重排所有未结束工单的工序日期，手工调整过的计划日期会被覆盖。
:::
