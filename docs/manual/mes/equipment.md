# 设备台账

设备台账登记工厂的生产设备，记录型号、所属工作中心、安装位置、状态和定期保养周期，系统按周期计算下次保养日期并提醒到期、逾期的设备。设备是 [设备维护](./maintenance)、[设备 OEE](./oee)、报工选择生产设备、模具安装设备的基础资料。

## 页面入口

生产制造 → 工艺与设备 → 设备台账

![设备台账列表](/images/manual/mes/equipment-list.jpg)

## 列表

**查询条件**：设备（编码或名称）、状态、工作中心；点击「展开」后还有「保养提醒」：已到期、7 天内到期、30 天内到期，用于筛选需要安排保养的设备。

| 列 | 说明 |
| --- | --- |
| 设备 | 设备名称，下方显示编码和规格型号 |
| 工作中心 | 所属工作中心 |
| 位置 | 安装位置 |
| 状态 | 运行、闲置、维修中、报废 |
| 定期保养 | 「下次 日期」，下方显示「每 N 天 · 上次 日期」。下次保养日期已过时显示红色「逾期 N 天」，7 天内到期显示橙色「N 天后到期 / 今天到期」（报废设备不提示）；没有设置保养周期的显示「不做定期保养」 |
| 购置日期、备注 | |
| 操作 | 「维护」「编辑」、删除图标 |

点击「维护」跳转到 [设备维护](./maintenance) 页面，列表按该设备筛选并自动打开「报修 / 保养」弹窗。

## 新增 / 编辑设备

点击「新增设备」打开抽屉。

![编辑设备](/images/manual/mes/equipment-form.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 设备编码 | 是 | 只能包含字母、数字、下划线和短横线，最多 32 个字符，不能重复，如 EQ-SMT-01 |
| 设备名称 | 是 | 最多 64 个字符 |
| 规格型号 | 否 | |
| 工作中心 | 否 | 设备 OEE 按所属工作中心的工作日历计算计划时间，未关联的按全厂日历 |
| 安装位置 | 否 | |
| 购置日期 | 否 | |
| 状态 | 否 | 默认「运行」，可选运行、闲置、维修中、报废 |
| 保养周期 | 否 | 1 ~ 3650 天；不填不做定期保养 |
| 上次保养日期 | 否 | 下次保养日期 = 上次保养（没有时取购置日期，再没有取今天）日期 + 周期 |
| 备注 | 否 | |

保存时系统按上述规则重新计算下次保养日期；删除保养周期则清空下次保养日期。

## 设备状态

| 状态 | 说明 |
| --- | --- |
| 运行 | 正常使用 |
| 闲置 | 暂不使用 |
| 维修中 | 故障维修单开始处理时自动变为维修中，维修完成后恢复为维修前的状态 |
| 报废 | 不能再新建维护单，不参与 OEE 统计，不能被报工、模具领用选择，也不再提示保养 |

状态可以在编辑时手工修改。

## 保养提醒

- 列表上按下次保养日期显示到期、逾期标签，并可通过「保养提醒」条件筛选；
- 「设备保养提醒」定时任务（默认每天 8:30 运行，参数 days=3）给有维护处理权限的人员发送[站内消息](../guide/profile#我的消息)：「设备「编码 名称」需要保养」，提醒下次保养日期在 3 天内（含已逾期）的未报废设备，同一设备同一保养日期只提醒一次。可在「系统监控 → [定时任务](../monitor/job)」中调整执行时间和天数。
- 定期保养维护单完成后，自动把上次保养日期更新为完成当天，并重新计算下次保养日期。

## 与其他模块的联动

- [设备维护](./maintenance)：故障维修、定期保养会改变设备状态和保养日期。
- [设备 OEE](./oee)：按设备统计可用率、性能率、良品率。
- [生产工单](./wo)：报工时可选择生产设备，用于 OEE 的产量和性能率统计。
- [模具工装](./mold)：模具领用时可指定安装设备。

## 注意事项

::: warning 注意
已有维护记录的设备不能删除，提示「已有维护记录，不能删除，可以改为报废」。
:::
