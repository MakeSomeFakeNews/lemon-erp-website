# 齐套分析

齐套分析检查未结束的工单「料够不够」：把仓库现有库存按优先级分配给各工单，算出每张工单缺哪些料、还能生产多少；同时按物料汇总全部工单的缺料，一键生成[采购订单](../scm/purchase)或工单补齐缺口。主料缺料时还可以切换为替代料。

## 页面入口

生产制造 → 车间执行 → 齐套分析

页面有两个页签：「工单齐套」和「生产用料汇总」。

## 计算规则

1. 参与分析的是**未结束的工单**：草稿、已下达、生产中。
2. 每个工单用料的**待领 = 需求 + 已补料 - 已领**；待发料的补料申请数量也计入待领。
3. 全部仓库的库存按优先级依次分配给各工单的待领数量：**已下达 / 生产中的工单在前，草稿在后；同一类再按计划开工日期、工单号**。分不到的部分就是**缺料**。
4. 工单的**齐套状态**：

| 齐套状态 | 含义 |
| --- | --- |
| 已领齐 | 全部用料都已领齐 |
| 齐套 | 没有缺料，待领部分都能分到库存 |
| 部分缺料 | 有缺料，但按已领 + 分到的库存还能继续生产一部分 |
| 缺料 | 有缺料，且已领 + 分配的数量不足以再生产 |

5. **可生产数量** = 各用料「(已领 - 已补料 + 分配) / 单位用量」中的最小值，即按现有物料最多能做多少。

## 工单齐套

![工单齐套](/images/manual/mes/kit-orders.jpg)

**工具栏**：按工单号搜索；按齐套状态筛选（全部、缺料、部分缺料、齐套、已领齐，后面显示数量）；右侧提示分配优先级；刷新按钮。

**列表列**

| 列 | 说明 |
| --- | --- |
| 工单 | 工单号和工单状态 |
| 产品 | 产品编码、名称，下方显示完工 / 工单数量 |
| 计划开工 | |
| 齐套率 | 进度条，100% 为绿色；下方显示「缺料 x / y 项」 |
| 可生产数量 | 可生产数量 / 工单数量 |
| 齐套状态 | 齐套、部分缺料、缺料、已领齐 |

点击行首的「+」展开该工单的用料明细：

![工单用料明细](/images/manual/mes/kit-lines.jpg)

| 列 | 说明 |
| --- | --- |
| 物料 | 编码、名称、规格 |
| 需求、已领、待领 | 见计算规则 |
| 库存 | 该物料全部仓库的现有库存 |
| 分配 | 分配给本工单的库存数量 |
| 缺料 | 待领 - 分配，大于 0 时标红 |
| 在途 | 采购、委外件为未完成的采购订单数量，自制件为未完工的工单数量 |
| 单位 | |
| 操作 | 缺料且设置了替代料时显示「替代料（n）」（有替代料切换权限时可点击，否则只提示「有替代料」） |

列表只显示有数据权限的工单，但库存分配仍按全部工单计算，因此看到的分配结果与全厂一致。

### 替代料切换

主料缺料时，可以把工单中主料**未领**的部分换成替代料。替代料及比例在「仓库 → [物料管理](../wms/material#生产计划-需要生产计划属性修改权限)」的物料编辑抽屉「生产计划」分区中维护（比例表示替代 1 个主料需要的替代料数量，可设优先级）。

1. 展开缺料工单，在缺料物料行点击「替代料（n）」。
2. 弹窗显示工单、主料和「待领 / 缺料」数量。
3. 选择**替代料**（显示比例「1 : x」和替代料库存），系统默认填写**替代的主料数量**：缺料数量与替代料库存能覆盖的数量中的较小者。
4. 下方提示「需要替代料 n」，确认后点击「切换」。

切换后，主料需求减少所填数量，替代料需求增加「数量 × 比例」（工单中没有该替代料时新增一行用料）。替代数量不能超过主料的待领数量；主料是序列号物料时必须为整数；已结束的工单不能切换。

## 生产用料汇总

![生产用料汇总](/images/manual/mes/kit-materials.jpg)

按物料汇总全部未结束工单的用料。

**工具栏**：物料编码或名称搜索、「只看缺料」复选框、「缺料下单（n）」按钮、刷新按钮。

| 列 | 说明 |
| --- | --- |
| 物料 | 编码、名称，下方为规格和单位 |
| 属性 | 物料属性：自制、采购、委外、虚拟件 |
| 工单数 | 用到该物料的未结束工单数 |
| 需求、已领、待领、库存 | 各工单合计 |
| 缺料 | 合计缺料，下方显示最早的需求日期（工单计划开工） |
| 在途 | 采购、委外件为未完成的采购订单，自制件为未完工的工单 |
| 建议下单 | 建议数量 = 缺料 - 在途，按最小批量、批量倍数等批量规则取整；下方显示「生成工单」或默认供应商名称（没有时显示「未设置默认供应商」） |

点击「+」展开该物料在各工单的分配明细：工单（含状态）、产品、计划开工、待领、分配、缺料。

### 缺料下单

1. 勾选需要下单的物料（需要缺料下单权限才显示勾选框）。
2. 点击「缺料下单（n）」，弹窗列出物料、建议数量和生成去向（「工单」或供应商）。
3. 选择**收货 / 入库仓库**（必填）。
4. 点击「生成单据」，系统提示生成的草稿单据号。

生成规则：

- **采购、委外件**按默认供应商合并为草稿采购订单，来源为「生产缺料」，交货日期取最早需求日期；物料没有默认供应商时提示先设置默认供应商。
- **自制件**每个物料生成一张草稿工单（来源标记「缺料」）。
- 所选物料都没有缺料，或缺料已被在途的采购订单 / 工单覆盖时，提示「所选物料没有缺料，或缺料已有在途的采购订单 / 工单」。

生成后请到「供应链 → [采购订单](../scm/purchase#审核与审批)」中确认审核，到 [生产工单](./wo) 中下达。

## 注意事项

::: tip 提示
- 齐套分析和 MRP 一样**不区分仓库**，库存取全部仓库合计。
- 下达工单前先看齐套状态，优先下达「齐套」的工单，可以减少停工待料。
:::

::: warning 注意
草稿工单修改后会按 BOM 重新生成用料，之前切换的替代料会被还原，需要重新切换。
:::
