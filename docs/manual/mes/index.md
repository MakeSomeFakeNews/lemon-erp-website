# 生产制造

生产制造模块覆盖从「要生产什么」到「产品入库」的全过程：主生产计划、MRP 物料需求计算、产能排程，车间的工单下达、齐套检查、领料、报工、补料、完工入库，以及物料清单、工艺路线、工程变更、技术文档、工作中心、设备与模具等基础资料。领料、完工等业务自动生成仓库单据，报工数据进入成本核算、计件工资和设备 OEE。

顶部导航「生产制造」，侧边栏分为三组：生产计划、车间执行、工艺与设备。质量检验、不合格品处理等在顶部导航「质量」中，见 [质量管理](../qms/)。

## 典型业务流程

### 计划到入库全流程

| 步骤 | 操作 | 页面 | 结果 |
| --- | --- | --- | --- |
| 1 | 维护物料清单（子件、用量、损耗率、工艺路线）并设为默认；在物料管理中设置物料属性、提前期、批量规则、允许超领比例 | [物料清单](./bom)、仓库 → [物料管理](../wms/material) | 基础数据就绪 |
| 2 | 新增生产计划，或「由销售订单生成」 | [生产计划](./plan) | 草稿计划 |
| 3 | 确认计划 | [生产计划](./plan) | 已确认计划 |
| 4 | 勾选计划发起 MRP 运算（可计入销售订单、销售预测） | [生产计划](./plan) | 运算结果：各层物料的净需求和建议 |
| 5 | 检查结果，调整建议数量、供应商，下达所选 | [MRP 运算](./mrp) | 自制件生成草稿工单，采购 / 委外件按供应商合并生成草稿采购订单 |
| 6 | [采购订单](../scm/purchase)审核、[到货入库](../scm/purchase-in) | 供应链 → 采购 | 原材料入库 |
| 7 | 查看齐套情况，缺料时缺料下单或切换替代料 | [齐套分析](./kit) | 料齐的工单 |
| 8 | 排程（可选），下达工单 | [产能排程](./capacity)、[生产工单](./wo) | 已下达工单 |
| 9 | 领料 | [生产工单](./wo) | 生产领料出库单，工单变为生产中 |
| 10 | 首件工序先报工 1 件并做首件检验（如需要） | [生产工单](./wo)、[质量检验](../qms/inspection) | 首件合格后放开报工 |
| 11 | 按工序报工（合格、报废、工时、设备、模具、操作员） | [生产工单](./wo) | 工序进度、计件工资、OEE 数据 |
| 12 | 损耗超出领料上限时提交补料申请，审批后仓库发料 | [补料申请](./supplement) | 补料单、生产领料出库单 |
| 13 | 成品检验（如产品要求完工需成品检验） | [质量检验](../qms/inspection) | 成品检验合格数 |
| 14 | 完工入库；报废品可报废入库到不良品仓 | [生产工单](./wo) | 生产入库单，满数量后工单自动完工，计划自动关闭 |
| 15 | 多领的物料退料；不再生产的工单关闭 | [生产工单](./wo) | 生产退料入库单 |
| 16 | 月末成本核算 | 财务 → [成本核算](../fin/cost) | 工单成本、成本结转凭证 |

不需要 MRP 的简单场景，可以在第 3 步后直接对计划「转工单」，或直接「新增工单」。

### 单据状态一览

| 单据 | 状态流转 |
| --- | --- |
| 生产计划 | 草稿 → 已确认 → 已关闭（手工关闭，或工单完工数量达到计划数量自动关闭） |
| MRP 建议 | 待下达 → 已下达；再次运算后未下达的变为已作废；净需求为 0 的为无需处理 |
| 生产工单 | 草稿 → 已下达 → 生产中 → 已完工；已下达、生产中可关闭 |
| 补料申请 | 审批中 → 待发料 → 已发料；或已拒绝、已撤销 |

### 与其他模块的关系

| 模块 | 关系 |
| --- | --- |
| 供应链 | [销售订单](../scm/sales)生成生产计划、作为 MRP 需求；MRP 和缺料下单生成[采购订单](../scm/purchase)；采购订单作为在途 |
| 仓库 | [库存](../wms/stock)参与 MRP 和齐套分析；领料、退料、补料、完工入库、报废入库自动生成并确认仓库单据 |
| 质量 | [首件检验](../qms/inspection#首件检验限制报工)控制报工、[成品检验](../qms/inspection#完工需成品检验)控制完工入库；[不合格品](../qms/ncr)返工生成返工工单；过程检验、成品检验针对工单 |
| 财务 | [成本核算](../fin/cost)按领料、报工工时与工作中心费率计算工单成本，生成成本结转凭证；设备维修保养费用生成费用凭证 |
| 人力资源 | 报工计件工资计入[工资表](../hr/payroll) |
| 流程中心 | 补料申请、工程变更可以接入[审批流程](../workflow/business) |

## 单据编号

生产计划 JH、MRP 运算 MR、生产工单 SC、返工工单 FG、领料 LL、退料 TL、完工入库 WG、报废入库 BF、补料 BL、补料申请 BS、工程变更 ECN、技术文档 TD、维护单 WX。编号规则可在「系统管理 → [编码规则](../system/code-rule)」中查看和调整。

## 相关角色

系统内置以下与生产相关的角色，可在「系统管理 → [角色管理](../system/role)」中调整：

| 角色 | 数据范围 | 主要功能 |
| --- | --- | --- |
| 生产计划员 | 本部门及以下 | 生产计划、MRP、产能排程、工单（不含领料、报工、完工）、齐套分析、物料清单、工作中心、物料计划属性、请购单 |
| 车间主管 | 本部门 | 工单领料、报工、完工入库，补料申请、质量检验、不合格登记、设备与维护、OEE 停机登记、模具工装 |
| 质量工程师 | 全部 | 质量管理全部功能；物料、供应商、工单只读 |
| 仓库管理员 | 全部 | 出入库等仓库业务，生产领料和完工入库，补料申请发料 |
