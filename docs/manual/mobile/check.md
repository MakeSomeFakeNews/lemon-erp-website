# 盘点

对后台已经生成的盘点单（草稿），在手机 / PDA 上逐个库位扫码录入实盘数量。账面没有的物料扫描后自动作为盘盈行添加。保存后回到后台确认盘点。

## 页面入口

移动作业首页 → 盘点（需要盘点单修改权限）

## 准备工作

先在后台「仓库 → 库存作业 → [盘点单](../wms/check)」新增盘点单，选择仓库后点「按库存生成」并保存。手机上只能对已有的草稿盘点单录入数据，不能新建盘点单，也不能确认盘点。

## 第一步：选择盘点单

![选择盘点单](/images/manual/mobile/check-list.jpg)

页面提示「在后台按库存生成盘点单（草稿）后，在这里扫码录入实盘数量」，列出草稿状态的盘点单（单号、盘点日期、仓库、备注），点击进入。截图中暂无草稿盘点单，显示「没有待盘点的盘点单」。

## 第二步：扫码盘点

进入后上方显示单号、仓库、「已盘 X / 总行数」和「换盘点单」链接。每张卡片是一行盘点明细：库位、账面数量、物料、规格、批次，以及实盘数量输入框（与账面一致为完成色，不一致为提醒色）。

### 扫码规则

| 扫描内容 | 效果 |
| --- | --- |
| 库位标签 | 设为当前库位；勾选「只看当前库位」（默认勾选）时只显示该库位的明细 |
| 物料条码 / 编码 | 在当前库位找该物料的行，实盘数量 +1（包装条码按换算率增加）；序列号物料提示「请扫描序列号」。**当前库位没有该物料的明细时，自动添加一行盘盈**（带绿色「盘盈」标签，账面为 0） |
| 其他条码 | 作为当前序列号物料行的实盘序列号，同一序列号在整张盘点单中不能重复 |

- 普通物料也可以直接在「实盘」框中输入数量；
- 序列号物料的实盘数量 = 扫描的序列号个数，可点标签上的 × 删除；
- 批次物料的盘盈行需要填写批次号。

### 保存实盘

底部显示「差异 N 行」，点「**保存实盘**」：

- 盘盈的批次物料必须填写批次号；
- 只保存有实盘数量的盘盈行；
- 保存后提示「已保存实盘数量」并重新加载盘点单，可以分多次、多人分区域盘点。

## 后续操作

全部盘完后，在后台打开盘点单详情，按「有差异」「未录入」核对，然后「[确认盘点](../wms/check#确认时如何调整库存)」。确认时所有行都必须有实盘数量，系统按确认时的库存计算差异，盘盈入库、盘亏出库（发布了[盘点差异审批](../workflow/business#仓库)流程时先审批）。

::: warning 注意
多人同时对同一张盘点单保存时，后保存的会覆盖先保存的全部明细。多人盘点时建议按库位拆分成多张盘点单（「按库存生成」时可选择库位）。
:::
