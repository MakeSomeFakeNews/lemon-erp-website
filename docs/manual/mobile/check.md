# 盘点

在手机 / PDA 上逐个库位扫码（没有条码时搜索物料）录入实盘数量。可以对后台建好的盘点单（草稿）盘点，也可以在手机上选择仓库直接新建盘点；明细中没有的物料随扫随加。保存后回到后台确认盘点。

## 页面入口

移动作业首页 → 盘点（需要盘点单修改权限；在手机上新建盘点还需要盘点单新增权限）

## 准备工作

两种方式任选：

- **后台建单**：在后台「仓库 → 库存作业 → [盘点单](../wms/check)」新增盘点单，选择仓库后用「选择商品」按货位、分类、变动日期等条件挑选本次要盘点的商品并保存，再到手机上盘点；
- **手机上新建**：有盘点单新增权限时，在手机上选择仓库直接开始盘点，边扫边加，第一次保存时生成盘点单（草稿）。

手机上不能确认盘点，确认仍在后台进行。

## 第一步：选择盘点单

![选择盘点单](/images/manual/mobile/check-list.jpg)

页面提示「选择草稿盘点单，扫码或搜索物料录入实盘数量；不在明细中的物料会自动加入（有库存的带出账面数量）。也可选择仓库新建盘点，保存时生成盘点单」。

- **新建盘点**：有盘点单新增权限时显示。在「选择盘点仓库」中选择仓库，点「新建盘点」，进入一张没有明细的盘点（标题显示「新建盘点」，盘点日期为今天、不冻结仓库），扫码或搜索物料逐个加入；第一次「保存实盘」时生成盘点单（草稿）。保存前点「换盘点单」离开，已录入的内容不会保留；
- **选择已有盘点单**：下方列出草稿状态的盘点单（单号、盘点日期、仓库、备注），点击进入；没有草稿盘点单时显示「没有待盘点的盘点单」。

## 第二步：扫码盘点

进入后上方显示单号、仓库、「已盘 X / 总行数」和「换盘点单」链接。每张卡片是一行盘点明细：库位、账面数量、物料、规格、批次，以及实盘数量输入框（与账面一致为完成色，不一致为提醒色）。

### 扫码规则

| 扫描内容 | 效果 |
| --- | --- |
| 库位标签 | 设为当前库位；勾选「只看当前库位」（默认勾选）时只显示该库位的明细 |
| 物料条码 / 编码 | 找该物料的明细行，实盘数量 +1（包装条码按换算率增加）；序列号物料提示「请扫描序列号」。扫描了库位时找当前库位的行，**没有扫描库位时匹配该物料的任意一行**。明细中没有时自动加入，规则见下文 [随扫随加](#随扫随加) |
| 其他条码 | 作为当前序列号物料行的实盘序列号，同一序列号在整张盘点单中不能重复 |

- **没有条码**的物料：点扫码框下方的「没有条码？搜索物料」，按编码、名称搜索并选择，定位到（或加入）该物料的明细行，提示「物料名称：请录入实盘数量」，在「实盘」框中输入数量；序列号物料提示扫描序列号；
- 普通物料也可以直接在「实盘」框中输入数量；
- 序列号物料的实盘数量 = 扫描的序列号个数，可点标签上的 × 删除；
- 批次物料的盘盈行需要填写批次号。

### 随扫随加

扫描或搜索的物料在明细中没有对应的行（扫描了库位时指当前库位没有）时，自动加入明细，不需要回后台补：

- 该物料在盘点仓库**有库存**：按库存位置（库位、批次）各加一行，带出账面数量，带蓝色「**新加入**」标签；扫描了库位时只加该库位的库存位置；
- 在盘点仓库（或当前库位）**没有库存**：加一行账面为 0 的盘盈行，带绿色「**盘盈**」标签，库位为当前库位；批次管理的物料需要填写批次号。

加入后实盘数量为空，扫描继续累加或直接输入。

### 保存实盘

底部显示「差异 N 行」，点「**保存实盘**」：

- 盘盈的批次物料必须填写批次号（提示「物料名称：请填写盘盈的批次号」）；
- 手机上新加入的行（「新加入」「盘盈」）只保存填了实盘数量的；
- 新建的盘点第一次保存时生成盘点单（草稿），之后再保存为修改该盘点单；
- 保存后提示「已保存实盘数量」并重新加载盘点单，可以分多次、多人分区域盘点。

## 后续操作

全部盘完后，在后台打开盘点单详情，按「有差异」「未录入」核对，然后「[确认盘点](../wms/check#确认时如何调整库存)」。确认时所有行都必须有实盘数量，系统按确认时的库存计算差异，盘盈入库、盘亏出库（发布了[盘点差异审批](../workflow/business#仓库)流程时先审批）。

::: warning 注意
多人同时对同一张盘点单保存时，后保存的会覆盖先保存的全部明细。多人盘点时建议按库位、分类拆分成多张盘点单（后台「选择商品」时按货位、分类筛选，或每人在手机上各自新建盘点）。
:::
