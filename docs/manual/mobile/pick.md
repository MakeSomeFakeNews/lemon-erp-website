# 拣货

按销售发货通知的拣货建议，在手机 / PDA 上按库位顺序逐行拣货：扫描库位、扫描物料（或序列号）累计已拣数量，全部拣完后确认拣货。确认后回到后台装箱、出库。

## 页面入口

移动作业首页 → 拣货（需要发货通知拣货权限）

## 第一步：选择发货通知

![待拣货的发货通知](/images/manual/mobile/pick-list.jpg)

- 列出「待拣货」状态的发货通知（最近 50 张），显示通知号、所属波次号（已合并到波次时）、客户、仓库、发货日期；
- 扫描或输入发货通知号后回车查找，只找到一张时自动进入；
- 点击卡片进入拣货。

## 第二步：按库位拣货

![拣货](/images/manual/mobile/pick-detail.jpg)

页面上方显示通知号、客户、仓库和「换通知」链接。下方每张卡片是一条拣货建议，按库位编码排序，显示库位、物料、规格、批次和「已拣 / 应拣」数量（拣完为完成色，部分拣货为提醒色）。

如果某物料的拣货建议合计少于通知数量（库存不足），页面会提示「XX 拣货建议不足，请在后台调整后再拣货」，并禁止确认拣货。可在后台发货通知中「重新建议」或调整拣货。

### 扫码规则

| 扫描内容 | 效果 |
| --- | --- |
| 库位标签 | 设为当前库位，并选中该库位下第一条未拣完的行；该库位没有待拣物料时提示 |
| 物料条码 / 编码 | 在当前库位中找该物料未拣完的行并选中：普通物料已拣数量 +1（包装条码按换算率增加）；序列号物料提示「请扫描序列号」。不在当前库位时提示「请到库位 XX 拣货」；超过应拣数量时提示 |
| 其他条码 | 作为当前行的序列号：必须是该库位、批次在库的序列号，不能重复，个数不超过应拣数量 |

普通物料也可以直接在卡片的「已拣」输入框中修改数量。

### 确认拣货

底部显示「已拣 N / 总行数」。点「**确认拣货**」：

- 每一行的已拣数量都必须等于应拣数量，否则提示哪个库位哪个物料「已拣 X，应拣 Y」；
- 确认后按实际拣货的库位、批次、序列号保存，发货通知变为「已拣货」，提示「拣货完成」。

## 后续操作

在后台「供应链 → 销售 → [发货通知](../scm/delivery)」详情中：

1. 装箱（「装一箱」、打印装箱单和箱标签），见[装箱](../wms/label-putaway#装箱)；
2. 点「出库」，按拣货明细生成[销售出库单](../scm/sales-out)，扣减库存并核销销售订单的[库存预留](../scm/sales#库存预留)。

::: tip 提示
拣货建议按「先到期先出」生成；拣货路径按库位的区域、排序、编码，可在[库位管理](../wms/location)中调整排序。
:::
