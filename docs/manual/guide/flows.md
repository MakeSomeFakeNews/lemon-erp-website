# 核心业务流程总览

柠檬ERP 的各模块不是孤立的：前一个环节的单据会自动生成或回写后一个环节的数据。本页按八条典型业务主线，说明每一步在哪个菜单完成、由谁负责、系统自动联动了什么。具体的字段和操作见各章节。

::: tip 阅读说明
- 「菜单」一列写的是菜单路径，例如「供应链 → 采购 → 采购订单」表示顶部导航「供应链」、侧边栏分组「采购」下的「采购订单」。
- 标注「可审批」的步骤，在流程中心发布对应的[审批流程](../workflow/model)后改为提交审批，审批通过后才生效；没有发布流程时直接生效。
- 标注「可选」的步骤可以根据企业的管理需要省略。
:::

## 一、采购到付款

从提出采购需求，到收货入库、质量检验，最后与供应商结算付款。

| 步骤 | 菜单 | 负责人 | 系统自动联动 |
| --- | --- | --- | --- |
| 1. 提出采购需求（可选） | 供应链 → 采购 → [请购单](../scm/requisition) | 需求部门 | 提交后可审批；批准后按建议供应商（为空取物料的默认供应商）合并生成草稿采购订单 |
| 也可以：补货建议 | 供应链 → 采购 → [补货建议](../scm/reorder) | 采购员 | 按再订货点计算建议数量，一键生成请购单 |
| 也可以：MRP / 缺料下单 | 生产制造 → 生产计划 → [MRP 运算](../mes/mrp)；车间执行 → [齐套分析](../mes/kit) | 生产计划员 | 采购件按默认供应商合并生成草稿采购订单 |
| 2. 寻源（可选） | 供应链 → 采购寻源 → [询价比价](../scm/inquiry) / [招标采购](../scm/tender) / [采购合同](../scm/contract) | 采购员 | 询价定标可更新供货价格并生成采购订单；招标定标可生成采购合同或订单；订单引用合同时按合同价下单并控制数量、金额上限 |
| 3. 下采购订单 | 供应链 → 采购 → [采购订单](../scm/purchase) | 采购员 | 选择物料自动带出供货价格，没有供货价时带出该供应商最近一次成交价；单价高于[价格控制](../scm/price-list)中的最高采购价时提示或禁止保存；多规格物料可按规格矩阵录入；审核（可审批）后订单变为「已审核」，开通了门户的供应商收到通知 |
| 4. 供应商确认（可选） | 供应商门户 → [我的订单](../portal/supplier#我的订单) | 供应商 | 供应商接受（填写承诺交期）或拒绝，结果通知制单人 |
| 5. 送货通知（可选） | 供应商门户 → [送货通知](../portal/supplier#送货通知)；供应链 → 采购 → [送货通知](../scm/asn) | 供应商、仓库 | 仓库按实收数量收货，生成采购入库单 |
| 6. 采购入库 | 供应链 → 采购 → [采购入库](../scm/purchase-in)（或移动作业 → [扫码收货](../mobile/receive)） | 仓库管理员 | **保存即确认**：自动生成已确认的仓库入库单、增加库存（批次、序列号），回写订单入库进度（默认不能超过未入库数量，允许超收的比例见[业务参数](../system/biz-rule)）；生成应付单；需要来料检验的物料入库后冻结为「待检」 |
| 7. 来料检验 | 质量 → 检验管理 → [质量检验](../qms/inspection) | 质量工程师 | 合格或让步接收后放行冻结库存；不合格保持冻结，并自动生成不合格品处理单，见「质量闭环」 |
| 8. 退货（需要时） | 供应链 → 采购 → [采购退货](../scm/purchase-in#新增采购退货) | 仓库管理员 | 自动出库（优先退冻结的不合格库存），生成红字应付单；可选择「补收」恢复订单未完成数量 |
| 9. 应付单 | 财务 → 应收应付 → [应付管理](../fin/ar-ap) | 会计 | 入库、退货自动生成；生成凭证：借 原材料 / 库存商品、进项税额，贷 应付账款 |
| 10. 发票与对账（可选） | 财务 → 应收应付 → [发票管理](../fin/invoice) / [供应商对账](../fin/statement) / [往来对账单](../fin/partner-statement) | 会计 | 登记或导入（数电票）进项发票并勾稽应付单；对账单发送后供应商在门户确认或提出异议；往来对账单按期间列出应付、付款和逐笔余额，可打印给供应商签字盖章 |
| 11. 付款 | 财务 → 应收应付 → [付款单](../fin/settlement) | 出纳 | 付款单核销应付单（可审批，审批中不核销）；生成凭证：借 应付账款，贷 银行存款；出纳在[出纳管理](../fin/cashier)中查看银行日记账和资金日报 |

相关章节：[供应链管理](../scm/)、[仓库管理](../wms/)、[质量管理](../qms/)、[财务管理](../fin/)、[供应商门户](../portal/)。

## 二、订单到收款

从客户询价到发货、开票、收款。

| 步骤 | 菜单 | 负责人 | 系统自动联动 |
| --- | --- | --- | --- |
| 1. 报价（可选） | 供应链 → 销售 → [销售报价](../scm/quotation) | 销售员 | 按价目表自动取价，记录折扣；提交审批（可审批），批准且在有效期内可转销售订单 |
| 订单的其他来源 | 客户关系 → 客户经营 → [销售机会](../crm/opportunity)；经销商门户 → [我要订货](../portal/dealer#我要订货)；销售订单 → [导入外部订单](../scm/sales#导入外部订单) | 销售员、经销商 | 商机赢单生成销售订单草稿；经销商订货生成草稿并通知审核人；外部订单按外部单号导入 |
| 2. 销售订单 | 供应链 → 销售 → [销售订单](../scm/sales) | 销售员 | 按[价目表](../scm/price-list)取价（客户专属价优先，其次客户等级），没有价目价时带出该客户最近一次成交价；单价低于最低销售价时提示或禁止保存；自动应用促销和返利抵扣；记录业务员（用于销售提成）；多规格物料可按规格矩阵录入；审核（可审批）时校验客户信用额度：应收余额 + 未完成订单 + 本单不超过额度（是否在审核时校验见[业务参数](../system/biz-rule#客户信用额度控制)） |
| 3. 库存预留（可选） | 销售订单详情 → [库存预留](../scm/sales#库存预留) | 销售员 | 锁定空闲库存给该订单，出库时核销，订单完成 / 关闭时释放 |
| 4. 发货通知与拣货（可选） | 供应链 → 销售 → [发货通知](../scm/delivery) / [波次拣货](../scm/wave)（或移动作业 → [拣货](../mobile/pick)） | 仓库管理员 | 按先到期先出生成拣货建议，确认拣货后一键生成销售出库单；可装箱、打印拣货单和装箱单 |
| 5. 销售出库 | 供应链 → 销售 → [销售出库](../scm/sales-out) | 仓库管理员 | **保存即确认**：再次校验信用额度（业务参数选「不控制」时不校验），出库数量默认不能超过未出库数量（可按业务参数超发），自动生成仓库出库单、扣减库存（库存不足时整单不能保存），回写订单出库进度；生成应收单 |
| 6. 物流发运（可选） | 供应链 → 销售 → [物流发运](../scm/shipment) | 仓库管理员 | 由出库单生成，记录运单号和物流动态；指定承运商时生成运费应付单 |
| 7. 退货（需要时） | 供应链 → 销售 → [销售退货](../scm/sales-out#新增销售退货) | 仓库管理员 | 自动入库，生成红字应收单；可选择「补发」 |
| 8. 应收单与开票 | 财务 → 应收应付 → [应收管理](../fin/ar-ap) / 发票管理 | 会计 | 出库、退货自动生成；生成凭证：借 应收账款，贷 主营业务收入、销项税额；登记销项发票并勾稽 |
| 9. 收款 | 财务 → 应收应付 → [收款单](../fin/settlement)（预收款在「[预收预付](../fin/advance)」） | 出纳 | 核销应收单；生成凭证：借 银行存款，贷 应收账款；逾期应收出现在首页待办；可打印[往来对账单](../fin/partner-statement)与客户核对余额 |
| 10. 销售提成（可选） | 供应链 → 销售 → [销售提成](../scm/commission) | 销售主管、人事专员 | 按月统计各业务员的销售额、毛利、回款，按阶梯规则计算提成；确认后计入当月工资表的「销售提成」 |

相关章节：[供应链管理](../scm/)、[仓库管理](../wms/)、[财务管理](../fin/)、[客户关系](../crm/)。

## 三、计划到生产

从销售需求到生产计划、物料需求计算、工单执行和完工入库。

| 步骤 | 菜单 | 负责人 | 系统自动联动 |
| --- | --- | --- | --- |
| 1. 基础资料 | 仓库 → 基础资料 → [物料管理](../wms/material)；生产制造 → 工艺与设备 → [物料清单](../mes/bom) / [工作中心](../mes/work-center) | 生产计划员 | 物料的计划属性（自制 / 采购 / 委外 / 虚拟件、提前期、批量）、BOM 用量与损耗率、工艺路线 |
| 2. 生产计划 | 生产制造 → 生产计划 → [生产计划](../mes/plan) | 生产计划员 | 可由销售订单的自制件生成（不会重复生成）；确认后参与 MRP，也可直接转工单 |
| 3. MRP 运算 | 生产制造 → 生产计划 → MRP 运算 | 生产计划员 | 多级展开 BOM，计算净需求；下达后自制件生成草稿工单，采购、委外件按供应商合并生成草稿采购订单 |
| 4. 产能排程（可选） | 生产制造 → 生产计划 → [产能排程](../mes/capacity) | 生产计划员 | 按工作中心产能排定工序日期，分析负荷 |
| 5. 下达工单 | 生产制造 → 车间执行 → [生产工单](../mes/wo) | 生产计划员 | 保存时按 BOM 生成用料和工序；下达后可领料、报工 |
| 6. 齐套分析 | 生产制造 → 车间执行 → 齐套分析 | 生产计划员 | 按优先级把库存分配给各工单，显示缺料；「缺料下单」生成采购订单 / 工单 |
| 7. 领料 | 生产工单详情 → [领料](../mes/wo#领料) | 仓库管理员 | 生成生产领料出库单、扣减库存；累计领料不能超过需求 ×（1 + 允许超领比例） |
| 8. 补料（需要时） | 生产制造 → 车间执行 → [补料申请](../mes/supplement) | 车间主管、仓库 | 超出领料上限时申请（可审批），仓库发料生成补料出库 |
| 9. 报工 | 生产工单详情 → 工序列表中的「[报工](../mes/wo#报工)」 | 车间主管 | 按工序累计合格、报废数量；首件检验合格前只能报工 1 件；计件工资计入操作员当月工资表 |
| 10. 检验（可选） | 质量 → 检验管理 → 质量检验 | 质量工程师 | 首件、过程、成品检验；物料要求成品检验时，完工入库不能超过检验合格数 |
| 11. 完工入库 | 生产工单详情 → [完工入库](../mes/wo#完工入库) | 仓库管理员 | 生成完工入库单、增加成品库存；入库满数量后工单「已完工」；生产计划达到数量后自动关闭 |
| 也可以：组装拆卸 | 仓库 → 库存作业 → [组装拆卸](../wms/assembly) | 仓库管理员 | 不需要工单的简单组装（如配套、礼盒）或拆卸：按 BOM 带出子件，确认后生成出库单、入库单；成本核算按子件成本结转成套件成本 |
| 12. 成本核算 | 财务 → 资产与成本 → [成本核算](../fin/cost) | 会计 | 按物料的计价方法（月末一次加权平均、移动加权平均、先进先出）计算出库成本，归集材料、人工、制造费用，生成成本结转凭证 |

相关章节：[生产制造](../mes/)、[仓库管理](../wms/)、[质量管理](../qms/)、[财务管理](../fin/)。

## 四、质量闭环

从检验发现问题，到处置、整改和向供应商索赔。

| 步骤 | 菜单 | 负责人 | 系统自动联动 |
| --- | --- | --- | --- |
| 1. 检验方案 | 质量 → 检验管理 → [检验方案](../qms/plan) | 质量工程师 | 按检验类型 + 物料（或分类）定义检验项目和抽样方式（全检、固定数量、AQL 抽样） |
| 2. 检验 | 质量 → 检验管理 → 质量检验 | 质量工程师 | 来料、过程、成品、首件检验；按方案逐项录入，自动判定合格 / 不合格；确认后不能修改 |
| 3. 不合格品处理 | 质量 → 不良处理 → [不合格品处理](../qms/ncr) | 质量工程师 | 检验确认不合格时自动生成，也可手工登记；评审处置（可审批）：退货（保持冻结，通知采购退货）、返工（生成返工工单）、报废（生成报废出库单）、让步接收（放行）、挑选 |
| 4. 纠正预防（8D） | 质量 → 不良处理 → [纠正预防](../qms/capa) | 质量工程师 | 从不合格品处理单「发起 8D」，按 D1 ~ D8 步骤推进，逾期提醒负责人 |
| 5. 供应商索赔 | 质量 → 不良处理 → [供应商索赔](../qms/claim) | 质量工程师 | 确认后财务生成红字应付单冲减应付；供应商在门户查看 |
| 6. 质量分析 | 质量 → 质量分析 → [质量分析](../qms/analysis) / [SPC 控制图](../qms/spc) | 质量工程师 | 合格率趋势、不良柏拉图、供应商来料质量排名、控制图与过程能力 |

相关章节：[质量管理](../qms/)。

## 五、记账到报表

日常凭证处理与月末结账。

| 步骤 | 菜单 | 负责人 | 系统自动联动 |
| --- | --- | --- | --- |
| 1. 初始化 | 财务 → 期末与设置 → [会计科目](../fin/account) / [凭证科目设置](../fin/account-rule) / [期初余额](../fin/opening) / [币种汇率](../fin/currency) | 会计 | 科目上设置辅助核算；按[启用向导](../fin/opening#启用向导)录入科目期初（借贷必须平衡）、导入期初库存和期初往来、录入存货期初（成本核算的起点） |
| 2. 业务凭证 | 应收管理、应付管理、收款单、付款单、费用报销等页面的「生成凭证」 | 会计 | 业务单据一键生成凭证，科目按[凭证科目设置](../fin/account-rule)取得，带客户、供应商、部门、项目辅助核算 |
| 3. 手工凭证 | 财务 → 总账 → [凭证管理](../fin/voucher) | 会计 | 借贷必须平衡；凭证号按期间连续编号 |
| 4. 审核与记账 | 财务 → 总账 → 凭证管理 | 会计主管 | 默认制单人不能审核自己的凭证（可在[业务参数](../system/biz-rule)中放开，可接入审批）；只有已记账的凭证进入账簿和报表 |
| 5. 月末处理 | [固定资产](../fin/asset)（计提折旧）、成本核算、期末结账（增值税结转）、[银行对账](../fin/bank) | 会计 | 折旧凭证、成本结转凭证、增值税结转凭证自动生成 |
| 6. 期末结账 | 财务 → 期末与设置 → [期末结账](../fin/period) | 会计主管 | 结账前检查（凭证全部记账、试算平衡等）；结账时自动生成并记账结转损益凭证；结账后该期间不能再录入凭证和业务单据 |
| 7. 账簿与报表 | 财务 → 总账 → [账簿查询](../fin/book) / [财务报表](../fin/report) | 会计、管理层 | 科目余额表、明细账、资产负债表、利润表、现金流量表 |

相关章节：[财务管理](../fin/)。

## 六、招聘到发薪

从招聘入职到考勤、绩效、工资发放。

| 步骤 | 菜单 | 负责人 | 系统自动联动 |
| --- | --- | --- | --- |
| 1. 招聘需求 | 人力资源 → 招聘培训 → [招聘管理](../hr/recruit) | 部门、人事专员 | 提交（可审批）时校验岗位编制 |
| 2. 应聘者与录用 | 人力资源 → 招聘培训 → 招聘管理（切换到「应聘者」） | 人事专员 | 录用后一键生成员工档案，可同时建立试用期薪资档案、开通登录账号（初始密码见参数设置） |
| 3. 员工档案与合同 | 人力资源 → 员工管理 → [员工档案](../hr/employee) / [劳动合同](../hr/contract) | 人事专员 | 转正、调岗、调薪、离职通过「异动」办理（可审批）；离职时账号停用、工作移交 |
| 4. 考勤 | 人力资源 → 员工管理 → [员工自助](../hr/self)（打卡）；考勤绩效 → [考勤管理](../hr/attendance) | 员工、人事专员 | 按班次计算迟到、早退、缺卡，生成月度汇总 |
| 5. 请假加班 | 员工自助 → 请假加班；考勤绩效 → [假勤审批](../hr/leave) | 员工、主管 | 可审批；年假、调休按余额校验 |
| 6. 绩效考核 | 人力资源 → 考勤绩效 → [绩效考核](../hr/perf) | 人事专员、部门负责人 | 员工自评、负责人评分，等级对应奖金系数 |
| 7. 薪酬核算 | 人力资源 → 薪酬福利 → [薪酬核算](../hr/payroll) | 人事专员 | 汇总考勤扣款、加班费、绩效奖金、计件工资、社保公积金、个税；确认（可审批）后生成计提凭证并锁定当月考勤 |
| 8. 发放 | 薪酬核算 → 发放 | 人事专员、出纳 | 生成发放凭证；员工在员工自助中查看工资条 |

相关章节：[人力资源](../hr/)。

## 七、线索到回款

客户关系管理的完整过程。

| 步骤 | 菜单 | 负责人 | 系统自动联动 |
| --- | --- | --- | --- |
| 1. 市场活动（可选） | 客户关系 → 服务与营销 → [市场活动](../crm/campaign) | 市场人员 | 统计活动带来的线索、商机、赢单金额和 ROI |
| 2. 线索 | 客户关系 → 客户经营 → [线索管理](../crm/lead) | 销售员 | 转化时新建或关联客户，可同时生成商机 |
| 3. 客户与跟进 | 客户关系 → 客户经营 → [客户管理](../crm/customer) / [跟进记录](../crm/followup) | 销售员 | 公海客户可领取；跟进记录更新下次跟进时间，当天需跟进的客户出现在首页待办 |
| 4. 销售机会 | 客户关系 → 客户经营 → 销售机会 | 销售员 | 按阶段推进（赢率 10% → 80%）；可新建报价；赢单后生成销售订单草稿 |
| 5. 合同 | 客户关系 → 客户经营 → [合同管理](../crm/contract) | 销售员 | 提交审批后执行；设置回款计划 |
| 6. 订单执行 | 见「订单到收款」 | 销售员、仓库 | 出库生成应收单 |
| 7. 回款 | 财务 → 应收应付 → 收款单；合同详情查看回款 | 出纳、销售员 | 回款按关联订单应收的核销金额计算，逾期回款提醒负责人 |
| 8. 售后服务 | 客户关系 → 服务与营销 → [服务工单](../crm/ticket) | 客服 | 按序列号判断保修；领用备件生成出库单；服务收费生成应收单 |

相关章节：[客户关系](../crm/)、[供应链管理](../scm/)。

## 八、项目全过程

项目型业务从立项到核算的过程。

| 步骤 | 菜单 | 负责人 | 系统自动联动 |
| --- | --- | --- | --- |
| 1. 立项 | 项目管理 → [项目列表](../pm/project) | 项目经理 | 可由销售订单、赢单商机一键建项目；启动（可审批）后为「进行中」 |
| 2. 成员与计划 | 项目详情 → [成员](../pm/project#成员与投入比例)；项目管理 → [计划进度](../pm/plan) / [资源分配](../pm/resource) | 项目经理 | WBS 任务树、前置任务、甘特图；成员投入超过 100% 提示超负荷 |
| 3. 工时 | 项目管理 → [工时管理](../pm/timesheet) | 项目成员、项目经理 | 按任务填报，经理审批后计入任务实际工时和人工成本（工时 × 小时成本） |
| 4. 成本 | 项目管理 → [成本控制](../pm/cost) | 项目经理 | 费用录入（可审批）；项目领料生成并确认出库单；可开启超预算控制 |
| 5. 收款计划与开票 | 项目管理 → [项目核算](../pm/accounting#收款计划与开票) | 项目经理、会计 | 开票生成应收单（来源「项目开票」） |
| 6. 项目月结 | 项目管理 → 项目核算 → [项目月结](../pm/accounting#项目月结)（入总账） | 会计 | 人工、费用转入合同履约成本；按完工进度确认收入并结转成本，生成凭证 |
| 7. 分析 | 项目核算 | 项目经理、管理层 | 挣值分析（SPI、CPI）、成本趋势 |

相关章节：[项目管理](../pm/)、[财务管理](../fin/)。

## 数据汇总到商务智能

以上各条业务线的数据每天凌晨自动同步到数据仓库（也可在「商务智能 → [数据仓库](../bi/etl)」中手动立即同步），供[经营驾驶舱](../bi/cockpit)、[多维分析](../bi/olap)、[自定义报表](../bi/report)与[仪表盘](../bi/board)、[决策支持](../bi/decision)使用。分析数据不是实时的，业务数据变化后需要同步才会体现。[数据大屏](../bi/screen)例外：它直接读取业务单据，每 30 秒刷新，可通过投屏链接显示在车间、仓库的电视上。详见[商务智能](../bi/)。
