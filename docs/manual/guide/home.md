# 工作台首页

首页（工作台）是登录后看到的第一个页面，集中展示与你相关的经营数据、待办事项、待审批事项和最新消息，并提供常用功能的快捷入口。首页上的每一项都**只显示当前账号有权限的内容**，不同岗位看到的首页不同。

## 页面入口

点击顶部导航的 **首页**、标签栏的「首页」标签，或侧边栏顶部的系统 Logo。

![工作台首页](/images/manual/guide/home.jpg)

## 欢迎栏与快捷入口

页面顶部的欢迎栏显示：

- 头像、问候语（按当前时间显示「早上好」「上午好」「中午好」「下午好」「晚上好」「夜深了」）和姓名；
- 今天的日期、星期，以及你拥有的角色（显示角色编码）。

右侧是**快捷入口**按钮，点击直接打开对应的列表页。系统按以下顺序从你有权限的页面中取前 5 个显示：

[销售订单](../scm/sales)、[采购订单](../scm/purchase)、[生产工单](../mes/wo)、[库存查询](../wms/stock)、[凭证](../fin/voucher)、[费用报销](../fin/claim)、[员工自助](../hr/self)。

例如普通员工通常只看到「费用报销」「员工自助」，仓库管理员看到「生产工单」「库存查询」等。

## 经营数据卡片

欢迎栏下方是经营数据卡片，点击卡片打开对应的列表页。卡片按权限显示，没有相关权限时不显示：

| 卡片 | 内容 | 显示条件 | 点击打开 |
| --- | --- | --- | --- |
| 本月销售额 | 本月 1 日至今的销售订单价税合计，并与上月同期（上月 1 日到上月的今天）比较，显示涨跌百分比 | 有销售订单查看权限 | 销售订单 |
| 本月采购额 | 本月 1 日至今的采购订单价税合计，并与上月同期比较 | 有采购订单查看权限 | 采购订单 |
| 应收余额 | 全部未核销的应收单余额 | 有应收管理查看权限，且数据权限为「全部数据」 | [应收管理](../fin/ar-ap) |
| 应付余额 | 全部未核销的应付单余额 | 有应付管理查看权限，且数据权限为「全部数据」 | 应付管理 |
| 待发货订单 | 已审核、部分出库的销售订单数 | 有销售订单查看权限 | 销售订单 |
| 在制工单 | 已下达、生产中的生产工单数 | 有生产工单查看权限 | 生产工单 |

- 销售额、采购额、待发货订单、在制工单按你的数据权限统计，例如「仅本人」的销售员只统计自己制单的订单。
- 比较值显示为「↑ 12.5%」「↓ 3.0%」；上月同期为 0 时显示「新增」或「持平」。

## 功能导航

「功能导航」卡片按模块列出你能访问的全部页面（不含流程中心、系统管理和系统监控），点击页面名称直接打开。适合刚开始使用系统、还不熟悉菜单位置的用户。没有任何可访问的业务功能时显示「暂无可访问的功能」。

## 待办事项

右侧「待办事项」汇总各模块需要你处理的事项，每项显示名称和数量，点击跳转到对应页面处理。数量为 0 的事项不显示，全部为 0 时显示「暂无待办，一切顺利」。点击卡片右上角的刷新图标可以重新统计。

事项前的圆点颜色表示紧急程度，红色（已逾期或异常）排在最前，其次是橙色（需要关注），最后是蓝色（一般）。

| 模块 | 待办事项 | 级别 | 需要的权限（满足才显示） |

| 供应链 | 销售订单逾期未发货 | 已逾期 | 新增销售出库 |

| 仓库 | 出入库单待确认 | 一般 | 新增入库单 |
| 仓库 | 库存低于安全库存 | 需要关注 | 查看库存 |

| 仓库 / 质量 | 来料待检 | 一般 | 新增质量检验 |
| 仓库 | 来料不合格待退货 | 已逾期 | 查看库存冻结 |
| 生产 | 补料待发料 | 需要关注 | 补料发料 |

| 质量 | 检验单待确认 | 一般 | 编辑质量检验 |
| 质量 | 不合格品待评审 | 需要关注 | 编辑不合格品处理 |
| 质量 | 纠正预防逾期 | 已逾期 | 编辑纠正预防 |
| 生产 | 设备保养到期 | 需要关注 | 处理设备维护 |
| 财务 | 凭证待审核 | 一般 | 审核凭证 |
| 财务 | 凭证待记账 | 一般 | 凭证记账 |

部分事项点击后会自动带上筛选条件，直接显示需要处理的数据：

- 「库存低于安全库存」：打开[库存查询](../wms/stock)，切换到按物料汇总并只看低于安全库存的物料；
- 「检验单待确认」：打开[质量检验](../qms/inspection)，只看状态为草稿的检验单；
- 「我处理中的服务工单」：打开[服务工单](../crm/ticket)，只看指派给我的工单。

## 待我审批

有「我的待办」权限的用户会看到「待我审批」卡片，列出最近 5 条等待你审批的流程，每条显示流程名称、发起人、当前节点和到达时间。点击某条或右上角的 **全部** 打开「流程中心 → 我的待办」进行审批，详见[我的待办](../workflow/todo)。没有待审批事项时显示「没有待审批的事项」。

## 消息通知

「消息通知」卡片显示最近 6 条站内消息（包括已读的），未读消息前有蓝色圆点，已读为灰色。有关联页面的消息可以点击跳转。点击 **全部** 打开「我的消息」。

::: tip 提示
首页的数据在打开首页时加载。处理完待办后，点击「待办事项」右上角的刷新图标，或点击标签栏的刷新按钮重新加载首页。
:::
