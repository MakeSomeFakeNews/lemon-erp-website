# 登录与账号

本页说明如何登录柠檬ERP（账号密码登录，以及钉钉 / 企业微信 / 飞书扫码登录和应用内免登）、登录失败的原因与处理办法、密码规则，以及什么情况下登录会失效需要重新登录。所有用户都需要阅读。

## 登录页面

在浏览器中打开系统地址，未登录时自动进入登录页。登录页左侧是产品介绍，右侧是登录表单。

![登录页](/images/manual/guide/login.jpg)

右上角的月亮 / 太阳图标可以在亮色和暗色之间切换，选择会保存在当前浏览器中，登录后的界面同样生效。

![登录页（暗色）](/images/manual/guide/login-dark.jpg)

### 切换语言

登录页右上角、月亮图标左边显示语言图标和当前语言名称（「简体中文」或「English」）。点击后在下拉菜单中选择语言，页面刷新后以所选语言显示，登录表单的字段名、提示和登录失败的错误信息也随之改变。选择保存在当前浏览器中，登录后的界面使用同一语言，之后也可以在顶部栏随时切换。

![英文登录页](/images/manual/guide/login-en.jpg)

在这个浏览器中从没有选择过语言时，浏览器语言为英文的显示英文，其他显示简体中文。语言切换的详细说明见[界面介绍 → 语言切换](./layout#语言切换)。

::: tip 提示
英文界面下，系统名称没有修改过时显示为「Lemon ERP」；租户名称是录入的数据，SaaS 模式下仍要按实际名称填写（例如「柠檬科技」），不需要翻译。
:::

### 表单字段

| 字段 | 说明 |
| --- | --- |
| **租户** | 只在开启了 SaaS 多租户模式时显示，必填。填写公司（租户）的名称，例如「柠檬科技」。同一个用户名在不同租户中是不同的账号 |
| **用户名** | 必填。由管理员在「系统管理 → [用户管理](../system/user)」中创建，或在[人事录用](../hr/recruit#录用入职)、[开通门户账号](../portal/account)时自动生成 |
| **密码** | 必填。输入框右侧的眼睛图标可显示 / 隐藏密码 |
| **验证码** | 只在管理员开启了登录验证码时显示，必填。点击验证码图片可以换一张 |
| **记住租户和用户名** / **记住用户名** | 勾选后，下次打开登录页自动填好租户和用户名（不保存密码）；取消勾选并登录后清除已记住的内容 |

登录页下方如果显示「演示账号」提示，说明系统处于演示状态，正式使用时管理员应在「参数设置」中关闭「登录页显示演示账号」。提示中的两个演示账号可以直接点击：点击 **admin / admin123**（超级管理员）或 **test / admin123**（只读）会自动填好用户名和密码，SaaS 模式下同时填好租户「柠檬科技」，再点「登 录」即可。

在开启了演示模式的环境（登录页显示「当前为演示环境，只能查看，不能新增、修改、删除数据」）中，打开登录页时已经默认填好超级管理员账号和密码，直接点击「登 录」即可；如果当前浏览器记住的用户名是 test，则默认填好 test 账号。

### 登录步骤

1. 打开系统地址，进入登录页。
2. SaaS 模式下先填写 **租户**。
3. 填写 **用户名**、**密码**；如显示验证码，按图片填写（算术题填写计算结果，字母数字不区分大小写）。
4. 需要时勾选 **记住用户名**。
5. 点击 **登 录**（也可以直接按回车）。
6. 登录成功提示「登录成功」，进入[工作台首页](./home)；如果是因为登录过期被带回登录页的，登录后会回到之前所在的页面。

::: tip 提示
系统名称（登录页、侧边栏、浏览器标题中显示的「柠檬ERP」）可由管理员在「系统管理 → 参数设置 → [基本设置](../system/config#基本设置)」中修改。没有修改过时，英文界面显示为「Lemon ERP」。
:::

## 钉钉 / 企业微信 / 飞书登录

管理员在「系统管理 → [第三方集成](../system/im)」中接入了钉钉、企业微信或飞书后，除了账号密码，还可以用这些平台的账号登录。

![登录页的其他登录方式](/images/manual/guide/login-im.jpg)

### 先绑定账号

用平台账号登录之前，你的平台账号必须已经和系统账号绑定，绑定方式有三种：

- 管理员同步通讯录时按手机号自动绑定（系统账号的手机号与平台中的手机号一致）；
- 管理员在「第三方集成 → 成员绑定」中为你手工绑定；
- 你先用账号密码登录，在「个人中心 → [第三方账号](./profile#第三方账号)」中自行扫码绑定。

### 扫码登录

1. 打开登录页。SaaS 模式下先填写 **租户**，稍等片刻，登录按钮下方出现「其他登录方式」和本公司启用的平台图标（钉钉、企业微信、飞书）。没有出现说明本公司没有启用，或租户名称填写不正确。
2. 点击平台图标，页面跳转到该平台的授权页面。
3. 用手机上的钉钉 / 企业微信 / 飞书扫描二维码，在手机上确认登录（也可以按平台页面的提示用其他方式确认）。
4. 页面跳回系统，显示「正在登录…」，成功后提示「登录成功」，进入首页；如果是因为登录过期被带回登录页的，登录后回到之前所在的页面。

### 在钉钉 / 企业微信 / 飞书中打开（免登）

- 在平台的「工作台」中点开柠檬ERP 应用；
- 或点击平台中收到的消息卡片上的「查看详情」（企业微信为「详情」）。

页面显示「正在进入钉钉…」（或企业微信、飞书），在平台客户端内自动完成授权并登录，然后进入首页或消息对应的页面（例如待审批的单据），不需要输入账号密码。如果在这个浏览器中已经登录过并且登录还没有过期，会直接进入。在电脑浏览器中打开这类链接时，会跳转到平台的扫码页面，扫码后同样进入对应页面。这个过程中的页面没有语言切换按钮，使用该浏览器上次选择的语言（没有选择过时按浏览器语言）。

自动登录失败时页面显示「无法自动登录」和失败原因，可以点击 **使用账号密码登录**。

### 登录失败的提示

扫码或免登失败时，页面显示「登录失败」和原因，点击 **返回登录** 回到登录页：

| 提示 | 原因与处理 |
| --- | --- |
| 该钉钉账号（…）还没有绑定系统用户，请先用账号密码登录，在个人中心绑定，或联系管理员同步通讯录 | 你的平台账号还没有绑定系统账号（企业微信、飞书同理）。按提示先绑定 |
| 该钉钉账号不是本企业的成员 / 该企业微信账号不是本企业的成员 | 扫码使用的平台账号不属于公司的组织，或不在应用的可见范围内。换用公司的账号，或请管理员把你加入应用可见范围 |
| 授权已过期，请重新操作 | 从打开授权页到完成扫码超过了 10 分钟，或刷新了回调页面。回到登录页重新点击平台图标 |
| 没有收到授权码，可能是取消了授权 | 在授权页面取消了授权。重新操作即可 |
| 账号已停用 | 绑定的系统账号已被停用 |
| 门户账号不能使用钉钉登录（企业微信、飞书同理） | 供应商、经销商门户账号只能用账号密码登录 |
| 未启用钉钉集成 / 未开启钉钉登录 | 管理员停用了该平台集成或关闭了扫码登录。请改用账号密码登录 |
| 租户不存在或已停用 | 公司（租户）已停用或已到期 |

登录成功和失败都会记录在「系统监控 → [登录日志](../monitor/loginlog)」中，成功的提示为「钉钉登录成功」「企业微信登录成功」「飞书登录成功」。如果绑定的账号仍在使用初始密码或密码已过期，登录后同样要求先[修改密码](#首次登录与密码过期)。

## 验证码规则

验证码由管理员在「系统管理 → 参数设置 → [登录与会话](../system/config#登录与会话)」中配置：

| 参数 | 可选值 | 说明 |
| --- | --- | --- |
| 登录验证码 | 关闭 / 每次登录 / 密码输错后 | 默认「关闭」。「密码输错后」：同一账号密码输错后，下次登录需要输入验证码，直到登录成功 |
| 验证码类型 | 算术题 / 字母数字 | 算术题如「3 + 5 = ?」，填写结果；字母数字为 4 位，不区分大小写 |

- 验证码 2 分钟内有效，并且**只能使用一次**：登录失败后会自动换一张新的验证码。
- 验证码错误不计入密码错误次数。
- 选择「密码输错后」时，如果你在别的电脑上输错过密码，在本机登录时可能先提示「请输入验证码」，此时验证码输入框会自动出现，填写后再次登录即可。

| 提示 | 原因与处理 |
| --- | --- |
| 请输入验证码 | 没有填写验证码，或该账号此前输错过密码需要验证码。填写后重新登录 |
| 验证码已过期，请刷新 | 超过 2 分钟或已使用过。点击图片换一张 |
| 验证码错误 | 重新计算或辨认后填写；看不清时点击图片换一张 |

## 登录失败与账号锁定

连续输错密码会锁定账号，锁定期间即使密码正确也不能登录。锁定规则在「参数设置 → 登录与会话」中配置：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 密码错误锁定次数 | 5 次 | 可设 1 ~ 20 次。连续输错达到次数后锁定 |
| 锁定时长（分钟） | 10 分钟 | 可设 1 ~ 1440 分钟。到时自动解锁；管理员重置密码会立即解锁 |

登录时可能看到的提示：

| 提示 | 原因与处理 |
| --- | --- |
| 用户名或密码错误 | 用户名不存在或密码不正确。注意区分大小写、检查键盘大写锁定 |
| 用户名或密码错误，再错 N 次将锁定账号 | 剩余可尝试次数不多于 2 次时提示。不确定密码时请先联系管理员重置，避免被锁定 |
| 用户名或密码错误，账号已锁定 | 本次输错后达到了锁定次数 |
| 密码错误次数过多，账号已锁定，请 N 分钟后再试或联系管理员重置密码 | 账号处于锁定期。等待提示的分钟数后再试，或请管理员在「用户管理」中重置密码 |
| 账号已停用 | 账号被管理员停用，或员工已办理离职。请联系管理员 |
| 请输入租户名称 / 租户不存在 | SaaS 模式下租户名称没有填写或填写错误，请向管理员确认公司在系统中的准确名称 |
| 租户已停用 / 租户已过期，请联系平台续费 | 公司（租户）被平台停用或已到期，该租户下所有账号都无法登录 |

::: warning 注意
不存在的用户名同样会累计错误次数并锁定，所以「锁定」并不代表这个用户名一定存在。每次登录成功与失败都会记录在「系统监控 → [登录日志](../monitor/loginlog)」中，包括 IP 和归属地。
:::

## 密码策略

管理员在「参数设置 → [密码策略](../system/config#密码策略)」中设置以下规则，对**新设置**的密码生效（新增用户、管理员重置、本人修改密码、开通账号），已有的密码不受影响：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 密码最小长度 | 8 位 | 可设 6 ~ 32 位；密码最长 32 位 |
| 密码复杂度 | 包含字母和数字 | 可选「包含字母和数字」「包含大写字母、小写字母和数字」「包含字母、数字和特殊字符」 |
| 密码有效期（天） | 0（不限制） | 超过有效期后登录，系统要求修改密码 |
| 初始密码 | Lemon@123 | 人事录用、组织同步、同步钉钉 / 企业微信 / 飞书通讯录自动开通账号时使用的初始密码，必须符合密码策略 |

修改密码时，输入框中会提示当前的要求，例如「8-32 位，包含字母和数字」。不符合时保存会提示「密码长度为 8-32 位」或「密码必须同时包含字母和数字」等。

## 首次登录与密码过期

以下两种情况登录后，系统会提示「当前密码为管理员设置的初始密码或已过期，请先修改密码」，并自动打开「个人中心」的 **修改密码** 页签：

- 密码是管理员新建账号或重置时设置的初始密码（包括人事录用、门户账号开通时自动生成的账号）；
- 距上次修改密码已超过「密码有效期」。

按[个人中心 → 修改密码](./profile#修改密码)的步骤设置新密码即可。在修改之前，每次登录都会再次提示。

::: tip 提示
管理员在「用户管理」中重置某人的密码后，该用户已登录的所有会话立即失效，并解除登录锁定；用户用新密码登录后需要再改成自己的密码。
:::

## 退出登录

1. 点击页面右上角的头像和姓名。
2. 在下拉菜单中选择 **退出登录**。
3. 在确认框中点击 **退出**。

退出后当前登录凭证立即作废，回到登录页。在公用电脑上使用后请务必退出。

## 会话失效的情况

登录后，系统会在服务器上保存你的会话。出现以下情况时会话失效，页面提示「登录已过期，请重新登录」并自动跳转到登录页，重新登录后回到原来的页面：

| 情况 | 说明 |
| --- | --- |
| 超过登录有效期 | 默认登录 12 小时后需要重新登录（「参数设置 → 登录有效期（小时）」，1 ~ 720 小时，修改后对新登录生效） |
| 主动退出登录 | 只影响当前这次登录 |
| 管理员强制下线 | 管理员在「系统监控 → [在线用户](../monitor/online)」中强制下线 |
| 账号被停用或删除 | 立即失效，所有登录都会下线 |
| 管理员重置了密码 | 该账号所有已登录的会话立即失效 |
| 在别处登录 | 管理员开启了「同一账号只允许一处登录」时，账号在另一处登录后，之前的登录自动下线 |
| 员工离职 | 办理离职后登录账号停用并强制下线 |
| 租户停用或到期 | SaaS 模式下，租户停用或到期后其下所有账号立即下线 |

::: warning 注意
页面上正在填写但未保存的内容在跳转到登录页后会丢失。长时间填写复杂单据时，请注意登录有效期。
:::
