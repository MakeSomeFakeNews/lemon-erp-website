# 界面设置

每个人可以按自己的习惯调整系统外观：浅色 / 深色、主题色、菜单布局、是否显示多标签页、紧凑模式和界面语言。修改立即生效，并自动保存到你的账号，换浏览器或换电脑登录后仍然是你的设置，不影响其他用户。

## 页面入口

点击顶部栏右侧、搜索菜单旁边的 **界面设置** 图标（鼠标悬停提示「界面设置」），从右侧打开设置抽屉。

![界面设置](/images/manual/guide/ui-settings-drawer.jpg)

抽屉中的每一项修改后立即应用到当前页面，可以边看边调；不需要保存按钮，关闭抽屉即可。

## 主题模式

| 选项 | 说明 |
| --- | --- |
| 浅色 | 始终使用浅色界面 |
| 深色 | 始终使用深色界面，适合夜间或光线较暗的环境 |
| 跟随系统 | 默认值。按操作系统的深浅色设置显示，系统切换深色模式时页面随之切换 |

顶部栏原有的月亮 / 太阳图标仍然保留，用于在浅色和深色之间快速切换，效果与这里选择「浅色」「深色」相同，见[界面介绍](./layout#亮色-暗色模式)。

## 主题色

主题色用于按钮、链接、选中的菜单和标签、开关等强调元素：

- **预设颜色**：拂晓蓝（默认，也是柠檬ERP 的品牌色）、薄暮红、火山橙、日暮黄、柠檬黄、极光绿、明青、极客蓝、酱紫、法式洋红，鼠标悬停色块显示名称，点击即可选用；
- **自定义颜色**：点击最后一个虚线框的取色图标，用浏览器的取色器选择任意颜色，拖动时页面实时预览。

色块下方显示当前颜色的名称（自定义时显示「自定义颜色」）和色值。悬停、浅色背景等派生颜色由系统按主题色自动生成，在深色模式下同样适用。图表的系列颜色、状态标签的颜色（如「已审核」的绿色、「逾期」的红色）表示数据含义，不随主题色变化。

## 布局

用缩略图选择菜单的排列方式，共四种：

| 布局 | 说明 | 适合 |
| --- | --- | --- |
| 顶部模块 + 侧边菜单 | 默认布局。顶部栏切换模块，左侧边栏显示当前模块的分组和页面 | 大多数用户，模块多、页面多时查找清楚 |
| 侧边菜单 | 没有顶部模块导航，左侧边栏以多级树列出全部模块、分组和页面；顶部栏显示当前页面的完整位置（面包屑） | 习惯传统后台菜单、经常跨模块操作的用户 |
| 顶部菜单 | 没有侧边栏，全部菜单显示在顶部栏中，内容区最宽 | 宽屏显示器、常用页面不多的用户 |
| 双栏 | 最左一列显示各模块的图标和名称，第二栏显示当前模块的分组和页面 | 既想一眼看到全部模块，又想保留分组菜单的用户 |

### 顶部模块 + 侧边菜单

![顶部模块 + 侧边菜单](/images/manual/guide/layout-mix.jpg)

顶部栏、侧边栏的用法见[界面介绍](./layout#顶部模块导航)。

### 侧边菜单

![侧边菜单](/images/manual/guide/layout-side.jpg)

- 模块和分组都可以点击折叠、展开；展开一个模块时自动收起其他模块，菜单不会越拉越长；
- 打开页面时自动展开它所在的模块和分组并高亮当前页面；
- 顶部栏显示面包屑（模块 / 分组 / 页面），便于确认当前位置。

### 顶部菜单

![顶部菜单](/images/manual/guide/layout-top.jpg)

- 系统 Logo 和名称移到顶部栏最左侧，点击回到首页；
- 鼠标移到模块上展开下拉面板，模块下的页面按分组排成多列，同一分组不会被拆到两列；
- 窗口宽度放不下的模块收进末尾的 **···** 中；
- 这种布局没有侧边栏，因此也没有收起 / 展开侧边栏的按钮。

### 双栏

![双栏](/images/manual/guide/layout-column.jpg)

- 点击最左列的模块进入该模块，第二栏显示它的分组和页面；
- 点击顶部栏最左侧的折叠按钮可以隐藏第二栏，只保留模块栏，让内容区更宽；
- 首页、个人中心等不属于模块的页面只显示模块栏。

四种布局下，多标签页、[菜单搜索](./layout#菜单搜索-⌘k-ctrl-k)、面包屑和当前页面的高亮都正常使用，菜单都只包含你有权限访问的页面。

::: tip 提示
布局只在电脑和平板上生效。窗口宽度小于 768 像素（手机）时不区分布局，统一使用从左侧滑出的抽屉菜单，抽屉中显示全部模块的完整菜单树，见[界面介绍](./layout#侧边栏与分组)；此时抽屉中的布局选项下方会提示「手机上统一使用抽屉菜单，布局在电脑上生效」。[移动作业](../mobile/)、数据大屏、打印预览等独立页面不使用后台布局，不受影响。
:::

## 界面

| 设置项 | 说明 |
| --- | --- |
| 显示多标签页 | 默认开启。关闭后隐藏顶部栏下方的[标签栏](./layout#多标签页)，内容区更高，页面之间通过菜单切换 |
| 紧凑模式 | 默认关闭。开启后缩小按钮、输入框、表格行等控件的尺寸和间距，一屏显示更多内容，适合数据量大的列表和小屏幕 |
| 界面语言 | 简体中文 / English，与顶部栏的语言切换相同，切换后页面刷新一次，见[语言切换](./layout#语言切换) |

## 恢复默认

抽屉底部的「**恢复默认**」把主题模式（跟随系统）、主题色（拂晓蓝）、布局（顶部模块 + 侧边菜单）、多标签页（显示）、紧凑模式（关闭）恢复为默认值，提示「已恢复默认设置」。界面语言和侧边栏的收起状态保持不变。

## 设置保存在哪里

- 设置**跟随账号保存**在服务器上：修改后自动保存，抽屉底部提示「修改立即生效，自动保存到你的账号，换浏览器或设备登录后恢复」。换一个浏览器、换一台电脑登录后，自动恢复为你上次的设置；
- 每个人的设置互不影响，管理员也不能替别人修改；
- 登录页面使用这个浏览器上一次的外观（深浅色、主题色）；
- 界面语言同时保存在浏览器中（登录页也可以切换）：在从没选择过语言的浏览器上登录时，采用账号中保存的语言，页面自动刷新一次；这个浏览器中选择过语言的，以浏览器中的选择为准；
- 从旧版本升级后第一次登录时，原来在浏览器中保存的深浅色和侧边栏收起状态会自动带到账号中。

::: warning 注意
在对外开放的[演示环境](./layout#演示模式标签)中，所有人共用同一个演示账号，界面设置**只保存在当前浏览器**，不会保存到账号，抽屉底部提示「演示环境中所有人共用账号，设置只保存在本浏览器」。
:::
