# 产品介绍

柠檬ERP 是一套面向中小型制造、贸易与项目型企业的一体化企业资源计划系统。它把采购、销售、仓储、生产、质量、财务、人力、客户关系、项目和经营分析放在同一套系统里，业务单据之间自动联动：[采购入库](../scm/purchase-in)自动生成仓库入库单和应付单，[销售出库](../scm/sales-out)自动扣减库存并生成应收单，[工资表](../hr/payroll)确认后自动生成计提凭证……做到「一次录入、处处可用、账实一致」。

## 适用企业

| 企业类型 | 典型用法 |
| --- | --- |
| 离散制造企业（电子、机械、五金、设备组装等） | 销售订单驱动生产计划，MRP 计算物料需求，工单领料、报工、完工入库，质量检验与不合格品处理，月末成本核算 |
| 商贸流通企业（批发、分销、经销商体系） | 采购、销售、库存、发运、价目表与促销、返利、经销商门户订货、渠道库存 |
| 项目型企业（工程、系统集成、软件实施等） | 项目立项、WBS 计划、工时填报与审批、项目领料与费用、收款计划与开票、完工百分比确认收入 |
| 集团或多公司（SaaS 模式） | 一套系统为多个公司（租户）服务，数据相互隔离，可按套餐控制每个租户可用的功能 |

系统同时支持电脑浏览器、平板和手机访问，仓库人员可以用手机或 PDA 扫码完成收货、上架、拣货和盘点。

## 产品特点

- **业务全流程联动**：从订单到出入库、应收应付、收付款再到凭证，自动生成下游单据并回写上游进度，详见[核心业务流程总览](./flows)。
- **审批流程可配置**：采购 / 销售订单、请购、报价、请假加班、费用报销、凭证、盘点差异等几十种业务都可以接入审批；流程用拖拽式[设计器](../workflow/designer)配置，不发布流程时单据直接生效。
- **功能权限 + 数据权限**：角色控制能看到哪些菜单、能点哪些按钮；数据权限控制能看到哪些部门或本人的数据。
- **期间与成本控制**：会计期间结账后，该期间内的业务单据不能再改动；按物料设置的计价方法（月末一次加权平均、移动加权平均、先进先出）核算成本，自动生成成本结转凭证。
- **多币种、多租户**：订单可使用外币，按汇率折算本位币；可开启 SaaS 模式为多个公司提供服务。
- **按企业灵活配置**：[业务参数](../system/biz-rule)控制超收超发、信用额度、凭证审核等规则；[自定义字段](../system/custom-field)不改表结构为客户、供应商、物料、订单扩展字段；[打印模板](../system/print-template)可调整版式、上传 JRXML、在预印单据纸上套打。
- **易用的界面**：多标签页、菜单搜索（⌘ / Ctrl + K）、深色模式、表格列设置与导出、Excel 导入、单据打印（服务器生成 PDF）与附件、修改历史。

## 内置角色

系统预置了按岗位划分的角色，管理员只需给用户分配角色即可开始使用：

超级管理员、普通用户（全部只读）、总经理、采购员、销售员、仓库管理员、生产计划员、车间主管、质量工程师、会计、出纳、人事专员、项目经理、普通员工，以及供应商、经销商两个门户专用角色。各角色的权限范围见[角色、权限与数据范围](./permission)。

## 如何阅读本手册

本手册按模块分章节，每个章节先有一页「概览」介绍模块用途、功能清单和典型流程，再按菜单逐页说明。建议按以下顺序阅读：

1. **所有用户**：先读本章的[登录与账号](./login)、[界面介绍](./layout)、[工作台首页](./home)、[个人中心与消息](./profile)、[通用操作](./common)，掌握查询、新增、导出、打印等在所有页面都通用的操作。
2. **业务人员**：阅读[核心业务流程总览](./flows)，了解自己的工作在整条业务链中的位置，再进入所属模块的章节。
3. **系统管理员**：阅读[角色、权限与数据范围](./permission)以及[系统管理](../system/)、[系统监控](../monitor/)章节，完成用户、部门、角色和参数的初始化。
4. **遇到问题时**：先查看[常见问题](../faq/)。
