# 智能（AI）

智能模块（顶部导航「智能」）把大模型接入柠檬ERP，让业务人员用自然语言查数据、用图片和文件录单据、让 AI 帮忙检查主数据质量、自动撰写经营报告。所有 AI 功能都在用户自己的权限和数据权限范围内工作，**AI 只读取数据、给出结果或建议，不会自己保存单据或修改资料**——需要落地的内容都由用户核对后在原业务页面保存或逐条采纳。

::: tip 提示
顶部导航模块较多时，「智能」可能收在最右侧的「…」中。
:::

## 功能清单

| 菜单 | 解决什么问题 |
| --- | --- |
| [AI 问数](./chat) | 不用翻报表、不用记菜单，直接问「本月销售额是多少？和上月相比怎么样？」「库存低于安全库存的物料有哪些？」。AI 在提问人的权限范围内调用 40 多种查询（库存、订单、生产、质量、财务、人事、客户、项目、经营分析），用文字回答，并附上查询过程和数据表格 |
| [智能录入](./extract) | 供应商发来的报价单、客户的订货单、名片、营业执照、发票车票，不用再逐字抄录：上传图片 / PDF / Excel 或粘贴文字，AI 识别后打开采购订单、销售订单、供应商、客户、物料、费用报销的新增表单并填好，人工核对后保存 |
| [数据整理](./cleanse) | 物料、客户、供应商资料用久了会出现重复（「M3*10 螺丝」和「螺钉 M3×10」）、写法不统一、分类和单位缺失。AI 找出疑似重复并给出规范化建议，确认后一键采纳；Excel 导入时表头与模板不一致，也可以让 AI 对应字段 |
| [智能报告](./report) | 每周、每月自动汇总销售、采购、库存、生产、质量、财务、人事数据，由 AI 撰写包含概览、各板块要点、异常与风险、建议的经营报告；商务智能的经营预警可以一键「AI 分析」原因 |
| [AI 设置](./settings) | 管理员配置模型服务商、API Key、模型、每月用量上限，逐项开启各功能，查看本月用量 |

## 使用前提

AI 功能**默认全部关闭**。使用前需要：

1. **管理员完成 AI 设置**：在「智能 → [AI 设置](./settings)」中选择服务商、填写 API Key 和对话模型（智能录入要识别图片时还需要识图模型），打开「启用 AI」总开关，再逐项打开需要的功能（AI 问数、智能录入、数据整理、智能报告各有独立开关）。没有配置或没有开启时，对应页面显示「AI 问数尚未开启」等提示和「前往 AI 设置」按钮（没有 AI 设置权限的用户看到「请联系系统管理员开启」）。
2. **用户有相应菜单权限**：AI 功能的菜单需要在[角色管理](../system/role)中授权，见下文「权限」。
3. **用户有对应业务数据的权限**：AI 只能查询、录入、整理你本来就有权限的数据。例如没有「销售订单」查看权限的人问销售额，AI 会说明查不到；没有采购订单新增权限的人，智能录入中不会出现「采购订单」。
4. **SaaS 模式**：租户的套餐中要包含「智能（AI）」功能模块，每个租户单独配置自己的模型服务和开关。

### 权限

| 菜单 / 按钮 | 作用 | 内置角色 |
| --- | --- | --- |
| AI 问数 | 使用 AI 问数 | 总经理 |
| 智能录入 | 使用智能录入（还需要目标单据的新增权限，如总经理只能生成费用报销） | 总经理、采购员、销售员、会计 |
| 数据整理 | 发起整理任务、查看建议（还需要对应资料的查看权限） | 采购员、仓库管理员 |
| 数据整理 → 采纳整理建议 | 采纳、忽略建议（还需要对应资料的修改权限） | 采购员、仓库管理员 |
| 智能报告 | 查看报告 | 总经理 |
| 智能报告 → 生成报告 | 手动生成、删除报告 | 总经理 |
| AI 设置 | 查看 AI 设置和用量 | 超级管理员（SaaS 租户管理员按套餐获得） |
| AI 设置 → AI 设置修改 | 保存设置、测试连接 | 超级管理员 |

### 用量与月度上限

每次调用模型都会消耗 token（输入 + 输出），费用由模型服务商按 token 收取。管理员可以在 AI 设置中填写「每月 token 上限」：本月用量达到上限后，所有 AI 功能都会提示「本月 AI 用量已达上限（已用 … / 上限 … token），请联系管理员调整」，下个月自动恢复。AI 设置页右侧的「本月用量」按功能、按人员统计调用次数和 token。

## 数据安全

开启 AI 前请了解：**AI 功能会把业务数据发送给所配置的第三方模型服务处理**。AI 设置页顶部有醒目提示，打开总开关或任一功能时还会弹出确认框。

| 功能 | 发送给模型服务的内容 |
| --- | --- |
| AI 问数 | 提问内容、最近 20 条对话历史，以及 AI 调用查询得到的结果（编码、名称、数量、金额、日期、状态等精简字段，每次最多 200 行） |
| 智能录入 | 上传的图片、从 PDF 中提取的文字、Excel 表格内容（每个工作表最多 300 行）或粘贴的文字；以及用于匹配的选项（如费用科目的名称、物料分类的完整路径） |
| 数据整理 | 物料：编码、名称、规格、分类、单位、条码；客户 / 供应商：编码、名称、联系人、地址、税号（税号只用于查重）。不发送电话、邮箱、银行账号、信用额度 |
| 智能报告 | 各板块的汇总指标和前 5 名排行（如销售额、毛利率、客户排行、在职人数），不发送单据明细 |
| Excel 导入字段对应 | 表头和前 3 行样例（每格最多 50 字） |

系统在以下方面限制 AI 能接触的数据：

- **按用户权限和数据权限查询**：AI 问数只把提问人有权限的查询提供给模型，每次查询都按提问人的数据权限过滤（例如销售员只能查到自己的订单）；智能报告只汇总生成人有权限的板块。
- **不提供敏感数据**：查询结果不含密码、身份证号、电话、个人工资等字段。工资只能按部门汇总，人数少于 3 人的部门会合并，防止推算个人工资；人事报告只有人数，不含薪资。
- **汇总全公司的数据需要「全部数据」权限**：经营驾驶舱、ABC 分析、呆滞物料、销售预测等查询，以及采购、库存、生产、质量、财务、人事报告板块，只对数据权限为「全部数据」的用户提供。
- **API Key 只写不读**：保存后页面上只显示脱敏后的提示（如 `sk-****abcd`），不再显示原文，也不会出现在操作日志中。
- **上传的文件不保存**：智能录入的文件只在内存中处理，识别结束即丢弃；识别结果也只在当前浏览器页面中暂存，刷新后丢失。
- **回答安全渲染**：AI 回答中的图片、样式、表单不会显示，避免借图片地址向外发送数据。

系统中保存的 AI 相关数据：

| 内容 | 是否保存 | 谁能看到 |
| --- | --- | --- |
| AI 问数的对话 | 保存（直到用户自己删除） | 只有提问人本人，管理员也看不到别人的对话 |
| 智能录入上传的文件和识别结果 | 不保存 | — |
| 数据整理任务和建议 | 保存 | 有该数据类型查看权限的用户 |
| 智能报告 | 保存 | 手动生成的只有生成人能看；自动生成的只有「全部数据」权限的用户能看 |
| 预警的 AI 分析 | 不保存 | — |
| 用量记录（人员、功能、模型、token、时间） | 保存 | 有 AI 设置权限的用户 |

::: warning 注意
- AI 的回答、识别结果和报告都可能有误，重要数据请以业务单据和报表为准。
- 只向需要的角色开放 AI 菜单。特别是「智能报告」，自动报告包含全公司财务、人事等汇总数据，建议只授给管理层。
:::

## 支持的模型服务

柠檬ERP 通过 **OpenAI Chat Completions 兼容协议**接入国产大模型，「服务商」可选：

| 服务商 | 默认接口地址 | 对话模型示例 | 识图模型示例 |
| --- | --- | --- | --- |
| DeepSeek | `https://api.deepseek.com` | deepseek-chat | （无） |
| 通义千问（阿里云百炼） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | qwen-plus | qwen-vl-plus |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | glm-4-plus | glm-4v-plus |
| Kimi（月之暗面） | `https://api.moonshot.cn/v1` | kimi-k2-turbo-preview | moonshot-v1-8k-vision-preview |
| 豆包（火山方舟） | `https://ark.cn-beijing.volces.com/api/v3` | doubao-seed-1-6 | doubao-1-5-vision-pro-32k |
| 其他（兼容 OpenAI 协议） | 必须填写 | 如 qwen2.5-72b-instruct | 如 qwen2.5-vl-72b-instruct |

模型名称只是页面上的输入提示，实际以服务商控制台中开通的模型为准。「其他」用于私有化部署的模型或其他兼容 OpenAI 协议的服务。对话模型需要支持**函数调用（工具调用）**，否则 AI 问数无法查询数据。

## 典型使用流程

| 步骤 | 操作 | 页面 |
| --- | --- | --- |
| 1 | 管理员到服务商控制台创建 API Key，在 AI 设置中填写并「测试连接」，设置每月 token 上限，开启需要的功能 | [AI 设置](./settings) |
| 2 | 在[角色管理](../system/role)中把 AI 菜单授给需要的角色 | 系统管理 |
| 3 | 管理层随时提问经营数据 | [AI 问数](./chat) |
| 4 | 采购、销售、财务人员把收到的单据交给 AI 识别，核对后保存 | [智能录入](./extract) 或业务页面的「AI 识别」 |
| 5 | 资料管理员定期整理物料、客户、供应商资料 | [数据整理](./cleanse) |
| 6 | 每周一、每月 1 日查看自动生成的经营报告；发现预警时点「AI 分析」 | [智能报告](./report)、[决策支持](../bi/decision#预警的-ai-分析) |
| 7 | 管理员定期查看用量 | [AI 设置](./settings#本月用量) |
