# 智能报告

智能报告按周或按月汇总销售、采购、库存、生产、质量、财务、人事等板块的经营指标，由 AI 撰写一份经营报告：概览、各板块要点、异常与风险、建议。系统每周一、每月 1 日自动生成上周周报和上月月报，也可以随时手动生成。商务智能「决策支持」中的经营预警还可以一键「AI 分析」原因。

**AI 只读取汇总数据、撰写文字，不修改任何业务数据。**

## 页面入口

智能 → 智能报告

![智能报告](/images/manual/ai/report.jpg)

管理员还没有开启「智能报告」时，页面顶部显示黄色提示「智能报告尚未开启，目前只能查看已生成的报告」（有 AI 设置权限的用户右侧有「前往 AI 设置」），「生成报告」按钮不可用。

工具栏：「全部 / 周报 / 月报」筛选、「生成报告」（需要「生成报告」按钮权限）；右侧的问号图标说明自动生成规则和可见范围。

![自动生成说明](/images/manual/ai/report-help.jpg)

列表列：

| 列 | 说明 |
| --- | --- |
| 标题 | 如「周报（2026-10-26 ~ 2026-11-01）」「月报（2026-10）」，点击查看 |
| 类型 | 周报（蓝色）/ 月报（紫色） |
| 期间 | 起止日期 |
| 生成人 | 手动生成的显示生成人；定时生成的显示绿色「自动」标签（提示「定时任务自动生成，包含全公司数据」） |
| 数据来源 | 报告包含的板块，如「销售 / 采购 / 库存 / 财务」 |
| 状态 | 生成中（转圈）/ 已完成 / 失败（鼠标移上显示原因） |
| 用量 | 消耗的 token |
| 生成时间 | |
| 操作 | 「查看」；「删除」（需要「生成报告」权限，生成中的不能删除） |

有报告正在生成时，列表每 5 秒自动刷新。

## 报告类型与期间

| 类型 | 期间 | 对比 |
| --- | --- | --- |
| 周报 | 周一至周日 | 本期与上一周、去年同期对比 |
| 月报 | 自然月 | 本期与上月、去年同月对比 |

可以生成当前（尚未结束的）周或月的报告，但不能选择尚未开始的期间。

## 报告包含哪些数据

报告由多个板块组成，**每个板块需要相应的权限**，没有权限的板块不会出现在你生成的报告中：

| 板块 | 需要的权限 | 主要指标 |
| --- | --- | --- |
| 销售 | [多维分析](../bi/olap) | 销售额、成本、毛利、毛利率、出库单数、客户数，客户和物料分类排行。**按生成人的数据权限统计**，不是全公司口径时报告中会注明 |
| 采购 | 多维分析，需要「全部数据」 | 采购额，供应商和物料分类排行 |
| 库存 | 多维分析，需要「全部数据」 | 期末库存与上期末对比、分类排行，当前低于安全库存的物料数，呆滞物料 |
| 生产 | [生产工单](../mes/wo)，需要「全部数据」 | 下达、完工、按期完工率，报工合格与报废、工时，当前在制与延期工单 |
| 质量 | [质量分析](../qms/analysis)，需要「全部数据」 | 检验批数、合格率（总计与按检验类型）、不良类型排行 |
| 财务 | [财务报表](../fin/report)，需要「全部数据」 | 月报：收入、成本、营业利润、净利润（本月、上月、去年同月）；资金期初、收入、支出、期末；应收 / 应付余额、逾期、90 天以上、余额前 5 |
| 人事 | [员工档案](../hr/employee)，需要「全部数据」 | 期初 / 期末在职、入职、离职、离职率，试用期人数，各部门人数。**只有人数，不含薪资** |

- 每个板块只包含汇总值和前 5 名排行，以及本期、上期、去年同期的数据和已经算好的环比、同比。
- 销售、采购、库存板块来自商务智能的[数据仓库](../bi/etl)，最近一次同步早于期间结束日期时，报告会提示数据可能不完整。
- 某个板块取数失败时，只在该板块注明「该板块数据获取失败」，不影响其他板块。

## 手动生成

1. 点「**生成报告**」，打开「生成经营报告」对话框。
2. 「报告类型」选择周报或月报。
3. 「期间」选择周或月，默认上一个完整的周 / 月；下方显示「统计期间：…，与上期对比」。
4. 「将包含的数据」列出你有权限的板块（蓝色标签）；橙色的「销售（按数据权限）」表示只统计你数据权限范围内的数据，不是全公司口径。没有任何可用板块时提示「你没有可用的数据来源（需要商务智能、财务报表、生产、质量、人事等相应权限）」，不能生成。
5. 阅读底部说明：报告由 AI 根据上述数据的汇总值撰写，汇总数据会发送给所配置的模型服务。生成通常需要 30 秒到 2 分钟。
6. 点「生成报告」，提示「已开始生成，完成后可在列表中查看」。

报告在后台撰写，可以离开本页。同一个人同一期间的报告正在生成时，再次生成会提示「该期间的报告正在生成，请稍候」。生成超过 30 分钟仍未完成的视为中断，显示「生成过程被中断，请重新生成」。

## 自动生成

系统[定时任务](../monitor/job)中有两个任务：

| 任务 | 时间 | 内容 |
| --- | --- | --- |
| 智能报告-周报 | 每周一 7:00 | 生成上周（周一至周日）的周报 |
| 智能报告-月报 | 每月 1 日 7:30 | 生成上月的月报 |

- 只对在 AI 设置中开启了「智能报告」的公司生成；同一期间已经生成过的不重复生成。
- 自动报告以系统身份汇总**全公司全部板块**的数据，使用系统默认语言撰写。
- 生成成功后，向有「智能报告」权限的用户发送站内消息「…已生成」，点击打开该报告；消息本身不含报告数据。

## 谁能看到报告

| 报告 | 可见范围 |
| --- | --- |
| 手动生成的 | **只有生成人**（管理员也看不到别人生成的报告），内容按生成人的权限取数 |
| 自动生成的 | 包含全公司财务、人事等数据，**只有拥有「智能报告」权限且数据权限为「全部数据」的用户**能看到，其他人列表中看不到 |

因此「智能报告」菜单只应授给管理层角色（内置只给总经理）。删除报告需要「生成报告」权限，可以删除本人生成的报告和能看到的自动报告。

## 查看报告

点标题或「查看」打开报告详情：

- 顶部：类型、期间、生成人或「自动」、生成时间、消耗的 token，以及「数据来源：」标签。
- 生成中显示「正在撰写…」（AI 正在根据数据快照撰写报告，可以离开本页稍后查看），页面每 3 秒刷新；失败显示「生成失败」和原因。
- 已完成的报告先显示提示「报告由 AI 根据数据快照撰写，可能有误，重要数据请以业务报表为准」，下面是报告正文。
- 底部「**数据快照**」可展开，显示生成时使用的全部汇总数据（金额单位元），可用于核对报告中的数字。

报告正文的结构：

1. **概览**：3 ～ 5 条最重要的结论。
2. **各板块要点**：每个板块一个小标题（销售、采购、库存……），列出关键指标及与上期、去年同期的对比。
3. **异常与风险**：明显下滑、逾期、延期、呆滞、合格率下降、离职率上升等，写明依据的数字；没有时写「未发现明显异常」。
4. **建议**：3 ～ 5 条具体可执行的建议，与上面的问题对应。

AI 被要求**所有数字只能来自数据快照**，不得编造、估算或自行计算（增长率、占比等已在快照中算好）；快照中没有的写「暂无数据」；按数据权限统计的板块注明「按数据权限统计，非全公司口径」。

### 复制、下载与打印

已完成的报告右上角有三个按钮：

| 按钮 | 作用 |
| --- | --- |
| 复制 Markdown | 把报告标题和正文以 Markdown 格式复制到剪贴板，可粘贴到邮件、钉钉、企业微信或文档中 |
| 下载 | 下载为 `报告标题.md` 文件 |
| 打印 | 打开浏览器打印，可选择「另存为 PDF」 |

## 预警的 AI 分析

商务智能「[决策支持](../bi/decision#预警的-ai-分析)」的预警卡片上，在开启了智能报告时显示「**AI 分析**」。点击后弹出「AI 分析：规则名称」，显示「AI 正在分析预警原因…」，完成后给出：

- **结论**（一两句话）；
- **可能原因**：按可能性排序，每条写明依据的数据；
- **建议措施**：3 ～ 5 条；
- **需要核实**（可选）：数据不足以确定原因时列出需要核实的方向。

AI 参考的数据包括：预警规则与当前值、近期趋势（如近 6 个月毛利率）、相关明细（如呆滞物料前 10、超支的预算科目前 10），以及与预警相关、你有权限的报告板块近 30 天与前 30 天的数据（例如应收逾期参考财务、销售板块，工单延期参考生产、质量板块）。底部显示「参考数据：…」；没有可参考的板块时提示「没有可参考的相关板块数据（可能没有相应权限），只根据预警本身分析」。

分析结果不保存，页面打开期间再次点同一预警会显示上次结果，点「重新分析」重新生成。分析仅供参考，用量记在「智能报告」下。

## 注意事项

::: warning 注意
- 报告由 AI 撰写，可能有误，重要数据请以业务报表为准，可展开「数据快照」核对。
- 汇总数据会发送给所配置的模型服务。快照中只有汇总值和少量排行，不含单据明细和个人薪资。
- 报告每次生成都消耗 token（通常比问数多），月度上限较低时注意自动报告也会占用额度。
:::
