# AI 设置

AI 设置用于配置柠檬ERP 使用的大模型服务：选择服务商、填写 API Key 和模型、设置参数和每月用量上限，并逐项开启 AI 问数、智能录入、数据整理、智能报告。页面右侧显示本月用量。SaaS 模式下每个租户分别配置。

## 页面入口

智能 → AI 设置

![AI 设置](/images/manual/ai/settings.jpg)

页面顶部是黄色提示「业务数据会发送给所配置的第三方模型服务」：开启 AI 功能后，提问内容、查询到的业务数据、上传的单据会发送给所选的模型服务商处理。请确认符合公司的数据安全要求，并只向需要的角色开放相应菜单。

需要「AI 设置」菜单权限才能打开本页；只有同时拥有「AI 设置修改」按钮权限的用户可以编辑表单、「保存」和「测试连接」，其他人只能查看。内置角色中只有超级管理员有这两个权限。

## 模型服务

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 服务商 | 是 | DeepSeek（默认）、通义千问（阿里云百炼）、智谱 GLM、Kimi（月之暗面）、豆包（火山方舟）、其他（兼容 OpenAI 协议）。切换服务商时会清空已填写的接口地址，改用新服务商的默认地址 |
| API Key | 开启「启用 AI」时必填 | 在服务商控制台创建，只保存在服务器上，**保存后不会再显示**。已保存过时输入框显示「已设置（sk-****abcd），留空表示不修改」；要更换时直接输入新的 Key |
| 接口地址 | 服务商为「其他」时必填 | 兼容 OpenAI Chat Completions 协议的地址（不含 /chat/completions），留空使用服务商的默认地址（输入框中灰色显示）。误粘贴了完整的 `…/chat/completions` 地址时，保存时会自动去掉末尾部分。必须以 http:// 或 https:// 开头 |
| 对话模型 | 开启「启用 AI」时必填 | 用于问数、整理、报告（需支持函数调用），按服务商控制台中的模型名称填写，输入框中有该服务商的示例（如 deepseek-chat、qwen-plus） |
| 识图模型 | 否 | 用于识别图片中的单据，可留空。留空时[智能录入](./extract)只支持 PDF、Excel、文本，不能识别图片 |

各服务商的默认接口地址和模型示例见[支持的模型服务](./#支持的模型服务)。

::: tip 提示
- 对话模型一定要选支持函数调用（Function Calling / 工具调用）的模型，否则 AI 问数无法查询数据。
- DeepSeek 没有识图模型示例；需要识别图片时，可以选择提供视觉模型的服务商（如通义千问的 qwen-vl-plus）。识图模型和对话模型使用同一个服务商、同一个 API Key。
:::

::: warning 注意
SaaS 模式下，租户（平台租户除外）的接口地址不能指向内网或本机地址，否则提示「接口地址不能指向内网或本机地址」；域名无法解析时提示「无法解析接口地址的域名：…」。私有化部署的模型请由平台管理员配置或联系运维放开限制。
:::

## 参数

| 字段 | 说明 |
| --- | --- |
| 温度 | 0 ～ 2，默认 0.30。越低回答越稳定，查询数据建议 0 ～ 0.3 |
| 单次最大输出 token | 1 ～ 65536，留空由服务商决定。限制每次回答的长度；设得太小会导致报告、长回答被截断 |
| 每月 token 上限 | 输入 + 输出合计，达到后本月不能再调用，留空不限。用于控制费用 |

## 功能开关

![功能开关](/images/manual/ai/settings-features.jpg)

| 开关 | 说明 |
| --- | --- |
| 启用 AI | 总开关，关闭后所有 AI 功能不可用 |
| AI 问数 | 用自然语言提问，AI 在提问人的权限范围内查询业务数据并回答，见 [AI 问数](./chat) |
| 智能录入 | 上传图片、PDF、Excel，识别成采购订单等单据的草稿，核对后保存，见 [智能录入](./extract) |
| 数据整理 | 对物料、客户、供应商等主数据查重，给出名称、规格、分类的规范化建议，见 [数据整理](./cleanse)。Excel 导入时的「AI 对应字段」也归属这个开关 |
| 智能报告 | 按周、按月汇总经营指标，自动撰写经营报告，见 [智能报告](./report)。商务智能预警的「AI 分析」、定时生成周报月报也归属这个开关 |

- 四个功能开关默认关闭，要先打开「启用 AI」才能操作。
- 打开总开关或任一功能时弹出「确认开启？」对话框，红字提示「业务数据会发送给所配置的第三方模型服务」，并说明开启后该功能所需的业务数据会发送给所选服务商的模型服务处理，点「确认开启」才会打开。关闭开关不需要确认。
- 开关的变化要点「保存」后才生效。

![确认开启](/images/manual/ai/settings-confirm.jpg)

## 保存与测试连接

1. 填写服务商、API Key、对话模型等。
2. 点「测试连接」：用**表单中当前填写的配置**（API Key 留空时使用已保存的）向模型发送一个极短的连接测试请求，不需要先保存，也不要求已打开「启用 AI」。
3. 成功时显示绿色「连接成功」，包括「模型回复：…」和「模型 …，耗时 … ms，消耗 … token」；失败时显示红色「连接失败」和原因。
4. 打开「启用 AI」和需要的功能，点「保存」，提示保存成功。

测试连接会消耗少量 token，记在用量的「测试连接」下。

### 保存或测试时的提示

| 提示 | 处理 |
| --- | --- |
| 请填写 API Key / 请填写对话模型 | 开启「启用 AI」或测试连接时必须填写 |
| 自定义服务商需要填写接口地址 | 服务商为「其他」时填写接口地址 |
| 接口地址格式不正确，应以 http:// 或 https:// 开头 | 检查地址 |
| API Key 无效或没有权限，请检查 API Key 是否正确、是否已开通该模型 | 核对 API Key，或到服务商控制台开通该模型 |
| 模型服务的账户余额或额度不足，请到服务商控制台充值 | 到服务商控制台充值或领取额度 |
| 模型不存在或无权使用，请检查模型名称 | 模型名称以服务商控制台为准，注意大小写 |
| 接口地址不正确，未找到对话接口，请检查接口地址 | 一般是接口地址少了或多了路径（如 /v1） |
| 请求过于频繁，已被模型服务限流，请稍后再试 | 稍后再试，或在服务商处提高限额 |
| 模型服务响应超时 / 无法连接模型服务，请检查接口地址和服务器网络 | 检查服务器能否访问外网、接口地址是否正确 |

系统遇到限流、服务暂时不可用、网络连接失败时会自动重试（默认最多 2 次），仍失败才提示。

## 本月用量

页面右侧的「本月用量」卡片（右上角为月份）：

- **已用 token**：本月全部 AI 调用的输入 + 输出 token 合计；右侧显示「上限 …」或「不限」，设置了上限时下方有进度条，达到上限时进度条变红。
- **按功能**：AI 问数、智能录入、数据整理、智能报告、测试连接各自的调用次数和 token 合计。
- **按人员**：每个人的调用次数和 token 合计。

本月还没有调用时显示「本月还没有调用」。每次调用都会记录一条用量（调用失败但已产生消耗的也会记录）；部分服务商不返回用量时按字数估算。

::: tip 提示
系统在每次调用前检查本月合计是否已达上限，达到后提示「本月 AI 用量已达上限（已用 … / 上限 … token），请联系管理员调整」。最后一次调用可能使合计略微超过上限。需要继续使用时调高上限或清空（不限）后保存。
:::

## 注意事项

::: warning 注意
- API Key 相当于服务商账户的密码，泄露会产生费用。只在本页填写，不要通过聊天工具传递；怀疑泄露时到服务商控制台作废并重新创建，再在本页更新。
- 关闭「启用 AI」或某个功能后，相应页面立即提示未开启；已有的对话、整理建议、报告仍然保留。
- 更换服务商或模型后，建议先「测试连接」再保存。
:::
