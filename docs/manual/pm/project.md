# 项目列表

项目列表是项目管理的入口：新建项目、维护项目基本信息和合同金额，执行启动、暂停、恢复、完成、关闭等状态操作，并在项目详情中管理成员（角色、投入比例、小时成本），查看计划、工时、费用、收款和变更记录。

## 页面入口

项目 → 项目列表

![项目列表](/images/manual/pm/project-list.jpg)

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 项目 | 项目编号或名称 |
| 状态 | 规划中、立项审批中、进行中、已暂停、已完成、已关闭 |
| 类型 | 研发项目、交付实施、工程项目、内部改进 |
| 范围 | 勾选「只看我负责的」只显示自己是项目经理的项目（点「展开」显示） |

## 列表字段

| 列 | 说明 |
| --- | --- |
| 项目 | 项目名称（点击打开详情），下方为项目编号和优先级（高 / 中 / 低） |
| 类型 | 项目类型 |
| 客户 | 对外项目的客户；没有客户显示「内部项目」 |
| 项目经理 | |
| 状态 | |
| 进度 | 完工进度，由末级任务进度按计划工时加权汇总，见[计划进度](./plan) |
| 计划日期 | 计划开始 ~ 计划完成，下方为实际开始 ~ 实际完成 |
| 合同额 | 含税合同金额 |
| 实际成本 / 预算 | 实际成本 = 人工成本 + 费用；超过预算时显示为红色；未编制预算显示「未编制」 |
| 任务 | 已完成任务数 / 任务总数，有逾期任务时显示「逾期 N」 |

行操作：**详情**；**编辑**（已关闭的项目不显示）；状态操作按钮（见下文）；删除（仅规划中的项目）。列表支持导出。

## 新建 / 编辑项目

点击「**新建项目**」。

![新建项目](/images/manual/pm/project-add.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 项目编号 | 是 | 只能包含字母、数字、下划线和短横线，最长 32 位，不能重复，如 PRJ-2026-001 |
| 项目名称 | 是 | 最长 128 字 |
| 项目类型 | 是 | 默认「交付实施」 |
| 优先级 | 否 | 默认「中」 |
| 项目经理 | 否 | 不填为当前用户；项目经理自动加入项目成员（角色为项目经理），负责部门取项目经理的部门 |
| 客户 | 否 | 对外项目填写，开票时生成该客户的[应收单](../fin/ar-ap) |
| 计划开始、计划完成 | 是 | 计划完成不能早于计划开始 |
| 合同金额（含税） | 否 | 默认 0，用于确认收入 |
| 税率 | 否 | 默认 6%，用于计算不含税合同额和开票税额 |
| 关联销售订单 | — | 从销售订单「创建项目」时显示，不可修改 |
| 超预算控制 | 否 | 勾选后，费用、领料超过成本预算（有分类预算时按分类）时不能录入 |
| 项目说明 | 否 | 最长 1000 字 |

成本预算不在此处填写，请到[成本控制](./cost)中「编制预算」。

### 从商机、销售订单创建项目

- [销售机会](../crm/opportunity)赢单后，在商机详情点击「**创建项目**」，自动打开新建项目表单并带入项目名称、客户、合同金额。
- 在供应链的[销售订单](../scm/sales#订单详情)详情中点击「**创建项目**」，带入客户、合同金额和关联销售订单。一张销售订单只能关联一个项目，重复关联会提示「销售订单 XXX 已关联项目」。

## 项目状态与流转

| 当前状态 | 可用操作 | 结果 |
| --- | --- | --- |
| 规划中 | **启动** | 进入进行中，记录实际开始日期；发布了「项目立项审批」流程时进入「立项审批中」 |
| 立项审批中 | — | 审批通过进入进行中（记录实际开始日期），拒绝或撤回回到规划中 |
| 进行中 | **暂停**、**完成** | 暂停后不能更新任务进度和领料；完成时记录实际完成日期 |
| 已暂停 | **恢复** | 回到进行中 |
| 已完成 | **关闭** | 关闭后项目不能再修改 |
| 已关闭 | — | |

每个操作都有确认提示。以下情况不能执行：

- 项目还有**待审批的工时**时，不能完成或关闭（提示先审批或驳回）。
- 项目还有**未开票的收款计划**时，不能完成（提示先开票或删除）。

### 立项审批

系统内置「项目立项审批」流程（默认未发布）：部门主管 → 会计（预算评审）→ 合同金额 ≥ 50 万元时总经理。在[流程设计](../workflow/designer)中调整审批人并发布后，规划中的项目点击「启动」会提交立项审批，提示「已提交立项审批，审批通过后项目进入进行中」。设计条件分支时可用的变量：合同金额、成本预算、项目类型、项目编号。

### 删除项目

只能删除**规划中**、且没有工时、费用和已开票收款计划的项目。删除时一并删除其任务、成员、预算和收款计划。

## 项目详情

点击项目名称或「**详情**」。

![项目详情](/images/manual/pm/project-detail.jpg)

上方为基本信息（类型、状态、优先级、客户、销售订单、预算控制、项目经理、负责部门、计划日期、实际日期、合同金额与税率、说明），以及三个概况卡片：

| 卡片 | 内容 |
| --- | --- |
| 完工进度 / 计划进度 | 完工进度条和按日期计算的计划进度条 |
| 实际成本 / 预算 | 实际成本（超预算红色）、人工与费用构成 |
| 已确认收入 / 毛利 | 按完工百分比确认的收入和毛利，SPI、CPI 指标，已收款 |

页签：

| 页签 | 内容 |
| --- | --- |
| 成员 | 见下文 |
| 计划 | 项目任务的甘特图 |
| 工时 | 项目的工时记录：日期、成员、任务、工时、工作内容、状态、人工成本（需要工时查看权限） |
| 费用 | 项目的费用记录：日期、类型、金额、说明、录入人（需要成本或核算查看权限） |
| 收款 | 收款计划：款项、里程碑、计划日期、金额、状态、应收单与已收金额 |
| 附件 | 项目文档 |
| 变更记录 | 项目名称、类型、客户、项目经理、优先级、计划日期、合同金额、税率、成本预算等字段的修改历史 |

### 成员与投入比例

在「成员」页签点击「**添加成员**」（需要成员维护权限，已关闭的项目不能添加）。

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 成员 | 是 | 选择用户，同一用户不能重复加入 |
| 项目角色 | 是 | 项目经理、开发、测试、实施、工程师、顾问 |
| 投入比例 | 是 | 1–100%，表示该成员在本项目投入的工作时间比例，用于[资源分配](./resource)统计负荷 |
| 小时成本 | 否 | 审批工时时按此计算人工成本。不填时按人力资源[薪资档案](../hr/salary)自动计算 |
| 加入日期、退出日期 | 否 | 退出日期不能早于加入日期；已退出的成员不计入资源负荷 |

成员列表显示成员、角色、投入、小时成本、已审批工时、参与期间。

**小时成本的计算**：不手工填写时，取员工薪资档案的月人工成本（基本工资 + 岗位津贴 + 其他津贴 + 单位承担的社保公积金）÷ 每月计薪小时（人力资源[业务参数](../system/biz-rule#人力资源)的月计薪天数 × 每日工时，默认 21.75 天 × 8 小时 = 174 小时）。每次审批工时时按最新的薪资档案重新折算；手工指定的小时成本保持不变。账号没有关联员工或没有薪资档案时为 0。

::: warning 注意
- 项目经理不能移除。
- 已填报工时的成员不能移除，可以设置退出日期。
- 员工离职时，其在各项目的投入比例自动清零；[办理离职](../hr/employee#人事异动)指定了交接人时，其担任项目经理的项目和未完成的任务转给交接人。
:::
