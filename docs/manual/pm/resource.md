# 资源分配

资源分配按人汇总每个成员在各项目中的投入比例，帮助项目经理和部门负责人发现超负荷（投入超过 100%）的人员，合理安排人力；同时统计每人剩余的任务工时。

## 页面入口

项目 → 资源分配

![资源分配](/images/manual/pm/resource.jpg)

## 页面说明

- 顶部可按**部门**筛选（默认全部部门），右侧为刷新按钮。
- 横向柱状图展示每个成员的投入比例合计，橙色虚线为 100%，超过 100% 的柱子显示为红色。
- 下方表格：

| 列 | 说明 |
| --- | --- |
| 成员 | 姓名和部门 |
| 投入比例 | 该成员在各项目投入比例的合计；超过 100% 时进度条为红色并显示「超负荷」标签 |
| 剩余任务工时 | 该成员负责的未完成任务的剩余工时 |
| 参与项目 | 每个项目一个标签：项目编号、名称、角色、投入比例；已退出的项目显示为灰色 |

列表按投入比例从高到低排序。

## 统计口径

- 只统计**规划中**和**进行中**项目的成员。
- 投入比例合计**不含已退出**（退出日期早于今天）的项目。
- 剩余任务工时 = 未完成任务的计划工时 ×（1 − 进度）之和。

## 如何调整

投入比例在[项目列表](./project)的项目详情「成员」页签中修改；[员工离职](../hr/employee#人事异动)时其投入比例自动清零。
