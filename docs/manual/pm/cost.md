# 成本控制

成本控制用于按成本类型编制项目预算，录入差旅、外包等费用，办理项目领料，并对比预算与实际、查看按月成本趋势。项目的实际成本由三部分组成：审批通过的工时（人工）、手工录入的费用、项目领料（材料）。

## 页面入口

项目 → 成本控制

![成本控制](/images/manual/pm/cost.jpg)

## 页面说明

顶部选择项目（与计划进度共用上次的选择），显示项目状态、成本预算、实际成本（超预算为红色）和执行率。右侧按钮：

| 按钮 | 可用条件 | 作用 |
| --- | --- | --- |
| **编制预算** | 项目未关闭 | 按成本类型编制预算 |
| **项目领料** | 项目进行中 | 从仓库领用材料，计入材料成本 |
| **录入费用** | 项目未完成、未关闭 | 手工录入费用 |

页面主体：

| 区块 | 内容 |
| --- | --- |
| 预算与实际 | 按成本类型列出预算、实际、差异（超支为红色）、执行率；没有预算但有实际发生的显示「无预算」 |
| 预算与实际对比 | 柱状图，超支的实际柱为红色 |
| 按月成本 | 每月人工和费用的堆叠柱状图 |
| 费用明细 | 手工费用和领料成本的明细，可按类型、日期筛选 |

### 成本类型

| 类型 | 来源 |
| --- | --- |
| 人工 | 审批通过的工时 × 小时成本，不能手工录入，不在费用明细中列出 |
| 材料 | 项目领料，或手工录入 |
| 差旅、外包、设备、其他 | 手工录入 |

## 编制预算

1. 点击「**编制预算**」，弹窗按成本类型逐项填写预算金额。
2. 底部显示合计，确定后保存。项目的**成本预算 = 各类预算合计**，在项目列表、项目核算和挣值分析中使用。

## 录入费用

点击「**录入费用**」。

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 成本类型 | 是 | 不能选择人工，默认差旅 |
| 发生日期 | 是 | 默认今天 |
| 金额（不含税） | 是 | 大于 0 |
| 说明 | 否 | 最长 255 字 |

- 系统内置「**项目费用审批**」流程（默认未发布）：部门主管 → 金额 ≥ 2 万元时总经理 → 抄送会计。[发布](../workflow/model#发布与版本)后，录入的费用处于审批中，审批通过才计入项目成本，拒绝或撤回后为已拒绝。费用明细的「来源」列会显示审批状态。未发布流程时录入即计入成本。

## 项目领料

点击「**项目领料**」打开领料页面。

![项目领料](/images/manual/pm/cost-issue.jpg)

1. 选择**仓库**（必填）、**业务日期**（必填，默认今天），可填写备注。
2. 点击「**添加物料**」，逐行选择物料、库位 / 批次（显示可用数量）、领用数量；启用[序列号](../wms/trace#序列号追踪)管理的物料需录入序列号。
3. 点击「**确认领料**」。

系统生成并直接确认一张「项目领料」[出库单](../wms/out)（来源单号为项目编号），扣减库存；按物料单位成本（最近一期[成本核算](../fin/cost)单价，没有时取采购均价）计算金额，作为「材料」成本记入费用明细，来源显示「领料 出库单号」。

::: tip 提示
领料生成的成本不能在此删除；需要退料时到仓库办理退料。
:::

## 超预算控制

项目开启了「超预算控制」（在新建 / 编辑项目时勾选）时，录入费用和领料会检查预算：

- 该成本类型编制了预算的，已发生 + 本次不能超过该类预算，提示「超出项目「类型」类预算」；
- 该类型没有预算的，已发生 + 本次不能超过项目成本预算合计，提示「超出项目成本预算」；
- 项目没有编制任何预算的不控制。

## 删除费用

费用明细中只有**手工录入**的费用可以删除（需要费用删除权限）。审批中的费用需先在「[我的申请](../workflow/mine#撤回申请)」中撤回；已在项目月结中入账的费用不能删除，需要先删除月结凭证。

## 与其他模块的联动

| 动作 | 联动结果 |
| --- | --- |
| 项目领料 | 仓库生成「项目领料」[出库单](../wms/out)并扣减库存 |
| 费用、人工 | 计入项目实际成本，用于[项目核算](./accounting)的毛利和挣值分析 |
| 项目月结 | 已审批的手工费用 借 合同履约成本 / 贷 其他应付款 |
