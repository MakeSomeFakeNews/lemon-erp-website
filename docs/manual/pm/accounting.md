# 项目核算

项目核算汇总每个项目的收入、成本、毛利和挣值指标：收入按**完工百分比法**确认，成本来自工时和费用；通过**收款计划**管理分期开票，开票时为客户生成[应收单](../fin/ar-ap)；每月执行**项目月结**，把项目的人工、费用、收入确认和成本结转生成[凭证](../fin/voucher#业务生成的凭证)入总账。

## 页面入口

项目 → 项目核算

![项目核算列表](/images/manual/pm/accounting-list.jpg)

## 列表

查询条件：项目（编号或名称）、状态。列表按项目的数据权限过滤，支持导出。

| 列 | 说明 |
| --- | --- |
| 项目 | 项目名称（点击打开核算详情），下方为编号和客户（无客户显示「内部项目」） |
| 状态 | 项目状态 |
| 完工进度 | 完工进度条，下方为计划进度 |
| 合同额 | 含税合同金额，下方为不含税金额 |
| 已确认收入 | 不含税合同额 × 完工进度 |
| 实际成本 | 人工 + 费用（含领料），超过预算为红色；下方为预算 |
| 毛利 / 毛利率 | 毛利为负显示为红色 |
| 已开票 / 已收款 | 收款计划已开票金额和应收单已核销金额 |
| SPI、CPI | 进度绩效指数、成本绩效指数，≥ 1 绿色，< 1 红色 |
| 完工估算 EAC | |

工具栏「**项目月结**」见下文；行操作「**核算**」打开核算详情。

## 核算指标

| 指标 | 计算方式 |
| --- | --- |
| 不含税合同额 | 合同金额 × 100 ÷（100 + 税率） |
| 完工进度 | 末级任务进度按计划工时加权，见[计划进度](./plan#自动汇总规则) |
| 已确认收入 | 不含税合同额 × 完工进度（完工百分比法） |
| 实际成本 | 已审批工时的人工成本 + 已审批的费用（含领料） |
| 毛利 | 已确认收入 − 实际成本 |
| 毛利率 | 毛利 ÷ 已确认收入 |

### 挣值分析指标含义

| 指标 | 名称 | 计算方式 | 含义 |
| --- | --- | --- | --- |
| BAC | 完工预算 | 项目成本预算 | 计划花多少钱完成整个项目 |
| 计划进度 | — | 计划开始至今已过天数 ÷ 计划工期（0–100%）；已完成、已关闭的项目为 100% | 按日期到今天应完成的比例 |
| PV | 计划价值 | 预算 × 计划进度 | 到今天按计划应完成的工作量（以预算计） |
| EV | 挣值 | 预算 × 完工进度 | 实际已完成的工作量（以预算计） |
| AC | 实际成本 | 人工 + 费用 | 实际已花费 |
| SPI | 进度绩效指数 | EV ÷ PV | ≥ 1 进度超前或正常，< 1 进度落后 |
| CPI | 成本绩效指数 | EV ÷ AC | ≥ 1 成本节约或正常，< 1 成本超支 |
| EAC | 完工估算 | 预算 ÷ CPI | 按当前成本效率，完成整个项目预计的总成本 |

没有编制预算时 PV、EV 为 0，相关指标显示「-」；还没有实际成本时 CPI、EAC 显示「-」。

## 核算详情

点击项目名称或「**核算**」。

![项目核算详情](/images/manual/pm/accounting-detail.jpg)

- **统计卡片**：完工进度 / 计划进度（落后时醒目显示）、已确认收入（含不含税合同额）、实际成本（人工、费用构成）、毛利 / 毛利率、成本预算、合同金额（含税）、已开票、已收款（含应收余额）。
- **挣值分析**：柱状图对比预算 BAC、计划价值 PV、挣值 EV、实际成本 AC，下方显示 SPI、CPI 和 EAC。
- **按月成本**：每月人工和费用的堆叠柱状图。
- **收款计划**：见下文。
- **项目月结（入总账）**：各期月结记录：期间、人工入账、费用入账、完工进度、确认收入、结转成本、凭证号。

## 收款计划与开票

### 新增款项

在「收款计划」区域点击「**新增款项**」（需要收款计划维护权限，已关闭的项目不能新增）。

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 款项名称 | 是 | 如预付款、验收款，最长 64 字 |
| 关联里程碑 | 否 | 从项目的里程碑任务中选择；关联后里程碑完成才能开票 |
| 计划开票日期 | 是 | |
| 金额（含税） | 是 | 大于 0 |
| 备注 | 否 | |

收款计划列表：款项（关联里程碑带旗帜标记）、计划日期、金额、状态（待开票 / 已开票）、应收单与收款进度。待开票的款项可以编辑、删除；已开票的不能修改、删除。

### 开票

1. 在待开票的款项上点击「**开票**」（需要开票生成应收权限）。
2. 确认客户和金额，选择**开票日期**（默认今天），确定。
3. 系统为项目客户生成应收单：来源「项目开票」，金额为款项金额，税额按项目税率计算。款项变为「已开票」，显示应收单号。

开票条件：

- 项目必须有客户，否则提示「项目没有客户，不能开票」。
- 关联了里程碑的，里程碑必须已完成，否则提示「关联的里程碑「XXX」尚未完成，不能开票」。

开票后在财务的「[应收管理](../fin/ar-ap#生成凭证)」中生成凭证（计入合同负债），在「[收款单](../fin/settlement#核销规则)」中收款核销；核销金额回写为已收款，显示在收款进度中。

### 取消开票

已开票的款项可点击「**取消开票**」：删除生成的应收单，款项回到待开票。应收单**已收款核销或已生成凭证**的不能取消。

::: warning 注意
项目还有未开票的收款计划时不能完成项目。
:::

## 项目月结

每月末点击工具栏的「**项目月结**」（需要项目月结权限），选择月结期间后确定。系统按项目生成凭证（未审核）：

| 内容 | 分录 | 说明 |
| --- | --- | --- |
| 人工 | 借 合同履约成本 / 贷 员工岗位类别对应的薪酬费用科目 | 已审批工时的人工成本（[工资计提](../hr/payroll#确认)时已计入费用，这里转入项目成本） |
| 费用 | 借 合同履约成本 / 贷 其他应付款 | 已审批的手工费用（报销、付款时冲销）；领料成本由[成本核算](../fin/cost)计入 |
| 收入确认 | 借 合同负债 / 贷 主营业务收入 | 有合同金额的项目按完工进度确认收入的增量 |
| 成本结转 | 借 主营业务成本 / 贷 合同履约成本 | 按累计实际成本结转的增量 |

- 分录带项目辅助核算和项目部门（计入部门[预算执行](../fin/budget#执行分析)）。
- 每次只处理**未入账**的工时、费用和收入、成本的增量；没有需要入账的内容时提示「没有需要入账的工时、费用或收入」。
- 删除月结凭证后，相应工时、费用恢复为未入账，可以重新月结。
- 已入账的工时、费用不能删除或撤销，需先删除月结凭证。
