# 供应商与经销商门户

柠檬ERP 内置两个面向外部伙伴的门户，伙伴使用专属账号登录同一个系统，但只能看到并操作与自己相关的数据：

| 门户 | 使用者 | 主要功能 |
| --- | --- | --- |
| [供应商门户](./supplier) | 供应商的业务人员 | 确认采购订单（承诺交期）、发起送货通知、确认对账单并填写发票、在线投标、查看质量索赔 |
| [经销商门户](./dealer) | 经销商（销售渠道为「经销商」的客户） | 按价目表在线订货（自动应用促销、可抵扣返利）、查看订单进度、按月上报渠道库存和销量 |

门户账号由本公司的管理员或采购 / 销售人员在供应商、客户资料中开通，见 [开通门户账号](./account)。

## 功能清单

- [开通门户账号](./account)：管理员如何为供应商、经销商开通、停用账号和重置密码。
- [供应商门户](./supplier)：我的订单、送货通知、对账单、招标投标、质量索赔。
- [经销商门户](./dealer)：我要订货、库存销量上报。

## 典型协作流程

### 与供应商协作

1. 采购员审核 [采购订单](../scm/purchase)，系统给供应商的门户账号发送「新采购订单待确认」消息。
2. 供应商在门户「我的订单」中接受订单并填写承诺交期（或拒绝并说明原因），结果通知采购员。
3. 供应商发货时在门户「发起送货」，填写发货日期、预计到货、物流单号和送货数量；仓库收到「供应商送货通知」消息。
4. 仓库在 [送货通知](../scm/asn) 中按实收数量收货，自动生成[采购入库](../scm/purchase-in)单和[应付单](../fin/ar-ap)。
5. 财务在「[供应商对账](../fin/statement)」中生成并发送对账单，供应商在门户确认对账或提出异议，填写发票、上传扫描件。
6. [招标](../scm/tender)时，供应商收到「招标邀请」消息，在门户投标；定标后中标供应商收到「中标通知」。
7. 质量部门确认的[供应商质量索赔](../qms/claim)，供应商在门户可以看到，索赔金额冲减应付并体现在对账单中。

### 与经销商协作

1. 销售为经销商客户设置[价目表](../scm/price-list)、[促销活动](../scm/promotion)和[返利协议](../scm/rebate)。
2. 经销商在门户「我要订货」，提交后生成来源为「经销商订货」的[销售订单](../scm/sales)草稿，记到负责销售名下，并通知有审核权限的人员。
3. 销售审核订单后正常发货出库，经销商在门户查看订单状态和已发货数量。
4. 经销商每月在门户上报各产品的当月销量和月末库存，销售在 [渠道库存](../scm/channel) 中查看库存可售月数。

## 数据隔离与安全

- 门户账号与一个供应商或一个客户绑定，所有门户数据都按账号绑定的供应商 / 客户读取，**看不到其他供应商、其他经销商的任何数据**，例如招标中看不到其他供应商的报价，只能看到自己是否中标。
- 门户账号只拥有门户权限：即使在[角色管理](../system/role)中给它分配了其他角色，也只保留门户相关的权限；登录后顶部导航只有「供应商门户」或「经销商门户」，只能使用门户、个人中心、站内消息等公共功能。
- 公司内部用户看不到门户菜单。
- 账号停用、重置密码后，已登录的会话立即下线。

## 相关角色

| 角色 | 说明 |
| --- | --- |
| 供应商（内置角色） | 门户账号自动分配，拥有订单确认、发起送货、对账确认、提交投标、查看索赔的权限 |
| 经销商（内置角色） | 门户账号自动分配，拥有订货、上报的权限 |
| 采购 / 销售人员 | 在供应商、客户资料中开通门户账号（需要「门户账号」按钮权限） |
