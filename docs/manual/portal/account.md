# 开通门户账号

供应商、经销商的门户账号在本公司系统中开通，不需要到[用户管理](../system/user)中单独创建。开通的账号自动关联对应的供应商或客户，并只分配内置的「供应商」或「经销商」角色。

需要的权限：供应商门户账号需要「供应商 - 门户账号」按钮权限，经销商门户账号需要「客户 - 门户账号」按钮权限，可在系统管理的「[角色管理](../system/role)」中给采购、销售主管授权。

## 为供应商开通

1. 进入 供应链 → 往来单位 → [供应商](../scm/supplier)。
2. 在供应商所在行点「门户账号」，打开「供应商门户账号 - 供应商名称」窗口。
3. 窗口上方列出该供应商已有的账号：账号、联系人、手机号、状态开关、「重置密码」。
4. 在「开通账号」中填写：

   | 字段 | 必填 | 说明 |
   | --- | --- | --- |
   | 登录账号 | 是 | 最多 64 位，不能与系统中已有的用户名重复 |
   | 初始密码 | 是 | 须符合系统的[密码策略](../system/config#密码策略)（长度、复杂度在系统参数中设置）；首次登录后提示修改 |
   | 联系人 | 是 | 默认带出供应商资料中的联系人 |
   | 手机号 | 否 | 默认带出供应商的联系电话 |

5. 点「开通」，提示「已开通」。

![供应商门户账号](/images/manual/portal/supplier-account.jpg)

一个供应商可以开通多个账号（例如业务员、财务各一个），每个账号都能看到该供应商的全部门户数据，都会收到门户消息。

## 为经销商开通

1. 先在 [客户](../scm/customer) 中把客户的「销售渠道」设为「经销商」，并填写负责销售、授权区域。只有渠道为经销商的客户才显示「门户账号」按钮，否则提示「只有渠道为「经销商」的客户才能开通经销商门户」。
2. 在客户所在行点「门户账号」，打开「经销商门户账号 - 客户名称」窗口。
3. 填写登录账号、初始密码、联系人、手机号，点「开通」。

![经销商门户账号](/images/manual/portal/dealer-account.jpg)

## 停用与重置密码

- **停用 / 启用**：在账号列表中切换状态开关。停用后该账号立即下线，不能再登录。
- **重置密码**：点「重置密码」，输入新密码后确定，提示「已重置，原登录会话已下线」。对方下次登录后提示修改密码。

## 伙伴如何登录

把以下信息告知供应商或经销商：

1. 系统访问地址（与公司内部用户相同）。
2. 登录账号和初始密码。
3. SaaS 模式下还需填写 **租户名称**，与本公司的租户名称相同。

登录后，供应商的顶部导航只有「供应商门户」，经销商只有「经销商门户」。首次登录会提示修改初始密码。密码连续输错多次后需要输入验证码，超过次数会被锁定，可由管理员重置密码解锁。

## 注意事项

::: warning 注意
门户账号只能在供应商、客户资料中开通。不要在「用户管理」中把普通用户关联到供应商或客户，也不要给门户账号分配内部角色——即使分配了，门户账号也只保留门户权限。
:::

::: tip 提示
门户消息（新采购订单待确认、招标邀请、中标通知、对账单待确认、质量索赔等）发送给该供应商的全部启用账号，供应商可以在右上角消息中心查看。
:::
