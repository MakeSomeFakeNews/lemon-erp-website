# 经销商门户

经销商门户供经销商使用（销售渠道为「经销商」的客户）。经销商用门户账号登录后，顶部导航只有「经销商门户」，左侧菜单为：我要订货、库存销量上报。所有页面只显示本经销商的数据。

账号的开通方法见 [开通门户账号](./account)。

## 我要订货

页面列出本经销商在门户下的订单，提示「订单提交后由销售审核，审核前可以撤销」。

**列表列**：订单号（下方为下单日期）、数量、金额（有促销优惠或返利抵扣时下方显示「优惠 ¥…」）、期望交货、状态、操作「查看」。

### 下单

1. 点右上角「我要订货」，打开订货页面，提示「价格按[价目表](../scm/price-list)（起订数量越大价格越低），提交时自动应用促销活动」。
2. 可订货清单列出价目表中 **当天有效、适用本经销商客户等级** 的物料：物料、价格（基础价「¥单价 / 单位」，下方列出阶梯价，如「满 100 块：¥245.00」）、订货数量、金额。可按物料编码或名称搜索。
3. 在需要的物料行填写 **订货数量**，金额按满足数量的最高一档单价计算。
4. 在下方填写：
   - **期望交货日期**（选填）；
   - **使用[返利](../scm/rebate)**（有返利余额时显示，提示「返利余额 ¥…」，不超过余额和订单金额）；
   - **备注**。
5. 底部显示「按价目价合计 ¥…（促销优惠以提交后的订单为准）」。点右上角「提交订单（N 种）」，提示「订单已提交，等待销售审核」。

提交后系统：

- 按价目表取价，不在可订货清单中的物料不能订购；
- 生成来源为「经销商订货」的[销售订单](../scm/sales)草稿，自动应用当前的 [促销活动](../scm/promotion)（折扣、满减、买赠赠品），扣减使用的返利；
- 订单记到客户资料中「负责销售」名下，并给有销售订单审核权限的人员发送「经销商订货待审核」消息。

### 订单详情与撤销

详情显示下单日期、期望交货、状态、金额、促销优惠、返利抵扣、备注，以及明细（物料、数量、单价、金额、已发货数量；赠品带「赠品」标签）。

订单还是草稿（销售尚未审核）时，右上角有「撤销订单」，确认后删除该订单。审核后不能撤销，如需修改请联系负责销售。

销售审核、出库后，经销商可以在这里跟踪订单状态（已审核、部分完成、已完成）和已发货数量。

## 库存销量上报

经销商每月上报各产品的 **当月销量**（卖给终端客户的数量）和 **月末库存**，页面提示「每月上报各产品的当月销量（卖给终端客户）和月末库存，同一月份重复上报会覆盖」。

**列表列**：月份、产品数、当月销量、月末库存、说明、上报时间和人。

**上报步骤**：

1. 点「上报」，打开「库存销量上报 月份」页面。
2. 选择 **月份**（不能选以后的月份）；切换月份时自动带出该月已上报的数据。
3. 填写说明（选填）。
4. 产品清单为可订货的产品（以前上报过、现在不在清单中的产品也保留），逐个填写当月销量、月末库存。只上报填写了销量或库存的产品。
5. 点「提交上报」，提示「已上报」。至少要填写一个产品，否则提示「请填写至少一个产品的销量或库存」。

本公司销售人员在 [渠道库存](../scm/channel) 中查看各经销商的上报和库存可售月数。

## 常见问题

**可订货清单是空的？** 本公司还没有为您的客户等级维护当天有效的销售价目表，请联系负责销售。

**提交的订单金额和订货页面显示的不一样？** 订货页面按价目价计算，提交时系统自动应用促销活动、扣减返利，以订单详情中的金额为准。
