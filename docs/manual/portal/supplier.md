# 供应商门户

供应商门户供供应商的业务人员使用。供应商用本公司开通的门户账号登录后，顶部导航只有「供应商门户」，左侧菜单为：我的订单、送货通知、对账单、招标投标、质量索赔。所有页面只显示本供应商的数据。

账号的开通方法见 [开通门户账号](./account)。

## 我的订单

显示本公司发给本供应商的、已审核的[采购订单](../scm/purchase)。供应商在这里确认订单、承诺交期，并按订单发起送货。

**列表**：顶部切换「待确认」/「全部订单」，可按订单号、物料搜索。

| 列 | 说明 |
| --- | --- |
| 订单号 | 引用了[采购合同](../scm/contract)时下方显示合同号 |
| 订单日期、要求交货 | |
| 金额 | 价税合计 |
| 收货进度 | 进度条和「已收货 X / 订单数量」 |
| 确认 | 已接受（下方显示「承诺 日期」）/ 已拒绝 / 「待确认」 |
| 状态 | 订单状态 |
| 操作 | 未确认且可执行的订单显示「确认」，其他显示「查看」 |

**订单详情**：订单日期、要求交货、状态、收货仓库、价税合计、采购员、确认结果、采购合同、备注，以及明细（物料、数量、已收货、单价（含税）、金额、交货日期）。

订单为已审核、部分完成时，右上角有：

| 按钮 | 作用 |
| --- | --- |
| 接受订单 / 重新确认 | 填写 **承诺交期**（必填）和说明，提示「已接受订单」 |
| 拒绝 | 填写 **拒绝原因**（必填），提示「已拒绝订单」 |
| 发起送货 | 订单未被拒绝时显示，见下文 |

确认结果会以站内消息通知订单的制单人，并显示在采购方的订单详情中。订单完成、关闭后不能再确认；在订单入库完成前可以重新确认（例如修改承诺交期）。

### 发起送货

在订单详情点「发起送货」，打开「发起送货 - 订单号」页面：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 发货日期 | 是 | |
| 预计到货 | 否 | |
| 承运商、运单号 | 否 | |
| 备注 | 否 | |

明细列出每个物料的「可送货」数量（未收货且未通知的数量），填写「本次送货」数量（不超过可送货）和「批次号」（批次管理的物料必填）。点「提交送货通知」，提示「已提交送货通知，仓库将按通知收货」。订单已全部送货或收货时提示「订单已全部送货或收货」。

提交后，采购方有收货权限的人员收到「供应商送货通知」消息。

## 送货通知

列出本供应商提交的送货通知，提示「在「我的订单」中按订单发起送货」。

**筛选**：状态（待收货 / 已收货 / 已取消）、关键字（送货单号、订单号、运单号）。

**列表列**：送货单号（下方为订单号）、发货日期、预计到货、物流、数量、状态。

**操作**：「查看」；待收货的可「取消」（确认「取消该送货通知？」）。

详情显示采购订单、状态、收货时间、发货日期、预计到货、物流，以及明细（物料、批次、送货数量）。采购方收货后状态变为「已收货」。

## 对账单

本公司财务按期间汇总与本供应商的[应付单](../fin/ar-ap)（采购入库、退货、质量索赔等）生成[对账单](../fin/statement)并发送后，供应商在这里确认。收到对账单时会有「对账单待确认」消息。

**筛选**：状态（待确认 / 已确认 / 有异议）。

**列表列**：对账单号、对账期间、对账金额（下方为单据笔数）、发票、状态；待确认的显示「确认」，其他显示「查看」。

**详情**：对账期间、对账金额、状态、发票信息、确认时间、我方意见，对账明细，以及「发票及附件（可上传发票扫描件）」。

| 按钮 | 显示条件 | 作用 |
| --- | --- | --- |
| 确认对账 | 待确认 | 提示「确认对账金额无误，可同时填写发票信息（也可确认后再填写）」：可填写发票号码、发票金额、开票日期和说明 |
| 有异议 | 待确认 | 填写异议说明（必填），对账单变为「有异议」，由本公司财务核对后重新生成 |
| 填写发票 / 修改发票 | 已确认 | 填写发票号码、发票金额、开票日期（都必填） |

## 招标投标

列出邀请本供应商参加的[招标](../scm/tender)。收到邀请时会有「招标邀请」消息。

**列表列**：招标编号 / 标题、投标截止（剩余时间）、我的投标（已投标 / 未投标）、状态（定标后显示「已中标」或「未中标」）、操作（可投标时为「投标」，否则「查看」）。

**投标**：

1. 打开招标详情，查看投标截止、状态、我的投标、招标说明。可投标时提示「截止前可以修改投标，开标前采购方看不到报价」。
2. 在物料表中为 **每个物料** 填写含税单价和税率，系统计算小计。
3. 填写交货期（天）和投标说明，下方显示「投标总价」。
4. 点「提交投标」（已投过时为「修改投标」），提示「投标已提交」。

投标截止或采购方开标后不能再修改。定标后只显示本供应商是否中标，不显示其他供应商的报价；中标时收到「中标通知」消息。

## 质量索赔

列出本公司质量部门向本供应商提出并已确认（或确认后又取消）的[质量索赔](../qms/claim)：索赔单号、索赔日期、索赔金额、索赔原因、状态（已确认 / 已取消）。还在待确认的索赔不会显示。已确认的索赔冲减应付款，并体现在对账单中。索赔确认时供应商会收到「质量索赔」消息。

## 常见问题

**登录后看不到菜单或提示没有权限？** 请确认使用的是门户账号，并联系本公司管理员检查账号是否被停用。

**为什么「我的订单」里没有某张订单？** 门户只显示已审核的采购订单；草稿、审批中的订单在审核通过后才会出现。
