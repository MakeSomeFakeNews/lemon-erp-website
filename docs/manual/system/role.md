# 角色管理

角色是一组权限的集合。管理员在角色上配置「能用哪些菜单和按钮」（菜单权限）以及「能看哪些部门的数据」（数据权限），再把角色分配给用户。系统按岗位内置了一批角色，可以直接使用或按需调整。

## 页面入口

系统管理 → 角色管理

![角色管理](/images/manual/system/role.jpg)

页面左侧是角色列表，右侧是所选角色的详情，分为「基本信息」「菜单权限」「数据权限」「成员」四个页签。

## 角色列表

- 每个角色显示名称、角色编码和成员数；超级管理员角色带「管理员」标记，停用的角色带「停用」标记并显示为灰色。
- 顶部输入框按角色名称或编码搜索。
- 「新增」按钮新增角色。
- 切换角色时，如果当前角色有未保存的修改，会弹出「放弃未保存的修改？」确认，可选「放弃修改」或「继续编辑」。

## 角色头部信息

右侧顶部显示角色名称、编码、成员数、数据权限和备注，右侧有：

- **状态开关**：启用 / 停用角色。超级管理员角色不能停用。
- **删除**：管理员角色不能删除；角色下还有成员时按钮不可用，提示「角色下还有成员，请先在『成员』中移除」。

## 新增角色

点击左侧「新增」，填写：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 角色名称 | 是 | 最长 64 个字符，如「财务专员」 |
| 角色编码 | 是 | 以字母开头，仅包含字母、数字、下划线、横线，如 `finance`；不能与已有角色重复 |
| 排序 | 否 | 默认排在最后 |
| 备注 | 否 | 最长 255 个字符 |

点击「创建并分配权限」后，系统自动选中新角色并切换到「菜单权限」页签。新角色默认没有任何菜单权限，数据权限为「本部门数据」。

## 基本信息页签

可以修改角色名称、角色编码、排序、状态、备注。超级管理员角色的编码和状态不能修改。修改后页签标题旁出现橙色圆点，底部显示「有未保存的修改」，点击「保存」生效，点击「撤销修改」恢复。

## 菜单权限页签

![菜单权限](/images/manual/system/role-menu.jpg)

以树形列出全部菜单，每个节点后面标注类型（目录 / 菜单 / 按钮）。

- 勾选需要的目录、菜单和按钮，然后点击底部「保存」，提示「菜单权限已保存，立即生效」。
- 勾选按钮时会自动勾选所在的菜单和目录（模块、分组）。
- 树上方可以搜索菜单、「全选」「展开」「父子联动」。
- 保存后，拥有该角色的用户刷新页面即可看到新的菜单。
- 超级管理员角色显示「管理员角色拥有全部可用菜单和按钮权限（SaaS 模式下以租户套餐为准），无需分配」。
- 非超级管理员只能授予自己拥有的菜单权限，否则提示「不能授予自己没有的菜单权限」。
- SaaS 模式下，非平台租户的角色权限以租户套餐为上限。

::: tip 菜单与按钮的关系
「菜单」决定能否打开页面并查看数据；「按钮」决定页面上的新增、修改、删除、审核等操作。只勾选菜单不勾选按钮，相当于只读权限。
:::

## 数据权限页签

![数据权限](/images/manual/system/role-scope.jpg)

| 数据权限 | 说明 |
| --- | --- |
| 全部数据 | 可以查看和操作所有部门的数据 |
| 自定义数据 | 只能访问勾选的部门的数据；选择后下方出现「可访问的部门」树，至少勾选一个部门 |
| 本部门数据 | 只能访问用户所在部门的数据 |
| 本部门及以下数据 | 可以访问用户所在部门及其全部下级部门的数据 |
| 仅本人数据 | 只能访问用户本人的数据（本人创建或负责的单据） |

- 修改后点击「保存」。此页签需要「数据权限」按钮权限，没有时只能查看。
- 一个用户有多个角色时，数据范围取并集。
- 只有拥有「全部数据」的管理员才能给角色分配「全部数据」；自定义的部门也必须在操作人自己的范围内。
- 超级管理员角色拥有全部数据权限，无需分配。

## 成员页签

![角色成员](/images/manual/system/role-users.jpg)

列出拥有该角色的用户：用户、部门、手机号、状态、操作。

- **添加用户**：从用户列表中挑选用户加入该角色。
- **批量移除**：勾选后移出该角色；行内「移除」移出单个用户。
- 右上角输入框按用户名或昵称搜索。
- 增减成员需要「分配用户」按钮权限；只有超级管理员能增减「超级管理员」角色的成员，内置超级管理员账号的超级管理员角色不能移除。

## 内置角色

系统按岗位预置了以下角色（除供应商、经销商两个门户账号角色外，所有内置角色都有[员工自助](../hr/self)、流程中心个人页面、[费用报销](../fin/claim)和[借款申请](../fin/loan)，其中普通用户为只读；员工查看发给自己的通知公告登录即可，不需要授权），可在本页调整：

| 角色 | 编码 | 数据权限 | 权限范围 |
| --- | --- | --- | --- |
| 超级管理员 | admin | 全部 | 全部权限 |
| 普通用户 | common | 本部门及以下 | 所有页面只读（数据大屏除外，含通知公告管理页） |
| 总经理 | gm | 全部 | 业务模块只读 + 商务智能（含数据大屏和投屏链接管理）；审核、关闭采购 / 销售订单，审核招聘需求、假勤、工时；AI 问数、智能录入、智能报告（含生成） |
| 采购员 | purchaser | 本部门（另可看到各部门已提交的请购单） | 请购、询价、采购订单（流程发布后审核即提交审批）、采购入库退货、补货、供应商及评估、寄售结算；库存、物料只读；智能录入、数据整理（含采纳建议） |
| 销售员 | sales | 仅本人 | 报价、销售订单（流程发布后审核即提交审批）、发货通知（不含拣货）、客户、CRM 客户线索商机跟进合同、[服务工单](../crm/ticket)受理处理、[市场活动](../crm/campaign)；库存、出库、价目表只读；智能录入 |
| 销售经理 | sales_mgr | 本部门及以下 | 销售员的全部功能，可看到下属的客户、订单和跟进（CRM「团队客户」）；另有[客户分析](../crm/analysis)、[价目表](../scm/price-list)和[商品价格](../scm/goods-price)维护 |
| 仓库管理员 | warehouse | 全部 | 仓库全部单据与资料、采购收退货、销售出库退货、拣货、发运、工单领料与完工入库、补料发料、移动作业、数据大屏；数据整理（含采纳建议） |
| 生产计划员 | planner | 本部门及以下 | 生产计划、MRP、产能排程、工单（不含领料报工完工）、齐套、BOM、工作中心、物料计划属性、请购单 |
| 车间主管 | workshop | 本部门 | 工单领料、报工、完工入库，补料申请、质量检验、不合格登记、设备与维护、OEE 停机登记、模具工装 |
| 质量工程师 | quality | 全部 | 质量管理全部功能（检验方案、检验、不合格品评审、8D、供应商索赔、质量分析与 SPC）；物料、供应商、工单只读；员工自助、费用报销、借款申请等员工通用权限 |
| 会计 | accountant | 全部 | 财务全部功能；采购销售单据、工资表、项目核算只读；智能录入 |
| 出纳 | cashier | 全部 | 收付款、预收预付、银行对账、报销借款付款；账簿、应收应付、发票只读 |
| 人事专员 | hr | 全部 | 人力资源全部功能；[通知公告](./notice)（新增、修改、删除、发布与撤回） |
| 项目经理 | pm | 仅本人 | 项目管理全部功能（只看自己负责的项目），审批本人负责项目的工时 |
| 普通员工 | staff | 仅本人 | 员工自助、流程中心、费用报销和借款申请；「项目 → [我的工时](../pm/timesheet)」（作为项目成员填报工时，不含审批） |
| 供应商 | supplier | 仅本人 | 供应商门户账号专用：只有门户功能，只能看到关联供应商的数据 |
| 经销商 | dealer | 仅本人 | 经销商门户账号专用：只有经销商门户，只能看到关联客户的数据 |

供应商、经销商角色由门户账号使用，不要分配给内部员工，详见[供应商与经销商门户](../portal/)。

[智能（AI）](../ai/)模块的菜单按以上方式预置：「AI 设置」只有超级管理员拥有（SaaS 租户管理员按套餐获得）。AI 功能只在用户自己的权限范围内工作：智能录入只能生成有新增权限的单据（例如总经理的业务模块只读，只能识别生成费用报销），数据整理的采纳还需要对应资料的修改权限。「智能报告」中自动生成的报告包含全公司财务、人事汇总数据，只授给管理层角色，详见[智能（AI）→ 权限](../ai/#权限)。

## 注意事项

::: warning 注意
- 删除角色前必须先在「成员」页签移除全部成员，否则提示「角色已分配给用户，不允许删除」。
- 停用角色后，拥有该角色的用户将不再获得该角色的权限。
- [流程设计器](../workflow/designer#审批人类型)中按「角色」指定审批人时，审批任务会分配给该角色下启用的用户；调整角色成员会影响之后产生的审批任务。
:::
