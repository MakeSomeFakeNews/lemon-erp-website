# 租户管理

开启 SaaS 多租户模式后，一套柠檬ERP 可以同时为多家企业（租户）提供服务：各租户共享系统但数据相互隔离，用户登录时需要填写租户名称。租户管理用于开通租户、设置套餐、到期时间和账号数量上限，以及停用、删除租户。

::: warning 适用范围
- 只有开启 SaaS 模式（由部署人员在服务端配置开启）时才显示「租户管理」和「租户套餐」菜单；未开启时系统只有一个平台租户，行为与单租户系统完全相同。
- 租户管理是平台专属功能，只有平台租户（初始数据中的「柠檬科技」）的管理员可以使用。
:::

## 页面入口

系统管理 → 租户管理

![租户管理](/images/manual/system/tenant.jpg)

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 租户名称 | 模糊查询 |
| 状态 | 启用 / 停用 |

## 列表字段

| 列 | 说明 |
| --- | --- |
| 租户名称 | 平台租户带「平台」标记 |
| 套餐 | 租户使用的套餐，平台租户显示「不限」 |
| 联系人 | 联系人姓名，下方小字为联系电话 |
| 账号 / 上限 | 当前账号数 / 账号数量上限，没有上限显示「不限」；达到上限时数字标红 |
| 到期时间 | 为空显示「长期」；已到期时标红 |
| 备注、创建时间 | |
| 状态 | 启用 / 停用开关；平台租户不能停用 |
| 操作 | 「编辑」；非平台租户还有删除按钮 |

## 新增租户

![新增租户](/images/manual/system/tenant-add.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 租户名称 | 是 | 用户登录时在「租户」输入框中填写，不能与其他租户重复 |
| 套餐 | 是 | 决定租户可用的菜单和功能，只能选择启用的套餐 |
| 联系人、联系电话 | 否 | 租户的对接人 |
| 到期时间 | 否 | 为空表示长期有效；到期后该租户的用户无法登录 |
| 账号数量上限 | 否 | 为空不限；达到上限后租户不能再新增用户 |
| 管理员账号 | 是 | 租户管理员的登录名，如 `admin` |
| 管理员密码 | 是 | 必须符合「参数设置」中的密码策略；首次登录后需修改 |
| 备注 | 否 | |

保存时系统会自动为新租户完成初始化：

1. 创建与租户同名的根部门；
2. 创建「租户管理员」角色（数据权限为全部数据，菜单与套餐一致）和管理员账号；
3. 从平台复制内置岗位角色（采购员、销售员、会计等），菜单取与套餐的交集；平台上使用「自定义数据」权限的角色在新租户中改为「本部门数据」；
4. 从平台复制基础数据：[会计科目](../fin/account)和[币种](../fin/currency#币种)、[考勤班次](../hr/attendance#班次)、[经营预警规则](../bi/decision#内置预警规则)、[流程模型](../workflow/model)（以未发布的草稿复制，审批角色换成新租户中对应的角色，租户管理员需检查后发布）。

之后由租户管理员登录（租户名称 + 管理员账号）继续本租户的初始化，参见[系统管理概述](./)中的初始化步骤。

## 编辑租户

可以修改名称、套餐、联系人、到期时间、账号数量上限、备注；管理员账号只显示不能修改。

- **更换套餐**后，租户管理员的菜单立即与新套餐一致，其他角色去掉新套餐之外的菜单，已登录用户的权限立即刷新。
- 平台租户不受套餐、到期时间和账号数量限制，相关字段不可编辑。

## 停用与删除

- **停用**：点击状态开关。停用后该租户的所有已登录会话立即失效，用户无法登录。
- **到期**：效果与停用相同，延长「到期时间」即可恢复。
- **删除**：必须先停用才能删除（否则提示「请先停用租户再删除」）。删除只删除租户记录，使其无法登录，**业务数据保留**，便于审计或恢复。平台租户不能删除。

## 租户之间的数据隔离

- 用户、部门、角色、单据、库存、财务等业务数据按租户完全隔离，编码、单号在各租户内独立编号；
- 菜单、字典、参数设置、[定时任务](../monitor/job)等由平台统一维护，所有租户共用；
- 编码规则、打印模板、流程模型由各租户自行维护；
- 定时任务按租户逐个执行，执行日志中汇总各租户的结果。
