# 租户套餐

租户套餐定义一类租户可以使用哪些菜单和功能，例如「标准版（进销存 + 财务）」「专业版（含生产、质量）」。开通租户时选择套餐，租户管理员拥有套餐内的全部菜单，租户内其他角色的权限也以套餐为上限。

::: warning 适用范围
仅在开启 SaaS 模式时显示，平台专属功能。
:::

## 页面入口

系统管理 → 租户套餐

![租户套餐](/images/manual/system/tenant-package.jpg)

## 新增 / 编辑套餐

![编辑套餐](/images/manual/system/tenant-package-edit.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 套餐名称 | 是 | 最多 64 个字符，不能重复 |
| 状态 | 否 | 启用 / 停用，默认启用。停用后不能用于新建租户，已有租户不受影响 |
| 备注 | 否 | 最多 255 个字符 |
| 可用菜单 | 是 | 由上面的「行业模板」「功能模块」卡片和下面的「菜单明细」树组成，见下文；至少选择一项，否则提示「请选择套餐包含的菜单」 |

「可用菜单」下方的说明：「租户管理员拥有套餐内的全部菜单；修改后，使用该套餐的租户立即按新菜单生效。菜单管理、系统字典、参数设置、租户与套餐、服务与缓存监控、定时任务等平台功能不能加入套餐（业务字典可以）」。

### 行业模板

一组卡片，每张显示行业名称、简要说明和包含的模块数（如「21 个模块」，含基础平台）。点击卡片后自动勾选该行业常用的功能模块（及其依赖的模块），卡片高亮；之后可以再增减模块或菜单。内置的行业模板：

| 行业模板 | 包含的功能模块 |
| --- | --- |
| 离散制造 | 采购管理、采购寻源、供应商门户、销售管理、库存管理、仓储作业、生产管理、工程技术、设备管理、质量管理、总账、应收应付、资金与费用、资产管理、成本核算、预算与分析、人事管理、薪酬福利、商务智能、数据大屏 |
| 流程加工 | 采购管理、销售管理、库存管理、仓储作业、生产管理、设备管理、质量管理、总账、应收应付、资金与费用、资产管理、成本核算、预算与分析、人事管理、薪酬福利、商务智能、数据大屏 |
| 商贸批发 | 采购管理、采购寻源、销售管理、渠道分销、销售提成、进销存报表、库存管理、仓储作业、总账、应收应付、资金与费用、预算与分析、客户关系、商务智能、数据大屏 |
| 电商零售 | 采购管理、销售管理、渠道分销、进销存报表、库存管理、仓储作业、总账、应收应付、资金与费用、商务智能、数据大屏 |
| 工程项目 | 采购管理、销售管理、库存管理、项目管理、客户关系、总账、应收应付、资金与费用、资产管理、预算与分析、人事管理、薪酬福利、商务智能 |
| 专业服务 | 销售管理、客户关系、项目管理、总账、应收应付、资金与费用、预算与分析、人事管理、薪酬福利、商务智能 |

「基础平台」模块在每个模板中都包含（上表未列出）。

### 功能模块

标题旁显示「已选 N / 总数；勾选时自动加上依赖的模块，取消时一并取消依赖它的模块」。模块按分类排列，每张卡片显示模块名称、说明，以及依赖的模块（如「依赖：库存管理」）：

| 分类 | 功能模块 |
| --- | --- |
| 基础 | 基础平台（系统管理、流程审批、物料与仓库、客户与供应商等基础资料），标记「必选」，不能取消 |
| 供应链 | 采购管理、采购寻源、供应商门户、销售管理、渠道分销、销售提成、进销存报表 |
| 仓储 | 库存管理、仓储作业 |
| 生产与质量 | 生产管理、工程技术、设备管理、质量管理 |
| 财务 | 总账、应收应付、资金与费用、资产管理、成本核算、预算与分析 |
| 客户与项目 | 客户关系、项目管理 |
| 人力资源 | 人事管理、薪酬福利 |
| 分析 | 商务智能、数据大屏、智能（AI） |

- 勾选模块时同时勾选它依赖的模块，例如勾选「采购寻源」会带上「采购管理」和「库存管理」，并提示「同时勾选了依赖的模块：…」；
- 取消模块时一并取消依赖它的模块，并提示「同时取消了依赖它的模块：…」；
- 模块中的菜单全部包含时卡片为勾选状态；只包含一部分（在菜单明细中单独调整过）时为半选，卡片边框显示为虚线。

### 菜单明细

「菜单明细」树（提示「按模块勾选后可在这里单独增减页面和按钮」）列出所有可加入套餐的目录、页面和按钮，与上面的模块卡片同步。树上方可以搜索、「全选」、「展开」和切换「父子联动」：联动时勾选会同时勾选下级和上级（勾选按钮会自动勾选所在页面和目录），取消时同时取消下级。树下方显示「已选择 N / 总数 项」。

### 平台专属功能

以下功能由平台统一维护，只有平台租户可以使用，不出现在行业模板、功能模块和菜单明细中，不能加入套餐（即使通过其他方式分配给租户内的用户也不生效）：

- 系统管理：[菜单管理](./menu)、[字典管理](./dict)（系统字典）、[参数设置](./config)、[租户管理](./tenant)、租户套餐；
- 系统监控：[服务监控](../monitor/server)、[缓存监控](../monitor/cache)、[定时任务](../monitor/job)。

[业务字典](./biz-dict)不是平台专属功能，每个租户各有一份，可以加入套餐由租户自行维护；操作日志、登录日志、在线用户等其他系统管理、系统监控页面也可以加入套餐。

修改套餐的菜单后，使用该套餐的所有租户**立即**按新菜单生效：

- 租户管理员的菜单与套餐保持一致（新增的菜单自动获得）；
- 租户内其他角色去掉套餐之外的菜单（新增的菜单不会自动授予，需要租户管理员在角色管理中勾选）。

## 删除套餐

正在被租户使用的套餐不能删除（提示「套餐正在被租户使用，不能删除」），请先把租户换到其他套餐。

## 注意事项

::: tip 提示
缩小套餐范围会立即收回租户的相关权限，建议先与租户沟通。如果只是不再向新客户提供某个套餐，把它「停用」即可。
:::
