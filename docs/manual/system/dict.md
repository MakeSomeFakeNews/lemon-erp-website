# 字典管理

字典是系统中各种下拉选项、状态标签的统一来源，例如「通用状态（启用 / 停用）」「操作类型」「波次状态」「库位类型」等。每个字典由「字典类型」和若干「字典数据」组成，字典数据的标签文字和颜色会显示在各页面的下拉框和状态标签中。

::: warning 平台专属
字典管理是平台专属功能，SaaS 模式下只有平台租户的管理员可以使用，修改对所有租户生效。
:::

## 页面入口

系统管理 → 字典管理

![字典管理](/images/manual/system/dict.jpg)

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 字典名称 | 模糊查询，如「库位类型」 |
| 字典类型 | 模糊查询，如 `wms_location_type` |
| 状态 | 启用 / 停用 |

## 列表字段与按钮

列：字典名称、字典类型（点击可打开字典数据）、状态、备注、创建时间、操作。

| 按钮 | 说明 |
| --- | --- |
| 新增字典 | 新增字典类型 |
| 批量删除 | 删除勾选的字典，字典数据会一并删除 |
| 清理前端字典缓存（工具栏右侧扫帚图标） | 清除当前浏览器中缓存的字典数据，下次使用时重新加载 |
| 导出 | 按当前条件导出 Excel |
| 行内「数据」 | 打开该字典的数据维护抽屉 |
| 行内「编辑」「删除」 | 修改或删除字典类型（删除时字典数据一并删除） |

## 新增 / 编辑字典

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 字典名称 | 是 | 如「用户性别」，最长 64 个字符 |
| 字典类型 | 是 | 字典的唯一标识，小写字母开头，仅包含小写字母、数字、下划线，如 `sys_user_sex`；不能与已有字典重复 |
| 状态 | 是 | 启用 / 停用 |
| 备注 | 否 | 最长 255 个字符 |

::: warning 注意
系统内置字典的「字典类型」被程序引用，不要修改或删除，否则相关页面的下拉框和状态标签将无法正确显示。
:::

## 字典数据

点击某个字典的「数据」或字典类型，打开「字典数据」抽屉，抽屉右上角显示字典类型。

![字典数据](/images/manual/system/dict-data.jpg)

列：数据标签、数据键值、排序、状态、备注、操作。上方可以按标签搜索，「新增数据」「批量删除」，行内「编辑」「删除」。

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 数据标签 | 是 | 界面上显示的文字，如「拣货中」 |
| 数据键值 | 是 | 系统内部保存的值，如 `PICKING`；同一字典内不能重复 |
| 标签颜色 | 否 | 状态标签的颜色，从预设颜色中选择，默认为灰色 |
| 排序 | 否 | 下拉框中的顺序 |
| 状态 | 否 | 停用的数据不再出现在下拉选项中 |
| 备注 | 否 | 说明 |

## 常见用法

- **修改显示文字或颜色**：只改「数据标签」和「标签颜色」，不要改「数据键值」。
- **增加可选项**：只对业务上自由选择的字典（如客户来源、线索来源等）增加数据；表示单据状态的字典由程序控制状态流转，增加新值没有意义。
- 修改后如果页面仍显示旧值，点击工具栏的「清理前端字典缓存」或刷新页面。
