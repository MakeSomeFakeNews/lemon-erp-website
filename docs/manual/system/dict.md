# 字典管理

字典是系统中各种下拉选项、状态标签的统一来源，例如「通用状态（启用 / 停用）」「操作类型」「波次状态」「库位类型」等。每个字典由「字典类型」和若干「字典数据」组成，字典数据的标签文字和颜色会显示在各页面的下拉框和状态标签中。

::: warning 平台专属
字典管理是平台专属功能，SaaS 模式下只有平台租户的管理员可以使用。系统字典的修改对所有租户生效；各企业自己的业务字典取值在「[业务字典](./biz-dict)」中维护。
:::

## 系统字典与业务字典

字典按「种类」分为两类：

| | 系统字典 | 业务字典 |
| --- | --- | --- |
| 用途 | 单据状态、单据类型、操作类型等由程序控制的取值，程序按键值判断业务逻辑 | 企业按管理习惯分类的选项，如客户等级、物料分类、不良类型、假期类型、出入库类别、停机原因 |
| 数据归属 | 全平台共用一份 | 每个租户各自一份，新租户开通时从平台复制 |
| 谁来维护 | 平台管理员在本页维护 | 各企业管理员在「系统管理 → [业务字典](./biz-dict)」中维护；平台在本页维护的是平台自己的取值，也是新租户的默认取值 |
| 能改什么 | 只能修改名称（数据标签）、颜色、排序、备注；**不能新增、删除取值，不能改键值和状态** | 可以新增取值、修改名称和颜色、停用、删除；标记为「内置」的取值不能删除、不能改键值 |
| 键值格式 | 由程序内置 | 大写字母开头，只能包含大写字母、数字、下划线，不超过 16 位 |
| 删除字典类型 | 不能删除 | 没有内置取值的可以删除（全部租户的取值一并删除） |

哪些字典属于业务字典、各有哪些内置取值，见[业务字典](./biz-dict#有哪些业务字典)。除此之外的字典（如各类单据状态、出入库类型、销售阶段、项目费用类型、不合格品来源、通用状态等）都是系统字典。

**内置取值**：程序依赖的取值（系统字典的全部取值，以及业务字典中被程序引用的取值，例如物料分类的「原材料」「成品」、假期类型的「年假」「调休」）。内置取值不能删除、不能改键值，可以改名称和颜色；业务字典的内置取值不需要时可以停用。

## 页面入口

系统管理 → 字典管理

![字典管理](/images/manual/system/dict.jpg)

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 字典名称 | 模糊查询，如「库位类型」 |
| 字典类型 | 模糊查询，如 `wms_location_type` |
| 种类 | 系统字典 / 业务字典 |
| 状态 | 启用 / 停用 |

## 列表字段与按钮

列：字典名称、字典类型（点击可打开字典数据）、种类（系统字典蓝色、业务字典绿色）、状态、备注、创建时间、操作。

| 按钮 | 说明 |
| --- | --- |
| 新增字典 | 新增字典类型 |
| 批量删除 | 删除勾选的字典，字典数据会一并删除。勾选了系统字典或有内置取值的业务字典时提示「“字典名称”有程序依赖的内置取值，不能删除」，整批不删除 |
| 清理前端字典缓存（工具栏右侧扫帚图标） | 清除当前浏览器中缓存的字典数据，下次使用时重新加载 |
| 导出 | 按当前条件导出 Excel |
| 行内「数据」 | 打开该字典的数据维护抽屉 |
| 行内「编辑」 | 修改字典名称、状态、备注 |
| 行内「删除」 | 只有业务字典显示，删除字典类型及所有租户的取值；有内置取值的不能删除 |

## 新增 / 编辑字典

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 字典名称 | 是 | 如「用户性别」，最长 64 个字符 |
| 字典类型 | 是 | 字典的唯一标识，小写字母开头，仅包含小写字母、数字、下划线，如 `sys_user_sex`；不能与已有字典重复。**保存后不能修改**（编辑时置灰） |
| 种类 | 是 | 系统字典 / 业务字典，新增时默认业务字典。表单提示「系统字典的取值由程序内置，全平台共用，只能改名称、颜色、排序；业务字典由各租户在「业务字典」中自行维护，平台维护的是新租户的默认取值。保存后不能修改」 |
| 状态 | 是 | 启用 / 停用 |
| 备注 | 否 | 最长 255 个字符 |

::: warning 注意
字典类型和种类保存后都不能修改。自己新增的字典类型不会被任何程序字段引用，一般只在二次开发时使用；业务上需要的新选项请在已有的业务字典中新增取值。
:::

## 字典数据

点击某个字典的「数据」或字典类型，打开「字典数据」抽屉，抽屉右上角显示字典类型，顶部按种类给出提示：

- 系统字典：「系统字典的取值由程序内置，全平台共用：只能修改名称、颜色、排序和备注，不能新增、删除或修改键值。」此时没有「新增数据」「批量删除」和行内「删除」，编辑时键值、状态置灰；
- 业务字典：「业务字典由各租户在「业务字典」中自行维护；这里是平台租户的取值，也是新租户开通时复制的默认取值。」可以新增、删除取值，内置取值的键值后带「内置」标记，不能删除、不能改键值。

![字典数据](/images/manual/system/dict-data.jpg)

列：数据标签、数据键值、排序、状态、备注、操作。上方可以按标签搜索，「新增数据」「批量删除」（仅业务字典），右侧可导出；行内「编辑」「删除」（删除仅业务字典的非内置取值）。

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 数据标签 | 是 | 界面上显示的文字，如「拣货中」 |
| 数据键值 | 是 | 系统内部保存的值，如 `PICKING`；同一字典内不能重复。业务字典的新取值须大写字母开头、只含大写字母数字下划线、不超过 16 位；系统字典和内置取值不能修改 |
| 标签颜色 | 否 | 状态标签的颜色，从预设颜色中选择，默认为灰色 |
| 排序 | 否 | 下拉框中的顺序 |
| 状态 | 否 | 停用的数据不再出现在下拉选项中；系统字典不能修改状态 |
| 备注 | 否 | 说明 |

## 常见用法

- **修改显示文字或颜色**：只改「数据标签」和「标签颜色」，不要改「数据键值」。
- **增加可选项**：只有业务字典可以增加取值。SaaS 模式下各企业在「[业务字典](./biz-dict)」中维护自己的取值；在本页为业务字典新增的取值只属于平台租户，并作为以后新开通租户的默认取值，不会加到已开通的租户中。
- 修改后如果页面仍显示旧值，点击工具栏的「清理前端字典缓存」或刷新页面。

::: tip 多语言
本页维护的是中文标签，列表中始终显示保存的原文。系统内置的字典数据已带英文译文：英文界面下，内置项显示内置的英文名称（即使在这里修改了中文标签）；自己新增的字典数据没有译文，英文界面也显示这里填写的标签。见[语言切换](../guide/layout#语言切换)。
:::
