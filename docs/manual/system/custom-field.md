# 自定义字段

自定义字段用于在不修改系统的情况下，为客户、供应商、物料、采购订单、销售订单等业务记录增加企业自己需要的信息，例如物料的「品牌」「产地」、客户的「行业」「开票要求」、订单的「项目号」。字段定义好后，会出现在对应表单的「扩展信息」区域，可选在列表中显示为一列。

自定义字段按租户独立维护，SaaS 模式下各租户互不影响。

## 页面入口

系统管理 → 自定义字段

![自定义字段](/images/manual/system/custom-field.jpg)

页面上方的「业务类型」下拉框可以只看某一种业务类型的字段，清空则显示全部。演示数据中没有预置自定义字段，列表为空。

列表列：

| 列 | 说明 |
| --- | --- |
| 业务类型 | 字段属于哪种业务记录，如客户、物料、销售订单 |
| 显示名称 | 表单、列表中显示的字段名称 |
| 字段标识 | 字段的内部标识，保存后不能修改 |
| 类型 | 文本、多行文本、数字、日期、下拉选择、是否 |
| 选项 | 下拉选择类型的可选值 |
| 属性 | 「必填」「列表显示」标签 |
| 排序 | 数字小的排在前面 |
| 状态 | 启用 / 停用 |
| 操作 | 「编辑」「删除」（需要「自定义字段维护」权限） |

列表按业务类型、排序排列。

## 新增与编辑字段

点击右上角「新增字段」，在右侧抽屉中填写。如果页面上方已选择了业务类型，新增时自动带入。

![新增自定义字段](/images/manual/system/custom-field-add.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 业务类型 | 是 | 字段加在哪种业务记录上，保存后不能修改 |
| 字段标识 | 是 | 字母开头，由字母、数字、下划线组成，最多 32 个字符，如 `brand`；同一业务类型内不能重复（提示「字段标识「…」已存在」），保存后不能修改 |
| 显示名称 | 是 | 最多 32 个字符，如「品牌」 |
| 类型 | 是 | 默认「文本」，见下表 |
| 排序 | 否 | 默认 0，决定字段在表单和列表中的先后顺序 |
| 选项 | 类型为「下拉选择」时必填 | 可选值，用逗号或换行分隔，最多 1000 个字符；没有填写时提示「下拉选择请填写选项」 |
| 必填 | 否 | 勾选后，保存业务记录时必须填写该字段 |
| 列表显示 | 否 | 勾选后，在业务列表中增加一列显示该字段 |
| 启用 | 否 | 默认勾选。停用的字段不在表单和列表中显示，已填写的值保留，重新启用后恢复显示 |
| 说明 | 否 | 最多 255 个字符，显示为表单中该字段下方的提示文字 |

字段类型：

| 类型 | 表单中的输入方式 | 保存时的校验 |
| --- | --- | --- |
| 文本 | 单行输入框 | 最多 1000 个字符 |
| 多行文本 | 多行输入框，占整行 | 最多 1000 个字符 |
| 数字 | 数字输入框 | 必须是数字，否则提示「「…」请填写数字」 |
| 日期 | 日期选择框 | 必须是日期，否则提示「「…」请填写日期」 |
| 下拉选择 | 下拉框，可清空 | 必须是选项之一，否则提示「「…」请从选项中选择」 |
| 是否 | 开关 | 在列表和详情中显示为「是」「否」 |

每个业务类型最多 50 个自定义字段。

点击列表中的「编辑」可以修改显示名称、类型、选项、必填、列表显示、排序、启用和说明；业务类型、字段标识不能修改。

::: warning 修改类型的影响
修改字段类型或下拉选项不会转换已经填写的值。例如把文本改为数字后，原来填写的非数字内容在下次保存该记录时会提示「请填写数字」，需要修改后才能保存。
:::

## 删除字段

点击「删除」，确认「删除字段「…」？已填写的值一并删除。」后，字段定义和所有记录上已填写的值都会被删除，不能恢复。只是暂时不用的字段，建议编辑后取消「启用」。

## 业务类型

「业务类型」下拉框列出系统中可以挂附件、记录修改历史的全部业务记录：客户、供应商、物料、采购订单、销售订单、采购合同、招标、凭证、供应商对账单、发票、生产工单、技术文档、工程变更、员工档案、候选人、项目、客户关系中的客户、商机等。

目前以下页面的表单和列表已经支持自定义字段，在其他业务类型上定义的字段暂时不会在页面中显示：

| 业务类型 | 填写位置 | 列表显示 |
| --- | --- | --- |
| 客户（供应链 → 往来单位 → [客户](../scm/customer)） | 新增 / 编辑客户表单的「扩展信息」 | 支持 |
| 供应商（供应链 → 往来单位 → [供应商](../scm/supplier)） | 新增 / 编辑供应商表单的「扩展信息」 | 支持 |
| 物料（仓库 → 基础资料 → [物料管理](../wms/material)） | 新增 / 编辑物料表单的「扩展信息」 | 支持 |
| 采购订单（[采购订单](../scm/purchase)） | 订单表单的「扩展信息」；订单详情中只读显示 | 不支持（只在详情中显示） |
| 销售订单（[销售订单](../scm/sales)） | 订单表单的「扩展信息」；订单详情中只读显示 | 不支持（只在详情中显示） |

::: tip 两个「客户」
下拉框中有两个「客户」：一个是供应链「往来单位」中的客户，另一个是「客户关系」模块中的客户。为供应链客户表单增加字段时，请选择紧跟在「销售订单」之后、「供应商」之前的那个「客户」；新增后打开客户表单确认字段已经出现。
:::

## 在业务页面中填写

1. 打开客户、供应商、物料的新增 / 编辑表单，或采购 / 销售订单的表单。
2. 在表单的「扩展信息」区域填写自定义字段；必填字段名称前有红色星号。
3. 点击保存。必填字段没有填写时提示「请填写 …」并中止保存。

自定义字段的修改会计入表单的「未保存修改」：没有保存就关闭表单时会提示确认。勾选了「列表显示」的字段在列表中显示为一列，位于「操作」列之前。

## 权限

| 操作 | 需要的权限 |
| --- | --- |
| 查看自定义字段页面 | 「自定义字段」菜单权限 |
| 新增、编辑、删除字段定义 | 「自定义字段维护」按钮权限 |
| 在业务记录上查看字段值 | 该业务记录的查看权限（如客户查看），并且记录在自己的数据权限范围内 |
| 在业务记录上填写字段值 | 该业务记录的修改权限（如客户修改），并且记录在自己的数据权限范围内 |

内置角色中，超级管理员拥有全部权限，普通用户（common）可以只读查看本页面。

## 注意事项

::: tip 提示
- 自定义字段不修改数据库表结构，系统升级不受影响。
- 管理员修改字段定义后，其他用户已打开的页面需要刷新才能看到新的字段。
- 自定义字段目前不能作为列表的查询条件，也不会打印在单据上；Excel 导入不包含自定义字段。
:::
