# 系统管理概述

「系统管理」是面向系统管理员的模块，负责维护登录账号、组织架构、角色权限、菜单、字典（含各企业自己的业务字典）、编码规则、打印模板、系统参数，以及按企业设置的自定义字段、业务参数和钉钉 / 企业微信 / 飞书集成；开启 SaaS 多租户时，平台管理员还在这里开通租户、配置租户套餐。业务人员一般不需要进入本模块。

## 页面入口

顶部导航「系统管理」，侧边栏包含以下菜单：

| 菜单 | 用途 | 说明 |
| --- | --- | --- |
| [用户管理](./user) | 登录账号的新增、编辑、停用、重置密码、分配角色、调整部门 | |
| [部门管理](./dept) | 维护组织架构树、部门负责人和部门成员 | 部门负责人即审批流程中的「部门主管」 |
| [角色管理](./role) | 角色的基本信息、菜单权限、数据权限和成员 | 内置 16 个岗位角色 |
| [菜单管理](./menu) | 维护目录、菜单、按钮三级权限 | 平台专属 |
| [字典管理](./dict) | 维护字典类型和系统字典（单据状态、类型等）的名称、颜色 | 平台专属 |
| [业务字典](./biz-dict) | 本企业的下拉选项：客户等级、物料分类、不良类型、假期类型、出入库类别、停机原因等，可新增取值 | 每个租户独立 |
| [租户管理](./tenant) | 开通租户、设置到期时间和账号上限 | 仅 SaaS 模式显示，平台专属 |
| [租户套餐](./tenant-package) | 定义租户可用的菜单范围 | 仅 SaaS 模式显示，平台专属 |
| [编码规则](./code-rule) | 设置各类单据、主数据的编号格式 | 每个租户独立 |
| [打印模板](./print-template) | 配置单据打印版式（服务器生成 PDF，可上传 JRXML、设置套打）和标签模板 | 每个租户独立 |
| [参数设置](./config) | 系统名称、水印、登录验证码、密码策略、会话、附件大小等 | 平台专属，所有租户共用 |
| [自定义字段](./custom-field) | 不改表结构，为客户、供应商、物料、采购 / 销售订单等扩展字段，在表单中填写、可在列表中显示 | 每个租户独立 |
| [业务参数](./biz-rule) | 采购超收、销售超发比例，客户信用额度控制方式，是否允许审核自己制单的凭证；月计薪天数、每日工时、默认社保比例、考勤扣款、加班倍数、个税预扣率表、默认试用期等人事计算规则 | 每个租户独立 |
| [第三方集成](./im) | 接入钉钉、企业微信、飞书：扫码登录与应用内免登、消息推送到应用和群机器人、通讯录同步与成员绑定 | 每个租户接入自己的应用 |

::: tip 平台专属功能
菜单管理、字典管理、参数设置、租户管理、租户套餐，以及「系统监控」中的[服务监控](../monitor/server)、[缓存监控](../monitor/cache)、[定时任务](../monitor/job)，属于平台专属功能：只有平台租户（初始数据中的「柠檬科技」）的用户可以使用，不能加入租户套餐，其他租户即使被分配了这些菜单也不会生效。未开启 SaaS 模式时只有平台租户，这些功能对超级管理员正常可用。
:::

## 首次上线的初始化步骤

新系统上线时，建议管理员按以下顺序完成初始化，前一步的数据会被后一步使用：

| 步骤 | 页面 | 要做的事 |
| --- | --- | --- |
| 1 | [参数设置](./config) | 修改系统名称；关闭「登录页显示演示账号」；按公司安全要求设置登录验证码、密码错误锁定、密码最小长度与复杂度、密码有效期、登录有效期；确认人事录用自动开通账号的「初始密码」 |
| 2 | [部门管理](./dept) | 按公司实际组织搭建部门树，为每个部门设置「负责人」（审批流程中的部门主管依赖它）；可以停用或删除演示部门 |
| 3 | [角色管理](./role) | 检查内置岗位角色的菜单权限和数据权限是否符合公司分工，按需调整或新增角色 |
| 4 | [用户管理](./user) | 为员工开通账号，选择所属部门、分配角色；也可以在人力资源的[员工录用](../hr/employee#办理入职)时自动开通账号 |
| 5 | [编码规则](./code-rule) | 确认各单据编号的前缀、日期格式、流水位数和重置周期，上线前定好，避免中途修改造成编号风格不一致 |
| 6 | [打印模板](./print-template) | 在「通用设置」中填写公司名称，按需调整采购订单、出入库单、记账凭证等单据的纸张和版式；使用预印单据纸的设置[套打](./print-template#套打)；调整物料、库位、箱标签 |
| 7 | [业务参数](./biz-rule)、[业务字典](./biz-dict) | 与业务部门确认是否允许采购超收、销售超发及比例，客户信用额度在审核还是出库时控制，是否允许制单人审核自己的凭证；与人事确认月计薪天数、每日工时、默认社保比例、迟到早退扣款、病假扣发比例、加班倍数、个税基本减除费用和默认试用期；在业务字典中按企业习惯调整客户等级、物料分类、不良类型、假期类型、出入库类别、停机原因等下拉选项（新增需要的取值，停用用不到的取值） |
| 8 | [自定义字段](./custom-field)（可选） | 录入基础资料之前，为客户、供应商、物料、订单补充企业需要的扩展字段（如品牌、行业），录入时一并填写 |
| 9 | 各业务模块基础资料 | [仓库](../wms/warehouse)与[库位](../wms/location)、[规格属性](../wms/attribute)与[物料](../wms/material)（含计价方法、多规格）、[供应商](../scm/supplier)、[客户](../scm/customer)、[会计科目](../fin/account)（含辅助核算）、员工档案、[工作中心](../mes/work-center)与 [BOM](../mes/bom) 等，参见各模块章节，例如[仓库管理](../wms/)、[供应链管理](../scm/)、[人力资源](../hr/)、[生产制造](../mes/) |
| 10 | [凭证科目设置](../fin/account-rule) | 确认自动生成凭证使用的科目：往来、存货与成本、收入与费用、税费、资产、薪酬、期末；存货、收入、成本可按物料分类，工资费用可按职位类别分别设置。只影响之后生成的凭证，务必在业务开始前设好 |
| 11 | [期初余额](../fin/opening)（启用向导） | 按「启用向导」页签的顺序准备期初数据：科目期初（借贷平衡）、期初库存（Excel 导入，生成期初入库单）、存货期初、期初往来（Excel 导入应收应付单，与应收账款、应付账款科目期初核对） |
| 12 | [流程中心](../workflow/model) | 设计并发布需要审批的流程（采购订单、销售订单、请假等），审批人可选「部门主管」「角色」等 |
| 13 | [第三方集成](./im)（可选） | 企业使用钉钉、企业微信或飞书时，在平台中创建企业自建应用，填写应用凭证和系统访问地址并启用；同步通讯录按手机号绑定账号（也可以放在第 4 步之前，开启「自动创建部门和账号」直接从通讯录生成部门和账号，再分配角色），之后员工可以扫码登录、在平台中接收审批待办等消息 |

::: warning 注意
默认账号 `admin` 是内置超级管理员，拥有全部权限，不能被停用或删除。正式上线前请务必修改其密码，并关闭登录页的演示账号提示。
:::

## 权限模型简介

柠檬ERP 的权限分为两层：

| 层级 | 控制什么 | 在哪里配置 |
| --- | --- | --- |
| 功能权限 | 能看到哪些菜单、能点哪些按钮、能调用哪些功能 | [角色管理](./role) →「菜单权限」页签 |
| 数据权限 | 能看到、能操作哪些部门的数据 | [角色管理](./role) →「数据权限」页签 |

一个用户可以拥有多个角色，功能权限和数据权限都取各角色的并集。角色、菜单、部门修改后立即生效，用户刷新页面即可看到新的菜单。

为防止越权，除超级管理员外的管理员还受以下限制：

- 不能分配「超级管理员」角色，不能修改超级管理员角色；
- 不能授予自己没有的菜单权限，不能授予超出自己范围的数据权限（例如自己不是「全部数据」，就不能给角色分配「全部数据」）；
- 不能重置密码、修改、停用、删除拥有超级管理员角色的账号；
- 只能管理自己数据权限范围内的部门和用户。

## 典型业务流程

**新员工入职开通账号**

1. 人事在[员工档案](../hr/employee)中办理录用（或在用户管理中手工新增用户）。
2. 系统按「参数设置 → 密码策略 → 初始密码」开通账号，员工首次登录时被要求修改密码。
3. 管理员在[用户管理](./user)中为该账号分配岗位角色；如需审批，确认其所在部门已设置负责人。

**员工调岗、离职**

1. 人事在员工档案中办理调岗时，登录账号的部门同步变更，「本部门」类数据权限和部门主管审批按新部门生效。
2. 办理离职时，登录账号自动停用并立即下线。
3. 也可以在[用户管理](./user)中手工「调整部门」或停用账号。

**新开一个租户（SaaS 模式）**

1. 在[租户套餐](./tenant-package)中准备好套餐（勾选可用菜单）。
2. 在[租户管理](./tenant)中新增租户，选择套餐、填写管理员账号和密码。
3. 系统自动开通根部门、租户管理员和内置岗位角色，并复制会计科目、班次、流程模型等基础数据。
4. 租户管理员登录（登录页填写租户名称）后，按上面的「首次上线的初始化步骤」完成本租户的初始化。

## 相关角色

| 角色 | 在本模块中的工作 |
| --- | --- |
| 超级管理员（admin） | 拥有本模块全部功能 |
| 租户管理员 | SaaS 模式下每个租户自动生成，管理本租户的用户、部门、角色、业务字典、编码规则、打印模板、自定义字段、业务参数、第三方集成（不含平台专属功能） |
| 普通用户（common） | 可以只读查看用户、部门、角色、自定义字段、业务参数等页面，没有增删改权限 |

其他岗位角色默认没有系统管理权限。
