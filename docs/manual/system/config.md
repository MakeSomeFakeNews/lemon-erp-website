# 参数设置

参数设置集中管理系统级参数：系统名称、登录页演示账号、页面水印、登录验证码、密码错误锁定、登录有效期、单点登录、密码策略、初始密码和附件大小上限。

采购超收、销售超发、信用额度控制、凭证自审等按企业（租户）设置的业务规则不在这里，见[业务参数](./biz-rule)。

::: warning 平台专属，所有租户共用
参数设置是平台专属功能，SaaS 模式下只有平台租户的管理员可以修改，修改后对所有租户**立即生效**。
:::

## 页面入口

系统管理 → 参数设置

![参数设置 - 基本设置](/images/manual/system/config.jpg)

参数按「基本设置」「登录与会话」「密码策略」「文件上传」四个页签分组。每个参数下方有说明和默认值。

## 页面操作

- 修改过（与默认值不同并已保存）的参数显示蓝色「已修改」标签；
- 改动后尚未保存的参数显示橙色「未保存」标签；
- 参数值与默认值不同时，右侧出现「恢复默认」链接；
- 页面底部「放弃修改」撤销全部未保存的改动，「保存（N）」一次保存全部改动（N 为改动的参数个数），各页签的改动会一起保存；
- 没有「参数修改」权限的用户只能查看。

## 基本设置

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 系统名称 | 柠檬ERP | 显示在登录页、侧边栏和浏览器标题中，1～30 个字符。保持默认值时，英文界面显示为「Lemon ERP」；改过的名称在两种语言下都原样显示 |
| 登录页显示演示账号 | 开启 | 在登录页提示演示账号和密码，**正式使用时请关闭** |
| 页面水印 | 关闭 | 在页面上平铺显示当前用户的姓名、账号和日期，防止截图外传 |

## 登录与会话

![参数设置 - 登录与会话](/images/manual/system/config-login.jpg)

| 参数 | 默认值 | 取值 | 说明 |
| --- | --- | --- | --- |
| 登录验证码 | 关闭 | 关闭 / 每次登录 / 密码输错后 | 「密码输错后」：同一账号密码输错后，下次登录需要输入验证码 |
| 验证码类型 | 算术题 | 算术题 / 字母数字 | 算术题如「3 + 5 = ?」，或 4 位字母数字；2 分钟内有效，校验一次后作废 |
| 密码错误锁定次数 | 5 | 1～20 | 连续输错达到次数后锁定账号，锁定期间密码正确也不能登录；管理员重置密码后解锁 |
| 锁定时长（分钟） | 10 | 1～1440 | 账号被锁定的时长 |
| 登录有效期（小时） | 12 | 1～720 | 登录后超过有效期需要重新登录，修改后对新登录生效 |
| 同一账号只允许一处登录 | 关闭 | 开 / 关 | 开启后，账号在别处登录时，之前的登录自动下线 |

补充说明：

- 验证码输错不计入密码错误次数；
- 不存在的用户名同样会计入失败次数，防止撞库；
- 被锁定的账号可以由管理员在[用户管理](./user)中重置密码解锁，或在[缓存监控](../monitor/cache)中清空「登录失败」缓存解锁；
- 登录有效期、密码错误锁定次数、锁定时长、密码最小长度、密码有效期、初始密码的默认值可以由部署人员在服务端配置文件中修改，页面上修改后以页面为准。

## 密码策略

![参数设置 - 密码策略](/images/manual/system/config-password.jpg)

| 参数 | 默认值 | 取值 | 说明 |
| --- | --- | --- | --- |
| 密码最小长度 | 8 | 6～32 | 密码最长 32 位 |
| 密码复杂度 | 字母和数字 | 字母和数字 / 大小写字母和数字 / 字母、数字和特殊字符 | 对新设置的密码生效（新增用户、重置密码、修改密码、开通账号），已有密码不受影响 |
| 密码有效期（天） | 0 | 0～3650 | 超过有效期后，登录时要求修改密码；0 表示不限制 |
| 初始密码 | Lemon@123 | 6～32 个字符 | [人事录用](../hr/employee#办理入职)、组织同步、[第三方集成](./im#同步通讯录)同步通讯录自动开通账号时的初始密码，须符合密码策略；首次登录要求修改 |

- 页面上的密码输入框提示（如「8-32 位，包含字母和数字」）和随机密码生成都会按当前策略自动调整。
- 保存时，系统会用修改后的最小长度和复杂度校验「初始密码」，不符合时不能保存，需同时修改初始密码。
- 管理员新建、重置的密码以及过期的密码，在用户登录后都会提示本人修改，详见[登录与账号](../guide/login)。

## 文件上传

| 参数 | 默认值 | 取值 | 说明 |
| --- | --- | --- | --- |
| 附件大小上限（MB） | 20 | 1～100 | 单据附件单个文件的大小上限；可执行文件始终禁止上传 |

## 上线前建议

::: tip 推荐配置
- 关闭「登录页显示演示账号」，修改「系统名称」为公司名称或系统简称；
- 「登录验证码」设为「密码输错后」或「每次登录」；
- 密码复杂度至少为「大小写字母和数字」，按公司制度设置密码有效期（如 90 天）；
- 修改默认的「初始密码」；
- 对数据保密要求高时开启「页面水印」。
:::
