# 业务字典

业务字典是各企业（租户）自己维护的下拉选项，例如客户等级、客户来源、物料分类、不良类型、假期类型、出库类别、停机原因等。企业可以按自己的管理习惯**新增取值**、修改显示名称和颜色、停用不再使用的取值，修改只影响本企业，不影响其他租户。

单据状态、单据类型等由程序控制流转的选项属于**系统字典**，全平台共用，由平台管理员在[字典管理](./dict)中维护，不在本页显示。两类字典的区别见[字典管理](./dict#系统字典与业务字典)。

## 页面入口

系统管理 → 业务字典

![业务字典](/images/manual/system/biz-dict.jpg)

## 权限

| 权限 | 说明 |
| --- | --- |
| 业务字典 | 打开本页，查看各业务字典的取值 |
| 业务字典：业务字典维护 | 新增、编辑、删除取值（没有此权限时只能查看） |

本页不是平台专属功能：SaaS 模式下，租户套餐中包含「业务字典」菜单时，各租户的管理员都可以维护本企业的业务字典。从旧版本升级时，升级脚本会把本菜单授权给已有「部门管理」菜单的角色，并加入包含「部门管理」的租户套餐。

## 列表

页面顶部的提示：「业务字典由本公司自己维护：可以新增取值（如新的出库类别、客户等级、不良类型）、修改名称和颜色、停用不再使用的取值。标记为「内置」的取值程序依赖，不能删除。状态、单据类型等系统字典由程序内置，不在这里维护。」

列表一次列出全部业务字典（不分页），按字典类型排序：

| 列 | 说明 |
| --- | --- |
| 字典名称 | 如「出库类别」，英文界面显示英文名称 |
| 字典类型 | 字典的编码，如 `wms_out_category` |
| 备注 | 字典的用途说明，如「其他出库、报废出库的用途分类，可在凭证科目设置中按类别指定对方科目」 |
| 操作 | 「**维护取值**」打开该字典的取值抽屉；点击整行也可以打开 |

上方搜索框「搜索字典名称、编码」按字典名称、字典类型或备注筛选，输入即生效。

## 维护取值

点击「维护取值」打开「字典数据：字典名称」抽屉，右上角显示字典类型。

![业务字典取值](/images/manual/system/biz-dict-data.jpg)

抽屉顶部提示：「可以新增取值、修改名称和颜色、停用不再使用的取值；标记为「内置」的取值程序依赖，不能删除、不能改键值。已经用过的取值建议停用而不是删除。」

**列**：数据标签（按设置的颜色显示为标签）、数据键值（内置取值后面带「内置」标记，悬停说明「程序依赖这个取值，不能删除、不能改键值；可以改名称、颜色，不需要时可以停用」）、排序、状态、备注、操作（「编辑」；非内置取值另有「删除」）。

**工具栏**：「搜索标签」按数据标签模糊查询；「新增数据」；勾选后「批量删除」；右侧为导出、刷新、密度。

### 新增 / 编辑取值

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 数据标签 | 是 | 下拉框和标签中显示的文字，如「展会赠品」 |
| 数据键值 | 是 | 系统保存的编码。**大写字母开头，只能包含大写字母、数字、下划线，不超过 16 位**，如 `SAMPLE`、`VIP_2`；同一字典内不能重复。内置取值的键值不能修改（输入框置灰） |
| 标签颜色 | 否 | 从 16 种预设颜色中选择，下方实时预览，默认灰色（default） |
| 排序 | 否 | 下拉框中的顺序，数字小的在前；新增时默认为现有条数 + 1 |
| 状态 | 否 | 启用 / 停用，默认启用 |
| 备注 | 否 | 最多 255 字 |

保存后本浏览器中的字典缓存立即更新；其他已打开系统的用户刷新页面后看到新的取值。

### 删除

- 内置取值不能删除（没有「删除」按钮，批量删除时提示「“标签”是内置取值，程序依赖它，不能删除；不需要时可以停用」）。
- 非内置取值可以删除，但**已经在单据、资料中使用过的取值建议停用而不是删除**：删除后，历史数据中保存的键值找不到对应的名称，列表和详情中只能显示原始键值。

### 停用

停用的取值不再出现在下拉框中，保存单据或资料时也不能再选择它（提示「字段名“键值”不正确，请选择业务字典中启用的取值」）；历史数据仍正常显示原来的名称。已经使用了停用取值的资料再次编辑保存时，需要先改选一个启用的取值。

### 新增取值后程序怎么处理

新增的取值与内置取值一样可以在下拉框中选择、保存、筛选和导出，但**没有内置取值的特殊处理**，例如：

- **假期类型**：年假、调休提交时校验余额，事假全额扣发、病假按比例扣发工资；婚假、产假以及新增的假期类型按普通带薪假处理（不校验余额、不扣工资，已通过的请假在考勤汇总中同样不计旷工）。
- **合同类型**：只有「无固定期限」不填结束日期，其他类型（包括新增的）都必须填写结束日期。
- **停机原因**：内置的「计划保养」「无生产计划」是计划停机，从 OEE 的计划生产时间中扣除；其他原因（包括新增的）都算作可用率损失。
- **入库类别 / 出库类别**：新增后在[凭证科目设置](../fin/account-rule#其他出入库对方科目)中自动出现，可以为新类别单独指定对方科目。
- **流程审批条件**：流程设计器中按字典取值设置条件分支时（如请假类型），可选项包括新增的取值。

## SaaS 多租户

- 业务字典每个租户各自一份。新租户开通时，自动复制平台租户当时的业务字典取值作为初始数据，之后各租户独立维护，互不影响。
- 平台租户在本页维护的是平台自己的取值，同时也是**以后新开通租户**的默认取值；已开通租户的取值不会随之变化。
- 平台管理员在[字典管理](./dict)中新增的业务字典类型，对所有租户可见；已开通的租户需要自行在本页为它新增取值。

## 注意事项

::: tip 提示
- 只改显示文字时修改「数据标签」即可，键值保持不变，历史数据会自动显示新名称。
- 英文界面下，内置取值显示系统内置的英文名称（即使改过中文标签）；新增的取值没有译文，英文界面也显示这里填写的标签。
:::

::: warning 注意
保存单据和资料时，业务字典字段的取值按**本企业**启用的取值校验。导入 Excel 时请填写本企业业务字典中存在的名称或键值。
:::
