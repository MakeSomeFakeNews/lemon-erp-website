# 编码规则

编码规则决定各类单据编号和主数据编码的生成格式，例如采购订单号 `CG202610160001`、销售报价单号 `BJ202610160001`。管理员可以按单据修改前缀、日期格式、流水位数和重置周期。SaaS 模式下每个租户的编码规则相互独立。

## 页面入口

系统管理 → 编码规则

![编码规则](/images/manual/system/code-rule.jpg)

## 列表

工具栏左侧按模块筛选（全部、供应链管理、仓库管理、生产制造、质量管理、财务管理、客户关系、人力资源等），右侧提示「修改后只影响之后新建的单据，已有单号不变」。

| 列 | 说明 |
| --- | --- |
| 单据 | 单据或主数据名称；修改过的规则带「已修改」标记 |
| 模块 | 所属模块 |
| 编号示例 | 按当前规则生成的示例编号 |
| 前缀 | 编号开头的字母 |
| 日期格式 | 年月日、短年月日、年月、短年月、年、不含日期 |
| 流水位数 | 流水号的位数 |
| 重置周期 | 每天、每月、每年、不重置 |
| 操作 | 「修改」；修改过的规则还有「恢复默认」 |

## 编号的组成

**编号 = 前缀 + 日期 + 流水号**

例如前缀 `CG`、日期格式「年月日」、流水 4 位、每天重置：2026 年 10 月 16 日的第 1 张采购订单编号为 `CG202610160001`，第 2 张为 `CG202610160002`，第二天重新从 `0001` 开始。

## 修改编码规则

![修改编码规则](/images/manual/system/code-rule-edit.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 前缀 | 是 | 大写字母、数字和短横线，最多 8 个字符（输入的小写字母自动转为大写）；不能与其他单据重复 |
| 日期格式 | 是 | 年月日（20261015）、短年月日（261015）、年月（202610）、短年月（2610）、年（2026）、不含日期 |
| 流水重置周期 | 是 | 每天、每月、每年、不重置。流水号按周期从 1 开始计数 |
| 流水位数 | 是 | 3～8 位；超出位数时自动加长，不会重复 |

表单下方实时显示「编号预览」。

::: warning 日期至少要精确到重置周期
如果日期格式不够精确，就会产生重复编号。例如日期格式为「年月」却按「每天」重置，每天的流水都从 1 开始而日期部分相同，编号会重复。此时预览下方会提示「日期格式不够精确：流水按『每天』重置时会产生重复编号」，系统也不允许保存。对应关系：

| 重置周期 | 可用的日期格式 |
| --- | --- |
| 每天 | 年月日、短年月日 |
| 每月 | 以上 + 年月、短年月 |
| 每年 | 以上 + 年 |
| 不重置 | 全部，包括不含日期 |
:::

操作步骤：

1. 在列表中找到要修改的单据，点击「修改」。
2. 修改前缀、日期格式、重置周期、流水位数，确认预览符合预期。
3. 点击「保存」。之后新建的单据按新规则取号，已有单据的编号不变。
4. 需要还原时点击「恢复默认」。

## 主数据编码

[物料](../wms/material)、[供应商](../scm/supplier)、[客户](../scm/customer)等主数据也在这里配置编码规则。新增这些资料时**编码留空**，系统按规则自动生成；手工填写编码则以填写的为准。

## 注意事项

::: tip 提示
- 建议在系统上线前确定好编码规则，上线后尽量不再修改，以免同一类单据的编号风格不一致。
- 前缀用于在各种单据之间区分编号，修改时不能与其他单据的前缀重复。
:::
