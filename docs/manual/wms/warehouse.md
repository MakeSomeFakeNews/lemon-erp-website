# 仓库管理

维护企业的仓库。所有库存都归属于某个仓库，仓库类型决定其库存是否参与计划和可用库存计算。

## 页面入口

仓库 → 基础资料 → 仓库管理

![仓库管理](/images/manual/wms/warehouse-list.jpg)

## 列表

**查询条件**：仓库（编码或名称）、状态。

**列表列**：仓库（名称、编码）、类型（寄售仓下方显示关联的客户 / 供应商）、地址、联系人（及电话）、排序、状态（开关，可直接启用 / 停用）、备注。

**操作**：

| 按钮 | 作用 |
| --- | --- |
| 新增仓库 | 打开新增表单 |
| 库位 | 跳转到[库位管理](./location)，并自动按该仓库筛选 |
| 编辑 | 修改仓库 |
| 删除 | 删除仓库及其全部库位（确认提示「确定删除仓库及其库位？」） |

工具栏可导出 Excel。

## 新增 / 编辑仓库

![新增仓库](/images/manual/wms/warehouse-add.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 仓库编码 | 是 | 最多 32 字符，不能重复，如 WH01 |
| 仓库名称 | 是 | 最多 64 字 |
| 仓库类型 | 否 | 默认「普通仓」，见下表 |
| 寄售客户 / 寄售供应商 | 寄售仓必填 | 类型为客户寄售仓时选择客户，供应商寄售仓时选择供应商 |
| 联系人、联系电话、地址 | 否 | — |
| 排序 | 否 | 下拉选项中的排列顺序 |
| 备注 | 否 | 最多 255 字 |

### 仓库类型

| 类型 | 说明 |
| --- | --- |
| 普通仓 | 一般仓库 |
| 原料仓 | 存放原材料，用于区分管理 |
| 成品仓 | 存放成品 |
| 不良品仓 | 存放不良品、过期品。库存**不计入** MRP、齐套分析、可承诺量、补货建议的可用库存；报废入库只能入不良品仓 |
| 客户寄售仓 | 寄放在客户处、客户使用后再结算的库存，不计入可用库存，须关联客户 |
| 供应商寄售仓 | 供应商寄放在本企业的库存（VMI），属于供应商，**不计入存货成本**和可用库存，须关联供应商；只能做「寄售入库」，寄售入库也只能入这类仓库 |

## 注意事项

::: warning 注意
- 已有库存或单据（出入库、调拨、盘点）的仓库不能删除，只能停用；被其他业务引用的也不能删除；
- 停用的仓库不能再入库或作为调入仓库，但可以出库、调出，用于清空剩余库存；
- 删除仓库会同时删除它的全部库位。
:::
