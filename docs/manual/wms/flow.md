# 库存流水

库存流水记录每一次库存变动：哪张单据、什么时间、谁操作、哪个仓库库位批次、增加或减少了多少。它是对账、追查库存差异和成本核算的依据，只能查询，不能修改。

## 页面入口

仓库 → 库存查询 → 库存流水

![库存流水](/images/manual/wms/flow-list.jpg)

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 业务类型 | 入库、出库、调拨、盘点 |
| 物料 | 编码或名称 |
| 仓库 | — |
| 单据号 | 需输入**完整**单据号，如 RK202610140015 |
| 批次号 | 需输入**完整**批次号 |
| 日期 | 流水发生日期范围 |

## 列表列

| 列 | 说明 |
| --- | --- |
| 时间 | 库存变动的时间（单据确认、调拨收货、审批通过的时间） |
| 业务类型 | 入库、出库、调拨、盘点 |
| 单据号 | 产生变动的仓库单据号（业务单据生成的为对应的入库单 / 出库单号） |
| 物料 | 名称，下方为编码和规格 |
| 仓库、库位、批次 | 变动的库存位置 |
| 变动数量 | 带正负号，增加为正、减少为负，带单位 |
| 操作人 | 确认单据的人 |

工具栏可导出 Excel、显示 / 隐藏搜索、刷新、调整密度和列。

## 说明

- 一张调拨单会产生两条流水：调出仓库库位为负、调入为正；在途调拨确认时只有调出流水，收货时才有调入流水；
- 盘点只为有差异的行产生流水；
- 冲销产生的红字单据流水与原单方向相反；
- 财务[成本核算](../fin/cost)按流水的单据种类和数量归集出入库成本。
