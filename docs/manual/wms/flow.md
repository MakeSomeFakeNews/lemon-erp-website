# 库存流水

库存流水记录每一次库存变动：哪张单据、什么时间、谁操作、哪个仓库库位批次、增加或减少了多少，以及这一笔的业务单价、成本价、成本金额和往来单位。它是对账、追查库存差异和成本核算的依据，只能查询，不能修改。

## 页面入口

仓库 → 库存查询 → 库存流水

![库存流水](/images/manual/wms/flow-list.jpg)

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 业务类型 | 入库、出库、调拨、盘点 |
| 物料 | 编码或名称 |
| 仓库 | — |
| 单据号 | 需输入**完整**单据号，如 RK202610140015 |
| 批次号 | 需输入**完整**批次号 |
| 日期 | 流水发生日期范围 |

## 列表列

| 列 | 说明 |
| --- | --- |
| 时间 | 库存变动的时间（单据确认、调拨收货、审批通过的时间） |
| 业务类型 | 入库、出库、调拨、盘点 |
| 单据号 | 产生变动的仓库单据号（业务单据生成的为对应的入库单 / 出库单号） |
| 物料 | 名称，下方为编码和规格 |
| 仓库、库位、批次 | 变动的库存位置 |
| 变动数量 | 带正负号，增加为正、减少为负，带单位 |
| 业务单价 | 来源业务单据的不含税单价（本位币），如采购入库的进价、销售出库的售价；手工单据、调拨、盘点为「-」 |
| 成本价 | 这一笔的实时成本单价（移动加权平均计价的结果，见[实时库存成本](./stock#实时库存成本)）；升级前的历史流水前面显示橙色「近似」标签 |
| 成本金额 | 成本价 × 数量，与数量同号，减少为负数（红色）；供应商寄售仓的库存不计价，为「-」 |
| 往来单位 | 采购入库 / 退货的供应商、销售出库 / 退货的客户（记录的是当时的名称），其他为「-」 |
| 操作人 | 确认单据的人 |

业务单价、成本价、成本金额三列需要「查看成本金额」权限，没有权限时不显示。

工具栏可导出 Excel、显示 / 隐藏搜索、刷新、调整密度和列。

## 说明

- 一张调拨单会产生两条流水：调出仓库库位为负、调入为正；在途调拨确认时只有调出流水，收货时才有调入流水；
- 盘点只为有差异的行产生流水；
- 冲销产生的红字单据流水与原单方向相反；
- 调拨流水按当时的均价记成本金额，但不改变物料的均价；
- 「近似」标签表示该流水发生在系统升级到实时库存成本之前，成本是升级时按单据价格、当月成本核算单价或参考成本价补算的近似值；
- 按物料逐笔查看进出和结余，用库存查询或物料管理中的「[经营历史](./stock#经营历史)」更直观；
- 财务[成本核算](../fin/cost)按流水的单据种类和数量归集出入库成本，月末重新计价，不使用流水上的实时成本价。
