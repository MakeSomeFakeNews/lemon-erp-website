# 库存冻结

需要来料检验的物料采购入库后不能马上使用，入库数量会先冻结为「待检」；来料检验合格（或让步接收）后自动放行，不合格的保持冻结等待退货。本页面列出所有冻结记录，并支持手工放行。

## 页面入口

仓库 → 库存控制 → 库存冻结

![库存冻结](/images/manual/wms/hold-list.jpg)

页面顶部提示：需要来料检验的物料采购入库后冻结为待检；来料检验合格或让步接收后自动放行，不合格的保持冻结，采购退货时优先退冻结的库存。

## 列表

**查询条件**：状态、关键字（物料编码、名称或采购入库单号）。

**列表列**：

| 列 | 说明 |
| --- | --- |
| 采购入库单 | 产生冻结的采购入库单号 |
| 供应商 | — |
| 物料 | 编码、名称、规格 |
| 仓库 / 库位 | 冻结库存所在位置，有批次时显示批次 |
| 冻结 / 入库 | 当前仍冻结的数量 / 入库时冻结的数量 |
| 状态 | 待检、不合格、已放行、已退货 |
| 检验单 | 处理该冻结的检验单号 |
| 放行 | 放行人和时间 |
| 说明 | 放行原因等 |

工具栏可导出 Excel。

## 状态

| 状态 | 说明 |
| --- | --- |
| 待检 | 采购入库后等待来料检验 |
| 不合格 | 来料检验判定不合格，继续冻结，等待采购退货 |
| 已放行 | 检验合格、让步接收、不合格品处置或手工放行后解冻，库存可以正常出库 |
| 已退货 | 已通过采购退货退回供应商 |

## 手工放行

「待检」「不合格」状态的记录，有放行权限的用户可点「放行」：

1. 弹窗显示物料、冻结数量和当前状态；
2. 填写放行原因（不合格的默认填「让步接收」，可改为「复检合格」等）；
3. 点击确定，提示「已放行，库存可以出库」。

## 与其他模块的联动

- 是否需要来料检验在[物料管理](./material)的「追踪方式 → 来料检验」中设置；
- 来料检验在「质量 → [质量检验](../qms/inspection#来料冻结与放行)」中做（类型 IQC，填写采购入库单号），确认合格 / 让步接收后自动放行，不合格保持冻结；检验单填了批次时只处理该批次；
- [不合格品处置](../qms/ncr#处置方式与联动)（让步接收、报废）也会放行，报废时据此生成报废出库；
- [采购退货](../scm/purchase-in#新增采购退货)时先解冻同一订单、同一库存位置的冻结库存（先不合格、后待检）再出库；
- 冻结数量在[库存查询](./stock)的「冻结」列显示，出库、调拨、领料只能使用未冻结的数量；[MRP](../mes/mrp) 把待检数量视为即将可用的库存；
- [首页待办](../guide/home#待办事项)：有检验权限的用户看到「来料待检」，有冻结查看权限的用户看到「来料不合格待退货」。
