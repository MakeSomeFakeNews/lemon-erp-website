# 调拨单

调拨单用于把库存从一个仓库（库位）移到另一个仓库（库位），包括跨仓库调拨、同一仓库内移库（如从收货暂存区上架到存储位）。跨地区运输需要时间的调拨可以使用「[在途调拨](#在途调拨)」：调出后数量挂在途，到货后由调入方分批验收入库，少到、破损、错发、多发等差异登记后单独处理。

仓库、门店之间需要考核调拨金额时，可以选择[同价调拨或差价调拨](#调拨价格)，调拨价作为内部结算价记在单据上；配送产生的运费可以在单据上登记为[调拨费用](#调拨费用)，自动生成费用支出单或承运商应付单。

## 页面入口

仓库 → 库存作业 → 调拨单

![调拨单列表](/images/manual/wms/transfer-list.jpg)

## 列表

**查询条件**：单据号、状态、在途进度（「未完结」「已超过预计到达」，见[在途调拨](#在途调拨)）、仓库、业务日期。

**列表列**：单据号（红字 / 已冲销标签）、调出 → 调入（在途调拨下方显示「在途调拨」）、业务日期、合计数量、调拨金额（只对有「查看成本金额」权限的人显示；调拨金额与调出成本不同时，下方显示「成本 …」）、调拨费用（没有时显示「-」）、状态（未完结的在途调拨下方显示「已验收 X / Y」，超过预计到达日期时以红色显示「预计 … 到达，已超期」）、制单人、确认（确认人，下方为确认时间）、备注、创建时间。调拨金额、调出成本在单据确认（调出）时生成，草稿显示「-」。

点击表格工具栏的下载图标可按当前查询条件**导出**列表：「调出 → 调入」拆成调出仓库、调入仓库、调拨方式（直接调拨 / 在途调拨）三列，「调拨金额」拆成调出成本金额、调拨金额两列，详见[通用操作 → 导出](../guide/common#导出)。

有「查看成本金额」权限时，工具栏还有「**调拨汇总**」按钮，见下文[调拨汇总](#调拨汇总)。

**行操作**：

操作显示为图标，鼠标悬停显示名称：

| 图标（悬停文字） | 出现条件 | 作用 |
| --- | --- | --- |
| 查看 | 所有单据 | 打开详情 |
| 编辑、确认、删除 | 草稿 | 同[入库单](./in#列表) |
| 调拨入库 | 在途、部分到货、验收异常且还有未到数量，有「调拨验收入库」权限 | 打开[调拨入库（验收）](#调拨入库验收)窗口，录入本次验收入库的数量、登记差异 |
| 冲销 | 已完成的手工调拨单（在途调拨须全部验收入库，没有退回、损耗） | 生成红字调拨单，库存反向调回；有调拨费用时同时生成红字的费用单据 |

## 新增调拨单

![新增调拨单](/images/manual/wms/transfer-add.jpg)

### 表头字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 调出仓库 | 是 | 可选择已停用的仓库（用于把库存调走）。更换后清空已选明细 |
| 调入仓库 | 是 | 必须是启用的仓库，可以与调出仓库相同（库内移库）。更换后清空各行的调入库位 |
| 业务日期 | 是 | 默认今天 |
| 在途调拨 | 否 | 开关，「直接调拨」/「在途」。开启后提示「确认时只调出（数量挂在途），调入仓库分批验收入库，差异处理完毕后完成」 |
| 预计到达 | 否 | 在途调拨时显示，可不填（提示「可不填；超过仍未完结时首页提醒」）。不能早于业务日期 |
| 调拨价格 | 是 | 默认「同价调拨」；选择参考成本价、库存均价、最低售价、零售价、批发价等依据时为差价调拨，见[调拨价格](#调拨价格) |
| 价格系数 | 差价调拨时 | 调拨价 = 依据价 × 系数，默认 1，可以大于 1（如 1.05 表示加价 5%），最多 4 位小数 |
| 调拨费用 | 否 | 配送费等，大于 0 时显示结算方式等字段，见[调拨费用](#调拨费用) |
| 结算方式 | 有调拨费用时 | 「现付」（默认）/「月结」 |
| 结算账户 | 现付时 | 付款的现金、银行账户 |
| 承运商 | 月结时 | 下拉只列出[物流公司](../scm/supplier#物流公司)；现付时可不选 |
| 备注 | 否 | — |

### 明细

与出库单一样，点「从库存选择」从**调出仓库**的现有库存中勾选（只显示可用数量，弹窗中有批次的生产日期、有效期），然后填写：

| 字段 | 说明 |
| --- | --- |
| 物料、调出库位、批次 | 来自所选库存 |
| 调入库位 | 调入仓库的库位，可不选（未指定）。调出、调入的仓库和库位不能完全相同 |
| 数量 | 必填，大于 0，不超过可用数量 |
| 调出成本价 | 只对有「查看成本金额」权限的人显示。草稿中显示物料的当前均价，下方提示「确认时按调出成本生成」 |
| 调拨价 | 只对有「查看成本金额」权限的人显示。同价调拨显示「= 调出成本价」，不能修改；差价调拨按 依据价 × 系数 自动带出，可以逐行修改，不填（提示「不填按调出成本价」）时按调出成本价 |
| 调拨金额 | 只对有「查看成本金额」权限的人显示。数量 × 调拨价的预估金额（同价调拨或调拨价为空时按当前均价），确认时按实际调出成本重新计算 |
| 序列号 | 序列号物料从该位置的在库序列号中选择或扫码 |
| 备注 | 可选 |

选择调入仓库后可点「**推荐库位**」，按上架策略为未选调入库位的行推荐库位（见[上架策略](./label-putaway#上架策略)）。

### 操作步骤

1. 点击「新增调拨单」，选择调出仓库、调入仓库，需要时打开「在途调拨」；
2. 需要按差价考核时选择「调拨价格」的依据并填写价格系数；有配送费时填写「调拨费用」、结算方式和结算账户（或承运商）；
3. 点「从库存选择」勾选要调拨的库存，填写数量、调入库位（或点「推荐库位」），差价调拨时核对或修改各行的调拨价；
4. 保存为草稿；
5. 确认调拨：直接调拨时调出、调入同时完成；在途调拨时只扣减调出仓库，单据变为「在途」。确认时生成调出成本价、调拨价和调拨金额，有调拨费用时生成费用支出单（现付）或承运商应付单（月结）；
6. 在途调拨的货物到达后，调入方在列表或详情点「**调拨入库**」分批验收入库，有差异时登记并处理，见下文[在途调拨](#在途调拨)。

## 在途调拨

跨地区运输需要时间时，在新增调拨单时打开「在途调拨」。确认（调出）时只扣减调出仓库，数量挂在途，单据状态为「在途」；货物到达后由调入方**引用这张调拨单**分批验收入库，到货与发货不一致的登记为差异，由有权限的人处理。全部数量都有了去向后单据自动完成。

### 在途进度

已确认的在途调拨，详情的明细把「数量」显示为「**实发**」，并增加以下列：

| 列 | 说明 |
| --- | --- |
| 已验收 | 已验收入库的数量（含让步接收的差异） |
| 未到 | 还没有验收、也没有登记差异或处理的数量 = 实发 − 已验收 − 差异待处理 − 退回 − 损耗 |
| 差异待处理 | 验收时登记、还没有处理的差异数量（不含多发），有数量时以红色显示 |
| 退回 | 差异或未到量退回调出仓的数量 |
| 损耗 | 差异或未到量确认损耗的数量 |
| 进度 | 进度条 =（已验收 + 退回 + 损耗）÷ 实发；有差异待处理时显示为异常 |

表头另有「预计到达」（超过且未完结时显示「已超期」标签）、「最近验收」（验收人、时间和验收日期），由补发生成的调拨单显示「原调拨单」。明细下方依次是**验收记录**、**差异**和**补发 / 补调的调拨单**，见下文。

### 调拨入库（验收） {#调拨入库验收}

需要「调拨验收入库」权限。调拨入库只能从未完结的在途调拨单发起：在列表或详情点「**调拨入库**」，打开「调拨入库（验收）DB…」窗口，提示「调出仓 → 调入仓：录入本次实际验收合格的数量（默认全部未到量），验收入库的数量进入调入仓库，按调出时的批次、序列号和成本入库；少到、破损、错发、多发请登记差异，差异数量不入库，由有权限的人处理。每次验收生成一张验收单，可分多次验收。」

表头：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 验收日期 | 是 | 默认当天，不能早于调拨单的业务日期（否则提示「收货日期 … 不能早于调拨日期 …」）；所在月份已结账时不能验收 |
| 物流单号 | 否 | 最多 64 个字符 |
| 车牌号 | 否 | 最多 32 个字符 |
| 备注 | 否 | — |

明细只列出还有未到数量的行，上方显示「本次验收入库 X，登记差异 Y」，以及「**全部到货**」（每行验收数量 = 未到数量，清除差异）、「**清空验收数量**」两个按钮：

| 列 | 说明 |
| --- | --- |
| 物料 | 编码、名称，下方为规格和批次 |
| 未到 / 实发 | 本行的未到数量和实发数量；本行验收与差异合计超过未到数量时显示「超过未到数量」 |
| 验收入库 | 默认等于未到数量，可以改小；序列号物料改为从本行**未到的序列号**中选择（默认全选） |
| 差异类型 | 默认「无差异」，可选「少到」「破损」「错发」「多发」。选择后差异数量默认为 未到数量 − 本次验收 |
| 差异数量 | 选择差异类型后填写；序列号物料（多发除外）从未到的序列号中选择差异的序列号，多发的序列号可以手工输入（可不填，不能是本调拨单上的序列号） |
| 差异说明 | 可选 |

点击「**确认入库**」：

- 每行「验收入库 + 差异数量」不能超过未到数量（**多发除外**，多发在实发之外），否则提示「…：验收入库与差异合计超过未到数量，多发请选择「多发」」；填写了差异数量但没选差异类型时提示「填写了差异数量的行请选择差异类型」；验收和差异都没有填写时提示「请填写验收入库数量或登记差异」；
- 验收入库的数量按调出时的**批次、序列号**进入调入仓库的调入库位，按**调出时的成本**计价；差异数量不入库，挂在「差异待处理」中；
- 每次验收生成一张**调拨验收单**（单号以 DR 开头），成功提示「验收入库成功」。货物分几批到达时，每批做一次调拨入库即可。

详情的「**验收记录**」列出各次验收单：验收单号、验收日期、验收数量、差异数量、物流单号 / 车牌、验收人（下方为时间）、备注，展开可看到本次验收的物料、批次、调入库位、数量和序列号。行末「打印」打印**调拨验收单**（表头有调拨单号、调出仓库、调入仓库、验收日期、物流单号、车牌号、验收数量、差异数量，明细为本次验收入库的物料、批次、调入库位、验收数量、序列号，签字栏为验收人、送货人、复核），模板为「调拨验收单」，可以在[打印模板](../system/print-template)中调整。

手机上可以用微信小程序的[调拨验收](../miniapp/warehouse#调拨验收)扫码验收。

### 差异处理

需要「调拨差异处理」权限（内置角色仓库管理员已授权）。详情的「**差异**」表列出登记的差异：物料（批次）、差异类型（下方为登记差异的验收单号）、差异数量、序列号、差异说明、处理方式（待处理显示「待处理」，已处理显示处理方式、处理日期、处理人、生成的单据和处理说明），表头显示「N 条待处理」。待处理的差异点行末「**处理**」，在「处理差异」窗口中选择处理方式：

| 处理方式 | 说明 |
| --- | --- |
| 退回调出仓 | 差异数量回到调出仓库的调出库位（按调出成本），如少发、错发、破损退回 |
| 确认损耗 | 差异数量退回调出仓库后生成一张[报废出库单](./out)（来源单号为本调拨单号），按调出成本出库计入损失，成本凭证按报废出库处理；处理日期所在月份的存货已结账时不能确认损耗 |
| 让步接收 | 差异数量按原批次、序列号入调入仓库（如破损不影响使用、后来又到了），计入已验收 |

**多发**的货品不在调拨单的实发中，处理方式只有两种（不能确认损耗）：

| 处理方式 | 说明 |
| --- | --- |
| 退回实物 | 多发的货品退回调出方，系统没有记录这部分库存，不变动库存 |
| 确认调入 | 生成一张调出仓 → 调入仓的**直接调拨**草稿（关联本单），由调出方确认后调出仓扣减、调入仓入库 |

- 「处理数量」默认为全部差异数量，可以改小（序列号物料选择要处理的序列号）：少于差异数量时只处理这部分，其余继续待处理，差异记录拆成已处理、待处理两条；
- 「处理日期」默认当天，不能早于调拨单的业务日期；可以填写处理说明；
- 生成的报废出库单、调拨单草稿在差异的「处理方式」下方显示单号，点击可以打开。

### 处理未到量

货物确实丢失、或者有一部分没有发出 / 被召回时，有「调拨差异处理」权限的人在详情点「**处理未到量**」，把剩余的全部未到数量一次处理：

- **确认损耗**：确有丢失时使用，生成报废出库单计入损失（差异类型记为「在途丢失」）；
- **退回调出仓**：未发出或召回时使用，数量回到调出仓库。

未到量不能让步接收，到货的请做调拨入库。处理后每行生成一条已处理的差异记录。

### 单据状态与自动完成

| 状态 | 含义 |
| --- | --- |
| 在途 | 已调出，还没有验收、退回或损耗 |
| 部分到货 | 已部分验收（或退回 / 损耗），仍有未到的数量 |
| 验收异常 | 有登记了差异、待处理的数量 |
| 已完成 | 实发 = 已验收 + 退回 + 损耗，且没有待处理的差异 |

每次验收、处理差异、处理未到量后系统自动更新状态，满足条件时自动变为「已完成」，不能手工完成。在途、部分到货、验收异常的单据都可以继续验收和处理差异。

### 预计到达日期与待办

- 新增在途调拨时可以填写「预计到达」日期，超过该日期仍未完结的，列表和详情显示「已超期」；
- 列表的「在途进度」条件：「未完结」列出在途、部分到货、验收异常的单据，「已超过预计到达」列出超期未完结的单据；
- 首页[待办事项](../guide/home#待办事项)有「在途调拨待验收」（在途、部分到货，需要调拨验收入库权限）、「在途调拨超过预计到达日期」（需要调拨单查看权限）、「调拨差异待处理」（验收异常，需要调拨差异处理权限），点击打开调拨单列表并带上对应的筛选。

### 生成补发调拨单

有退回、损耗或差异待处理（不含多发）的数量时，有调拨单新增权限的人可以在详情点「**生成补发调拨单**」：打开新增调拨单，带出原单的调出仓库、调入仓库、库位和批次，数量为各行退回 + 损耗 + 差异待处理的数量，默认在途调拨、备注「补发 原单号」，表单顶部提示「补发调拨单，关联原在途调拨单 …」。保存确认后原单详情的「补发 / 补调的调拨单」中列出这张单据（单号、日期、数量、状态），点击可以打开。

### 数据权限

调拨入库、差异处理与调拨单使用相同的[数据权限](../system/role#数据权限页签)（制单人所在部门 + 制单人）：能看到这张调拨单的人，才能对它验收和处理差异。调入方需要验收时，请给调入仓库的人员授予能看到调出方单据的数据范围。

## 调拨价格

调拨价是调拨单上的**内部结算价**，用于仓库、门店之间考核调拨金额。

| 调拨价格 | 调拨价 | 用途 |
| --- | --- | --- |
| 同价调拨（默认） | = 调出成本价（确认时按实际调出成本生成），不能修改 | 只移动库存，调拨金额就是调出的成本 |
| 参考成本价 × 系数 | 物料资料中的参考成本价 × 系数 | 按标准成本考核 |
| 库存均价 × 系数 | 物料的当前库存均价 × 系数 | 按成本加价考核，如系数 1.05 |
| 最低售价 × 系数 | [价格控制](../scm/sales#价格控制)中设置的最低销售价 × 系数 | 按最低售价考核门店 |
| 零售价 / 批发价 × 系数 | 物料的零售价或批发价 1–8 × 系数（只列出启用的[价格列](./material#价格列设置)；售价为含税价，按原值计算） | 按配送价、批发价供货给门店 |

- 修改依据或系数时，所有明细的调拨价按 依据价 × 系数 批量重新计算；新从库存中选择的明细也自动带出调拨价。物料没有依据价时提示「N 行没有依据价，按调出成本价」，这些行的调拨价留空，确认时按调出成本价；
- 批量计算后可以逐行修改调拨价（最多 4 位小数）；
- 确认（调出）时，系统按实际调出的成本生成每行的**调出成本价**，同价调拨或调拨价为空的行调拨价 = 调出成本价，并计算调拨金额（数量 × 调拨价）和表头的调出成本金额、调拨金额；**调拨差价** = 调拨金额 − 调出成本金额；
- 调出成本价、调拨价、调拨金额和差价**只对有「查看成本金额」权限的人显示**（同价调拨的调拨价就是成本）。没有该权限的人也可以开差价调拨单：看不到也不能填写明细的调拨价，保存时由系统按依据价 × 系数计算。

::: tip 调拨价为什么不影响库存成本和凭证
系统的存货成本按物料**全公司**计算移动加权平均（不分仓库，见[实时库存成本](./stock#实时库存成本)）。同一公司内部的调拨只是存放地点变化，不改变存货的价值，因此调出、调入的流水仍按调出成本计价、金额相抵，调拨价只记在单据上和库存流水的业务单价中：

- 不改变物料的均价、库存金额、[收发存汇总](./inout)、[库龄](../fin/analysis#库龄分析)和月末[成本核算](../fin/cost)；
- 不生成凭证，调拨差价不是收入或利润，只用于仓库 / 门店之间的内部考核，在[调拨汇总](#调拨汇总)中统计。

各门店是独立核算的公司、需要核算双方的货款和利润时，请改用销售单处理，见[连锁店之间的往来业务](../scm/sales-out#连锁店之间的往来业务)。
:::

## 调拨费用

调拨配送产生的运费（配送费）由本公司承担，在表头填写「调拨费用」后选择结算方式，管理方式与[销售出库本公司承担的运费](../scm/sales-out#销售出库的运费)一致：

| 结算方式 | 表单提示 | 确认时生成 |
| --- | --- | --- |
| 现付（默认） | 本公司承担、现付：确认时生成费用支出单（类别「调拨费用」，来源为本调拨单，可互相联查），出纳确认后 借 调拨费用（默认销售费用）/ 贷 结算账户；计入当期费用，不计入存货成本，冲销时生成红字单据 | 一张待确认的[费用支出单](../fin/other-income#业务单据生成的费用支出单)（内置类别「调拨费用」），必须选择结算账户，承运商可不选 |
| 月结 | 本公司承担、月结：确认时生成承运商的应付单（借 调拨费用 / 贷 应付账款-承运商），以后付款核销；计入当期费用，不计入存货成本，冲销时生成红字应付 | 承运商的[应付单](../fin/ar-ap)（来源「调拨费用」），必须选择承运商 |

- 现付没有选择结算账户时提示「调拨费用现付时请选择付款账户」，月结没有选择承运商时提示「调拨费用月结时请选择承运商」；
- 调拨费用**计入当期费用，不计入存货成本**：内部调拨不增加存货的价值，且存货成本不分仓库，计入成本只会抬高全公司的均价。现付按内置收支类别「调拨费用」的科目入账，月结按[凭证科目设置](../fin/account-rule#运费科目)中的「调拨费用」入账，默认都是 6601 销售费用；
- 费用单据在确认（调出）时生成，与确认同时完成；单据日期所在期间已结账等原因导致生成失败时，调拨单也不能确认；
- 在途调拨的费用同样在确认（调出）时生成，验收时不再生成；
- **冲销**调拨单时，红字调拨单带负数的调拨费用，按原单的结算方式生成红字费用支出单（现付）或红字承运商应付单（月结），业务日期为冲销当天；原来的费用单据不变。

## 调拨汇总

在列表工具栏点「**调拨汇总**」（需要调拨单查看和「查看成本金额」权限），按**调出仓库 → 调入仓库**汇总已调出的调拨单（含在途、红字冲销）：

- 查询条件：业务日期范围（打开时沿用列表的业务日期）、仓库（可不选）；
- 列：调出 → 调入、单数、调出数量、在途数量、退回 / 损耗、调出成本金额、调拨金额、调拨差价、调拨费用，底部为合计；
- 在途调拨退回调出仓、确认损耗的数量不算调出：调出数量、调出成本金额、调拨金额都已扣除这部分，扣除的数量列在「退回 / 损耗」中；「在途数量」为尚未验收的数量；
- 按调拨单的数据权限统计。调拨差价是仓库 / 门店之间的内部结算差额，不影响存货成本和利润。

## 详情

![调拨单详情](/images/manual/wms/transfer-detail.jpg)

详情显示调出仓库、调入仓库、调拨方式（直接调拨 / 在途调拨）、调拨价格（「同价调拨」或「差价调拨（依据 × 系数）」，如「差价调拨（批发价1 × 1.05）」）、业务日期、合计数量、调出成本金额 / 调拨金额 / 调拨差价（确认后，有「查看成本金额」权限时）、调拨费用（金额和「现付」或「月结」标签，下方为承运商、结算账户；现付生成了费用支出单的显示「费用支出单」，有其他收支查看权限时点击跳转到[其他收支](../fin/other-income)并打开该单据；月结显示「已生成承运商应付单」）、制单、确认、在途调拨的预计到达和最近验收（验收人、时间和验收日期），以及明细（物料、调出库位、调入库位、批次（下方显示批次登记的生产日期 ~ 有效期）、数量、调出成本价、调拨价、调拨金额（价格金额列只对有「查看成本金额」权限的人显示）、序列号；在途调拨另有实发、已验收、未到、差异待处理、退回、损耗和进度，见[在途进度](#在途进度)）。右上角「打印」；底部按钮：草稿「编辑」「确认调拨」，未完结的在途调拨「调拨入库」「处理未到量」，有退回、损耗或差异待处理时「生成补发调拨单」，已完成的手工单据「冲销」。

从费用支出单、应付单的「来源单据」也可以打开调拨单详情。

### 打印

调拨单打印的表头除原有字段外，还有调拨价格、调出成本金额、调拨金额、调拨差价、调拨费用、结算方式、结算账户、承运商；明细在数量之后有调出成本价、调拨价、调拨金额列，合计行显示调拨金额。价格和金额只在打印人有「查看成本金额」权限时有值，没有该权限时为空。新字段按默认显示在末尾，可以在[打印模板](../system/print-template)中取消勾选或调整顺序。

## 单据状态

| 状态 | 说明 | 可做操作 |
| --- | --- | --- |
| 草稿 | 未影响库存 | 编辑、删除、确认 |
| 审批中 | 发布「出入库审批」流程后确认的单据 | 等待审批，通过后执行调拨 |
| 在途 | 在途调拨已从调出仓库扣减，尚未验收 | 调拨入库、处理未到量（不能冲销） |
| 部分到货 | 在途调拨已部分验收（或退回 / 损耗），仍有未到数量 | 调拨入库、处理差异、处理未到量 |
| 验收异常 | 在途调拨有待处理的差异 | 处理差异、调拨入库、处理未到量 |
| 已完成 | 调拨完成（在途调拨为数量守恒、差异处理完毕后自动完成） | 查看、打印、冲销（在途调拨须全部验收入库，有退回或损耗的不能冲销） |

## 与其他模块的联动

- 调拨不影响存货成本，确认只受财务[结账](../fin/period)限制（不受[成本核算](../fin/cost)限制）；[实时库存成本](./stock#实时库存成本)按全公司计算均价，调拨（含在途）不改变物料的数量和均价，库存流水按当时的均价记金额，业务单价记为调拨价；在途调拨验收入库、退回调出仓、让步接收都按**调出时的成本**计价，调出、调入金额相抵；确认损耗生成的报废出库单按调出成本出库，计入损失；
- 调拨价、调拨差价只是内部结算价，不生成凭证；调拨费用生成[费用支出单](../fin/other-income#业务单据生成的费用支出单)（现付）或承运商[应付单](../fin/ar-ap)（月结），计入当期费用；
- 按仓库统计的报表（[收发存汇总](./inout)、[经营历史](./stock#经营历史)、[库龄分析](../fin/analysis#库龄分析)、商务智能的库存金额等）中，在途调拨的验收入库、退回、让步接收按**各次操作的日期**（库存流水的业务日期，如每张验收单的验收日期）统计，调出按调拨单的业务日期统计；
- 调出同样要满足[库存预留](./reservation)：调走后仓库可用库存不能少于预留；
- 过期批次可以调拨到不良品仓隔离，不良品仓的库存不参与 [MRP](../mes/mrp)、[齐套分析](../mes/kit)、[可承诺量](../scm/sales#可承诺量)；
- 手机上的[上架](../mobile/putaway)会生成同仓库的调拨单（备注「移动上架」）。

## 供应商寄售仓

供应商寄售仓的货物属于供应商，不计入本公司存货成本，因此：

- **不能在供应商寄售仓与本公司仓库之间调拨**，否则提示「供应商寄售仓（仓库名）的货物属于供应商，不能与本公司的仓库互相调拨：领用请做寄售结算，退回供应商请做其他出库」。需要使用寄售货物时，在[寄售结算](../scm/consign)中办理（结算时采购入库到本公司仓库，同时从寄售仓做寄售消耗出库）；退回供应商时在寄售仓做[其他出库](./out)；
- 只能在**同一供应商**的寄售仓之间调拨，不同供应商的寄售仓之间调拨提示「只能在同一供应商的寄售仓之间调拨」。

客户寄售仓的货物仍属于本公司，可以正常调拨。

## 注意事项

::: tip 提示
调拨单号格式为 DB + 日期 + 4 位流水号。
:::

::: warning 注意
- 在途期间货物不在任何仓库的库存中，请及时验收；
- 验收、退回按操作日期检查期间，日期所在月份已结账时不能操作；确认损耗影响存货成本，存货已结账的月份不能确认损耗；
- 在途调拨未完结（在途、部分到货、验收异常）时不能冲销，提示「在途调拨未完结，验收入库、差异处理完毕后才能冲销」；有退回调出仓或确认损耗数量的在途调拨完成后也不能冲销；
- 盘点单勾选「冻结仓库」期间，调出、调入仓库都不能调拨。
:::

调拨单只处理同一公司内部的库存移动。连锁店各自独立核算、需要核算双方的货款、往来和利润时，请见[连锁店之间的往来业务](../scm/sales-out#连锁店之间的往来业务)。
