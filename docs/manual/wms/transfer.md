# 调拨单

调拨单用于把库存从一个仓库（库位）移到另一个仓库（库位），包括跨仓库调拨、同一仓库内移库（如从收货暂存区上架到存储位）。跨地区运输需要时间的调拨可以使用「在途调拨」，到货后由调入方收货。

仓库、门店之间需要考核调拨金额时，可以选择[同价调拨或差价调拨](#调拨价格)，调拨价作为内部结算价记在单据上；配送产生的运费可以在单据上登记为[调拨费用](#调拨费用)，自动生成费用支出单或承运商应付单。

## 页面入口

仓库 → 库存作业 → 调拨单

![调拨单列表](/images/manual/wms/transfer-list.jpg)

## 列表

**查询条件**：单据号、状态、仓库、业务日期。

**列表列**：单据号（红字 / 已冲销标签）、调出 → 调入（在途调拨下方显示「在途调拨」）、业务日期、合计数量、调拨金额（只对有「查看成本金额」权限的人显示；调拨金额与调出成本不同时，下方显示「成本 …」）、调拨费用（没有时显示「-」）、状态、制单人、确认（确认人，下方为确认时间）、备注、创建时间。调拨金额、调出成本在单据确认（调出）时生成，草稿显示「-」。

点击表格工具栏的下载图标可按当前查询条件**导出**列表：「调出 → 调入」拆成调出仓库、调入仓库、调拨方式（直接调拨 / 在途调拨）三列，「调拨金额」拆成调出成本金额、调拨金额两列，详见[通用操作 → 导出](../guide/common#导出)。

有「查看成本金额」权限时，工具栏还有「**调拨汇总**」按钮，见下文[调拨汇总](#调拨汇总)。

**行操作**：

操作显示为图标，鼠标悬停显示名称：

| 图标（悬停文字） | 出现条件 | 作用 |
| --- | --- | --- |
| 查看 | 所有单据 | 打开详情 |
| 编辑、确认、删除 | 草稿 | 同[入库单](./in#列表) |
| 收货 | 在途状态，有收货权限 | 确认调入仓库已收货（可选择收货日期），增加调入仓库库存 |
| 冲销 | 已完成的手工调拨单 | 生成红字调拨单，库存反向调回；有调拨费用时同时生成红字的费用单据 |

## 新增调拨单

![新增调拨单](/images/manual/wms/transfer-add.jpg)

### 表头字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 调出仓库 | 是 | 可选择已停用的仓库（用于把库存调走）。更换后清空已选明细 |
| 调入仓库 | 是 | 必须是启用的仓库，可以与调出仓库相同（库内移库）。更换后清空各行的调入库位 |
| 业务日期 | 是 | 默认今天 |
| 在途调拨 | 否 | 开关，「直接调拨」/「在途」。开启后确认时只调出，调入仓库收货后才入库 |
| 调拨价格 | 是 | 默认「同价调拨」；选择参考成本价、库存均价、最低售价、零售价、批发价等依据时为差价调拨，见[调拨价格](#调拨价格) |
| 价格系数 | 差价调拨时 | 调拨价 = 依据价 × 系数，默认 1，可以大于 1（如 1.05 表示加价 5%），最多 4 位小数 |
| 调拨费用 | 否 | 配送费等，大于 0 时显示结算方式等字段，见[调拨费用](#调拨费用) |
| 结算方式 | 有调拨费用时 | 「现付」（默认）/「月结」 |
| 结算账户 | 现付时 | 付款的现金、银行账户 |
| 承运商 | 月结时 | 下拉只列出[物流公司](../scm/supplier#物流公司)；现付时可不选 |
| 备注 | 否 | — |

### 明细

与出库单一样，点「从库存选择」从**调出仓库**的现有库存中勾选（只显示可用数量，弹窗中有批次的生产日期、有效期），然后填写：

| 字段 | 说明 |
| --- | --- |
| 物料、调出库位、批次 | 来自所选库存 |
| 调入库位 | 调入仓库的库位，可不选（未指定）。调出、调入的仓库和库位不能完全相同 |
| 数量 | 必填，大于 0，不超过可用数量 |
| 调出成本价 | 只对有「查看成本金额」权限的人显示。草稿中显示物料的当前均价，下方提示「确认时按调出成本生成」 |
| 调拨价 | 只对有「查看成本金额」权限的人显示。同价调拨显示「= 调出成本价」，不能修改；差价调拨按 依据价 × 系数 自动带出，可以逐行修改，不填（提示「不填按调出成本价」）时按调出成本价 |
| 调拨金额 | 只对有「查看成本金额」权限的人显示。数量 × 调拨价的预估金额（同价调拨或调拨价为空时按当前均价），确认时按实际调出成本重新计算 |
| 序列号 | 序列号物料从该位置的在库序列号中选择或扫码 |
| 备注 | 可选 |

选择调入仓库后可点「**推荐库位**」，按上架策略为未选调入库位的行推荐库位（见[上架策略](./label-putaway#上架策略)）。

### 操作步骤

1. 点击「新增调拨单」，选择调出仓库、调入仓库，需要时打开「在途调拨」；
2. 需要按差价考核时选择「调拨价格」的依据并填写价格系数；有配送费时填写「调拨费用」、结算方式和结算账户（或承运商）；
3. 点「从库存选择」勾选要调拨的库存，填写数量、调入库位（或点「推荐库位」），差价调拨时核对或修改各行的调拨价；
4. 保存为草稿；
5. 确认调拨：直接调拨时调出、调入同时完成；在途调拨时只扣减调出仓库，单据变为「在途」。确认时生成调出成本价、调拨价和调拨金额，有调拨费用时生成费用支出单（现付）或承运商应付单（月结）；
6. 在途调拨的货物到达后，在列表或详情点「收货」，在确认框中选择「收货日期」（默认当天，不能早于调拨单的业务日期，否则提示「收货日期 … 不能早于调拨日期 …」），确认后调入仓库按明细入库，单据变为「已完成」。

## 调拨价格

调拨价是调拨单上的**内部结算价**，用于仓库、门店之间考核调拨金额。

| 调拨价格 | 调拨价 | 用途 |
| --- | --- | --- |
| 同价调拨（默认） | = 调出成本价（确认时按实际调出成本生成），不能修改 | 只移动库存，调拨金额就是调出的成本 |
| 参考成本价 × 系数 | 物料资料中的参考成本价 × 系数 | 按标准成本考核 |
| 库存均价 × 系数 | 物料的当前库存均价 × 系数 | 按成本加价考核，如系数 1.05 |
| 最低售价 × 系数 | [价格控制](../scm/sales#价格控制)中设置的最低销售价 × 系数 | 按最低售价考核门店 |
| 零售价 / 批发价 × 系数 | 物料的零售价或批发价 1–8 × 系数（只列出启用的[价格列](./material#价格列设置)；售价为含税价，按原值计算） | 按配送价、批发价供货给门店 |

- 修改依据或系数时，所有明细的调拨价按 依据价 × 系数 批量重新计算；新从库存中选择的明细也自动带出调拨价。物料没有依据价时提示「N 行没有依据价，按调出成本价」，这些行的调拨价留空，确认时按调出成本价；
- 批量计算后可以逐行修改调拨价（最多 4 位小数）；
- 确认（调出）时，系统按实际调出的成本生成每行的**调出成本价**，同价调拨或调拨价为空的行调拨价 = 调出成本价，并计算调拨金额（数量 × 调拨价）和表头的调出成本金额、调拨金额；**调拨差价** = 调拨金额 − 调出成本金额；
- 调出成本价、调拨价、调拨金额和差价**只对有「查看成本金额」权限的人显示**（同价调拨的调拨价就是成本）。没有该权限的人也可以开差价调拨单：看不到也不能填写明细的调拨价，保存时由系统按依据价 × 系数计算。

::: tip 调拨价为什么不影响库存成本和凭证
系统的存货成本按物料**全公司**计算移动加权平均（不分仓库，见[实时库存成本](./stock#实时库存成本)）。同一公司内部的调拨只是存放地点变化，不改变存货的价值，因此调出、调入的流水仍按调出成本计价、金额相抵，调拨价只记在单据上和库存流水的业务单价中：

- 不改变物料的均价、库存金额、[收发存汇总](./inout)、[库龄](../fin/analysis#库龄分析)和月末[成本核算](../fin/cost)；
- 不生成凭证，调拨差价不是收入或利润，只用于仓库 / 门店之间的内部考核，在[调拨汇总](#调拨汇总)中统计。

各门店是独立核算的公司、需要核算双方的货款和利润时，请改用销售单处理，见[连锁店之间的往来业务](../scm/sales-out#连锁店之间的往来业务)。
:::

## 调拨费用

调拨配送产生的运费（配送费）由本公司承担，在表头填写「调拨费用」后选择结算方式，管理方式与[销售出库本公司承担的运费](../scm/sales-out#销售出库的运费)一致：

| 结算方式 | 表单提示 | 确认时生成 |
| --- | --- | --- |
| 现付（默认） | 本公司承担、现付：确认时生成费用支出单（类别「调拨费用」，来源为本调拨单，可互相联查），出纳确认后 借 调拨费用（默认销售费用）/ 贷 结算账户；计入当期费用，不计入存货成本，冲销时生成红字单据 | 一张待确认的[费用支出单](../fin/other-income#业务单据生成的费用支出单)（内置类别「调拨费用」），必须选择结算账户，承运商可不选 |
| 月结 | 本公司承担、月结：确认时生成承运商的应付单（借 调拨费用 / 贷 应付账款-承运商），以后付款核销；计入当期费用，不计入存货成本，冲销时生成红字应付 | 承运商的[应付单](../fin/ar-ap)（来源「调拨费用」），必须选择承运商 |

- 现付没有选择结算账户时提示「调拨费用现付时请选择付款账户」，月结没有选择承运商时提示「调拨费用月结时请选择承运商」；
- 调拨费用**计入当期费用，不计入存货成本**：内部调拨不增加存货的价值，且存货成本不分仓库，计入成本只会抬高全公司的均价。现付按内置收支类别「调拨费用」的科目入账，月结按[凭证科目设置](../fin/account-rule#运费科目)中的「调拨费用」入账，默认都是 6601 销售费用；
- 费用单据在确认（调出）时生成，与确认同时完成；单据日期所在期间已结账等原因导致生成失败时，调拨单也不能确认；
- 在途调拨的费用同样在确认（调出）时生成，收货时不再生成；
- **冲销**调拨单时，红字调拨单带负数的调拨费用，按原单的结算方式生成红字费用支出单（现付）或红字承运商应付单（月结），业务日期为冲销当天；原来的费用单据不变。

## 调拨汇总

在列表工具栏点「**调拨汇总**」（需要调拨单查看和「查看成本金额」权限），按**调出仓库 → 调入仓库**汇总已调出的调拨单（含在途、红字冲销）：

- 查询条件：业务日期范围（打开时沿用列表的业务日期）、仓库（可不选）；
- 列：调出 → 调入、单数、合计数量、调出成本金额、调拨金额、调拨差价、调拨费用，底部为合计；
- 按调拨单的数据权限统计。调拨差价是仓库 / 门店之间的内部结算差额，不影响存货成本和利润。

## 详情

详情显示调出仓库、调入仓库、调拨方式（直接调拨 / 在途调拨）、调拨价格（「同价调拨」或「差价调拨（依据 × 系数）」，如「差价调拨（批发价1 × 1.05）」）、业务日期、合计数量、调出成本金额 / 调拨金额 / 调拨差价（确认后，有「查看成本金额」权限时）、调拨费用（金额和「现付」或「月结」标签，下方为承运商、结算账户；现付生成了费用支出单的显示「费用支出单」，有其他收支查看权限时点击跳转到[其他收支](../fin/other-income)并打开该单据；月结显示「已生成承运商应付单」）、制单、确认、收货信息（收货人、收货时间和收货日期），以及明细（物料、调出库位、调入库位、批次（下方显示批次登记的生产日期 ~ 有效期）、数量、调出成本价、调拨价、调拨金额（价格金额列只对有「查看成本金额」权限的人显示）、序列号）。右上角「打印」；底部按钮：草稿「编辑」「确认调拨」，在途「收货」，已完成的手工单据「冲销」。

从费用支出单、应付单的「来源单据」也可以打开调拨单详情。

### 打印

调拨单打印的表头除原有字段外，还有调拨价格、调出成本金额、调拨金额、调拨差价、调拨费用、结算方式、结算账户、承运商；明细在数量之后有调出成本价、调拨价、调拨金额列，合计行显示调拨金额。价格和金额只在打印人有「查看成本金额」权限时有值，没有该权限时为空。新字段按默认显示在末尾，可以在[打印模板](../system/print-template)中取消勾选或调整顺序。

## 单据状态

| 状态 | 说明 | 可做操作 |
| --- | --- | --- |
| 草稿 | 未影响库存 | 编辑、删除、确认 |
| 审批中 | 发布「出入库审批」流程后确认的单据 | 等待审批，通过后执行调拨 |
| 在途 | 在途调拨已从调出仓库扣减，尚未调入 | 收货（不能冲销，需先收货） |
| 已完成 | 调拨完成 | 查看、打印、冲销 |

## 与其他模块的联动

- 调拨不影响存货成本，确认只受财务[结账](../fin/period)限制（不受[成本核算](../fin/cost)限制）；[实时库存成本](./stock#实时库存成本)按全公司计算均价，调拨（含在途）不改变物料的数量和均价，库存流水按当时的均价记金额，业务单价记为调拨价；在途调拨收货时，调入按**调出时的成本**计价（确认框提示「按调出时的成本计价」），调出、调入金额相抵；
- 调拨价、调拨差价只是内部结算价，不生成凭证；调拨费用生成[费用支出单](../fin/other-income#业务单据生成的费用支出单)（现付）或承运商[应付单](../fin/ar-ap)（月结），计入当期费用；
- 按仓库统计的报表（[收发存汇总](./inout)、[经营历史](./stock#经营历史)、[库龄分析](../fin/analysis#库龄分析)、商务智能的库存金额等）中，在途调拨的调入按**收货日期**统计，调出按调拨单的业务日期统计；
- 调出同样要满足[库存预留](./reservation)：调走后仓库可用库存不能少于预留；
- 过期批次可以调拨到不良品仓隔离，不良品仓的库存不参与 [MRP](../mes/mrp)、[齐套分析](../mes/kit)、[可承诺量](../scm/sales#可承诺量)；
- 手机上的[上架](../mobile/putaway)会生成同仓库的调拨单（备注「移动上架」）。

## 供应商寄售仓

供应商寄售仓的货物属于供应商，不计入本公司存货成本，因此：

- **不能在供应商寄售仓与本公司仓库之间调拨**，否则提示「供应商寄售仓（仓库名）的货物属于供应商，不能与本公司的仓库互相调拨：领用请做寄售结算，退回供应商请做其他出库」。需要使用寄售货物时，在[寄售结算](../scm/consign)中办理（结算时采购入库到本公司仓库，同时从寄售仓做寄售消耗出库）；退回供应商时在寄售仓做[其他出库](./out)；
- 只能在**同一供应商**的寄售仓之间调拨，不同供应商的寄售仓之间调拨提示「只能在同一供应商的寄售仓之间调拨」。

客户寄售仓的货物仍属于本公司，可以正常调拨。

## 注意事项

::: tip 提示
调拨单号格式为 DB + 日期 + 4 位流水号。
:::

::: warning 注意
- 在途期间货物不在任何仓库的库存中，请及时收货；
- 收货按收货日期检查期间，收货日期所在月份已结账时不能收货；
- 盘点单勾选「冻结仓库」期间，调出、调入仓库都不能调拨。
:::

调拨单只处理同一公司内部的库存移动。连锁店各自独立核算、需要核算双方的货款、往来和利润时，请见[连锁店之间的往来业务](../scm/sales-out#连锁店之间的往来业务)。
