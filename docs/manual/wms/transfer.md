# 调拨单

调拨单用于把库存从一个仓库（库位）移到另一个仓库（库位），包括跨仓库调拨、同一仓库内移库（如从收货暂存区上架到存储位）。跨地区运输需要时间的调拨可以使用「在途调拨」，到货后由调入方收货。

## 页面入口

仓库 → 库存作业 → 调拨单

![调拨单列表](/images/manual/wms/transfer-list.jpg)

## 列表

**查询条件**：单据号、状态、仓库、业务日期。

**列表列**：单据号（红字 / 已冲销标签）、调出 → 调入（在途调拨下方显示「在途调拨」）、业务日期、合计数量、状态、制单人、确认、备注、创建时间。

**行操作**：

| 按钮 | 出现条件 | 作用 |
| --- | --- | --- |
| 查看 | 所有单据 | 打开详情 |
| 编辑、更多 → 确认 / 删除 | 草稿 | 同[入库单](./in#列表) |
| 收货 | 在途状态，有收货权限 | 确认调入仓库已收货，增加调入仓库库存 |
| 冲销 | 已完成的手工调拨单 | 生成红字调拨单，库存反向调回 |

## 新增调拨单

![新增调拨单](/images/manual/wms/transfer-add.jpg)

### 表头字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 调出仓库 | 是 | 可选择已停用的仓库（用于把库存调走）。更换后清空已选明细 |
| 调入仓库 | 是 | 必须是启用的仓库，可以与调出仓库相同（库内移库）。更换后清空各行的调入库位 |
| 业务日期 | 是 | 默认今天 |
| 在途调拨 | 否 | 开关，「直接调拨」/「在途」。开启后确认时只调出，调入仓库收货后才入库 |
| 备注 | 否 | — |

### 明细

与出库单一样，点「从库存选择」从**调出仓库**的现有库存中勾选（只显示可用数量），然后填写：

| 字段 | 说明 |
| --- | --- |
| 物料、调出库位、批次 | 来自所选库存 |
| 调入库位 | 调入仓库的库位，可不选（未指定）。调出、调入的仓库和库位不能完全相同 |
| 数量 | 必填，大于 0，不超过可用数量 |
| 序列号 | 序列号物料从该位置的在库序列号中选择或扫码 |
| 备注 | 可选 |

选择调入仓库后可点「**推荐库位**」，按上架策略为未选调入库位的行推荐库位（见[上架策略](./label-putaway#上架策略)）。

### 操作步骤

1. 点击「新增调拨单」，选择调出仓库、调入仓库，需要时打开「在途调拨」；
2. 点「从库存选择」勾选要调拨的库存，填写数量、调入库位（或点「推荐库位」）；
3. 保存为草稿；
4. 确认调拨：直接调拨时调出、调入同时完成；在途调拨时只扣减调出仓库，单据变为「在途」；
5. 在途调拨的货物到达后，在列表或详情点「收货」，调入仓库按明细入库，单据变为「已完成」。

## 详情

![调拨单详情](/images/manual/wms/transfer-detail.jpg)

详情显示调出仓库、调入仓库、调拨方式（直接调拨 / 在途调拨）、业务日期、合计数量、制单、确认、收货信息，以及明细（物料、调出库位、调入库位、批次、数量、序列号）。右上角「打印」；底部按钮：草稿「编辑」「确认调拨」，在途「收货」，已完成的手工单据「冲销」。

## 单据状态

| 状态 | 说明 | 可做操作 |
| --- | --- | --- |
| 草稿 | 未影响库存 | 编辑、删除、确认 |
| 审批中 | 发布「出入库审批」流程后确认的单据 | 等待审批，通过后执行调拨 |
| 在途 | 在途调拨已从调出仓库扣减，尚未调入 | 收货（不能冲销，需先收货） |
| 已完成 | 调拨完成 | 查看、打印、冲销 |

## 与其他模块的联动

- 调拨不影响存货成本，确认只受财务[结账](../fin/period)限制（不受[成本核算](../fin/cost)限制）；
- 调出同样要满足[库存预留](./reservation)：调走后仓库可用库存不能少于预留；
- 过期批次可以调拨到不良品仓隔离，不良品仓的库存不参与 [MRP](../mes/mrp)、[齐套分析](../mes/kit)、[可承诺量](../scm/sales#可承诺量)；
- 手机上的[上架](../mobile/putaway)会生成同仓库的调拨单（备注「移动上架」）。

## 注意事项

::: tip 提示
调拨单号格式为 DB + 日期 + 4 位流水号。
:::

::: warning 注意
- 在途期间货物不在任何仓库的库存中，请及时收货；
- 收货按当天日期检查期间，当月已结账时不能收货；
- 盘点单勾选「冻结仓库」期间，调出、调入仓库都不能调拨。
:::
