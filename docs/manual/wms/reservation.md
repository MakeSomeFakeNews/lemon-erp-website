# 库存预留

库存预留用于给重要的销售订单提前「占住」仓库中的库存，防止被其他订单、手工出库或调拨用掉。预留在销售订单中操作，本页面集中查看全部预留，并可手工释放。

## 页面入口

仓库 → 库存控制 → 库存预留

![库存预留](/images/manual/wms/reservation-list.jpg)

## 预留规则

页面顶部提示：预留不锁定库位批次；其他出库、调拨不能占用已预留的库存；销售出库时核销本订单的预留，订单完成、关闭或反审核时自动释放。

- 预留针对「仓库 + 物料」，不指定具体库位和批次；
- 预留数量不能超过该仓库的空闲库存（可用库存 − 已有预留），每行也不能超过订单明细「未出库且未预留」的数量；
- 任何扣减库存的操作（出库、调拨、领料等）完成后，仓库中该物料的可用库存必须仍不少于全部预留，否则提示「库存已被预留（共 X，订单号等），出库后不足以满足预留，请先释放预留」；
- 盘亏不受预留限制；
- 本订单的销售出库会先核销本订单的预留；
- 订单变更减少数量、删除明细时释放对应预留；订单完成、关闭、反审核时释放全部剩余预留。

## 在哪里预留

在「供应链 → 销售 → [销售订单](../scm/sales#库存预留)」详情的「库存预留」页签中：

- 「预留库存」：按明细选择仓库和预留数量；
- 「一键预留」：每行按「未出库 − 已预留」和仓库空闲库存的较小值预留；
- 「全部释放」：释放本订单的全部预留。

## 列表

**查询条件**：仓库、物料（编码或名称）、来源单号（销售订单号）。

**列表列**：销售订单（点击打开该销售订单）、仓库、物料、规格、预留数量、单位、说明、预留人、预留时间。只显示还有剩余预留数量的记录。

**操作**：「释放」（需要释放权限），确认提示「确定释放该预留？释放后库存可被其他订单或出库占用」。工具栏可导出 Excel。

## 注意事项

::: warning 注意
预留会影响仓库的手工出库和调拨。如果出库时提示库存已被预留，请先与销售确认，再在这里或销售订单中释放预留。
:::
