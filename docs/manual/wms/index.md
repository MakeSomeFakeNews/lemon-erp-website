# 仓库管理

仓库管理（顶部导航「仓库」）负责物料主数据、仓库与库位，以及所有库存的进出、调拨、盘点和查询。采购、销售、生产、项目、委外等业务产生的出入库最终都落到这里的库存上，因此它是整个系统中库存数量的唯一来源。

## 基本概念

| 概念 | 说明 |
| --- | --- |
| 仓库 | 存放物料的物理或逻辑仓库。仓库类型决定库存是否计入可用库存，详见[仓库管理](./warehouse) |
| 库位 | 仓库内的具体位置（如货架 A-01-02）。库位是可选的：出入库时不选库位，库存就记在该仓库的「未指定」库位上 |
| 物料 | 物料主数据只有一份，仓库、采购、销售、生产、财务共用，在[物料管理](./material)中维护 |
| 款式与 SKU | 多规格物料中，款式是同一款商品（如一款 T 恤），SKU 是其中一个具体规格（如红色 XL）。库存、出入库都按 SKU，款式不能出入库，见[多规格物料与 SKU](./material#多规格物料与-sku) |
| 库存位置 | 系统按「仓库 + 库位 + 物料 + 批次」记录库存，每一个组合是一行库存。出库、调拨、盘点都按库存位置选择 |
| 批次管理 | 物料启用后，出入库必须填写批次号；批次第一次入库时登记生产日期、有效期（同一批次以第一次入库填写的为准），之后可按批次追踪去向 |
| 序列号管理 | 物料启用后数量必须为整数，出入库要逐个登记序列号（扫码枪逐个录入或粘贴多个），系统记录每个序列号当前所在位置和完整轨迹 |
| 冻结数量 | 需要来料检验的物料采购入库后先冻结为「待检」，检验不合格的保持冻结。冻结的数量不能出库、调拨，见[库存冻结](./hold) |
| 可用数量 | 库存数量 − 冻结数量。出库、调拨选择库存时显示的就是可用数量 |
| 预留 | 销售订单可以预留某个仓库的库存，预留不锁定具体库位和批次，只保证其他出库、调拨不能把已预留的部分用掉，见[库存预留](./reservation) |

## 库存是怎么变动的

- **所有库存变动都来自单据的确认**。入库单、出库单、调拨单、盘点单保存时只是草稿，草稿可以随意修改、删除，**确认后才更新库存**，确认后不能再修改或删除。
- 一张单据确认时，所有明细在同一次操作中处理：任何一行失败（库存不足、序列号不在库等），整张单据都不生效，库存不会只扣一部分。
- 多人同时确认也不会把库存扣成负数；同一张单据也不会被重复确认（提示「单据已确认，请刷新」）。
- 每次变动都会记一条[库存流水](./flow)，数量带正负号；批次第一次入库时登记批次资料；序列号物料同时记录序列号轨迹。
- 由采购入库、销售出库、工单领料、完工入库等**业务单据生成的仓库单据是保存即确认**的，单据号旁会显示「来源 XXX」。这类单据在仓库中不能修改、删除或冲销，错误需要在原业务单据中通过退货、退料冲回。
- 仓库中的手工入库只能选「其他入库」「寄售入库」，手工出库只能选「其他出库」「报废出库」。采购、销售、生产、项目、委外等类型只能由对应业务单据生成，否则会绕过应收应付和成本归集。

## 冲销

已完成的**手工**入库单、出库单、调拨单如果录错了，可以「冲销」：系统生成一张数量为负的红字单据（业务日期为冲销当天，备注「冲销 原单号」），库存按原单反向变动，原单标记「已冲销」。

- 入库冲销要求入库的库存仍在原库位，否则会提示库存不足；
- 红字单据不能再冲销，一张单据只能冲销一次；
- 在途调拨要先收货再冲销；
- 业务单据生成的出入库不能冲销，需要在业务单据中办理退货；
- 成本核算按单据种类归集，红字单冲减原单。

## 期间控制

- 业务日期所在月份已在财务中[**结账**](../fin/period)的，不能再确认该月份的出入库、调拨、盘点单；
- 业务日期所在月份（或之后的月份）已经做过**成本核算**的，不能再确认入库、出库、盘点单，需要先在「财务 → [成本核算](../fin/cost)」中撤销该期间的核算。调拨单不影响存货成本，只受结账限制。

## 审批

系统内置两个流程，默认**未发布**，发布后生效（在「流程中心 → 流程管理 → [流程模型](../workflow/model)」中维护）：

| 流程 | 作用 |
| --- | --- |
| 出入库审批 | 发布后，手工入库单、出库单、调拨单点「确认」时先提交审批（状态「审批中」），审批通过后才更新库存，驳回或撤回后回到草稿。内置流程：仓库主管审批 → 报废、其他出入库时再由会计审核 |
| 盘点差异审批 | 发布后，有差异的盘点单确认时先审批，审批通过后才调整库存；没有差异的盘点单直接完成。内置流程：仓库主管审批 → 会计审核，抄送总经理 |

审批进度可在「流程中心 → [我的申请](../workflow/mine)」中查看。业务单据生成的仓库单据不走出入库审批。

## 典型业务流程

**采购到货入库**

1. [采购订单](../scm/purchase)审核后，仓库在「供应链 → 采购 → [采购入库](../scm/purchase-in)」或手机上的[扫码收货](../mobile/receive)办理入库，系统自动生成已完成的入库单；
2. 物料勾选了「来料检验」的，入库数量先冻结为待检，质量部门在「质量 → [质量检验](../qms/inspection)」中做来料检验，合格或让步接收后自动放行；
3. 收货在暂存区的，用[上架](../mobile/putaway)或[调拨单](./transfer)移到存储库位。

**销售发货出库**

1. [销售订单](../scm/sales)可预留库存（[库存预留](./reservation)）；
2. 销售开[发货通知](../scm/delivery)，系统按「先到期先出」生成拣货建议；仓库在后台或手机[拣货](../mobile/pick)，然后装箱、出库，系统生成销售出库单并核销预留。

**组装与拆零**

1. 新建[组装拆卸单](./assembly)，选择组装或拆卸、成套件和数量，「按 BOM 带出」子件，核对库位、批次；
2. 确认后系统生成「组装拆卸」类型的出库单和入库单，子件与成套件的库存同时变化；
3. 月末[成本核算](../fin/cost)按子件成本计算成套件成本。

**定期盘点**

1. 新建[盘点单](./check)，选择仓库后「按库存生成」盘点明细，可勾选「冻结仓库」；
2. 在后台或手机[盘点](../mobile/check)录入实盘数量；
3. 确认盘点，系统按确认时的账面数量计算差异，盘盈入库、盘亏出库。

**库内管理**

- 每天查看[库存查询](./stock)中「低于安全库存」的物料和[批次与序列号](./trace)中临期、过期的批次（首页待办和消息也会提醒）；
- 过期批次不能做销售、生产、项目、委外、服务领用出库，可做「报废出库」或调拨到不良品仓。

## 首页待办与提醒

有对应权限的用户会在[首页待办](../guide/home#待办事项)中看到：出入库单待确认（自己创建的草稿）、库存低于安全库存、批次 30 天内到期、来料不合格待退货。系统定时任务「批次临期提醒」每天 8:20 检查 30 天内到期（及已过期）的有库存批次，向有库存查询权限的用户发送消息，每个批次只提醒一次（天数可在「系统监控 → [定时任务](../monitor/job)」中调整）。

## 相关角色

| 角色 | 可以做什么 |
| --- | --- |
| 仓库管理员 | 仓库全部单据与基础资料、采购收退货、销售出库退货、拣货、发运、工单领料与完工入库、补料发料、移动作业 |
| 普通用户、总经理等 | 按授权查看库存、单据 |
| 会计 | 参与出入库、盘点差异审批（流程发布后） |

单据按「制单人部门 + 制单人」控制[数据权限](../guide/permission)：只能看到数据权限范围内的单据。仓库、库位、物料的下拉选项登录即可使用。
