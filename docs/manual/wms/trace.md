# 批次与序列号

用于追踪启用了批次管理或序列号管理的物料：某个批次现在在哪里、什么时候入库、发往何处；某个序列号当前是否在库、经历过哪些出入库。也是临期、过期批次预警的主要查询页面。

## 页面入口

仓库 → 库存查询 → 批次与序列号

工具栏用「批次追踪 / 序列号追踪」切换两种视图，两种视图都可以导出 Excel。

## 批次追踪

![批次追踪](/images/manual/wms/trace-batch.jpg)

**查询条件**：

| 条件 | 说明 |
| --- | --- |
| 批次号 | — |
| 物料 | 编码或名称 |
| 有效期至 | 列出有效期在该日期（含）之前的批次，用于临期、过期预警。例如选择 30 天后的日期，即可查出 30 天内到期和已经过期的批次 |
| 只看有库存的批次 | 工具栏勾选项，排除已全部出库的批次 |

**列表列**：批次号、物料、生产日期、有效期至（已过期红色「已过期」、30 天内到期橙色「N 天后到期」）、在库数量、首次入库时间、操作「追踪」。

### 批次详情

点击「追踪」打开批次详情：

![批次追踪详情](/images/manual/wms/trace-batch-detail.jpg)

- 基本信息：物料、批次号、在库数量、生产日期、有效期至、首次入库时间；
- **库存分布**：该批次当前在各仓库、库位的数量；
- **出入库记录（最近 100 条）**：时间、业务类型、单据号、位置（仓库 / 库位）、数量（正负）、操作人。

## 序列号追踪

![序列号追踪](/images/manual/wms/trace-serial.jpg)

**查询条件**：序列号（可直接扫码）、物料、状态（在库 / 已出库）、仓库。

**列表列**：序列号、物料、状态、位置（仓库 / 库位）、批次、首次入库、最近变动、操作「追踪」。

点「追踪」打开序列号轨迹：显示当前状态、当前位置（已出库时为「最后所在」位置）、批次，以及按时间排列的轨迹，每条显示业务类型、入 / 出及仓库库位、时间、单据号和操作人（入库为绿色、出库为橙色）。

## 常见用途

- **质量追溯**：按批次号查出该批次发出的所有出库单，定位受影响的客户或工单；
- **售后保修**：客户关系中的[服务工单](../crm/ticket#序列号保修判断)按序列号查找销售出库记录判断保修；仓库也可以在这里直接查序列号的完整轨迹；
- **临期处理**：每天按「有效期至」查询临期批次，优先安排出库；过期批次不能用于销售、生产、项目、委外、服务领用出库，可做报废出库或调拨到不良品仓。

## 临期提醒

- 首页待办显示「批次 30 天内到期」的数量（有库存且有效期在 30 天内，含已过期）；
- [定时任务](../monitor/job)「批次临期提醒」每天 8:20 向有库存查询权限的用户发送消息（即将到期为提醒、已过期为告警），每个批次只提醒一次，点击消息进入本页面。提前天数默认 30 天，可在定时任务参数中修改。

::: tip 提示
批次的生产日期、有效期以该批次第一次入库时填写的为准，后续入库同一批次不会修改。
:::
