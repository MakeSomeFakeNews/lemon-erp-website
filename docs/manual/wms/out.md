# 出库单

出库单记录物料离开仓库。仓库人员在这里手工办理「其他出库」和「报废出库」；销售出库、生产领料、采购退货、项目领料、委外发料、服务领用、部门领用、寄售消耗、[组装拆卸](./assembly)等由业务单据自动生成的出库单也在这里查看。

## 页面入口

仓库 → 库存作业 → 出库单

![出库单列表](/images/manual/wms/out-list.jpg)

## 列表

**查询条件**：单据号、出库类型、状态、仓库、业务日期。

**列表列**：单据号（红字 / 已冲销标签、来源单号）、出库类型、仓库、业务日期、合计数量、状态、制单人、确认（人和时间）、备注、创建时间。

**工具栏**：「新增出库单」、「批量删除」（只能勾选草稿），以及显示搜索、刷新、密度、列设置。

**行操作**：「查看」；草稿可「编辑」「更多 → 确认 / 删除」；已完成的手工单据可「冲销」。规则与[入库单](./in#列表)相同。

## 新增出库单

![新增出库单](/images/manual/wms/out-add.jpg)

### 表头字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 出库类型 | 是 | 手工只能选「其他出库」或「报废出库」 |
| 出库仓库 | 是 | 允许选择已停用的仓库（用于清空剩余库存）。**更换仓库会清空已选明细**，并提示「仓库已变更，已清空明细，请重新选择库存」 |
| 业务日期 | 是 | 默认今天 |
| 备注 | 否 | 最多 255 字 |

### 从库存选择明细

出库明细不能手工输入物料，只能从仓库现有库存中选择：

1. 选择出库仓库后，点击「从库存选择」；
2. 在弹窗中按物料编码或名称、批次号、库位筛选，勾选要出库的库存行（可跨页多选，右上角显示「已选 N 项」）。弹窗显示物料、库位、批次、有效期至和**可用数量**（有冻结数量时另行显示「冻结 X」）；
3. 点「添加到明细」。同一库存位置（库位 + 物料 + 批次）已在明细中的会自动跳过并提示。

### 明细字段

| 字段 | 说明 |
| --- | --- |
| 物料、库位、批次 | 来自所选库存，不可修改 |
| 数量 | 必填，大于 0，最多 4 位小数（序列号物料为整数）；下方显示该库存位置的可用数量 |
| 序列号 | 序列号物料必填，下拉列出该库存位置的在库序列号供选择，也可以扫码录入；个数须与数量一致 |
| 备注 | 可选 |

### 操作步骤

1. 点击「新增出库单」，选择出库类型、出库仓库；
2. 点击「从库存选择」，勾选库存行并添加到明细；
3. 填写每行出库数量，序列号物料选择或扫描序列号；
4. 点击「保存」生成草稿；
5. 在列表「更多 → 确认」或详情「确认出库」，库存扣减。

## 详情

![出库单详情](/images/manual/wms/out-detail.jpg)

详情显示表头（出库类型、出库仓库、业务日期、合计数量、来源单号、冲销原单、制单、确认、备注）和明细。右上角可「打印」（出库单模板）；底部按钮：草稿「编辑」「确认出库」，已完成的手工单据「冲销」。

## 单据状态

| 状态 | 可做操作 |
| --- | --- |
| 草稿 | 编辑、删除、确认 |
| 审批中 | 发布「出入库审批」流程后确认的单据，等待审批；通过后出库，驳回 / 撤回回到草稿 |
| 已完成 | 查看、打印、冲销（仅手工单据） |

## 确认时的校验

- **库存不足**：扣减后可用数量不能为负，提示「库存不足：物料（批次），可用 X，需要 Y」，有冻结数量时会说明「另有冻结 Z，待检或不合格」；
- **预留**：出库后仓库中该物料的可用库存不能少于已有的预留，否则提示「库存已被预留……请先释放预留」，见[库存预留](./reservation)；
- **序列号**：出库的序列号必须在所选库存位置在库；
- **过期批次**：销售、生产、项目、委外、服务领用出库不能发出已过期的批次。过期物料可手工做「报废出库」（或其他出库），或调拨到不良品仓；
- **盘点冻结**：仓库正在盘点且勾选了「冻结仓库」时不能出库；
- **期间**：业务日期所在月份已结账或已成本核算时不能确认。

## 与其他模块的联动

- [销售出库](../scm/sales-out)、[生产领料](../mes/wo#领料)、[采购退货](../scm/purchase-in#新增采购退货)等在各自业务单据中办理，保存即生成已完成的出库单；
- 销售出库时先核销本订单的库存预留；
- 采购退货时优先退冻结（不合格、待检）的库存；
- 报废出库、其他出库计入[成本核算](../fin/cost)，红字单冲减原单。

## 注意事项

::: tip 提示
出库单号格式为 CK + 日期 + 4 位流水号。
:::

::: warning 注意
冲销出库单相当于把物料按原库位、原批次、原序列号重新入库。
:::
