# 库位管理

维护仓库内的库位（货架、货位）。库位有区域、类型和排序，用于上架推荐、拣货路径和拣货建议；每个库位可以打印二维码标签，供手机 / PDA 扫码作业。

## 页面入口

仓库 → 基础资料 → 库位管理（也可以从[仓库管理](./warehouse)的「库位」按钮进入，自动筛选该仓库）

![库位管理](/images/manual/wms/location-list.jpg)

## 列表

**查询条件**：仓库（选择后立即查询）、库位（编码或名称）、状态。

**工具栏**：

| 按钮 | 作用 |
| --- | --- |
| 新增库位 | 已筛选仓库时，新增表单自动带出该仓库 |
| 批量删除 | 删除勾选的库位 |
| 打印库位标签（N） | 为勾选的库位（当前页）打印标签 |
| 导出 | 导出 Excel |

**列表列**：仓库、库位编码、库位名称、区域、类型、排序、状态（开关启用 / 停用）、备注；操作「编辑」「删除」。

## 新增 / 编辑库位

![新增库位](/images/manual/wms/location-add.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 所属仓库 | 是 | 新增后不能修改 |
| 库位编码 | 是 | 只能包含字母、数字、下划线和短横线，最多 32 字符，同一仓库内不能重复。建议按「区-排-层」编码，如 A-01-02。库位编码就是库位标签的条码内容 |
| 库位名称 | 否 | 如「整机区 1 排 2 层」 |
| 类型 | 否 | 默认「存储位」，见下表 |
| 区域 | 否 | 如「A 区」「冷藏区」，最多 32 字 |
| 排序 | 否 | 拣货路径按 区域 → 排序 → 编码 |
| 备注 | 否 | 最多 255 字 |

### 库位类型

| 类型 | 用途 |
| --- | --- |
| 存储位 | 一般存储，上架推荐空库位时使用 |
| 拣货位 | 拣货区，上架推荐空库位时使用 |
| 收货暂存 | 到货待上架的暂存区，可配合手机[上架](../mobile/putaway)移到存储位 |
| 发货暂存 | 拣货后待发运的暂存区 |
| 不良品位 | 存放不良品，库存**不参与拣货建议** |

## 打印库位标签

勾选库位后点「打印库位标签」，设置每个打印的张数，预览后打印。库位标签默认是二维码，内容为库位编码，可显示库位编码、名称、区域、仓库，样式在「系统管理 → [打印模板](../system/print-template)」的「库位标签」中设置。详见[条码标签](./label-putaway#条码标签)。

## 注意事项

::: warning 注意
- 已有库存记录的库位不能删除，只能停用；
- 停用的库位不能再入库、调入，但可以出库、调出和盘点；
- 库位不是必须的：出入库不选库位时，库存记在仓库的「未指定」位置。
:::
