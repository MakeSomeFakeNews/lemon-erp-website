# 库存查询

库存查询显示各仓库、库位、批次的当前库存，以及按物料汇总的库存与安全库存预警，是仓库、采购、销售、计划人员最常用的查询页面。有「查看成本金额」权限的用户还能看到每个物料的实时均价和库存金额，并可以打开「经营历史」查看某个物料每一笔进出的单价、数量和结余。

## 页面入口

仓库 → 库存查询 → 库存查询

::: tip 微信小程序
在[微信小程序](../miniapp/warehouse#库存查询)中可以扫描物料条码查询库存，并查看各仓库、库位、批次的数量。
:::

## 库存明细

默认显示「库存明细」，每行是一个库存位置（仓库 + 库位 + 物料 + 批次）。

![库存明细](/images/manual/wms/stock-list.jpg)

**查询条件**：仓库、物料（编码或名称）、分类、库位（先选仓库）、批次号。

**工具栏选项**：

- 「库存明细 / 按物料汇总」切换；
- 「显示零库存」：默认不显示数量为 0 的库存行，勾选后显示（例如查看曾经存放过的位置）；
- 合计：显示按当前查询条件统计的**全部页**的「合计数量」，有「查看成本金额」权限时还显示「库存金额」合计；
- 导出 Excel（按当前查询条件和显示的列）、显示搜索、刷新、密度、列设置。

**列表列**：

| 列 | 说明 |
| --- | --- |
| 物料 | 名称，下方为编码 |
| 规格型号、仓库 | — |
| 库位 | 未选库位入库的显示「未指定」 |
| 批次 | 未启用批次管理的显示「-」 |
| 数量 | 库存数量（包含冻结数量） |
| 冻结 | 待检或检验不合格冻结的数量（橙色），鼠标悬停提示「待检或检验不合格，不能出库，见『库存冻结』」 |
| 单位 | — |
| 均价 | 物料当前的实时移动加权平均单价（全公司一个均价，不分仓库，见下文[实时库存成本](#实时库存成本)）。只有「查看成本金额」权限时显示；供应商寄售仓的库存不计价，显示「-」 |
| 库存金额 | 数量 × 均价，同样需要「查看成本金额」权限 |
| 生产日期 | — |
| 有效期至 | 已过期显示红色「已过期」标签，30 天内到期显示橙色「N 天后到期」 |
| 操作 | 「经营历史」：打开该物料的[经营历史](#经营历史)，默认选中这一行所在的仓库；序列号物料另有「序列号」按钮，弹窗列出该位置当前在库的全部序列号 |

## 按物料汇总

点「按物料汇总」，每个物料一行，汇总所选仓库（不选为全部仓库）的库存。

![按物料汇总](/images/manual/wms/stock-summary.jpg)

**列表列**：物料、规格型号、分类、单位、安全库存、库存数量、冻结、均价和库存金额（需要「查看成本金额」权限）、操作（「经营历史」，不限定仓库）。

库存数量低于物料设置的安全库存时，数量标红并显示「低于安全库存」标签。勾选工具栏的「**只看低于安全库存**」可以只列出需要补货的物料。

## 经营历史

经营历史把某个物料的库存流水按时间顺序排成一张「进销存账页」：期初多少、每一笔从哪里来到哪里去、单价多少、结余多少。从库存查询的行操作「**经营历史**」，或[物料管理](./material)列表的行操作「**经营历史**」进入（款式行没有此按钮，请在 SKU 上查看）。

![经营历史](/images/manual/wms/stock-history.jpg)

**查询条件**：

| 条件 | 说明 |
| --- | --- |
| 仓库 | 不选为「全部仓库」：全公司的进出与结余，**不含仓库之间的调拨和供应商寄售仓**（调拨只是换了存放位置）；选择仓库时只看该仓库，含调入、调出 |
| 日期范围 | 默认本月 1 日到今天。日期为单据的**业务日期**；范围内流水超过 5000 条时提示缩小日期范围或选择仓库 |

查询条件下方的灰色文字会说明当前口径。

**列表列**（第一行为「期初余额」，即开始日期之前的结余）：

| 列 | 说明 |
| --- | --- |
| 日期 | 单据的业务日期 |
| 单据号 | 仓库单据号，点击打开入库单、出库单、调拨单或盘点单详情；下方灰字为来源业务单号（如采购入库单、领料单号） |
| 业务类型 | 入库类型、出库类型（如采购入库、生产领料、销售出库），调拨、盘点 |
| 往来单位 | 采购入库 / 退货的供应商、销售出库 / 退货的客户，其他业务为空 |
| 仓库 | 只在「全部仓库」时显示 |
| 业务单价 | 来源单据的不含税单价（本位币），如采购价、销售价；手工单据没有 |
| 成本价 | 这一笔的成本单价（实时移动加权平均计价的结果） |
| 入库数量 / 出库数量 | — |
| 结余数量 | 这一笔之后的结余 |
| 金额 | 这一笔的成本金额，出库为负数（红色） |
| 结余金额 | 这一笔之后的库存金额 |

业务单价、成本价、金额、结余金额需要「查看成本金额」权限，没有权限时只显示数量。

::: tip 近似成本
系统升级到实时库存成本之前的历史流水没有当时的计价，升级时按单据价格（采购取不含税单价）、流水所在月份的成本核算单价或物料的参考成本价补算，是近似值：这些行的成本价前显示橙色「**近似**」标签（鼠标悬停有说明），期初余额包含这类流水时，「期初余额」后也显示「近似」。升级之后发生的流水是准确的实时成本。[库存流水](./flow)中同样标出。
:::

## 实时库存成本

系统按**移动加权平均**实时计算每个物料的库存成本：每次入库后按「(原库存金额 + 本次入库金额) ÷ (原数量 + 本次数量)」重新计算均价，出库按当时的均价转出。均价按物料计算，**全公司一个均价，不分仓库**；供应商寄售仓的货物属于供应商，不计价。库存查询的均价和库存金额、经营历史、库存流水的成本价、[进销存报表](../scm/jxc)的销售成本和毛利都来自这里。

各类业务的成本来源：

| 业务 | 入库 / 出库成本 |
| --- | --- |
| [采购入库](../scm/purchase-in) | 行的不含税金额 ÷ 数量（本位币，已扣除促销、返利、整单优惠的分摊）；**采购退货**按退货单的不含税单价冲减 |
| [销售出库](../scm/sales-out) | 按当前均价出库；**销售退货**按该订单原销售出库的实际成本入库 |
| [其他入库](./in#成本价) | 按填写的成本价（默认当前均价，可改为 0，如赠品） |
| 期初入库 | 按[期初余额](../fin/opening)导入时填写的成本单价，不填按物料的参考成本价 |
| 其他出库、报废出库、各类领用 | 按当前均价出库 |
| [盘点](./check#盘盈成本价) | 盘盈按盘点明细填写的成本价（不填按确认时的均价），盘亏按当前均价 |
| [调拨](./transfer) | 不改变数量和均价，流水按均价记金额 |
| [组装拆卸](./assembly) | 组装：成套件成本 = 子件出库成本合计；拆卸：成套件的出库成本按「子件数量 × 子件均价」的比例分给各子件 |
| 冲销 | 按原单的实际成本反向冲回 |
| [生产领料 / 补料](../mes/wo#领料) | 按当前均价出库；**生产退料**按该工单该物料的领料平均成本入库 |
| [完工入库](../mes/wo#完工入库的成本) | 优先取产品的标准成本，没有时按工单实际成本 = 领料成本分摊 + 报工工时 × 工作中心费率，见生产工单 |
| [报废入库](../mes/wo#报废入库) | 按填写的成本价（如残值，默认产品的当前均价） |
| 委外 | 委外发料按当前均价出库；加工商退回子件按该委外订单的发料平均成本入库；委外件收货 = 加工费（采购入库的不含税单价）+ 核销的子件成本，退货反向冲回 |

其他规则：

- 物料出完（结余为 0）时剩余金额全部转出，不留尾差；结余为 0 时保留最后的单价，下次没有指定成本的入库按它计价；从来没有成本的物料取物料档案的「参考成本价」。
- 物料第一次发生库存变动时开始计价，以当时的库存数量和参考成本价作为起点；从旧版本升级的系统，升级时按各物料最近一期成本核算的单价（没有时取参考成本价）初始化。
- 供应商寄售仓与本公司仓库之间**不能互相调拨**，见[调拨单](./transfer#供应商寄售仓)。

::: warning 与月末成本核算的关系
实时库存成本是**业务参考成本**，随出入库即时计算，便于随时查看库存金额和毛利。财务记账仍以「财务 → [成本核算](../fin/cost)」的月末核算结果为准：月末核算按物料设置的计价方法（默认月末一次加权平均）统一计算，含工单料工费，并生成成本结转凭证。两者口径不同（例如月末一次加权平均的出库单价要到月末才确定），金额可能不一致，账面数以月末核算为准，见[成本核算 · 实时库存成本与月末核算](../fin/cost#实时库存成本与月末核算)。
:::

## 常见用途

| 需要 | 做法 |
| --- | --- |
| 查某个物料在哪些库位 | 库存明细中输入物料，查看各行仓库 / 库位 |
| 查某个库位放了什么 | 选择仓库和库位 |
| 安全库存预警 | 按物料汇总 + 只看低于安全库存；[首页待办](../guide/home#待办事项)也会显示「库存低于安全库存」，点击后直接打开按物料汇总、只看低于安全库存的结果 |
| 临期 / 过期预警 | 看「有效期至」列标签；按批次查询更方便的是[批次与序列号](./trace)中的「有效期至」条件 |
| 可出库数量 | 数量 − 冻结；另外销售订单预留的部分其他出库不能使用，见[库存预留](./reservation) |
| 一段时间内的进出与结存 | 用[收发存汇总](./inout)按期间查看期初、各类出入库和期末数量 |
| 某个物料每一笔的进价、售价和结余 | 行操作「经营历史」 |
| 当前库存值多少钱 | 工具栏的「库存金额」合计（需要「查看成本金额」权限），可按仓库、分类筛选 |
| 某个款式各颜色尺码的库存 | 在[物料管理](./material#多规格物料与-sku)中点款式的「多规格」，按颜色 × 尺码矩阵查看各 SKU 的库存 |

## 注意事项

::: tip 提示
安全库存在[物料管理](./material)中设置，按全部仓库的库存合计判断。数量最多显示 4 位小数，并带千分位。

均价、库存金额，以及库存流水、经营历史、出入库单详情中的单价和金额，都由按钮权限「**查看成本金额**」（库存查询下的按钮）控制，内置角色中总经理、仓库管理员、会计拥有；没有该权限时这些列不显示，系统也不返回这些数据。

多规格物料的库存按 SKU 记录，每个 SKU 单独一行（物料编码如 TS01-RD-XL，规格型号中带颜色、尺码等属性值）；款式本身不能出入库，没有库存。按款式编码查询（如输入 TS01）可以列出该款式的全部 SKU。
:::
