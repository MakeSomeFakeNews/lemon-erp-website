# 条码标签、上架策略与装箱

本页集中说明几个分布在多个页面中的仓储功能：条码与标签打印、上架策略（推荐库位）、拣货建议与装箱、在途调拨，以及它们在哪里操作。

## 条码标签

系统支持三种标签，条码内容也是手机 / PDA 扫码时识别的依据：

| 标签 | 默认条码 | 条码内容 | 可显示字段 | 在哪里打印 |
| --- | --- | --- | --- | --- |
| 物料标签 | 一维码（CODE128） | 物料条码，没有条码时为物料编码 | 物料名称、物料编码、规格型号、单位 | [物料管理](./material#打印物料标签)：勾选物料后「打印标签」 |
| 库位标签 | 二维码 | 库位编码 | 库位编码、库位名称、区域、仓库 | [库位管理](./location#打印库位标签)：勾选库位后「打印库位标签」 |
| 箱标签 | 一维码（CODE128） | 箱号 | 箱号、客户、发货通知、箱序、箱内物料、毛重 | [发货通知](../scm/delivery#装箱)详情的装箱区域：「箱标签」 |

打印时可以设置「每个打印」几张（1～100），弹窗预览第一张，然后调用浏览器打印。

**标签样式**在「系统管理 → [打印模板](../system/print-template)」左侧的「标签」分组中设置：标签宽、高（毫米，默认 60 × 40）、字号、条码类型（一维码 / 二维码）、条码下是否显示内容，以及显示哪些字段、字段的显示名称；右侧实时预览，可「恢复默认样式」。

**扫码规则**：

- 物料选择框（入库单、盘点单添加物料等）支持扫码：输入或扫描条码后回车，按物料条码、辅助单位条码查找并选中；
- 辅助单位条码（如整箱条码）在[物料管理 → 单位](./material#辅助单位与包装条码)中设置，扫码时数量按换算率折算为基本单位；
- 移动作业中扫描的内容先按当前仓库的库位编码匹配，再按物料条码 / 包装条码 / 物料编码匹配物料，都不匹配时作为序列号处理。

## 上架策略

「推荐库位」按以下顺序为**还没有选择库位**的明细行推荐库位（已选库位的行不变）：

1. 物料的**默认库位**（默认库位属于本仓库且启用时）；
2. 已有**同批次**库存的库位（批次物料）；
3. 已有**该物料**库存的库位（库存多的优先）；
4. **没有库存的空库位**：只用启用的「存储位」「拣货位」，按 区域 → 排序 → 编码 的顺序；同一次推荐中一个空库位只分给一种物料。

第 2、3 步只考虑启用的存储位、拣货位。都找不到时该行保持「未指定」，提示「没有可推荐的库位」。

**在哪里使用**：

| 位置 | 按钮 |
| --- | --- |
| [入库单](./in) 新增 / 编辑 | 明细上方「推荐库位」 |
| [调拨单](./transfer) 新增 / 编辑 | 「推荐库位」（为调入库位推荐） |
| [采购入库](../scm/purchase-in)、[销售退货](../scm/sales-out#新增销售退货) | 单据表单中的「推荐库位」 |
| 手机[扫码收货](../mobile/receive) | 没有指定库位的行在确认入库时自动推荐 |
| 手机[上架](../mobile/putaway) | 「推荐库位」按钮（推荐结果就是来源库位时不上架） |

## 拣货建议与拣货路径

- 销售「发货通知」创建时，系统按**先到期先出**（批次有效期 → 批次号 → 库位顺序）在发货仓库的可用库存中生成拣货建议；不良品位的库存不参与；库存不足的部分不生成建议，可在发货通知中「重新建议」；
- 拣货路径按库位的 区域 → 排序 → 编码；
- 拣货可以在后台发货通知详情中「确认拣货」，也可以在手机上[拣货](../mobile/pick)；多张发货通知可合并为「供应链 → 销售 → [波次拣货](../scm/wave)」统一拣货；
- 拣货完成后在发货通知中「出库」，系统按实际拣货的库位、批次、序列号生成销售出库单。

## 装箱

装箱在「供应链 → 销售 → 发货通知」的详情中操作，发货通知为「已拣货」或「已出库」状态时显示装箱区域：

- 「装一箱」：选择本箱装入的各物料数量（不超过尚未装箱的数量），填写毛重（kg）、体积（m³）、备注，系统自动生成箱号（发货通知号-两位箱序，如 FH202610150001-01）；
- 已装的箱可编辑、删除；区域标题显示箱数和总毛重，并显示每个物料「已装 / 通知数量」，未装完的标为提醒色；
- 「装箱单」：打印装箱清单；
- 「箱标签」：为每一箱打印箱标签。

装箱需要发货通知的装箱权限（仓库管理员默认有）。

## 在途调拨

跨仓库运输需要时间时，在[调拨单](./transfer)中打开「在途调拨」：确认时只从调出仓库扣减，单据状态为「在途」；货到后由调入方在列表或详情中点「收货」，调入仓库才增加库存。在途期间货物不在任何仓库的库存中。

## 临期预警

- [库存查询](./stock)、[批次与序列号](./trace)中，有效期已过显示红色「已过期」，30 天内到期显示橙色「N 天后到期」；
- 批次追踪可按「有效期至」查询临期批次；
- 首页待办「批次 30 天内到期」、定时任务「批次临期提醒」消息；
- 过期批次不能用于销售、生产、项目、委外、服务领用出库。
