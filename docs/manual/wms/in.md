# 入库单

入库单记录物料进入仓库。仓库人员在这里手工办理「其他入库」（如赠品、样品、盘点以外的补录）和「寄售入库」；采购入库、生产入库、销售退货、生产退料、委外收回等由对应业务单据自动生成的入库单也在这里统一查看。

## 页面入口

仓库 → 库存作业 → 入库单

![入库单列表](/images/manual/wms/in-list.jpg)

## 列表

**查询条件**：单据号、入库类型、状态、仓库、业务日期（日期范围）。点「展开」显示全部条件。

**列表列**：

| 列 | 说明 |
| --- | --- |
| 单据号 | 点击打开详情。红字单据带「红字」标签并显示「冲销 原单号」；被冲销的原单带「已冲销」标签；业务单据生成的显示「来源 业务单号」 |
| 入库类型 | 采购入库、生产入库、销售退货、生产退料、委外收回、报废入库、寄售入库、其他入库 |
| 仓库 | 入库仓库 |
| 业务日期 | 入库的业务日期，决定所属会计期间 |
| 合计数量 | 明细数量合计，红字单据为负数（红色显示） |
| 状态 | 草稿、审批中、已完成 |
| 制单人 / 确认 | 制单人；确认人和确认时间 |
| 备注、创建时间 | — |

**工具栏**：「新增入库单」；「批量删除」（只能勾选草稿）；右侧图标依次为显示 / 隐藏搜索、刷新、密度、列设置。

**行操作**：

| 按钮 | 出现条件 | 作用 |
| --- | --- | --- |
| 查看 | 所有单据 | 打开详情 |
| 编辑 | 草稿 | 修改单据 |
| 更多 → 确认 | 草稿，有确认权限 | 确认入库，更新库存（发布了出入库审批流程时先提交审批） |
| 更多 → 删除 | 草稿，有删除权限 | 删除草稿 |
| 冲销 | 已完成的手工单据（非业务单据生成、非红字、未冲销） | 生成红字单据，库存反向变动 |

## 新增入库单

点击「新增入库单」打开全屏表单。

![新增入库单](/images/manual/wms/in-add.jpg)

### 表头字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 入库类型 | 是 | 手工只能选「其他入库」或「寄售入库」 |
| 入库仓库 | 是 | 选择启用的仓库。选「寄售入库」时只能选**供应商寄售仓**；其他入库不能选供应商寄售仓。切换入库类型使仓库类型不再匹配时，已选仓库会被清空 |
| 业务日期 | 是 | 默认今天 |
| 备注 | 否 | 最多 255 字 |

### 明细

点「添加物料」增加一行，每行字段如下：

| 字段 | 说明 |
| --- | --- |
| 物料 | 必填。可输入编码、名称搜索，也可以扫码：在框中扫描（或输入）物料条码、包装条码后回车直接选中。扫的是辅助单位条码（如整箱）且数量为空时，数量自动填为一个辅助单位折算的基本单位数量。行下方用「批次」「序列号」标签标出物料的管理方式 |
| 库位 | 可选，不选为「未指定」。物料设置了默认仓库和默认库位、且默认仓库就是本单仓库时，自动带出默认库位 |
| 批次号 | 启用批次管理的物料必填，最多 64 字符；未启用的不可填 |
| 生产日期、有效期至 | 仅批次物料可填，有效期不能早于生产日期。同一批次以第一次入库填写的日期为准 |
| 数量 | 必填，必须大于 0，最多 4 位小数；序列号物料只能是整数 |
| 序列号 | 仅序列号物料。可用扫码枪逐个扫描，也可以粘贴多个（逗号、分号、空格、换行分隔），自动去重；右侧显示「已录个数 / 数量」，不一致时变为黄色。单个序列号不超过 64 字符 |
| 备注 | 可选 |

明细标题显示行数和合计数量。表头右侧的「**推荐库位**」按上架策略为还没有选库位的行填入库位（已选库位的行不变），规则见[上架策略](./label-putaway#上架策略)。

### 保存规则

- 草稿保存时，序列号个数只要求不超过数量；确认时必须与数量完全一致。
- 同一物料的序列号在一张单据内不能重复。
- 已在库的序列号不能再次入库（提示「序列号已在库」）；已出库的序列号可以重新入库（例如退回）。
- 停用的物料、仓库、库位不能入库。

### 操作步骤

1. 点击「新增入库单」，选择入库类型、入库仓库，确认业务日期；
2. 点击「添加物料」，选择或扫描物料，填写数量；批次物料填写批次号（及生产日期、有效期），序列号物料扫描序列号；
3. 需要时点「推荐库位」自动分配库位；
4. 点击「保存」（或按 Ctrl / ⌘ + Enter），单据保存为草稿；
5. 在列表「更多 → 确认」或详情中点「确认入库」，确认后库存增加。

## 详情

点击单据号或「查看」打开详情，显示表头信息（来源单号、冲销原单、制单、确认、收货信息）和明细（物料、库位、批次及生产日期 ~ 有效期、数量、序列号、备注）。

![入库单详情](/images/manual/wms/in-detail.jpg)

详情右上角：

- **打印**：按「入库单」[打印模板](../system/print-template)打印，含仓库、业务日期、来源单号、合计数量、明细和「制单、确认、经手人」签字栏；
- 状态标签（红字、已冲销、状态）。

详情底部按钮：草稿时「编辑」「确认入库」；已完成的手工单据「冲销」。从详情进入编辑不会关闭详情，保存后详情自动刷新。审批中的单据显示提示「单据审批中，可在『流程中心 → [我的申请](../workflow/mine)』查看审批进度」。

## 单据状态

| 状态 | 说明 | 可做操作 |
| --- | --- | --- |
| 草稿 | 已保存，未影响库存 | 编辑、删除、确认 |
| 审批中 | 发布了「出入库审批」流程，确认后等待审批 | 只能查看；通过后自动变为已完成并入库，驳回 / 撤回后回到草稿 |
| 已完成 | 已入库 | 查看、打印、冲销（仅手工单据） |

## 与其他模块的联动

- [采购入库](../scm/purchase-in)、[生产完工入库](../mes/wo#完工入库)、[销售退货](../scm/sales-out#新增销售退货)、[生产退料](../mes/wo#退料)、委外收回、[报废入库](../mes/wo#报废入库)等在各自业务单据中办理，保存即生成已完成的入库单，单据号下方显示来源单号；
- 物料勾选了「来料检验」的，**采购入库**后该数量自动冻结为待检，见[库存冻结](./hold)；
- 寄售入库进入供应商寄售仓，库存属于供应商，不计入存货成本和可用库存；
- 入库流水是财务「[成本核算](../fin/cost)」的数据来源。

## 注意事项

::: tip 提示
入库单号格式为 RK + 日期 + 4 位流水号，例如 RK202610140015。
:::

::: warning 注意
- 业务日期所在月份已结账或已做成本核算时不能确认，需先在财务中撤销成本核算；
- 仓库正在盘点且盘点单勾选了「冻结仓库」时，盘点完成前不能入库；
- 冲销入库单要求入库的数量仍在原库位，如果已经出库或移走，冲销会提示库存不足。
:::
