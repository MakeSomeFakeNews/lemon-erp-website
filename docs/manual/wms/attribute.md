# 规格属性

规格属性用于**多规格物料**：服装、鞋帽、配件等同一款商品按颜色、尺码等规格区分时，先在这里维护「颜色」「尺码」这样的属性和它们的取值（黑色、白色、S、M、L……），再到[物料管理](./material#多规格物料与-sku)中为款式选择属性值组合，一次批量生成全部 SKU。

## 页面入口

仓库 → 基础资料 → 规格属性

![规格属性](/images/manual/wms/attribute-list.jpg)

页面顶部提示：「规格属性用于多规格物料（款式）：在「物料管理」中选择属性值组合，批量生成 SKU」。

系统为每个企业（租户）预置了两个规格属性：

| 属性 | 属性值（编码） |
| --- | --- |
| 颜色 | 黑色（BK）、白色（WH）、红色（RD）、蓝色（BL） |
| 尺码 | S、M、L、XL、XXL（编码与属性值相同） |

可以按需修改、补充或新增其他属性（如「材质」「容量」）。

## 列表

列表不分页，按排序显示全部规格属性。

| 列 | 说明 |
| --- | --- |
| 属性名称 | 如颜色、尺码 |
| 属性值 | 按顺序列出全部属性值，属性值后面的灰色小字是编码 |
| 排序 | 数字越小越靠前；生成 SKU 时多个属性也按此顺序组合（如先颜色后尺码） |
| 状态 | 启用 / 停用。停用的属性不能再用于新款式生成 SKU，已生成的 SKU 不受影响 |
| 操作 | 「编辑」「删除」 |

**工具栏**：「新增规格属性」。新增、编辑、删除需要「规格属性维护」权限，没有该权限的用户只能查看。

## 新增 / 编辑规格属性

![编辑规格属性](/images/manual/wms/attribute-form.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 属性名称 | 是 | 最多 32 个字，如「颜色」「尺码」；不能与已有属性重名 |
| 排序 | 否 | 默认 0 |
| 状态 | 否 | 开关，默认启用 |
| 属性值 | 否 | 每行一个：左侧填属性值（如「红色」，最多 32 个字），右侧填编码（如「RD」，最多 16 个字符，可不填）。同一属性下属性值不能重复 |
| 备注 | 否 | 最多 255 字 |

属性值的操作：

- 「添加属性值」：在末尾增加一行；空着的行保存时自动忽略；
- 上移按钮：与上一行交换位置，属性值的先后顺序就是保存后的排序，也是生成 SKU、规格矩阵中的排列顺序；
- 删除按钮：删除该行。**已被 SKU 使用的属性值不能删除**（保存时提示「已被 SKU 使用的属性值不能删除」），但可以改名或改编码。

表单中的提示：「编码用于生成 SKU 编码，为空用属性值；已被 SKU 使用的不能删除」。

::: tip 属性值编码
SKU 的物料编码 = 款式编码 + 「-」+ 各属性值的编码（按属性排序依次用「-」连接），属性值没有编码时直接用属性值本身。例如款式 TS01、颜色「红色」编码 RD、尺码「XL」，生成的 SKU 编码为 **TS01-RD-XL**。物料编码只能包含字母、数字、下划线、点和短横线，因此建议为中文属性值填写英文或数字编码。
:::

## 删除规格属性

点行上的「删除」并确认。已被 SKU 使用的规格属性不能删除，提示「规格属性已被 SKU 使用，不能删除，可以停用」。

## 与其他功能的关系

- [物料管理](./material#多规格物料与-sku)：在物料上点「多规格」，选择规格属性和属性值生成 SKU，查看款式的库存矩阵；
- [采购订单](../scm/purchase#按规格录入)、[销售订单](../scm/sales#按规格录入)：按款式的规格矩阵（如颜色 × 尺码）填写数量，一次加入多行明细。

## 注意事项

::: warning 注意
- 一个款式生成 SKU 后，所用的规格属性就固定了：之后可以为该款式补充新的属性值（生成新的组合），但不能再增加或减少属性；
- 修改属性值的名称不会改变已生成 SKU 的编码和规格文字。
:::
