# 盘点单

盘点单用于核对仓库的实物数量与系统账面数量。选择仓库后按当前库存生成盘点明细，录入实盘数量（或在手机上扫码盘点），确认后系统自动盘盈入库、盘亏出库，把库存调整为实盘数量。

## 页面入口

仓库 → 库存作业 → 盘点单

![盘点单列表](/images/manual/wms/check-list.jpg)

## 列表

**查询条件**：单据号、仓库、状态、盘点日期。

**列表列**：

| 列 | 说明 |
| --- | --- |
| 单据号 | 点击查看详情；勾选了冻结仓库的带「冻结」标签 |
| 盘点仓库、盘点日期 | — |
| 明细 | 明细行数，有差异时显示「差异 N」 |
| 状态 | 草稿、审批中、已完成 |
| 制单人、确认、备注 | — |

**工具栏**：「新增盘点单」，以及导出 Excel（按当前查询条件）、显示搜索、刷新、密度、列设置。

**行操作**：「查看」；草稿时「盘点」（打开编辑录入实盘数量）、「删除」。

## 新增盘点单

![新增盘点单](/images/manual/wms/check-add.jpg)

### 表头字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 盘点仓库 | 是 | 更换仓库会清空盘点明细 |
| 盘点日期 | 是 | 默认今天 |
| 冻结仓库 | 否 | 「冻结 / 不冻结」开关。冻结时，盘点完成（确认或审批完成）前该仓库**不能出入库、调拨**，包括业务单据生成的出入库 |
| 备注 | 否 | — |

页面提示：确认盘点时以当时的库存为账面数量，库存调整为实盘数量；序列号物料按实盘序列号盘点，多出的盘盈入库、缺少的盘亏出库。

### 生成和录入明细

明细标题显示「N 行，已录入 X，有差异 Y」。右侧工具：

| 工具 | 作用 |
| --- | --- |
| 库位、物料编码或名称 | 「按库存生成」的筛选条件，可只盘某个库位或某些物料 |
| 按库存生成 | 按仓库当前库存（数量不为 0 的库存位置）生成明细，已在明细中的库存位置保留已录入的数据，提示「已添加 N 行」 |
| 添加物料 | 手工添加一行，用于账面没有的盘盈物料：选择物料、库位，批次物料填写批次号 |
| 账实相符 | 把所有**未录入**实盘数量的行填为账面数量（序列号物料除外） |

明细字段：物料、库位、批次、账面数量、实盘数量（未录入时为空）、差异（实盘 − 账面，正数为盘盈、负数为盘亏）、实盘序列号、备注。明细超过 50 行时分页显示。删除已录入实盘数量的行时会再次确认。

::: tip 序列号物料
序列号物料不能直接填实盘数量，实盘数量 = 实盘序列号的个数。按库存生成时会带出该位置在库的序列号作为参考，请按实物扫码、删除缺少的或补充多出的序列号；修改后该行才算已录入。
:::

### 保存规则

- 同一库位、物料、批次的明细不能重复；
- 批次物料必须填写批次号；
- 草稿中允许有未录入的行，**确认时所有行都必须填写实盘数量**；
- 保存时账面数量会刷新为当时的库存。

### 操作步骤

1. 点击「新增盘点单」，选择盘点仓库，按需打开「冻结仓库」；
2. （可选）选择库位或输入物料，点「按库存生成」；
3. 按实物录入实盘数量；与账面一致的可点「账实相符」批量填写；账面没有的物料点「添加物料」；
4. 保存。可以多次打开「盘点」继续录入，也可以在手机上[扫码盘点](../mobile/check)；
5. 在详情中点「确认盘点」。

## 详情

![盘点单详情](/images/manual/wms/check-detail.jpg)

详情显示盘点仓库、盘点日期、冻结仓库、制单、确认、明细统计（N 行，有差异 M 行）。明细可按「全部 / 有差异 / 未录入」筛选；草稿状态下提示「草稿中的账面数量为最近一次保存时的库存，确认时以当时的库存为准」。底部按钮：草稿时「编辑」「确认盘点」。

确认时弹窗提示：将以当前库存为账面数量计算差异，盘盈入库、盘亏出库，库存调整为实盘数量，确认后不能修改。

## 单据状态

| 状态 | 说明 | 可做操作 |
| --- | --- | --- |
| 草稿 | 盘点进行中 | 盘点（编辑）、删除、确认 |
| 审批中 | 发布了「盘点差异审批」流程且有差异，等待审批 | 只能查看；通过后调整库存，驳回 / 撤回回到草稿 |
| 已完成 | 库存已调整 | 查看 |

没有差异的盘点单即使发布了审批流程也直接完成。审批流程变量包括盘盈数量、盘亏数量、差异行数，可在[流程设计](../workflow/designer#条件分支)中按这些条件分支。

## 确认时如何调整库存

1. 重新读取每行库存位置的当前库存作为账面数量（并保存到盘点单）；
2. 差异 = 实盘 − 账面，差异为正时盘盈入库，为负时盘亏出库，库存流水业务类型为「盘点」；
3. 序列号物料按序列号逐个比较：实盘有、账面没有的盘盈入库，账面有、实盘没有的盘亏出库；
4. 盘亏不受库存预留限制（实物已经不在），也不受冻结仓库限制。

## 注意事项

::: tip 提示
盘点单号格式为 PD + 日期 + 4 位流水号。盘点允许包含已停用的物料和库位（它们可能还有库存）。
:::

::: warning 注意
- 盘点日期所在月份已[结账](../fin/period)或已做[成本核算](../fin/cost)时不能确认；
- 勾选了「冻结仓库」的盘点单如果长期不确认，会阻塞该仓库的所有出入库，盘点完成后请及时确认，或删除不用的草稿；
- 生成明细后到确认前如果库存有变化（例如没有冻结仓库时仍有出入库），差异会按确认时的库存重新计算。
:::
