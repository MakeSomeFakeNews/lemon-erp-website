# 盘点单

盘点单用于核对仓库的实物数量与系统账面数量。选择仓库后用「[选择商品](#选择商品)」按货位、分类、品牌、库存等条件勾选本次要盘点的商品（只挑一段时间内有过库存变动的商品即[动态盘点](#动态盘点)），录入实盘数量（或在手机上扫码盘点），确认后系统自动盘盈入库、盘亏出库，把库存调整为实盘数量。

## 页面入口

仓库 → 库存作业 → 盘点单

![盘点单列表](/images/manual/wms/check-list.jpg)

## 列表

**查询条件**：单据号、仓库、状态、盘点日期。

**列表列**：

| 列 | 说明 |
| --- | --- |
| 单据号 | 点击查看详情；勾选了冻结仓库的带「冻结」标签 |
| 盘点仓库、盘点日期 | — |
| 明细 | 明细行数，有差异时显示「差异 N」 |
| 状态 | 草稿、审批中、已完成 |
| 确认 | 确认人和确认时间 |
| 制单人、备注 | — |

**工具栏**：「新增盘点单」，以及导出 Excel（按当前查询条件）、显示搜索、刷新、密度、列设置。

**行操作**（图标，鼠标悬停显示名称）：「查看」；草稿时另有「盘点」（编辑图标，打开编辑录入实盘数量）、「删除」。

## 新增盘点单

![新增盘点单](/images/manual/wms/check-add.jpg)

### 表头字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 盘点仓库 | 是 | 更换仓库会清空盘点明细 |
| 盘点日期 | 是 | 默认今天 |
| 冻结仓库 | 否 | 「冻结 / 不冻结」开关。冻结时，盘点完成（确认或审批完成）前该仓库**不能出入库、调拨**，包括业务单据生成的出入库 |
| 备注 | 否 | — |

页面提示：确认盘点时以当时的库存为账面数量，库存调整为实盘数量；序列号物料按实盘序列号盘点，多出的盘盈入库、缺少的盘亏出库。显示「盘盈成本价」列时还提示：盘盈按填写的成本价入库，不填按确认时的当前均价；盘亏按当前均价出库。

### 生成和录入明细

明细标题显示「N 行，已录入 X，有差异 Y」。右侧工具：

| 工具 | 作用 |
| --- | --- |
| 选择商品 | 打开「选择商品」窗口，按条件查询商品，勾选后加入明细，见 [选择商品](#选择商品)。鼠标悬停提示：按仓库、按变动商品（动态盘点）都是其中的查询条件 |
| 添加物料 | 手工添加一行，逐个添加要盘点的物料或账面没有的盘盈物料：选择物料、库位，批次物料填写批次号 |
| 账实相符 | 把所有**未录入**实盘数量的行填为账面数量（序列号物料除外） |

未选择盘点仓库时「选择商品」「添加物料」不可用。明细为空时提示「选择仓库后点击「选择商品」，按仓库、变动日期、分类、货位等条件勾选本次要盘点的物料；也可「添加物料」逐个添加」。

::: tip 为什么没有「按库存生成」
盘点单不再一次按整个仓库的库存（或全部变动商品）生成明细：商品多的仓库一次生成几千行明细，既无法逐个核对，也很难一次盘完。实际做法是**每次盘一部分**，按货位、分类或品牌把一次大盘点拆成多张盘点单，分批盘点、分批确认。原来的两种用法都可以在「选择商品」中完成：

- **按库存生成**：仓库范围选「本仓库货品」、库存选「库存 > 0」（可再加货位、分类、品牌），查询后点「全部符合条件的」加入；
- **按变动商品生成**：勾选「变动日期」，用快捷选项选择今天、昨天、本周或本月，查询后点「全部符合条件的」加入，见 [动态盘点](#动态盘点)。
:::

明细字段：物料、库位、批次、账面数量、实盘数量（未录入时为空）、差异（实盘 − 账面，正数为盘盈、负数为盘亏）、盘盈成本价（见下文）、实盘序列号、备注。明细超过 50 行时分页显示。删除已录入实盘数量的行时会再次确认。

::: tip 序列号物料
序列号物料不能直接填实盘数量，实盘数量 = 实盘序列号的个数。通过「选择商品」加入明细时会带出该位置在库的序列号作为参考，请按实物扫码、删除缺少的或补充多出的序列号；修改后该行才算已录入。
:::

### 动态盘点

动态盘点只盘点一段时间内有过库存变动的商品，不必每次全盘，适合：

- **日终盘点**：每天下班前盘点今天有过出入库的商品（选「今天」）；
- **次日早上盘点**：上班后盘点昨天有过变动的商品（选「昨天」）；
- **每周 / 每月盘点**：盘点本周（从周一起到今天）或本月（从 1 日起到今天）有过变动的商品。

做法：打开「选择商品」，勾选「变动日期」，用快捷选项选择今天、昨天、本周或本月（也可以自己选日期范围），查询后勾选或点「全部符合条件的」加入明细（加入规则见下文 [加入明细的规则](#加入明细的规则)）。还可以同时加上货位、分类等条件，把变动商品再分批盘点。

**变动的口径**：

- 只看**盘点仓库**的库存变动；
- 按库存实际变化的时间，即单据**确认时间**，不是单据上的业务日期（例如昨天日期的入库单今天才确认，算今天的变动）；
- 包括出入库、调拨（含在途调拨的验收入库、退回）、组装拆卸、冲销等所有库存变动；
- **不包括盘点本身的盘盈盘亏**，刚盘点过、调整过的商品不会因此在下一次动态盘点中再次出现。

### 选择商品

点「选择商品」打开窗口：上方是查询条件，下方是商品列表。数据来源是**商品资料**（不是库存），所以盘点仓库当前没有库存的商品也会列出，可用于盘点账面为 0、实际可能有货的商品。不列出多规格商品的款式（只列具体规格的物料）。

**查询条件**：默认显示前三个（仓库范围、名称 / 规格 / 编码、变动日期），点「展开」显示全部，「收起」恢复。

| 条件 | 说明 |
| --- | --- |
| 仓库范围 | 「本仓库货品」（默认）或「全部物料」，切换后立即查询。**本仓库货品**指与盘点仓库有关的商品：在盘点仓库有库存记录（包括已经出完、库存为 0 的）、在盘点仓库有过出入库，或默认库位在该仓库。「全部物料」不限，用于盘点从没进过该仓库、但实物出现在仓库中的商品 |
| 名称 / 规格 / 编码 | 按名称、规格、编码、条码或简拼模糊查询 |
| 变动日期 | 勾选后才生效，只列出该日期范围内在盘点仓库有过库存变动的物料（口径同上文 [动态盘点](#动态盘点)）；默认今天，日期范围可只填一头或都不填（不限），快捷选项今天、昨天、本周、本月 |
| 分类 | 含下级分类 |
| 品牌 | — |
| 货位 | 盘点仓库的库位：物料的默认库位是它，或在该库位有库存 |
| 库存 | 全部（默认）、库存 > 0、库存 = 0、库存 < 0，按盘点仓库的库存合计判断（与列表中的「当前库存」一致）；「库存 = 0」包括在盘点仓库没有库存记录的商品 |
| 状态 | 启用、停用，默认不限（停用的物料可能还有库存，也可以盘点） |
| 最新进货、最新销售 | 日期范围，按全公司最近一次已完成的采购入库 / 销售出库的业务日期筛选 |

**列表列**：

| 列 | 说明 |
| --- | --- |
| 编码、名称、规格、单位 | 停用的商品名称后带「停用」标签，已在盘点明细中的带「已在明细」标签 |
| 分类、品牌 | — |
| 货位 | 盘点仓库中有库存的库位（多个用逗号分隔）；没有库存时显示物料在该仓库的默认库位 |
| 当前库存 | 盘点仓库的库存，为 0 也显示（灰色），负数为红色 |
| 最近变动 | 在盘点仓库最近一次库存变动的时间，不含盘点 |
| 最新进货、最新销售 | 全公司最近一次已完成的采购入库 / 销售出库的业务日期 |
| 条码 | — |

没有的显示「-」。列表默认每页 20 条，可切换为 50、100、200 条。

**勾选和加入**：

- 点击行或左侧复选框勾选，再点一次取消；可以翻页继续勾选，勾选会跨页保留；底部左侧显示「已选 N 种」，点「清空」取消全部勾选；
- 「**确定**」：把勾选的商品加入明细并关闭窗口；
- 「**加入并继续选择**」：把勾选的商品加入明细，窗口不关闭、清空勾选，可以换条件继续选；
- 「**全部符合条件的（N）**」：把当前条件下的全部商品加入明细，最多 2000 个（盘点明细上限 2000 行），超过时提示「符合条件的物料有 N 个，超过盘点明细上限 2000 行，请缩小范围」。建议按货位、分类等分批盘点。

### 加入明细的规则

「选择商品」加入明细时：

- 盘点仓库**有库存**的物料，按库存位置（库位、批次）各加一行，带出账面数量；序列号物料同时带出在库序列号；
- 盘点仓库**没有库存**的物料加一行，账面数量为 0，库位默认取物料在该仓库的默认库位，库位、批次可以修改；
- 已在明细中的库存位置不重复添加（没有库存的物料已在明细中时也不再添加），已录入的数据保留；
- 添加后提示「已添加 N 行」，选择的都已在明细中时提示「选择的物料都已在盘点明细中」；明细超过 2000 行时提示「盘点明细超过 2000 行，请分多张盘点单」。

### 盘盈成本价

![盘点单填写盘盈成本价](/images/manual/wms/check-add.jpg)

差异为正（盘盈）的行可以填写「**盘盈成本价**」，即盘盈的物料以什么单价进入库存（不含税、按基本单位，最多 4 位小数）。有「查看成本金额」权限时，输入框中灰色提示「均价 X」为该物料的当前均价；没有该权限时只提示「默认当前均价」，不显示具体数值。不填时，确认盘点时按当时的均价入库。盘亏的行不用填写，按当前均价出库，显示「-」。

该列在有「查看成本金额」权限，或有盘点单新增 / 修改权限时显示。当前均价属于成本信息，只给有「查看成本金额」权限的人看。成本价只影响[实时库存成本](./stock#实时库存成本)，月末[成本核算](../fin/cost)对盘盈盘亏另行计价。

### 保存规则

- 同一库位、物料、批次的明细不能重复；
- 批次物料必须填写批次号；
- 草稿中允许有未录入的行，**确认时所有行都必须填写实盘数量**；
- 保存时账面数量会刷新为当时的库存。

### 操作步骤

1. 点击「新增盘点单」，选择盘点仓库，按需打开「冻结仓库」；
2. 点「选择商品」，按货位、分类、品牌、库存等条件挑选本次要盘点的商品（动态盘点时勾选「变动日期」），勾选后「确定」加入明细；一次盘点的商品较多时拆成多张盘点单；
3. 按实物录入实盘数量；与账面一致的可点「账实相符」批量填写；账面没有的物料点「添加物料」；
4. 保存。可以多次打开「盘点」继续录入，也可以在手机上[扫码盘点](../mobile/check)；
5. 在详情中点「确认盘点」。

## 详情

![盘点单详情](/images/manual/wms/check-detail.jpg)

详情显示盘点仓库、盘点日期、冻结仓库、制单、确认、明细统计（N 行，有差异 M 行）。明细中与成本有关的两列按权限显示：

- **盘盈成本价**：有「查看成本金额」权限时显示；没有该权限但有盘点单新增 / 修改权限的，只在盘点单确认前显示。盘盈行填写的成本价；未确认时没有填写的显示「均价 X」（有「查看成本金额」权限）或「默认当前均价」；已完成的盘点单中没有填写的显示实际计价的单价（差异金额 ÷ 盘盈数量）；非盘盈行为「-」；
- **差异金额**：只对有「查看成本金额」权限的人显示。已完成的盘点单为实际计入库存的成本金额（盘亏为负数，红色）；未确认的按当前均价（盘盈有填写成本价时按成本价）估算，显示为「≈ 金额」，鼠标悬停提示「按当前均价估算，确认时以实际计价为准」。

明细可按「全部 / 有差异 / 未录入」筛选；草稿状态下提示「草稿中的账面数量为最近一次保存时的库存，确认时以当时的库存为准」。底部按钮：草稿时「编辑」「确认盘点」。

确认时弹窗提示：将以当前库存为账面数量计算差异，盘盈入库、盘亏出库，库存调整为实盘数量，确认后不能修改。

## 单据状态

| 状态 | 说明 | 可做操作 |
| --- | --- | --- |
| 草稿 | 盘点进行中 | 盘点（编辑）、删除、确认 |
| 审批中 | 发布了「盘点差异审批」流程且有差异，等待审批 | 只能查看；通过后调整库存，驳回 / 撤回回到草稿 |
| 已完成 | 库存已调整 | 查看 |

没有差异的盘点单即使发布了审批流程也直接完成。审批流程变量包括盘盈数量、盘亏数量、差异行数，可在[流程设计](../workflow/designer#条件分支)中按这些条件分支。

## 确认时如何调整库存

1. 重新读取每行库存位置的当前库存作为账面数量（并保存到盘点单）；
2. 差异 = 实盘 − 账面，差异为正时盘盈入库，为负时盘亏出库，库存流水业务类型为「盘点」；
3. 序列号物料按序列号逐个比较：实盘有、账面没有的盘盈入库，账面有、实盘没有的盘亏出库；
4. 盘亏不受库存预留限制（实物已经不在），也不受冻结仓库限制；
5. 实时库存成本：盘盈按填写的盘盈成本价（不填按确认时的均价）入库，盘亏按当前均价出库，金额记在库存流水上。

## 注意事项

::: tip 提示
盘点单号格式为 PD + 日期 + 4 位流水号。盘点允许包含已停用的物料和库位（它们可能还有库存）。
:::

::: warning 注意
- 盘点日期所在月份已[结账](../fin/period)或已做[成本核算](../fin/cost)时不能确认；
- 勾选了「冻结仓库」的盘点单如果长期不确认，会阻塞该仓库的所有出入库，盘点完成后请及时确认，或删除不用的草稿；
- 手机端（移动作业、微信小程序）可以在草稿盘点单上随扫随加物料，有新增权限时也可以选择仓库直接新建盘点，但没有「选择商品」窗口，**确认盘点只能在电脑端**，见 [移动作业 - 盘点](../mobile/check)；
- 生成明细后到确认前如果库存有变化（例如没有冻结仓库时仍有出入库），差异会按确认时的库存重新计算。
:::
