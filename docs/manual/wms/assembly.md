# 组装拆卸

组装拆卸单用于不经过生产工单的简单组合与拆分：**组装**把若干子件组合成一个成套件（如礼盒装、套装、整机配件包），**拆卸**把成套件拆回子件（如整箱拆零、套装拆散单卖）。子件可以按成套件的 BOM 自动带出；确认后系统自动生成出库单、入库单并更新库存，成本核算时成套件按所耗子件的成本入账。

## 页面入口

仓库 → 库存作业 → 组装拆卸

![组装拆卸列表](/images/manual/wms/assembly-list.jpg)

## 列表

**查询条件**：单据号、种类（组装 / 拆卸）、仓库、状态（草稿 / 已完成）。点「展开」显示全部条件。

**列表列**：

| 列 | 说明 |
| --- | --- |
| 单据号 | 点击打开详情，编号默认以 ZZ 开头（如 ZZ202610170001），规则可在「系统管理 → [编码规则](../system/code-rule)」中调整 |
| 种类 | 组装 / 拆卸 |
| 成套件 | 成套件的编码、名称，下方为规格 |
| 数量 | 成套件数量和单位 |
| 仓库、业务日期 | — |
| 状态 | 草稿 / 已完成 |
| 制单人 | — |
| 操作 | 草稿：「编辑」「确认」「删除」；已完成：「查看」 |

**工具栏**：「新增组装拆卸单」，以及显示搜索、刷新、密度。

只能看到数据权限范围内的单据（按制单人部门 + 制单人控制，见[数据权限](../guide/permission)）。

## 新增 / 编辑组装拆卸单

点「新增组装拆卸单」，表单占满内容区：

![新增组装拆卸单](/images/manual/wms/assembly-form.jpg)

表单顶部提示：「组装：子件出库、成套件入库，成套件成本 = 所耗子件成本；拆卸：成套件出库、子件入库，成套件成本按子件参考单价分摊。确认后不能修改，撤回时做一张反向的单据。」

### 表头

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 种类 | 是 | 「组装」或「拆卸」，默认组装 |
| 仓库 | 是 | 子件、成套件都在这个仓库出入库。更换仓库会清空已选的库位 |
| 业务日期 | 是 | 默认今天，生成的出入库单使用这个日期 |
| 备注 | 否 | 最多 255 字 |

### 成套件

标题随种类显示「成套件（组装后入库）」或「成套件（拆卸出库）」。

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 物料 | 是 | 搜索选择物料（支持扫码）。多规格物料要选具体的 SKU，不能选款式 |
| 数量 | 是 | 大于 0，最多 4 位小数；序列号物料只能为整数 |
| 库位 | 否 | 组装时为成套件入库的库位，拆卸时为成套件出库的库位；不选为「未指定」库位 |
| 批次号 | 批次物料必填 | 成套件启用批次管理时显示 |
| 序列号 | 序列号物料必填 | 成套件启用序列号管理时显示，逗号或换行分隔，个数与数量一致 |

### 子件

标题显示「子件（组装时出库 / 拆卸后入库，N 行）」。

- 「**按 BOM 带出**」（选择成套件并填写数量后可用）：读取成套件的默认 [BOM](../mes/bom)（没有默认时取第一个启用的），按「BOM 用量 × 成套件数量」生成子件明细，并提示「已按 BOM … 带出 N 个子件，请核对批次、序列号」。物料没有可用的 BOM、或当前用户没有查看 BOM 的权限时，提示「该物料没有可用的 BOM，或没有查看 BOM 的权限」。带出会覆盖已录入的子件行。
- 「**添加子件**」：手工增加一行。

| 列 | 必填 | 说明 |
| --- | --- | --- |
| 子件 | 是 | 不能与成套件相同；多规格物料要选具体的 SKU |
| 数量 | 是 | 序列号物料只能为整数 |
| 库位 | 否 | 组装时为子件出库库位，拆卸时为子件入库库位 |
| 批次号 | 批次物料必填 | 非批次物料显示「-」 |
| 序列号 | 序列号物料必填 | 逗号分隔；非序列号物料显示「-」 |

子件最多 200 行。点每行右侧的删除按钮删除该行。

保存后单据为「草稿」，草稿可以反复编辑、删除，不影响库存。

## 确认

在列表中点草稿行的「确认」，提示「确认 单据号？确认后生成出入库单并更新库存，不能再修改。」确认后系统在同一次操作中：

| 种类 | 先生成出库单 | 再生成入库单 |
| --- | --- | --- |
| 组装 | 子件出库 | 成套件入库 |
| 拆卸 | 成套件出库 | 子件入库 |

- 生成的[出库单](./out)、[入库单](./in)类型都是「**组装拆卸**」，状态为已完成，单据号旁显示「来源 组装拆卸单号」，备注为「组装 单号」或「拆卸 单号」；
- 出库时校验库存：库存不足、批次不在该库位、序列号不在库等任何一行出错，整张单据不会确认，库存不变；
- 业务日期所在月份已结账或已做成本核算时不能确认（与其他出入库单相同，见[期间控制](./#期间控制)）；
- 多人同时确认同一张单据时只有一次生效，其他人提示「单据已确认，请刷新」。

确认需要「组装拆卸确认」权限；新增、编辑、删除需要「组装拆卸维护」权限。

## 详情

点单据号或「查看」打开详情：种类、仓库、业务日期、成套件、数量、库位 / 批次、状态、出入库单（已完成时显示「出库 … ，入库 …」两个单据号）、制单人、序列号、备注，以及子件明细（子件、数量、库位、批次号、序列号）。

## 单据状态

| 状态 | 可以做什么 |
| --- | --- |
| 草稿 | 编辑、删除、确认 |
| 已完成 | 只能查看。生成的出入库单不能修改、删除或冲销 |

组装拆卸单确认后不能撤销。如果做错了，**做一张反向的单据**冲回：组装错了做一张相同物料、数量的拆卸单，拆卸错了做一张组装单。

## 成本

在「财务 → [成本核算](../fin/cost)」中，组装拆卸生成的出入库按以下方式计价：

- **组装**：成套件的入库成本 = 所耗各子件的「数量 × 单价」之和；
- **拆卸**：拆出的成套件成本按各子件的单价（上期单价，没有时取参考成本价）比例分摊到子件，作为子件的入库成本；
- 组装拆卸在凭证中表现为存货之间的结转（借 入库物料的存货科目、贷 出库物料的存货科目），不计入盘盈盘亏。

具体的计算顺序和凭证说明见[成本核算](../fin/cost)。

## 与其他模块的联动

- **库存**：确认时生成并确认出库单、入库单，更新库存、批次、序列号，并记入[库存流水](./flow)；在[收发存汇总](./inout)中计入「其他入库」「其他出库」；
- **BOM**：子件可按成套件的默认 BOM 带出；
- **财务**：[成本核算](../fin/cost)按子件成本计算成套件成本。

## 注意事项

::: tip 提示
需要工序、工时、报工的组装请使用生产模块的[生产工单](../mes/wo)；组装拆卸单适合仓库内的简单组套、拆零。
:::

::: warning 注意
- 已被组装拆卸单引用的物料（成套件或子件）不能删除，只能停用；
- 多规格物料的款式不能用于组装拆卸，提示「…是多规格款式，请选择具体的规格（SKU）」。
:::
