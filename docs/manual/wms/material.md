# 物料管理

物料是整个系统共用的主数据：采购、销售、生产、仓库、财务使用的都是这里的同一份物料。在这里维护物料的编码、单位、分类、批次 / 序列号 / 来料检验等追踪方式、安全库存、补货参数、条码与辅助单位、默认仓库库位、参考成本与存货计价方法、品牌和多档销售价格（零售价、批发价），以及生产计划属性和替代料，可以上传[商品图片](#商品图片)、[复制物料](#复制物料)、在发生库存业务后[切换批次管理](#批次管理的启用与停用)，并可以打印物料条码标签。服装、鞋帽等按颜色、尺码区分的商品可以设为[多规格款式](#多规格物料与-sku)，按规格属性批量生成 SKU。

## 页面入口

仓库 → 基础资料 → 物料管理

![物料管理列表](/images/manual/wms/material-list.jpg)

## 列表

页面左侧是[物料分类](#物料分类)树，右侧是物料列表。点击左侧的分类，列表只显示该分类及其所有下级分类的物料；点「全部物料」恢复显示全部。

**查询条件**：物料（编码、名称、规格、条码，也可输入拼音首字母或去掉分隔符的规格缩写，规则同[搜索选择资料](../guide/common#搜索选择资料)）、品牌、状态（启用 / 停用）；分类在左侧分类树中选择。

**工具栏**：

| 导入 | 从 Excel 批量导入物料 |
| 批量删除 | 删除勾选的物料 |
| 价格列设置 | 设置零售价、批发价1～8 的名称和是否启用（需要「价格列设置」权限），见[价格列设置](#价格列设置) |
| 打印标签（N） | 为勾选的物料（当前页）打印物料条码标签 |
| 导出 | 按当前查询条件导出 Excel |
| 隐藏分类 / 显示分类 | 工具栏右侧的图标按钮，收起或展开左侧的分类树，本机浏览器会记住当前状态 |

## 物料分类

物料分类是多级的（最多 5 级），例如「原材料 → 电子元器件 → 电阻」，在本页左侧的「物料分类」树中维护，不再在业务字典中维护。初始有原材料、半成品、成品、包装材料、其他、低值易耗品 6 个一级分类，可以在它们下面建下级分类，也可以新增其他一级分类。

**查看**：

- 分类树顶部是「全部物料」，下面按层级列出分类；每个分类右侧的数字是该分类及其所有下级分类的物料数，停用的分类后面显示「停用」标签；
- 搜索框可按分类名称或编码查找；标题右侧的按钮可以全部展开 / 全部折叠；
- 点击分类时，右侧列出该分类及其所有下级分类的物料。

**维护**（需要「物料分类维护」按钮权限，没有时分类树只能查看）：

| 操作 | 说明 |
| --- | --- |
| 新增一级分类 | 分类树标题右侧的「+」图标 |
| 新增下级分类 | 鼠标移到分类上，点右侧三个点图标中的「新增下级分类」；已经是第 5 级时不可用 |
| 编辑 | 三个点菜单中的「编辑」，可修改上级分类、名称、排序、状态、备注 |
| 删除 | 三个点菜单中的「删除」，确认后删除，不能删除的情况见下文 |
| 拖动排序 | 直接拖动分类调整顺序；拖到其他分类上就成为它的下级。搜索时不能拖动 |

新增 / 编辑分类的字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 上级分类 | 否 | 不选为一级分类。不能选它自己或它的下级 |
| 分类编码 | 否 | 只能包含字母、数字、下划线和短横线，不超过 16 位，不能重复；**留空自动生成**（如 C0001）。物料、检验方案、促销等按编码关联，**保存后不能修改** |
| 分类名称 | 是 | 最多 64 个字；同一上级下不能重名 |
| 排序 | 否 | 留空排在最后 |
| 状态 | 是 | 停用后不能再给物料选择该分类及其下级分类，已有物料不受影响 |
| 备注 | 否 | 最多 255 字 |

因为各处按编码关联分类，修改分类名称、移动到其他上级、调整层级都不影响已有的物料和设置，显示的名称和路径会随之变化。

**不能删除的情况**（删除时提示原因）：

- 下面还有下级分类：先删除或移走下级分类；
- 分类下有物料：先把物料改到其他分类，或者停用该分类；
- 被[检验方案](../qms/plan)、[促销活动](../scm/promotion)、[返利协议](../scm/rebate)的返利项目、[提成规则](../scm/commission)、[凭证科目设置](../fin/account-rule)引用；
- 内置分类（原材料、半成品、成品、低值易耗品）：系统按它们计算凭证科目、低值易耗品领用等，不能删除，可以改名或停用。

**下级分类的规则**：

- 按分类筛选的地方（本页、[商品价格](../scm/goods-price)、[库存查询](./stock)、收发存汇总、库龄分析、[进销存报表](../scm/jxc)、[生产统计](../mes/stat)、[销售预测](../bi/decision)等）选择上级分类时，**包含所有下级分类**的物料；
- 按分类设置的规则（[检验方案](../qms/plan)、[促销](../scm/promotion)、[销售提成](../scm/commission)、[凭证科目设置](../fin/account-rule)）中，**上级分类的设置对下级分类同样适用**；下级分类自己有设置时用自己的，多级上级都有设置时取最近的一级；
- 按分类汇总的报表按物料所在的分类分别统计，名称显示完整路径。

## 新增 / 编辑物料

![编辑物料](/images/manual/wms/material-edit.jpg)

### 基础信息

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 物料编码 | 是 | 只能包含字母、数字、下划线、点和短横线，最多 64 字符，不能重复 |
| 物料名称 | 是 | 最多 128 字 |
| 规格型号 | 否 | — |
| 计量单位 | 否 | 基本单位，可从常用单位（个、件、台、箱、包、桶、瓶、袋、kg、g、L、m）中选或自行输入。库存、成本都按基本单位 |
| 分类 | 否 | 从物料分类树中选择（可搜索），选中后显示完整路径。可以选任意一级分类；已停用的分类及其下级不能选择 |
| 品牌 | 否 | 从业务字典「商品品牌」中选择（可搜索），品牌的取值在「系统管理 → [业务字典](../system/biz-dict)」中维护；[进销存报表](../scm/jxc)可按品牌汇总 |
| 安全库存 | 否 | 全部仓库的库存合计低于该值时预警（库存查询、首页待办）；MRP 计算净需求时也会保留这部分库存。为空不预警 |
| 再订货点 | 否 | 预计库存（可用 + 采购在途 + 在制 − 销售待发 − 工单待领料）不高于此值时，出现在「供应链 → 采购 → [补货建议](../scm/reorder)」中。为空不参与 |
| 再订货量 | 否 | 经济批量，补货建议的建议数量 |
| 条码 | 否 | 物料的条码（如商品条码），扫码选择物料时使用；不能与其他物料或辅助单位条码重复 |
| 参考成本价 | 否 | 按基本单位，没有实际成本时参考使用（[成本核算](../fin/cost)没有单价时按此计价，毛利分析未核算的期间也取此价；[实时库存成本](./stock#实时库存成本)还没有均价的物料、期初导入不填成本单价时也取此价） |
| 计价方法 | 否 | 存货计价方法：月末一次加权平均（默认）、移动加权平均、先进先出。月末[成本核算](../fin/cost#存货计价方法)时按此计算出库成本，修改后从下一次核算生效；修改记入变更历史 |
| 默认仓库 | 否 | 录入单据时带出 |
| 默认库位 | 否 | 必须属于默认仓库。入库单选择的仓库就是默认仓库时自动带出；上架推荐优先使用 |
| 追踪方式 | 否 | 见下表 |
| 销售价格 | 否 | 「销售价格」分区按启用的价格列各一个输入框（如零售价、批发价1～3），含税、按基本单位，不能小于 0，见下文[销售价格与品牌](#销售价格与品牌) |
| 备注 | 否 | 最多 255 字 |

**追踪方式**（已发生库存业务的物料，表单中不能再修改批次、序列号管理方式，下方提示「已发生库存业务的物料，在操作栏「更多 → 批次管理」中切换（会同时调整已有库存）」，见[批次管理的启用与停用](#批次管理的启用与停用)）：

| 选项 | 说明 |
| --- | --- |
| 批次管理 | 出入库须填写批次号，可记录生产日期、有效期，按批次追踪 |
| 序列号管理 | 数量为整数，出入库逐个登记序列号，追踪每一件的流转 |
| 来料检验 | 采购入库后冻结为待检，来料检验合格（或让步接收）后才能出库，不合格的等待退货，见[库存冻结](./hold) |

### 生产计划（需要生产计划属性修改权限）

拥有生产模块的物料计划权限时，编辑抽屉中多出「生产计划」分区；只有该权限、没有物料修改权限时，基础信息只读，页面提示「没有物料修改权限，只能维护生产计划属性」。

| 字段 | 说明 |
| --- | --- |
| 物料属性 | 自动：有启用的默认 [BOM](../mes/bom) 为自制，否则为采购；自制：[MRP](../mes/mrp) 建议生成工单，按 BOM 展开子件；采购：MRP 建议生成采购订单，即使有 BOM 也不展开；委外：向默认供应商（加工商）下采购订单，同时展开要提供的子件；虚拟件：不入库的中间组件，需求直接传给子件，工单用料展开为子件 |
| 提前期 | 0～365 天，为空时取 BOM 或供货价格的提前期 |
| 计划员 | 选填 |
| 最小批量 | MRP、缺料下单的建议数量不低于该值 |
| 批量倍数 | 建议数量向上取整到该值的整数倍 |
| 允许超领 | 0～100%，工单领料上限，超出部分须走[补料申请](../mes/supplement) |
| 完工需成品检验 | 勾选后，工单完工入库的累计数量不能超过已确认的[成品检验](../qms/inspection#完工需成品检验)（FQC）合格数 |

**替代料**：主料缺料时，可在「生产制造 → [齐套分析](../mes/kit)」中把工单未领的部分按比例换成替代料。点「添加替代料」增加一行：替代料（必填）、替代比例（必填，替代 1 个主料需要的数量）、优先级（1～99）、备注（适用条件）。物料属性为虚拟件时不能设置替代料。

### 扩展信息

管理员在「系统管理 → [自定义字段](../system/custom-field)」中为「物料」定义了扩展字段（如产地、材质）后，表单末尾出现「扩展信息」分区，按字段类型填写；设置为必填的字段未填写时提示「请填写…」，不能保存。勾选了「列表显示」的字段同时作为物料列表的列。没有定义扩展字段时不显示该分区。

### 操作步骤

1. 点击「新增物料」，填写编码、名称、单位等基础信息；
2. 按管理需要勾选批次管理、序列号管理、来料检验，设置安全库存、默认仓库库位；
3. （有权限时）在「生产计划」分区设置物料属性、提前期、批量规则、替代料；
4. 保存。需要辅助单位时在列表操作栏的「更多」中选择「单位」维护。

## 销售价格与品牌

![物料的销售价格](/images/manual/wms/material-price.jpg)

物料可以维护 9 档销售价格：零售价、批发价1～批发价8，都是含税单价、按基本单位、人民币。客户资料中的「[价格等级](../scm/customer#价格等级与执行价)」指定客户使用哪一档，开销售订单、报价单或直接开单时，没有客户执行价和价目价的物料按这一档带出单价，取价顺序见[开单默认价](../scm/price-list#开单默认价)。

- 逐个维护：在编辑物料表单的「销售价格」分区填写，修改记入物料的变更记录；
- 批量维护：在「供应链 → 销售 → [商品价格](../scm/goods-price)」中按分类、品牌筛选后在表格中修改，或按零售价比例、参考成本加价批量填充；
- 导入：物料导入模板中包含启用的价格列。

只有生产计划属性修改权限、没有物料修改权限的用户，表单中的品牌和价格不可编辑。

### 价格列设置

点工具栏的「**价格列设置**」打开对话框：

![价格列设置](/images/manual/wms/material-price-level.jpg)

顶部提示：「设置零售价、批发价的显示名称；停用的价格列在物料表单、列表、导入导出和价格选择中隐藏，已填写的价格保留。」

| 列 | 说明 |
| --- | --- |
| 价格列 | 0 为零售价，1～8 为批发价1～8，固定不变 |
| 显示名称 | 必填，最多 32 个字，例如把「批发价1」改为「一级经销价」；为空时提示「请填写价格列名称」 |
| 启用 | 开关。默认只启用零售价和批发价1～3 |

点「确定」保存，提示「价格列设置已保存」，物料列表、商品价格页面、客户的价格等级选项立即使用新的名称。说明：

- 价格列设置对整个企业（租户）生效，新开通的租户使用默认设置；
- 停用的列在各处隐藏，已经填写的价格保留，编辑物料时也不会被清空，重新启用后恢复；
- 停用的列不参与开单默认价：价格等级为该列的客户改按零售价取价；
- 名称未修改时随界面语言显示（如英文界面显示 Retail price）。

## 复制物料

新增一个与已有物料大部分资料相同的物料（如同一系列的另一个型号）时，在列表操作栏的「更多」中选择「**复制**」（需要物料新增权限），打开新增表单并带出原物料的资料，修改不同的部分后保存。

| 项目 | 说明 |
| --- | --- |
| 带出的内容 | 名称、规格型号、计量单位、分类、品牌、各价格列、安全库存、再订货点 / 再订货量、默认仓库与库位、参考成本价、计价方法、批次 / 序列号管理和来料检验、备注；生产计划属性（物料属性、提前期、批量规则等）、替代料；扩展信息（自定义字段） |
| 物料编码 | **留空**，保存时按「系统管理 → 编码规则」自动生成，也可以手工填写 |
| 条码 | **不带出**（条码不能重复），需要时重新填写 |
| 保存时另外复制 | 辅助单位（不含包装条码，原因同上）和商品图片（复制为新的图片文件，之后两个物料的图片互不影响） |
| 不复制 | 库存、批次、序列号、库存流水等业务数据，附件和变更记录 |

**多规格**：从款式或 SKU 复制出来的都是**普通物料**，只复制资料，不复制 SKU 和规格属性，复制时提示「多规格款式 / SKU 复制为普通物料：只复制资料，不复制 SKU 和规格属性，可在新物料上重新生成多规格」。需要时在新物料上点「多规格」重新生成。

## 批次管理的启用与停用

物料一旦发生库存业务，就不能在编辑表单中修改批次、序列号管理方式，因为库存按「仓库 + 库位 + 物料 + 批次」记账：直接改开关会让已有库存与新规则对不上。需要改变时，在列表操作栏的「更多」中选择「**批次管理**」（需要物料修改权限），在「批次 / 序列号管理 - 编码 名称」弹窗中切换，系统会同时调整已有库存。

弹窗先显示「当前库存」，以及「有库存的批次数」（已启用批次管理）或「没有批次号的库存」（未启用），然后勾选或取消「批次管理」「序列号管理」，点「确定」保存。

**启用批次管理**：

- 弹窗提示「启用后，已有库存按库位整体归入下面的批次（数量不变）；之后出入库必须填写批次号，出库时可选择该批次」；
- 填写「已有库存归入批次」（默认「期初」，可以修改；有库存时必填，未填提示「请填写已有库存归入的批次号」），可选填生产日期、有效期，登记到该批次，出库选择批次和[批次追溯](./trace)中可以看到；
- 已有的库存按库存位置（仓库 + 库位）整体归入该批次，在库的序列号同步归入该批次。

**停用批次管理**：

- 弹窗提示「停用后，各批次的库存按库位合并为无批次（数量不变），历史流水和批次追溯保留原批次号；之后出入库不再要求批次」；
- 同一库位上各批次的库存合并为一条无批次的库存，数量和冻结数量相加；在库序列号的批次清空；
- 历史的库存流水、序列号轨迹和批次登记仍保留原批次号，批次追溯照常能查；之后出入库填写的批次号会被清空。

两种切换都**不改变任何库位的库存数量合计**，不产生库存流水，不影响成本；切换记入物料的变更记录。

**序列号管理**也可以在这里切换，但**只能在库存为 0 时**切换，有库存时复选框不可用，并提示「库存不为 0，不能切换序列号管理：启用需要为每件在库物品登记序列号，停用会使在库序列号失真，请先出库或盘点调整到 0」。需要切换时先出库或盘点调整到 0。

**阻止切换的单据**：以下单据已经按确定的批次 / 序列号执行，存在时弹窗顶部列出单号并提示「以下单据按已确定的批次 / 序列号执行，完成或取消后才能切换」，「确定」按钮不可用：

| 单据 | 处理方式 |
| --- | --- |
| 在途的调拨单 | 调入仓库收货后 |
| 审批中的仓库单据（入库、出库、调拨） | 审批完成或撤回后 |
| 草稿或审批中的盘点单 | 完成或删除盘点单后 |
| 仍冻结的待检 / 不合格库存 | 来料检验放行或退货后，见[库存冻结](./hold) |
| 未出库的发货通知 | 出库或取消后 |

**不阻止的单据**：出入库单草稿、进销存单据（采购入库、销售出库等）草稿、组装拆卸单草稿。它们在确认时按物料切换后的方式校验：启用后需要补填批次号，停用后批次号自动清空（弹窗底部提示同样内容）。库存预留只保证仓库可用量、不锁定批次，不受影响。

多规格款式本身没有库存，不在这里切换，请在各 SKU 上切换（列表中款式行没有此项）。

## 辅助单位与包装条码

在列表操作栏的「更多」中选择「单位」：

![辅助单位](/images/manual/wms/material-units.jpg)

- 「1 辅助单位 = 换算率 × 基本单位」，库存、成本都按基本单位核算，采购 / 销售订单可按辅助单位录入（保存换算后的基本单位数量）；
- 每行：辅助单位（必填，最多 16 字，不能与基本单位相同、不能重复）、换算率（必填，大于 0，最多 4 位小数）、条码（选填，如整箱条码）；
- 点「添加辅助单位」增加，点「保存」整体保存。

扫描辅助单位条码时，系统按换算率折算数量：例如 1 箱 = 20 个，扫一次箱码数量加 20。

## 多规格物料与 SKU

同一款商品有多种颜色、尺码等规格，并且每种规格需要分别管理库存时，可以把它设为**款式**，按规格属性的组合批量生成 **SKU**：

- 每个 SKU 是一个独立的物料，有自己的编码、库存、成本，出入库、订单、盘点都按 SKU 进行；
- **款式**本身只是 SKU 的归集，不能出入库，也不会出现在单据的物料下拉中。

规格属性（颜色、尺码等）及其属性值在「仓库 → 基础资料 → [规格属性](./attribute)」中维护。

### 生成 SKU

1. 先新增一个物料作为款式（如编码 TS01、名称「圆领 T 恤」），填好单位、分类、批次 / 序列号管理、计价方法、默认仓库等，这些设置会被 SKU 继承；
2. 在列表中点该物料的「**多规格**」，打开「多规格 · 编码 名称」抽屉；
3. 在「规格属性」中选择要用的属性（最多 3 个），如颜色、尺码；
4. 每个属性下勾选需要的属性值，或点「全选」；下方实时显示「将新增 N 个 SKU」；
5. 点「**生成 SKU**」（需要物料新增权限），提示「已生成 N 个 SKU」。

![多规格：生成 SKU](/images/manual/wms/material-variant.jpg)

抽屉顶部提示：「选择规格属性和属性值后生成 SKU：每个 SKU 是一个独立的物料（编码 = 款式编码-属性值编码），继承本物料的单位、分类、批次 / 序列号管理、计价方法等；生成后本物料成为款式，不能再直接出入库。」

生成规则：

| 项目 | 说明 |
| --- | --- |
| SKU 编码 | 款式编码 + 「-」+ 各属性值的编码（属性按规格属性的排序，属性值没有编码时用属性值本身），如 TS01-RD-XL；最长 64 个字符，与已有物料编码重复时不能生成 |
| 物料名称 | 与款式相同 |
| 规格型号 | 款式的规格型号 + 属性值，如「纯棉 红色 / XL」；款式没有规格时就是「红色 / XL」 |
| 继承的设置 | 计量单位、分类、批次管理、序列号管理、来料检验、默认仓库与库位、参考成本价、计价方法 |
| 不继承的设置 | 条码、辅助单位、安全库存、再订货点 / 再订货量、生产计划属性等，需要时在 SKU 上单独维护；SKU 没有条码时，标签和扫码使用 SKU 编码 |
| 数量上限 | 一个款式最多 500 个 SKU |

第一次生成后，原物料就成为款式（列表中显示「款式」标签）。

### 补充规格与库存矩阵

再次在款式行操作栏的「更多」中选择「多规格」：

- 抽屉列出已生成的 SKU（「SKU（N 个）」）。使用两个属性时显示为二维矩阵（如颜色 × 尺码），每个格子显示 SKU 编码和库存，右侧为行合计；一个或三个属性时按列表显示 SKU 编码、规格、库存、状态；
- 库存为全部仓库（不含不良品仓）的库存数量，需要库存查询权限才显示；
- 已生成过的属性值不能取消勾选；勾选新的属性值（例如新增了「XXL」尺码）后点「生成 SKU」，只生成尚未存在的组合；
- 所用的规格属性不能再增加或减少，提示「该款式已按其他规格属性生成过 SKU，属性需要保持一致」。

### 款式与 SKU 的规则

- 已经发生过库存业务（有库存流水）的物料不能设为款式，提示「…已发生库存业务，不能设为多规格款式，请新建款式物料」；
- SKU 不能再作为款式，SKU 行的「更多」中没有「多规格」；
- 款式不能用于任何出入库、调拨、盘点、组装拆卸，提示「…是多规格款式，请选择具体的规格（SKU）」；
- 款式下还有 SKU 时不能删除，提示「款式「…」下还有 SKU，请先删除 SKU」；
- 新增、导入的物料都是普通物料，款式和 SKU 只能通过「多规格」生成；编辑款式或 SKU 不会改变它们之间的关系；
- SKU 可以像普通物料一样单独编辑（如补充条码、安全库存）、停用。停用的 SKU 在订单「按规格录入」时不会加入明细。

采购、销售订单可以「按规格录入」：选择款式后在规格矩阵中直接填写各 SKU 的数量，见[采购订单](../scm/purchase#按规格录入)。

## 导入

点击「导入」：先「下载导入模板」，按模板填写后上传 .xlsx 文件。可导入的列：物料编码 *、物料名称 *、规格型号、计量单位、分类、品牌、批次管理（是 / 否）、序列号管理（是 / 否）、来料检验（是 / 否）、安全库存、启用的各价格列（列名为价格列设置中的名称）、备注。品牌须是「商品品牌」字典中的值。带 * 的列必填，**任何一行有错误时整批不导入**，弹窗中列出错误行。

「分类」列可以按以下任一种写法填写，须是未停用的分类：

| 写法 | 示例 | 说明 |
| --- | --- | --- |
| 分类编码 | RAW、C0003 | 不区分大小写 |
| 完整路径 | 电子元器件/电阻 | 从一级分类写起，各级之间用「/」分隔，「/」两侧有没有空格都可以 |
| 分类名称 | 电阻 | 只有一个分类叫这个名称时才能匹配；有重名时请改写编码或完整路径 |

匹配不上时提示「找不到物料分类「…」（可填写分类编码、完整路径如「电子元器件/电阻」，或不重名的分类名称）」。分类需要先在左侧分类树中建好，导入不会自动新建分类。导出时「分类」列输出完整路径，可以直接再导入。

## 注意事项

::: warning 注意
- 已发生库存业务或被单据（含组装拆卸单）引用的物料不能删除，只能停用；
- 多规格款式下还有 SKU 时不能删除；款式不能直接出入库，单据中请选择具体的 SKU；
- 已发生库存业务的物料不能在表单中修改批次、序列号管理方式，请用「更多 → 批次管理」切换；有在途调拨、未完成的盘点、待检冻结、未出库的发货通知等进行中的单据时不能切换，序列号管理只能在库存为 0 时切换；
- 商品图片的地址不登录也能访问，只上传可以公开的商品图；
- 条码在所有物料和辅助单位之间必须唯一；
- 物料分类的编码保存后不能修改；有下级分类、有物料、被其他设置引用的分类以及内置分类不能删除，不用的分类可以停用；
- 多规格款式生成 SKU 时不继承品牌和销售价格，需要为 SKU 单独填写。
:::
