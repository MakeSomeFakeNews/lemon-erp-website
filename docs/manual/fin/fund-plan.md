# 资金计划

从现金和银行存款的当前余额出发，按周或按月预测未来的资金流入、流出和期末余额，提前发现资金缺口。出纳、财务主管使用。

## 页面入口

财务 → 资金与费用 → 资金计划

![资金计划](/images/manual/fin/fund-plan.jpg)

## 页面说明

### 顶部

- **按周 / 按月**：切换统计粒度。
- **期数**：按周可选未来 4、8、12、26 周（默认 12 周）；按月可选未来 3、6、12 个月（默认 6 个月）。
- **刷新**：重新计算。

下方四个指标：

| 指标 | 说明 |
| --- | --- |
| 当前余额（现金 + 银行） | 库存现金、银行存款科目的期初余额加全部凭证发生额 |
| 期内预计流入 / 流出 | 各期合计 |
| 最低余额 | 当前余额与各期期末余额中的最小值；出现缺口时提示「N 期出现资金缺口，最早在 xx」，否则显示「期内资金充足」 |

图表以柱状图显示每期预计流入、流出，折线显示期末余额，红色虚线为 0 余额线。

### 资金计划表

| 列 | 说明 |
| --- | --- |
| 期间 | 第一行为「已逾期」（到期日已过但仍未收付的款项），其后为各周 / 各月；期末余额为负的期间显示「资金缺口」 |
| 预计流入 | 应收账款（未核销的应收单余额）、应收票据到期（持有的应收票据）、计划项 |
| 预计流出 | 应付账款（未核销的应付单余额）、应付票据到期（未兑付的应付票据）、待付报销、计划项 |
| 净流量 | 流入 − 流出 |
| 期末余额 | 上期余额 + 净流量 |

各款项按到期日归入对应期间。**点击任意一行**打开该期的预计收支明细：到期日、方向、来源、单号、往来单位 / 说明、金额。

### 计划项

录入应收应付之外预计发生的收支，如房租、借款到期、投资款。列表只显示今天及以后的计划项。

点击「**新增计划项**」：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 方向 | 是 | 流入 / 流出，默认流出 |
| 预计日期 | 是 | |
| 金额 | 是 | 大于 0 |
| 说明 | 是 | 如「支付房租、收回投资款」 |

计划项可以编辑、删除（需要「计划项维护」权限），保存后资金计划自动刷新。
