# 期初余额

系统上线时录入各科目的期初余额和存货期初数量、金额，作为账簿、报表和成本核算的起点。实施人员、会计使用。

## 页面入口

财务 → 期末与设置 → 期初余额

页面有两个页签：**科目期初**、**存货期初**。

## 科目期初

![科目期初](/images/manual/fin/opening-account.jpg)

列出全部末级科目（每页 50 个），可按科目编码或名称过滤，勾选「只看有余额的科目」。

| 列 | 说明 |
| --- | --- |
| 科目编码 / 科目名称 / 类别 / 方向 | |
| 期初借方 / 期初贷方 | 录入启用时的余额，不能小于 0；与科目方向相反的一栏提示为「-」 |

工具栏右侧实时显示借方合计和贷方合计，不平衡时标红。

### 操作步骤

1. 逐个科目录入期初借方或贷方余额；或点「**导入**」，按模板（科目编码必填、科目名称、期初借方、期初贷方）导入，导入只填入表格，需核对后保存。导入的科目必须是存在的末级科目。
2. 确认**借方合计等于贷方合计**。
3. 点击「**保存科目期初**」。

科目期初合并到科目余额表、明细账的期初，以及资产负债表的年初、期末数。**已有结账期间后不能再修改**科目期初。

## 存货期初

![存货期初](/images/manual/fin/opening-stock.jpg)

录入成本核算启用期间之前的存货结存数量和金额，作为启用期间成本核算的期初。

### 操作步骤

1. 选择**启用期间**（第一个要做成本核算的月份）。
2. 系统列出启用期间之前有库存的物料，「账面结存」与「期初数量」默认按之前的[库存流水](../wms/flow)推算。
3. 为每个物料录入**期初金额**，或录入**单价**自动计算金额（金额 = 单价 × 数量）。也可以点「**添加物料**」补充物料（手工添加的行可删除），或点「**导入**」（物料编码、数量、金额）。
4. 点击「**保存存货期初**」。

存货期初保存为启用期间上一期的成本结果（成本核算页显示为「存货期初」），启用期间核算时作为期初。

工具栏会对比**存货期初金额**与「原材料」「库存商品」的**科目期初**，不一致时标红，请调整至一致。

### 限制

- 数量为 0 的物料不能有期初金额；同一物料不能重复。
- **已经核算过成本后不能修改**存货期初（显示「已核算成本，不能修改」），需先撤销全部成本核算。
- 存货期初所在期间不能做成本核算，也不能再发生库存变动。

::: tip 提示
成本核算时如提示某些物料「有出库但单价为 0」，说明缺少这些物料的期初金额，请在这里补录后重新核算。
:::
