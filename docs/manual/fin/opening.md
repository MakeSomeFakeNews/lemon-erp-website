# 期初余额

系统上线时录入各科目的期初余额和存货期初数量、金额，作为账簿、报表和成本核算的起点。实施人员、会计使用。

## 页面入口

财务 → 期末与设置 → 期初余额

页面有三个页签：**启用向导**（默认）、**科目期初**、**存货期初**。

## 启用向导

![启用向导](/images/manual/fin/opening-guide.jpg)

系统上线时按顺序准备期初数据。向导列出 5 个步骤及完成情况，已完成的步骤序号以蓝色实心圆显示：

| 步骤 | 内容 | 完成标志 | 操作 |
| --- | --- | --- | --- |
| 1 会计科目与凭证科目 | 在[会计科目](./account)中按企业实际增加明细科目、设置辅助核算；在[凭证科目设置](./account-rule)中确认自动凭证使用的科目 | 始终显示为完成，请自行确认 | — |
| 2 科目期初 | 显示已录入的科目数、借方合计、贷方合计；不平衡时提示「借贷不平衡」 | 已录入且借贷平衡 | 「**去录入**」切换到科目期初页签 |
| 3 期初库存 | 按仓库、库位、批次、序列号导入启用时的结存数量，生成「期初入库」单；显示已导入的单据（单号、仓库、数量，冲销过的标注「已冲销」）和总数量 | 已导入期初入库单 | 选择**启用期间**后点「**导入期初库存**」 |
| 4 存货期初 | 数量按期初库存自动带出，录入或导入金额；显示是否已保存及结存所在期间 | 已保存存货期初 | 「**去录入**」切换到存货期初页签 |
| 5 期初往来 | 按客户、供应商导入启用时未收、未付的余额；分别显示应收、应付的张数和合计，与应收账款、应付账款科目期初对比 | 已导入期初应收或应付 | 「**导入期初应收**」「**导入期初应付**」 |

导入按钮需要「期初余额修改」权限。

### 导入期初库存

1. 在第 3 步选择**启用期间**（第一个要做成本核算的月份；已保存存货期初时默认为其启用期间）。
2. 点「**导入期初库存**」，下载模板并填写：

| 列 | 必填 | 说明 |
| --- | --- | --- |
| 仓库 | 是 | 仓库编码或名称 |
| 库位 | 否 | 该仓库下的库位编码 |
| 物料编码 | 是 | |
| 物料名称 | 否 | 仅便于核对，不导入 |
| 批次号 | 否 | 批次管理的物料填写 |
| 数量 | 是 | 启用时的结存数量 |
| 序列号 | 否 | 序列号管理的物料填写 |
| 生产日期 / 有效期至 | 否 | |

3. 上传后逐行校验仓库、库位、物料等，**任何一行有错误时整批不导入**。
4. 全部通过后，按仓库生成已确认的**期初入库**单（入库类型「期初入库」，每张最多 500 行），业务日期为启用期间的前一天，库存随之增加。

之后在「存货期初」中选择同一启用期间，期初数量会按这些库存流水自动带出，只需录入金额。启用期间及之后已经核算过成本时不能再导入期初库存，需要先撤销成本核算。导入有误时，可在仓库的[入库单](../wms/in)中冲销期初入库单后重新导入。

### 导入期初往来

1. 在第 5 步点「**导入期初应收**」或「**导入期初应付**」，下载模板并填写：

| 列 | 必填 | 说明 |
| --- | --- | --- |
| 往来单位（编码或名称） | 是 | 客户或供应商的编码或名称，必须已存在 |
| 单据日期 | 是 | 一般为启用期间的前一天，所在期间不能已结账 |
| 到期日 | 否 | 不填按往来单位的账期计算 |
| 金额 | 是 | 未收 / 未付余额，不能为 0，可为负数（如期初预收冲减） |
| 备注 | 否 | 不填时为「期初余额」 |

2. 上传导入，任何一行有错误时整批不导入。每行生成一张手工[应收单 / 应付单](./ar-ap)，之后在[收款单、付款单](./settlement)中核销。
3. 向导显示应收（应付）合计与应收账款（应付账款）科目期初（含下级科目，科目取自[凭证科目设置](./account-rule)）的对比，一致时显示绿色「一致」，否则显示橙色「相差 金额」，请调整至一致。

::: tip 提示
期初往来导入生成的是手工应收应付单，不会自动生成凭证；期初余额已经通过科目期初录入，**不要为这些单据生成凭证**，否则会重复计入应收账款、应付账款。
:::

## 科目期初

![科目期初](/images/manual/fin/opening-account.jpg)

列出全部末级科目（每页 50 个），可按科目编码或名称过滤，勾选「只看有余额的科目」。

| 列 | 说明 |
| --- | --- |
| 科目编码 / 科目名称 / 类别 / 方向 | |
| 期初借方 / 期初贷方 | 录入启用时的余额，不能小于 0；与科目方向相反的一栏提示为「-」 |

工具栏右侧实时显示借方合计和贷方合计，不平衡时标红。

### 操作步骤

1. 逐个科目录入期初借方或贷方余额；或点「**导入**」，按模板（科目编码必填、科目名称、期初借方、期初贷方）导入，导入只填入表格，需核对后保存。导入的科目必须是存在的末级科目。
2. 确认**借方合计等于贷方合计**。
3. 点击「**保存科目期初**」。

科目期初合并到科目余额表、明细账的期初，以及资产负债表的年初、期末数。**已有结账期间后不能再修改**科目期初。

## 存货期初

![存货期初](/images/manual/fin/opening-stock.jpg)

录入成本核算启用期间之前的存货结存数量和金额，作为启用期间成本核算的期初。

### 操作步骤

1. 选择**启用期间**（第一个要做成本核算的月份）。
2. 系统列出启用期间之前有库存的物料，「账面结存」与「期初数量」默认按之前的[库存流水](../wms/flow)推算（通过启用向导导入的期初库存也在其中）。
3. 为每个物料录入**期初金额**，或录入**单价**自动计算金额（金额 = 单价 × 数量）。也可以点「**添加物料**」补充物料（手工添加的行可删除），或点「**导入**」（物料编码、数量、金额）。
4. 点击「**保存存货期初**」。

存货期初保存为启用期间上一期的成本结果（成本核算页显示为「存货期初」），启用期间核算时作为期初。存货期初按一个批次处理：计价方法为先进先出的物料，启用期间以期初数量和金额作为最早的批次。

工具栏会按物料分类把**存货期初金额**汇总到对应的存货科目（取自[凭证科目设置](./account-rule)中「存货」的设置，预置为原材料、库存商品等），与这些科目的**科目期初**对比，不一致时标红，请调整至一致。

### 限制

- 数量为 0 的物料不能有期初金额；同一物料不能重复。
- **已经核算过成本后不能修改**存货期初（显示「已核算成本，不能修改」），需先撤销全部成本核算。
- 存货期初所在期间不能做成本核算，也不能再发生库存变动。

::: tip 提示
成本核算时如提示某些物料「有出库但单价为 0」，说明缺少这些物料的期初金额，请在这里补录后重新核算。
:::
