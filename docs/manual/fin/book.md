# 账簿查询

按会计期间查询科目余额表、明细账和辅助核算余额。所有账簿**只统计已记账的凭证**，未审核、已审核未记账的凭证不计入。会计、出纳、财务主管使用。

## 页面入口

财务 → 总账 → 账簿查询

页面有三个页签：**科目余额表**、**明细账**、**辅助核算**。三个页签共用同一组起止期间，切换页签时期间保持不变；默认期间为本年 1 月至当前月份。

## 科目余额表

![科目余额表](/images/manual/fin/book-balance.jpg)

### 查询条件

| 条件 | 说明 |
| --- | --- |
| 期间 … 至 … | 起始期间和截止期间（年月），起始不能晚于截止 |
| 显示无发生额的科目 | 默认不勾选，只列出有期初余额或本期发生额的科目；勾选后列出全部科目 |

点击「**查询**」刷新。查询结果右侧显示「试算平衡」（绿色）或「试算不平衡」（红色）。

### 表格列

| 列 | 说明 |
| --- | --- |
| 科目 | 科目编码 + 名称，下级科目缩进显示；点击编码直接打开该科目的明细账 |
| 方向 | 科目的余额方向：借 / 贷 |
| 期初余额 | 起始期间之前的余额，包含「期初余额」中录入的科目期初 |
| 本期借方 / 本期贷方 | 起止期间内的借贷发生额 |
| 期末余额 | 期初 + 本期发生按科目方向计算的余额；与科目方向相反时显示为负数 |

- 上级科目的金额由下级科目汇总得出。
- 表格底部的「合计（一级科目）」行，按一级科目汇总期初借方 / 贷方、本期借方 / 贷方、期末借方 / 贷方，借贷相等即为试算平衡。
- 金额为 0 时显示为空，便于阅读。

## 明细账

![明细账](/images/manual/fin/book-ledger.jpg)

### 操作步骤

1. 在「选择科目（含下级）」中选择科目，可以选上级科目，此时包含其全部下级科目的分录。
2. 选择起止期间，点击「**查询**」。

也可以在科目余额表中点击科目编码，自动切换到明细账并查询该科目。

### 表格列

| 列 | 说明 |
| --- | --- |
| 日期 | 凭证日期 |
| 凭证号 | 点击打开凭证详情 |
| 摘要 | 分录摘要 |
| 科目 | 分录的末级科目 |
| 借方 / 贷方 | 分录金额 |
| 方向 / 余额 | 逐笔滚动计算的余额及其方向（借 / 贷 / 平） |

第一行为「期初余额」，最后一行为「本期合计」，这两行以合计行样式显示。

## 辅助核算

按项目、客户或供应商查询科目的本期发生额和期末余额。凭证分录带有辅助核算时才会出现在这里：手工凭证在录入时选择；应收应付、收付款、预收预付、[项目月结](../pm/accounting#项目月结)等业务生成的凭证会自动带上客户、供应商或项目。

### 查询条件

| 条件 | 说明 |
| --- | --- |
| 维度 | 项目 / 客户 / 供应商，切换后立即查询 |
| 科目 | 可选，不选为全部科目 |
| 期间 | 起止期间 |

### 表格列

| 列 | 说明 |
| --- | --- |
| 项目 / 往来单位 | 编码和名称 |
| 科目 | 科目编码和名称 |
| 本期借方 / 本期贷方 | 起止期间内的发生额 |
| 期末余额 | 截至截止期间的余额，以「借 / 贷 + 金额」显示 |

## 注意事项

::: tip 提示
- 账簿中看不到某张凭证时，请先确认凭证是否已经「记账」。
- 科目余额表试算不平衡，通常是科目期初余额借贷不平衡，请在[期初余额](./opening)中检查。
- 「账簿查询」权限（查看）同时控制科目余额表、明细账、辅助核算三个页签。
:::
