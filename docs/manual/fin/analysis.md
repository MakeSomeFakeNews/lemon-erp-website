# 经营分析

提供销售毛利（汇总与单据明细）、存货对账、库龄分析三项财务分析。财务主管、管理层、成本会计使用。

## 页面入口

财务 → 预算与分析 → 经营分析

## 销售毛利

![销售毛利](/images/manual/fin/analysis-margin.jpg)

### 查询条件

| 条件 | 说明 |
| --- | --- |
| 日期范围 | 默认本年 1 月 1 日至今天 |
| 分组方式 | 按物料 / 按客户 / 按月份 / 单据明细 |
| 客户 | 可选，只看某个客户 |
| 单据号、物料编码或名称 | 仅「单据明细」显示，模糊查询，按回车或搜索图标查询 |

### 计算口径

- **收入**：[销售出库](../scm/sales-out)（扣除销售退货）的不含税金额。
- **成本**：出库数量 × 出库当期[成本核算](./cost)的出库单价（月末一次加权平均的物料为加权平均单价，移动加权平均、先进先出的物料为本期出库的平均单价）；当期还没有核算成本的物料取物料的参考成本价，此时成本列显示「含参考成本」标签，鼠标悬停可看到涉及的行数。
- **毛利** = 收入 − 成本；**毛利率** = 毛利 ÷ 收入。

顶部汇总销售收入、销售成本、毛利（负数标红）、毛利率。表格列：物料 / 客户 / 月份、销量（按物料时）、收入、成本、毛利、毛利率。

### 单据明细

![销售毛利单据明细](/images/manual/fin/analysis-margin-detail.jpg)

选择「**单据明细**」后，按销售出库、销售退货单的每一行物料逐行列出毛利，便于追查某张单据、某个物料的毛利：

| 列 | 说明 |
| --- | --- |
| 日期 | 单据业务日期 |
| 单据 | 单据号，后面以标签显示「销售出库」或「销售退货」 |
| 客户 | |
| 物料 | 编码、名称和规格 |
| 数量 / 单位 | 销售退货为负数 |
| 收入 | 该行不含税金额，退货为负数 |
| 成本 | 数量 × 出库当期的出库单价；当期还没有核算成本时按参考成本价计算，显示「参考成本」标签 |
| 毛利 / 毛利率 | |

明细按日期、单据顺序排列，**最多显示 5000 行**；超过时提示「明细超过 5000 行，只显示前 5000 行（汇总卡片也只统计这些行）」，请缩小日期范围或按客户、物料筛选。

## 存货对账

![存货对账](/images/manual/fin/analysis-inventory.jpg)

选择期间后核对总账与成本核算、成本核算与库存是否一致：

### 科目余额核对

| 列 | 说明 |
| --- | --- |
| 科目 | 存货科目（按[凭证科目设置](./account-rule)中「存货」的设置，预置为原材料 1403、库存商品 1405，以及按物料分类设置的其他科目）和委托加工物资 1408 |
| 总账余额 | 截至期末的科目余额（含下级） |
| 成本核算期末金额 | 成本核算期末金额按物料分类汇总到对应的存货科目；委托加工物资显示「不参与成本核算」 |
| 差异 | 一致时显示「一致」，否则以红色显示差额 |

### 数量差异

列出成本核算期末数量与截至期末的[库存流水](../wms/flow)结存不一致的物料：物料、成本核算期末数量、库存流水结存、差异。全部一致时显示「全部一致」。

::: tip 提示
出现差异的常见原因：成本核算后又发生了库存变动、成本结转凭证未记账、手工凭证直接调整了存货科目，或存货期初与科目期初不一致。
:::

## 库龄分析

![库龄分析](/images/manual/fin/analysis-age.jpg)

按入库时间分析截止日期的库存结存，找出积压、呆滞的存货。

### 查询条件

| 条件 | 说明 |
| --- | --- |
| 截止日期 | 默认今天 |
| 仓库 | 不选时统计全部仓库 |
| 分类 | 物料分类，可选 |
| 物料编码或名称 | 模糊查询 |
| 分段 | 各段的上限天数，逗号分隔、递增，例如 `30,60,90,180,365`（默认），最多 8 段；不是递增的正整数时提示「库龄分段必须是递增的正整数」 |

首次切换到本页签时自动查询，修改条件后点「**查询**」。

### 计算方法

- 结存数量取截止日期的库存，按**先进先出**对应到最近的入库记录：结存来自最后几次入库，按每次入库距截止日期的天数归入相应分段。
- 不选仓库时统计全部仓库，仓库之间的调拨不改变库龄；选择仓库时，调入该仓库也算作入库。
- 入库记录不足以覆盖结存时（例如期初库存没有入库流水），差额计入最老的一段，「最早入库」显示「早于入库记录」。
- **金额** = 数量 × 截止日期所在期间及之前最近一次成本核算的单价，没有核算结果时取物料的参考成本价。

### 结果

顶部按分段显示金额、占比，最后两段（如 181-365 天、365 天以上）的金额以红色显示；最右侧为合计金额和物料种数。

表格列：物料（编码、名称、规格）、结存数量、结存金额、各分段的数量和金额（如 0-30 天、31-60 天 … 365 天以上）、最早入库日期。每页 50 种物料。
