# 经营分析

提供销售毛利（汇总与单据明细）、存货对账、库龄分析三项财务分析。财务主管、管理层、成本会计使用。

## 页面入口

财务 → 预算与分析 → 经营分析

## 销售毛利

![销售毛利](/images/manual/fin/analysis-margin.jpg)

### 查询条件

| 条件 | 说明 |
| --- | --- |
| 日期范围 | 默认本年 1 月 1 日至今天 |
| 分组方式 | 按物料 / 按客户 / 按月份 / 单据明细；按月份时按月份先后排列，按物料、客户时按销售收入从高到低排列 |
| 客户 | 可选，只看某个客户 |
| 单据号、物料编码或名称 | 仅「单据明细」显示，模糊查询，按回车或搜索图标查询 |

### 计算口径

口径与进销存[销售报表](../scm/jxc-sales#金额口径)相同，单据是存放成本、销售金额、毛利的基本单元。金额都是不含税、本位币，退货为负数：

| 项目 | 计算 | 说明 |
| --- | --- | --- |
| 货款 | — | [销售出库](../scm/sales-out)（扣除销售退货）在整单优惠**前**的不含税金额 |
| 整单优惠 | — | 订单或直接开单的[整单优惠 / 抹零](../scm/sales#整单优惠与抹零)分摊到各行的部分，含税的分摊额按行税率折算为不含税 |
| 销售收入 | 货款 − 整单优惠 | 与记账的主营业务收入一致 |
| 本公司运费 | — | 本公司承担的运费：[销售出库](../scm/sales-out#销售出库的运费)单上「本公司承担」的运费；出库单没有登记运费时，该出库单的[物流发运](../scm/shipment#运费承担)单中「本公司承担」的运费（已发货的发运单）；[销售退货](../scm/sales-out#销售退货的运费)单上客户代垫、本公司承担的运费（按退货单计入）。同一笔运费只算一次（出库单登记了运费时，由它生成的发运单不再计入）；客户承担（代垫）的运费不计入 |
| 收款折让 | — | 该销售出库 / 退货单生成的[应收单](./ar-ap)在[收款时给的折让 / 抹零](./settlement#折让与抹零)，同一单据多次收款时累计（作废、删除收款时扣回）；包括货款应收单，以及该单客户代垫运费、退货运费应收单上的折让。按该应收单的不含税比例折算；退货的红字应收单折让为负数（少退给客户）；外币单据已按记账汇率折算为本位币 |
| 坏账核销 | — | 该销售出库单的应收单上已做[坏账核销](./ar-ap#应收坏账核销)的金额，按该应收单的不含税比例折算；退货单为 0 |
| 销售金额 | 销售收入 − 本公司运费 − 收款折让 − 坏账核销 | 这笔销售最终实际得到的金额 |
| 成本 | — | 出库数量 × 出库当期[成本核算](./cost)的出库单价（月末一次加权平均的物料为加权平均单价，移动加权平均、先进先出的物料为本期出库的平均单价）；当期还没有核算成本的物料取物料的参考成本价，此时成本列显示「含参考成本」标签，鼠标悬停可看到涉及的行数 |
| 毛利 | 销售金额 − 成本 | 毛利率 = 毛利 ÷ 销售金额 |

说明：

- 运费、折让、坏账按单据各行金额比例分摊到明细，所以按物料汇总时只含所属明细的部分；
- 折让、坏账都按出库单归属：查询的是出库单的业务日期范围，不论在哪天收款、核销，看的是每张单据的真实收益；
- **与利润表毛利的区别**：在利润表中，本公司运费计入销售费用、收款折让计入财务费用（[凭证科目设置](./account-rule#折让与冲账科目)中的「收款折让 / 抹零」科目）、坏账计入营业外支出，都不在营业成本里，利润表的毛利 = 销售收入 − 成本。这里的毛利已扣除这三项，所以与利润表的毛利不同；按期间也不一定一致（利润表中的折让、坏账含税，按收款 / 核销日期）。与利润表对账时用「销售收入」列；
- 没有整单优惠、运费、折让、坏账时，货款 = 销售收入 = 销售金额。

页面上的口径说明：「口径（issue #93，不含税、退货为负数）：货款（整单优惠前）− 整单优惠 = 销售收入（与记账的主营业务收入一致）；销售金额 = 销售收入 − 本公司承担运费 − 收款折让 / 抹零 − 坏账核销；毛利 = 销售金额 − 成本，毛利率 = 毛利 ÷ 销售金额。……利润表中这三项分别计入销售费用、财务费用（收款折让科目）、营业外支出，不在营业成本里，利润表的毛利 = 销售收入 − 成本，因此与这里的毛利不同。……」

![销售毛利的坏账核销、本公司运费](/images/manual/fin/analysis-margin-badDebt.jpg)

**顶部卡片**：销售收入、销售金额、销售成本、毛利（负数标红）、毛利率；所选范围内有整单优惠、本公司运费、收款折让、坏账核销时，另外各显示一张卡片，为 0 的不显示。

**表格列**（按物料、客户、月份）：物料 / 客户 / 月份、销量（按物料时）、货款、整单优惠、销售收入、本公司运费、收款折让、坏账核销、销售金额、成本、毛利、毛利率（调整项为 0 时显示「-」），底部为合计行。

### 单据明细

![销售毛利单据明细](/images/manual/fin/analysis-margin-detail.jpg)

选择「**单据明细**」后，按销售出库、销售退货单的每一行物料逐行列出毛利，便于追查某张单据、某个物料的毛利。查询条件右侧可以切换整单优惠、本公司运费、收款折让、坏账核销的显示方式（鼠标悬停提示「整单优惠、本公司运费、收款折让、坏账核销的显示方式，两种方式合计相同」），与进销存[销售报表的商品明细](../scm/jxc-sales#商品明细)共用同一个设置（记在本机浏览器）：

| 显示方式 | 金额列 | 说明 |
| --- | --- | --- |
| **调整项汇总到底部**（默认） | 销售金额、成本、毛利、毛利率 | 行上的销售金额为该行优惠前的货款，毛利 = 货款 − 成本，不分摊调整项；表格底部在合计行之前按类别各列一行「整单优惠」「本公司承担运费」「收款折让 / 抹零」「坏账核销」（只列出有金额的项），销售金额为负数、成本为 0、毛利 = 销售金额，退货方向相反 |
| **分摊到各行** | 货款、整单优惠、销售收入、本公司运费、收款折让、坏账核销、销售金额、成本、毛利、毛利率 | 调整项按行金额比例分摊到每一行 |

两种方式共有的列：日期、单据（单据号，后面以标签显示「销售出库」或「销售退货」）、客户、物料（编码、名称和规格）、数量 / 单位（销售退货为负数）；成本当期还没有核算时按参考成本价计算，显示「参考成本」标签。

两种方式下的合计相同，都等于单据口径的销售金额与毛利。按单据号、物料关键字筛选只列出单据的部分明细时，调整行按所列明细占单据的金额比例计算（整单优惠取所列行的分摊额）。

明细按日期、单据顺序排列，**最多显示 5000 行**；超过时提示「明细超过 5000 行，只显示前 5000 行（汇总卡片也只统计这些行）」，请缩小日期范围或按客户、物料筛选。

## 存货对账

![存货对账](/images/manual/fin/analysis-inventory.jpg)

选择期间后核对总账与成本核算、成本核算与库存是否一致：

### 科目余额核对

| 列 | 说明 |
| --- | --- |
| 科目 | 存货科目（按[凭证科目设置](./account-rule)中「存货」的设置，预置为原材料 1403、库存商品 1405，以及按物料分类设置的其他科目）和委托加工物资 1408 |
| 总账余额 | 截至期末的科目余额（含下级） |
| 成本核算期末金额 | 成本核算期末金额按物料分类汇总到对应的存货科目；委托加工物资显示「不参与成本核算」 |
| 差异 | 一致时显示「一致」，否则以红色显示差额 |

### 数量差异

列出成本核算期末数量与截至期末的[库存流水](../wms/flow)结存不一致的物料：物料、成本核算期末数量、库存流水结存、差异。全部一致时显示「全部一致」。

::: tip 提示
出现差异的常见原因：成本核算后又发生了库存变动、成本结转凭证未记账、手工凭证直接调整了存货科目，或存货期初与科目期初不一致。
:::

## 库龄分析

![库龄分析](/images/manual/fin/analysis-age.jpg)

按入库时间分析截止日期的库存结存，找出积压、呆滞的存货。

### 查询条件

| 条件 | 说明 |
| --- | --- |
| 截止日期 | 默认今天 |
| 仓库 | 不选时统计全部仓库 |
| 分类 | 物料分类，可选；选择上级分类时包含其所有下级分类 |
| 物料编码或名称 | 模糊查询 |
| 分段 | 各段的上限天数，逗号分隔、递增，例如 `30,60,90,180,365`（默认），最多 8 段；不是递增的正整数时提示「库龄分段必须是递增的正整数」 |

首次切换到本页签时自动查询，修改条件后点「**查询**」。

### 计算方法

- 结存数量取截止日期的库存，按**先进先出**对应到最近的入库记录：结存来自最后几次入库，按每次入库距截止日期的天数归入相应分段。
- 不选仓库时统计全部仓库，仓库之间的调拨不改变库龄；选择仓库时，调入该仓库也算作入库（在途调拨按收货日期）。
- 入库记录不足以覆盖结存时（例如期初库存没有入库流水），差额计入最老的一段，「最早入库」显示「早于入库记录」。
- **金额** = 数量 × 截止日期所在期间及之前最近一次成本核算的单价，没有核算结果时取物料的参考成本价。

### 结果

顶部按分段显示金额、占比，最后两段（如 181-365 天、365 天以上）的金额以红色显示；最右侧为合计金额和物料种数。

表格列：物料（编码、名称、规格）、结存数量、结存金额、各分段的数量和金额（如 0-30 天、31-60 天 … 365 天以上）、最早入库日期。每页 50 种物料。
