# 资金账户

维护出纳的现金、银行、微信、支付宝等账户。每个资金账户绑定一个**入账科目**，收付款、其他收支、报销、借款、调拨等单据的「结算账户」「付款账户」下拉框中选择的就是这里启用的账户，生成凭证时记入它的入账科目；[出纳管理](./cashier)的日记账、资金日报和[银行对账](./bank)也按资金账户统计。出纳、会计使用。

## 页面入口

财务 → 资金与费用 → 资金账户

页面顶部提示：「出纳的现金、银行、微信、支付宝等账户，绑定入账科目（「指定科目」下的末级科目，不启用辅助核算，一个科目只对应一个账户）；单据的账户下拉只列出启用的账户」。

## 使用步骤

1. **设置指定科目**：在[会计科目](./account#指定科目)页面点击「指定科目」，确认现金科目、银行科目、其他货币资金科目（默认 1001 库存现金、1002 银行存款、1012 其他货币资金，一般不用修改）。本页右上角的「指定科目」按钮可直接跳转到会计科目页面。
2. **准备入账科目**：在指定科目下为每个账户建好末级科目，例如在 1002 下增加「100203 建设银行」，在 1012 下使用预置的「101201 微信」「101202 支付宝」。
3. **新增资金账户**：点击「**新增账户**」，填写名称、类型，选择入账科目，按需填写启用日期和期初，保存。
4. **银行类账户录入期初未达账**（只在填写了启用日期、且日记账期初与对账单期初不相等时需要）：在账户行点「期初」录入未达账，调平后点「启用账户」。

| 日记账期初 | — | 填写启用日期后显示：启用日期前一天的日记账余额。下方显示入账科目在启用日期之前的账面余额，供参考 |
| 对账单期初 | — | 填写启用日期后、非现金账户显示：启用日期前一天的银行对账单余额 |
| 排序、备注 | 否 | |
| 保存后立即启用 | — | 新增时显示，默认勾选。银行类账户的日记账期初与对账单期初不同时自动取消勾选，并提示「日记账期初与对账单期初不同：保存后在「期初」中录入期初未达账，调平后再启用」 |

### 入账科目的要求

- 必须是**指定科目下的启用末级科目**：现金账户在现金科目下，银行、微信、支付宝、其他账户在银行科目或其他货币资金科目下。没有合适的科目时先在「会计科目」中增加下级科目。
- **不能启用辅助核算**；已绑定为入账科目的科目也不能再启用辅助核算。
- **一个科目只能对应一个账户**，选择已被其他账户使用的科目时提示「科目 … 已是资金账户「…」的入账科目，一个科目只能对应一个账户」。
- 被资金账户绑定的科目视为已使用：不能删除，也不能再增加下级科目；账户启用中时，入账科目不能停用（提示先停用该账户）。

### 修改的限制

- **启用中的账户**只能修改名称、开户行、账号、排序和备注，表单顶部提示「账户已启用，只能修改名称、开户行、账号、排序和备注；停用后才能修改类型、入账科目、启用日期和期初」。
- **入账科目已被凭证、单据或银行对账单使用后**，不能更换入账科目（表单中提示「入账科目已被凭证或单据使用，不能更换」），账户也不能删除，只能停用。
- 录入了期初未达账的账户，不能改为现金账户或清空启用日期，需要先删除期初未达账。

## 启用日期与期初

| 情况 | 日记账、资金日报 | 银行对账 |
| --- | --- | --- |
| 不填启用日期（从建账开始） | 期初取科目的期初余额（[期初余额](./opening#科目期初)中录入），包含入账科目的全部凭证 | 账面取入账科目的全部凭证 |
| 填写启用日期 | 期初为「日记账期初」，只统计启用日期当天及以后的凭证 | 账面余额 = 日记账期初 + 启用日期起的凭证；银行余额 = 对账单期初 + 启用日期起的流水（未手工填写银行余额时） |

从旧版本升级时，已有的现金、银行末级科目会自动生成资金账户，启用日期为空，日记账期初仍取科目期初余额，原有单据和凭证不变。

### 期初未达账（银行类账户）

银行类账户启用时，日记账期初与对账单期初往往不相等，差额来自启用日期之前已发生、一方还没有入账的收支，称为**期初未达账**。在账户行点击「**期初**」，打开「期初 - 账户名称」抽屉：

- **期初平衡检查（启用日期 …）**：左边为日记账期初，加「银行已收、企业未收」、减「银行已付、企业未付」；右边为对账单期初，加「企业已收、银行未收」、减「企业已付、银行未付」；两边的「调节后余额」相等时显示「调节后余额相等」，否则显示不相等。下方显示入账科目在启用日期之前的账面余额，供核对日记账期初。
- **期初未达账**：逐笔录入类型（「企业已记银行未记」或「银行已记企业未记」）、日期（必须早于启用日期）、金额（收入为正数、支出为负数，不能为 0）、摘要、流水号，点击「新增」。可删除未勾对的未达账。

调平公式：

**日记账期初 + 银行已收企业未收 − 银行已付企业未付 = 对账单期初 + 企业已收银行未收 − 企业已付银行未付**

两边相等后点击抽屉底部的「**启用账户**」，提示「账户已启用」。不平衡时按钮不可用，直接启用也会提示「资金账户「…」的期初不平衡：调整后的日记账余额 …，调整后的对账单余额 …，请录入期初未达账调平后再启用」。

- 期初未达账只能在账户**停用（未启用）**时录入、删除；启用后抽屉中只能查看，提示「账户已启用，期初只能查看；未达账在「银行对账」中勾对」。
- 现金账户没有银行对账单，不需要录入期初未达账；没有启用日期的账户也没有期初未达账。需要从某天起启用时，先停用账户，在「修改」中填写启用日期和期初。
- 期初未达账在[银行对账](./bank#期初未达账)中标「期初」，与启用日期以后的凭证分录或银行流水勾对，未勾对的计入余额调节表。

## 启用与停用

- **启用**的账户才会出现在单据的账户下拉框中。启用时再次检查入账科目是否可用，有启用日期的银行类账户还要求期初平衡。
- **停用**后单据中不能再选择该账户；已有单据中停用的账户显示为「名称（已停用）」。[出纳管理](./cashier)、[银行对账](./bank)的账户选择框仍可选择停用的账户查询历史数据。

## 单据中的结算账户

收付款、预收预付、其他收支、费用报销和借款的付款 / 还款、账户调拨、票据（贴现、托收、兑付）、固定资产（直接付款、处置）、工资发放、销售出库 / 采购退货的运费现付、调拨单的调拨费用、小程序开单的运费付款账户，选择账户时都从资金账户中选择：

- 下拉框显示账户名称，后面附入账科目的编码和名称，只能选择**启用**的账户；
- 保存或确认时检查：所选科目建立了启用的资金账户，否则提示「科目 … 还没有建立资金账户，请先在「资金账户」中新增并启用」；账户已停用时提示「资金账户「…」已停用」；
- 业务日期**不能早于账户的启用日期**，否则提示「业务日期早于资金账户「…」的启用日期 …（启用日期之前的收支已包含在日记账期初中）」。

## 权限

| 权限 | 说明 |
| --- | --- |
| 资金账户 | 打开本页查看 |
| 资金账户新增 / 修改 / 删除 | 新增账户；修改、启用 / 停用、录入期初未达账；删除账户 |

内置的出纳、会计角色可以维护，总经理、普通用户只读。单据中的账户下拉框不需要本页权限，登录即可选择。

## 注意事项

::: tip 提示
- 新租户开通时会复制平台预置的账户（库存现金、工商银行、招商银行、微信、支付宝），不复制期初。
- 微信、支付宝的余额属于其他货币资金（1012），资产负债表的货币资金、现金流量表、资金计划都包含它们。
- 想核对日记账与总账是否一致，使用[出纳管理](./cashier#核对总账)的「核对总账」。
:::
