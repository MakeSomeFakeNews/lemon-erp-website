# 出纳管理

按日期查看库存现金、银行存款各账户的收支流水和余额：「资金日报」汇总各账户的期初、收入、支出和余额，「日记账」逐笔列出每笔收支、对方科目和滚动余额。数据直接来自凭证，出纳不需要另外登记。出纳、会计、总经理使用。

## 页面入口

财务 → 资金与费用 → 出纳管理

页面有两个页签：**资金日报**（默认）、**日记账**。两个页签共用页签右侧的条件：

| 条件 | 说明 |
| --- | --- |
| 日期范围 | 默认本月 1 日至今天，按凭证日期统计；结束日期不能早于开始日期，范围不能超过一年 |
| 只看已记账 | 默认不勾选：包含未审核、审批中、已审核和已记账的凭证，便于出纳掌握实时余额；勾选后只统计已记账凭证，与[账簿查询](./book)口径一致 |

修改日期范围或勾选「只看已记账」后，当前页签自动重新查询。

### 未生成凭证的收付款提示

页面顶部会提示「还有收款单 N 张（金额）、付款单 N 张（金额）没有生成凭证，不在日记账中；请在收款单、付款单中生成凭证」。统计的是已生效（审批通过）但还没有生成凭证的[收款单、付款单](./settlement)。这些收付款在生成凭证前不会出现在资金日报和日记账中，请先在收款单、付款单中生成凭证。全部生成后不再显示该提示。

## 资金日报

![资金日报](/images/manual/fin/cashier-daily.jpg)

列出库存现金（默认 1001）、银行存款（默认 1002，均按[凭证科目设置](./account-rule#货币资金科目范围)的「货币资金」识别）下的全部末级科目在日期范围内的情况，只显示有余额或有发生额的账户。

| 列 | 说明 |
| --- | --- |
| 账户 | 科目编码和名称；点击编码切换到「日记账」并查询该账户 |
| 期初余额 | 开始日期之前的余额，包含[期初余额](./opening#科目期初)中录入的科目期初 |
| 收入 / 收入笔数 | 日期范围内的借方发生额和借方分录笔数 |
| 支出 / 支出笔数 | 日期范围内的贷方发生额和贷方分录笔数 |
| 期末余额 | 期初余额 + 收入 − 支出；负数以红色显示 |

表格底部固定显示「合计」行。修改条件后可点「**查询**」手工刷新。

## 日记账

![日记账](/images/manual/fin/cashier-journal.jpg)

### 操作步骤

1. 切换到「日记账」页签。
2. 在账户选择框中选择现金或银行科目，可选上级科目（如 1002 银行存款，包含其全部下级账户）；不选时为全部现金和银行账户。只能选择库存现金、银行存款及其下级科目。
3. 点击「**查询**」。

### 表格列

| 列 | 说明 |
| --- | --- |
| 日期 | 凭证日期 |
| 凭证号 | 点击打开凭证详情；凭证还没有记账时在后面显示凭证状态标签（未审核、审批中、已审核） |
| 摘要 | 分录摘要 |
| 账户 | 分录的现金 / 银行科目 |
| 对方科目 | 同一张凭证中现金、银行以外的科目名称，多个用顿号分隔 |
| 收入 / 支出 | 现金、银行科目的借方 / 贷方金额 |
| 余额 | 逐笔滚动计算的余额，负数以红色显示 |

第一行为「期初余额」；每一天的流水后有一行「本日合计」；最后一行为「合计」（日期范围内的收入、支出合计和期末余额）。这些行以合计行样式显示。

## 与其他模块的联动

- 收款单、付款单、预收预付、费用报销与借款付款、票据、[账户调拨](./transfer)、工资发放等业务生成的凭证，以及手工录入的现金、银行凭证，都会出现在本页。
- 银行流水与账面的逐笔勾对、余额调节表请使用[银行对账](./bank)。
- 未来一段时间的资金预测请使用[资金计划](./fund-plan)。

## 注意事项

::: tip 提示
- 本页只查询，不能录入或修改数据；需要调整时请修改或冲销对应的凭证。
- 默认口径包含未记账凭证，因此余额可能与账簿查询（只统计已记账凭证）不一致；勾选「只看已记账」后两者一致。
- 凭证删除后，对应的收支会从本页消失。
:::

## 权限

「出纳管理」只有查看权限，内置的会计、出纳、总经理、普通用户角色都可以访问。
