# 出纳管理

按日期查看各[资金账户](./cash-account)（现金、银行、微信、支付宝等）的收支流水和余额：「资金日报」汇总各账户的期初、收入、支出和余额，「日记账」逐笔列出每笔收支、来源单据、对方科目和滚动余额，「核对总账」把日记账与总账科目余额逐户比对。数据直接来自资金账户入账科目的凭证，出纳不需要另外登记。出纳、会计、总经理使用。

## 页面入口

财务 → 资金与费用 → 出纳管理

页面有三个页签：**资金日报**（默认）、**日记账**、**核对总账**。三个页签共用页签右侧的条件：

| 条件 | 说明 |
| --- | --- |
| 日期范围 | 默认本月 1 日至今天，按凭证日期统计；结束日期不能早于开始日期，范围不能超过一年 |
| 只看已记账 | 默认不勾选：包含未审核、审批中、已审核和已记账的凭证，便于出纳掌握实时余额；勾选后只统计已记账凭证，与[账簿查询](./book)口径一致。「核对总账」页签不显示此选项 |

修改日期范围或勾选「只看已记账」后，当前页签自动重新查询。

### 未生成凭证的收付款提示

页面顶部会提示「还有收款单 N 张（金额）、付款单 N 张（金额）没有生成凭证，不在日记账中；请在收款单、付款单中生成凭证」。统计的是已生效（审批通过）但还没有生成凭证的[收款单、付款单](./settlement)。这些收付款在生成凭证前不会出现在资金日报和日记账中，请先在收款单、付款单中生成凭证。全部生成后不再显示该提示。

## 资金日报

![资金日报](/images/manual/fin/cashier-daily.jpg)

列出各[资金账户](./cash-account)在日期范围内的情况，只显示有余额或有发生额的账户。

| 列 | 说明 |
| --- | --- |
| 账户 | 资金账户名称，后面为入账科目编码；点击名称切换到「日记账」并查询该账户 |
| 期初余额 | 开始日期之前的余额：账户没有启用日期时包含[期初余额](./opening#科目期初)中录入的科目期初；有启用日期时为账户的「日记账期初」加启用日期至开始日期前一天的发生额 |
| 收入 / 收入笔数 | 日期范围内的借方发生额和借方分录笔数 |
| 支出 / 支出笔数 | 日期范围内的贷方发生额和贷方分录笔数 |
| 期末余额 | 期初余额 + 收入 − 支出；负数以红色显示 |

表格底部固定显示「合计」行。修改条件后可点「**查询**」手工刷新。

[账户调拨](./transfer)的手续费计入手续费支付账户的支出金额和支出笔数（与调拨本身分开计为一笔）。

## 日记账

![日记账](/images/manual/fin/cashier-journal.jpg)

### 操作步骤

1. 切换到「日记账」页签。
2. 在账户选择框中选择资金账户（显示账户名称和入账科目，停用的账户也可以选择，名称后带「（已停用）」）；不选时为全部资金账户。
3. 点击「**查询**」。

### 表格列

| 列 | 说明 |
| --- | --- |
| 日期 | 凭证日期 |
| 凭证号 | 点击打开凭证详情；凭证还没有记账时在后面显示凭证状态标签（未审核、审批中、已审核） |
| 摘要 | 分录摘要 |
| 来源单据 | 生成该凭证的业务：上方为凭证来源标签（如收款、付款、其他收支、账户调拨、报销），下方为来源单号；手工凭证为空 |
| 账户 | 资金账户名称，下方为入账科目编码 |
| 对方科目 | 按分录对应的对方科目：一张凭证中有多笔业务时（如调拨的本金和手续费）每行只显示自己那组分录的对方科目；一借多贷、多借一贷时显示全部对方科目，多个用顿号分隔；账户之间的调拨显示对方账户 |
| 收入 / 支出 | 入账科目的借方 / 贷方金额 |
| 余额 | 逐笔滚动计算的余额，负数以红色显示 |

[账户调拨](./transfer)在日记账中为两行：转出账户的支出、转入账户的收入（调拨金额）；有手续费时，手续费支付账户另有单独一行支出（摘要带「手续费」，对方科目为财务费用），可与银行流水中单列的手续费逐笔核对。

页签上方提示：数据来自资金账户入账科目的凭证，默认包含未审核、未记账的凭证；收入为借方、支出为贷方；账户有启用日期时从启用日期起按日记账期初计算。

第一行为「期初余额」；每一天的流水后有一行「本日合计」；最后一行为「合计」（日期范围内的收入、支出合计和期末余额）。这些行以合计行样式显示。

## 核对总账

检查出纳日记账与总账（会计科目余额）是否一致，便于出纳与会计月末对账。切换到「核对总账」页签，按页签右侧的日期范围查询，也可以点「**查询**」刷新。页签上方提示：「日记账（启用日期起，日记账期初 + 全部凭证，含未记账）与总账（入账科目的科目期初 + 已记账凭证）比对；差额来自未记账凭证和日记账期初与总账不一致，未生成凭证的收付款两边都不包含」。

每个资金账户一行（含停用的账户）：

| 列 | 说明 |
| --- | --- |
| 账户 | 资金账户名称（点击切换到日记账），下方为入账科目编码和名称 |
| 出纳日记账：期初余额 / 收入 / 支出 / 期末余额 | 日记账口径：有启用日期时从启用日期起，日记账期初 + 全部凭证（**包含未审核、未记账的凭证**）；没有启用日期时为科目期初 + 全部凭证 |
| 总账：期初余额 / 借方 / 贷方 / 期末余额 | 总账口径：入账科目的科目期初 + **已记账**凭证，不受启用日期限制，与[账簿查询](./book)一致 |
| 期末差额 | 日记账期末余额 − 总账期末余额 |
| 其中：未记账凭证 | 截至结束日期，日记账中包含、总账中还没有的未记账凭证的金额 |
| 其中：期初差异 | 有启用日期时，账户的日记账期初 − 总账在启用日期之前的余额；没有启用日期时为 0 |
| 未生成凭证的收付款 | 截至结束日期已生效但还没有生成凭证的收付款，显示「N 笔，金额」；它们不在日记账中，也不在总账中，不影响差额，只作提醒 |
| 核对结果 | 期末差额为 0 显示绿色「相符」，否则显示红色「不符」 |

期末差额 = 未记账凭证 + 期初差异。出现「不符」时按以下顺序排查：

1. **未记账凭证**：在[凭证管理](./voucher)中审核、记账相关凭证，记账后这部分差额消失；
2. **期初差异**：账户的「日记账期初」与总账在启用日期之前的余额不一致，在[资金账户](./cash-account)中核对日记账期初（账户需先停用才能修改），或检查启用日期之前的凭证是否漏记、多记；
3. 最后处理「未生成凭证的收付款」：虽然不影响差额，但日记账和总账都还没有这些收付，请在收款单、付款单中生成凭证。

## 与其他模块的联动

- 收款单、付款单、预收预付、费用报销与借款付款、票据、[账户调拨](./transfer)、[其他收支](./other-income)、工资发放等业务生成的凭证，以及手工录入的使用资金账户入账科目的凭证，都会出现在本页，可通过「来源单据」列区分。
- 账户的增减、启用日期和期初在[资金账户](./cash-account)中维护。
- 废料销售、房租水电等不经过收付款单的零星收支，请在[其他收支](./other-income)中登记，确认后即进入日记账。
- 银行流水与账面的逐笔勾对、余额调节表请使用[银行对账](./bank)。
- 未来一段时间的资金预测请使用[资金计划](./fund-plan)。

## 注意事项

::: tip 提示
- 本页只查询，不能录入或修改数据；需要调整时请修改或冲销对应的凭证。
- 默认口径包含未记账凭证，因此余额可能与账簿查询（只统计已记账凭证）不一致；勾选「只看已记账」后两者一致。
- 凭证删除后，对应的收支会从本页消失。
:::

## 权限

「出纳管理」只有查看权限，内置的会计、出纳、总经理、普通用户角色都可以访问。
