# 账户调拨

登记银行账户之间、银行与现金之间的资金划转（如资金归集、提取备用金、备付工资），保存后自动生成凭证。出纳使用。

## 页面入口

财务 → 资金与费用 → 账户调拨

## 列表

查询条件：日期范围、单号或备注。

| 列 | 说明 |
| --- | --- |
| 调拨单号 | 以 HB 开头 |
| 日期 | |
| 转出 → 转入 | 转出账户和转入账户 |
| 金额 | 有手续费时下方显示「手续费 ¥… · 转出账户 / 转入账户」，即手续费金额和承担方 |
| 凭证 | 点击查看 |
| 备注、制单人 | |
| 操作 | 删除 |

## 新增调拨

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 调拨日期 | 是 | 默认今天 |
| 转出账户 | 是 | 库存现金、银行存款下的末级科目 |
| 转入账户 | 是 | 同上，不能与转出账户相同 |
| 金额 | 是 | 大于 0 |
| 手续费 | 否 | 默认 0，计入财务费用 |
| 手续费承担方 | 是 | 填写了手续费时显示：**转出账户**（默认）或**转入账户**；下方提示两个账户实际付出、收到的金额，见下文 |
| 备注 | 否 | 如「归集资金、备付工资」 |

保存后生成凭证（未审核），分录按手续费承担方不同：

| 承担方 | 凭证 | 说明 |
| --- | --- | --- |
| 转出账户 | 借 转入账户（金额）、财务费用（手续费）/ 贷 转出账户（金额 + 手续费） | 转出账户多付出手续费，转入账户足额到账，提示「转出账户付出 ¥…，转入账户收到 ¥…」 |
| 转入账户 | 借 转入账户（金额 − 手续费）、财务费用（手续费）/ 贷 转出账户（金额） | 手续费从到账金额中扣除，适用于汇入行扣费的情况；手续费必须小于调拨金额 |

例如调拨 10,000 元、手续费 5 元：转出账户承担时，转出账户付出 10,005 元，转入账户收到 10,000 元；转入账户承担时，转出账户付出 10,000 元，转入账户收到 9,995 元。

调拨凭证会出现在[出纳管理](./cashier)的日记账中，「来源单据」列显示「账户调拨」和调拨单号。

## 删除

删除调拨时一并删除其凭证，凭证必须未审核。调拨凭证不能在凭证管理中直接删除。

::: tip 提示
现金、银行之间的划转不计入现金流量表。
:::
