# 账户调拨

登记银行账户之间、银行与现金之间的资金划转（如资金归集、提取备用金、备付工资），保存后自动生成凭证。出纳使用。

## 页面入口

财务 → 资金与费用 → 账户调拨

![账户调拨](/images/manual/fin/transfer-list.jpg)

截图环境中暂无调拨数据。

## 列表

查询条件：日期范围、单号或备注。

| 列 | 说明 |
| --- | --- |
| 调拨单号 | 以 HB 开头 |
| 日期 | |
| 转出 → 转入 | 转出账户和转入账户 |
| 金额 | 下方显示手续费 |
| 凭证 | 点击查看 |
| 备注、制单人 | |
| 操作 | 删除 |

## 新增调拨

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 调拨日期 | 是 | 默认今天 |
| 转出账户 | 是 | 库存现金、银行存款下的末级科目 |
| 转入账户 | 是 | 同上，不能与转出账户相同 |
| 金额 | 是 | 大于 0 |
| 手续费 | 否 | 默认 0，由转出账户承担，计入财务费用 |
| 备注 | 否 | 如「归集资金、备付工资」 |

保存后生成凭证（未审核）：借 转入账户（金额）、财务费用（手续费）/ 贷 转出账户（金额 + 手续费）。

## 删除

删除调拨时一并删除其凭证，凭证必须未审核。调拨凭证不能在凭证管理中直接删除。

::: tip 提示
现金、银行之间的划转不计入现金流量表。
:::
