# 账户调拨

登记银行账户之间、银行与现金之间的资金划转（如资金归集、提取备用金、备付工资），保存后自动生成凭证。出纳使用。

## 页面入口

财务 → 资金与费用 → 账户调拨

![账户调拨](/images/manual/fin/transfer-list.jpg)

![新增调拨，手续费旁边显示「手续费支付账户」](/images/manual/fin/transfer-form.jpg)

## 列表

查询条件：日期范围、单号 / 票据号码 / 备注。

| 列 | 说明 |
| --- | --- |
| 调拨单号 | 以 HB 开头；点击打开调拨详情 |
| 日期 | |
| 转出 → 转入 | 转出账户和转入账户 |
| 金额 | 调拨金额 |
| 手续费 | 没有手续费时显示「-」 |
| 手续费支付账户 | 转出账户支付或转入账户支付；没有手续费时显示「-」 |
| 票据号码、经办人 | 没有填写时为空 |
| 凭证 | 系统生成的凭证号，点击查看凭证 |
| 备注、制单人 | |
| 操作 | 删除 |

不需要的列可以在列设置中隐藏。

## 新增调拨

点击「**新增调拨**」，表单顶部提示：「银行账户之间、银行与现金之间转账，保存后生成凭证：借 转入账户 / 贷 转出账户（调拨金额）；有手续费时另记 借 财务费用 / 贷 手续费支付账户，出纳日记账、资金日报中作为该账户的一笔支出。」

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 调拨日期 | 是 | 默认今天 |
| 金额 | 是 | 大于 0 |
| 转出账户 | 是 | 库存现金、银行存款下的末级科目 |
| 转入账户 | 是 | 同上，不能与转出账户相同 |
| 手续费 | 否 | 默认 0，计入财务费用；没有手续费填 0 |
| 手续费支付账户 | 是 | 始终显示，可选**转出账户支付**（默认）或**转入账户支付**。手续费为 0 时不起作用，下拉框禁用，并提示「手续费为 0 时不起作用」；填写手续费后提示两个账户实际付出、收到的金额，见下文 |
| 经办人 | 否 | 选择用户，可不填（制单人另行记录） |
| 票据号码 | 否 | 转账回单号、支票号等，最多 64 个字符；列表可按票据号码查询 |
| 备注 | 否 | 如「归集资金、备付工资」 |

调拨保存后不能修改，填错时删除后重新登记。

### 生成的凭证

保存后生成凭证（未审核）：借 转入账户 / 贷 转出账户（调拨金额）；有手续费时另记一组分录 借 财务费用 / 贷 手续费支付账户（手续费），摘要后带「手续费」。

| 手续费支付账户 | 手续费分录 | 合计效果 |
| --- | --- | --- |
| 转出账户支付 | 借 财务费用 / 贷 转出账户 | 转出账户多付出手续费，转入账户足额到账，提示「转出账户付出 ¥…，转入账户收到 ¥…」 |
| 转入账户支付 | 借 财务费用 / 贷 转入账户 | 手续费从到账金额中扣除，适用于汇入行扣费的情况，提示「转出账户付出 ¥…，转入账户收到 ¥…（手续费从到账金额中扣除）」；手续费必须小于调拨金额 |

例如调拨 10,000 元、手续费 5 元：转出账户支付时，转出账户付出 10,005 元（调拨 10,000 元 + 手续费 5 元两笔），转入账户收到 10,000 元；转入账户支付时，转出账户付出 10,000 元，转入账户收到 10,000 元、再支出手续费 5 元，实际到账 9,995 元。

手续费单独记一组分录，所以在[出纳管理](./cashier)的日记账、资金日报和[银行对账](./bank)中，手续费是支付账户**单独的一笔支出**（日记账中对方科目为财务费用，资金日报中计入支出金额和支出笔数），可以与银行流水中单列的手续费逐笔核对。调拨凭证在日记账的「来源单据」列显示「账户调拨」和调拨单号。

手续费计入财务费用，利润表、科目余额表 / 明细账、预算执行、现金流量表、BI 利润分析等按凭证统计的报表都会包含；[其他收支](./other-income#收支汇总)的「收支汇总」中，期间内的调拨手续费单列为一行「账户调拨手续费」。

## 调拨详情

在列表中点击调拨单号打开详情，显示调拨单号、日期、转出账户、转入账户、金额、手续费、手续费支付账户（有手续费时同时显示两个账户实际付出、收到的金额；没有手续费时显示「无手续费」）、经办人、票据号码、凭证（点击查看，后面显示凭证状态）、制单人和创建时间、备注。

从其他收支的收支汇总明细中点击调拨手续费的单号，也会跳转到本页并打开该调拨的详情。

## 删除

删除调拨时一并删除其凭证，凭证必须未审核。调拨凭证不能在凭证管理中直接删除。

::: tip 提示
现金、银行之间划转的调拨金额不计入现金流量表。
:::
