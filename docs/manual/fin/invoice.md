# 发票管理

登记开给客户的销项发票和收到供应商的进项发票（支持增值税专用发票、普通发票和数电票，可导入数电票 XML 文件或税务数字账户导出的发票清单），并与应收单、应付单勾稽，从而统计未开票收入和暂估应付；进项专用发票可按期间认证。会计使用。

## 页面入口

财务 → 应收应付 → 发票管理

页面有三个页签：**销项发票**、**进项发票**、**未开票 · 暂估**。

![发票管理](/images/manual/fin/invoice-list.jpg)

## 发票列表

查询条件：客户（供应商）、状态（有效 / 已作废）、发票号码或备注，勾选「**只看待勾稽**」只列出还没有勾稽完的有效发票。列表上方显示本页价税合计和税额（已作废的不计入）。

页签右侧按钮：进项发票页签有「**认证（N）**」；两个发票页签都有「**导入**」（下拉选择「数电票 XML 文件」或「发票清单（Excel）」）和「**登记销项发票 / 登记进项发票**」。

| 列 | 说明 |
| --- | --- |
| 发票号码 | 点击查看详情 |
| 类型 | 增值税专用发票、普通发票、数电票（专票）、数电票（普票） |
| 客户 / 供应商 | |
| 开票日期 | |
| 价税合计 / 税额 | 作废的发票以删除线样式显示 |
| 状态 | 有效 / 已作废 |
| 勾稽 | 已全部勾稽显示绿色「已勾稽」；未勾稽完显示橙色「待勾稽 金额」；作废的显示「-」 |
| 认证期间 | 仅进项发票：已认证显示期间；有效的专票（含数电票专票）未认证显示「未认证」 |
| 备注、登记人 | |
| 操作 | 查看；有待勾稽金额的有效发票可「勾稽」；有效的发票可「作废」 |

## 登记发票

1. 在「销项发票」或「进项发票」页签点击「**登记销项发票 / 登记进项发票**」。
2. 填写表头：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 客户 / 供应商 | 是 | 选择后下方列出该单位**未全部开票（收票）**的应收单（应付单） |
| 发票号码 | 是 | 最多 32 位，同种类的发票号码不能重复登记 |
| 发票类型 | 否 | 默认增值税专用发票，可选普通发票、数电票（专票）、数电票（普票） |
| 开票日期 | 是 | 默认今天 |
| 价税合计 | 是 | 默认为勾稽金额合计 |
| 税额 | 是 | 按所勾单据的税额比例自动计算（税额 = 单据税额 × 勾稽金额 / 单据金额），可修改；不能大于价税合计 |
| 备注 | 否 | |

3. 在单据表格中**勾选**要勾稽的单据，勾选后「本次勾稽」默认为该单据全部未勾稽金额，可修改（红字单据为负数）。表格列：单号、来源单号、日期、金额（含税额）、已勾稽、未勾稽、本次勾稽。
4. 页面显示「勾稽合计」，与价税合计不一致时显示红色「与价税合计不一致」。
5. 点击「保存」。**勾稽合计必须等于价税合计**，每张单据累计勾稽金额不能超过其金额。

## 导入数电票

![导入数电票 XML](/images/manual/fin/invoice-xml.jpg)

在「销项发票」或「进项发票」页签点「**导入**」，按当前页签导入销项或进项发票。导入的发票先**不勾稽**应收应付单，可以选择自动勾稽，也可以之后在列表中手工勾稽。

### 数电票 XML 文件

1. 点「导入 → **数电票 XML 文件**」。
2. 把从税务数字账户下载的数电票 XML 拖到对话框中或点击选择，可多选，最多 200 个。
3. 「**自动勾稽**」默认勾选：往来单位只有一张未开票（未收票）金额与发票价税合计相等的单据时自动勾稽该单据。
4. 点「**导入**」。成功时提示「导入 N 张，M 张已登记过跳过，自动勾稽 K 张」；有错误时列出出错的文件和原因，**整批不导入**。

系统从 XML 中读取发票号码、开票日期、销售方和购买方的名称与纳税人识别号、价税合计、税额和明细行（项目名称、规格型号、单位、数量、单价、金额、税率、税额）。发票类型按票种识别为数电票（普票）或数电票（专票）。明细行的税率按百分数保存和显示：XML 中写作 0.13、13% 或 13 的，都识别为 13%。

### 发票清单（Excel）

点「导入 → **发票清单（Excel）**」，下载模板或使用税务数字账户导出的发票清单整理后上传。列：发票号码*、发票类型（按名称填写，为空按数电票（专票））、开票日期*、销方识别号、销方名称、购方识别号、购方名称、价税合计*、税额*。发票清单导入始终执行自动勾稽，没有发票明细行。

### 匹配往来单位

- 进项发票按**销售方**、销项发票按**购买方**的纳税人识别号匹配供应商 / 客户（往来单位资料中的「纳税人识别号」）；没有识别号或匹配不到时按名称匹配。
- 都匹配不到时提示「供应商「名称 识别号」不存在，请先在往来单位中登记（纳税人识别号或名称）」，请先在[供应商](../scm/supplier)或[客户](../scm/customer)中补充纳税人识别号。
- 同一种类下已登记过的发票号码自动跳过；同一批文件中发票号码重复时报错。

## 勾稽导入的发票

导入后没有勾稽（或只勾稽了部分）的发票，在列表中点「**勾稽**」：

1. 对话框显示往来单位、价税合计和**待勾稽**金额，下方列出该往来单位未全部开票（收票）的单据；未勾稽金额恰好等于待勾稽金额的单据默认勾选。
2. 勾选单据并修改「本次勾稽」金额，对话框显示本次勾稽合计。
3. 点「**勾稽**」。累计勾稽金额不能超过发票价税合计，每张单据累计勾稽不能超过其金额；已勾稽过的单据不能重复勾稽。

一张发票可以分多次勾稽，直到待勾稽为 0。

## 作废

在列表点击「作废」并确认。作废后释放对应收应付单的勾稽金额，单据重新变为未开票（未收票）。**已认证的进项发票不能作废**，需先取消认证。

## 进项发票认证

1. 在「进项发票」页签勾选有效的发票，点击「**认证（N）**」。
2. 选择**认证期间**，点「认证」，所选发票记入该期间的进项税额抵扣。
3. 在同一对话框中点「取消认证」可撤销所选发票的认证。

## 未开票 · 暂估

![未开票与暂估](/images/manual/fin/invoice-uninvoiced.jpg)

按往来单位汇总截至某日期的应收应付单中**还没有勾稽发票**的金额：

- **未开票收入（销项）**：已确认应收、尚未开具销项发票的金额；
- **暂估应付（进项）**：已入库形成应付、尚未收到进项发票的金额，可用于月末暂估。

选择「截止日期」后自动刷新。顶部汇总客户（供应商）家数、单据金额、已开票（已收票）、未开票（暂估）和其中税额。表格列：客户 / 供应商、单据数、单据金额、已开票 / 已收票、未开票 / 暂估金额、其中税额。

## 详情

显示种类、发票类型、往来单位、开票日期、价税合计、税额、状态、认证期间（进项）、登记人、来源（手工登记 / 数电票 XML 导入 / 发票清单导入）、销售方和购买方（名称、纳税人识别号，导入的发票有）、备注，以及：

- **发票明细**：XML 导入的发票显示项目名称、规格型号、数量、单价、金额、税率、税额；
- **勾稽单据**：标题显示已勾稽金额，列出单据、来源单号、单据金额、勾稽金额。有效发票可点「**取消勾稽**」释放全部勾稽的单据（已认证的进项发票也可以），之后重新勾稽；
- **版式文件（PDF / OFD / XML）**：上传发票的版式文件作为附件，需要发票修改权限。

## 与其他模块的联动

应收管理、应付管理列表中的「已开票 / 已收票」列来自本页的勾稽结果；作废、取消勾稽后相应释放。

::: tip 提示
系统不对接税局的开票和查验接口：销项数电票在税务数字账户开具后，下载 XML 导入本页登记；发票真伪请在税务平台查验。
:::
