# 员工借款

管理员工借支的备用金：申请、审批、付款，之后通过现金还款或报销冲抵还清。员工、会计、出纳使用。

## 页面入口

财务 → 资金与费用 → 员工借款

![员工借款](/images/manual/fin/loan-list.jpg)

## 列表

查询条件：关键字（单号、借款人或事由）、状态（草稿、审批中、待付款、未还清、已还清）。

| 列 | 说明 |
| --- | --- |
| 单号 | 以 JK 开头，点击查看详情 |
| 借款人 | 借款人及部门 |
| 借款日期 | |
| 金额 | |
| 已还 | 已还金额；未还清时下方显示未还金额 |
| 状态 | |
| 付款凭证 | |
| 事由 | |
| 操作 | 草稿：提交、删除；待付款：付款；未还清：还款 |

工具栏支持导出。

## 新增借款

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 借款人 | 否 | 不选为本人 |
| 部门 | 否 | 不选取借款人的部门 |
| 借款日期 | 是 | 默认今天 |
| 金额 | 是 | 大于 0 |
| 事由 | 否 | 如「出差备用金」 |

保存后为「草稿」，提示「保存成功，请提交」。

## 提交与审批

点击「**提交**」：发布了「员工借款审批」[流程](../workflow/business#财务)（内置：部门主管 → 会计 → 金额 ≥ 1 万元时总经理 → 抄送出纳）时进入「审批中」，通过后变为「待付款」，拒绝或撤回后退回「草稿」；未发布流程时直接变为「待付款」。

## 付款

在待付款的借款行点击「**付款**」，选择付款账户（库存现金或银行存款）和日期，确认后生成凭证「借 其他应收款 / 贷 付款账户」，状态变为「未还清」。

## 还款

借款有两种还款方式：

- **现金还款**：在未还清的行点击「**还款**」，选择收款账户、填写还款金额（默认为全部未还金额，不能超过）、日期，生成凭证「借 收款账户 / 贷 其他应收款」。
- **报销冲抵**：员工报销时在[费用报销](./claim)中选择该借款，报销付款时自动冲抵。

累计还款等于借款金额时，状态变为「已还清」。

## 状态流转

草稿 → 审批中（启用审批时）→ 待付款 → 未还清 → 已还清

## 详情

显示借款人、部门、借款日期、状态、金额、已还（未还）、付款凭证、事由，以及还款记录（日期、金额、方式：现金还款 / 报销冲抵及报销单号、凭证）。

## 注意事项

::: tip 提示
只有草稿状态的借款可以删除。借款付款、还款生成的凭证不能在凭证管理中直接删除。
:::
