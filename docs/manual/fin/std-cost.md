# 标准成本

按版本维护物料的标准成本：采购件手工维护标准单价，自制件按 [BOM](../mes/bom) 和[工艺路线](../mes/bom#工艺路线)逐级卷算。发布后用于[成本核算](./cost)中的成本差异分析。成本会计使用。

## 页面入口

财务 → 资产与成本 → 标准成本

![标准成本版本](/images/manual/fin/std-cost-list.jpg)

| 列 | 说明 |
| --- | --- |
| 版本 | 版本名称，下方为说明；点击查看详情 |
| 生效期间 | |
| 物料数 | 总数及自制、采购件数量 |
| 待补单价 | 单价为 0 的采购件数量 |
| 状态 | 草稿 / 已发布；草稿修改单价后未卷算时显示「需重新卷算」 |

期间 P 的成本差异使用生效期间不晚于 P 的最近一个已发布版本。

## 新建版本

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 版本名称 | 是 | 如「2026 年标准成本」，不能重复 |
| 生效期间 | 是 | 默认当前月份 |
| 复制版本 | 否 | 复制已有版本中采购件的标准单价；不选时取最近一次成本核算的单价，没有时取物料的参考成本价 |
| 说明 | 否 | |

保存后按当前的默认 BOM 和工艺路线卷算自制件的标准成本，并打开详情。

### 卷算规则

自制件单位标准成本 = Σ 子件用量 × (1 + 损耗率) × 子件标准成本 + 本级工序标准工时 × [工作中心](../mes/work-center)人工费率 + 标准工时 × 制造费用率，按 BOM 逐级向上计算。BOM 有循环引用时报错。

点击自制件的「**明细**」查看卷算明细：材料部分列出子件、用量（含损耗）、单价；人工和制造费用部分列出各工序。明细按卷算时的 BOM 和当前费率显示，修改 BOM、费率后请重新卷算。

### 草稿版本的操作

- **编辑**：修改版本名称、生效期间、说明。
- **添加采购件 / 改价**：填写物料和标准单价（4 位小数）。有默认 BOM 的物料是自制件，不能手工定价。**修改单价后必须重新卷算**。
- **删除采购件**：自制件由卷算得出，不能删除。
- **卷算**：重新卷算自制件；仍有单价为 0 的采购件时提示补录。
- **发布**：发布后不能再修改，成本差异从生效期间开始使用该版本。修改单价后未卷算的不能发布；同一生效期间只能有一个已发布的版本。
- **删除**：删除草稿版本。

### 已发布版本

点击「**取消发布**」后可以修改，成本差异分析改用更早的版本。
