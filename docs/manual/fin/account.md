# 会计科目

维护会计科目表。系统已预置企业会计准则常用科目，可以按需增加明细科目。会计、财务主管使用。

## 页面入口

财务 → 期末与设置 → 会计科目

![会计科目](/images/manual/fin/account.jpg)

## 列表

以树形展示全部科目，默认全部展开。工具栏：按科目编码或名称搜索、「全部展开 / 全部折叠」、「**指定科目**」（需要凭证科目设置的修改权限）、「**新增一级科目**」。

| 列 | 说明 |
| --- | --- |
| 科目编码 | |
| 科目名称 | 没有下级的科目带「末级」标签；被设为指定科目的带「现金科目」「银行科目」「其他货币资金科目」标签 |
| 类别 | 资产、负债、所有者权益、成本、损益 |
| 余额方向 | 借 / 贷 |
| 辅助核算 | 科目设置的辅助核算项目，以标签显示（部门、客户、供应商、项目、存货） |
| 状态 | 启用 / 停用开关（需要修改权限） |
| 备注 | |
| 操作 | 图标按钮，鼠标悬停显示名称：编辑、新增下级、删除（仅末级科目显示） |

## 编码规则

- **一级科目为 4 位数字**，如 1002 银行存款。
- **下级科目在上级编码后加 2 位数字**，如 100201 工商银行。
- 下级科目的类别、余额方向默认继承上级，类别不能修改。

## 新增 / 编辑科目

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 上级科目 | — | 新增下级时显示，不可修改 |
| 科目编码 | 是 | 纯数字，按上述编码规则，不能重复 |
| 科目名称 | 是 | |
| 类别 | 是 | 新增一级科目时选择；下级继承上级 |
| 余额方向 | 是 | 借 / 贷 |
| 辅助核算 | 否 | 多选：部门、客户、供应商、项目、存货。新增下级科目时默认沿用上级科目的设置，可修改 |
| 备注 | 否 | |

## 辅助核算

在科目上勾选辅助核算项目后，**手工录入凭证**使用该科目时这些项目必填，录入时自动显示在分录的辅助核算列中（见[凭证管理](./voucher#辅助核算)）。可以多选，例如管理费用同时按部门和项目核算。

- 预置科目中，应收账款（1122）、预收账款（2203）按**客户**核算，应付账款（2202）、预付账款（1123）按**供应商**核算。
- 科目已经使用后也可以修改辅助核算，只影响之后录入的凭证，已有凭证不变。
- 业务单据生成的凭证按单据自动带出客户、供应商、项目等，不受科目设置的约束。
- 按辅助核算项目查询余额请使用「[账簿查询 → 辅助核算](./book#辅助核算)」。

## 使用规则

- 凭证、折旧科目、费用科目、资金账户的入账科目等只能选择**启用的末级科目**。
- **已被使用（有凭证分录、收付款、固定资产、预算，被凭证科目设置引用，或是资金账户的入账科目）的科目**不能删除，可以停用。
- 已被使用或有下级科目的科目，编辑时只能修改名称、备注和辅助核算。
- 已被使用的科目**不能再增加下级科目**，因此请在使用前规划好明细科目。
- 有下级科目的科目不能删除。
- 停用的科目不能再用于新凭证。

## 系统自动生成凭证使用的科目

业务单据自动生成凭证时使用的科目（应收账款、应付账款、存货、主营业务收入、主营业务成本、应付职工薪酬、工资费用、税费等）在「[凭证科目设置](./account-rule)」中查看和修改，未设置时使用预置科目（如应收账款 1122、原材料 1403、库存商品 1405、主营业务收入 6001）。

- 自动凭证使用的科目**必须是启用的末级科目**。如果要给预置科目增加明细科目（例如把 6001 主营业务收入按产品线拆分），请先建好明细科目，再到凭证科目设置中改为使用明细科目，否则相关业务生成凭证时会提示该科目不是末级科目。
- 被凭证科目设置引用的科目视为已使用：不能删除，也不能再增加下级科目。

## 指定科目

点击工具栏的「**指定科目**」，设置三类货币资金科目（参照用友的「指定科目」）：

| 项目 | 不指定时 | 用途 |
| --- | --- | --- |
| 现金科目 | 预置科目 1001 库存现金 | 现金类[资金账户](./cash-account)的入账科目只能选它下面的末级科目 |
| 银行科目 | 预置科目 1002 银行存款 | 银行、微信、支付宝等资金账户的入账科目可以选它或其他货币资金科目下的末级科目 |
| 其他货币资金科目 | 预置科目 1012 其他货币资金 | 同上，用于微信、支付宝、存出投资款等 |

- 弹窗顶部提示：「资金账户的入账科目只能选这些科目下的末级科目（现金账户选现金科目，银行、微信、支付宝等选银行科目或其他货币资金科目），现金流量表、资金计划按此识别货币资金；可以指定一级科目」。
- 指定的是一个科目及其全部下级，通常选一级科目；必须是资产类科目，三者不能互相包含。
- 设置与[凭证科目设置](./account-rule#货币资金科目范围)「货币资金」中的库存现金、银行存款、其他货币资金是同一份，在任一处修改都可以；保存后列表中对应的科目显示标签。
- 预置科目表中已有 1012 其他货币资金及其下级 101201 微信、101202 支付宝；从旧版本升级时没有 1012 的会自动补充，1012 还没有下级和分录时补充这两个下级科目。

现金、银行存款可以按开户行增加明细科目（如 100203 建设银行），再在「[资金账户](./cash-account)」中为它新增账户，单据中选择的是资金账户；[出纳管理](./cashier)、[资金计划](./fund-plan)、现金流量表按指定科目识别货币资金。
