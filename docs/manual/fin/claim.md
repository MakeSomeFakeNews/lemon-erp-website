# 费用报销

员工填写报销单，提交时做预算控制并可走审批，审批通过后由出纳付款，付款时可先冲抵员工借款。员工、部门主管、会计、出纳使用。

## 页面入口

财务 → 资金与费用 → 费用报销

![费用报销列表](/images/manual/fin/claim-list.jpg)

## 列表

查询条件：关键字（单号、报销人或事由）、状态（草稿、审批中、待付款、已付款）、「只看我的」。

| 列 | 说明 |
| --- | --- |
| 单号 | 以 BX 开头，点击查看详情 |
| 报销人 | 报销人及其部门 |
| 报销日期 | |
| 金额 | 报销明细合计 |
| 冲抵借款 | 关联的借款单号及实际冲抵金额 |
| 状态 | 草稿 / 审批中 / 待付款 / 已付款 |
| 付款 | 付款日期和付款凭证号（点击查看凭证） |
| 事由 | |
| 操作 | 草稿：编辑、提交、删除；待付款：付款 |

工具栏支持导出。

## 新增报销

![新增报销](/images/manual/fin/claim-add.jpg)

### 表头字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 报销人 | 否 | 不选为本人 |
| 费用部门 | 否 | 不选取报销人所在部门；费用和预算按此部门归集 |
| 报销日期 | 是 | 默认今天；预算控制按其所在年度 |
| 冲抵借款 | 否 | 下拉列出报销人**未还清**的借款（单号、日期、未还金额）；更换报销人时自动清除 |
| 事由 | 否 | 如「10 月上海出差」 |

### 报销明细

| 字段 | 说明 |
| --- | --- |
| 费用日期 | 默认今天，新增行沿用上一行的日期 |
| 费用科目 | 制造费用（5101）、销售费用（6601）、管理费用（6602）、财务费用（6603）下的末级科目；须为损益类或成本类末级科目 |
| 项目 | 选填，费用归集到[项目成本](../pm/cost) |
| 金额 | 大于 0 |
| 说明 | 如「高铁票」 |

点「**添加一行**」增加明细，至少保留一行。顶部显示合计金额。保存后为「草稿」，提示「保存成功，请提交」。

## 提交与审批

在草稿行点击「**提交**」：

1. **预算控制**：按报销日期所在年度、费用部门、费用科目检查[预算](./budget)。若该预算设置了控制方式，且「已执行 + 在途（审批中、待付款的报销）+ 本次」超过全年预算：
   - 超预算提示：仍可提交，弹窗列出超支说明；
   - 超预算禁止：不能提交，提示超出金额。
2. **审批**：发布了「费用报销审批」[流程](../workflow/business#财务)（内置：部门主管 → 会计 → 金额 ≥ 5000 元时总经理 → 抄送出纳）时进入「审批中」，审批通过后变为「待付款」，拒绝或撤回后退回「草稿」；未发布流程时直接变为「待付款」。

## 付款

1. 在待付款的行点击「**付款**」。
2. 选择**付款账户**（库存现金或银行存款）和**付款日期**（所在期间须未结账）。
3. 确认后生成凭证，状态变为「已付款」。

关联了借款时，先冲抵借款的未还金额，差额再付款：

- 借款未还金额足以冲抵全部报销额时，付款账户可以不选；
- 凭证：借 各明细的费用科目（费用部门、项目）/ 贷 其他应收款（冲抵部分）、付款账户（差额部分）；
- 冲抵部分记入借款的还款记录（方式为「报销冲抵」），借款还清后变为「已还清」。

未关联借款时，凭证为：借 费用科目 / 贷 付款账户。

## 状态与操作

| 状态 | 可做操作 |
| --- | --- |
| 草稿 | 编辑、提交、删除 |
| 审批中 | 在[流程中心](../workflow/)审批或撤回 |
| 待付款 | 付款 |
| 已付款 | 查看 |

## 详情

显示报销人、费用部门、报销日期、状态、金额、冲抵借款（冲抵金额）、付款日期和凭证、事由，以及报销明细（费用日期、费用科目、金额、说明）。

## 注意事项

::: tip 提示
- 报销付款生成的凭证不能在凭证管理中直接删除。
- 预算执行数只统计已记账的凭证，在途金额则包括审批中、待付款的报销单。
:::
