# 往来对账单

按客户或供应商查询一段时间内的往来明细：应收（应付）单增加余额，收款（付款）和预收（预付）款减少余额，逐笔计算余额，可以打印后发给对方签字盖章核对。会计、出纳使用。

需要一次看所有往来单位当前欠款时，用应收应付的[往来汇总](./ar-ap#往来汇总)，点汇总行上的「对账单」可直接跳转到本页并查询该单位。

与[供应商对账](./statement)的区别：供应商对账是按期间生成对账单、在供应商门户中在线确认的流程单据；往来对账单是随时查询的账表，客户、供应商都可以用，打印纸质或 PDF 对账单与对方核对。

## 页面入口

财务 → 应收应付 → 往来对账单

![往来对账单](/images/manual/fin/partner-statement.jpg)

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 客户（应收）/ 供应商（应付） | 切换对账对象的类型，切换后清空已选的往来单位和查询结果 |
| 客户 / 供应商 | 必选，可按编码或名称搜索 |
| 日期范围 | 默认本年 1 月 1 日至今天 |
| 挂接应付 | 只有查询客户、且有「应付管理」查看权限时显示：把该客户关联供应商的应付一起列入，见下文[挂接应付](#挂接应付) |

选择往来单位或修改日期范围后自动查询，也可以点「**查询**」刷新。查询条件下方提示余额的增减规则。

## 查询结果

顶部四个指标：**期初余额**、**本期应收（应付）**、**本期收款 / 预收款**（付款 / 预付款）、**期末余额**。

表格列：

| 列 | 说明 |
| --- | --- |
| 日期 | 单据日期、收付款日期或预收预付日期 |
| 类型 | 期初余额、应收单（应付单）、收款（付款）、预收款（预付款）、应收应付对冲；挂接应付时另有应付单（关联）、付款（关联）、预付款（关联）、对冲（关联应付） |
| 单号 | 应收应付单号、收付款单号、预收预付单号 |
| 来源 / 结算方式 | 应收应付单显示来源（如销售出库、采购入库、销售返利）和来源单号；收付款、预收预付显示结算方式（如银行转账、票据） |
| 应收金额（应付金额） | 应收应付单的金额，增加余额；红字单据为负数，以红色显示 |
| 收款金额（付款金额） | 收付款、预收预付的金额，减少余额；收付款时有折让的，金额为 实收（实付）+ 折让 |
| 余额 | 逐笔滚动计算的余额，负数以红色显示 |
| 备注 | 单据备注 |

第一行为「期初余额」（开始日期之前的累计余额），底部固定显示「本期合计」。同一天的记录按应收应付单、收付款、预收预付的顺序排列。

### 计算口径

- **增加**：日期范围内该往来单位的全部[应收单 / 应付单](./ar-ap)，包括出入库自动生成、手工录入（含期初往来）和红字单据。
- **增加**中的红字单据包括退货、[冲账单](./offset)等，以负数冲减余额。
- **减少**：已生效的[收款单 / 付款单](./settlement)（草稿、审批中、已拒绝的不计入，金额为实收实付加核销时的[折让 / 抹零](./settlement#折让与抹零)），以及[预收预付](./advance)登记的款项（含收付款多收、多付转入的预收预付）。
- 预收、预付款在**收付当天**即冲减余额；之后用预收预付冲抵应收应付单时（无论在预收预付页面冲抵，还是在收付款单中[一起冲抵](./settlement#冲抵预收预付)）不再重复计入，收付款单只按实收实付的部分减少余额。
- **减少**中还包括[应收应付对冲](./ar-ap#应收应付对冲)：应收、应付对账单上各有一行「应收应付对冲」，金额为本次对冲冲减的金额。
- **坏账核销（含应付的无法支付转销）不在对账单中体现**。
- 期初余额 = 开始日期之前的应收应付单合计 − 收付款合计（含折让）− 预收预付合计。

### 与往来汇总的关系

[往来汇总](./ar-ap#往来汇总)显示各单位当前的净欠款，与本页口径一致，区别是往来汇总把坏账核销从余额中扣除：

**本页截至今天的期末余额 = 往来汇总的净欠款 + 坏账核销（无法支付转销）**

外币单据的收付款按收付款汇率、单据按记账汇率折算，两者之间可能还有汇率差额。从往来汇总跳转过来时，日期范围仍为默认的本年 1 月 1 日至今天，期末余额即截至今天的余额。

## 挂接应付

客户在[供应商资料](../scm/supplier#关联客户)中被设置为关联客户时（同一单位既是客户又是供应商），查询该客户的对账单可以勾选「**挂接应付**」，把欠对方的应付也列入，按净额与对方核对：

- 结果上方提示「已挂接关联供应商 … 的应付，余额为应收 − 应付」；
- 期初余额、期末余额、逐笔余额都按 **应收 − 应付** 计算；
- 关联供应商的应付单计入**减少**（显示为「应付单（关联）」，红字应付单为负数），付款、预付款计入**增加**（显示为「付款（关联）」「预付款（关联）」），方向与应收相反；
- 做过[应收应付对冲](./ar-ap#应收应付对冲)时，应收一侧的「应收应付对冲」与应付一侧的「对冲（关联应付）」两行正好抵消，余额不变；
- 打印的对账单表头带上关联供应商。

从[往来汇总](./ar-ap#往来汇总)勾选了「挂接应付」后点「对账单」跳转过来时，本页保持勾选。需要「应付管理」的查看权限，没有时不显示这个选项。

## 打印

查询出结果后点击「**打印**」，生成「客户对账单」或「供应商对账单」PDF：

- 表头：客户（供应商）、对账期间、期初余额、期末余额；挂接应付时另有关联供应商；
- 明细：日期、类型、单号、来源 / 结算方式、增加金额、减少金额、余额、备注，末行为本期合计；
- 底部说明「请贵方核对以上往来明细，如无误请签字盖章后回传；如有差异请注明」；
- 签字栏：制表、财务审核、客户确认（盖章）或供应商确认（盖章）。

打印版式可在「系统管理 → [打印模板](../system/print-template)」中调整（模板名称「往来对账单」）。

## 权限

- 需要「往来对账单」菜单权限；查询客户时还需要「应收管理」的查看权限，查询供应商时需要「应付管理」的查看权限，否则提示「没有权限查看应收 / 应付」。
- 内置的会计、出纳、总经理、普通用户角色可以访问。

## 注意事项

::: tip 提示
- 对账单余额与应收应付单的「未核销金额」口径不同：对账单按收付款发生的日期减少余额，不区分核销到哪张单据。
- 对账单余额与总账应收账款 / 应付账款科目余额不一致时，常见原因是有应收应付单或收付款还没有生成凭证、凭证未记账，或者做过坏账核销。
:::
