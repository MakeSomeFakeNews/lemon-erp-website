# 冲账单

冲账单用来登记**不付现金、用来抵扣往来款**的项目，例如替客户垫付的运费、给客户的销售返利、三包赔偿，或者供应商给的返利、赔偿。冲账单复核后生成一张红字应收单（应付单）和凭证，之后在收款单、付款单中勾选这张红字单据，就能与客户、供应商的欠款相抵。会计使用，出纳、总经理可以查看。

与收付款时的[折让 / 抹零](./settlement#折让与抹零)的区别：折让是收付款当时临时给的优惠，随收付款单一起入账；冲账单是事先单独登记、需要复核的抵扣项目，有项目、期间、票据编号等信息，可以先登记、以后收付款时再抵扣。

## 页面入口

财务 → 应收应付 → 冲账单

![冲账单列表](/images/manual/fin/offset-list.jpg)

## 新增冲账单

点击「**新增冲账单**」，在右侧抽屉中填写：

![新增冲账单](/images/manual/fin/offset-add.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 方向 | 是 | **应收冲账**：抵扣客户的欠款（如垫付运费、销售返利、三包赔偿）；**应付冲账**：抵扣欠供应商的款（如供应商返利、赔偿）。切换方向时清空往来单位 |
| 冲账日期 | 是 | 默认今天；复核时该日期所在期间必须未结账 |
| 经办人 | 否 | 新增时不填保存为制单人；修改时不填保留原经办人（原来也没有时为当前修改人） |
| 客户 / 供应商 | 是 | 随方向切换 |
| 冲账项目 | 是 | 业务字典「冲账项目」，预置垫付运费、销售返利、三包赔偿、其他，可在[业务字典](../system/biz-dict)中增加 |
| 冲账金额 | 是 | 大于 0，人民币 |
| 项目期间 | 否 | 开始、结束日期，如本次登记的是 1 月 1 日至 3 月 31 日的应冲账合计；结束日期不能早于开始日期 |
| 票据编号 | 否 | 运单号、返利协议号、赔偿单号等，最多 64 个字符 |
| 凭证科目 | 否 | 复核生成凭证时的对方科目，只能选末级科目。不填时取[凭证科目设置](./account-rule#折让与冲账科目)：应收冲账默认销售费用，应付冲账默认主营业务成本（冲减成本）。选择框下方提示对应的凭证分录 |
| 备注 | 否 | 会写入红字单据的备注 |

点击「**保存**」，冲账单为「待复核」。待复核的冲账单可以修改、删除；已复核的不能修改，需要先取消复核。

## 复核与凭证

1. 在待复核的冲账单行点击「**复核**」。
2. 确认框说明复核的结果：应收冲账「复核后生成红字应收单和凭证（未审核），收款时可与客户欠款相抵。」，应付冲账「复核后生成红字应付单和凭证（未审核），付款时可与欠供应商的款相抵。」
3. 确认后提示「已复核，红字单据和凭证已生成」，列表显示红字单据号和凭证号。

复核时系统：

- 生成一张红字应收单（应付单），来源为「冲账单」，金额为冲账金额的负数，单据日期和到期日都是冲账日期，备注为「冲账单 单号：项目 备注」，在[应收管理 / 应付管理](./ar-ap)中可以看到；
- 同时为红字单据生成一张未审核的凭证，在[凭证管理](./voucher)中审核、记账：

| 方向 | 凭证分录 |
| --- | --- |
| 应收冲账 | 借 冲账单上的凭证科目（默认销售费用）/ 贷 应收账款（客户辅助核算） |
| 应付冲账 | 借 应付账款（供应商辅助核算）/ 贷 冲账单上的凭证科目（默认主营业务成本） |

凭证摘要为「冲账 单号 往来单位」。冲账单只调整往来款，不影响库存。

### 复核人

默认制单人可以复核自己录入的冲账单，方便一个人操作的小公司。需要分开时，在「系统管理 → [业务参数](../system/biz-rule)」中开启「**冲账单复核人不能是制单人**」，开启后制单人复核自己的冲账单会提示「冲账单 单号 由你制单，复核人不能是制单人」。

## 收付款时抵扣

冲账单复核后，在[收款单 / 付款单](./settlement)中选择该客户（供应商），生成的红字单据会出现在未核销单据中（金额为负数），默认勾选：

- 点「自动核销」时，红字单据先冲抵勾选的欠款（冲抵总额不超过欠款合计），剩余金额再分配到其他欠款；
- 冲账金额小于欠款时，本次实收（实付）= 欠款 − 冲账金额；
- 冲账金额等于勾选的欠款时，本次收付款金额可以为 0，直接保存即可完成抵扣；
- 冲账金额大于欠款时，只冲抵欠款部分：「自动核销」「全部核销」按单据日期从早到晚冲抵红字单据，冲抵总额等于勾选的欠款合计，核销合计为 0，直接确认即可，不需要手工修改金额；冲不完的红字单据（或其剩余部分）留待以后再抵扣。

抵扣后冲账单列表的状态下方显示「已抵扣 ¥…」或「已全部抵扣」。

## 取消复核

已复核的冲账单发现有误时，点击「**取消复核**」：删除生成的红字单据和未审核的凭证，冲账单回到「待复核」，可以修改或删除。

不能取消的情况：

- 红字单据已参与收付款核销（需要先删除相关的收付款单）；
- 凭证已审核：先在凭证管理中反审核；
- 凭证已记账：不能取消复核，可红字冲销凭证后另行登记冲账单。

## 查看

点击单号打开「冲账单 单号」窗口，显示方向、状态、往来单位、冲账日期、冲账项目、冲账金额、项目期间、票据编号、经办人、凭证科目（未选择时显示「凭证科目设置」）、制单人和时间、复核人和时间、红字单据及抵扣情况、凭证号、备注。

## 权限

| 权限 | 说明 |
| --- | --- |
| 冲账单（查看） | 打开页面。内置的普通用户、总经理、出纳、会计角色有此权限 |
| 冲账单新增 / 修改 / 删除 | 新增、修改、删除待复核的冲账单。内置的会计角色有此权限 |
| 冲账单复核 | 复核、取消复核。内置的会计角色有此权限 |

## 注意事项

::: tip 提示
- 销售返利也可以在[销售返利](../scm/rebate)中按协议结算生成红字应收单；冲账单适合没有返利协议、需要手工登记的返利和其他抵扣项目。
- 冲账单只调整应收应付，不改变出入库单金额，因此不计入销售、进货报表。
- 复核前生成凭证需要的科目（凭证科目设置或冲账单上选择的科目）必须是启用的末级科目。
:::

::: warning 注意
冲账单复核时同时生成红字单据和凭证，冲账日期所在期间已结账时不能复核；取消复核时也要求凭证所在期间未结账。
:::
