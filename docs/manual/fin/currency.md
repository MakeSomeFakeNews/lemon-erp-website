# 币种汇率

维护外币币种和每月汇率，并在月末对外币应收应付执行期末调汇。有外贸业务的企业使用。

## 页面入口

财务 → 期末与设置 → 币种汇率

页面有三个页签：**币种**、**汇率**、**期末调汇**。

![币种](/images/manual/fin/currency.jpg)

## 多币种业务说明

- 本位币为人民币（CNY）。[销售订单](../scm/sales)、[采购订单](../scm/purchase)可以选择外币，按业务日期所在月份的汇率自动带出（可在单据上修改）。
- 外币订单出入库后生成的应收应付单同时记录原币金额、记账汇率和折算后的人民币金额。
- 收付款核销外币单据时按原币核销，汇率差额计入财务费用（汇兑损益），详见[收款单与付款单](./settlement)。
- 预收预付冲抵、票据、坏账核销只支持人民币单据。

## 汇率

![汇率](/images/manual/fin/currency-rate.jpg)

汇率为 **1 外币折合多少人民币**，按月维护。

1. 选择**期间**，表格列出所有启用的外币。
2. 在「汇率（1 外币 = ? 人民币）」中填写汇率（6 位小数，必须大于 0），右侧显示换算提示。
3. 点击「**保存本月汇率**」，只保存有修改的币种；同币种同月重复保存会覆盖。

下方「历史汇率」可按币种查看各期间的汇率。本位币不需要维护汇率。

## 期末调汇

月末把外币应收应付**未核销的原币**按期末汇率重新折算：

1. 先在「汇率」中维护该月的汇率，否则提示「请先维护 xx 在 xx 的汇率」。
2. 选择**调汇期间**（须未结账），点击「**执行期末调汇**」。
3. 结果显示汇兑损益合计和明细：币种、类型（应收 / 应付）、期末汇率、未核销原币、账面本位币、重估本位币、汇兑损益。
4. 系统生成两张未审核凭证：调汇凭证（期末，差额计入财务费用 - 汇兑损益，往来科目为应收账款 / 应付账款）和冲回凭证（下月 1 日自动冲回）。没有差额时不生成凭证。

每个期间只能调汇一次；如需重新调汇，先删除调汇凭证。
