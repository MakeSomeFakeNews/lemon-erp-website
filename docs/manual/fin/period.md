# 期末结账

月末完成结账检查、增值税结转和结账。结账时自动生成并记账「结转损益」凭证，结账后本期不能再录入、修改凭证和业务单据。会计、财务主管使用。完整的月末操作顺序见[月末结账操作指引](./month-end)。

## 页面入口

财务 → 期末与设置 → 期末结账

![期末结账](/images/manual/fin/period-list.jpg)

## 页面说明

顶部工具栏：

| 控件 | 说明 |
| --- | --- |
| 结账期间 | 默认当前月份 |
| **结账检查** | 检查所选期间能否结账，结果显示在工具栏下方，可「收起」 |
| **增值税结转** | 结转本期增值税并计提附加税费（需要「增值税结转」权限） |
| **结账** | 对所选期间结账（需要「结账」权限） |

会计期间列表：

| 列 | 说明 |
| --- | --- |
| 会计期间 | 如「2026 年 10 月」；期间在首次录入凭证时自动创建 |
| 状态 | 未结账 / 已结账 |
| 凭证 | 凭证张数，有未记账凭证时显示「（N 张未记账）」 |
| 结账 | 结账人和结账时间 |
| 操作 | 未结账：结账；已结账：反结账 |

## 结账检查

![结账检查](/images/manual/fin/period-check.jpg)

检查结果分为三级：绿色通过、橙色**提示**（建议处理，可以确认后继续结账）、红色**错误**（必须处理，否则不能结账）。

| 检查项 | 级别 | 不通过时的说明 |
| --- | --- | --- |
| 之前的期间已结账 | 错误 | xx 期间还未结账 |
| 凭证全部记账 | 错误 | N 张凭证未审核或未记账 |
| 试算平衡 | 错误 | 期初、本期发生或期末余额借贷不平衡 |
| 应收应付单已生成凭证 | 提示 | 本月业务生成的应收应付单有 N 张未生成凭证 |
| 收付款单已生成凭证 | 提示 | 本月已生效的收付款单有 N 张未生成凭证 |
| 成本核算 | 提示 | 本期还没有做成本核算 / 成本结转凭证未生成 |
| 计提折旧 | 提示 | 有应计提的固定资产但本期还没有计提折旧 |
| 增值税结转 | 提示 | 有销项税额但还未结转，未计提附加税费 |
| 银行对账 | 提示 | 本月有 N 笔银行流水未勾对 |

## 增值税结转

1. 选择结账期间，点击「**增值税结转**」。
2. 确认或修改税率：城建税 7%、教育费附加 3%、地方教育附加 2%（0 ~ 100 之间）。
3. 点击「结转」，系统生成结转凭证（未审核）：
   - 销项税额与进项税额相抵，差额转入应交税费 - 未交增值税；进项大于销项时留抵，不计提；
   - 按未交增值税计提城建税、教育费附加、地方教育附加：借 税金及附加 / 贷 对应的应交税费明细科目。
4. 结果页显示销项税额、进项税额、应交增值税、附加税费，可「查看凭证」。

每个期间只能结转一次；如需重新结转，先删除结转凭证。截至本期没有销项税额时不能结转（会提示进项税额留抵下期）。

## 结账

1. 在工具栏点「**结账**」或在期间行点「结账」，系统先执行结账检查并显示结果。
2. 存在错误项时「结账」按钮不可用，提示「存在错误项，请处理后再结账」。
3. 只有提示项时，勾选「我已了解以上 N 项提示，仍然结账」后才能结账。
4. 确认后完成结账：
   - 把本期损益类末级科目的发生额结转到**本年利润**，生成并**直接记账**一张「结转损益」凭证（收入科目借记、费用科目贷记，差额记本年利润）；本期没有损益发生额时不生成；
   - **12 月结账**时，再把本年利润的累计余额转入**利润分配 - 未分配利润**；
   - 期间状态变为「已结账」，记录结账人和时间。

结账条件（系统强制）：之前的期间必须全部已结账；本期凭证必须全部记账。

## 反结账

在已结账期间行点击「**反结账**」并确认：

- 只能从**最后一个已结账的期间**开始反结账，之后还有已结账期间时提示「请先反结账之后的期间」；
- 反结账时**删除本期的结转损益凭证**，期间恢复为未结账。

## 结账后的限制

- 不能在该期间新增、修改、删除、审核、记账凭证，也不能冲销到该期间。
- 业务单据受期间锁约束：业务日期在已结账期间的出入库、[盘点](../wms/check)、[报工](../mes/wo#报工)不能再确认，收付款、应收应付、预收预付、报销付款等不能再新增、删除。
