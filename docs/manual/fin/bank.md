# 银行对账

导入银行对账单流水，与账面银行存款科目的凭证分录逐笔勾对，并编制银行存款余额调节表。出纳使用。

## 页面入口

财务 → 资金与费用 → 银行对账

![银行对账](/images/manual/fin/bank.jpg)

## 页面布局

顶部工具栏：

| 控件 | 说明 |
| --- | --- |
| 选择银行账户 | 银行存款（1002）下的末级科目，选择后自动查询 |
| 日期范围 | 默认本月 1 日至今天 |
| 查询 | 重新加载 |
| 只看未勾对 | 两边表格只显示未勾对的记录 |
| **导入对账单** | 导入银行流水（需要「导入与勾对」权限） |
| **自动勾对** | 按规则自动匹配 |
| **手工勾对** | 两边各选一条后勾对 |
| **余额调节表** | 打开余额调节表 |

下方左右两栏：

- **银行流水**：交易日期、金额（收入为正、支出为负）、摘要 / 流水号、勾对状态。已勾对的显示对应的凭证号和日期，可「取消勾对」。可勾选多条后删除。标题旁显示条数、未勾对条数和净额。
- **企业账面分录**：所选银行科目在日期范围内的凭证分录，凭证（点击查看）、金额（借方为正、贷方为负）、摘要、勾对状态。

## 导入对账单

1. 选择银行账户，点击「**导入对账单**」，可下载模板。
2. 模板列：交易日期（必填）、收入、支出、金额、摘要、流水号。可以只填「金额」一列（收入为正、支出为负）代替收入、支出两列。
3. 每行都需要交易日期和非 0 金额，否则提示错误、不导入。
4. **流水号已导入过的行自动跳过**，导入后提示跳过的条数。

## 勾对

- **自动勾对**：对未勾对的流水，查找金额相同、日期相差不超过 5 天的凭证分录，取日期最近的一条一一勾对，完成后提示勾对的笔数。
- **手工勾对**：在左边勾选一条未勾对的流水，在右边选中一条未勾对的分录，点击「**手工勾对**」。两者金额必须一致。
- **取消勾对**：在已勾对的流水上点「取消勾对」。

## 余额调节表

点击「**余额调节表**」：

1. 选择**截止日期**（默认为查询范围的结束日期）。
2. 填写**银行对账单余额**；不填时按已导入流水的累计数计算。
3. 点击「计算」。

调节表左右两栏：

| 企业账面 | 银行对账单 |
| --- | --- |
| 银行存款日记账余额 | 银行对账单余额 |
| 加：银行已收、企业未收 | 加：企业已收、银行未收 |
| 减：银行已付、企业未付 | 减：企业已付、银行未付 |
| 调节后余额 | 调节后余额 |

两边调节后余额相等时显示绿色「调节后余额相等」，否则提示检查未勾对的记录。下方分别列出「银行已记、企业未记」和「企业已记、银行未记」的明细。

## 与月末结账的关系

结账检查会提示本期还有多少笔银行流水未勾对（提示项，不影响结账）。
