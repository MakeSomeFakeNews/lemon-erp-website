# 财务报表

根据已记账凭证自动生成资产负债表、利润表和现金流量表，格式参照《小企业会计准则》（会小企01表、会小企02表、会小企03表），每个项目带行次。报表上方列出常用财务指标，利润表下方有本年利润趋势图；点击报表中的金额可以逐级追溯到构成科目、明细账和凭证。报表可以打印和导出 Excel。财务主管、会计、管理层查看。

## 页面入口

财务 → 总账 → 财务报表

![资产负债表](/images/manual/fin/report-balance.jpg)

## 页面布局

顶部工具栏从左到右：

| 控件 | 说明 |
| --- | --- |
| 「资产负债表」「利润表」「现金流量表」 | 切换报表，默认打开资产负债表 |
| 期间 | 资产负债表、利润表选择一个月份，默认当前月份；现金流量表选择开始期间和截止期间，默认本年 1 月至当前月份，开始期间晚于截止期间时自动调整为与截止期间相同。修改后立即重新计算 |
| 「隐藏金额为零的项目」 | 资产负债表、利润表可勾选：各列金额都为零的普通项目不显示（分组标题、合计行始终显示） |
| 「打印」 | 生成 PDF 打印预览，见[打印与导出](#打印与导出) |
| 「导出」 | 导出当前报表为 Excel |

工具栏下方依次是：

1. **财务指标卡片**（资产负债表、利润表）：鼠标悬停在卡片上显示计算公式，见[财务指标](#财务指标)；
2. **报表正文**：居中的报表名称；表头一行左侧为「编制单位」（公司名称），中间为期间（资产负债表为「2026 年 10 月末」，利润表为「2026 年 10 月」，现金流量表为「2026 年 1 月 至 2026 年 10 月」），右侧为表号和「单位：元」；
3. **表尾签字栏**：「单位负责人」「会计主管」「制表」（制表为当前登录用户）；
4. **说明**：报表的取数口径提示，例如「只统计已记账凭证；未分配利润含尚未结转的本年损益，生产成本等成本类科目余额计入存货。点击金额可查看构成科目和明细账」；
5. **利润趋势图**（仅利润表）。

报表中，普通项目金额为零时留空，合计行显示 0.00；负数以红色显示。报表较长时只有报表区域滚动，表头固定在顶部。

::: tip 提示
所有报表**只统计已记账的凭证**。凭证审核后还需要在[凭证管理](./voucher)中记账，才会进入报表。报表实时计算，记账后重新选择期间或刷新页面即可看到变化。
:::

## 取数规则

资产负债表和利润表的每个项目按**会计科目编码前缀**取数：

- 取编码以所列前缀开头的**末级科目**，借方项目取「借方 − 贷方」，贷方项目取「贷方 − 借方」；
- 每个科目只计入第一个匹配的项目，不会重复计算；
- 「其中」项（如存货下的原材料、在产品）只用于展示，不参与合计；
- 合计行按行次相加减，例如「流动资产合计」为「行 1 + 2 + … + 9 + 14」；
- 没有被任何项目匹配到的科目，按科目类别计入兜底项目（其他流动资产、其他流动负债、存货、未分配利润、营业外收入 / 支出），以保证报表平衡。

所以新增明细科目时，只要挂在正确的上级科目之下（见[会计科目](./account)），就会自动进入对应的报表项目。每一行的取数说明可以点击金额查看，见[追溯到科目、明细账和凭证](#追溯到科目、明细账和凭证)。

## 利润表

表号「会小企02表」。列为「行次」「本月金额」「本年累计金额」「上年同期累计」：

- **本月金额**：所选月份的发生额；
- **本年累计金额**：本年 1 月至所选月份；
- **上年同期累计**：上年 1 月至上年同一月份。

## 现金流量表

表号「会小企03表」。选择开始期间和截止期间，只有「行次」「金额」两列。

![现金流量表](/images/manual/fin/report-cash.jpg)

采用**直接法**：取已记账凭证中库存现金（默认 1001）、银行存款（默认 1002）及其下级科目的发生额（范围按[凭证科目设置](./account-rule#货币资金科目范围)的「货币资金」识别），按凭证中的**对方科目**归类到现金流量项目。一张凭证有多个对方科目时，按对方科目金额比例分摊；只有现金、银行科目之间的划转（如提现、账户调拨）不计入。

| 分类 | 项目 | 对方科目规则 |
| --- | --- | --- |
| 经营活动 | 销售商品、提供劳务收到的现金 | 流入，对方为应收账款、预收账款、主营 / 其他业务收入、销项税额 |
| | 收到其他与经营活动有关的现金 | 其余流入（含财务费用流入） |
| | 购买商品、接受劳务支付的现金 | 流出，对方为应付账款、预付账款、存货类（14 开头）、生产成本、制造费用、进项税额 |
| | 支付给职工以及为职工支付的现金 | 应付职工薪酬 |
| | 支付的各项税费 | 应交税费、税金及附加、所得税费用 |
| | 支付其他与经营活动有关的现金 | 其余流出 |
| 投资活动 | 处置固定资产、无形资产和其他长期资产收回的现金净额 | 流入，对方为固定资产、在建工程、固定资产清理 |
| | 购建固定资产、无形资产和其他长期资产支付的现金 | 流出，对方同上 |
| 筹资活动 | 吸收投资收到的现金 | 实收资本流入 |
| | 取得借款收到的现金 / 偿还债务支付的现金 | 短期借款 |
| | 分配股利、利润或偿付利息支付的现金 | 实收资本流出、利润分配、财务费用流出 |

每类活动之后列出现金流入小计、现金流出小计和现金流量净额，最后为「四、现金及现金等价物净增加额」「加：期初现金及现金等价物余额」「五、期末现金及现金等价物余额」。除分类标题外，各行按顺序编行次（共 24 行）。

计算出的期末余额与账面库存现金、银行存款余额不一致时，报表上方显示黄色提示「期末余额与账面不一致（账面现金及银行存款余额 ¥…），可能有未记账的现金凭证」。

现金流量表没有财务指标，金额也不能点击追溯；需要查看现金收支明细时使用[出纳管理](./cashier)的日记账。

## 财务指标

资产负债表和利润表的报表上方显示指标卡片：大字为当期值，下方小字为对比值（资产负债表为「年初」，利润表为「本年累计」）。鼠标悬停在卡片上显示计算公式。分母为零时显示「-」。

| 报表 | 指标 | 计算方式 | 含义 |
| --- | --- | --- | --- |
| 资产负债表 | 资产负债率 | 负债合计 ÷ 资产总计 × 100% | 总资产中有多少来自负债，衡量长期偿债风险，越高负债压力越大 |
| | 流动比率 | 流动资产合计 ÷ 流动负债合计（倍） | 每 1 元短期负债有多少流动资产可以偿还，衡量短期偿债能力 |
| | 速动比率 | （流动资产合计 − 存货）÷ 流动负债合计（倍） | 扣除变现较慢的存货后的短期偿债能力，比流动比率更严格 |
| 利润表 | 毛利率 | （营业收入 − 营业成本）÷ 营业收入 × 100% | 产品或服务本身的盈利空间 |
| | 营业利润率 | 营业利润 ÷ 营业收入 × 100% | 扣除成本、税金和三项费用后的经营盈利能力 |
| | 净利率 | 净利润 ÷ 营业收入 × 100% | 每 1 元收入最终带来的净利润 |
| | 期间费用率 | （销售费用 + 管理费用 + 财务费用）÷ 营业收入 × 100% | 期间费用占收入的比重，衡量费用控制水平 |

指标保留两位小数。资产负债表的指标分别按期末余额、年初余额计算；利润表的指标分别按本月金额、本年累计金额计算。

## 利润趋势

所选月份为 2 月及以后时，利润表下方显示「XXXX 年利润趋势」图：横轴为本年 1 月至所选月份，柱形为「营业收入」「营业成本」，折线为「营业利润」「净利润」，鼠标悬停显示各月金额。口径与利润表相同：只统计已记账凭证，不含结转损益凭证。

## 追溯到科目、明细账和凭证

资产负债表、利润表中有取数规则的金额（项目行、其中项和合计行）都可以点击，鼠标移上去时金额变为带下划线的主题色。点击后右侧打开以项目名称为标题的抽屉：

![追溯到科目和明细账](/images/manual/fin/report-drill.jpg)

1. **取数说明**：显示「行次」「取数」和该行各列的金额。取数为科目规则（如「科目 1001、1002、1012 的借方余额」，兜底项目会注明「以及未列示的其他资产类科目」）或行次公式（如「行 15 + 28」）；
2. **构成科目**：列出该项目包含的、有余额或发生额的末级科目，以及各科目在各列的金额（按报表行的方向取数）。没有科目时显示「没有余额或发生额的科目」。合计行没有构成科目，只显示行次公式，可以关闭后再点击被合计的各行；
3. **明细账**：点击构成科目的编码，下方显示该科目的明细账（期间为本年 1 月至报表所选月份），包括「期初余额」行、逐笔分录（日期、凭证号、摘要、借方、贷方、方向、余额）和「本期合计」行，当前选中的科目整行高亮；
4. **凭证**：点击明细账中的凭证号，打开该凭证的详情，可以查看分录、附件，也可以打印。

关闭抽屉即回到报表，报表的期间和滚动位置不变。

::: tip 提示
利润表「上年同期累计」列的构成科目金额可以在抽屉中看到，但明细账只查询本年 1 月至所选月份。需要查看上年明细时，到[账簿查询](./book)中选择相应期间。
:::

## 打印与导出

- **打印**：按当前显示的报表生成 PDF，默认 A4 纵向，版式与页面一致：报表名称、编制单位、期间、单位与表号，表格各列，以及签字栏「单位负责人」「会计主管」「制表」。勾选了「隐藏金额为零的项目」时，打印结果同样不含这些项目。三张报表在[打印模板](../system/print-template)的「财务」分组下各有一个模板（「资产负债表」「利润表」「现金流量表」），可以调整纸张、字号、列宽、签字栏名称等；
- **导出**：导出为 Excel 文件，文件名为「报表名称_期间」，例如「资产负债表_2026 年 10 月末」。列与页面一致（项目名称按层级缩进），金额导出为数字，可直接在 Excel 中计算。

## 注意事项

::: tip 提示
- 报表数据实时计算，凭证记账后即可看到变化，不需要结账。
- 报表项目按科目编码取数，新增科目请按[会计科目](./account)的编码规则挂在正确的上级之下，否则会进入「其他流动资产」「其他流动负债」「未分配利润」「营业外收入 / 支出」等兜底项目。
- 资产负债表不平衡通常是因为科目期初余额借贷不平衡或科目类别设置错误，可在[账簿查询](./book)的科目余额表中检查试算平衡。
:::

::: warning 注意
资产负债表的货币资金包含其他货币资金（1012），而现金流量表只统计库存现金和银行存款（1001、1002）。使用了其他货币资金科目时，现金流量表的期末余额与资产负债表的货币资金会有差异。
:::
