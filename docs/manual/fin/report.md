# 财务报表

根据已记账凭证自动生成资产负债表、利润表和现金流量表，无需手工编制。财务主管、管理层查看。

## 页面入口

财务 → 总账 → 财务报表

页面顶部用按钮切换三张报表，右侧选择期间；报表标题下方注明期间和「单位：元」。所有报表**只统计已记账的凭证**。

## 资产负债表

![资产负债表](/images/manual/fin/report-balance.jpg)

- **期间**：选择月份，报表为该月末的余额。
- **列**：期末余额、年初余额（上年末余额）。
- 报表按以下项目归集末级科目余额：

| 分类 | 项目 | 取数科目 |
| --- | --- | --- |
| 资产 | 货币资金 | 库存现金 1001、银行存款 1002 |
| | 应收账款 / 预付账款 / 其他应收款 | 1122 / 1123 / 1221 |
| | 存货 | 原材料 1403、库存商品 1405，以及全部成本类科目（5 开头，如生产成本） |
| | 固定资产（净值） | 固定资产 1601 减累计折旧 1602 |
| | 固定资产清理 | 1606 |
| | 其他资产 | 其余资产类科目 |
| 负债 | 短期借款、应付账款、预收账款、应付职工薪酬、应交税费、其他应付款 | 2001、2202、2203、2211、2221、2241 |
| | 其他负债 | 其余负债类科目 |
| 所有者权益 | 实收资本 | 4001 |
| | 未分配利润 | 本年利润 4103、利润分配 4104，以及全部损益类科目（6 开头） |
| | 其他权益 | 其余权益类科目 |

- **未分配利润包含尚未结转的本年损益**，因此在月末结账之前查看报表也是平衡的。
- 标题下方显示校验结果：平衡时显示绿色「资产 = 负债 + 所有者权益」，不平衡时显示红色「报表不平衡，请检查科目设置」。

## 利润表

![利润表](/images/manual/fin/report-income.jpg)

- **期间**：选择月份。
- **列**：本期金额（当月）、本年累计（1 月至所选月份）。
- **不含期末结转损益凭证**，因此结账前后查看结果一致。

| 项目 | 取数 |
| --- | --- |
| 一、营业收入 | 主营业务收入 6001、其他业务收入 6051 |
| 减：营业成本 | 主营业务成本 6401、其他业务成本 6402 |
| 税金及附加 | 6403 |
| 销售费用 / 管理费用 / 财务费用 | 6601 / 6602 / 6603 |
| 二、营业利润 | 营业收入 − 营业成本 − 税金及附加 − 三项费用 |
| 加：营业外收入 | 6301，另加其余未列出的贷方损益科目 |
| 减：营业外支出 | 6711，另加其余未列出的借方损益科目 |
| 三、利润总额 | 营业利润 + 营业外收入 − 营业外支出 |
| 减：所得税费用 | 6801 |
| 四、净利润 | 利润总额 − 所得税费用 |

收入类取贷方减借方，费用类取借方减贷方，负数以红色显示。

## 现金流量表

![现金流量表](/images/manual/fin/report-cash.jpg)

- **期间**：选择开始期间和截止期间（默认本年 1 月至当前月份），开始期间晚于截止期间时自动调整为与截止期间相同。
- 采用**直接法**：取已记账凭证中库存现金、银行存款科目的发生额，按凭证中的**对方科目**归类到现金流量项目。
- 一张凭证有多个对方科目时，按对方科目金额比例分摊；只有现金、银行科目之间的划转（如提现、账户调拨）不计入。

| 分类 | 项目 | 对方科目规则 |
| --- | --- | --- |
| 经营活动 | 销售商品、提供劳务收到的现金 | 流入，对方为应收账款、预收账款、主营 / 其他业务收入、销项税额 |
| | 收到其他与经营活动有关的现金 | 其余流入（含财务费用流入） |
| | 购买商品、接受劳务支付的现金 | 流出，对方为应付账款、预付账款、存货类（14 开头）、生产成本、制造费用、进项税额 |
| | 支付给职工以及为职工支付的现金 | 应付职工薪酬 |
| | 支付的各项税费 | 应交税费、税金及附加、所得税费用 |
| | 支付其他与经营活动有关的现金 | 其余流出 |
| 投资活动 | 处置固定资产等收回的现金净额 / 购建固定资产等支付的现金 | 固定资产、在建工程、固定资产清理 |
| 筹资活动 | 吸收投资收到的现金 | 实收资本流入 |
| | 取得借款收到的现金 / 偿还债务支付的现金 | 短期借款 |
| | 分配股利、利润或偿付利息支付的现金 | 实收资本流出、利润分配、财务费用流出 |

每类活动列出现金流入小计、流出小计和净额，最后为「现金及现金等价物净增加额」「期初现金及现金等价物余额」「期末现金及现金等价物余额」。

如果计算出的期末余额与账面现金、银行存款余额不一致，页面顶部显示黄色提示（通常是存在未记账的现金凭证）。

## 注意事项

::: tip 提示
- 报表数据实时计算，凭证记账后刷新即可看到变化。
- 报表项目按科目编码取数，新增科目请按[会计科目](./account)的编码规则挂在正确的上级之下，否则会进入「其他」项目。
:::
