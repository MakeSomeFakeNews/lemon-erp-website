# 凭证管理

记账凭证是总账的核心。手工录入的凭证和各业务单据自动生成的凭证都在这里集中审核、记账；只有「已记账」的凭证才进入账簿和财务报表。会计、出纳、财务主管日常都会用到。

## 页面入口

财务 → 总账 → 凭证管理

![凭证管理列表](/images/manual/fin/voucher-list.jpg)

## 凭证字号规则

- 凭证字统一为「记」，凭证号按**会计期间**（凭证日期所在月份）连续编号，格式为 `记-0001`、`记-0002`……，每个期间从 0001 重新开始。
- 凭证号在保存时自动分配，不能手工指定。修改未审核凭证的日期、使其跨到另一个期间时，会在新期间重新分配凭证号。
- 删除凭证后，已用过的凭证号不会回收，因此同一期间的凭证号可能出现断号。
- 某期间第一次录入凭证时系统自动创建该会计期间（未结账状态），无需预先建期间。
- 期间结账后，该期间不能再新增、修改、删除凭证，也不能审核、记账或反操作。

## 新增凭证

![新增凭证](/images/manual/fin/voucher-add.jpg)

### 表头字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 凭证日期 | 是 | 默认今天；决定凭证所属期间，该期间必须未结账 |
| 附单据数 | 否 | 原始单据张数，0 至 999，默认 0 |

表头右侧实时显示**借方合计**、**贷方合计**；借贷相等时显示绿色「借贷平衡」，不等时显示红色「差额 xx」。

### 分录字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 摘要 | 是 | 最多 255 字。光标进入空白摘要时自动带出上一行的摘要 |
| 会计科目 | 是 | 可按编码或名称搜索，**只能选择启用的末级科目** |
| 部门 | 否 | 费用归属部门，预算执行按部门统计 |
| 辅助核算 | 否 | 先选类型（项目 / 客户 / 供应商），再选具体的项目或往来单位；用于「账簿查询 → 辅助核算」 |
| 借方金额 / 贷方金额 | 是（二选一） | 每条分录只能填一边，填了借方会自动清空贷方，反之亦然；保留两位小数 |

### 操作步骤

1. 点击「**新增凭证**」，选择凭证日期，填写附单据数。
2. 逐行填写摘要、科目、金额，需要时选择部门和辅助核算。默认有两行，点「**添加分录**」增加行，点行尾删除图标删除行（至少保留两行）。
3. 最后一行金额可以**双击借方或贷方输入框**，系统自动把差额补到该格，使借贷平衡。
4. 点击「保存」。保存成功后自动打开该凭证的详情。

保存时的校验：

- 凭证至少两条分录；
- 每条分录借方、贷方必须且只能填一个；
- 科目必须是启用的末级科目；
- 借方合计必须等于贷方合计，否则提示「借贷不平衡」。

## 凭证详情

在列表点击凭证号或「查看」打开详情，以标准记账凭证样式展示：凭证字号、日期、期间、附单据张数，分录的摘要、科目、部门 / 辅助核算、借贷金额，合计行带金额大写；底部显示来源、制单、审核、记账人。

![凭证详情](/images/manual/fin/voucher-detail.jpg)

详情页还提供：

- **打印**：按「记账凭证」模板打印，签字栏为制单、审核、记账、财务主管。打印模板可在系统的[打印模板](../system/print-template)设置中调整。
- **附件（原始凭证）**：上传发票、合同等扫描件，有凭证修改权限的用户可上传删除。
- **变更记录**：记录凭证日期、凭证号、摘要、借方合计、附单据数的修改历史。

详情底部的操作按钮随状态变化：

| 状态 | 可用操作 |
| --- | --- |
| 未审核 | 删除（与业务联动的凭证除外）、编辑（仅手工凭证）、提交审批、审核 |
| 已审核 | 反审核、记账 |
| 已记账 | 反记账（结转损益凭证除外）、红字冲销（满足条件时） |

## 凭证状态与操作

凭证状态流转：**未审核 → 已审核 → 已记账**；启用凭证审批流程时为 **未审核 → 审批中 → 已审核 → 已记账**。

| 操作 | 前置状态 | 结果 | 说明 |
| --- | --- | --- | --- |
| 编辑 | 未审核 | — | 只有手工凭证可以编辑；业务生成的凭证不能修改，可删除后由业务单据重新生成 |
| 删除 | 未审核 | 凭证删除 | 业务生成的凭证删除后，来源单据恢复为「未生成凭证」，可以重新生成 |
| 审核 | 未审核 | 已审核 | 记录审核人、审核时间。**制单人不能审核自己制单的凭证**（超级管理员除外） |
| 提交审批 | 未审核 | 审批中 | 仅在发布了「凭证审批」流程时可用 |
| 反审核 | 已审核 | 未审核 | 清空审核人 |
| 记账 | 已审核 | 已记账 | 记录记账人、记账时间，凭证进入账簿和报表 |
| 反记账 | 已记账 | 已审核 | 结转损益凭证不能反记账，需要反结账 |
| 红字冲销 | 已记账 | 生成红字凭证 | 见下文 |

所有操作都要求凭证所在期间未结账；批量操作中只要有一张不满足条件，会提示具体凭证号。

### 凭证审批

系统内置了「凭证审批」流程模型（财务主管审核，默认未发布）。在「流程中心 → [流程模型](../workflow/model)」中发布后：

- 凭证不能再直接「审核」，制单人在凭证详情中点「**提交审批**」，凭证变为「审批中」；
- 审批通过后凭证自动变为「已审核」，审核人记为审批人；
- 审批被拒绝或撤回后，凭证退回「未审核」，可修改后重新提交。

流程中可以使用凭证金额、凭证号、凭证来源作为条件。

### 红字冲销

已记账的凭证发现错误又不便反记账时，可以做红字冲销：

1. 在列表点「**冲销**」或在详情中点「**红字冲销**」。
2. 选择**冲销日期**，红字凭证记入该日期所在期间，期间必须未结账。
3. 确认后生成一张科目、方向与原凭证相同、金额为负数的红字凭证（未审核），摘要为「冲销 期间 原凭证号 原摘要」，来源为「红字冲销」；原凭证标记为「已冲销」。

限制：只能冲销已记账、未被冲销过、本身不是红字凭证、也不是结转损益凭证的凭证；每张凭证只能冲销一次。删除红字凭证后，原凭证的「已冲销」标记解除，可以重新冲销。

## 业务生成的凭证

以下业务会自动生成凭证（均为未审核状态，需审核、记账）：

| 来源 | 生成时机 | 典型分录 |
| --- | --- | --- |
| 应收 / 应付 | 在应收管理、应付管理中勾选单据「生成凭证」 | 借 应收账款 / 贷 主营业务收入、销项税额；借 原材料或库存商品、进项税额 / 贷 应付账款 |
| 收款 / 付款 | 在收款单、付款单中「生成凭证」 | 借 银行存款 / 贷 应收账款；借 应付账款 / 贷 银行存款 |
| 预收预付 | 登记、冲抵时立即生成 | 借 银行存款 / 贷 预收账款 等 |
| 坏账 | 应收单坏账核销时生成 | 借 营业外支出 / 贷 应收账款 |
| 报销、借款 | 付款、还款时生成 | 借 费用 / 贷 银行存款、其他应收款 |
| 票据 | 贴现、托收、拒付、兑付时生成 | 见[票据管理](./note) |
| 账户调拨 | 保存调拨时生成 | 借 转入账户、财务费用 / 贷 转出账户 |
| 折旧、资产处置 | 计提折旧、处置资产时生成 | 见[固定资产](./asset) |
| 成本结转 | 成本核算时生成 | 见[成本核算](./cost) |
| 税费 | 增值税结转时生成 | 见[期末结账](./period) |
| 汇兑 | 期末调汇时生成 | 见[币种汇率](./currency) |
| 工资 | 人力资源模块[工资表](../hr/payroll)确认、发放时生成 | 计提：借 制造费用 / 销售费用 / 管理费用 / 贷 应付职工薪酬 |
| 项目 | [项目月结](../pm/accounting#项目月结)时生成 | 人工、费用转入合同履约成本，按进度确认收入和成本 |
| 费用 | [设备维修保养费](../mes/maintenance)、[培训费](../hr/training)等 | 借 制造费用、管理费用 - 培训费 / 贷 其他应付款 |
| 结转损益 | 期末结账时自动生成并**直接记账** | 损益类科目余额转入本年利润 |

业务生成凭证时，同摘要、同科目、同辅助核算、同方向的分录会自动合并，金额为 0 的分录不生成。

## 注意事项

::: warning 不能直接删除的凭证
来源为预收预付、坏账、报销、借款、票据、账户调拨的凭证，与业务单据的金额联动，不能在凭证管理中删除。请在对应的业务页面撤销（例如删除预收预付单、撤销票据操作、删除调拨），或对已记账凭证做红字冲销。
:::

::: tip 提示
- 删除应收应付、收付款、折旧、成本结转生成的凭证后，可以在来源单据中重新生成；删除工资凭证后，工资表会解除与凭证的关联。
- 结转损益凭证随结账生成，不能反记账、不能冲销，也不能手工删除，需要在「期末结账」中反结账。
- 凭证分录的部门用于预算执行统计，辅助核算用于按项目、客户、供应商查询余额，建议费用类分录填写部门。
:::

## 常见问题

**提示「凭证 xx 是你制单的，不能自己审核」？**
系统执行不相容职务分离，制单人和审核人必须是不同的人，请由其他有审核权限的人员审核。

**提示「已启用凭证审批流程，请提交审批」？**
凭证审批流程已发布，需由制单人在详情中提交审批，审批通过后自动变为已审核。

**提示「xx 期间已结账，不能再录入或修改凭证」？**
该期间已结账。如确需调整，可在[期末结账](./period)中从最后一个已结账期间开始反结账，或在未结账的期间录入调整凭证。
