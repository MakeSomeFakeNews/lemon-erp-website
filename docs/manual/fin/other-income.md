# 其他收支

登记与采购、销售无关的日常现金、银行收支：**其他收入单**用于废料销售、佣金、房租收入等非主营业务收入，**费用支出单**用于房租、水电、差旅、招待、快递、工资等直接支付的费用。单据的明细按「收支类别」填写，确认后自动生成凭证，进入[出纳管理](./cashier)的日记账和资金日报。出纳、会计使用，总经理和普通用户可以查看。

## 页面入口

财务 → 资金与费用 → 其他收支

<!-- 截图：other-income-list.jpg（其他收支 - 收支单列表） -->

页面有三个页签：**收支单**（默认）、**收支汇总**、**收支类别**。

## 收支单列表

查询条件：收 / 支（全部、其他收入、费用支出）、状态（待确认、已确认）、日期范围、关键字（单号、票据编号、单位、备注）。

| 列 | 说明 |
| --- | --- |
| 单号 | 其他收入单以 SR 开头，费用支出单以 ZC 开头；点击打开详情 |
| 日期 | 收支发生的日期，即凭证日期 |
| 收 / 支 | 收入、支出 |
| 收支类别 | 明细中的类别名称，多个用顿号分隔 |
| 金额 | 收入为绿色，支出为红色 |
| 结算账户 | 收款或付款的现金 / 银行账户 |
| 关联单位、结算方式、票据编号、费用部门、制单人、备注 | 默认隐藏，可在列设置中显示 |
| 状态 | 待确认、已确认；已确认的下方显示凭证号，点击查看凭证 |
| 操作 | 待确认：修改、确认、删除；已确认且凭证未记账：取消确认 |

工具栏右侧有「**其他收入单**」「**费用支出单**」两个新增按钮。

## 新增收支单

<!-- 截图：other-income-form.jpg（新增费用支出单表单） -->

点击「其他收入单」或「费用支出单」，打开新增页面。页面顶部说明确认后生成的凭证：

- 其他收入单：借 结算账户 / 贷 各收支类别的科目；
- 费用支出单：借 各收支类别的科目 / 贷 结算账户。员工先垫付、需要审批的费用请走[费用报销](./claim)。

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 日期 | 是 | 默认今天；所在期间已结账时不能保存 |
| 票据编号 | 否 | 发票号、收据号等，最多 64 个字符 |
| 结算方式 | 否 | 业务字典「结算方式」，如现金、转账；不能选择「票据」，承兑汇票请在[票据管理](./note)中办理 |
| 结算账户 | 是 | 库存现金、银行存款下的末级科目（范围见[凭证科目设置](./account-rule#货币资金科目范围)） |
| 关联单位 | 否 | 先选类型：**客户**、**供应商**从资料中选择；**其他**（物流公司、个人等）直接填写名称，最多 128 个字符；选「不关联」时不填 |
| 费用部门 | 否 | 只有费用支出单有；凭证分录带部门，预算按部门统计 |
| 备注 | 否 | 写入凭证摘要 |

**收支明细**：每行选择一个收支类别、填写金额（大于 0）和备注（如「3 月电费」「张三工资」），「凭证科目」列显示该类别关联的科目。点「**添加行**」增加明细，右上角显示合计。只能选择与单据方向一致、启用中的类别；至少一行，最多 200 行。

保存后自动打开单据详情，状态为「待确认」，可以继续修改或删除。

## 确认与取消确认

### 确认

在列表或详情中点击「**确认**」，提示「确认收支单 单号（¥金额）？确认后生成凭证（未审核），进入出纳日记账和资金日报，不能再修改。」确定后生成一张未审核凭证，凭证来源为「其他收支」：

| 单据 | 凭证分录 |
| --- | --- |
| 其他收入单 | 借 结算账户（合计金额）/ 贷 各明细的类别科目 |
| 费用支出单 | 借 各明细的类别科目（带费用部门）/ 贷 结算账户（合计金额） |

- 摘要为「其他收入 单号」或「费用支出 单号」，后接关联单位、类别名称和备注。
- 关联单位为客户或供应商时，类别科目的分录带客户 / 供应商辅助核算。
- 类别没有设置凭证科目、类别已停用、结算账户不是现金或银行科目时不能确认。

凭证生成后需要在[凭证管理](./voucher)中审核、记账才进入账簿和报表；出纳管理默认包含未记账凭证，确认后即可在日记账中看到这笔收支，「来源单据」列显示「其他收支」和单号。

### 取消确认

已确认的单据，凭证还没有记账时，可以点击「**取消确认**」：删除生成的凭证（须未审核，已审核的先在凭证管理中反审核），单据回到「待确认」，可以修改或删除。凭证已记账时不能取消确认，可以在凭证管理中红字冲销后重新登记。

::: warning 注意
- 收支单生成的凭证不能在凭证管理中直接删除，只能通过取消确认删除。
- 单据日期所在的会计期间已结账时，不能新增、修改、删除、确认或取消确认。
:::

## 单据详情

<!-- 截图：other-income-detail.jpg（收支单详情） -->

详情显示收 / 支、日期、状态、金额、结算账户、结算方式、关联单位、票据编号、费用部门、凭证（点击查看；未记账时显示凭证状态）、制单人、确认人和备注，下方为收支明细（收支类别、凭证科目、金额、备注）。

按钮：待确认时有「删除」「修改」「确认」；已确认且凭证未记账时有「取消确认」。

## 收支汇总

<!-- 截图：other-income-summary.jpg（收支汇总） -->

按日期范围（默认本月 1 日至今天，不超过一年）和收 / 支（全部、其他收入、费用支出）汇总**已确认**的收支单：

- 左侧按收支类别列出收 / 支、笔数和金额，类别名称下方显示凭证科目；底部合计行显示收入合计、支出合计、总笔数和收支差额。
- 点击某个类别，右侧列出该类别的明细（日期、单号、收支类别、金额、关联单位、结算账户、备注）；点击「查看全部」显示全部类别的明细。点击单号打开单据详情。

## 收支类别

<!-- 截图：other-income-category.jpg（收支类别） -->

收支类别每个公司一份，可以自行增加。列表可按收 / 支筛选，列有类别名称、收 / 支、凭证科目（没有设置时提示「未设置科目」）、排序、状态、备注和操作（修改、删除）。

点击「**新增类别**」：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 收 / 支 | 是 | 收入或支出；已被收支单使用的类别不能修改 |
| 类别名称 | 是 | 同一方向下不能重复，最多 64 个字符 |
| 凭证科目 | 是 | 末级会计科目。收入类别在确认收入单时贷记该科目（如其他业务收入、营业外收入）；支出类别在确认支出单时借记该科目（如管理费用下的明细科目、销售费用、财务费用） |
| 排序、状态、备注 | | 停用的类别不能再选择，已有单据不受影响 |

已被收支单使用的类别不能删除，可以停用。被收支类别或收支单引用的科目视为「已使用」，不能删除，也不能再增加下级科目；被收支单关联的客户、供应商和费用部门也不能删除。

系统预置了常用类别：

| 方向 | 类别 | 凭证科目 |
| --- | --- | --- |
| 收入 | 废料销售、佣金收入、房租收入 | 6051 其他业务收入 |
| | 其他收入 | 6301 营业外收入 |
| 支出 | 差旅费 / 业务招待费 / 办公费 / 房租 / 水电费 / 快递费 / 工资 | 管理费用下的差旅费 660204、业务招待费 660206、办公费 660202、租赁费 660208、水电费 660207、快递费 660209、工资 660201 |
| | 银行手续费 | 6603 财务费用 |
| | 其他支出 | 6711 营业外支出 |

可以把类别改到企业自己的明细科目，例如把销售部门的差旅记到销售费用。

## 与其他模块的联动

- 确认后的凭证进入[出纳管理](./cashier)的资金日报和日记账，费用支出带部门的分录计入[预算管理](./budget)的部门执行数。
- 收支单不接入审批流程：由出纳按实际收付登记；需要审批的员工垫付费用使用[费用报销](./claim)，与客户、供应商往来款相关的收付使用[收款单与付款单](./settlement)。
- 账户之间的划转使用[账户调拨](./transfer)。

## 权限

| 权限 | 说明 |
| --- | --- |
| 其他收支（查看） | 打开本页面，查看收支单、收支汇总和收支类别。内置的会计、出纳、总经理、普通用户角色有此权限 |
| 收支单新增 / 修改 / 删除 / 确认 | 内置的会计、出纳角色有此权限；「确认」权限同时用于取消确认 |
| 收支类别维护 | 新增、修改、删除收支类别。内置的会计、出纳角色有此权限 |
