# 应收管理与应付管理

应收单、应付单记录与客户、供应商之间的往来款项。绝大多数应收应付单由业务单据**自动生成**，财务人员在这里查看核销进度、生成凭证、做坏账核销（应付为无法支付的应付款转销）和账龄分析，也可以手工录入系统启用前的期初余额。

「应收管理」与「应付管理」是同一套页面，区别只是往来对象（客户 / 供应商）和凭证分录方向。

## 页面入口

- 财务 → 应收应付 → 应收管理
- 财务 → 应收应付 → 应付管理

页面有三个页签：**应收单（应付单）**、**往来汇总** 和 **账龄分析**。

![应付管理](/images/manual/fin/ap-list.jpg)

## 应收应付单从哪里来

| 来源（列表「来源」列） | 生成时机 | 种类 |
| --- | --- | --- |
| 销售出库 / 销售退货 | [销售出库单、销售退货单](../scm/sales-out)确认时 | 应收；退货为红字（负数） |
| 采购入库 / 采购退货 | [采购入库单、采购退货单](../scm/purchase-in)确认时 | 应付；退货为红字（负数） |
| 项目开票 | 项目管理中[开票](../pm/accounting#开票)时 | 应收 |
| 服务收费 | 客户[服务工单](../crm/ticket#服务收费)收费时 | 应收 |
| 运费 | [物流发运单](../scm/shipment#运费承担)指定承运商和运费、发货时；运费由客户承担（代垫）时，同时生成客户的代垫运费应收单 | 应付（承运商）；代垫运费为应收（客户） |
| 采购运费 | [采购入库](../scm/purchase-in#采购运费)填写了运费时：供应商代垫的应付本单供应商，本公司承担的应付所选承运商 | 应付 |
| 销售运费 | [销售出库](../scm/sales-out#销售出库的运费)登记了运费时：付给承运商为「月结」的生成承运商的应付单；运费承担为「代垫运费」的另生成客户的代垫运费应收单（不含税）。现付的不生成应付，而是生成[费用支出单](./other-income#业务单据生成的费用支出单) | 应付（承运商）；代垫运费为应收（客户） |
| 销售退货运费 | [销售退货](../scm/sales-out#销售退货的运费)登记了客户代垫的运费时 | 红字应收（客户） |
| 采购退货运费 | [采购退货](../scm/purchase-in#采购退货的运费)登记了代垫运费时：冲减欠供应商的款；付给承运商为「月结」的另生成承运商的应付单 | 红字应付（供应商）；月结时另有应付（承运商） |
| 质量索赔 | [供应商质量索赔](../qms/claim)确认时 | 红字应付 |
| 返利 | [销售返利](../scm/rebate)按红字应收方式结算时；[采购返利](../scm/purchase-rebate)结算时 | 销售返利为红字应收，采购返利为红字应付；税额按业务参数「[默认税率](../system/biz-rule#默认税率)」（默认 13%）价内计算 |
| 订单尾差调整 | 部分出入库的[采购 / 销售订单关闭](../scm/sales#分批出库与关闭时的尾差)时，按订单口径结算的几分钱差额 | 应收或应付；正数蓝字、负数红字 |
| 冲账单 | [冲账单](./offset)复核时（垫付运费、返利、三包赔偿等抵扣往来款） | 红字应收或红字应付，到期日为冲账日期 |
| 固定资产 | 新增固定资产时填写了采购供应商（直接付款、选择付款账户的不生成应付单，直接生成购置凭证，见[固定资产](./asset#资产购入的入账)） | 应付 |
| 票据拒付 | 应收票据被拒付时转回 | 应收 |
| 期初 / 手工 | 在本页手工录入 | 应收或应付 |

到期日：业务生成的单据按单据日期加往来单位的账期天数计算；采购订单引用了约定付款天数的[采购合同](../scm/contract#采购订单如何引用合同)时，按合同的付款天数计算。外币订单生成的单据带币种和记账汇率，金额同时记录原币和折算后的人民币。

## 生成凭证

1. 在列表勾选单据（已生成凭证的、手工录入的、金额为 0 的单据不能勾选）。
2. 点击右上角「**生成凭证（N）**」并确认。
3. 每张单据生成一张未审核凭证，到[凭证管理](./voucher)审核、记账。

凭证分录：

| 单据 | 分录 |
| --- | --- |
| 销售出库应收 | 借 应收账款（客户辅助核算）/ 贷 主营业务收入（可按物料分类分别记账）、应交税费 - 销项税额 |
| 项目开票应收 | 借 应收账款 / 贷 合同负债、销项税额（带项目辅助核算） |
| 服务收费应收 | 借 应收账款 / 贷 其他业务收入、销项税额 |
| 采购入库应付 | 借 存货科目（按物料分类，预置为：半成品、成品记库存商品，低值易耗品记周转材料，其余记原材料）、应交税费 - 进项税额 / 贷 应付账款（供应商辅助核算） |
| 运费等费用类应付 | 借 销售费用等费用科目、进项税额 / 贷 应付账款；发运运费、销售出库月结的运费本公司承担时借 销售运费，客户承担（代垫）时借 代垫运费 |
| 代垫运费应收 | 借 应收账款 / 贷 代垫运费，与付承运商时借记的代垫运费相抵，不是销售收入 |
| 销售退货运费红字应收 | 借 销售运费 / 贷 应收账款，冲减客户欠款 |
| 采购退货运费红字应付 | 借 应付账款 / 贷 代垫运费，冲减欠供应商的款；月结时承运商的应付单 借 代垫运费 / 贷 应付账款 |
| 采购运费应付 | 计入存货成本时（供应商代垫，或本公司承担且[业务参数](../system/biz-rule#本公司承担的采购运费计入)为「存货成本」）借 存货科目（按物料分类，与入库成本中分摊的运费一致）/ 贷 应付账款；本公司承担且参数为「当期费用」时借 采购运费科目（默认销售费用 6601）/ 贷 应付账款 |
| 质量索赔红字应付 | 借 应付账款 / 贷 营业外收入 |
| 销售返利红字应收 | 借 应收账款 / 贷 主营业务收入、销项税额（金额为负数，即冲减收入和销项税额） |
| 采购返利红字应付 | 借 应付账款 / 贷 采购返利的对方科目（默认主营业务成本，冲减成本）、进项税额（进项税额转出） |
| 冲账单红字应收 / 应付 | 应收冲账 借 冲账单上的科目（默认销售费用）/ 贷 应收账款；应付冲账 借 应付账款 / 贷 冲账单上的科目（默认主营业务成本）。冲账单复核时已自动生成，见[冲账单](./offset#复核与凭证) |
| 退货等红字单据 | 分录方向不变，金额为负数 |

以上科目在「[凭证科目设置](./account-rule)」中配置，未设置时使用预置科目。

## 期初 / 手工录入

用于录入系统启用前尚未收付的往来余额。

1. 点击「**期初 / 手工录入**」。
2. 填写字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 客户 / 供应商 | 是 | 往来单位 |
| 单据日期 | 是 | 默认今天 |
| 到期日 | 否 | 不填按往来单位的账期计算 |
| 金额 | 是 | 不能为 0；负数为红字（冲减） |
| 备注 | 否 | 如「2025 年末余额」 |

3. 点击「确定」保存。

期初往来较多时，可在[期初余额 → 启用向导](./opening#导入期初往来)中用 Excel 批量导入，导入后同样生成手工应收应付单。

手工录入的单据**不生成凭证**（期初余额请在[期初余额](./opening)中录入科目期初）。

::: tip 金额为 0 的单据
整单赠品等金额（含税额）为 0 的应收应付单没有分录，生成时即为「已核销」，不生成凭证（批量生成凭证时自动跳过，不影响同批其他单据），结账检查也不计入。
:::
只有未核销的手工单据可以删除；业务生成的单据不能删除，需要通过退货等业务冲回。

## 坏账核销（应收）与无法支付转销（应付）

### 应收坏账核销

确认无法收回的应收款，按直接转销法核销：

1. 在应收单行末点击「**坏账核销**」图标（只有金额为正、还有未核销余额的应收单显示）。
2. 填写**核销金额**（默认为全部未核销余额，不能超过）、**核销日期**、核销原因。
3. 确认后计入该单据的已核销金额，并生成凭证「借 营业外支出 / 贷 应收账款」，随后自动打开该凭证。

### 应付：无法支付的应付款转销

供应商注销、债权人放弃等原因确认不再支付的应付款，同样可以转销：

1. 在应付单行末点击「**无法支付转销**」图标（只有金额为正、还有未核销余额的应付单显示）。
2. 在弹窗「无法支付的应付款转销 单号」中填写**核销金额**（默认为全部未核销余额）、**核销日期**、核销原因（如「供应商已注销，确认无需支付」）。
3. 确认后计入该单据的已核销金额，并生成凭证「借 应付账款 / 贷 营业外收入」，随后自动打开该凭证。

![无法支付的应付款转销](/images/manual/fin/ap-bad-debt.jpg)

### 限制

- 单据必须已经生成应收（应付）凭证，手工录入的期初单据除外；
- 外币单据需先收付款或期末调汇后再处理；
- 核销日期所在期间必须未结账；
- 坏账凭证不能在凭证管理中直接删除，需要红字冲销；
- 应收坏账需要「坏账核销」按钮权限，应付转销需要「应付坏账」按钮权限（内置的会计角色两者都有）。

## 往来汇总

「往来汇总」页签按往来单位汇总**当前**还欠多少钱：一个客户（供应商）一行，把期初余额、业务单据的未核销余额、未冲抵的预收（预付）款合在一起算出净欠款，适合催款、安排付款时快速查看。

![往来汇总](/images/manual/fin/ar-summary.jpg)

### 查询条件

| 条件 | 说明 |
| --- | --- |
| 全部客户 / 全部供应商 | 选择一个往来单位，选择后立即查询 |
| 单位编码或名称 | 模糊查询，按回车或点搜索图标查询 |
| 负责销售 | 只有应收：按客户资料中的负责人筛选（供应商没有负责人） |
| 只看有余额 | 默认勾选，只列出期初、单据余额、预收预付中任一项不为 0 的单位 |

条件后面的问号图标悬停显示净欠款的计算公式。列表上方显示所有符合条件的单位的合计：期初、单据余额、预收（预付）余额、净欠款、坏账核销（无法支付转销）和收款折让（付款折让）。

### 列

| 列（应收 / 应付） | 说明 |
| --- | --- |
| 客户 / 供应商 | 名称（点击展开明细），下方为编码和负责销售 |
| 期初应收 / 期初应付 | 期初 / 手工录入的应收应付单的未核销余额 |
| 应收单据余额 / 应付单据余额 | 其他来源（出入库、退货、运费、返利、索赔、冲账单等）的应收应付单的未核销余额，红字单据为负数 |
| 预收余额 / 预付余额 | 未冲抵的预收（预付）款，以负数显示 |
| 坏账核销 / 无法支付转销 | 累计做过坏账核销（转销）的金额，已经从单据余额中扣除，单列供参考 |
| 收款折让 / 付款折让 | 该单位的应收应付单在收付款时累计给出（取得）的[折让 / 抹零](./settlement#折让与抹零)，已经计入已核销、从单据余额中扣除，单列供参考 |
| 净欠款 | 期初 + 单据余额 + 预收（预付）余额，即对方实际还欠（应付为本公司还欠对方）的金额；负数表示预收（预付）大于欠款 |
| 操作 | 图标按钮：「收款」（应付为「付款」）、「对账单」 |

- 金额都是人民币，外币单据按记账汇率折算；
- 出入库单登记的代垫运费单独一张应收应付单，与货款的单据一起计入单据余额：销售出库代垫运费时客户欠款 = 货款 + 代垫运费，销售退货客户代垫、采购退货代垫运费时分别冲减 货款 + 代垫运费，收付款时把两张单据一起勾选即可；
- 按净欠款从大到小排列；
- 只统计已生效的单据：收付款草稿、审批中的付款单还没有核销，不减少余额。

### 展开明细

点击单位名称或行首的「+」展开该单位的明细（同时只展开一个单位），分三个页签：

| 页签 | 内容 |
| --- | --- |
| 未核销的应收单 / 未核销的应付单 | 单号、来源（可[穿透](#来源单据穿透)到来源单据）、单据日期、到期日、金额（外币另显示原币；部分收付款时给过折让的，下方显示「折让 金额 · 净额 金额」）、未核销余额、状态，含红字单据 |
| 未冲抵的预收款 / 未冲抵的预付款 | 预收预付单号、日期、金额、未冲抵余额；需要「预收预付」的查看权限 |
| 收款记录 / 付款记录 | 最近 20 笔收付款：单号、日期、实收（实付）金额（下方显示折让、冲抵预收预付的金额）、结算账户、状态；更多请到收付款页面查询。需要收款单 / 付款单的查看权限 |

### 直接收付款与对账单

- 「**收款**」（「**付款**」）：打开[收款单 / 付款单](./settlement)录入页，并自动带出该单位的未核销单据和可冲抵的预收预付，保存后汇总刷新。需要收款单 / 付款单的新增权限。
- 「**对账单**」：跳转到[往来对账单](./partner-statement)并直接查询该单位。需要「往来对账单」的菜单权限。

### 与往来对账单的关系

往来汇总与往来对账单的口径一致（两者都扣除收付款折让），只是对账单不扣坏账：

**往来对账单截至今天的期末余额 = 净欠款 + 坏账核销（无法支付转销）**

有外币单据时，对账单中的收付款按收付款汇率折算，两者之间还会有汇率差额。

## 账龄分析

![账龄分析](/images/manual/fin/ar-aging.jpg)

按往来单位汇总截至某一日期的**未核销余额**，并按到期日计算逾期天数分段：

| 列 | 说明 |
| --- | --- |
| 客户 / 供应商 | 名称和编码 |
| 未核销余额 | 截止日期时尚未核销的金额合计 |
| 未到期 | 到期日在截止日期之后 |
| 逾期 1-30 天 / 31-60 天 / 61-90 天 / 90 天以上 | 按截止日期与到期日相差天数分段，逾期金额以红色显示 |

- **截止日期**默认为今天，可以选择历史日期；核销金额只取截止日期之前的收付款（含收付款时的折让），因此查历史日期的账龄也准确。
- 审批中的付款单尚未核销，不计入账龄。

## 与其他模块的联动

- 收款单、付款单（含折让、在收付款中一起冲抵的预收预付）、预收预付冲抵、票据收票 / 背书 / 开票都会核销应收应付单，更新「已核销」和状态；收付款草稿在确认之前不核销。
- [冲账单](./offset)复核后生成红字应收应付单，收付款时勾选即可与欠款相抵。
- 发票管理勾稽单据后更新「已开票 / 已收票」。
- 供应商对账汇总应付单生成对账单。
- [销售订单](../scm/sales#订单详情)、[采购订单](../scm/purchase#订单详情)详情的「单据追溯」中可以看到对应的应收应付单。
- 客户[信用额度](../scm/sales#信用额度与账期)占用会扣减未冲抵的预收款。
- 系统默认每天上午 9 点汇总逾期应收，向有应收管理权限的人员发送站内消息；[首页待办](../guide/home#待办事项)中也会显示「应收逾期」。

## 注意事项

::: tip 提示
- 应收应付单所在期间已结账时，不能再新增、删除该期间的应收应付单。
- 在结账检查中，本月业务生成的应收应付单未生成凭证会给出提示（金额为 0 的单据除外）。
:::
