# 应收管理与应付管理

应收单、应付单记录与客户、供应商之间的往来款项。绝大多数应收应付单由业务单据**自动生成**，财务人员在这里查看核销进度、生成凭证、做坏账核销和账龄分析，也可以手工录入系统启用前的期初余额。

「应收管理」与「应付管理」是同一套页面，区别只是往来对象（客户 / 供应商）和凭证分录方向。

## 页面入口

- 财务 → 应收应付 → 应收管理
- 财务 → 应收应付 → 应付管理

页面有两个页签：**应收单（应付单）** 和 **账龄分析**。

## 应收应付单从哪里来

| 来源（列表「来源」列） | 生成时机 | 种类 |
| --- | --- | --- |
| 销售出库 / 销售退货 | [销售出库单、销售退货单](../scm/sales-out)确认时 | 应收；退货为红字（负数） |
| 采购入库 / 采购退货 | [采购入库单、采购退货单](../scm/purchase-in)确认时 | 应付；退货为红字（负数） |
| 项目开票 | 项目管理中[开票](../pm/accounting#开票)时 | 应收 |
| 服务收费 | 客户[服务工单](../crm/ticket#服务收费)收费时 | 应收 |
| 运费 | [物流发运单](../scm/shipment)指定承运商和运费、发货时 | 应付（承运商） |
| 质量索赔 | [供应商质量索赔](../qms/claim)确认时 | 红字应付 |
| 销售返利 | [销售返利](../scm/rebate)按红字应收方式结算时 | 红字应收 |
| 固定资产 | 新增固定资产时填写了采购供应商 | 应付 |
| 票据拒付 | 应收票据被拒付时转回 | 应收 |
| 期初 / 手工 | 在本页手工录入 | 应收或应付 |

到期日：业务生成的单据按单据日期加往来单位的账期天数计算；采购订单引用了约定付款天数的[采购合同](../scm/contract#采购订单如何引用合同)时，按合同的付款天数计算。外币订单生成的单据带币种和记账汇率，金额同时记录原币和折算后的人民币。

| 列 | 说明 |
| --- | --- |
| 单号 | 应收单以 YS 开头，应付单以 YF 开头 |
| 客户 / 供应商 | 名称和编码 |
| 来源 | 来源类型标签和来源单号（手工单显示备注） |

| 已核销 | 已核销金额、剩余未核销金额；外币单据显示原币核销情况；做过坏账核销的显示坏账金额 |
| 已开票 / 已收票 | 发票管理中已勾稽的金额，以及未开票（未收票）金额 |
| 日期 / 到期日 | 单据日期；未核销完且已过期的显示红色「逾期 N 天」 |
| 状态 | 未核销 / 部分核销 / 已核销 |
| 凭证 | 已生成时显示凭证号（点击查看），否则显示「未生成」；手工单显示「期初不生成」 |
| 操作 | 「坏账核销」（仅应收）、「删除」（仅手工单） |

## 生成凭证

1. 在列表勾选单据（已生成凭证的、手工录入的单据不能勾选）。
2. 点击右上角「**生成凭证（N）**」并确认。
3. 每张单据生成一张未审核凭证，到[凭证管理](./voucher)审核、记账。

凭证分录：

| 单据 | 分录 |
| --- | --- |
| 销售出库应收 | 借 应收账款（客户辅助核算）/ 贷 主营业务收入、应交税费 - 销项税额 |
| 项目开票应收 | 借 应收账款 / 贷 合同负债、销项税额（带项目辅助核算） |
| 服务收费应收 | 借 应收账款 / 贷 其他业务收入、销项税额 |
| 采购入库应付 | 借 原材料或库存商品（按物料分类：半成品、成品记库存商品，低值易耗品记周转材料，其余记原材料）、应交税费 - 进项税额 / 贷 应付账款（供应商辅助核算） |
| 运费等费用类应付 | 借 销售费用等费用科目、进项税额 / 贷 应付账款 |
| 质量索赔红字应付 | 借 应付账款 / 贷 营业外收入 |
| 退货等红字单据 | 分录方向不变，金额为负数 |

## 期初 / 手工录入

用于录入系统启用前尚未收付的往来余额。

1. 点击「**期初 / 手工录入**」。
2. 填写字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 客户 / 供应商 | 是 | 往来单位 |
| 单据日期 | 是 | 默认今天 |
| 到期日 | 否 | 不填按往来单位的账期计算 |
| 金额 | 是 | 不能为 0；负数为红字（冲减） |
| 备注 | 否 | 如「2025 年末余额」 |

3. 点击「确定」保存。

手工录入的单据**不生成凭证**（期初余额请在[期初余额](./opening)中录入科目期初）。只有未核销的手工单据可以删除；业务生成的单据不能删除，需要通过退货等业务冲回。

## 坏账核销（应收）

确认无法收回的应收款，按直接转销法核销：

1. 在应收单行点击「**坏账核销**」（只有金额为正、还有未核销余额的应收单显示）。
2. 填写**核销金额**（默认为全部未核销余额，不能超过）、**核销日期**、核销原因。
3. 确认后计入该单据的已核销金额，并生成凭证「借 营业外支出 / 贷 应收账款」，随后自动打开该凭证。

限制：单据必须已经生成应收凭证；外币应收单需先收款或期末调汇后再处理坏账。坏账凭证不能在凭证管理中直接删除，需要红字冲销。

## 账龄分析

![账龄分析](/images/manual/fin/ar-aging.jpg)

按往来单位汇总截至某一日期的**未核销余额**，并按到期日计算逾期天数分段：

| 列 | 说明 |
| --- | --- |
| 客户 / 供应商 | 名称和编码 |
| 未核销余额 | 截止日期时尚未核销的金额合计 |
| 未到期 | 到期日在截止日期之后 |
| 逾期 1-30 天 / 31-60 天 / 61-90 天 / 90 天以上 | 按截止日期与到期日相差天数分段，逾期金额以红色显示 |

- **截止日期**默认为今天，可以选择历史日期；核销金额只取截止日期之前的收付款，因此查历史日期的账龄也准确。
- 审批中的付款单尚未核销，不计入账龄。

## 与其他模块的联动

- 收款单、付款单、预收预付冲抵、票据收票 / 背书 / 开票都会核销应收应付单，更新「已核销」和状态。
- 发票管理勾稽单据后更新「已开票 / 已收票」。
- 供应商对账汇总应付单生成对账单。
- [销售订单](../scm/sales#订单详情)、[采购订单](../scm/purchase#订单详情)详情的「单据追溯」中可以看到对应的应收应付单。
- 客户[信用额度](../scm/sales#信用额度与账期)占用会扣减未冲抵的预收款。
- 系统默认每天上午 9 点汇总逾期应收，向有应收管理权限的人员发送站内消息；[首页待办](../guide/home#待办事项)中也会显示「应收逾期」。

## 注意事项

::: tip 提示
- 应收应付单所在期间已结账时，不能再新增、删除该期间的应收应付单。
- 在结账检查中，本月业务生成的应收应付单未生成凭证会给出提示。
:::
