# 客户对账

按客户和期间生成**客户对账单**，把期间内的应收、收款、折让和欠款固定下来发给客户确认：有[经销商门户](../portal/dealer#对账单)账号的客户在门户中在线确认或提出异议；没有门户账号的客户打印给对方签字盖章，收回后由财务登记确认结果。会计使用。

与[往来对账单](./partner-statement)的区别：往来对账单是随时查询的账表，数据随单据变化；客户对账单是按往来对账单的口径生成的**快照**，生成后之后的单据变化不再影响它，并有发送、确认、异议的流程记录。供应商一方的对账见[供应商对账](./statement)。

## 页面入口

财务 → 应收应付 → 客户对账

## 列表

查询条件：状态（全部状态 / 草稿 / 待确认 / 已确认 / 有异议）、客户、关键字（对账单号、客户名称或编码）。

| 列 | 说明 |
| --- | --- |
| 对账单号 | 以 KDZ 开头，点击查看详情 |
| 客户 | 客户名称，下方为客户编码 |
| 对账期间 | 开始日期 ~ 结束日期 |
| 期初余额 | 开始日期之前的欠款 |
| 本期应收 | 期间内的应收单合计，退货、冲账等红字单据为负数 |
| 本期收款 | 期间内的收款实收和预收款合计；有收款折让时下方显示「折让 ¥…」 |
| 期末欠款 | 期初余额 + 本期应收 − 本期收款 − 本期折让 − 应收应付对冲 |
| 状态 | 草稿、待确认、已确认、有异议；有客户意见时在下方显示，鼠标悬停看全文 |
| 操作 | 查看 |

## 生成对账单

1. 点击右上角「**生成对账单**」。
2. 选择**客户**和**对账期间**（默认上个月整月），可填写备注。
3. 点击「确定」，提示「已生成对账单」，生成草稿状态的对账单。

弹窗中的提示：按往来对账单的口径生成客户在期间内的对账快照（期初、本期应收、收款、折让、对冲、期末和逐笔明细），之后的单据变化不影响已生成的对账单。

- 计算口径与[往来对账单](./partner-statement#计算口径)相同：应收单增加欠款，已生效的收款单（实收 + 折让）和预收款减少欠款，应收应付对冲减少欠款，坏账核销不计入；不挂接关联供应商的应付。
- 客户在期间内没有任何往来、期初余额也为 0 时不能生成，提示「客户在期间内没有往来，期初余额也为 0，不需要对账」。
- 同一客户、同一期间可以多次生成，例如有异议的对账单删除后重新生成。

## 对账单详情

点击对账单号或「查看」打开详情：

- **基本信息**：客户、对账期间、状态、客户确认（确认或提出异议的时间和操作人）、制单（制单人和时间）、客户意见、备注。
- **金额**：期初余额、本期应收、本期收款、本期折让、应收应付对冲（有对冲时才显示）、期末欠款。
- **往来明细（N 笔）**：日期、类型、单号、来源 / 结算方式、应收金额、收款金额、余额、备注，与往来对账单的列相同；收款中有折让的，在收款金额下方注明「其中折让 ¥…」。明细分页显示（每页 20、50、100、200、500 条，默认 50），第一页首行为「期初余额」，之后各页首行为「承前页余额」；底部「本期合计」按全部明细计算，与翻页无关。
- **打印**：生成「客户对账单」PDF，表头为客户、对账期间、期初余额、本期应收、本期收款、本期折让、本期对冲、期末余额，明细为全部往来，底部有核对说明和签字栏（制表、财务审核、客户确认（盖章））。版式可在[打印模板](../system/print-template)中调整（模板名称「客户对账单」）。
- **导出**：把全部明细（含期初行和合计行）导出为 Excel。
- **附件（客户签字盖章的对账单扫描件等）**：财务和客户（经销商门户）都可以查看、上传。

## 状态流转

| 状态 | 说明 | 可做操作 |
| --- | --- | --- |
| 草稿 | 刚生成 | 删除、发送客户 |
| 待确认 | 已发送，等待客户确认 | 登记确认结果 |
| 已确认 | 客户确认无误 | 上传附件 |
| 有异议 | 客户提出异议（必须说明原因） | 删除后重新生成，或核对后再次发送 |

### 发送客户

草稿或有异议的对账单，在详情右上角点击「**发送客户**」，确认「发送给客户确认？有经销商门户账号的客户会收到消息」后，状态变为「待确认」。

- 客户开通了[经销商门户账号](../portal/account#为经销商开通)时，其门户账号收到站内消息「对账单待确认」，在门户的「对账单」中确认或提出异议。客户确认或提出异议后，对账单的**制单人**收到站内消息（确认时附期末欠款，有异议时附异议说明）。
- 客户没有门户账号时，打印对账单交给客户签字盖章，收回后按下文登记结果。

### 登记确认结果

待确认的对账单，详情右上角有「**登记确认结果**」下拉菜单，用于登记客户线下签回的结果（有门户账号的客户也可以由财务代为登记）：

- **客户已确认**：弹窗提示「客户签字盖章确认了对账单（可在附件中上传扫描件）」，可填写说明；确定后状态变为「已确认」。
- **客户有异议**：必须填写「异议说明」，否则提示「请说明异议」；确定后状态变为「有异议」。

登记后记录操作人和时间（显示在「客户确认」中）。签回的扫描件在详情下方的附件中上传。

### 删除

只能删除**草稿**或**有异议**的对账单。已发送待确认、已确认的对账单不能删除，提示「已发送待确认或已确认的对账单不能删除」。有异议时，核对差异后可以删除重新生成（例如补录了漏记的收款），也可以不改动直接再次发送。

## 权限

| 权限 | 说明 |
| --- | --- |
| 客户对账 | 打开本页，查看对账单、打印、导出 |
| 客户对账单生成 | 生成对账单 |
| 客户对账单发送 | 发送客户、登记确认结果、上传附件 |
| 客户对账单删除 | 删除草稿或有异议的对账单 |

内置的会计角色拥有全部权限，普通用户、总经理、出纳只能查看。

## 注意事项

::: tip 提示
- 对账单是生成时的快照：生成后补录、作废的应收单或收款单不会改变已生成的对账单，需要反映最新数据时删除（草稿或有异议的）后重新生成。
- 合并客户时，被合并客户的对账单一并转到保留的客户名下，见[客户 - 资料合并](../scm/customer#资料合并)。
- 只想查看当前的往来明细、不需要客户确认流程时，直接用[往来对账单](./partner-statement)。
:::
