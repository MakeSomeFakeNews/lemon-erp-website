# 收款单与付款单

收款单记录收到客户的货款并核销应收单，付款单记录支付供应商的款项并核销应付单。录入时输入本次收付款金额，系统自动分配到各张单据；客户临时要求的优惠、抹零可以在核销时直接作为折让处理，多收、多付的部分可以转为预收、预付款。出纳、会计使用，两个页面结构相同。

## 页面入口

- 财务 → 应收应付 → 收款单
- 财务 → 应收应付 → 付款单

页面有两个页签：**收款单（付款单）** 和 **折让记录**。

![收款单列表](/images/manual/fin/receipt-list.jpg)

![付款单列表](/images/manual/fin/payment-list.jpg)

## 列表

查询条件：客户（供应商）、单号。

| 列 | 说明 |
| --- | --- |
| 单号 | 收款单以 SK 开头，付款单以 FK 开头；点击查看详情 |
| 客户 / 供应商 | 往来单位 |
| 日期 | 收款 / 付款日期 |
| 金额 | 实收 / 实付的人民币金额；外币时下方显示原币金额和汇率；有折让时显示「折让 金额」，多收转预收时显示「转预收 金额」（付款为「转预付」） |
| 结算账户 | 库存现金或银行存款下的末级科目 |
| 方式 | 结算方式：银行转账、现金、承兑汇票、票据、支付宝 / 微信 |
| 凭证 | 已生成时显示凭证号；付款单审批中或已拒绝时显示审批状态；否则显示「未生成」 |
| 制单人 | 录入人 |
| 操作 | 查看；未生成凭证且不在审批中的单据可删除 |

## 新增收款单 / 付款单

点击「**新增收款单**」（「**新增付款单**」）打开录入页。

![新增收款单](/images/manual/fin/receipt-add.jpg)

### 表头字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 客户 / 供应商 | 是 | 选择后下方列出该单位所有**未核销**的应收单 / 应付单，按单据日期从早到晚排列，并默认全部勾选 |
| 收款日期 / 付款日期 | 是 | 默认今天；所在期间必须未结账 |
| 结算方式 | 否 | 默认银行转账。「票据」在下拉中置灰并注明「（由票据业务自动生成）」，手工收付款不能选择（提示「票据结算的收付款单由票据业务自动生成，请在票据管理中办理」） |
| 结算账户 | 是 | 只能选库存现金（默认 1001）、银行存款（默认 1002）下的末级科目，范围按[凭证科目设置](./account-rule#货币资金科目范围)的「货币资金」识别 |
| 备注 | 否 | |
| 汇率 | 外币时必填 | 核销外币单据时出现，按收付款日期所在月份的汇率自动带出，未维护时需手工填写 |

### 单据表格

| 列 | 说明 |
| --- | --- |
| 勾选框 | 勾选的单据参与本次收付款；表格上方显示「已勾选 N 张，未核销合计 ¥…」 |
| 单号、来源、单据日期、到期日 | 应收应付单的信息；来源为退货、冲账单等的红字单据金额为负数 |
| 金额、未核销 | 外币单据显示原币，下方显示折算的人民币和记账汇率 |
| 本次核销 | 本次核销该单据的金额，只有勾选的单据可以填写 |
| 折让 / 抹零 | 本次给该单据的优惠或抹零金额，见下文[折让与抹零](#折让与抹零) |

### 操作步骤

1. 选择客户（供应商），系统列出未核销单据并全部勾选，「**本次收款**」（「**本次付款**」）默认为勾选单据的未核销合计。
2. 按实际到账金额修改「本次收款」，取消勾选本次不处理的单据。
3. 点击「**自动核销**」：系统先用勾选的红字单据（退货、冲账单）冲抵，再把金额按单据日期从早到晚（同一天按到期日）分配到勾选的单据，早的欠款先结清。也可以点「**全部核销**」，把勾选的蓝字单据的未核销余额（扣除已填的折让）全部填满，红字单据同样冲抵，本次收款同步改为核销合计；或者直接在「本次核销」中逐笔填写。红字单据的冲抵规则见下文[核销规则](#核销规则)。
4. 需要折让、抹零的单据在「折让 / 抹零」中填写金额（填写后再点「全部核销」或「自动核销」，已填的折让会保留）。
5. 核对右上方的「核销合计」「折让合计」：
   - 本次收款等于核销合计：可以直接保存；
   - 本次收款**大于**核销合计：黄色提示「本次金额比核销合计多 ¥…」，须勾选「**多收部分转为预收款**」（付款为「多付部分转为预付款」）才能保存，见[多收转预收预付](#多收转预收预付)；
   - 本次收款**小于**核销合计：红色提示「核销合计比本次金额多 ¥…，请调整核销金额或本次金额」，不能保存。
6. 点击「**确认收款**」（「**确认付款**」），保存后立即核销，单据的已核销金额和状态随之更新。

### 核销规则

- 本次核销金额必须与单据金额同号：正数单据填正数，**红字单据（退货、冲账单等）填负数，用来冲抵**；核销金额加折让的绝对值不能超过单据的未核销金额。
- 收付款金额（实收实付）= 各单据本次核销金额之和，**不能小于 0**。红字单据恰好抵消欠款时可以为 0，例如[冲账单](./offset)的金额足以抵扣欠款，不需要再收付款。
- 「自动核销」「全部核销」时，红字单据冲抵的总额**不超过勾选的蓝字欠款合计**，按单据日期从早到晚冲抵，冲不完的红字单据（或其剩余部分）留到下次核销。因此冲账、退货金额大于欠款时，也可以直接点「自动核销」后确认，不需要手工修改核销金额。
- 一张收付款单只能核销**同一往来单位、同一币种**的单据；已勾选某币种的单据后，其他币种的单据不能再勾选（打开时默认只勾选与第一张单据同币种的单据）。

### 折让与抹零

客户付款时临时要求的优惠、零头抹去，或者付款给供应商时对方同意的让利，不需要修改出入库单，在核销时填写折让即可：

- 折让与单据同号，单据的已核销 = 本次核销 + 折让，核销金额加折让不能超过未核销金额；
- 核销金额可以为 0，只填折让，即把这张单据的余额整笔抹去；
- 折让不计入实收实付金额，单独记入收付款单的「折让合计」，应收应付单「已核销」列下方显示「折让 金额」；
- 账龄分析、[往来对账单](./partner-statement)按 核销 + 折让 减少余额；销售提成的回款只计实收部分，不含折让；
- 生成凭证时折让计入「收款折让 / 抹零」「付款折让 / 抹零」科目（默认财务费用，可在[凭证科目设置](./account-rule#折让与冲账科目)中改为销售费用等）。

### 多收转预收预付

本次收款大于核销合计时，多出的部分可以勾选「多收部分转为预收款」（付款为「多付部分转为预付款」）：

- 保存时自动生成一张[预收预付](./advance)单，金额为多出的部分，日期、结算账户、结算方式与收付款单相同，备注为「收付款单号 多收付转入」，并按登记预收预付的规则立即生成凭证；
- 收付款单列表显示「转预收 金额」，详情显示「多收部分转为预收款」的金额和预收预付单号；
- 启用了付款审批时，多付的部分在**审批通过后**才生成预付单；
- 删除收付款单时，转入的预收预付单一并删除（预收预付已冲抵或其凭证已审核时不能删除）。

### 外币核销

核销外币单据时，本次收付款金额、本次核销、折让都填写**原币金额**：

- 往来单据按其**记账汇率**冲销；原币全部核销完时取剩余的本位币金额，避免尾差；
- 折让按单据记账汇率折算为本位币后入账，折让科目按本位币金额记账；
- 实收 / 实付本位币 = 原币合计 × 本次汇率，页面显示「原币 USD …，实收本位币 ¥…」；
- 核销金额的本位币与实收实付本位币的差额在生成凭证时计入**财务费用（汇兑损益）**，汇兑损益只来自实收实付部分；
- 外币多收、多付转为**同币种**的预收预付单，按本次汇率登记。

## 付款审批

系统内置「付款审批」流程（财务主管 → 金额 ≥ 10 万元时总经理 → 抄送出纳，默认未发布）。流程变量「付款金额」是这笔付款**实际付出的本位币金额**：核销合计加上多付转为预付款的金额，外币按付款单的汇率折算。多付转预付的部分同样计入，大额付款不会因为转为预付而绕过金额条件。在[流程中心](../workflow/model)发布后：

- 新增付款单保存后进入审批，状态为「审批中」，**暂不核销**应付单（保存时只校验未核销金额），不计入账龄，也不能生成凭证；
- 审批通过后核销应付单（含折让），多付的部分此时转为预付款；若此时金额已超过单据的未核销金额，审批失败；
- 审批被拒绝或撤回后为「已拒绝」，没有核销过，可以删除后重新录入；
- 审批中的付款单不能删除，需先在「[我的申请](../workflow/mine#撤回申请)」中撤回。

收款单不走审批。

## 详情

点击单号或「查看」打开详情，显示往来单位、日期、实收金额（实付金额）、折让合计（外币另显示原币）、多收转预收的金额和预收单号、原币 / 汇率、结算账户、结算方式、凭证号、制单人和时间、备注，以及核销明细（核销单据、来源单号、单据日期、单据金额、本次核销、折让 / 抹零）。

## 折让记录

「折让记录」页签列出**已生效**的收付款中填写过折让的核销明细，便于统计给客户的优惠和供应商的让利。

![折让记录](/images/manual/fin/receipt-discounts.jpg)

- 查询条件：客户（供应商）、日期范围、收付款单号 / 原单据号；
- 列：日期、单号（点击打开收付款单详情）、客户（供应商）、原单据（单号和来源）、折让金额（外币另显示原币）、经办人（收付款单的制单人）、备注；
- 点「**导出**」按当前条件导出 Excel（「收款折让记录」「付款折让记录」），原单据的来源单号、外币原币单独成列。

审批中、已拒绝的付款单不在折让记录中。

## 生成凭证

勾选已生效（非审批中、非已拒绝）且未生成凭证的单据，点击「**生成凭证（N）**」：

| 单据 | 分录 |
| --- | --- |
| 收款单 | 借 结算账户（银行存款 / 库存现金）、收款折让 / 抹零（有折让时）/ 贷 应收账款（客户辅助核算，金额 = 核销 + 折让） |
| 付款单 | 借 应付账款（供应商辅助核算，金额 = 核销 + 折让）/ 贷 结算账户、付款折让 / 抹零（有折让时） |
| 外币差额 | 计入财务费用（收款多收、付款少付为汇兑收益，冲减财务费用） |
| 红字单据恰好抵消欠款（金额为 0） | 不涉及资金：应收账款（应付账款）按蓝字、红字单据分两行相互冲抵 |

凭证摘要为「收到 / 支付 往来单位 货款」，折让分录摘要后加「折让」。多收转入的预收预付款在登记时已单独生成凭证，不在收付款凭证中。

## 删除

- 只能删除**未生成凭证**的收付款单；已生成凭证的需先在凭证管理中删除（未审核的）凭证。
- 删除已生效的收付款单时，**恢复**被核销单据的未核销金额（包括折让），并删除多收转入的预收预付单。
- 结算方式为「票据」的收付款单由票据业务生成，需在[票据管理](./note)中删除票据。
- 单据日期所在期间已结账时不能删除。

## 注意事项

::: tip 提示
- 有预收、预付款的往来单位，应在[预收预付](./advance)中冲抵应收应付单，不要再录入收付款单。
- 垫付运费、返利、三包赔偿等用来抵扣往来款的项目，先登记[冲账单](./offset)并复核，收付款时勾选生成的红字单据即可与欠款相抵。
- 结账检查会提示本月未生成凭证的收付款单。
:::

::: warning 注意
- 折让直接减少应收应付余额并计入费用，不改变出入库单金额，因此不影响销售、进货报表；需要调整商品售价的，应走退货或在订单中处理。
- 「转为预收 / 预付款」只能在新增时勾选；保存后发现多收，需要删除收付款单后重新录入。
:::
