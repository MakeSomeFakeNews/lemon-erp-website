# 收款单与付款单

收款单记录收到客户的货款并核销应收单，付款单记录支付供应商的款项并核销应付单。出纳、会计使用。两个页面结构相同。

## 页面入口

- 财务 → 应收应付 → 收款单
- 财务 → 应收应付 → 付款单

![收款单列表](/images/manual/fin/receipt-list.jpg)

![付款单列表](/images/manual/fin/payment-list.jpg)

## 列表

查询条件：客户（供应商）、单号。

| 列 | 说明 |
| --- | --- |
| 单号 | 收款单以 SK 开头，付款单以 FK 开头；点击查看详情 |
| 客户 / 供应商 | 往来单位 |
| 日期 | 收款 / 付款日期 |
| 金额 | 人民币金额；外币时下方显示原币金额和汇率 |
| 结算账户 | 库存现金或银行存款下的末级科目 |
| 方式 | 结算方式：银行转账、现金、承兑汇票、票据、支付宝 / 微信 |
| 凭证 | 已生成时显示凭证号；付款单审批中或已拒绝时显示审批状态；否则显示「未生成」 |
| 制单人 | 录入人 |
| 操作 | 查看；未生成凭证且不在审批中的单据可删除 |

## 新增收款单 / 付款单（核销规则）

![新增收款单](/images/manual/fin/receipt-add.jpg)

### 表头字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 客户 / 供应商 | 是 | 选择后下方列出该单位所有**未核销**的应收单 / 应付单，按到期日排序 |
| 收款日期 / 付款日期 | 是 | 默认今天；所在期间必须未结账 |
| 结算方式 | 否 | 默认银行转账。「票据」在下拉中置灰并注明「（由票据业务自动生成）」，手工收付款不能选择（提示「票据结算的收付款单由票据业务自动生成，请在票据管理中办理」） |
| 结算账户 | 是 | 只能选库存现金（默认 1001）、银行存款（默认 1002）下的末级科目，范围按[凭证科目设置](./account-rule#货币资金科目范围)的「货币资金」识别 |
| 备注 | 否 | |
| 汇率 | 外币时必填 | 核销外币单据时出现，按收付款日期所在月份的汇率自动带出，未维护时需手工填写 |

### 核销规则

1. 在单据表格的「**本次核销**」中填写每张单据本次核销的金额，或点「**全部核销**」把所有单据的未核销余额填满。
2. 本次核销金额必须与单据金额同号：正数单据填正数，**红字单据（退货等）填负数，用来冲抵**；绝对值不能超过单据的未核销金额。
3. 收付款金额 = 各单据本次核销金额之和，必须**大于 0**（红字冲抵后）。页面右上方实时显示「本次收款 / 本次付款」。
4. 一张收付款单只能核销**同一往来单位、同一币种**的单据；已填写某币种的单据后，其他币种的单据不能再填。
5. 点击「**确认收款 / 确认付款**」，保存后立即核销，单据的已核销金额和状态随之更新。

### 外币核销

核销外币单据时，「本次核销」填写的是**原币金额**：

- 往来单据按其**记账汇率**冲销；原币全部核销完时取剩余的本位币金额，避免尾差。
- 实收 / 实付本位币 = 原币合计 × 本次汇率。
- 两者的差额在生成凭证时计入**财务费用（汇兑损益）**。

## 付款审批

系统内置「付款审批」流程（财务主管 → 金额 ≥ 10 万元时总经理 → 抄送出纳，默认未发布）。在[流程中心](../workflow/model)发布后：

- 新增付款单保存后进入审批，状态为「审批中」，**暂不核销**应付单（保存时只校验未核销金额），不计入账龄，也不能生成凭证；
- 审批通过后核销应付单；若此时金额已超过单据的未核销金额，审批失败；
- 审批被拒绝或撤回后为「已拒绝」，没有核销过，可以删除后重新录入；
- 审批中的付款单不能删除，需先在「[我的申请](../workflow/mine#撤回申请)」中撤回。

收款单不走审批。

## 详情

点击单号或「查看」打开详情，显示往来单位、日期、金额（外币显示原币 / 汇率）、结算账户、结算方式、凭证号、制单人和时间、备注，以及核销明细（核销单据、来源单号、单据日期、单据金额、本次核销）。

![付款单详情](/images/manual/fin/payment-detail.jpg)

## 生成凭证

勾选已生效（非审批中、非已拒绝）且未生成凭证的单据，点击「**生成凭证（N）**」：

| 单据 | 分录 |
| --- | --- |
| 收款单 | 借 结算账户（银行存款 / 库存现金）/ 贷 应收账款（客户辅助核算） |
| 付款单 | 借 应付账款（供应商辅助核算）/ 贷 结算账户 |
| 外币差额 | 计入财务费用（收款多收、付款少付为汇兑收益，冲减财务费用） |

凭证摘要为「收到 / 支付 往来单位 货款」。

## 删除

- 只能删除**未生成凭证**的收付款单；已生成凭证的需先在凭证管理中删除（未审核的）凭证。
- 删除已生效的收付款单时，**恢复**被核销单据的未核销金额。
- 结算方式为「票据」的收付款单由票据业务生成，需在[票据管理](./note)中删除票据。
- 单据日期所在期间已结账时不能删除。

## 注意事项

::: tip 提示
- 有预收、预付款的往来单位，应在[预收预付](./advance)中冲抵应收应付单，不要再录入收付款单。
- 结账检查会提示本月未生成凭证的收付款单。
:::
