# 收款单与付款单

收款单记录收到客户的货款并核销应收单，付款单记录支付供应商的款项并核销应付单。录入时输入本次收付款金额，系统自动分配到各张单据；客户临时要求的优惠、抹零可以在核销时直接作为折让处理，多收、多付的部分可以转为预收、预付款，已有的预收、预付款也可以在收付款时一起冲抵。可以设置为先存草稿、确认后生效。出纳、会计使用，两个页面结构相同。

## 页面入口

- 财务 → 应收应付 → 收款单
- 财务 → 应收应付 → 付款单

页面有两个页签：**收款单（付款单）** 和 **折让记录**。

![收款单列表](/images/manual/fin/receipt-list.jpg)

![付款单列表](/images/manual/fin/payment-list.jpg)

## 新增收款单 / 付款单

点击「**新增收款单**」（「**新增付款单**」）打开录入页。

![新增收款单](/images/manual/fin/receipt-add.jpg)

| 备注 | 否 | |
| 汇率 | 外币时必填 | 核销外币单据时出现，按收付款日期所在月份的汇率自动带出，未维护时需手工填写 |

### 单据表格

| 列 | 说明 |
| --- | --- |
| 勾选框 | 勾选的单据参与本次收付款；表格上方显示「已勾选 N 张，未核销合计 ¥…」 |
| 单号、来源、单据日期、到期日 | 应收应付单的信息；来源为退货、冲账单等的红字单据金额为负数；来源单号可以点击打开来源单据，见[来源单据穿透](./ar-ap#来源单据穿透) |
| 金额、未核销 | 外币单据显示原币，下方显示折算的人民币和记账汇率 |
| 本次核销 | 本次核销该单据的金额，只有勾选的单据可以填写 |
| 折让 / 抹零 | 本次给该单据的优惠或抹零金额，见下文[折让与抹零](#折让与抹零) |

### 操作步骤

1. 选择客户（供应商），系统列出未核销单据并全部勾选，「**本次收款**」（「**本次付款**」）默认为勾选单据的未核销合计。
2. 按实际到账金额修改「本次收款」，取消勾选本次不处理的单据。
3. 点击「**自动核销**」：系统先用勾选的红字单据（退货、冲账单）冲抵，再把金额按单据日期从早到晚（同一天按到期日）分配到勾选的单据，早的欠款先结清。也可以点「**全部核销**」，把勾选的蓝字单据的未核销余额（扣除已填的折让）全部填满，红字单据同样冲抵，本次收款同步改为核销合计；或者直接在「本次核销」中逐笔填写。红字单据的冲抵规则见下文[核销规则](#核销规则)。
4. 需要折让、抹零的单据在「折让 / 抹零」中填写金额（填写后再点「全部核销」或「自动核销」，已填的折让会保留）。
5. 需要用预收（预付）款一起冲抵时，在下方「冲抵预收款」表格中勾选，见[冲抵预收预付](#冲抵预收预付)。
6. 核对右上方的「核销合计」「折让合计」（有冲抵时另显示冲抵金额和实收金额）：
   - 本次收款等于实收金额（没有冲抵时即核销合计）：可以直接保存；
   - 本次收款**大于**核销合计：黄色提示「本次金额比核销合计多 ¥…」，须勾选「**多收部分转为预收款**」（付款为「多付部分转为预付款」）才能保存，见[多收转预收预付](#多收转预收预付)；
   - 本次收款**小于**核销合计：红色提示「核销合计比本次金额多 ¥…，请调整核销金额或本次金额」，不能保存。
7. 点击「**确认收款**」（「**确认付款**」），保存后立即核销，单据的已核销金额和状态随之更新。开启了「收付款先存草稿」时按钮为「保存草稿」「保存并确认收款」，见[草稿与确认](#草稿与确认)。

还没有填写任何核销金额就点保存时，系统先按「本次收款」自动核销再保存。

### 核销规则

- 本次核销金额必须与单据金额同号：正数单据填正数，**红字单据（退货、冲账单等）填负数，用来冲抵**；核销金额加折让的绝对值不能超过单据的未核销金额。
- 收付款金额（实收实付）= 各单据本次核销金额之和 − 冲抵的预收预付，**不能小于 0**。红字单据或预收预付恰好抵消欠款时可以为 0，见[实收为 0 的收付款](#实收为-0-的收付款)。
- 「自动核销」「全部核销」时，红字单据冲抵的总额**不超过勾选的蓝字欠款合计**，按单据日期从早到晚冲抵，冲不完的红字单据（或其剩余部分）留到下次核销。因此冲账、退货金额大于欠款时，也可以直接点「自动核销」后确认，不需要手工修改核销金额。
- 一张收付款单只能核销**同一往来单位、同一币种**的单据；已勾选某币种的单据后，其他币种的单据不能再勾选（打开时默认只勾选与第一张单据同币种的单据）。

### 折让与抹零

客户付款时临时要求的优惠、零头抹去，或者付款给供应商时对方同意的让利，不需要修改出入库单，在核销时填写折让即可：

- 折让与单据同号，单据的已核销 = 本次核销 + 折让，核销金额加折让不能超过未核销金额；
- 核销金额可以为 0，只填折让，即把这张单据的余额整笔抹去；
- 折让不计入实收实付金额，单独记入收付款单的「折让合计」，应收应付单「已核销」列下方显示「折让 金额」；
- 账龄分析、[往来对账单](./partner-statement)按 核销 + 折让 减少余额；销售提成的回款只计实收部分，不含折让；
- 生成凭证时折让计入「收款折让 / 抹零」「付款折让 / 抹零」科目（默认财务费用，可在[凭证科目设置](./account-rule#折让与冲账科目)中改为销售费用等）。

### 多收转预收预付

本次收款大于核销合计时，多出的部分可以勾选「多收部分转为预收款」（付款为「多付部分转为预付款」）：

- 保存时自动生成一张[预收预付](./advance)单，金额为多出的部分，日期、结算账户、结算方式与收付款单相同，备注为「收付款单号 多收付转入」，并按登记预收预付的规则立即生成凭证；
- 收付款单列表显示「转预收 金额」，详情显示「多收部分转为预收款」的金额和预收预付单号；
- 启用了付款审批时，多付的部分在**审批通过后**才生成预付单；
- 删除收付款单时，转入的预收预付单一并删除（预收预付已冲抵或其凭证已审核时不能删除）。

### 冲抵预收预付

往来单位有未冲抵完的预收（预付）款时，可以在收付款单中勾选，与欠款一起冲抵，不需要先到[预收预付](./advance)页面单独冲抵：

1. 选择客户（供应商）后，单据表格下方出现「**冲抵预收款**」（付款为「**冲抵预付款**」）表格，列出该单位未冲抵完的预收预付单：预收预付单号、日期、备注、未冲抵余额、本次冲抵。没有可冲抵的预收预付时不显示这个表格。
2. 勾选要冲抵的预收预付单，「本次冲抵」自动填入 min(未冲抵余额, 勾选单据中还没有被冲抵的欠款)，可以修改，不能超过未冲抵余额。
3. 表格上方的合计行显示「冲抵预收 ¥X · 实收金额 ¥Y」，「本次收款」（用户没有改过时）自动改为扣除冲抵后的金额。
4. 点「自动核销」时，系统把 本次收款 + 冲抵金额 一起分配到勾选的单据。

![新增收款单中勾选预收款冲抵](/images/manual/fin/receipt-advance-offset.jpg)

规则：

- **本次实收 = 核销合计 − 冲抵合计**（付款为本次实付），冲抵金额不能超过核销合计，超过时红色提示「冲抵的预收预付比核销合计多 ¥…，请减少冲抵金额或增加核销金额」；
- 冲抵预收预付时**不能同时**勾选「多收部分转为预收款」：本次金额比实收多时提示「本次金额比实收实付多 ¥…：冲抵预收预付时不能再把多收的部分转为预收预付，请调整本次金额」；
- 外币只能冲抵与核销单据**同币种**的预收预付，其他币种的预收预付不能勾选（悬停提示「只能冲抵与核销单据同币种（USD）的预收预付」）；
- 冲抵金额按单据日期从早到晚分配到勾选的蓝字单据，详情的核销明细中「冲抵预收」（「冲抵预付」）列显示每张单据分到的冲抵金额；
- 收付款单**生效时**才真正冲抵（草稿、审批中的付款单不冲抵），冲抵记录登记在预收预付单的「冲抵记录」中，不单独生成冲抵凭证，并入收付款凭证（见下文[生成凭证](#生成凭证)）；
- 被收付款草稿或审批中的付款单选用的预收预付单不能删除，提示「预收预付单 … 已被收付款单选用（草稿或审批中），请先在收付款单中取消选用」；
- 删除已生效的收付款单时，冲抵一并撤销，预收预付恢复未冲抵余额。

### 实收为 0 的收付款

欠款与红字单据（冲账单、退货、返利等）正好相抵，或者欠款全部由预收预付冲抵时，本次实收（实付）为 0，也可以保存一张收付款单，用来完成核销：

- 例如客户欠款 1000 元，又有一张 -1000 元的冲账单：勾选两张单据，本次收款为 0，直接点「确认收款」即可；
- 还没有填写核销金额就提交时，系统先按本次金额自动核销再保存，因此本次金额为 0 时也能把蓝字、红字单据配对核销；
- 页面显示蓝色提示「实收为 0：欠款与红字单据（冲账、退货）正好抵消，不发生资金收付，凭证为应收账款的冲抵分录」，全部由预收款冲抵时为「实收为 0：欠款全部由预收款冲抵，不发生资金收付，凭证为 借 预收账款 / 贷 应收账款」（付款为对应的应付分录）；
- 必须至少有一张核销单据。

### 外币核销

核销外币单据时，本次收付款金额、本次核销、折让都填写**原币金额**：

- 往来单据按其**记账汇率**冲销；原币全部核销完时取剩余的本位币金额，避免尾差；
- 折让按单据记账汇率折算为本位币后入账，折让科目按本位币金额记账；
- 实收 / 实付本位币 = 原币合计 × 本次汇率，页面显示「原币 USD …，实收本位币 ¥…」；
- 核销金额的本位币与实收实付本位币的差额在生成凭证时计入**财务费用（汇兑损益）**，汇兑损益只来自实收实付部分；
- 外币多收、多付转为**同币种**的预收预付单，按本次汇率登记。

## 草稿与确认

默认情况下收付款单**保存即生效**。需要「出纳录入、会计确认」分工的企业，可以在「系统管理 → [业务参数](../system/biz-rule#收付款先存草稿)」的「财务」页签中开启「**收付款先存草稿**」（默认关闭）。开启后：

| 环节 | 说明 |
| --- | --- |
| 录入 | 录入页底部的按钮变为「**保存草稿**」和「**保存并确认收款**」（付款为「保存并确认付款」）。保存草稿后提示「草稿已保存，确认后生效」；「保存并确认」需要确认按钮权限，没有时只显示「保存草稿」 |
| 草稿 | 状态为「草稿」，**不核销**任何单据、不冲抵预收预付、不生成多收转入的预收预付，也不计入账龄、往来对账单、往来汇总、折让记录，不能生成凭证。可以「编辑」「删除」 |
| 修改 | 列表或详情中点「**修改**」，打开「修改收款单」（「修改付款单」）页，按原单据带出核销金额、折让和冲抵的预收预付，可以重新调整 |
| 确认 | 列表行末的「**确认**」图标或详情中的「**确认**」按钮，确认框标题为「确认 单号？」，说明「确认后核销应收单、冲抵勾选的预收款（多收的部分转为预收款），之后只能删除重做（凭证未审核时）」；确认时按最新的未核销余额重新校验，成功后提示「已确认」，单据生效 |

![收款单列表中的草稿和「确认」图标](/images/manual/fin/receipt-draft.jpg)

- 「编辑」需要收款单 / 付款单的新增权限，「确认」需要「**收款单确认**」「**付款单确认**」按钮权限（内置的会计、出纳角色都有）。
- 关闭参数后，保存即生效（只需新增权限），与以前一致；已经存在的草稿仍可修改、确认或删除。
- 结算方式为「票据」的收付款单由票据业务生成，不存草稿。

## 付款审批

系统内置「付款审批」流程（财务主管 → 金额 ≥ 10 万元时总经理 → 抄送出纳，默认未发布）。流程变量「付款金额」是这笔付款**实际付出的本位币金额**：实付金额（核销合计 − 冲抵的预付款）加上多付转为预付款的金额，外币按付款单的汇率折算。多付转预付的部分同样计入，大额付款不会因为转为预付而绕过金额条件；用预付款冲抵的部分不需要付钱，不计入。在[流程中心](../workflow/model)发布后：

- 付款单生效时（未开启草稿时为保存时，开启草稿时为「确认」时）进入审批，状态为「审批中」，**暂不核销**应付单、不冲抵预付款（提交时按最新余额校验），不计入账龄，也不能生成凭证；
- 审批通过后核销应付单（含折让）、冲抵勾选的预付款，多付的部分此时转为预付款；若此时金额已超过单据的未核销金额，审批失败；
- 审批被拒绝或撤回后为「已拒绝」，没有核销过，可以「**修改**」后再次提交（未开启草稿时保存即重新提交审批；开启草稿时保存为草稿，「确认」后重新提交），也可以删除；
- 审批中的付款单不能删除，需先在「[我的申请](../workflow/mine#撤回申请)」中撤回。

收款单不走审批。

## 详情

点击单号或行末的查看图标打开详情，显示往来单位、日期、实收金额（实付金额）、状态（草稿、审批中、已拒绝时显示）、折让合计（外币另显示原币）、多收转预收的金额和预收单号、冲抵预收（预付）的金额和预收预付单号、原币 / 汇率、结算账户、结算方式、凭证号、制单人和时间、备注，以及核销明细（核销单据、来源单号（可点击打开来源单据）、单据日期、单据金额、本次核销、折让 / 抹零、冲抵预收 / 冲抵预付）。草稿和已拒绝的付款单，详情底部有「编辑」按钮，草稿另有「确认」按钮。

![付款单详情](/images/manual/fin/payment-detail.jpg)

## 折让记录

「折让记录」页签列出**已生效**的收付款中填写过折让的核销明细，便于统计给客户的优惠和供应商的让利。

![折让记录](/images/manual/fin/receipt-discounts.jpg)

- 查询条件：客户（供应商）、日期范围、收付款单号 / 原单据号；
- 列：日期、单号（点击打开收付款单详情）、客户（供应商）、原单据（单号和来源）、折让金额（外币另显示原币）、经办人（收付款单的制单人）、备注；
- 点「**导出**」按当前条件导出 Excel（「收款折让记录」「付款折让记录」），原单据的来源单号、外币原币单独成列。

审批中、已拒绝的付款单不在折让记录中。

## 生成凭证

勾选已生效（非草稿、非审批中、非已拒绝）且未生成凭证的单据，点击「**生成凭证（N）**」：

| 单据 | 分录 |
| --- | --- |
| 收款单 | 借 结算账户（银行存款 / 库存现金）、收款折让 / 抹零（有折让时）/ 贷 应收账款（客户辅助核算，金额 = 核销 + 折让） |
| 付款单 | 借 应付账款（供应商辅助核算，金额 = 核销 + 折让）/ 贷 结算账户、付款折让 / 抹零（有折让时） |
| 外币差额 | 计入财务费用（收款多收、付款少付为汇兑收益，冲减财务费用） |
| 冲抵了预收预付 | 收款另借 预收账款（冲抵金额，按预收款的登记汇率折算）；付款另贷 预付账款。贷方应收账款（借方应付账款）= 核销 + 折让 + 冲抵 |
| 红字单据恰好抵消欠款（金额为 0） | 不涉及资金：应收账款（应付账款）按蓝字、红字单据分两行相互冲抵 |

凭证摘要为「收到 / 支付 往来单位 货款」，折让分录摘要后加「折让」。多收转入的预收预付款在登记时已单独生成凭证，不在收付款凭证中；在收付款中冲抵的预收预付不单独生成冲抵凭证，合并在这张凭证中，预收预付详情的冲抵记录也指向这张凭证。

## 删除

- 只能删除**未生成凭证**的收付款单；已生成凭证的需先在凭证管理中删除（未审核的）凭证。
- 删除已生效的收付款单时，**恢复**被核销单据的未核销金额（包括折让），撤销在收付款中冲抵的预收预付，并删除多收转入的预收预付单。
- 草稿、已拒绝的付款单没有核销过，直接删除。
- 结算方式为「票据」的收付款单由票据业务生成，需在[票据管理](./note)中删除票据。
- 单据日期所在期间已结账时不能删除。

## 注意事项

::: tip 提示
- 有预收、预付款的往来单位，可以在[预收预付](./advance)中单独冲抵应收应付单，也可以在收付款单中[一起冲抵](#冲抵预收预付)；不要把已预收的款项再录一次收款。
- 往来单位当前欠多少、预收多少，可以在应收应付的[往来汇总](./ar-ap#往来汇总)中查看。
- 垫付运费、返利、三包赔偿等用来抵扣往来款的项目，先登记[冲账单](./offset)并复核，收付款时勾选生成的红字单据即可与欠款相抵。
- 结账检查会提示本月未生成凭证的收付款单。
:::

::: warning 注意
- 折让直接减少应收应付余额并计入费用，不改变出入库单金额，因此不影响销售、进货报表；需要调整商品售价的，应走退货或在订单中处理。
- 已生效的收付款单不能修改；发现金额有误、需要转预收时，删除后重新录入（凭证已生成的先删除凭证）。草稿和已拒绝的付款单可以直接修改。
:::
