# 凭证科目设置

设置业务单据自动生成凭证时各用途使用的会计科目，例如哪些科目是库存现金和银行存款、应收账款记哪个科目、存货按物料分类记到哪个科目、工资费用按职位类别记到哪个费用科目、其他出入库按收发类别记到哪个对方科目。不设置时使用系统预置的科目。会计、财务主管在系统上线时设置，之后很少变动。

## 页面入口

财务 → 期末与设置 → 凭证科目设置

![凭证科目设置](/images/manual/fin/account-rule.jpg)

## 页面说明

页面按用途分为 8 个页签：**货币资金**、**往来**、**存货与成本**、**收入与费用**、**税费**、**资产**、**薪酬**、**期末**。每个用途一行，显示用途名称和一个科目选择框：

- 选择框为空时，灰色提示「预置：科目编码 科目名称」，即当前实际使用的预置科目；预置科目在会计科目中不存在或不是末级时提示「（科目不存在或不是末级）」。
- 设置过的用途名称后显示蓝色「已设置」标签；修改后还没保存的显示橙色「未保存」标签。
- 只能选择**启用的末级科目**（「货币资金」页签的两个用途除外，见下文），可按编码或名称搜索；清空选择框即恢复使用预置科目。
- 「其他入库对方科目」「其他出库对方科目」没有设置时，灰色提示为「同「待处理财产损溢（盘盈盘亏）」：科目」，即沿用待处理财产损溢的设置。

页面占满内容区，用途较多时只有中间的设置区域滚动，以下按钮固定在页面底部，随时可以点击：

| 按钮 | 作用 |
| --- | --- |
| **放弃修改** | 撤销所有未保存的修改，恢复为已保存的设置 |
| **保存（N）** | 保存所有修改过的用途，N 为有修改的用途数 |

没有「科目设置修改」权限的用户只能查看，选择框不可修改，也不显示这两个按钮。

## 货币资金科目范围

「库存现金」「银行存款」与其他用途不同，设置的是一个**科目范围**：所选科目及其全部下级科目都属于该用途，因此**可以选择上级科目**（例如 1002 银行存款下按银行开设了明细科目时，选 1002 即可包含全部银行账户）。只校验科目是启用状态，停用的科目提示「科目「编码 名称」已停用」。选择框下方提示「设置的科目及其全部下级都属于该用途，可以选择上级科目；收付款的结算账户、银行对账、现金流量表、资金计划按此识别」。

这两个用途不用于生成凭证分录，而是用来识别哪些科目是现金、银行存款：

| 使用场景 | 说明 |
| --- | --- |
| [收款单 / 付款单](./settlement) | 结算账户只能选择库存现金或银行存款范围内的科目 |
| [出纳管理](./cashier) | 现金日记账、银行日记账取这两个范围内的科目 |
| [银行对账](./bank) | 银行科目取银行存款范围内的科目 |
| [财务报表](./report)的现金流量表、[资金计划](./fund-plan) | 按这两个范围识别现金及现金等价物 |

不设置时使用预置的 1001 库存现金、1002 银行存款（含其下级科目）。

## 按物料分类、职位类别、收发类别分别设置

![存货按物料分类设置](/images/manual/fin/account-rule-inventory.jpg)

「存货」「主营业务收入」「主营业务成本」下方列出全部物料分类（原材料、半成品、成品、包装材料、其他、低值易耗品等，来自字典「物料分类」）；「工资费用」下方列出全部职位类别（管理、技术、生产、销售、职能，来自字典「职位类别」）；「其他入库对方科目」下方列出全部入库类别、「其他出库对方科目」下方列出全部出库类别（来自[业务字典](../system/biz-dict)「入库类别」「出库类别」）。每个分类可以单独选择科目；在业务字典中新增的分类会自动出现在这里。

取科目的优先顺序：

1. 该分类单独设置的科目；
2. 没有单独设置时，使用该用途上方设置的科目（分类选择框提示「同上：…」）；
3. 用途也没有设置时，使用该分类的预置科目（提示「预置：…」）；其他出入库对方科目没有预置科目，沿用「待处理财产损溢（盘盈盘亏）」的设置（提示「同「待处理财产损溢（盘盈盘亏）」：…」）。

::: warning 注意
为「存货」或「工资费用」设置了用途科目后，**没有单独设置的分类也会改用这个科目**，不再按分类区分预置科目。例如把存货设为 1403 原材料后，半成品、成品、低值易耗品也会记到 1403，除非再分别为它们选择科目。
:::

各分类设置用在：

| 用途 | 使用场景 |
| --- | --- |
| 存货 | 采购入库应付单的凭证（借 存货）、[成本核算](./cost)的成本结转凭证、[期初余额](./opening)中存货期初与科目期初的核对、[经营分析](./analysis#存货对账)的存货对账 |
| 主营业务收入 | 销售出库、销售退货应收单的凭证，按物料分类分摊不含税金额 |
| 主营业务成本 | 成本结转凭证中的销售成本；制造费用差异、关闭工单损失使用用途上方的科目 |
| 工资费用 | [工资表](../hr/payroll#生成计提凭证)计提凭证、[项目月结](../pm/accounting#项目月结)的人工成本，按员工职位类别取科目 |
| 其他入库对方科目 / 其他出库对方科目 | [成本核算](./cost#成本结转凭证)的成本结转凭证中，其他出入库的对方科目，按单据的收发类别取科目，见下文 |

## 其他出入库对方科目

![其他出入库对方科目](/images/manual/fin/account-rule-io-category.jpg)

仓库手工做的[其他入库](../wms/in#收发类别)、[其他出库和报废出库](../wms/out#收发类别)可以填写收发类别（入库类别、出库类别）。月末成本核算生成成本结转凭证时：

- 填写了类别的单据，按「数量 × 本期单位成本」拆出金额：其他入库 借 存货 / 贷 该类别的对方科目；其他出库、报废出库 借 该类别的对方科目 / 贷 存货；
- 没有填写类别的单据、盘盈盘亏，以及计价差额，仍计入「待处理财产损溢」；
- 存货科目的金额不受影响，只是把对方科目从待处理财产损溢中拆分出来；
- 供应商寄售仓的出入库不计存货成本，不参与拆分。

常见设置示例：福利领用 → 应付职工薪酬、研发领用 → 研发支出、办公领用 → 管理费用、赠品出库 / 样品出库 → 销售费用、受赠入库 → 营业外收入。

## 操作步骤

1. 打开「凭证科目设置」，切换到要调整的页签。
2. 在用途（或分类）的选择框中选择科目，用途名称后出现「未保存」。
3. 可以连续修改多个页签，最后点击页面底部的「**保存（N）**」，提示「已保存」。

## 注意事项

::: tip 提示
- 设置只影响**之后生成**的凭证，已经生成的凭证不会改变；需要按新科目重新生成的，可删除未审核的业务凭证后在来源单据中重新生成。
- 被设置引用的科目视为「已使用」：不能删除，也不能再增加下级科目。需要使用明细科目时，请先在[会计科目](./account)中建好明细科目，再在这里选择明细科目。
- 设置的科目被停用或增加了下级科目后，相关业务生成凭证时会提示「凭证科目设置『用途』：…」，请在这里改选其他末级科目。
- 系统上线时，可以在[期初余额](./opening#启用向导)的启用向导第 1 步确认本页设置。
:::
