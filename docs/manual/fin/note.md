# 票据管理

管理银行承兑汇票、商业承兑汇票的全流程：应收票据的收票、背书转让、贴现、托收、拒付，应付票据的开具和到期兑付。出纳、会计使用。

财务 → 资金与费用 → 票据管理

## 收票（应收票据）

客户以承兑汇票付款时登记：

1. 在「应收票据」下点击「**收票**」。
2. 填写：票据类型（必填，默认银行承兑汇票）、票据号码（必填，不能重复登记）、电子票据（默认是）、客户（必填）、票面金额（必填）、收票日期（必填）、出票日期（必填）、到期日期（必填，默认六个月后，不能早于出票日期）、承兑人、出票人、备注。
3. 在下方表格中填写要核销的**应收单**（只列人民币单据，红字单据为负数）。可点「**按金额自动分配**」，系统先用红字单据冲抵，再按到期日先后分配到票面金额。**核销合计必须等于票面金额**。
4. 点击「确认收票」。

系统生成一张结算方式为「票据」的收款单并核销应收单，票据状态为「持有」。该收款单可在[收款单](./settlement)中生成凭证：借 应收票据 / 贷 应收账款。

## 开具票据（应付票据）

以应付票据支付供应商：在「应付票据」下点击「**开具票据**」，字段同收票（开票日期替代收票日期，无出票人），核销供应商的**应付单**，合计等于票面金额。

系统生成结算方式为「票据」的付款单。启用付款审批时票据先为「开票审批中」，审批通过后变为「未兑付」，拒绝后变为「已作废」；未启用审批时直接为「未兑付」。付款单可生成凭证：借 应付账款 / 贷 应付票据。

## 办理

| 操作 | 填写 | 结果与凭证 |
| --- | --- | --- |
| 背书转让 | 供应商、背书日期、备注，核销供应商应付单（合计 = 票面金额） | 生成付款单并走付款审批；审批中为「背书审批中」，通过后「已背书」，拒绝后回到「持有」 |
| 贴现 | 日期、入账账户、年贴现率（按 360 天计息自动算贴现息，可直接修改贴现息）、备注 | 借 银行存款（实收）、财务费用（贴现息）/ 贷 应收票据；贴现息必须小于票面金额 |
| 托收 | 日期、入账账户、备注 | 借 银行存款 / 贷 应收票据 |
| 拒付 | 日期、备注 | 转回应收账款并生成一张来源为「票据拒付」的应收单，客户需重新付款；借 应收账款 / 贷 应收票据 |
| 到期兑付（应付票据） | 日期、付款账户、备注 | 借 应付票据 / 贷 银行存款 |

日期不能早于出票日期；贴现、托收、拒付、兑付直接生成凭证（未审核）。

## 详情

显示票据号码、类型（电子 / 纸质）、状态、收票客户 / 收款供应商、票面金额、承兑人、出票日期、到期日期、出票人、备注，以及**流转记录**：操作、对象（往来单位或账户）、金额（贴现息）、关联的收付款单、凭证、转回的应收单。

详情右上角：

- **撤销**：撤销最近一次贴现、托收、拒付或兑付，同时删除生成的凭证（凭证须未审核）。收票、背书、开票不能撤销，请在收付款单中处理或删除票据。
- **删除**：只有刚登记、还没有流转的票据（应收票据持有中，应付票据未兑付或已作废）可以删除，同时删除登记时生成的收付款单（须未生成凭证），往来单据恢复未核销。

## 到期提醒

系统默认每天上午 9:10 检查 7 天内到期仍未处理的票据，向有票据操作权限的人员发送站内消息：应收票据提醒托收，应付票据提醒备足资金兑付。

## 注意事项

::: tip 提示
- 票据只能核销人民币单据。
- 票据生成的收付款单只能在票据管理中删除；票据生成的凭证不能在凭证管理中直接删除。
- 持有的应收票据和未兑付的应付票据会计入[资金计划](./fund-plan)。
:::
