# 预收预付

登记发货前收到的客户预付款（预收）和收货前预先支付给供应商的款项（预付），并在应收应付单形成后进行冲抵（在本页冲抵，或在收付款单中一起冲抵）。支持外币预收预付；收付款时多收、多付的部分也会自动转为预收预付单。出纳、会计使用。

## 页面入口

财务 → 应收应付 → 预收预付

页面有两个页签：**预收（客户）**、**预付（供应商）**，右上角按钮随页签变为「登记预收」或「登记预付」。

![预收预付](/images/manual/fin/advance-list.jpg)

## 列表

查询条件：客户（供应商）、单号或备注、「只看有余额的」（只列出还有未冲抵余额的单据）。

| 列 | 说明 |
| --- | --- |
| 单号 | 预收以 YSK 开头，预付以 YFK 开头；点击查看详情 |
| 客户 / 供应商 | 往来单位 |
| 日期 | 收付款日期 |
| 结算账户 / 方式 | 结算科目和结算方式 |
| 金额 | 预收（预付）的人民币金额；外币时下方显示原币金额和汇率 |
| 已冲抵 | 已冲抵金额，下方显示剩余余额；外币单据均为原币 |
| 凭证 | 登记时生成的凭证号 |
| 备注 | |
| 操作 | 冲抵图标（有余额时）、删除图标（未冲抵时），鼠标悬停显示名称 |

## 登记预收 / 预付

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 客户 / 供应商 | 是 | |
| 日期 | 是 | 默认今天，所在期间必须未结账 |
| 币种 | 否 | 默认人民币（CNY），可选「币种汇率」中启用的外币 |
| 金额 | 是 | 大于 0；外币时填写原币金额，下方提示「折合本位币 ¥…」 |
| 汇率 | 外币时必填 | 标签为「汇率（1 USD = ? 人民币）」，按登记日期所在月份的记账汇率自动带出，未维护时提示「未维护汇率，请填写」 |
| 结算账户 | 是 | 库存现金、银行存款下的末级科目 |
| 结算方式 | 否 | 默认银行转账 |
| 备注 | 否 | 如「合同 HT-2026-001 定金」 |

![登记外币预收](/images/manual/fin/advance-add-foreign.jpg)

保存后立即生成凭证（未审核），外币按 原币 × 汇率 折算的本位币记账，摘要后附原币金额和汇率：

- 预收：借 结算账户 / 贷 预收账款（客户辅助核算）
- 预付：借 预付账款（供应商辅助核算）/ 贷 结算账户

### 由收付款多收转入

在[收款单 / 付款单](./settlement#多收转预收预付)中，本次收付款大于核销合计并勾选「多收部分转为预收款」（「多付部分转为预付款」）时，系统自动登记一张预收预付单：日期、结算账户、结算方式与收付款单相同，备注为「收付款单号 多收付转入」，外币收付款转为同币种、按收付款汇率登记。之后与手工登记的预收预付单一样冲抵；删除该收付款单时一并删除。

## 冲抵应收应付单

发货、收货形成应收应付单后，用预收预付款冲抵：

1. 在有余额的单据行点击行末的「**冲抵**」图标，打开冲抵页，页头显示往来单位、预收（预付）金额和可冲抵余额（外币为原币）。
2. 选择**冲抵日期**（默认今天，所在期间须未结账）。
3. 表格列出该往来单位未核销的应收单（应付单），**只列与预收预付同币种的正数单据**，红字单据不能用预收预付冲抵。在「本次冲抵」中填写金额，或点「**按到期日自动分配**」，系统按到期日先后把余额分配到各单据。
4. 页面显示「本次冲抵」合计，超过可冲抵余额时以红色提示。
5. 点击「**确认冲抵**」。

冲抵规则：每张单据的冲抵金额不能超过其未核销金额，合计不能超过预收预付余额。

**外币预收预付**只能冲抵同币种的单据（页面提示「外币预收预付只能冲抵 USD 单据，冲抵金额为原币；与单据记账汇率的差额计入财务费用（汇兑损益）」），冲抵金额为原币：

- 预收预付一方按其登记汇率折算本位币，原币冲抵完时取剩余的本位币；
- 应收应付单一方按单据的记账汇率折算本位币，原币核销完时取剩余的本位币；
- 两者的差额在冲抵凭证中计入财务费用（汇兑损益）。

外币预收预付属于非货币性项目，期末调汇不处理。

冲抵后核销对应的应收应付单，并生成一张凭证：

- 预收冲抵：借 预收账款 / 贷 应收账款
- 预付冲抵：借 应付账款 / 贷 预付账款
- 外币冲抵有汇率差时另加一行财务费用（汇兑损益）

## 在收付款中冲抵

除了在本页逐张冲抵，也可以在新增或修改[收款单 / 付款单](./settlement#冲抵预收预付)时勾选该单位的预收（预付）款，与本次收付款一起核销欠款，适合「部分用预收款、部分收现款」的情况：

| | 在本页冲抵 | 在收付款中冲抵 |
| --- | --- | --- |
| 操作入口 | 预收预付行末的「冲抵」图标 | 收付款录入页的「冲抵预收款」/「冲抵预付款」表格 |
| 可冲抵的单据 | 同币种的正数应收应付单 | 收付款单中勾选的单据（可与红字单据、现款一起核销），只能选与核销单据同币种的预收预付 |
| 生效时间 | 确认冲抵时立即生效 | 收付款单生效时：开启「收付款先存草稿」时为确认后，付款审批时为审批通过后 |
| 凭证 | 立即单独生成冲抵凭证（借 预收账款 / 贷 应收账款） | 不单独生成，并入收付款凭证（借 银行存款、预收账款 / 贷 应收账款） |
| 撤销 | 不能撤销 | 删除收付款单时自动撤销，预收预付恢复余额 |

在收付款中冲抵的记录同样出现在本页详情的「冲抵记录」中；收付款单生成凭证后，冲抵记录的凭证列显示这张收付款凭证。

被收付款**草稿**或**审批中**的付款单选用的预收预付单不能删除（提示「预收预付单 … 已被收付款单选用（草稿或审批中），请先在收付款单中取消选用」）；本页的冲抵仍可进行，金额以收付款单生效时的余额为准，余额不足时收付款单确认失败。

## 详情

显示往来单位、日期、金额（外币另显示原币和汇率）、已冲抵（余额）、结算账户、结算方式、凭证、备注，以及**冲抵记录**（冲抵单据、冲抵日期、金额、凭证；外币另显示冲抵的原币金额）。

## 删除

只有**未冲抵过**、且没有被收付款草稿或审批中的付款单选用的预收预付单可以删除，删除时同时删除登记时生成的凭证，该凭证必须还未审核（已审核的请先反审核）。预收预付生成的凭证不能在凭证管理中直接删除。由收付款多收转入的预收预付单，删除对应的收付款单时会一并删除。

## 与其他模块的联动

客户的[信用额度](../scm/sales#信用额度与账期)占用会扣减该客户未冲抵的预收款余额，即预收款越多，可用信用额度越大。
