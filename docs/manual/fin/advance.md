# 预收预付

登记发货前收到的客户预付款（预收）和收货前预先支付给供应商的款项（预付），并在应收应付单形成后进行冲抵。出纳、会计使用。

## 页面入口

财务 → 应收应付 → 预收预付

页面有两个页签：**预收（客户）**、**预付（供应商）**，右上角按钮随页签变为「登记预收」或「登记预付」。

![预收预付](/images/manual/fin/advance-list.jpg)

## 列表

查询条件：客户（供应商）、单号或备注、「只看有余额的」（只列出还有未冲抵余额的单据）。

| 列 | 说明 |
| --- | --- |
| 单号 | 预收以 YSK 开头，预付以 YFK 开头；点击查看详情 |
| 客户 / 供应商 | 往来单位 |
| 日期 | 收付款日期 |
| 结算账户 / 方式 | 结算科目和结算方式 |
| 金额 | 预收（预付）金额 |
| 已冲抵 | 已冲抵金额，下方显示剩余余额 |
| 凭证 | 登记时生成的凭证号 |
| 备注 | |
| 操作 | 「冲抵」（有余额时）、「删除」（未冲抵时） |

## 登记预收 / 预付

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 客户 / 供应商 | 是 | |
| 日期 | 是 | 默认今天，所在期间必须未结账 |
| 金额 | 是 | 大于 0 |
| 结算账户 | 是 | 库存现金、银行存款下的末级科目 |
| 结算方式 | 否 | 默认银行转账 |
| 备注 | 否 | 如「合同 HT-2026-001 定金」 |

保存后立即生成凭证（未审核）：

- 预收：借 结算账户 / 贷 预收账款（客户辅助核算）
- 预付：借 预付账款（供应商辅助核算）/ 贷 结算账户

## 冲抵应收应付单

发货、收货形成应收应付单后，用预收预付款冲抵：

1. 在有余额的单据行点击「**冲抵**」，打开冲抵页，页头显示往来单位、预收（预付）金额和可冲抵余额。
2. 选择**冲抵日期**（默认今天，所在期间须未结账）。
3. 表格列出该往来单位未核销的应收单（应付单），**只列正数单据**，红字单据不能用预收预付冲抵。在「本次冲抵」中填写金额，或点「**按到期日自动分配**」，系统按到期日先后把余额分配到各单据。
4. 页面显示「本次冲抵」合计，超过可冲抵余额时以红色提示。
5. 点击「**确认冲抵**」。

冲抵规则：每张单据的冲抵金额不能超过其未核销金额，合计不能超过预收预付余额；外币单据不能冲抵，请用收付款核销。

冲抵后核销对应的应收应付单，并生成一张凭证：

- 预收冲抵：借 预收账款 / 贷 应收账款
- 预付冲抵：借 应付账款 / 贷 预付账款

## 详情

显示往来单位、日期、金额、已冲抵（余额）、结算账户、结算方式、凭证、备注，以及**冲抵记录**（冲抵单据、冲抵日期、金额、凭证）。

## 删除

只有**未冲抵过**的预收预付单可以删除，删除时同时删除登记时生成的凭证，该凭证必须还未审核（已审核的请先反审核）。预收预付生成的凭证不能在凭证管理中直接删除。

## 与其他模块的联动

客户的[信用额度](../scm/sales#信用额度与账期)占用会扣减该客户未冲抵的预收款余额，即预收款越多，可用信用额度越大。
