# 资产盘点

按部门、存放地点生成固定资产盘点单，逐项核对实物，盘点完成后自动处理位置变化和盘亏资产。资产管理员、资产会计使用。

## 页面入口

财务 → 资产与成本 → 资产盘点

![资产盘点列表](/images/manual/fin/asset-check-list.jpg)

## 列表

查询条件：状态（盘点中、已完成）。

| 列 | 说明 |
| --- | --- |
| 盘点单号 | 以 ZCPD 开头，下方为盘点日期 |
| 范围 | 使用部门、存放地点；都未指定时为全部资产 |
| 进度 | 已盘数 / 总数 |
| 差异 | 位置变化、盘亏、盘盈的数量 |
| 状态 | 盘点中 / 已完成（显示完成时间） |
| 操作 | 盘点中显示「盘点」，已完成显示「查看」 |

## 新建盘点

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 盘点日期 | 是 | 默认今天 |
| 使用部门 | 否 | |
| 存放地点 | 否 | 模糊匹配，如「3 楼」 |
| 备注 | 否 | |

系统按范围列出所有未处置的资产，并**快照**账面的部门、使用人、存放地点。范围内没有资产时会提示。

## 逐项盘点

![资产盘点详情](/images/manual/fin/asset-check-detail.jpg)

详情页显示盘点日期、范围、状态、进度、差异和创建人；明细可按「全部 / 待盘 / 相符 / 位置变化 / 盘亏 / 盘盈」筛选。

| 列 | 说明 |
| --- | --- |
| 资产 | 名称、编码、型号；盘盈记录显示「账外资产」 |
| 账面部门 / 人 / 地点 | 生成盘点单时的账面信息 |
| 盘点结果 | 待盘、相符、位置变化、盘亏、盘盈 |
| 实际 | 位置变化时的实际部门、使用人、地点，以及说明 |
| 盘点人 | |

每项资产的操作：

- **相符**：实物与账面一致。
- **位置变化**：填写实际使用部门、实际使用人、实际存放地点（至少一项）和说明；与账面完全相同时须选「相符」。
- **盘亏**：未找到或已损坏丢弃，填写说明。

另外可以「**登记盘盈**」账外资产：填写资产名称（必填）、存放地点、说明；盘盈记录可以删除。

## 完成盘点

全部资产都盘点后（没有「待盘」），点击「**完成盘点**」：

- **位置变化**的资产按实际信息调拨，并记入资产履历；
- **盘亏**的资产按净值处置，生成处置凭证（净损失转营业外支出），确认框会提示将处置的数量；
- **盘盈**的资产需在[固定资产](./asset)中手工补登资产卡片。

完成后盘点单不能再修改。盘点中的盘点单可以删除。
