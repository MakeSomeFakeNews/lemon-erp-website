# 预算管理

按年度、部门、科目编制 12 个月的费用（或收入）预算，自动对比已记账凭证的实际执行数，并可在费用报销提交时进行预算控制。财务主管、部门负责人使用。

## 页面入口

财务 → 预算与分析 → 预算管理

![预算执行分析](/images/manual/fin/budget-execution.jpg)

## 页面说明

顶部工具栏：**年度**（默认今年）、**部门**（不选为全部部门）、视图切换「**执行分析 / 预算编制**」、「**编制预算**」按钮（需要「预算编制」权限）。

### 执行分析

| 列 | 说明 |
| --- | --- |
| 科目 / 部门 | 科目编码名称，下方为部门（全公司预算显示「全公司」） |
| 全年预算 | 12 个月合计 |
| 执行数 | 全年实际发生；超过预算时标红 |
| 执行率 | 进度条：超过 100% 为红色异常，超过 90% 为提醒样式 |
| 各月执行 / 预算 | 每月「执行数 / 预算数」，执行超过当月预算的月份标红；1 万以上以「x.x万」显示 |

执行数的取数规则：

- 只取**已记账**凭证，不含期末结转损益凭证；
- 预算科目可以是上级科目，执行数按其全部下级科目汇总；
- 费用类（借方科目）取借方 − 贷方，收入类（贷方科目）取贷方 − 借方；
- 部门预算统计分录上填了**该部门及其下级部门**的金额（与数据权限「本部门及以下」的范围一致），全公司预算统计所有部门；分录没有填部门的金额只计入全公司预算。

### 上下级部门都编制了预算

例如「销售部」下有「华东销售组」，两者都编制了差旅费预算：

- 上级部门的预算视为**包含下级部门在内的总额度**，不是上级部门自己单独花的部分；
- 华东销售组的差旅费同时计入华东销售组和销售部两条预算的执行数，销售部自己的差旅费只计入销售部的预算；
- 编制时，上级部门的预算应不少于各下级部门预算之和加上级部门自身的开支，否则下级尚未超支时上级可能已超支。

### 预算编制

![预算编制](/images/manual/fin/budget-plan.jpg)

列出已编制的预算：科目 / 部门、全年预算、预算控制、1-12 月各月金额、备注，可「编辑」「删除」。

## 编制预算

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 年度 | 是 | 默认当前选择的年度 |
| 部门 | 否 | 不选为全公司 |
| 科目 | 是 | 成本类、损益类科目，可选上级科目，执行数按下级汇总 |
| 1 月 ~ 12 月 | — | 各月预算金额，不能小于 0；顶部显示合计 |
| 平均分摊 | — | 输入全年金额后点「**平均分摊到 12 个月**」，尾差计入 12 月 |
| 预算控制 | 否 | 不控制（默认）/ 超预算提示 / 超预算禁止 |
| 备注 | 否 | |

同一年度、部门、科目只能编制一条预算，重复时提示「该年度、部门、科目已编制预算，请直接修改」。

## 预算控制

设置了「超预算提示」或「超预算禁止」的预算，在[费用报销](./claim)**提交**时检查：

- 按报销日期所在年度、报销的费用部门、明细的费用科目匹配预算：适用的预算包括全公司预算、**报销部门本身及其各级上级部门**的预算，科目可以是上级科目的预算；
- 每条适用的预算**分别校验**：当「已执行 + 在途 + 本次报销」超过该预算的**全年预算**时触发控制。其中已执行、在途都按该预算的部门范围统计——部门预算为该部门及其下级部门，全公司预算为所有部门；在途指这些部门审批中、待付款的报销。超出时：
  - 超预算提示：允许提交，弹窗列出「部门、科目、年度预算、已执行、在途、本次、超出」；
  - 超预算禁止：不允许提交，提示同样的信息。
- 例如华东销售组提交差旅费报销时，会分别检查华东销售组、销售部（及更上级部门）、全公司的差旅费预算，任何一条设置为「超预算禁止」且超出时都不能提交。
