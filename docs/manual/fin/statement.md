# 供应商对账

按期间汇总供应商的应付单生成对账单，发送给供应商在**[供应商门户](../portal/supplier#对账单)**中确认，供应商可同时登记发票信息。采购会计使用。

## 页面入口

财务 → 应收应付 → 供应商对账

![供应商对账](/images/manual/fin/statement-list.jpg)

## 列表

查询条件：状态、供应商、对账单号或供应商名称。

| 列 | 说明 |
| --- | --- |
| 对账单号 | 以 DZ 开头，点击查看详情 |
| 供应商 | |
| 对账期间 | 开始日期 ~ 结束日期 |
| 对账金额 | 下方显示包含的应付单张数 |
| 发票 | 供应商登记的发票号码、金额、日期 |
| 状态 | 草稿、待确认、已确认、有异议；有供应商意见时在下方显示 |
| 操作 | 查看 |

## 生成对账单

1. 点击「**生成对账单**」。
2. 选择**供应商**和**对账期间**（默认上个月整月），可填写备注。
3. 点击「确定」。系统汇总该供应商在期间内**还没有对过账**的应付单（[采购入库、采购退货](../scm/purchase-in)、[质量索赔](../qms/claim)等，退货和索赔为负数），生成草稿状态的对账单，并自动打开详情。

已经进入其他对账单的应付单不会重复计入；期间内没有需要对账的应付单时会提示。对账单明细是生成时的快照，之后应付单的变化不影响已生成的对账单。

## 对账单详情

![对账单详情](/images/manual/fin/statement-detail.jpg)

详情显示供应商、对账期间、状态、对账金额、供应商确认时间、发票、供应商意见、备注；明细列出日期、应付单号、来源（类型和单号）、价税合计、税额，底部为合计张数和金额。下方「发票及附件」可上传扫描件。

## 状态流转

| 状态 | 说明 | 可做操作 |
| --- | --- | --- |
| 草稿 | 刚生成 | 删除、发送供应商 |
| 待确认 | 已发送，等待供应商在门户处理 | — |
| 已确认 | 供应商确认无误 | 供应商可补填发票号码、金额、日期并上传扫描件 |
| 有异议 | 供应商提出异议（必须填写异议说明） | 删除后重新生成，或核对后再次发送 |

- 「**发送供应商**」：草稿或有异议的对账单发送后变为待确认，供应商在门户中可以看到。
- 「**删除**」：只能删除草稿或有异议的对账单，其中的应付单可以重新对账。待确认、已确认的不能删除。

## 与其他模块的联动

[供应商账号](../portal/account#为供应商开通)登录[供应商门户](../portal/supplier#对账单)后，只能看到发给本供应商的对账单，在门户中确认或提出异议，确认后可填写发票信息。
