# 财务管理

财务管理模块覆盖总账、应收应付、资金与费用、资产与成本、预算与分析、期末结账六大部分，采用**业财一体化**设计：采购、销售、仓库、生产、人力、项目等业务单据确认后自动形成应收应付和凭证来源，财务人员只需审核、记账，不再重复录入。

## 业财一体化：业务单据自动生成什么

### 自动生成应收应付单

| 业务单据（所属模块） | 确认后生成 |
| --- | --- |
| [销售出库 / 销售退货](../scm/sales-out)（供应链、仓库） | 应收单；退货为红字负数 |
| [采购入库 / 采购退货](../scm/purchase-in)（供应链、仓库） | 应付单；退货为红字负数 |
| [发运单](../scm/shipment)发货，指定承运商和运费（供应链） | 承运商运费应付单（借 销售费用） |
| [供应商质量索赔](../qms/claim)确认（质量） | 红字应付单（借 应付账款 / 贷 营业外收入） |
| [销售返利](../scm/rebate)结算（供应链） | 红字应收单 |
| [项目开票](../pm/accounting#开票)（项目） | 应收单（贷 合同负债） |
| [服务工单收费](../crm/ticket#服务收费)（客户关系） | 应收单（贷 其他业务收入） |
| 新增固定资产并填写采购供应商（财务） | 应付单（借 固定资产、进项税额） |
| 应收票据拒付（财务） | 应收单 |

### 生成凭证

| 业务 | 凭证生成方式 |
| --- | --- |
| 应收应付单、收付款单 | 在应收管理、应付管理、收款单、付款单中勾选「生成凭证」 |
| 预收预付、冲抵、坏账、报销付款、借款付款与还款、票据贴现 / 托收 / 拒付 / 兑付、账户调拨 | 业务操作时立即生成 |
| 计提折旧、资产处置、资产盘亏 | 业务操作时立即生成 |
| 成本结转（领料、人工制费分配、完工、销售成本、项目领料、委外发料、易耗品摊销、盘盈盘亏） | 成本核算时生成 |
| 增值税结转、期末调汇 | 期末操作时生成 |
| [工资计提、发放](../hr/payroll#生成计提凭证)（人力资源） | 工资表确认、发放时生成 |
| [项目月结](../pm/accounting#项目月结)（项目） | 项目月结时生成 |
| [设备维修保养费](../mes/maintenance)（生产）、[培训费](../hr/training)（人力资源） | 业务登记时生成 |
| 结转损益 | 期末结账时自动生成并记账 |

业务凭证使用的科目（应收账款、存货、收入、成本、工资费用等）在「[凭证科目设置](./account-rule)」中配置，未设置时使用预置科目。

除结转损益凭证外，业务生成的凭证都是「未审核」状态，需要在凭证管理中审核、记账后才进入账簿和报表。应收应付、收付款、折旧、成本结转等生成的凭证在未审核时可以删除，删除后可由来源单据重新生成。

## 会计期间

- 会计期间按自然月划分，以凭证日期（业务日期）所在的年月确定，例如 2026 年 10 月。
- 期间在首次录入凭证时自动创建，状态为「未结账」。
- 凭证号按期间连续编号（记-0001 起）。
- **期间锁**：期间结账后，不能再录入、修改该期间的凭证，也不能再处理业务日期在该期间的出入库、盘点、报工、收付款、应收应付等业务；期间已核算成本后，不能再发生该期间的库存变动和报工，需要先撤销成本核算。

## 月末流程清单

| 序号 | 事项 | 页面 |
| --- | --- | --- |
| 1 | 业务单据全部确认，应收应付、收付款生成凭证 | 应收管理、应付管理、收款单、付款单 |
| 2 | 核对资金日报、日记账；银行流水导入与勾对 | 出纳管理、银行对账 |
| 3 | 计提本月折旧 | 固定资产 |
| 4 | 期末调汇（有外币业务时） | 币种汇率 |
| 5 | 成本核算，生成成本结转凭证 | 成本核算 |
| 6 | 增值税结转、计提附加税费 | 期末结账 |
| 7 | 审核、记账全部凭证 | 凭证管理 |
| 8 | 结账检查并结账 | 期末结账 |
| 9 | 查看报表 | 财务报表、经营分析 |

详细步骤见[月末结账操作指引](./month-end)。

## 典型业务流程

**销售到收款**

1. [销售订单](../scm/sales)审核 → 销售出库确认，自动生成应收单。
2. 在应收管理中为应收单生成凭证（借 应收账款 / 贷 主营业务收入、销项税额）。
3. 收到货款后录入收款单，核销应收单，生成收款凭证；先收了预收款的，在预收预付中冲抵。
4. 在发票管理中登记销项发票（或导入数电票）并勾稽应收单。
5. 需要与客户核对往来时，在[往来对账单](./partner-statement)中查询并打印对账单。

**采购到付款**

1. [采购订单](../scm/purchase)审核 → 采购入库确认，自动生成应付单。
2. 为应付单生成凭证（借 原材料 / 库存商品、进项税额 / 贷 应付账款）。
3. 按月与供应商对账；登记或导入进项数电票并认证。
4. 录入付款单（启用付款审批时先审批），核销应付单，生成付款凭证；也可以用票据背书或开具应付票据支付。

**系统上线**

1. 在[会计科目](./account)中增加明细科目、设置辅助核算；在[凭证科目设置](./account-rule)中确认自动凭证使用的科目。
2. 按[期初余额](./opening#启用向导)的启用向导依次录入科目期初、导入期初库存、录入存货期初金额、导入期初应收应付，并核对往来与科目期初一致。
3. 在物料上确认[存货计价方法](./cost#存货计价方法)后开始日常业务。

**费用报销**

员工借款（审批、付款）→ 报销单提交（预算控制、审批）→ 出纳付款，自动冲抵借款并生成费用凭证。

## 相关角色

| 内置角色 | 职责 |
| --- | --- |
| 会计 | 财务全部功能：凭证、往来、资产、成本、预算、结账，可查看采购销售单据 |
| 出纳 | 收付款、预收预付、银行对账、报销和借款付款，可查看账簿和往来 |
| 普通用户 | 财务管理各页面只读 |

审批流程中的部门主管、总经理等审批人按[流程设计](../workflow/designer)确定。按钮权限（如凭证审核、凭证记账、结账、增值税结转、坏账核销、红字冲销）可在「[角色管理](../system/role)」中单独分配。
