# 低值易耗品

物料类别为「低值易耗品」的物品（如办公用品、工具）按库存管理，入账在周转材料科目；部门领用时从仓库出库，月末成本核算时一次摊销到领用部门的费用。仓管员、行政、会计使用。

## 页面入口

财务 → 资产与成本 → 低值易耗品

页面有两个页签：**领用单**、**部门领用台账**。

![低值易耗品领用](/images/manual/fin/consumable-list.jpg)

查询条件：状态（草稿、已出库）、领用部门、领用单号或用途。

| 领用部门 | 下方为领用人 |
| 出库仓库 | |
| 费用科目 | |
| 数量 | |
| 参考金额 | 按最近一次成本核算单价（没有时取参考成本价）估算 |
| 用途 | |
| 状态 | 草稿 / 已出库（显示出库单号） |

## 新增领用

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 领用部门 | 是 | |
| 领用人 | 否 | |
| 领用日期 | 是 | |
| 出库仓库 | 是 | |
| 费用科目 | 是 | 制造费用、销售费用、管理费用下的末级科目；月末按实际成本借记该科目 |
| 用途 | 否 | |

领用物料明细：物料、库位、批次（物料启用批次管理时填写）、数量、备注；点「添加物料」增加行。

只能领用类别为「低值易耗品」的物料；启用了[序列号管理](../wms/trace)的物料不能作为低值易耗品领用，应按固定资产管理。保存后为「草稿」。

## 确认出库

在详情中点击「**确认出库**」（需要「领用出库」权限）：系统生成并确认一张出库类型为「部门领用」的[仓库出库单](../wms/out)，扣减库存，领用单变为「已出库」。库存不足等错误会导致出库失败。

草稿状态的领用单可以编辑、删除；已出库的不能再修改。

## 部门领用台账

按日期范围、部门汇总已出库的领用：部门、物料、数量、参考金额，底部为合计。金额按最近一次成本核算单价参考，实际金额以月末成本核算为准。

## 月末摊销

[成本核算](./cost)时，部门领用按当月成本核算的实际出库单价一次摊销，生成分录：借 领用单的费用科目（领用部门）/ 贷 周转材料。
