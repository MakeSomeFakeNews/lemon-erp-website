# 固定资产

管理固定资产卡片，按月计提折旧，记录领用、归还、调拨履历，处置资产时自动生成处置凭证。资产会计、行政管理人员使用。

## 页面入口

财务 → 资产与成本 → 固定资产

页面有两个页签：**资产卡片**、**折旧计提**。

![固定资产](/images/manual/fin/asset-list.jpg)

## 资产卡片列表

查询条件：编码 / 名称 / 使用人 / 地点、类别（房屋建筑物、机器设备、运输工具、电子设备、办公家具）、状态（在用、闲置、已处置）。

| 列 | 说明 |
| --- | --- |
| 资产 | 名称，下方为编码和规格型号 |
| 类别 | |
| 使用部门 / 人 / 地点 | |
| 开始使用 | 开始使用日期 |
| 原值 | 下方显示残值率 |
| 折旧进度 | 进度条及「已提月数 / 使用年限月数，月折旧额」 |
| 净值 | 下方显示累计折旧 |
| 折旧科目 | 折旧费用科目 |
| 状态 | 在用 / 闲置 / 已处置（显示处置日期） |
| 操作 | 编辑、变动（领用 / 归还 / 调拨）、履历、处置、删除 |

| 资产名称 | 是 | |
| 类别 | 是 | 默认电子设备 |
| 规格型号 | 否 | |

| 使用人 | 否 | |

表单底部提示「月折旧额约 ¥xx」。

- **已计提过折旧的资产**，不能再修改原值、残值率、使用年限和开始使用日期（输入框置灰）。
- 已处置的资产不能编辑。
- 部门、使用人、存放地点在编辑时发生变化，也会记入资产履历。

### 资产采购生成应付

填写采购供应商后，系统生成来源为「固定资产」的应付单，在[应付管理](./ar-ap)中生成凭证（借 固定资产、应交税费 - 进项税额 / 贷 应付账款），在[付款单](./settlement)中付款。期初资产不能同时登记采购供应商。

## 折旧方法

- 平均年限法：**月折旧额 = 原值 × (1 − 残值率) ÷ 使用月数**。
- 开始使用的**次月**开始计提；最后一个月计提剩余的可折旧金额（消除尾差）。
- 当月处置的资产当月照提折旧。

## 折旧计提

![折旧计提](/images/manual/fin/asset-depreciation.jpg)

1. 切换到「折旧计提」页签，选择**期间**。
2. 点击「**计提本期折旧**」。系统为所有应计提的资产计提当月折旧，并生成一张凭证（未审核）：借 各资产的折旧费用科目（按使用部门）/ 贷 累计折旧。
3. 下方表格列出该期间的计提记录：期间、资产、使用部门、折旧额、凭证。

规则：

- 每个期间只能计提一次；期间必须未结账。
- **必须按月顺序计提**：之后的期间已计提时不能补提；之前有计提记录时，上一个期间必须已计提。
- 没有需要计提的资产时会提示。
- 「**撤销计提**」只能撤销最近一期，删除凭证（须未审核）并恢复资产的累计折旧。

## 领用、归还、调拨

在资产行点击「**变动**」（需要「领用调拨」权限）：

| 操作 | 适用状态 | 填写 | 结果 |
| --- | --- | --- | --- |
| 领用 | 闲置 | 日期、使用部门（必填）、使用人、存放地点、说明 | 转为在用 |
| 归还 | 在用 | 日期、归还后存放地点、说明 | 转为闲置，清空使用人 |
| 调拨 | 在用 / 闲置 | 日期、使用部门、使用人、存放地点、说明 | 更新部门 / 使用人 / 地点；不填的保持不变，三者都与现在相同时不允许 |

## 资产履历

点击「**履历**」查看该资产的全部变动记录：日期、类型（领用 / 归还 / 调拨）、部门、使用人、存放地点（以「原 → 新」显示）、说明、经办人及时间。

![资产履历](/images/manual/fin/asset-history.jpg)

## 处置资产

1. 在资产行点击「**处置**」。
2. 填写：处置日期（必填）、收付款账户（有处置收入或清理费用时必填）、处置收入、清理费用。弹窗底部实时显示净值和处置净损失 / 净收益。
3. 确认后资产变为「已处置」，生成处置凭证（未审核）：

| 步骤 | 分录 |
| --- | --- |
| 转入清理 | 借 累计折旧、固定资产清理 / 贷 固定资产 |
| 处置收入 | 借 银行存款 / 贷 固定资产清理 |
| 清理费用 | 借 固定资产清理 / 贷 银行存款 |
| 结转净损益 | 净损失转营业外支出，净收益转营业外收入，固定资产清理结平 |

当月减少的资产当月照提折旧：处置月份在使用中、且还没有计提该月折旧时，系统会提示先计提处置月份的折旧。

**删除处置凭证**（未审核时，在凭证管理中删除）后，资产恢复为处置前的状态，可以重新处置。

## 删除资产

只有**还没有计提过折旧**的资产可以删除；已计提折旧的资产请做处置。

## 与其他模块的联动

- [资产盘点](./asset-check)完成后，位置变化的资产自动调拨，盘亏的资产自动按净值处置。
- 结账检查会提示本期还没有计提折旧。
