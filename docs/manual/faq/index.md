# 常见问题

本页汇总使用柠檬ERP 时最常遇到的问题。答案中引号内的文字是系统实际显示的提示，可以直接对照查找。没有找到答案时，请联系系统管理员，并提供出错的页面、操作步骤和提示文字。

## 登录

### 提示「用户名或密码错误」

- 检查是否开启了键盘大写锁定，密码区分大小写。
- SaaS 模式下检查「租户」是否填对：同一个用户名在不同租户中是不同的账号。
- 连续输错会锁定账号，剩余 2 次及以下时会提示「再错 N 次将锁定账号」，不确定密码时请先联系管理员重置。

### 提示「密码错误次数过多，账号已锁定，请 N 分钟后再试或联系管理员重置密码」

连续输错密码达到次数（默认 5 次）后账号被锁定（默认 10 分钟）。可以等待提示的时间后再试，或请管理员在「系统管理 → [用户管理](../system/user#重置密码)」中重置密码，重置后立即解锁。

### 提示「账号已停用」

账号被管理员停用，或员工已办理离职。请联系管理员在「用户管理」中启用。

### 提示「租户不存在」「租户已停用」「租户已过期，请联系平台续费」

SaaS 模式下租户名称填写错误，或公司（[租户](../system/tenant#停用与删除)）已被平台停用、已到期。请向管理员确认公司在系统中的准确名称；停用、到期需要联系平台方处理。

### 登录页出现了验证码 / 提示「请输入验证码」

管理员开启了[登录验证码](../guide/login#验证码规则)。设置为「密码输错后」时，该账号输错过密码后，下次登录就需要验证码，直到登录成功。提示「验证码已过期，请刷新」时点击验证码图片换一张；验证码 2 分钟内有效，每张只能用一次。

### 登录后提示「当前密码为管理员设置的初始密码或已过期，请先修改密码」

首次使用管理员设置的初始密码登录，或密码超过了有效期。系统已自动打开「个人中心 → 修改密码」，按要求设置新密码即可，见[个人中心](../guide/profile#修改密码)。

### 用着用着提示「登录已过期，请重新登录」

登录会话失效了。常见原因：超过登录有效期（默认 12 小时）、管理员强制下线、重置了密码、账号在别处登录（开启了「同一账号只允许一处登录」时）、账号被停用。重新登录后会回到原来的页面，但未保存的内容会丢失。详见[会话失效的情况](../guide/login#会话失效的情况)。

### 忘记密码怎么办？

系统不提供自助找回密码，请联系管理员在「用户管理」中重置。

## 菜单与权限

### 看不到某个模块或菜单

1. 菜单由角色决定：请管理员在「系统管理 → 角色管理 → [菜单权限](../system/role#菜单权限页签)」中给你的角色勾选该页面，或给你分配有该页面的角色。
2. 管理员调整权限后，**刷新浏览器（F5）**才会显示新菜单，不需要重新登录。
3. SaaS 模式下，[租户套餐](../system/tenant-package)中不包含的功能，租户内的任何角色都看不到；菜单、字典、参数设置、服务监控等平台功能只有平台租户可用。
4. 可以用顶部的「[搜索菜单](../guide/layout#菜单搜索-⌘k-ctrl-k)」（⌘ / Ctrl + K）输入页面名称确认：搜不到就是没有权限。

### 页面中看不到「新增」「删除」「审核」等按钮

按钮权限与页面权限分开配置。只勾选了页面而没有勾选按钮时，只能查看。请管理员在角色的「菜单权限」中展开该页面，勾选需要的按钮。另外，很多按钮只在特定状态下出现，例如「编辑」只对草稿单据显示。

### 点击按钮提示「没有权限，请联系管理员」

你的角色没有该操作的权限，请联系管理员授权。

### 首页看不到「应收余额」「应付余额」卡片

这两张卡片除了需要[应收 / 应付管理](../fin/ar-ap)的查看权限，还要求数据权限为「全部数据」。

## 数据

### 列表中看不到别人录入的数据

这是数据权限的作用。角色的数据权限为「本部门」「仅本人」等时，只能看到所属部门或本人的数据。例如内置的销售员角色是「仅本人」，只能看到自己制单的订单。需要查看更多数据时，请管理员调整角色的数据权限，见[数据权限的 5 种范围](../guide/permission#数据权限的-5-种范围)。

### 用户刚调了部门，看到的数据变了

「本部门」「本部门及以下」按用户当前所在部门计算，调整部门后立即按新部门生效。

### 用户没有部门，什么数据都看不到

数据权限为「本部门」「本部门及以下」时，用户必须设置部门，否则看不到按部门控制的数据。请在「用户管理」中为其设置部门。

### 列表中明明有数据，查询却查不到

- 检查是否有隐藏的查询条件：查询区「展开」后可能还有已填写的条件，点击 **重置** 清空。
- 检查是否隐藏了查询区（工具栏的放大镜图标）。
- 商务智能中的分析数据来自数据仓库，业务数据变化后需要等每天凌晨的自动同步，或在「商务智能 → [数据仓库](../bi/etl#手动同步)」中手动立即同步。

### 新增时提示编码已存在，但列表里查不到

编码在整个公司（租户）内唯一，不受数据权限影响。你看不到的数据（其他部门或其他人的）也会占用编码，请换一个编码，或请有权限的人员查看。

## 单据不能修改或删除

### 提示「… 不是草稿，不能修改、删除或审核」「… 已确认，不能修改或删除」

单据审核或确认后就不能再修改、删除，这是为了保证库存和账务准确。处理方式：

| 单据 | 更正方法 |
| --- | --- |
| 采购 / 销售订单（已审核、还没有入库 / 出库） | 详情中 **反审核** 回到草稿后修改 |
| 采购 / 销售订单（已部分入库 / 出库） | 用 **变更** 生成变更单修改数量、单价、交期；不再执行的用 **关闭** |
| [采购入库](../scm/purchase-in)、[销售出库](../scm/sales-out)、工单领料、完工入库等 | 这些单据保存即确认，不能修改删除，通过采购退货、销售退货、退料等反向单据冲回 |
| 手工[入库单](../wms/in)、[出库单](../wms/out)、[调拨单](../wms/transfer)（已确认） | 使用 **冲销** 生成红字单据 |
| [凭证](../fin/voucher#凭证状态与操作)（已审核） | 提示「凭证 … 已审核，请先反审核或做红字冲销」，按提示处理 |
| [生产工单](../mes/wo)（已下达） | 提示「工单 … 已下达，不能修改或删除」；可在详情中 **改量**、**拆分** 或 **关闭** |

### 提示「订单已有入库 / 出库或不是已审核状态，不能反审核」

订单已经有入库或出库记录，不能再回到草稿。请使用订单变更或关闭。销售订单已生成生产计划时也不能反审核。

### 提示「……已被单据使用，不能删除，可以停用」

物料、客户、供应商、仓库、库位、工作中心等资料被单据引用后不能删除，以免历史单据失去关联。请在列表中把状态改为停用，停用后新单据中不能再选择。

### 单据在「审批中」，不能修改

审批中的单据不能修改。需要修改时，在单据详情中点击 **撤回审批**（只有发起人可以撤回），单据回到草稿后修改，再重新提交。

### 提示「… 状态已变化，请刷新」

单据在你打开之后被其他人处理过（例如已被审核、已被删除）。点击标签栏的刷新按钮重新加载后再操作。

## 库存

### 提示「库存不足：物料，可用 X，需要 Y」

出库、领料、调出时，指定仓库、库位、批次的可用库存不够。请检查：

- **仓库、库位、批次是否选对**：库存按「仓库 + 库位 + 物料 + 批次」分别记录，同一物料在其他库位或批次的库存不能混用。在「仓库 → 库存查询 → [库存查询](../wms/stock)」中按物料查询各位置的数量。
- **是否有冻结库存**：提示末尾有「（另有冻结 N，待检或不合格）」时，部分库存因来料待检或检验不合格被冻结，检验合格放行后才能使用，见「仓库 → 库存控制 → [库存冻结](../wms/hold)」。
- **入库单是否已确认**：手工入库单是草稿时不增加库存。
- 由业务单据（如销售出库）引起的库存不足，会让整张单据都不能保存。

### 提示「… 的库存已被预留 …，出库后不足以满足预留，请先释放预留」

该物料的库存已被销售订单预留，本次出库后剩余库存不够已有的预留。请确认是否应该从预留中出库（销售出库会先核销本订单的预留），或在「仓库 → 库存控制 → [库存预留](../wms/reservation)」中释放不需要的预留。

### 提示「批次 … 已于 … 过期，不能发出，请报废出库或调拨到不良品仓」

销售、生产、项目等出库不能发出已过期的批次。请选择其他批次；过期批次通过手工出库单的「报废出库」处理，或调拨到不良品仓。

### 提示「仓库「…」正在盘点（…）」

该仓库有勾选了「冻结仓库」的[盘点单](../wms/check)还没有完成，盘点期间不能出入库和调拨。请先完成或删除盘点单。

### 提示「序列号已在库」「序列号不在该库存位置」

序列号管理的物料：入库时序列号不能已经在库；出库、调出时序列号必须在所选的仓库库位中。请在「仓库 → 库存查询 → [批次与序列号](../wms/trace#序列号追踪)」中查询该序列号的当前位置。

### 销售出库提示「客户「…」超出信用额度，暂停出库」

客户的应收余额 + 未完成订单超过了信用额度。请先收款，或请有权限的人员在「供应链 → 往来单位 → [客户](../scm/customer#信用额度控制)」中调整信用额度。审核销售订单时提示「超出客户「…」的信用额度」也是同样原因。

## 审批

### 我提交的单据在哪里看审批进度？

「流程中心 → 我的事务 → [我的申请](../workflow/mine)」中列出你发起的全部流程，打开详情可以看到审批记录和流程进度图。业务单据详情中处于「审批中」时，也会提示到「我的申请」查看进度。

### 我需要审批的单据在哪里？

「流程中心 → 我的事务 → [我的待办](../workflow/todo)」，首页的「[待我审批](../guide/home#待我审批)」卡片和铃铛消息也会提醒。处理过的在「[我的已办](../workflow/done)」，抄送给你的在「[抄送我的](../workflow/copy)」。

### 点击「审核」后单据直接生效了，没有走审批

只有在「流程中心 → 流程管理 → [流程模型](../workflow/model#发布与版本)」中**发布**了该业务对应的流程后，审核才会改为提交审批；流程未发布或已停用时，单据直接生效。系统内置的业务审批流程默认未发布，需要管理员调整审批人后发布。

### 流程发起了，但审批人那里没有待办

- 审批人设置为「角色」时，该角色下必须有启用的用户；设置为「部门主管」时，[部门管理](../system/dept#部门负责人与审批中的「部门主管」)中必须设置了部门负责人。
- 找不到审批人时，按[流程设计](../workflow/designer#审批人为空时)中的设置自动通过或转交超级管理员。
- 管理员可在「流程中心 → 流程管理 → [流程实例](../workflow/instance)」中查看流程当前停在哪个节点、由谁处理。

### 审批被拒绝后怎么办？

审批拒绝或撤回后，单据回到草稿（或原来的状态），修改后可以重新提交审批。

### 提示「已启用凭证审批流程，请提交审批，审批通过后自动审核」

发布了[凭证审批](../fin/voucher#凭证审批)流程后，凭证不能再直接审核，需要由制单人提交审批。另外，制单人不能审核自己的凭证，会提示「凭证 … 是你制单的，不能自己审核」。

## 打印

### 点击「打印」没有反应

系统会弹出浏览器的打印对话框，稍等一两秒；数据较多时生成较慢。如果始终没有出现，请检查浏览器是否拦截了打印，或换用 Chrome、Edge 浏览器。

### 怎样打印成 PDF？

在浏览器打印对话框的「目标打印机」中选择「另存为 PDF」。

### 打印内容显示不全、列太挤

请管理员在「系统管理 → [打印模板](../system/print-template#单据模板)」中调整该单据：改为横向纸张、隐藏不需要的列、设置列宽。在浏览器打印对话框中也可以调整缩放比例。

### 打印的公司名称不对

公司名称取自「打印模板 → [通用设置](../system/print-template#通用设置)」；没有设置时，SaaS 模式下为当前租户名称。请管理员修改通用设置，或在单据模板中关闭「显示公司名称」。

### 打印的页眉页脚多了网址和日期

这是浏览器默认添加的，在打印对话框的「更多设置」中取消勾选「页眉和页脚」即可。

## 导入导出

### 导入失败

导入时任何一行有错误，整批都不会导入，修正后重新选择文件即可。常见错误：

| 提示 | 原因与处理 |
| --- | --- |
| 缺少列：…，请使用导入模板 | 表头被修改或删除了必填列。请重新下载导入模板，不要改动表头 |
| 文件中没有数据 / 文件中没有工作表 | 文件是空的，或数据不在第一个工作表中 |
| 文件解析失败，请使用导入模板 | 文件不是有效的 .xlsx（例如把 .xls、.csv 改了扩展名）。请用 Excel 另存为 .xlsx |
| …不能为空（错误列表中显示行号） | 带 * 的必填列没有填写 |
| …「…」不存在 | 字典或关联资料的名称、编码在系统中不存在，例如部门名称写错。请填写界面上显示的名称或准确的编码 |
| …「…」不是有效的数字 / 日期 | 数字列含有文字，或日期格式不对。日期可写 2026-10-16、2026/10/16 或 2026年10月16日 |
| …请填写 是 或 否 | 是否类的列只能填 是、否、Y、N、1、0、启用、停用 |
| 客户编码已存在 等 | 与系统中已有数据重复（包括你没有权限查看的数据） |
| 一次最多导入2000行 | 请拆分成多个文件导入 |

### 导出时提示「数据较多，只导出了前 N 条，请缩小查询范围」

一次最多导出 10000 条。请增加查询条件（例如按日期范围）分多次导出。

### 导出的列和我看到的不一样

导出的列与表格当前显示的列一致，在「[列设置](../guide/common#列设置)」中隐藏的列不会导出。请先在列设置中勾选需要的列再导出。

## 期间与结账

### 期间已结账

业务日期所在的会计期间结账后，不能再处理该期间的业务，以保证已出的报表不变。常见提示：

| 提示 | 说明 |
| --- | --- |
| 2026 年 9 月 已结账，不能再处理业务日期在该期间的… | 出入库、盘点、报工、收付款、应收应付等单据的业务日期落在已结账期间 |
| 202609 期间已结账，不能再录入或修改凭证 | 凭证日期所在期间已结账 |
| 2026 年 9 月 已核算成本，不能再处理业务日期在该期间的…，请先在「成本核算」中撤销 | 该期间已做成本核算，不能再发生库存变动和报工 |

处理方法：

- 一般情况下把业务日期改为当前未结账的期间录入；
- 确实需要补录到旧期间时，由会计在「财务 → 期末与设置 → [期末结账](../fin/period#反结账)」中从最后一个已结账期间开始依次 **反结账**（会删除结转损益凭证），并在「财务 → 资产与成本 → [成本核算](../fin/cost#核算操作)」中撤销相应期间的核算，补录后重新核算、结账。

### 结账时提示「… 期间还有 N 张凭证未记账」或「请先结账 … 期间」

结账要求本期凭证全部记账，且之前的期间都已结账。请先审核、记账全部凭证，并按月份顺序结账。结账前可以先查看[结账检查](../fin/period#结账检查)的结果。

### 新增凭证提示「借贷不平衡」或「借方、贷方金额必须且只能填一个」

每条分录只能填写借方或贷方中的一个，且全部分录借方合计必须等于贷方合计，至少两条分录。

## 其他

### 页面显示异常或数据不刷新

先点击标签栏右侧的刷新图标重新加载当前页；仍有问题时按 F5 刷新浏览器。浏览器缓存问题可尝试强制刷新（Windows：Ctrl + F5，Mac：⌘ + Shift + R）。

### 提示「请求超时，请稍后重试」或「网络连接失败」

网络不稳定或服务器繁忙。稍后重试；持续出现请联系管理员检查服务器状态（「系统监控 → [服务监控](../monitor/server)」）。

### 不小心关闭了正在填写的表单

关闭有修改的表单时系统会提示「放弃未保存的修改？」，选择「继续编辑」即可回到表单。如果已经确认放弃或关闭了标签页，未保存的内容无法恢复。

### 上传附件提示「不支持上传该类型的文件」或文件过大

不能上传可执行文件和脚本（如 .exe、.bat、.js、.html 等），可以压缩为 .zip 后上传。单个文件默认不超过 20MB，上限由管理员在「参数设置 → [文件上传](../system/config#文件上传)」中设置。
