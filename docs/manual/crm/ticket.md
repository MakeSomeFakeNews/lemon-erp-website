# 服务工单

服务工单用于受理和跟踪客户的咨询、投诉、报修、退换货和建议。系统按优先级自动计算处理时限并标出超时工单；报修时可按产品序列号追溯销售出库日期判断是否在保修期内；处理过程中可以领用备件、收取服务费，关闭时记录客户满意度。

## 页面入口

客户关系 → 服务与营销 → 服务工单

![服务工单列表](/images/manual/crm/ticket-list.jpg)

::: tip 微信小程序
客服和服务工程师可以在[微信小程序](../miniapp/sales#服务工单)中受理工单（可扫描产品序列号）、添加处理记录、解决、关闭和重新打开；指派、领用备件、服务收费仍在本页面进行。
:::

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 工单 | 工单号、标题、客户或序列号 |
| 类型 | 咨询、投诉、报修、退换货、建议 |
| 优先级 | 紧急、高、中、低 |
| 状态 | 待处理、处理中、已解决、已关闭 |
| 筛选 | 「指派给我」只看处理人是自己的；「已超时」只看超过处理时限仍未解决的 |

## 列表字段

| 列 | 说明 |
| --- | --- |
| 工单 | 标题（点击打开详情）和工单号（FW 开头，自动生成） |
| 客户 | 客户名称、联系人和电话 |
| 类型、优先级 | |
| 状态 | 工单状态；已关闭且有评价时显示满意度星级 |
| 处理人 | 未指派时显示「未指派」 |
| 处理时限 | 未解决的：显示「剩余 X 天 X 小时」或红色「超时 X 天 X 小时」及截止时间；已解决的：显示「按时解决」或「超时解决」及解决时间 |
| 受理时间 | |

行操作：**处理**（打开详情）；**编辑**（待处理、处理中的工单）；删除（仅待处理的工单）。

## 优先级与处理时限

处理时限 = 受理时间 + 优先级对应的时长：

| 优先级 | 处理时限 |
| --- | --- |
| 紧急 | 4 小时 |
| 高 | 24 小时 |
| 中 | 72 小时 |
| 低 | 168 小时（7 天） |

编辑工单修改优先级时，按原受理时间重新计算处理时限。

## 受理工单

点击「**受理工单**」。

![受理工单](/images/manual/crm/ticket-add.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 客户 | 是 | 更换客户时联系人清空 |
| 联系人 | 否 | 从该客户的联系人中选择 |
| 类型 | 是 | 默认「报修」 |
| 优先级 | 是 | 默认「中」，下方提示对应的处理时限 |
| 受理渠道 | 否 | 电话（默认）、邮件、在线客服、上门 |
| 标题 | 是 | 最长 128 字 |
| 问题描述 | 否 | 最长 2000 字 |
| 相关产品 | 否 | 搜索物料编码、名称或扫码 |
| 产品序列号 | 否 | 可点击「查询保修」，见下文 |
| 处理人 | 否 | 受理时可直接指派 |

### 序列号保修判断

输入产品序列号后点击「**查询保修**」，系统按仓库的[序列号轨迹](../wms/trace#序列号追踪)查找该序列号的销售出库记录：

- 找到时显示「在保修期内」或「已过保修期」，以及物料、销售日期、出库单号、销售给哪个客户、保修截止日期。保修期为**销售出库日期起 12 个月**。客户或相关产品未填写时，可点击「**带入客户和产品**」自动填入。
- 找不到时提示「没有找到该序列号的销售出库记录」。

## 工单状态

| 状态 | 说明 | 可执行的操作 |
| --- | --- | --- |
| 待处理 | 受理后的状态 | 编辑、删除、指派、处理记录、解决、领用备件、服务收费 |
| 处理中 | 第一次添加处理记录后 | 编辑、指派、处理记录、解决、领用备件、服务收费 |
| 已解决 | 填写解决方案后 | 关闭、重新打开、领用备件、服务收费 |
| 已关闭 | 关闭并记录满意度 | 重新打开、服务收费 |

## 处理工单

点击「**处理**」或工单标题打开详情。

![工单详情](/images/manual/crm/ticket-detail.jpg)

详情顶部提示剩余时间或已超时时长和处理时限；下方为工单信息、问题描述、解决方案、客户满意度，「备件与收费」以及「处理记录」时间线（受理、指派、处理、解决、关闭、重新打开，每条记录操作人和时间）。

右上角按钮（需要「工单处理」权限）：

| 按钮 | 显示条件 | 弹窗填写 | 结果 |
| --- | --- | --- | --- |
| **指派** | 待处理、处理中 | 处理人（必填）、说明 | 更换处理人 |
| **处理记录** | 待处理、处理中 | 处理记录（必填） | 记录处理过程；待处理变为处理中，没有处理人时处理人设为自己 |
| **解决** | 待处理、处理中 | 解决方案（必填） | 变为已解决，记录解决时间（用于判断是否按时解决） |
| **关闭** | 已解决 | 客户满意度（1–5 星，默认 5 星）、客户反馈 | 变为已关闭 |
| **重新打开** | 已解决、已关闭 | 重新打开的原因（必填） | 回到处理中，清除解决时间和满意度 |

### 领用备件

1. 在「备件与收费」处点击「**领用备件**」（已关闭的工单不能领用）。
2. 选择仓库、日期，点击「**选择库存**」从仓库现有库存中挑选物料（库位、批次），填写领用数量（不超过可用数量），可填写备注。
3. 确定后系统生成并直接确认一张「服务领用」[出库单](../wms/out)（来源单号为工单号），扣减库存，并在处理记录中记一条「领用备件，出库单 XXX」。

领用记录列表显示出库单、仓库、日期、数量、领用人、备注。

### 服务收费

1. 点击「**服务收费**」（每张工单只能收一次费）。
2. 填写收费金额（含税，必填）、税率（默认 6%）、收费日期（必填）、说明。
3. 确定后为客户生成应收单，凭证计入其他业务收入；工单显示「已收费 ¥X（已生成应收单，在「[应收管理](../fin/ar-ap)」中生成凭证、收款核销）」。

## 与其他模块的联动

| 动作 | 联动结果 |
| --- | --- |
| 查询保修 | 读取仓库的[序列号](../wms/trace#序列号追踪)销售出库轨迹 |
| 领用备件 | 生成并确认服务领用[出库单](../wms/out)，扣减库存 |
| 服务收费 | 在财务[应收管理](../fin/ar-ap)中生成客户应收单（借 应收账款 / 贷 其他业务收入、销项税额） |
| 工单数据 | 客户详情「服务工单」页签、客户分析「服务质量」统计 |

[首页待办](../guide/home#待办事项)显示「我处理中的服务工单」。员工[离职](../hr/employee#人事异动)并指定交接人时，处理人为该员工的工单转给交接人。

::: warning 注意
已开始处理（非待处理）的工单不能删除；已解决、已关闭的工单不能编辑，需要先重新打开。
:::
