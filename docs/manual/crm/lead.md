# 线索管理

线索是尚未确认需求的潜在客户信息，例如展会收集的名片、官网咨询、电话营销获得的联系方式。销售对线索进行跟进，确认有意向后「转化」为正式客户（可同时生成商机）；没有价值的线索「标记无效」。

## 页面入口

客户关系 → 客户经营 → 线索管理

![线索管理列表](/images/manual/crm/lead-list.jpg)

::: tip 微信小程序
在[微信小程序](../miniapp/sales#线索)中也可以录入、编辑、跟进、转化线索和标记无效。
:::

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 线索 | 按线索编号、公司、联系人或电话模糊查询 |
| 状态 | 待跟进、跟进中、已转化、无效 |
| 来源 | 官网咨询、展会、电话营销、客户转介绍、广告投放、其他 |
| 市场活动 | 线索关联的市场活动（点「展开」显示） |
| 负责人 | 勾选「只看我的」只显示自己负责的线索 |

从[市场活动](./campaign)列表点击「线索」进入时，会自动按该活动筛选。

## 列表字段

| 列 | 说明 |
| --- | --- |
| 公司 | 公司名称和线索编号（XL 开头，自动生成） |
| 联系人 | 联系人、职务、电话 |
| 来源 | 来源渠道，下方显示市场活动名称 |
| 行业 | 所属行业 |
| 负责人 | 负责跟进的销售 |
| 状态 | 线索状态；已转化的显示转化后的客户（可点击跳转到客户详情）；无效的显示无效原因 |
| 最近跟进 | 最近一次跟进时间 |
| 需求 | 需求描述 |
| 创建时间 | |

## 线索状态

| 状态 | 说明 | 可执行的操作 |
| --- | --- | --- |
| 待跟进 | 新增后的状态 | 跟进、转化、编辑、标记无效、删除 |
| 跟进中 | 第一次写跟进后自动变为跟进中 | 跟进、转化、编辑、标记无效、删除 |
| 已转化 | 转化为客户后 | 不能再修改或删除 |
| 无效 | 标记无效后 | 只能删除 |

## 新增 / 编辑线索

点击「**新增线索**」，或在行上点击「更多 → **编辑**」。

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 公司名称 | 是 | 最长 128 字，转化时作为客户名称 |
| 联系人、职务、电话 | 否 | 转化时生成客户的首要联系人 |
| 邮箱 | 否 | 需符合邮箱格式 |
| 来源 | 否 | 转化后带到客户和商机 |
| 市场活动 | 否 | 只能选择未取消的活动；用于统计活动效果 |
| 行业、地区 | 否 | 转化后带到客户 |
| 负责人 | 否 | 不选择时为你本人；负责人部门随负责人确定 |
| 需求描述 | 否 | 最长 500 字，转化时作为商机备注 |

## 跟进线索

在行上点击「**跟进**」，填写跟进方式、跟进时间、内容和下次跟进计划，保存后线索的「最近跟进」时间更新；待跟进的线索变为「跟进中」。跟进记录的字段见[跟进记录](./followup)。

## 转化线索

![转化线索](/images/manual/crm/lead-convert.jpg)

1. 在待跟进或跟进中的线索上点击「**转化**」。
2. 填写**客户编码**（必填，只能包含字母、数字、下划线和短横线，不能与已有客户重复）。
3. 「**同时生成商机**」默认勾选，可修改商机名称（默认「公司名称 商机」）、预计金额、预计成交日期；不需要商机时取消勾选。
4. 点击「确定」。成功后弹出提示，可点击「**查看客户**」直接打开新客户的详情。

转化时系统自动：

- 新建客户：客户名称取公司名称；负责人、部门、行业、来源、地区沿用线索；客户阶段为**意向客户**；最近跟进时间沿用线索。
- 有联系人时，建立客户的首要联系人（姓名、职务、电话、邮箱）。
- 勾选生成商机时，新建一个「初步接洽」阶段的商机，来源、市场活动、负责人沿用线索，需求描述作为商机备注。
- 线索状态变为「已转化」，记录转化的客户和转化时间。

::: tip 提示
转化总是新建客户。如果该公司已经是系统中的客户，建议把线索标记为无效，直接在已有客户下新建商机。
:::

## 标记无效与删除

- 「更多 → **标记无效**」：填写无效原因（如联系方式错误、没有需求），线索变为「无效」，原因显示在状态列下方。
- 「更多 → **删除**」或无效线索上的「**删除**」：删除线索。**已转化的线索不能删除。**

## 与其他模块的联动

- 转化生成客户、联系人和商机（见上文）。
- [市场活动](./campaign)按关联的线索统计线索数、转化数和转化率。
- [客户分析](./analysis)的「来源分析」按来源统计线索数和转化率。
