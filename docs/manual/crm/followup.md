# 跟进记录

跟进记录汇总了销售对客户、线索、商机的全部沟通记录（电话、拜访、微信、邮件、会议），并通过「下次跟进时间」安排后续工作、触发跟进提醒。跟进记录在客户、线索、商机中填写，本页面用于汇总查看。

## 页面入口

客户关系 → 客户经营 → 跟进记录

![跟进记录](/images/manual/crm/followup-list.jpg)

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 跟进对象 | 客户、线索、商机 |
| 跟进方式 | 电话、拜访、微信、邮件、会议 |
| 跟进时间 | 日期范围 |
| 跟进人 | 勾选「只看我的」只显示自己写的跟进 |

列表按数据权限过滤（跟进人所在部门 + 跟进人）。

## 列表字段

| 列 | 说明 |
| --- | --- |
| 跟进时间 | |
| 跟进对象 | 对象类型标签（客户 / 线索 / 商机）和对象名称 |
| 客户 | 对客户或商机的跟进显示所属客户 |
| 方式 | 跟进方式 |
| 内容 | 跟进内容，鼠标悬停显示全文 |
| 下次跟进 | 下次跟进时间和计划 |
| 跟进人 | |

行操作「**删除**」：跟进人本人可以删除自己的记录；删除他人的记录需要「跟进删除」权限。

## 写跟进

在以下位置点击「**写跟进**」（线索上为「跟进」）：

- [客户管理](./customer)列表的行操作，或客户详情右上角、「跟进记录」页签；
- [线索管理](./lead)列表的行操作；
- [销售机会](./opportunity)详情的「跟进记录」页签。

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 跟进方式 | 是 | 默认「电话」 |
| 跟进时间 | 否 | 默认当前时间，可以补录过去的跟进 |
| 跟进内容 | 是 | 最长 1000 字：沟通了什么、客户反馈、达成的结论 |
| 下次跟进时间 | 否 | 必须晚于本次跟进时间 |
| 下次跟进计划 | 否 | 下次准备做什么 |

## 保存后的联动

| 跟进对象 | 更新内容 |
| --- | --- |
| 客户 | 客户的「最近跟进」时间和「下次跟进」时间 |
| 商机 | 商机所属客户的「最近跟进」和「下次跟进」时间 |
| 线索 | 线索的「最近跟进」时间；待跟进的线索变为「跟进中」 |

补录较早时间的跟进时，不会覆盖客户已有的更晚的「最近跟进」时间。

## 跟进提醒

- [定时任务](../monitor/job)「**客户跟进提醒**」每天 8:00 执行，对下次跟进时间在今天及以前（含已过期未跟进）的客户，向负责人发送消息「今天需要跟进客户「XXX」」（同一客户每天只提醒一次），点击消息进入客户管理。
- [首页待办](../guide/home#待办事项)显示「今天需要跟进的客户」数量。
- 客户管理中勾选「今日待跟进」可筛选今天及以前应跟进的客户；下次跟进时间已过的在列表和详情中显示为红色。
- 长期不跟进的客户会被自动回收到公海，见[客户管理](./customer#公海自动回收规则)。
