# 合同管理

合同管理用于登记与客户签订的销售合同，约定合同金额、期限和分期回款计划。合同可以接入审批，生效后关联[销售订单](../scm/sales)（或由[报价单](../scm/quotation)生成订单），系统按订单的出库应收和收款核销情况自动计算回款进度和各期回款状态，并对逾期回款发出提醒。

## 页面入口

客户关系 → 客户经营 → 合同管理

![合同管理列表](/images/manual/crm/contract-list.jpg)

## 查询条件与列表

查询条件：合同（编号、名称或客户）、状态、客户。

| 列 | 说明 |
| --- | --- |
| 合同 | 合同名称（点击打开详情）和合同编号（XSHT 开头，自动生成） |
| 客户 | |
| 商机 / 报价单 | 关联的商机名称和报价单号 |
| 合同期限 | 开始日期 ~ 结束日期，下方为签订日期 |
| 合同金额 | 含税 |
| 已回款 | 已回款金额和回款进度条 |
| 销售订单 | 关联的销售订单，点击跳转到销售订单 |
| 状态 | 草稿、审批中、执行中、已完成、已终止 |
| 负责人、备注 | |

行操作：**详情**；草稿状态下可**编辑**、删除。列表支持导出。

## 新增 / 编辑合同

点击「**新增合同**」打开表单页面；也可以在[销售机会](./opportunity)详情的「合同」页签点击「新建合同」，自动带入客户和商机。

![新增合同](/images/manual/crm/contract-add.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 合同名称 | 是 | 最长 128 字；选择商机时若为空自动取商机名称 |
| 客户 | 是 | 更换客户时清空关联的商机和报价单 |
| 关联商机 | 否 | 只能选择该客户的商机；选择后合同金额为空时取商机金额，并自动带出该商机下已批准的报价单 |
| 关联报价单 | 否 | 只能选择该客户的报价单（不含已丢单的）；合同生效后可以按报价单生成销售订单 |
| 签订日期 | 是 | 默认今天 |
| 开始日期 | 否 | 默认今天 |
| 结束日期 | 否 | 不能早于开始日期 |
| 合同金额（含税） | 是 | |
| 负责人 | 否 | 不选择时为你本人 |
| 主要条款 / 备注 | 否 | 最长 500 字 |
| 回款计划 | 否 | 见下文 |

### 回款计划

点击「**添加一期**」增加一行：计划回款日期默认为上一期日期加一个月（第一期为签订日期），金额默认为尚未计划的金额。每期填写**计划回款日期**（必填）、**金额**（必填，大于 0）和**说明**（如预付款、验收款、质保金）。表头显示计划合计和未计划金额。

::: warning 注意
回款计划合计不能超过合同金额。
:::

## 合同状态

| 状态 | 说明 | 可执行的操作 |
| --- | --- | --- |
| 草稿 | 新增后的状态 | 编辑、删除、提交 |
| 审批中 | 提交后、已发布「销售合同审批」流程时 | 等待审批；审批通过后变为执行中，拒绝或撤回后回到草稿 |
| 执行中 | 合同生效 | 关联销售订单、生成销售订单、完成、终止 |
| 已完成 | 合同履行完毕 | 只能查看 |
| 已终止 | 合同提前终止，记录终止原因 | 只能查看 |

## 合同详情与操作

![合同详情](/images/manual/crm/contract-detail.jpg)

详情页显示客户、合同金额、负责人、签订日期、合同期限、商机、报价单、销售订单、主要条款，以及**回款进度**和**回款计划**表（期次、计划日期、计划金额、已回款、状态、说明）。

右上角按钮（需要合同修改权限）：

| 按钮 | 显示条件 | 作用 |
| --- | --- | --- |
| **编辑** | 草稿 | 打开编辑表单，保存后详情自动刷新 |
| **提交** | 草稿 | 确认后提交，提交后合同不能再修改 |
| **生成销售订单** | 执行中、未关联订单、关联了报价单（需要销售订单新增权限） | 选择发货仓库，按报价单生成销售订单草稿并与合同关联 |
| **关联销售订单** | 执行中、未关联订单 | 选择该客户已审核的销售订单进行关联 |
| **完成** | 执行中 | 确认合同已履行完成 |
| **终止** | 执行中 | 填写终止原因后终止合同 |

### 提交与审批

- 系统内置「销售合同审批」流程（默认未发布）：销售主管 → 会计（合同评审）→ 金额 ≥ 30 万元时总经理。管理员在流程中心的[流程设计](../workflow/designer)中调整审批人后发布即可启用，条件分支可使用「合同金额」「合同编号」变量。
- 发布了流程时，提交后合同进入「审批中」，提示「已提交审批，审批通过后合同生效」；未发布流程时，提交后合同直接生效（执行中）。

### 关联销售订单的规则

- 只能关联同一客户的销售订单，且订单必须已审核（草稿、审批中的订单不能关联）。
- 一张销售订单只能关联一个合同。
- 生成销售订单需要合同关联了报价单，订单交货日期取合同开始日期。

## 回款计算

回款按关联销售订单出库形成的应收单的**已核销金额**计算，并按计划日期先后依次分摊到各期回款计划：

| 回款状态 | 判断规则 |
| --- | --- |
| 已回款 | 分摊到的回款金额 ≥ 计划金额 |
| 逾期 | 未全部回款且计划日期已过 |
| 部分回款 | 未到期，已有部分回款 |
| 未到期 | 未到期，尚无回款 |

[定时任务](../monitor/job)「**合同回款提醒**」每天 8:50 检查执行中合同的逾期回款计划，向合同负责人发送「合同回款逾期：合同号 第 N 期」提醒（每期只提醒一次）。

## 与其他模块的联动

- 合同关联的销售订单在供应链中[出库](../scm/sales-out)后生成[应收单](../fin/ar-ap)，财务[收款核销](../fin/settlement)后，合同的已回款金额自动更新。
- 客户详情的「合同」页签、商机详情的「合同」页签显示相关合同。
