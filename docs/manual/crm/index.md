# 客户关系

客户关系模块（顶部导航「客户关系」）覆盖从获客到售后服务的完整过程：市场活动带来**线索**，线索转化为**客户**，围绕客户推进**销售机会（商机）**，赢单后签订**合同**、生成**销售订单**交由供应链执行，成交后的问题通过**服务工单**处理，最后在**客户分析**中查看漏斗、客户价值和销售业绩。

客户主数据与供应链共用：在「客户关系」中新增的客户，同样出现在供应链的[客户资料](../scm/customer)、[销售订单](../scm/sales)、发货和财务[应收](../fin/ar-ap)中；反过来，供应链中已有的客户也会出现在客户管理中（没有负责人的在「公海」）。

## 功能清单

左侧菜单分为两组：

| 分组 | 页面 | 说明 |
| --- | --- | --- |
| 客户经营 | [客户管理](./customer) | 我的客户 / 团队客户 / 公海；领取、分配、转移、放回公海；联系人、跟进、客户 360 视图 |
| 客户经营 | [线索管理](./lead) | 记录潜在客户线索，跟进后转化为客户（可同时生成商机），或标记无效 |
| 客户经营 | [销售机会](./opportunity) | 商机看板与列表，推进销售阶段，赢单生成销售订单，输单记录原因 |
| 客户经营 | [跟进记录](./followup) | 汇总查看对客户、线索、商机的全部跟进；下次跟进提醒 |
| 客户经营 | [合同管理](./contract) | 销售合同、回款计划与回款进度，可接入审批，关联或生成销售订单 |
| 服务与营销 | [服务工单](./ticket) | 受理客户咨询、投诉、报修等；处理时限、序列号保修判断、备件领用、服务收费、满意度 |
| 服务与营销 | [市场活动](./campaign) | 活动预算与实际花费，统计带来的线索、商机、订单、回款和 ROI |
| 服务与营销 | [客户分析](./analysis) | 经营概览、销售趋势、销售漏斗、RFM 客户价值分层、来源与行业、销售排名、服务质量 |

## 典型业务流程

| 步骤 | 操作 | 页面 | 结果 |
| --- | --- | --- | --- |
| 1 | 创建市场活动，录入预算 | 市场活动 | 活动可被线索、商机选为来源 |
| 2 | 录入线索（选择来源、市场活动），电话 / 拜访跟进 | 线索管理 | 线索由「待跟进」变为「跟进中」 |
| 3 | 线索「转化」 | 线索管理 | 生成意向客户和首要联系人，可同时生成商机；线索变为「已转化」 |
| 4 | 维护联系人、写跟进、安排下次跟进 | 客户管理 | 客户的最近 / 下次跟进时间更新，到期时收到提醒 |
| 5 | 维护商机的产品明细，逐步「推进阶段」 | 销售机会 | 初步接洽 10% → 需求确认 30% → 方案报价 50% → 商务谈判 80% |
| 6 | 在商机详情中新建报价单、合同 | 销售机会 / 合同管理 | 合同提交（审批）后进入执行中 |
| 7 | 商机推进到「赢单」 | 销售机会 | 客户阶段变为成交客户 |
| 8 | 「生成销售订单」，或在合同中关联 / 生成销售订单 | 销售机会 / 合同管理 | 生成销售订单草稿，到供应链审核、出库 |
| 9 | 出库形成应收、收款核销 | 供应链、财务 | 合同的已回款金额和各期回款状态自动更新 |
| 10 | 客户报修、投诉时受理工单，处理、解决、关闭并记录满意度 | 服务工单 | 可领用备件、收取服务费 |
| 11 | 查看漏斗、RFM、销售排名 | 客户分析 | 经营决策 |

线索不是必经步骤：可以直接在客户管理中新增客户，或直接为已有客户新增商机。

## 定时任务与消息提醒

系统内置以下与客户关系相关的定时任务（可在系统监控的[定时任务](../monitor/job)中调整执行时间和参数）：

| 任务 | 默认执行时间 | 作用 |
| --- | --- | --- |
| 客户跟进提醒 | 每天 8:00 | 下次跟进时间在今天及以前的客户，向负责人发送「今天需要跟进客户」提醒 |
| 客户公海回收 | 每天 2:30 | 负责人超过 30 天（参数 `days`）没有跟进的未成交客户自动退回公海，并通知原负责人 |
| 合同回款提醒 | 每天 8:50 | 执行中合同的逾期回款计划，提醒合同负责人 |

首页待办中还会显示「今天需要跟进的客户」和「我处理中的服务工单」。

## 相关角色与权限

内置角色「销售员」负责报价、销售订单、客户与商机跟进，数据权限为「仅本人」。客户、线索、商机、跟进记录按**负责人所在部门 + 负责人**做数据权限过滤，看不到权限范围外的数据。主要按钮权限：

| 权限 | 作用 |
| --- | --- |
| 客户新增 / 客户修改 | 新增客户；修改非本人负责的客户和联系人（负责人本人始终可以修改） |
| 分配客户 | 分配、转移客户，把任何客户放回公海 |
| 领取公海客户 | 从公海领取客户 |
| 线索新增 / 修改 / 删除 / 转化 | 线索的各项操作（标记无效属于修改） |
| 商机新增 / 修改 / 删除、生成销售订单 | 商机的各项操作（推进阶段属于修改） |
| 写跟进 / 跟进删除 | 写跟进记录；删除他人的跟进记录（本人写的可以直接删除） |
| 合同新增 / 修改 / 删除 | 合同的各项操作（提交、关联订单、完成、终止属于修改） |
| 活动新增 / 修改 / 删除 | 市场活动 |
| 工单受理 / 工单处理 / 工单删除 | 受理工单；指派、处理、解决、关闭、重新打开、领用备件、收费；删除待处理工单 |

## 单据编号

线索（前缀 XL）、销售机会（SJ）、销售合同（XSHT）、服务工单（FW）的编号由系统自动生成，编号规则可在系统管理的「[编码规则](../system/code-rule)」中调整。
