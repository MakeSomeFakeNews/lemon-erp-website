# 销售机会

销售机会（商机）记录一笔可能成交的生意：客户、预计金额、产品明细、预计成交日期和所处的销售阶段。销售通过看板直观地管理进行中的商机，逐步推进阶段，赢单后一键生成销售订单或创建项目，输单时记录原因。

## 页面入口

客户关系 → 客户经营 → 销售机会

页面有两种视图，用工具栏左侧的「**看板**」「**列表**」切换，默认为看板。

## 看板视图

![商机看板](/images/manual/crm/opportunity-board.jpg)

- 看板按四个进行中的阶段分列：**初步接洽、需求确认、方案报价、商务谈判**，每列标题显示商机个数和金额合计。
- 顶部汇总进行中商机的个数、金额和**加权金额**（各商机 金额 × 赢单概率 之和，用于销售预测）。
- 每张卡片显示商机名称、客户、预计金额、预计成交日期（已过期显示红色，未填写显示「未定成交日期」）、负责人和赢单概率。点击卡片打开商机详情。
- 赢单、输单的商机不在看板中显示，请到「列表」中查看。
- 看板最多显示 500 个进行中商机，支持按关键字和「只看我的」筛选。

## 列表视图

![商机列表](/images/manual/crm/opportunity-list.jpg)

查询条件：商机（编号、名称或客户）、状态（进行中、赢单、输单，仅列表视图）、阶段（仅列表视图）、负责人「只看我的」。

| 列 | 说明 |
| --- | --- |
| 商机 | 商机名称（点击打开详情）和编号（SJ 开头，自动生成） |
| 客户 | 客户名称和联系人 |
| 阶段 | 销售阶段和赢单概率 |
| 预计金额 | |
| 预计成交 | 预计成交日期（进行中且已过期显示红色）；已关闭的显示成交 / 输单日期 |
| 负责人 | |
| 来源 | 来源渠道和市场活动 |
| 销售订单 | 已生成的销售订单号 |

行操作：**详情**；**编辑**（仅进行中的商机）；删除（仅未生成销售订单的商机）。

## 销售阶段与赢单概率

| 阶段 | 默认赢单概率 | 说明 |
| --- | --- | --- |
| 初步接洽 | 10% | 新建商机的默认阶段 |
| 需求确认 | 30% | |
| 方案报价 | 50% | |
| 商务谈判 | 80% | |
| 赢单 | 100% | 最终阶段，不能再修改阶段和商机内容 |
| 输单 | 0% | 必须填写输单原因；可以重新推进到其他阶段（重新打开） |

推进阶段时赢单概率自动改为该阶段的默认值；进行中的商机可在编辑时手工调整概率。每次阶段变更都会记录阶段日志，详情页的阶段进度条下方显示到达各阶段的日期和操作人。

## 新增 / 编辑商机

点击「**新增商机**」打开表单页面。

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 商机名称 | 是 | 最长 128 字 |
| 客户 | 是 | 搜索选择客户；更换客户时联系人清空 |
| 联系人 | 否 | 从该客户的联系人中选择 |
| 负责人 | 否 | 不选择时为你本人 |
| 预计成交日期 | 否 | |
| 销售阶段 | 否 | 仅新增时可选，限四个进行中阶段，默认初步接洽；「赢单」「输单」在下拉中置灰并注明「（请在商机详情中推进阶段）」。选择后赢单概率自动带出 |
| 赢单概率 | 否 | 0–100% |
| 预计金额 | 否 | 有产品明细时按明细自动合计，不能手工修改 |
| 来源、市场活动 | 否 | 市场活动只能选未取消的 |
| 产品明细 | 否 | 点击「添加产品」逐行填写产品（必填）、数量（必填）、含税单价（必填）、税率（默认 13%），金额自动计算 |
| 备注 | 否 | 最长 500 字 |

::: warning 注意
赢单后要生成销售订单，商机必须有产品明细。建议在方案报价阶段就维护好产品明细。
:::

已赢单或输单的商机不能编辑。

## 商机详情

![商机详情](/images/manual/crm/opportunity-detail.jpg)

详情页顶部是阶段进度条；输单时显示输单原因，已生成销售订单时显示订单号和「到「销售订单」中审核」的链接。基本信息包括客户、联系人、负责人、预计金额、赢单概率、预计成交、来源、成交 / 输单日期、创建时间、备注。

页签：

| 页签 | 内容 |
| --- | --- |
| 产品明细 | 产品、数量、含税单价、税率、金额 |
| 报价单 | 该商机的销售报价单；「**新建报价**」跳转到供应链的[销售报价](../scm/quotation)并带入客户和商机（需要报价权限） |
| 合同 | 该商机的合同；「**新建合同**」跳转到[合同管理](./contract)并带入客户和商机 |
| 跟进记录 | 对该商机的跟进时间线，可「写跟进」 |
| 附件 | 商机相关文件 |

右上角按钮：

| 按钮 | 显示条件 | 作用 |
| --- | --- | --- |
| **推进阶段** | 未赢单 | 打开推进销售阶段弹窗 |
| **生成销售订单** | 已赢单且未生成订单 | 按产品明细生成销售订单草稿 |
| **创建项目** | 已赢单（需要项目新增权限） | 跳转到[项目管理](../pm/project#从商机、销售订单创建项目)新建项目，带入客户、商机名称和金额 |

### 推进阶段

![推进销售阶段](/images/manual/crm/opportunity-stage.jpg)

1. 点击「**推进阶段**」，弹窗默认选中下一个阶段（商务谈判的下一步为赢单）。
2. 选择目标阶段，可以跳级，也可以回退。
3. 选择「输单」时必须填写**输单原因**（如价格过高、选择了竞品）。
4. 选择「赢单」时提示：赢单后客户变为成交客户，可以按产品明细生成销售订单。
5. 点击「确定」。

### 赢单生成销售订单

1. 商机推进到「赢单」后，点击「**生成销售订单**」。
2. 选择**发货仓库**和**交货日期**（不填取商机的预计成交日期）。
3. 确定后按产品明细生成销售订单（草稿，来源为客户关系），订单备注为「商机 编号 名称」。
4. 到「供应链 → [销售订单](../scm/sales)」中审核订单，之后即可发货出库。

## 与其他模块的联动

| 动作 | 联动结果 |
| --- | --- |
| 推进到赢单 | 客户阶段自动变为「成交客户」 |
| 生成销售订单 | 生成销售订单草稿，商机记录订单号 |
| 生成的销售订单被删除 | 商机自动解除与订单的关联，可以重新生成订单或删除商机 |
| 创建项目 | 在[项目管理](../pm/project)中新建项目，客户、合同金额从商机带入 |
| 在商机上写跟进 | 同时更新所属客户的最近 / 下次跟进时间 |
| 关联市场活动 | 市场活动统计商机数、赢单金额，以及商机生成订单的金额与回款 |

## 注意事项

::: warning 注意
- 已生成销售订单的商机不能删除。
- 已赢单的商机不能再修改阶段；输单的商机可以重新推进阶段。
:::
