# 客户分析

客户分析是客户关系的经营驾驶舱，集中展示客户、线索、商机、赢单的关键指标，以及销售趋势、销售漏斗、RFM 客户价值分层、来源与行业分析、销售人员排名和服务质量。页面只读，打开即自动计算。

## 页面入口

客户关系 → 服务与营销 → 客户分析

![客户分析](/images/manual/crm/analysis.jpg)

## 关键指标

| 指标 | 主值 | 副信息 |
| --- | --- | --- |
| 本月新增客户 | 本月新增的客户数 | 有负责人的客户数 · 公海客户数 |
| 本月新增线索 | 本月新增的线索数 | 本月转化的线索数 |
| 进行中商机 | 进行中商机金额合计 | 个数 · 加权金额（金额 × 赢单概率） |
| 本月赢单 | 本月赢单金额 | 赢单个数 |
| 赢单率 | 赢单数 ÷（赢单数 + 输单数） | 赢、输的累计个数 |
| 未关闭工单 | 未关闭的服务工单数 | 已超时工单数 · 平均满意度 |

## 图表与报表

| 区块 | 内容 |
| --- | --- |
| 近 12 个月销售与赢单 | 柱状图为每月销售额（不含税，图例为「销售额（不含税）」），折线为每月赢单金额 |
| 客户阶段分布 | 环形图：潜在、意向、成交、流失客户的数量和占比 |
| 销售漏斗 | 漏斗图展示到达各阶段的商机数；下方表格列出各阶段的当前商机数、金额、到达数和转化率 |
| 客户价值分层（RFM，近一年） | 各分层的客户数和销售额；下方注明统计口径（近一年的月数，F 为每月购买次数、M 为平均每次购买金额） |
| 客户 RFM 明细 | 上方为分群参数条（见下文）；表格列出每个客户的负责人、最近购买（R，距今天数）、购买次数（F）、每月次数、购买金额（M）、平均每次金额和所属分层，按购买金额从高到低排列，判断为「高」的 R、每月次数、平均每次金额显示为绿色，每页 10 条 |
| 来源分析 | 各来源的线索数、已转化数、转化率、商机数、赢单金额 |
| 行业分布（近一年不含税销售额） | 饼图：各行业的近一年不含税销售额和客户数（悬停提示「销售额（不含税）¥X」「客户 N 个」），未设置行业的显示为「未设置」 |
| 销售人员排名 | 按销售列出负责客户数、在途商机数和金额、本年赢单数和金额、本月跟进次数，前三名高亮 |
| 服务质量 | 按工单类型统计工单数、未关闭数、平均解决时长、按时解决率、平均满意度 |

### 销售漏斗的口径

- **到达**：曾经推进到该阶段的商机数（依据阶段变更记录）。
- **转化率** = 到达下一阶段的商机数 ÷ 到达本阶段的商机数。
- **当前商机**、**金额**：目前停留在该阶段的商机数和金额。

### RFM 客户分层规则

统计近一年（今天往前 12 个月）有销售出库的客户，计算三个指标：

| 指标 | 含义 |
| --- | --- |
| R（Recency） | 最近一次购买距今天数，越小越好 |
| F（Frequency） | 每月购买次数 = 近一年的销售出库单数 ÷ 月数 |
| M（Monetary） | 平均每次购买金额 = 近一年销售出库减退货的不含税金额（价税合计 − 税额）÷ 销售出库单数 |

高低的判断方式与进销存报表的[客户分析（RFM）](../scm/jxc-rfm#分群参数)共用，在「客户 RFM 明细」上方的分群参数条中选择：

- **固定阈值**（默认）：最近购买在 R 天之内（默认 30 天）、每月不少于 F 次（默认 1 次）、平均每次不少于 M 元（默认 1000 元）为「高」；
- **平均分**：R、F、M 各按五分位打 1–5 分，不低于全体平均分为「高」。

在页面上修改只对本次查看有效，点「恢复默认」回到本公司默认参数；有业务参数修改权限的用户可以「保存为默认」，即[业务参数](../system/biz-rule#客户分析)中的「客户分析」分组。

M 决定「重要 / 一般」，R 和 F 决定类型：

| R | F | 类型 | M 高 | M 低 |
| --- | --- | --- | --- | --- |
| 近 | 多 | 价值 | 重要价值 | 一般价值 |
| 近 | 少 | 发展 | 重要发展 | 一般发展 |
| 远 | 多 | 保持 | 重要保持 | 一般保持 |
| 远 | 少 | 挽留 | 重要挽留 | 一般挽留 |

建议：重要价值客户重点维护；重要保持客户需要主动回访；重要挽留客户有流失风险，应尽快跟进。

## 注意事项

::: tip 提示
客户分析的数据来自线索、商机、[销售出库与退货](../scm/sales-out)（成交趋势、行业分布和 RFM 的金额都是不含税净销售额：销售出库减销售退货的「价税合计 − 税额」，与客户详情的「近一年销售额（不含税）」同一口径）和服务工单，需要相应业务数据积累后才有意义。供应链「进销存报表」中也有一个[客户分析](../scm/jxc-rfm)：两者共用分群方式和默认阈值，金额口径相同（不含税），那里可以自选日期范围和区域，这里固定统计近一年（今天往前一年），并显示客户负责人。查看本页面需要「客户分析」菜单权限。
:::
