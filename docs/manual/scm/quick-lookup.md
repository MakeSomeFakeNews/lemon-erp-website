# 商品速查

商品速查给销售和管理人员在接待客户、电话报价时快速查商品：输入名称、规格或简拼，一屏看到每个商品的可用库存和一种价格（如最新售价、批发价1），点击即可联查商品图片、各仓库库存和历史成交价。电脑端和[微信小程序](../miniapp/sales#商品速查)使用同一套数据和同一份价格设置。

## 页面入口

供应链 → 销售 → 商品速查

内置角色中普通用户、总经理、采购员、销售员、仓库管理员、销售经理有此菜单。能看到哪些价格由各自已有的查看权限决定，见下方[价格的查看权限](#价格的查看权限)。

## 查询

顶部搜索框提示「名称、规格、编码、简拼」：可以输入商品名称、规格、编码、条码、拼音首字母，或去掉分隔符的规格缩写（规则同[搜索选择资料](../guide/common#搜索选择资料)）。输入时自动搜索，也可以按回车或点击搜索按钮；每次显示 50 条，更多时点击表格底部的「加载更多」。

结果列表：

| 列 | 说明 |
| --- | --- |
| # | 序号 |
| 商品 | 名称，下方为规格和编码；设置了[商品图片](../wms/material#商品图片)的显示主图缩略图 |
| 单位 | 基本单位，库存和价格都按此单位 |
| 库存 | 全部仓库的可用数量（库存 − 冻结），为 0 时灰色显示 |
| 价格 | 「查询价格」中选择的一种价格（含税、基本单位、本位币），没有价格时显示「-」；选择「不显示价格」时没有这一列 |

## 查询价格

工具栏的「查询价格」下拉框选择列表中显示哪一种价格，选择后立即保存（提示「已保存」），跟随账号保存，手机小程序中看到的是同一个设置。没有选择过时显示最新售价。

| 分组 | 可选价格 | 说明 |
| --- | --- | --- |
| 进货类 | 参考进货价 | 物料资料中的参考成本价 |
| 进货类 | 最新进价 | 最近一次采购入库的单价 |
| 成本 | 库存均价 | 移动加权平均成本 |
| 销售类 | 最新售价 | 最近一次销售出库的单价 |
| 销售类 | 零售价、批发价1～8 | [商品价格](./goods-price)中的价格，只列出已启用的价格列，名称取「[价格列设置](../wms/material#价格列设置)」中的名称 |
| 其他 | 不显示价格 | 只显示数量 |

最新进价、最新售价取优惠前的单价，不含赠品，只统计你看得到的出入库单。

### 价格的查看权限

速查不另设权限按钮，沿用已有的查看权限（与[价格参考](./price-list#价格参考)的规则一致），并且由服务器过滤，不只是页面隐藏：

| 价格 | 需要的权限（任一） |
| --- | --- |
| 进货类（参考进货价、最新进价、进价历史） | 采购订单或采购入库的查看权限 |
| 库存均价 | 「查看成本金额」 |
| 销售类（最新售价、售价历史） | 销售报价、销售订单或销售出库的查看权限 |
| 零售价、批发价 | 同销售类，或有「商品价格」页面权限 |

- 没有权限的价格在下拉框中置灰并标「无权限」，不能选择；
- 之前选过的价格后来没有权限或价格列被停用时，列表不返回价格，工具栏提示「所选价格没有查看权限，只显示数量」。

按内置角色：销售员、销售经理只能看销售类价格，采购员只能看进货类价格，总经理、仓库管理员全部可看，普通用户按其查看权限。

## 点击联查

工具栏右侧提示「点击商品看图片、点击库存看分布、点击价格看历史参考」。

### 商品图片

点击商品名称打开「商品图片」，显示该商品的全部图片（第一张为主图），点击放大浏览。没有图片时提示在「物料管理」的商品图片中上传，见[物料管理 - 商品图片](../wms/material#商品图片)。

### 库存分布

点击库存数量打开「库存分布」，列出各仓库、库位、批次的数量，以及有效期、冻结数量，底部为合计。

### 价格历史

点击价格打开「价格历史」。价格为进货类（参考进货价、最新进价）或库存均价时默认打开进价历史，其他打开售价历史；售价、进价都能看的用户可以在顶部切换「售价」「进价」，只能看其中一种的只显示该种。

**历史参考**列出：

| 项目 | 说明 |
| --- | --- |
| 最近第 1 / 2 / 3 次 | 最近连续 3 次成交 |
| 系统最新价 | 最近一次成交的价格 |
| 系统最高价、系统最低价 | 历史最高、最低单价，同价时取最近一次 |

每项显示日期、往来单位、数量和单价，没有记录时显示「暂无记录」。按看得到的出入库单统计（看不到的单据不计入，所以「系统最高 / 最低」是你权限范围内的结果），单价为优惠前的含税单价，不含赠品。

底部按钮：

- **更多交易历史**：切换到交易明细，可按日期范围、单位编号 / 名称 / 电话筛选，分页显示；列为日期、数量、单价、单位名称、单位编号、单号、制单、复核（审核人）；
- **更多内容**：打开与销售订单明细相同的「[价格参考](./price-list#价格参考)」，含报价、销售、进货历史和客户、供应商的价格对比，按权限显示（只能看售价的用户看不到进货、供应商对比）。

::: tip 提示
- 没有查看某种价格的权限时，价格历史中不显示该种，交易历史也查询不到。
- 速查只读，不修改任何数据；要修改零售价、批发价请到[商品价格](./goods-price)。
:::
