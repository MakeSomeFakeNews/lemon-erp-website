# 周转分析

周转分析按一段时间的**期初库存、期末库存和本期出库**计算每个商品的库存周转天数和周转率，回答「这批货要多少天才能卖完、一段时间内库存周转了几次」，找出周转慢、占用库存时间长的商品。

与[商品分析](./jxc-goods)中的「周转」页签相比：商品分析按当前库存做快速排行；周转分析按所选期间的期初、期末库存计算，可以选择按数量或按成本价、零售价、批发价的金额计算，并能筛选本期有无出库的商品。

## 页面入口

供应链 → 进销存报表 → 周转分析

需要「周转分析」菜单权限（`bi:jxc:turnover`），内置角色中超级管理员、总经理、会计、普通用户、采购员、仓库管理员拥有，见[进销存报表概述](./jxc#权限)。

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 日期范围 | 必须选择，默认本月，最长 366 天；快捷选项有本月、上月、本年、近 12 个月 |
| 全部仓库 | 选择后，期初期末库存和本期出库都只按该仓库计算；不选为全部仓库 |
| 全部类别 / 全部品牌 | 物料分类、品牌；选择上级分类时包含其所有下级分类 |
| 编码 / 名称 / 规格 / 简拼 | 编码、名称、规格包含输入内容，也可以输入拼音首字母或去掉分隔符的规格缩写，规则同[搜索选择资料](../guide/common#搜索选择资料) |
| 计算维度 | 按数量或按金额计算周转，见下文[计算维度](#计算维度) |
| 数据筛选 | 「全部」（默认）、「不显示本期出库为 0」「只显示本期出库为 0」 |
| 剔除期初为 0 且本期无出库 | 默认勾选：期初库存为 0、本期也没有出库的商品（例如本期才进货、还没卖的）不列出 |

修改条件后点「**查询**」。期初库存、期末库存、本期出库都为 0 的商品始终不列出。

### 计算维度

| 计算维度 | 金额的单价 | 需要的权限 |
| --- | --- | --- |
| 销售数量（默认） | 按数量计算周转；金额列按库存均价 | 无。有库存查询的「**查看成本金额**」按钮权限时才显示金额列，没有时只显示数量 |
| 成本价 | 库存均价（实时移动加权平均，没有时取最近一期成本核算单价，再没有取参考成本价） | 「查看成本金额」，没有该权限时下拉框中没有此项 |
| 零售价 | 商品资料中的零售价（含税） | 售价查看权限：销售报价、销售订单、销售出库任一查看权限，或「商品价格」页面权限（同[商品速查](./quick-lookup#价格的查看权限)） |
| 批发价（各价格列） | 商品资料中所选价格列的批发价（含税）；下拉框中显示[价格列设置](../wms/material#价格列设置)中启用的列，名称为设置的名称 | 同零售价 |

按金额计算时，金额 = 数量 × 对应单价。同一个商品的单价不变，所以**单个商品的周转天数、周转率与按数量的结果相同**；区别在于：

- **合计行**按金额加权计算，单价高的商品对合计的影响更大；
- 商品资料中**没有设置该价格**的商品，金额列为空，周转天数、周转率也不计算（显示「—」），合计金额只包含有价格的商品。

## 计算口径

表格上方的灰色说明写明本次查询的口径，例如「期初库存为开始日期之前、期末库存为截至结束日期的库存（当前库存减去业务日期在其后的出入库，不含供应商寄售仓）；周转最慢的排在前面。按数量计算；金额列按库存均价。」

| 项目 | 口径 |
| --- | --- |
| 期初库存 | 开始日期之前的库存（所选仓库，不含供应商寄售仓）：当前库存减去业务日期在开始日期及之后的出入库 |
| 期末库存 | 截至结束日期的库存：当前库存减去业务日期在结束日期之后的出入库；结束日期为今天时与[库存查询](../wms/stock)一致 |
| 本期出库 | **销售出库 − 销售退货**（按所选仓库，与[销售报表](./jxc-sales)、[积压分析](./jxc-overstock)一致）；调拨、领料、盘点等不计入 |
| 期间天数 | 结束日期 − 开始日期 + 1，例如 11 月 1 日～11 月 30 日为 30 天 |

**库存周转天数 = 期间天数 × (期初库存 + 期末库存) ÷ 2 ÷ 本期出库**

**库存周转率 = 本期出库 ÷ ((期初库存 + 期末库存) ÷ 2) × 100%**

其中 (期初库存 + 期末库存) ÷ 2 为平均库存。表格中显示「—」的情况：

- 平均库存不大于 0 时，周转天数、周转率都显示「—」；
- 本期出库不大于 0（没有卖出，或退货多于出库）时，周转天数显示「—」；周转率按出库为 0 计算，显示 0.00%；
- 按金额计算时，没有设置所选价格的商品显示「—」。

**示例**：期间为 11 月 1 日～11 月 30 日（30 天），某商品期初库存 100、期末库存 60、本期销售出库 90、销售退货 10：本期出库 80，平均库存 80，周转天数 = 30 × 80 ÷ 80 = 30.0 天，周转率 = 80 ÷ 80 × 100% = 100.00%。

## 列表

每个商品一行，**周转最慢的排在前面**（有库存没有出库的排最前，没有库存只有出库的排最后）。部分列头带问号图标，鼠标移上去显示口径说明。

| 列 | 说明 |
| --- | --- |
| 编号 | 有库存查询权限时为链接，点击打开该商品的[经营历史](../wms/stock#经营历史) |
| 商品、类别、品牌、规格、单位 | — |
| 周转天数 | 保留一位小数，公式见上文 |
| 周转率 | 百分数，保留两位小数 |
| 本期出库数量、本期出库金额 | 销售出库 − 销售退货 |
| 期初库存数量、期初库存金额 | 开始日期之前的库存 |
| 期末库存数量、期末库存金额 | 截至结束日期的库存 |
| 操作 | 有库存查询权限时显示「经营历史」（选了仓库时默认该仓库）和「库存分布」（该商品**当前**在各仓库、库位、批次的数量） |

金额列只在按金额计算，或按数量计算且有「查看成本金额」权限时显示，没有权限时系统也不返回金额。

表格底部的**合计行**为全部符合条件的商品（不只是当前页）的合计：第一列显示「合计 · N 行」，数量、金额为合计，周转天数、周转率按合计的数量（按金额计算时按合计金额）计算。

## 导出

点表格右上角的「**导出**」，按当前条件导出全部商品（最多 5000 行），列与表格一致，最后一行为合计行，文件名为「周转分析_开始日期_结束日期」。

## 数据权限

- 本期出库来自出入库单，按出入库单的「制单人部门 + 制单人」过滤，与[商品分析](./jxc-goods)、[积压分析](./jxc-overstock)一致，见[进销存报表概述 · 权限](./jxc#权限)；
- 期初、期末库存不受数据权限限制。

::: tip 提示
- 期间太短时出库少，周转天数会偏大；对比不同商品时建议用相同的期间，按月或按季度查看。
- 周转慢的商品可以结合[积压分析](./jxc-overstock)查看多压的数量和资金占用，或在[滞销畅销](./jxc-sales-rate)中按进货量的销售比例判断是否滞销。
:::
