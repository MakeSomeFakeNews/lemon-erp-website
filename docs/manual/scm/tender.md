# 招标采购

招标采购用于金额较大、需要公平竞争的采购：采购方发布招标（物料、数量、投标截止时间、邀请的供应商），供应商在 [供应商门户](../portal/supplier#招标投标) 在线投标，**开标前采购方看不到任何报价**；截止后开标比价，选定中标供应商后按其报价生成采购合同或采购订单。没有门户账号的供应商，可以由采购员代录线下标书。

## 页面入口

供应链 → 采购寻源 → 招标采购

![招标采购列表](/images/manual/scm/tender-list.jpg)

## 列表

**筛选**：状态、关键字（招标编号、标题）。

**列表列**：

| 列 | 说明 |
| --- | --- |
| 招标编号 / 标题 | 点击打开详情 |
| 投标截止 | 截止时间；投标中的显示剩余时间（如「剩余 3 天」），已截止的显示「已截止，可开标」 |
| 投标 | 已投标家数 / 邀请家数 |
| 中标 | 中标供应商，下方显示生成的合同号或订单号 |
| 状态 | 草稿 / 投标中 / 已开标 / 已定标 / 已取消 |
| 创建人 | |

工具栏有「新增招标」。

## 新增招标

![新增招标](/images/manual/scm/tender-form.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 招标标题 | 是 | |
| 投标截止时间 | 是 | 默认 7 天后 17:00，必须晚于当前时间 |
| 邀请供应商 | 是 | 可多选，不能选停用的供应商。提示：发布后通知供应商的门户账号；没有门户账号的供应商可由采购代录线下标书 |
| 招标说明 | 否 | 技术要求、资质要求、付款与交货条件等，最多 500 字 |

**招标物料**：点「添加物料」，每行填写物料（必填）、数量（必填）、需求日期、要求（规格、技术要求）。物料不能重复。

只有草稿可以编辑、删除。

## 招标详情

![招标详情](/images/manual/scm/tender-detail.jpg)

详情显示状态、投标截止、开标时间、中标供应商、生成单据、定标说明、招标说明，以及：

- **邀请的供应商**：每家显示「已投标」或「未投标」。
- **招标物料**：开标前显示物料清单，并提示「已收到 N 份标书，报价在开标后可见」。
- **比价（开标后）**：行是物料，列是各投标供应商，每格显示含税单价和小计，绿色为该物料最低价；底部「投标总价 / 交货期」行显示每家的总价、交货天数和投标说明，最低总价标绿，已开标时每家下方有「定标给该供应商」链接。
- **附件**：上传招标文件、标书扫描件等。

**右上角按钮**（按状态）：

| 状态 | 按钮 |
| --- | --- |
| 草稿 | 「编辑」「删除」「发布」（确认「发布后通知邀请的供应商投标，不能再修改，确定？」） |
| 投标中 | 「代录标书」「开标」（确认「开标后各家报价公开，供应商不能再修改，确定？」） |
| 已开标 | 「定标」 |
| 草稿、投标中、已开标 | 「取消招标」 |

## 操作流程

1. **发布**：草稿 → 投标中。投标截止时间已过时不能发布，需先修改。发布后系统给邀请的每家供应商的门户账号发送站内消息「招标邀请」，内容包含截止时间。
2. **投标**：供应商在门户提交投标，每个物料都必须报价，截止前可以修改。采购员也可以点「代录标书」：选择投标供应商（只能选邀请的供应商）、交货期（天），逐个物料填写含税单价、税率，填写投标说明。同一供应商再次提交会覆盖之前的标书。
3. **开标**：投标截止后，或者邀请的供应商都已投标时，可以开标（否则「开标」按钮不可用，提示「投标截止或邀请的供应商都已投标后才能开标」）。开标后报价公开，供应商不能再修改。
4. **定标**：点「定标」或比价表中的「定标给该供应商」，弹出定标对话框：
   - **中标供应商**（必填）：默认投标总价最低的供应商。
   - **定标后生成**（必填）：
     - 「采购合同」：按中标价生成「固定数量合同」草稿，合同物料和数量上限为招标物料和数量；可填写合同生效日期（默认今天）、到期日期（默认一年）。合同需到 [采购合同](./contract) 中提交生效。
     - 「采购订单」：按中标价生成草稿采购订单（来源「招标」），须选择收货仓库；明细交货日期取需求日期，没有时按投标交货天数推算。
     - 「不生成」：只记录定标结果。
   - **定标说明**：如「综合价格与交期最优」。

定标后中标供应商收到站内消息「中标通知」；在门户中，每家供应商只能看到自己是否中标，看不到其他供应商的报价。

## 单据状态

| 状态 | 说明 |
| --- | --- |
| 草稿 | 可编辑、删除、发布、取消 |
| 投标中 | 供应商投标、采购代录标书；可开标、取消 |
| 已开标 | 报价公开，可定标、取消 |
| 已定标 | 已选定中标供应商 |
| 已取消 | 终止招标 |

## 注意事项

::: warning 注意
开标前任何人（包括管理员）在系统中都看不到投标报价，列表只显示已投标的供应商和提交时间。请在投标截止后再开标，以保证公平。
:::

::: tip 提示
招标按创建人部门和创建人控制数据权限。只做一般比价、不需要密封投标时，使用 [询价比价](./inquiry) 更方便。
:::
