# 商品价格

商品价格用于集中维护每个商品的多档销售价格：零售价和批发价 1～8（含税、按基本单位、人民币）。在表格中可以一次修改很多商品的价格，也可以按统一价格、零售价的比例或参考成本加价批量填充。这些价格与客户的[价格等级](./customer#价格等级与执行价)配合使用：开单时没有客户执行价、价目价时，按客户的价格等级带出对应列的价格，见[开单默认价](./price-list#开单默认价)。

适合批发、分销等「一个商品对不同客户有几档固定价格」的企业；按客户、数量、有效期精细定价仍使用[销售价目表](./price-list)。

## 页面入口

供应链 → 销售 → 商品价格

![商品价格](/images/manual/scm/goods-price.jpg)

## 价格列

物料共有 9 个价格列：零售价、批发价1 ～ 批发价8。哪些列启用、各列叫什么名称，在「仓库 → 基础资料 → 物料管理」工具栏的「[价格列设置](../wms/material#价格列设置)」中设置，例如把「批发价1」改名为「一级经销价」。默认只启用零售价和批发价1～3。

- 停用的价格列在本页、物料表单、物料列表、导入导出、客户的价格等级选择中都隐藏，已经填写的价格保留，重新启用后恢复显示；
- 停用的价格列不参与开单默认价。

## 列表

**查询条件**：物料（编码、名称或条码）、分类、品牌；点「展开」还有状态（启用 / 停用）。

**列表列**：

| 列 | 说明 |
| --- | --- |
| 物料 | 名称，下方为编码和规格 |
| 单位 | 基本单位，价格都按此单位 |
| 分类、品牌 | 品牌是物料的「品牌」字段（业务字典「商品品牌」） |
| 参考成本 | 物料的参考成本价，只读，没有时显示「-」 |
| 零售价、批发价… | 启用的价格列，列名为价格列设置中的名称 |

列表只列出可以开单的物料，多规格物料的「款式」不在其中（价格按各个 SKU 维护）。按物料编码排序，默认每页 50 条。

**工具栏**：「保存修改」「放弃修改」「批量填充」，右侧导出（按当前查询条件导出 Excel）、刷新等。工具栏上的提示：「直接在表格中修改价格（含税、基本单位），修改过的单元格高亮，点「保存修改」一次保存；翻页、筛选前请先保存。」

## 修改价格

有「商品价格维护」权限时，价格列是输入框（不能小于 0，最多 4 位小数），没有权限时只显示价格。

1. 用查询条件找到要调价的商品；
2. 直接在表格中修改价格，修改过的单元格以蓝色粗体高亮，「保存修改」按钮上显示已修改的商品数，如「保存修改 (3)」；清空单元格表示不设置该价格；
3. 点「**保存修改**」，一次保存本页所有修改，提示「已保存 N 个商品的价格」。只保存改过的单元格，同一商品没改的价格列保持原值（即使其间别人在物料表单中改过）；点「**放弃修改**」把本页恢复为修改前的价格。

有未保存的修改时，点查询、重置、翻页或刷新会先提示「有未保存的价格修改，确定放弃吗？」，确定后修改丢失。

## 批量填充

点「**批量填充**」，在下拉中选择要填充的价格列（只列出启用的列），打开「批量填充 列名」对话框：

![批量填充](/images/manual/scm/goods-price-fill.jpg)

| 方式 | 填写 | 结果 |
| --- | --- | --- |
| 统一价格 | 数值 | 本页每个商品的该列都改为这个价格 |
| 按零售价比例 | 比例（%） | 该列 = 零售价 × 比例 ÷ 100，例如批发价1 按零售价的 85% 填 85；没有零售价的商品不变。填充「零售价」时没有这个选项 |
| 按参考成本加价 | 比例（%） | 该列 = 参考成本 ×（100 + 比例）÷ 100，例如成本加价 30% 填 30；没有参考成本的商品不变 |

计算结果保留 4 位小数。对话框提示「只修改当前页的行，保存后生效」：点「确定」后只是填入表格（单元格高亮），核对无误后仍需点「保存修改」。需要调整多页商品时，可以先把每页条数调大，或按分类、品牌筛选后逐页填充、保存。

## 与其他功能的关系

- 物料的价格也可以在[物料管理](../wms/material#销售价格与品牌)的编辑表单中逐个修改，或通过物料导入批量填写；
- 客户资料中的「价格等级」决定该客户开单时取哪一列，见[客户](./customer#价格等级与执行价)；
- 销售订单、销售报价、销售出库 / 退货直接开单时，按[开单默认价](./price-list#开单默认价)的顺序取价，价格等级价、零售价排在客户执行价和价目表之后。

## 权限

| 操作 | 需要的权限 |
| --- | --- |
| 查看商品价格 | 「商品价格」菜单 |
| 修改、批量填充、保存 | 「商品价格维护」按钮权限 |
| 设置价格列名称、启用 | 物料管理的「价格列设置」按钮权限 |

内置角色中，普通用户、总经理、销售员可以查看本页；销售经理还可以修改（有「商品价格维护」权限）。

## 注意事项

::: tip 提示
- 价格都是含税单价、按基本单位、人民币。开单时如果按辅助单位录入，系统按换算率折算；外币订单按汇率折算。
- 在本页批量保存的价格不记入物料的变更记录；需要留痕的调价，可以在物料编辑表单中修改。
- 多规格物料生成 SKU 时不继承款式的品牌和价格，生成后在本页为各个 SKU 填写。
:::
