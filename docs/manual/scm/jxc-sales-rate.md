# 滞销畅销

滞销畅销按一段时间内**卖出的数量占进货（或期初库存加进货）的比例**判断商品是滞销还是畅销：进了 100 件只卖出 20 件，销售比例 20%，属于滞销；进了 100 件卖出 95 件，销售比例 95%，属于畅销。滞销和畅销在同一个页面中切换。

与[商品分析](./jxc-goods)中的「畅销」「滞销」页签相比：商品分析按销量排行、按销量阈值判断滞销；这里按销量与进货量的比例判断，进得多卖得少的才算滞销，适合检查采购是否过量。

## 页面入口

供应链 → 进销存报表 → 滞销畅销

需要「滞销畅销」菜单权限（`bi:jxc:salesRate`），内置角色中超级管理员、总经理、会计、普通用户、采购员、仓库管理员拥有，见[进销存报表概述](./jxc#权限)。

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 滞销 / 畅销 | 页面左上角的分段按钮，默认「滞销」；切换后阈值恢复为该项的默认值并立即查询 |
| 日期范围 | 必须选择，默认本月，最长 366 天；快捷选项有本月、上月、本年、近 12 个月 |
| 全部仓库 | 选择后，销售量、进货量、期初库存都只按该仓库计算；不选为全部仓库 |
| 全部类别 / 全部品牌 | 物料分类、品牌；选择上级分类时包含其所有下级分类 |
| 编码 / 名称 / 规格 / 简拼 | 规则同[积压分析](./jxc-overstock#查询条件) |
| 销售基数 | 「本期进货量」（默认）或「期初库存 + 本期进货量」，见下文 |
| 销售比例 ≤ / 销售比例 ≥ | 阈值（%，不能小于 0，可保留两位小数）。滞销时为「销售比例 ≤」，默认 **80%**；畅销时为「销售比例 ≥」，默认 **10%**，都可以修改 |

修改条件后点「**查询**」。

## 计算口径

**销售比例 = 本期净销量 ÷ 销售基数 × 100%**

| 项目 | 口径 |
| --- | --- |
| 本期净销量（销售量） | 销售出库 − 销售退货（按所选仓库，与[销售报表](./jxc-sales)一致） |
| 本期进货量 | 采购入库 − 采购退货（按所选仓库） |
| 期初库存 | 开始日期之前的库存（所选仓库，不含供应商寄售仓），口径同[周转分析](./jxc-turnover#计算口径) |
| 销售基数 | 「本期进货量」时为本期进货量；「期初库存 + 本期进货量」时为两者之和 |

- **滞销**列出销售比例不高于阈值的商品，按比例从低到高排序；
- **畅销**列出销售比例不低于阈值的商品，按比例从高到低排序；
- 以上为默认顺序，可点击列头按其他列排序，见[列头排序](../guide/common#列头排序)；
- 销售基数不大于 0 的商品（例如期间没有进货，或期初库存加进货不大于 0）无法计算比例，**不列出**。

销售基数选「本期进货量」时，只有期间有进货的商品才参与；想把原有库存也算进去（例如期间没有进货、只卖老库存的商品），选「期初库存 + 本期进货量」。

表格上方的灰色说明写明本次查询的口径，例如「销售比例不高于 80% 的商品，比例从低到高。销售比例 = 本期净销量（销售出库 − 销售退货）÷ 销售基数 × 100%；……基数不大于 0 的商品（期间没有进货等）无法计算比例，不列出。」

**示例**：本月某商品采购入库 120 件、采购退货 20 件，销售出库 30 件、销售退货 5 件。销售基数选「本期进货量」：基数 100，销售量 25，销售比例 25.00%，在滞销（默认 ≤ 80%）中列出，在畅销（默认 ≥ 10%）中也会列出。两个页签的阈值是独立的，同一个商品可能同时满足，可按需要调整阈值。

## 列表

| 列 | 说明 |
| --- | --- |
| 编号 | 有库存查询权限时为链接，点击打开该商品的[经营历史](../wms/stock#经营历史) |
| 商品、类别、品牌、规格、单位 | — |
| 销售量 | 本期净销量，鼠标移到问号上显示「本期出库 = 销售出库 − 销售退货……调拨、领料、盘点等不计入」 |
| 期初库存、本期进货 | 只在销售基数为「期初库存 + 本期进货量」时显示 |
| 销售基数 | 本期进货量，或期初库存 + 本期进货量 |
| 销售比例 | 百分数，保留两位小数 |
| 操作 | 有库存查询权限时显示「经营历史」和「库存分布」 |

表格底部的**合计行**为全部符合条件的商品（不只是当前页）的合计：第一列显示「合计 · N 行」，数量为合计，销售比例按合计的销售量 ÷ 合计的销售基数计算。

## 导出

点表格右上角的「**导出**」，按当前条件导出全部商品（最多 5000 行），最后一行为合计行，文件名为「滞销分析_开始日期_结束日期」或「畅销分析_开始日期_结束日期」。

## 数据权限

- 销售量、进货量来自出入库单，按出入库单的「制单人部门 + 制单人」过滤，见[进销存报表概述 · 权限](./jxc#权限)；
- 期初库存不受数据权限限制。
