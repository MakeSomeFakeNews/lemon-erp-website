# 客户

客户档案记录客户的基本信息、等级、销售渠道、信用额度和账期。客户等级决定 [价目表](./price-list) 和 [促销](./promotion) 的适用范围（价目表还可以为单个客户设置专属价），负责销售是销售订单的默认业务员，信用额度控制销售订单审核和出库，账期决定[应收单](../fin/ar-ap)到期日。销售渠道为「经销商」的客户可以开通[经销商门户](../portal/dealer)。

客户关系模块中的[客户](../crm/customer)与这里是同一份档案：CRM 中[线索转化](../crm/lead#转化线索)、[领取](../crm/customer#领取公海客户)的客户也会出现在本列表。

## 页面入口

供应链 → 往来单位 → 客户

![客户列表](/images/manual/scm/customer-list.jpg)

## 列表

**查询条件**：客户（编码或名称）、等级、渠道、状态（点「展开」显示更多）。

**列表列**：

| 列 | 说明 |
| --- | --- |
| 客户 | 名称，下方为编码 |
| 等级 | 重点客户 / 普通客户 / 潜在客户 |
| 渠道 | 直销 / 经销商；经销商下方显示授权区域；设置了负责销售时显示「负责 …」 |
| 联系人 | 下方为电话 |
| 信用额度 | 未设置显示「不限」 |
| 账期 | 为 0 显示「现结」 |
| 地址、状态、备注 | 状态为启用 / 停用开关，有编辑权限时可直接切换 |
| 自定义字段 | 在「系统管理 → [自定义字段](../system/custom-field)」中为客户定义并勾选了「列表显示」的扩展字段 |

**工具栏**：「新增客户」「导入」；右侧导出、刷新等。

**行操作**：「资料」（附件、变更记录）、「编辑」、「门户账号」（仅经销商，见 [开通门户账号](../portal/account)）、「删除」（已有销售订单的客户不能删除，提示改为停用）。

## 新增 / 编辑客户

![新增客户](/images/manual/scm/customer-form.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 客户编码 | 是 | 如 C001，只能包含字母、数字、下划线和短横线，最多 32 位，不能重复 |
| 客户名称 | 是 | |
| 等级 | 否 | 价目表、促销按等级匹配 |
| 销售渠道 | 否 | 直销 / 经销商，默认直销。经销商可开通经销商门户，在门户订货、上报渠道库存 |
| 负责销售 | 否 | 新建销售订单时默认作为订单的业务员（用于计算[销售提成](./commission)）；经销商门户的订单记到其名下审核 |
| 授权区域 | 否 | 渠道为经销商时显示，如「华南（广东、广西、海南）」 |
| 账期 | 否 | 默认 30 天，0 ~ 365 天。应收单到期日 = 出库日期 + 账期 |
| 联系人、联系电话 | 否 | 物流发运时默认带出 |
| 信用额度 | 否 | 审核销售订单、销售出库时校验应收余额和未完成订单金额，不填不限制 |
| 纳税人识别号 | 否 | |
| 收货地址 | 否 | 物流发运时默认带出 |
| 备注 | 否 | |

管理员在「系统管理 → [自定义字段](../system/custom-field)」中为「客户」定义了扩展字段（如行业细分、开票要求）时，表单末尾出现「扩展信息」分区，必填的扩展字段不填不能保存。

## 信用额度控制

- **审核销售订单时**：应收余额 + 其他未完成订单金额 + 本单金额 ≤ 信用额度，否则不能审核。
- **销售出库前**：应收余额 + 全部未完成订单金额 ≤ 信用额度，否则暂停出库。
- 未完成订单指审批中、已审核、部分完成的销售订单。
- 控制方式可在「系统管理 → [业务参数](../system/biz-rule)」的「客户信用额度控制」中调整：审核和出库时控制（默认）、只在出库时控制、不控制。
- 客户的信用占用（额度、应收余额、未完成订单、可用额度）可在客户关系模块的客户详情中查看。

详见 [销售订单 - 信用额度与账期](./sales#信用额度与账期)。

## 导入

点「[导入](../guide/common#导入-excel)」，下载模板后填写：客户编码*、客户名称*、客户等级、联系人、联系电话、收货地址、纳税人识别号、信用额度、账期(天)、备注。任何一行有错误时整批不导入。

## 注意事项

::: tip 提示
停用的客户不能新建销售订单、返利协议；经销商门户只对渠道为「经销商」且启用的客户开放，把渠道改回直销后其门户账号无法再订货。
:::
