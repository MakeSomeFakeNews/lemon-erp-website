# 客户

客户档案记录客户的基本信息、等级、销售渠道、信用额度和账期。客户等级决定 [价目表](./price-list) 和 [促销](./promotion) 的适用范围（价目表还可以为单个客户设置专属价），价格等级和执行价决定开单时默认带出的单价，负责销售是销售订单的默认业务员，信用额度控制销售订单审核和出库，账期决定[应收单](../fin/ar-ap)到期日。销售渠道为「经销商」的客户可以开通[经销商门户](../portal/dealer)。

客户关系模块中的[客户](../crm/customer)与这里是同一份档案：CRM 中[线索转化](../crm/lead#转化线索)、[领取](../crm/customer#领取公海客户)的客户也会出现在本列表。

## 页面入口

供应链 → 往来单位 → 客户

![客户列表](/images/manual/scm/customer-list.jpg)

## 列表

**查询条件**：客户（编码、名称、联系人、电话，也可输入拼音首字母，规则同[搜索选择资料](../guide/common#搜索选择资料)）、等级、区域、渠道、状态（点「展开」显示更多）。

**列表列**：

| 列 | 说明 |
| --- | --- |
| 客户 | 名称，下方为编码；已被合并的客户在名称旁显示「已合并」标签（鼠标悬停显示合并到哪个客户），有[关联供应商](#与供应商关联)的下方显示「关联供应商 …」 |
| 等级 | 重点客户 / 普通客户 / 潜在客户 |
| 价格等级 | 客户适用的价格列名称，如「零售价」「批发价1」；导出时为名称 |
| 区域 | 客户的区域（业务字典「客户区域」），未填显示「-」 |
| 渠道 | 直销 / 经销商；设置了负责销售时显示「负责 …」 |
| 联系人 | 下方为电话 |
| 信用额度 | 未设置显示「不限」 |
| 账期 | 为 0 显示「现结」 |
| 地址 | 客户地址，过长时省略显示 |
| 状态 | 启用 / 停用开关，有编辑权限时可直接切换 |
| 备注 | 过长时省略显示 |
| 自定义字段 | 在「系统管理 → [自定义字段](../system/custom-field)」中为客户定义并勾选了「列表显示」的扩展字段 |

**工具栏**：「新增客户」「导入」「执行价」（下拉：「导入执行价」「导出执行价」，见下文[执行价导入导出](#执行价导入导出)）；右侧导出、刷新等。

::: tip AI 识别与数据整理
管理员开启 AI 功能后，工具栏中还有「AI 识别」：上传名片、营业执照或开票信息，由 [智能录入](../ai/extract) 识别后打开新增表单并填好，核对后保存。资料多了出现重复或写法不统一时，可以用 [数据整理](../ai/cleanse) 让 AI 找出疑似重复的客户、统一名称、联系人、地址的写法。
:::

**行操作**：行末操作栏中的操作显示为图标（鼠标悬停显示名称）：「编辑」「执行价」（见下文[价格等级与执行价](#价格等级与执行价)）「删除」（确认后删除；已有销售订单的客户不能删除，提示改为停用）、「资料」（附件、变更记录）。经销商客户另有「门户账号」（见 [开通门户账号](../portal/account)），有客户合并权限时另有「合并到…」（见下文[资料合并](#资料合并)），这些操作收在最后的「更多」（三个点图标）中。

| 销售渠道 | 否 | 直销 / 经销商，默认直销。经销商可开通经销商门户，在门户订货、上报渠道库存 |

| 备注 | 否 | |

管理员在「系统管理 → [自定义字段](../system/custom-field)」中为「客户」定义了扩展字段（如行业细分、开票要求）时，表单末尾出现「扩展信息」分区，必填的扩展字段不填不能保存。

## 区域

客户的「区域」是销售区域（经销商为授权区域），[销售报表](./jxc-sales)按区域汇总和筛选。取值来自[业务字典](../system/biz-dict)「客户区域」，内置华东、华南、华北、华中、西南、西北、东北、海外，管理员可以按公司的区域划分新增、改名或停用。客户关系模块中客户、线索的「地区」也使用这个字典。

- 所有客户（不只是经销商）都可以填写区域；保存时按字典校验，只能选择启用的取值，已停用的取值在原来的客户上保留显示，不修改它时可以继续保存；
- 从旧版本升级时，原来手工填写的区域文字自动转为字典取值：与已有名称相同的直接对应，其他文字各自新增为一个取值（名称为原文字），可以在业务字典中合并、改名。

## 价格等级与执行价

![新增客户 - 价格等级](/images/manual/scm/customer-price-level.jpg)

**价格等级**：物料可以维护零售价和批发价1～8 多档价格（见[商品价格](./goods-price)）。客户的「价格等级」指定该客户用哪一档：例如一级经销商设为「批发价1」，开销售订单、报价单或直接开单时，没有客户执行价和价目价的物料按物料的批发价1 带出单价（单价下方显示「等级价」）；该列没有填写价格时取零售价。下拉框只列出启用的价格列；客户当前的价格等级所在列被停用时仍会列出，但开单时不再使用该列，改取零售价。修改价格等级记入客户的变更记录。

**执行价**：为某个客户单独约定的物料价格（含税、基本单位）。点行末操作栏中的「**执行价**」图标打开「客户执行价 - 客户名称」抽屉：

![客户执行价](/images/manual/scm/customer-price.jpg)

抽屉顶部提示：「客户执行价优先于价目表和价格等级，按基本单位、含税单价填写；税率为空时开单不改税率。」

| 列 | 必填 | 说明 |
| --- | --- | --- |
| 物料 | 是 | 同一物料只能有一行，重复时提示「物料 … 重复」 |
| 执行价 | 是 | 不能小于 0，最多 4 位小数 |
| 税率 | 否 | 0～100；填写后开单时同时带出税率 |
| 备注 | 否 | |

点「添加物料」增加一行，行右侧删除按钮删除一行，点「保存」整体保存该客户的全部执行价，提示「客户执行价已保存」。没有任何执行价时表格显示「没有执行价」。

- 查看执行价需要客户的查看权限，修改需要客户的修改权限；没有修改权限时抽屉只读、没有保存按钮；
- 执行价没有有效期和起订数量，需要按时间、数量定价时使用[价目表](./price-list)的客户专属价；
- 开单时的完整取价顺序见[开单默认价](./price-list#开单默认价)。外部订单导入、寄售结算不填单价时同样按这个顺序取价；只有经销商门户订货不使用执行价和价格等级，仍按价目表取价。

### 执行价导入导出

执行价多时可以用 Excel 批量维护：

- **全部客户**：客户列表工具栏「执行价」下拉（见上文[列表](#列表)截图）中的「导出执行价」导出所有客户的执行价（填写了「客户」查询条件时只导出匹配的客户）；「导入执行价」打开导入对话框，可下载模板。列为：客户编码*、物料编码*、执行价*、税率(%)、备注；导出的文件另附客户名称、物料名称、规格、单位（导入时忽略），修改后可以直接导入。
- **单个客户**：在「执行价」抽屉顶部点「导入」「导出」，只处理该客户，文件中没有客户编码列；没有任何执行价时「导出」不可用。导入后抽屉重新读取，未保存的修改会丢弃。

导入规则：

- 按「客户编码 × 物料编码」新增或更新执行价，税率、备注为空时清空；文件中没有的执行价保持不变（导入不会删除执行价，删除请在抽屉中操作）；
- 任何一行出错时整批不导入，按行号列出错误，例如「客户编码 … 不存在」「物料编码 … 不存在」「客户 … 的物料 … 重复」、执行价为空或小于 0、最多 4 位小数、税率不在 0 到 100 之间；
- 导出需要客户查看权限，导入需要客户修改权限（没有时下拉中不显示「导入执行价」）。

## 资料合并

同一个客户建了多份资料（如名称写法不同、重复导入）时，可以把重复的资料合并到保留的那一份：订单、出入库单、应收、收款、凭证等业务数据全部改为指向保留的客户，以后只用一份资料查询和对账。合并后**不能撤销**。

### 操作步骤

1. 在要被合并的客户行末点「更多 → **合并到…**」，打开「合并客户资料」对话框，「被合并的资料」中已带出该客户；
2. 还有其他重复的资料时，在「添加被合并的资料」中继续添加（下拉只列出启用的客户，一次最多 20 份），点标签上的叉号可移除；
3. 在「保留的资料」中选择要保留的客户（不能同时是被合并的资料）；
4. 选好后自动预览「影响范围（被合并资料的业务数据）」：按数据类型列出数量，以及其中的「重复（按规则合并 / 舍弃）」行数，例如两份资料都给同一物料设置了执行价。被合并的资料没有业务数据时提示「被合并的资料没有业务数据，合并后只是停用」；合并后有关联供应商的，显示「合并后关联的供应商：…」；
5. 核对无误后点「**确认合并**」，再次确认「确定合并？」后执行，提示「合并完成」。

对话框顶部列出合并规则，与下文一致。需要按钮权限「客户合并」，内置角色中销售经理拥有（从旧版本升级时授权给已有客户删除权限的角色，销售员除外：合并会改动财务数据，而销售员只能看到本人的客户）。合并记入操作日志。

### 合并的范围

被合并客户的下列数据都改为指向保留的客户：

- **供应链**：销售订单、出入库单、草稿、报价、发货通知、物流发运、返利、渠道库存、价目表的客户专属价、客户执行价、价格记忆；
- **仓库与质量**：出入库单和库存流水上的往来单位（单据上的往来单位名称改为保留客户的名称）；
- **财务**：应收单、收款单、预收款、冲账单、发票、其他收支、票据及其操作记录、应收应付对冲单，以及凭证分录的客户辅助核算（包括已记账、已结账期间的凭证，辅助余额按合并后的客户汇总）；
- **客户关系**：经营信息、联系人、线索、跟进、商机、合同、服务工单；
- **其他**：项目、商务智能的销售数据、经销商门户账号（合并后这些账号属于保留的客户，已登录的会话继续有效）、附件、自定义字段。

应收总账 / 明细账、往来汇总、账龄、往来对账单都按合并后的客户统计。

### 冲突规则

- **资料属性**：保留客户的名称、等级、信用额度、账期、价格等级、负责销售等不变，被合并客户的属性不带过来；信用额度只看保留的客户；
- **单据**：金额、币种、核销关系都不变。客户本身没有币种，币种记在每张单据上，外币单据仍按原币核销；
- **客户执行价**：同一物料以保留客户的执行价为准，被合并客户的这一行删除；保留客户没有该物料的执行价时，取被合并客户中最近修改的一条；
- **价格记忆**：同一物料合为一行，最新价取日期最近的一条，最低价、最高价分别取各行中的最低和最高；
- **CRM 经营信息**：以保留客户的为准，最近跟进时间取较晚的一次；保留客户没有经营信息时，从被合并客户移一份过来。保留客户已有首要联系人时，移过来的联系人不再是首要联系人；
- **自定义字段**：保留客户已填写的优先；
- **不能合并的情况**：参与合并的客户上报了同一期间的[渠道库存](./channel)，或合并后会关联多个供应商（各自关联了不同的供应商）时，拒绝合并并提示单号或期间。

### 被合并的资料

被合并的客户自动停用，列表名称旁显示「已合并」标签（鼠标悬停显示「已合并到 …」）：

- 不能再启用，也不能再次合并或被选为保留的资料，「合并到…」操作不再显示；
- 在「资料 → 变更记录」中有「合并到 …」，保留客户的变更记录中有「合并的资料」，可以追溯；
- 没有业务引用后可以删除。

::: tip 先找出重复的资料
资料多时可以用 AI [数据整理](../ai/cleanse)找出疑似重复的客户，确认后在这里合并。
:::

## 与供应商关联

同一个单位既是客户又是供应商（如互相供货）时，在[供应商资料](./supplier#关联客户)中设置「关联客户」，一个客户只能关联一个供应商。关联后客户列表在名称下方显示「关联供应商 …」，并且：

- 查询应收时可以勾选「**挂接应付**」，同时看到欠对方的应付，净额 = 应收 − 应付，见[应收管理 - 挂接应付](../fin/ar-ap#挂接应付)；
- 可以用[应收应付对冲](../fin/ar-ap#应收应付对冲)把应收和应付互相抵减，不收付现金；
- 客户关系模块的[客户详情](../crm/customer)显示关联供应商的应付和应收净额。

删除客户时自动解除关联。

## 信用额度控制

- **审核销售订单时**：应收余额 + 其他未完成订单金额 + 本单金额 ≤ 信用额度，否则不能审核。
- **销售出库前**：应收余额 + 全部未完成订单金额 ≤ 信用额度，否则暂停出库。
- 未完成订单指审批中、已审核、部分完成的销售订单。
- 控制方式可在「系统管理 → [业务参数](../system/biz-rule)」的「客户信用额度控制」中调整：审核和出库时控制（默认）、只在出库时控制、不控制。
- 客户的信用占用（额度、应收余额、未完成订单、可用额度）可在客户关系模块的客户详情中查看。
- 有[关联供应商](#与供应商关联)时，信用占用**不扣减**欠对方的应付：应付在双方确认互抵之前不能视为客户已经回款。做了[应收应付对冲](../fin/ar-ap#应收应付对冲)后应收余额减少，占用随之释放。

详见 [销售订单 - 信用额度与账期](./sales#信用额度与账期)。

## 导入

点「[导入](../guide/common#导入-excel)」，下载模板后填写：客户编码*、客户名称*、客户等级、区域（填业务字典「客户区域」中的名称或键值）、联系人、联系电话、收货地址、纳税人识别号、信用额度、账期(天)、价格等级（0 零售价，1-8 批发价）、备注。价格等级填数字，如 1 表示批发价1，为空时为零售价，超出 0～8 时提示「价格等级不正确」。任何一行有错误时整批不导入。

## 注意事项

::: tip 提示
停用的客户不能新建销售订单、返利协议；经销商门户只对渠道为「经销商」且启用的客户开放，把渠道改回直销后其门户账号无法再订货。
:::
