# 销售报价

销售报价是给客户的正式报价单。单价默认按 [销售价目表](./price-list) 带出，销售人员可以给出折扣，系统自动显示相对价目价的折扣比例。报价提交审批（可按折扣设置审批条件），批准后客户接受即可一键转为销售订单；未成交的报价标记为失效。

## 页面入口

供应链 → 销售 → 销售报价

也可以从客户关系模块的[客户](../crm/customer)、[商机](../crm/opportunity)中「新建报价」，会自动带入客户并关联商机。

![销售报价列表](/images/manual/scm/quotation-list.jpg)

## 列表

**查询条件**：关键字（报价单号或备注）、客户、状态。

**列表列**：报价单号（点击打开详情）、客户、报价日期、有效期至（为空显示「不限」；草稿、审批中、已批准的报价过了有效期显示红色「已过期」标签）、状态、价税合计、销售订单 / 失效原因、制单人、备注、创建时间。

**工具栏**：「新增报价单」、「批量删除」（只能勾选草稿），右侧有导出等。

**行操作**：「查看」；草稿另有「编辑」「删除」。

## 新增 / 编辑报价单

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 客户 | 是 | 选择后按该客户重新取价（客户专属价优先，其次客户等级，见[取价规则](./price-list#取价规则)） |
| 报价日期 | 是 | 默认今天，价目表按此日期匹配有效期 |
| 有效期至 | 否 | 不能早于报价日期；过期后不能转销售订单 |
| 关联商机 | - | 从 CRM 商机发起报价时自动关联，否则显示「无」 |
| 备注 | 否 | 如付款方式、交付条件 |

**明细**（点「添加物料」）：

| 列 | 必填 | 说明 |
| --- | --- | --- |
| 物料 | 是 | 选择后按价目表带出单价、税率 |
| 数量 | 是 | 修改数量后重新取价（满足起订数量的更高档）。下方「可承诺量」链接打开可承诺量查询，见 [销售订单](./sales#可承诺量) |
| 含税单价 | 是 | 下方显示「价目价 ¥…」；单价低于价目价时显示「折扣 X%」 |
| 税率 | 否 | |
| 价税合计 | - | 自动计算，下方显示税额 |
| 备注 | 否 | |

手工修改过的单价不会再被自动覆盖。保存后自动打开详情。

## 报价详情

![销售报价详情](/images/manual/scm/quotation-detail.jpg)

详情显示报价单号、客户、报价日期、有效期至、价税合计和税额、关联商机、销售订单（已成交时，可点击跳转）、制单、备注、失效原因，以及明细（物料、数量、含税单价和价目价折扣、价税合计、备注）。

- 审批中提示「报价单审批中，可在「流程中心 → 我的申请」查看审批进度，审批通过后自动变为已批准」。
- 已批准但已过期时提示「报价已过有效期，不能转为销售订单，请重新报价」。

**底部按钮**：

| 按钮 | 显示条件 | 作用 |
| --- | --- | --- |
| 编辑 | 草稿 | |
| 标记失效 | 草稿、已批准 | 填写失效原因（如「客户选择了其他供应商」），标记后不能再转销售订单 |
| 提交 | 草稿 | 发布了审批流程时发起审批，否则直接批准 |
| 转销售订单 | 已批准且未过期，有转单权限 | 选择发货仓库（选填）、交货日期（选填），按报价明细生成草稿销售订单 |

转单成功后弹窗提示「销售订单 XS… 为草稿状态，是否前往查看并审核？」，可「前往查看」或「留在此页」。生成的销售订单来源为「销售报价」，单价、税率与报价一致（不再自动应用促销），报价单变为「已成交」。

## 单据状态

| 状态 | 可以做什么 |
| --- | --- |
| 草稿 | 编辑、删除、提交、标记失效 |
| 审批中 | 等待审批；拒绝或撤回后回到草稿 |
| 已批准 | 转销售订单（未过期）、标记失效 |
| 已成交 | 已生成销售订单 |
| 已失效 | 只能查看 |

删除由报价单生成的草稿销售订单后，报价恢复为「已批准」，可以重新转单。

## 审批

在 [流程中心](../workflow/business#供应链) 发布「销售报价审批」流程后，「提交」改为发起审批。流程变量：

- **报价金额**：价税合计。
- **最低折扣率**：各明细「报价 ÷ 价目价 × 100」中最低的一个（如 85 表示 85 折），没有价目价的明细不参与，全部没有时为 100。可以设置「折扣率低于 90 时需要销售总监审批」之类的条件分支。
- **报价单号**。

## 注意事项

::: tip 提示
报价不占用库存、不影响信用额度，只有转成销售订单并审核后才进入执行。
:::

::: tip 价格控制
报价单不校验[价格控制](./price-list#价格控制)的最低销售价，转成的销售订单在生成时也不校验；之后编辑该销售订单并保存时才按价格控制校验。需要控制低价报价时，可在报价审批中用「最低折扣率」设置审批条件。
:::
