# 积压分析

积压分析列出截至某一天**库存超过「积压基数」**的商品：积压基数可以是商品设置的库存上限，也可以是上个月或最近若干天的销量。它回答「哪些货压多了、多压了多少、占用了多少资金」，帮助决定哪些商品要暂停采购、促销清货或调拨到其他仓库。

与[商品分析](./jxc-goods)中的「积压」页签相比：商品分析按「可销天数」判断，只看期间有销售的商品；积压分析按「库存数量 − 积压基数」直接算出多压的数量和资金，可以按库存上限判断，也可以把库存回推到过去某一天查看。

## 页面入口

供应链 → 进销存报表 → 积压分析

需要「积压分析」菜单权限，内置角色中超级管理员、总经理、会计、普通用户、采购员、仓库管理员拥有，见[进销存报表概述](./jxc#权限)。手机上也可以在小程序工作台的「积压分析」中查看，见[小程序 · 积压分析](../miniapp/warehouse#积压分析)。

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 全部仓库 | 选择后，库存数量、销量、库存上限都只按该仓库计算；不选为全部仓库 |
| 全部类别 / 全部品牌 | 物料分类、品牌；选择上级分类时包含其所有下级分类 |
| 编码 / 名称 / 规格 / 简拼 | 编码、名称、规格包含输入内容，也可以输入拼音首字母或去掉分隔符的规格缩写，规则同[搜索选择资料](../guide/common#搜索选择资料) |
| 截至日期 | 默认今天，不能晚于今天。鼠标移到文字上显示说明：「库存按该日期截止计算（当前库存减去业务日期在该日之后的出入库）」 |
| 积压基数 | 「库存上限」「上个月销量」「最近天数销量」三选一，默认「最近天数销量」；选择最近天数销量时右侧填写天数（1～366，默认 60 天） |

修改条件后点「**查询**」。

### 三种积压基数

| 积压基数 | 取值 | 适用 |
| --- | --- | --- |
| 库存上限 | 按总库存预警的商品取[物料管理](../wms/material#库存预警)中的「库存上限」；分仓库预警的商品取所选仓库的上限，不选仓库时为各仓库上限之和。**没有设置上限的商品不参与** | 已经为商品设好库存上下限，按上限检查哪些超了。上限设得很高时可能没有积压数据 |
| 上个月销量 | 截至日期所在月份的**上一个自然月**的净销量（例如截至 11 月 12 日，取 10 月 1 日～10 月 31 日） | 按月补货的商品，库存超过一个月的销量即视为积压 |
| 最近天数销量 | 截至日期往前 N 天（含截至日当天）的净销量，N 默认 60 | 按自己的补货周期判断，例如 30 天、90 天 |

净销量 = 销售出库 − 销售退货，按所选仓库统计，口径同[销售报表](./jxc-sales)；为负时按 0 计。期间没有销售的商品积压基数为 0，库存全部算作积压。

表格上方的灰色说明写明本次查询的口径，按销量时显示实际的销量期间，例如「积压基数 = 2026-09-14 ~ 2026-11-12 的净销量（销售出库 − 销售退货，按所选仓库，与销售报表一致）；期间没有销售的基数为 0。积压数量 = 库存数量 − 积压基数，只列出大于 0 的商品。」

## 列表

**积压数量 = 库存数量 − 积压基数**，只列出积压数量大于 0 的商品（多规格款式本身不列出，只列各个 SKU）。有「查看成本金额」权限时按资金占用从大到小排序，否则按积压数量从大到小排序。部分列头带问号图标，鼠标移上去显示口径说明：

| 列 | 说明 |
| --- | --- |
| 登记日期 | 商品资料的创建日期 |
| 最新进货 | 截至日之前最近一次采购入库的日期（全部仓库），没有时显示「无」 |
| 最新出库 | 截至日之前最近一次销售出库的日期（全部仓库），没有时显示「无」 |
| 编码 | 有库存查询权限时为链接，点击打开该商品的[经营历史](../wms/stock#经营历史) |
| 商品、类别、品牌、规格、单位 | — |
| 库存数量 | 截至日的库存（所选仓库，不含供应商寄售仓）：当前库存减去业务日期在截至日之后的出入库，截至今天时与[库存查询](../wms/stock)一致 |
| 在库天数 | 截至日 − 最新进货日期；没有进货记录时按登记日期计算 |
| 积压基数 | 见上文[三种积压基数](#三种积压基数) |
| 积压系数 | 库存数量 ÷ 积压基数，保留两位小数；基数为 0 时显示「—」。例如 2.50 表示库存是基数的 2.5 倍 |
| 积压数量 | 库存数量 − 积压基数，红色加粗显示 |
| 资金占用 | 积压数量 × 库存均价（实时移动加权平均，没有时取最近一期成本核算单价，再没有取参考成本价），同[资产状况](./jxc-assets)。只有拥有库存查询的「**查看成本金额**」按钮权限的用户才显示这一列，没有该权限时系统也不返回金额 |
| 操作 | 有库存查询权限时显示：「经营历史」查看该商品的进出流水与结余（选了仓库时默认该仓库）；「库存分布」弹窗列出该商品**当前**在各仓库、库位、批次的数量（有效期、冻结），弹窗底部也可以打开「经营历史（进销存）」 |

表格底部的**合计行**为全部积压商品（不只是当前页）的合计：第一列显示「合计 · N 个商品」，另有库存数量、积压基数、积压数量和资金占用的合计。

**示例**：积压基数选「最近天数销量」60 天，某商品最近 60 天卖出 40 件，截至今天库存 100 件：积压基数 40，积压系数 2.50，积压数量 60，资金占用 = 60 × 库存均价。

## 导出

点表格右上角的「**导出**」，按当前条件导出全部积压商品（最多 5000 行），列与表格一致，最后一行为合计行，文件名为「积压分析_截至日期」。

## 数据权限

- 销量（积压基数）以及最新进货、最新出库日期来自出入库单，按出入库单的「制单人部门 + 制单人」过滤，与[商品分析](./jxc-goods)一致，见[进销存报表概述 · 权限](./jxc#权限)；
- 库存数量、库存上限不受数据权限限制。

::: tip 提示
- 季节性商品按「上个月销量」或较短的天数判断，容易在淡季被列为积压，建议选择与采购周期相当的天数，或为商品设置库存上限后按上限判断。
- 积压的商品可以结合[库存查询](../wms/stock)中的分仓库预警和[调拨单](../wms/transfer)，把货调到缺货的仓库；也可以参考财务的[库龄分析](../fin/analysis#库龄分析)。
:::
