# 进货报表

进货报表把一段时间内的[采购入库与采购退货](./purchase-in)按类别、品牌、供货商、商品、日或月汇总，显示入库、退货、净额和均价，用法与[销售报表](./jxc-sales)相同：点击汇总行看明细，点击单据号看单据。

## 页面入口

供应链 → 进销存报表 → 进货报表

需要「进货报表」菜单权限，内置角色中超级管理员、总经理、会计、普通用户、采购员拥有，见[进销存报表概述](./jxc#权限)。

![进货报表](/images/manual/scm/jxc-purchase.jpg)

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 日期范围 | 必填，默认本月；快捷选项「本月」「上月」「本年」「近 12 个月」，最长 366 天。按入库 / 退货单的业务日期筛选 |
| 全部供货商 | 选择一个供应商 |
| 全部类别 / 全部品牌 | 物料档案上的分类、品牌；选择上级分类时包含其所有下级分类 |
| 全部仓库 | 入库 / 退货的仓库 |
| 商品编码 / 名称 | 模糊匹配，按回车查询 |

进货报表没有业务员和区域条件。

## 汇总方式

可选「类别」「品牌」「供货商」「商品」「日」「月」，默认按「供货商」。分组规则同[销售报表](./jxc-sales#汇总方式)：物料没有分类、品牌时归入「未设置」；日、月按日期升序，其他按净额降序；最多显示 1000 行，合计始终为全部数据。

## 指标

顶部合计：**净额**、**价税合计**、**净数量**、**单据数**。表格的列：

| 列 | 口径 |
| --- | --- |
| 入库数量 / 退货数量 | 采购入库、采购退货的数量合计 |
| 净数量 | 入库数量 − 退货数量 |
| 入库金额 / 退货金额 | 不含税金额（价税合计 − 税额），本位币 |
| 净额 | 入库金额 − 退货金额 |
| 价税合计 | 含税金额的净额 |
| 均价 | 净额 ÷ 净数量，即不含税的平均进货单价 |
| 单据数 | 涉及的入库单、退货单张数 |

进货报表不计算成本和毛利。

## 查看明细、单据与导出

- 点击汇总行进入「〈名称〉· 明细」子页，点「**全部明细**」查看全部明细。明细列为：日期、单据号（带「采购入库」「采购退货」标签）、供货商、商品、类别、品牌、仓库、数量（退货为负数）、含税单价、金额（不含税）、价税合计、备注。
- 点击单据号打开采购入库或采购退货的详情。
- 「**导出汇总**」导出当前汇总表；明细子页「**导出明细**」最多导出 5000 行。

::: tip 提示
进货报表统计的是**已入库**的数量和金额，不是采购订单金额。尚未入库的订单数量见[欠交清单](./backorder)，应付金额见[应收应付](../fin/ar-ap)（含税）。
:::
