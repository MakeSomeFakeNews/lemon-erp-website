# 进货报表

进货报表把一段时间内的[采购入库与采购退货](./purchase-in)按类别、品牌、供货商、商品、日或月汇总，显示入库、退货、净额和均价，用法与[销售报表](./jxc-sales)相同：汇总行可以穿透到单据（每张入库单、退货单一行，再看该单的明细）或商品明细，点击单据号看单据。

## 页面入口

供应链 → 进销存报表 → 进货报表

需要「进货报表」菜单权限，内置角色中超级管理员、总经理、会计、普通用户、采购员拥有，见[进销存报表概述](./jxc#权限)。

![进货报表](/images/manual/scm/jxc-purchase.jpg)

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 日期范围 | 必填，默认本月；快捷选项「本月」「上月」「本年」「近 12 个月」，最长 366 天。按入库 / 退货单的业务日期筛选 |
| 全部供货商 | 选择一个供应商 |
| 全部类别 / 全部品牌 | 物料档案上的分类、品牌；选择上级分类时包含其所有下级分类 |
| 全部仓库 | 入库 / 退货的仓库 |
| 商品编码 / 名称 | 模糊匹配，按回车查询 |

进货报表没有业务员和区域条件。

## 汇总方式

可选「类别」「品牌」「供货商」「商品」「日」「月」，默认按「供货商」。分组规则同[销售报表](./jxc-sales#汇总方式)：物料没有分类、品牌时归入「未设置」；日、月按日期升序，其他按净额降序；最多显示 1000 行，合计始终为全部数据。

## 指标

顶部合计：**净额**、**价税合计**、**净数量**、**单据数**；所选范围内有付款折让时，还显示「**扣折让后净进货额**」，鼠标悬停提示「净额 − 付款折让（应付单在付款时的折让 / 抹零，多次付款累计，按不含税比例折算，跟随入库单日期），只是参考口径：付款折让计入财务费用，不冲减存货成本」。表格的列：

| 列 | 口径 |
| --- | --- |
| 入库数量 / 退货数量 | 采购入库、采购退货的数量合计 |
| 净数量 | 入库数量 − 退货数量 |
| 入库金额 / 退货金额 | 不含税金额（价税合计 − 税额），本位币 |
| 净额 | 入库金额 − 退货金额 |
| 价税合计 | 含税金额的净额 |
| 均价 | 净额 ÷ 净数量，即不含税的平均进货单价 |
| 付款折让 | 入库 / 退货单生成的[应付单](../fin/ar-ap)（含该单的采购运费、退货运费应付单）在[付款时取得的折让 / 抹零](../fin/settlement#折让与抹零)，同一单据多次付款时累计，按应付单的不含税比例折算，再按单据各行金额比例分摊，跟随入库单的业务日期归属 |
| 扣折让后净进货额 | 净额 − 付款折让 |
| 单据数 | 涉及的入库单、退货单张数 |

进货报表不计算成本和毛利。付款折让和扣折让后净进货额只作**参考**：按会计准则，付款时取得的折让 / 抹零计入财务费用（[凭证科目设置](../fin/account-rule#折让与冲账科目)中的「付款折让 / 抹零」科目），**不冲减已入库存货的成本**，实时库存成本和月末成本核算都不调整，所以进货额、存货成本不变。

## 查看明细、单据与导出

穿透方式同[销售报表](./jxc-sales#查看明细和单据)：操作列有「**单据**」「**商品明细**」两个图标，直接点击汇总行时按汇总方式决定默认去向：

| 汇总方式 | 点击汇总行默认打开 |
| --- | --- |
| 类别、品牌、商品 | 商品明细（「〈名称〉· 明细」子页） |
| 供货商、日、月 | 单据列表（「〈名称〉· 单据」子页），再点击单据看该单的明细 |

表格上方的「**全部单据**」「**全部明细**」不限汇总行，按当前查询条件列出全部单据或全部明细。

- **单据列表**：每张采购入库单、采购退货单一行，列为日期、单据号（带「采购入库」「采购退货」标签）、供货商、仓库（表头仓库）、行数、数量、金额（不含税，已扣除整单优惠）、价税合计、整单优惠（分摊的优惠，参考）、付款折让、扣折让后金额、备注，没有业务员和成本、毛利列。付款折让为该单应付单的折让（多次付款累计）按这些明细分摊的部分。金额为该单中属于本汇总项的明细合计，按类别、品牌、商品汇总时只计入匹配的商品行，退货为负数；底部合计为全部单据的合计，等于汇总行。点击单据进入「〈名称〉/ 〈单号〉· 明细」子页，只列这张单据中属于本汇总项的明细；操作列的「查看单据」图标直接打开单据详情。
- **商品明细**：列为日期、单据号（带「采购入库」「采购退货」标签）、供货商、商品、类别、品牌、仓库、数量（退货为负数）、含税单价、金额（不含税）、价税合计、付款折让、扣折让后金额、备注。与销售报表相同，明细按整张单据列出（没有按商品、类别、品牌、仓库筛选）时，有付款折让的单据最后追加一行「**付款折让 / 抹零**」，否则折让按行金额比例分摊到各行，见[收款折让行](./jxc-sales#收款折让行)。
- 明细中点击单据号打开采购入库或采购退货的详情；每层子页左上角的「返回」逐层回到上一层，汇总的查询条件保持不变。
- 「**导出汇总**」导出当前汇总表；明细子页「**导出明细**」、单据子页「**导出**」各最多导出 5000 行。

::: tip 提示
进货报表统计的是**已入库**的数量和金额，不是采购订单金额。尚未入库的订单数量见[欠交清单](./backorder)，应付金额见[应收应付](../fin/ar-ap)（含税）。
:::
