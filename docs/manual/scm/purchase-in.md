# 采购入库与采购退货

采购入库是仓库按采购订单收货入库的单据，采购退货是把已入库的货物退还给供应商的单据。两者都必须从采购订单出发录入，**保存即确认**：立即生成仓库单据、更新库存，同时生成[应付单](../fin/ar-ap)（退货为红字应付单），并回写订单的已入库、已退货数量。

## 页面入口

- 供应链 → 采购 → 采购入库
- 供应链 → 采购 → 采购退货

也可以从 [采购订单](./purchase) 列表的「入库」按钮、订单详情的「采购入库」「采购退货」按钮直接打开，此时订单已固定，不能更换。

![采购入库列表](/images/manual/scm/purchase-in-list.jpg)

![采购退货列表](/images/manual/scm/purchase-return-list.jpg)

## 列表

两个页面的结构相同。

**查询条件**：单据号、订单号、供应商、仓库、业务日期范围。

**列表列**：单据号（点击查看详情）、订单号、供应商（名称和编码）、仓库、业务日期、数量、价税合计、仓库单据（自动生成的仓库[入库](../wms/in) / [出库](../wms/out)单号）、制单人、创建时间。

**工具栏**：「新增采购入库」或「新增采购退货」。

**行操作**：「查看」。入库、退货单据不能修改和删除。

## 新增采购入库

表单顶部提示：「录入入库的库位、批次（序列号）。保存后立即生成仓库入库单并更新库存，同时生成应付单，单据不能修改，错误时请做退货冲回。」

### 表头

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 采购订单 | 是 | 输入订单号搜索，只列出已审核、部分完成的订单。选择后带出全部有未完成数量的明细 |
| 仓库 | 是 | 默认订单的收货仓库。更换仓库会清空各行已选的库位、序列号 |
| 业务日期 | 是 | 默认今天，即入库日期，应付单的单据日期和到期日从此计算 |
| 备注 | 否 | |

明细标题栏显示行数、合计数量、价税合计和供应商名称，右侧「推荐库位」按钮按仓库的[上架策略](../wms/label-putaway#上架策略)为还没有选库位的行推荐库位。

### 明细

| 列 | 说明 |
| --- | --- |
| 物料 | 物料编码、名称、规格；启用批次 / 序列号管理的显示「批次」「序列号」标签 |
| 未完成数量 | 本行最多可入库的数量，下方显示订单单价 |
| 库位 | 入库库位，可不选 |
| 批次号 | 批次管理的物料必填；同时可填写「生产日期」「有效期至」（用于临期提示和先到期先出） |
| 数量 | 必填，默认等于未完成数量，可改小（分批到货）。序列号物料只能为整数 |
| 序列号 | 序列号物料扫码或输入，个数须与数量一致 |
| 操作 | 「拆分」：同一物料分多个库位 / 批次入库时，复制出一行分别填写；删除：本次不入库的行可删除 |

单价取订单单价，不能修改；外币订单按订单汇率折算为人民币。

## 新增采购退货

表单顶部提示：「从所选仓库的现有库存中选择库位、批次（序列号）。保存后立即生成仓库出库单并更新库存，同时生成应付单，单据不能修改，错误时请重新入库 / 出库冲回。」

| 字段 / 列 | 说明 |
| --- | --- |
| 采购订单 | 只列出部分完成、已完成、已关闭（即已经有过入库）的订单 |
| 仓库、业务日期、备注 | 同入库 |
| 退货后需要补收 | 勾选后订单恢复相应的未完成数量，可以继续入库；不勾选视为退款，订单不再补收 |
| 可退数量 | 已入库 − 已退货 |
| 库位 / 批次 | 必填，从所选仓库该物料的现有库存中选择，显示可用数量；包含冻结的库存（不合格、待检） |
| 数量 | 必填，退货默认不填，需逐行填写；不需要退的行可以删除 |
| 序列号 | 序列号物料从所选库位的在库序列号中选择或扫码 |

## 查看详情

详情显示单据号、订单号、供应商、仓库、业务日期、仓库单据、退货方式（退货单：退货退款 / 退货补收）、价税合计和税额（外币订单另显示原币金额）、制单，以及明细（物料、库位、批次及生产 / 有效日期、数量、含税单价、价税合计和税率、序列号）。右上角「打印」按[打印模板](../system/print-template)打印。

## 保存时发生了什么

**采购入库**：

1. 校验订单仍为已审核或部分完成，各行数量不超过未完成数量（并发入库时也不会超收）。
2. 生成已确认的仓库「采购入库」单，库存、批次、序列号即时增加。
3. 需要来料检验的物料按入库数量冻结为「待检」，由质量模块的[来料检验](../qms/inspection#来料冻结与放行)放行或判定不合格。
4. 回写订单明细的已入库数量，重算订单状态（部分完成 / 已完成）。
5. 生成应付单：金额为价税合计，到期日 = 业务日期 + 供应商账期；订单引用了约定付款天数的 [采购合同](./contract) 时按合同的付款天数。

**采购退货**：

1. 校验各行数量不超过可退数量。
2. 先解冻本订单的不合格、待检库存（优先退冻结库存），再生成已确认的仓库「采购退货」出库单。
3. 回写已退货数量；勾选补收的同时增加待补收数量，订单恢复未完成。
4. 生成红字（负数）应付单冲减应付。

任何一行出错（库存不足、序列号不在库、超出数量等），整张单据不会保存，提示会指明是第几行、哪个物料。

## 注意事项

::: warning 注意
入库、退货保存后不能修改或删除。数量录多了，请做采购退货冲回；退货录错了，请重新入库。
:::

::: tip 提示
有门户账号的供应商可以先在门户发起 [送货通知](./asn)，仓库按送货通知一键收货。使用手机 / PDA 时，也可以在「移动作业」的扫码收货中按采购订单扫码入库，见 [移动作业](../mobile/receive)。
:::

## 常见问题

**选择订单时找不到订单？** 入库只列出已审核、部分完成的订单；草稿、审批中的订单需要先审核。退货只列出已经有过入库的订单。

**提示数量超出未完成数量？** 订单剩余未入库数量不足，可能其他人刚刚入库了一部分。超出订单的数量需要先通过订单「变更」增加数量。
