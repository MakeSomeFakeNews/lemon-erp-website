# 采购入库与采购退货

采购入库是仓库按采购订单收货入库的单据，采购退货是把已入库的货物退还给供应商的单据。两者可以引用采购订单（退货引用原入库单）录入，也可以不选订单[直接开单](#直接开单)：选择供应商和商品直接入库、退货，系统自动生成已审核的订单。单据**保存即确认**：立即生成仓库单据、更新库存，同时生成[应付单](../fin/ar-ap)（退货为红字应付单），并回写订单的已入库、已退货数量。

需要「录单、确认」分开的企业，可以在[业务参数](../system/biz-rule#进销存单据先存草稿)中开启「进销存单据先存草稿」：单据先保存为草稿，审核后才入库、退货，见[草稿与审核](#草稿与审核)。

## 页面入口

- 供应链 → 采购 → 采购入库
- 供应链 → 采购 → 采购退货

也可以从 [采购订单](./purchase) 列表的「入库」按钮、订单详情的「采购入库」「采购退货」按钮直接打开，此时订单已固定，不能更换。

![采购入库列表](/images/manual/scm/purchase-in-list.jpg)

![采购退货列表](/images/manual/scm/purchase-return-list.jpg)

## 列表

两个页面的结构相同。

**查询条件**：单据号、订单号、供应商、仓库、业务日期范围。

**列表列**：单据号（点击查看详情）、订单号（来源采购订单号，直接开单的单据显示蓝色「直接开单」标签）、供应商（名称和编码）、仓库、业务日期、数量、价税合计（直接开单填写了整单优惠时下方显示「整单优惠 ¥…」，采购入库填写了运费时下方显示「运费 ¥…」）、仓库单据（自动生成的仓库[入库](../wms/in) / [出库](../wms/out)单号）、制单人、创建时间。

点击表格工具栏的下载图标可按当前查询条件**导出**列表（采购入库、采购退货各自导出）：供应商导出为「编码 名称」，仓库导出明细涉及的全部仓库，「价税合计」拆成价税合计、整单优惠两列（采购入库另有运费列），详见[通用操作 → 导出](../guide/common#导出)。

**工具栏**：「新增采购入库」或「新增采购退货」。

**行操作**：只有「查看」（显示为图标加文字）。入库、退货单据不能修改和删除。

开启「进销存单据先存草稿」（或关闭参数后还有未处理的草稿）时，列表上方有「**已审核**」「**草稿（N）**」两个页签，N 为草稿数量，上面所说的是「已审核」页签；「草稿」页签见[草稿与审核](#草稿与审核)。

## 新增采购入库

表单底部提示：「录入入库的库位、批次（序列号）。保存后立即生成仓库入库单并更新库存，同时生成应付单，单据不能修改，错误时请做退货冲回。」开启「进销存单据先存草稿」时，底部按钮为「保存草稿」「审核」，见[草稿与审核](#草稿与审核)。

| 列 | 说明 |
| --- | --- |
| 物料 | 必填，搜索或扫码选择商品（提示「请选择商品」） |
| 库位、批次号 | 同下文「引用订单的明细」 |
| 数量 | 必填 |
| 含税单价 | 必填（提示「请填写单价」）。选择供应商和商品后自动带出默认价：采购合同价 → 供货价格 → 最近进价 → 参考成本，单价下方显示来源，见[开单默认价](./price-list#开单默认价)（同一商品多行时，每行按本行数量匹配供货阶梯价）；「价格参考」查看该商品的进货历史、各供应商价格对比，点击其中的价格即可填入单价，见[价格参考](./price-list#价格参考) |
| 税率 | 默认 13%，合同价、供货价格带出时同时带出税率 |
| 价税合计 | 数量 × 含税单价，下方显示税率 |
| 序列号 | 序列号物料扫码或输入 |

更换供应商或业务日期后，没有手工改过的单价重新取价。

**整单优惠**：明细下方的合计区可以填写「整单优惠」（含税金额），或用「抹零」抹去分、角分、个位，适合供应商送货单上的抹零、整单折让。保存时整单优惠记在自动生成的采购订单上，在内部按行金额比例分摊（尾差放在金额最大的一行），入库单的价税合计、应付单和入库成本都按优惠后的金额计算；明细的单价不变，详情、打印按优惠前的单价和金额显示，合计处列出「优惠前合计」「整单优惠」「优惠后合计」，[价格记忆、价格参考](./price-list#价格参考)和供货价格的采购历史也按优惠前单价记录。采购退货直接退货时同样可以填写。用法见[销售订单 - 整单优惠与抹零](./sales#整单优惠与抹零)。

### 引用订单的明细

| 列 | 说明 |
| --- | --- |
| 物料 | 物料编码、名称、规格；启用批次 / 序列号管理的显示「批次」「序列号」标签 |
| 未完成数量 | 本行最多可入库的数量，下方显示订单单价（有整单优惠时为优惠前单价） |
| 库位 | 入库库位，可不选 |
| 批次号 | 批次管理的物料必填；同时可填写「生产日期」「有效期至」（用于临期提示和先到期先出） |
| 数量 | 必填，默认等于未完成数量，可改小（分批到货）。序列号物料只能为整数。允许超收时可以大于未完成数量，见下文「超收」 |
| 序列号 | 序列号物料扫码或输入，个数须与数量一致 |
| 操作 | 「拆分」：同一物料分多个库位 / 批次入库时，复制出一行分别填写；删除：本次不入库的行可删除 |

单价取订单单价，不能修改；外币订单按订单汇率折算为人民币。

### 订单优惠

引用订单时，明细下方列出「合计」（优惠前）、「订单优惠」和「优惠后合计」。**明细单价始终是订单 / 供应商送货单上的优惠前单价，订单优惠不改单价**：它作为整单减少应付金额，存货成本按各行金额比例冲减（只用于内部成本核算，不影响单据上的单价和金额显示）。鼠标停在「订单优惠」上有同样的说明。

- 默认带出本次按订单比例计算的优惠（完成订单的最后一批为订单剩余的优惠）；订单没有整单优惠时默认为 0；
- 可以按供应商实际给的优惠修改（含税金额，不能为负数，不能超过本单优惠前的价税合计，超出时提示「订单优惠不能超过本单优惠前合计 …」）。改过之后下方提示「与按订单计算的优惠 ¥… 不一致：本单应付和存货成本按修改后的优惠计算，订单的已入库金额仍按订单」，点「恢复按订单」可改回按订单计算的金额；
- 保存时按各行优惠前金额的比例重新分摊（尾差放在金额最大的一行），本单的应付单、入库成本、月末[成本核算](../fin/cost)和入库凭证都按修改后的金额计算；详情的「订单优惠」下方显示「已修改，比按订单分摊多（少）¥…」；
- 修改只影响这张入库单，**不回写订单**：订单的已入库金额、关闭时的尾差仍按订单计算，之后引用这张订单的采购退货也按订单的成交价退款。

只有引用订单的采购入库可以修改订单优惠；直接开单时在合计区填写「整单优惠」（见上文），销售出库、退货的优惠按订单 / 原单计算，不能修改。

### 采购运费

采购入库表单（直接开单和引用订单都可以）的明细下方有「运费」：

| 字段 | 说明 |
| --- | --- |
| 运费 | 选填，金额，最多 2 位小数；填写后才显示下面两项 |
| 运费付给 | 「供应商代垫」（默认）：运费由本单的供应商代垫，计入该供应商的应付；「本公司承担」：运费付给承运商 |
| 承运商 | 「本公司承担」时必填（提示「请选择承运商（物流公司）」）。下拉只列出在[供应商](./supplier#物流公司)资料中勾选了「物流公司（承运商）」的供应商；还没有标记任何物流公司时列出全部供应商，下拉顶部提示「还没有标记物流公司，下面列出全部供应商；请在「供应商」资料中勾选「物流公司」」 |

填写运费后，下方按「运费付给」和[业务参数](../system/biz-rule#本公司承担的采购运费计入)「本公司承担的采购运费计入」提示实际怎么入账：

| 情况 | 提示 | 入账 |
| --- | --- | --- |
| 供应商代垫 | 供应商代垫：运费并入该供应商的应付（单独一张运费应付单），按各行不含税金额分摊计入存货成本；不生成费用 | 计入存货成本，借 存货（按物料分类）/ 贷 应付账款-供应商 |
| 本公司承担，参数为「存货成本」（默认） | 本公司承担：应付给承运商，按各行不含税金额分摊计入存货成本（借 存货 / 贷 应付账款-承运商）；不另生成费用支出单，运费只计一次 | 计入存货成本，借 存货（按物料分类）/ 贷 应付账款-承运商 |
| 本公司承担，参数为「当期费用」 | 本公司承担：应付给承运商，计入当期费用（借 采购运费科目，默认销售费用 / 贷 应付账款-承运商），不分摊到存货成本 | 计入当期费用，借 采购运费科目（[凭证科目设置](../fin/account-rule#运费科目)，默认 6601 销售费用）/ 贷 应付账款-承运商 |

保存后：

- 计入存货成本时，运费按各行不含税金额的比例分摊到明细（全是赠品、金额为 0 时按数量分摊），计入这些物料的入库成本和月末[成本核算](../fin/cost)的采购金额；计入当期费用时不分摊，入库成本不含运费；
- 不论哪种方式，都只生成一张来源为「采购运费」的[应付单](../fin/ar-ap)：供应商代垫时应付本单供应商，本公司承担时应付所选承运商，到期日按其账期；不另生成费用支出单，运费只计一次，付给物流公司的钱就是核销这张应付单；
- 入账方式在入库时确定并记在单据上，之后修改业务参数不影响已有单据；
- 入库单详情显示「运费 ¥…」、付给方式标签，下方为承运商和「计入存货成本」或「计入当期费用」，打印的合计处也列出运费；
- 采购退货按退货单价冲减应付，运费不退。

::: tip 提示
只有采购入库可以填写运费；销售发货的运费在[物流发运](./shipment#运费承担)中登记。

## 新增采购退货

表单底部提示：「从所选仓库的现有库存中选择库位、批次（序列号）。保存后立即生成仓库出库单并更新库存，同时生成应付单，单据不能修改，错误时请重新入库 / 出库冲回。」

退货有两种方式：

- **引用原入库单**：在「原采购入库单」中输入单据号搜索（已选择供应商时只列出该供应商的入库单），选择后带出该入库单的明细（单价、批次号沿用原单），按原订单回写退货数量；
- **直接退货**：不选原单，像直接开单一样选择供应商、商品、数量、含税单价（默认价规则同采购入库）、税率，保存后系统生成一张已审核的订单（标记「直接开单」），只用于记录这次退货。

从采购订单详情点「采购退货」进入时，引用的是该订单（「引用订单」），订单不能更换。

| 字段 / 列 | 说明 |
| --- | --- |
| 原采购入库单 / 引用订单 | 见上文，可不选 |
| 供应商、仓库、业务日期、备注 | 同入库；仓库为退货出库的仓库 |
| 退货后需要补收 | 引用原单或订单时显示（原订单是直接开单生成的除外）。勾选后订单恢复相应的未完成数量，可以继续入库；不勾选视为退款，订单不再补收。原订单已关闭时只能退款 |
| 可退数量 | 引用时显示：订单该行的已入库 − 已退货 |
| 库位 / 批次 | 必填，从所选仓库该物料的现有库存中选择，显示可用数量；包含冻结的库存（不合格、待检） |
| 数量 | 必填，退货默认不填，需逐行填写；不需要退的行可以删除 |
| 序列号 | 序列号物料从所选库位的在库序列号中选择或扫码 |

## 查看详情

详情显示单据号、订单号（直接开单的单据在订单号后显示「直接开单」标签，打印时显示为「订单号 (直接开单)」）、供应商、仓库、业务日期、仓库单据、退货方式（退货单：退货退款 / 退货补收）、价税合计和税额（外币订单另显示原币金额）、运费（填写时）、制单（制单人、创建时间）、审核（审核人、审核时间，即入库 / 退货并生成应付的时间；保存即审核的单据为制单人，由草稿审核的为审核草稿的人），以及明细（物料、库位、批次及生产 / 有效日期、数量、含税单价、价税合计和税率、序列号）。本单有优惠时，明细为优惠前的单价和金额，表头显示「优惠前合计」「整单优惠」（引用订单的为「订单优惠」，修改过时下方显示与按订单分摊的差额；退货单为「原单优惠分摊」）和「优惠后合计」（退货单为「退款金额」）。右上角「打印」按[打印模板](../system/print-template)打印。

## 直接开单

直接开单适合没有事先下采购订单的业务，例如门店临时进货、零星采购。保存直接开单的入库 / 退货单时，系统在同一次保存中：

1. 按单据的供应商、业务日期、仓库、备注、整单优惠和明细（一行对应一行订单明细）生成一张采购订单，**直接审核**，不走采购订单审批流程，审核人为制单人；
2. 再按这张订单入库 / 退货，后续处理与引用订单完全相同（库存、批次序列号、来料检验冻结、应付单、成本等）；入库时同样校验[最高采购价](./price-list#价格控制)，控制方式为「禁止保存」时超出不能保存；
3. 入库生成的订单随即为「已完成」；直接退货生成的订单视为已全部入库，只用于回写退货数量，库存按退货出库，应付按退货金额冲减。

自动生成的订单在[采购订单](./purchase#直接开单生成的订单)列表中显示「直接开单」标签，不能修改、反审核、关闭、变更，也不能「退货后需要补收」；入库录错时请做采购退货冲回。任何一步失败（如超出最高采购价、序列号重复），入库单和订单都不会保存。

## 草稿与审核

默认情况下采购入库、采购退货**保存即审核**。在「系统管理 → [业务参数](../system/biz-rule#进销存单据先存草稿)」的「供应链」页签中开启「**进销存单据先存草稿**」（默认关闭）后，单据分两步：先保存草稿，确认无误后再审核（记账）。适合录单员先录入、仓库或会计核对后再入账的分工，也适合货到了但数量、价格还要和供应商确认的情况。引用订单和直接开单都可以存草稿。

### 保存草稿

开启后新增表单的底部按钮为：

- 「**保存草稿**」（需要新增权限）：保存为草稿，提示「草稿已保存，审核后才出入库」，列表自动切换到「草稿」页签；
- 「**审核**」（需要[审核权限](#权限)）：不存草稿，直接保存并审核，效果与关闭参数时的保存相同。

表单底部同时提示「已开启「进销存单据先存草稿」：保存草稿不更新库存、订单和应收应付，可再修改、删除；审核后才按上述规则出入库并生成应收应付，审核后不能修改。」

草稿的特点：

- **不影响任何业务数据**：不生成仓库单据、不更新库存，不回写订单的已入库 / 已退货数量，不生成应付单和凭证，也不计入进销存报表、库存成本、单据追溯等；
- **保存时就占用单据号**，审核后生成的入库 / 退货单沿用这个单号；
- 保存时只检查单据是否完整：引用订单时订单可见、明细属于该订单；直接开单时已选择供应商，每行都选了商品；运费只能用于采购入库，直接退货不能勾选补收，订单优惠只能用于引用订单的采购入库。可入库数量、可退数量、库存、最高采购价等**在审核时才校验**；
- 草稿的金额按订单单价或录入的单价估算，列表中显示为「金额（估算）」，以审核后的单据为准；
- 被草稿引用的物料、仓库、供应商等资料不能删除。

### 草稿列表

「草稿」页签与「已审核」页签共用上方的查询条件（单据号、订单号、供应商、仓库、业务日期），列出未审核的草稿：

**列表列**：单据号（下方显示「草稿」标签，有新增权限时点击打开编辑）、订单号（直接开单的显示「直接开单」标签）、供应商、仓库、业务日期、数量、金额（估算）（填写了运费时下方显示运费）、制单人、修改时间。

**行操作**（图标，鼠标悬停显示名称，按权限显示）：

- 「**编辑**」（新增权限）：打开表单修改草稿，标题为「修改采购入库草稿 单据号」。引用订单的草稿按订单的最新情况带出未完成数量、可退数量；库位批次、退货引用的原单、订单优惠、运费都按草稿回显。底部同样有「保存草稿」「审核」，可以改完直接审核；
- 「**审核**」（审核权限）：确认「审核草稿 单据号？审核后将按草稿出入库、回写订单并生成应收应付，采购入库不能再修改，错误时需做退货冲回。」后审核；
- 「**删除**」（新增权限）：确认「删除草稿 单据号？」后删除，草稿占用的单号不再使用。

从首页待办「采购入库草稿待审核」「采购退货草稿待审核」进入时直接打开「草稿」页签。

### 审核

审核时系统按审核当时的数据，执行与保存即审核完全相同的处理（见下文[保存时发生了什么](#保存时发生了什么)）：校验订单状态、可入库 / 可退数量、库存、最高采购价、订单优惠等，生成仓库单据、更新库存、回写订单、生成应付单。

- **任何一项校验不通过，整体回滚**：不入库、不生成应付，草稿保持原样，提示具体原因，修改草稿后可以再次审核；
- 审核成功后草稿从「草稿」页签消失，生成的单据出现在「已审核」页签，单号沿用草稿的单号；制单人、制单部门仍为草稿的制单人（数据权限不变），审核人为点审核的人，详情显示「审核」一行；
- 同一张草稿多人同时审核时只有一人成功，其他人提示「采购入库草稿不存在、已审核或无权访问」；
- **审核后不能修改、删除**，没有反审核；错误的单据请做退货冲回（入库录错做采购退货，退货录错重新入库）。

只有审核权限、没有新增权限的用户（例如只负责记账的会计）可以在列表中按草稿原样审核，但不能修改、删除草稿；编辑后再审核需要同时有新增和审核权限。

### 关闭参数后

关闭「进销存单据先存草稿」后，新增表单恢复为保存即审核，不能再新建草稿（提示「业务参数未开启「进销存单据先存草稿」，采购入库保存即审核」）；已有的草稿仍显示在「草稿」页签中，可以继续修改、审核、删除，直到处理完后页签自动隐藏。

### 不使用草稿的单据

由其他业务生成的入库单不经过草稿，各自已有确认步骤，仍直接审核：[送货通知](./asn)收货、[寄售结算](./consign)等。手机[扫码收货](../mobile/receive)在开启参数且没有审核权限时保存为草稿。

## 保存时发生了什么

开启「进销存单据先存草稿」时，以下处理在**审核**时发生，保存草稿时都不发生。

**采购入库**：

1. 校验订单仍为已审核或部分完成，各行数量不超过未完成数量（设置了超收比例时不超过允许超收后的数量；并发入库时也不会超出）。
2. 生成已确认的仓库「采购入库」单，库存、批次、序列号即时增加。
3. 需要来料检验的物料按入库数量冻结为「待检」，由质量模块的[来料检验](../qms/inspection#来料冻结与放行)放行或判定不合格。
4. 回写订单明细的已入库数量，重算订单状态（部分完成 / 已完成）。
5. 生成应付单：金额为价税合计，到期日 = 业务日期 + 供应商账期（订单行有整单优惠分摊时，完成该行的最后一批取「订单行金额 − 已入库金额」，各批累计正好等于订单行金额；修改了[订单优惠](#订单优惠)时按修改后的金额）；订单引用了约定付款天数的 [采购合同](./contract) 时按合同的付款天数。
6. 填写了运费时，另生成「采购运费」应付单，运费按入账方式分摊计入入库成本或计入当期费用，见上文[采购运费](#采购运费)。

**采购退货**：

1. 校验各行数量不超过可退数量。原订单有整单优惠时按扣除优惠后的成交价冲减应付，退货单的合计处显示「原单优惠分摊」和「退款金额」，规则同[销售退货](./sales-out#整单优惠与买赠)。
2. 先解冻本订单的不合格、待检库存（优先退冻结库存），再生成已确认的仓库「采购退货」出库单。
3. 回写已退货数量；勾选补收的同时增加待补收数量，订单恢复未完成。
4. 生成红字（负数）应付单冲减应付。

任何一行出错（库存不足、序列号不在库、超出数量等），整张单据不会保存，提示会指明是第几行、哪个物料。

## 超收

默认入库数量不能超过订单的未完成数量。供应商实际到货略多于订单（如按整包装发货）时，可以在「系统管理 → [业务参数](../system/biz-rule)」中设置「**采购入库超收比例（%）**」（0 ~ 100，默认 0 即不允许超收）：

- 每行累计入库数量最多为「订单数量 × (1 + 超收比例)」，再加上退货补收数量；
- 例如订单 100 个、超收比例 5%，最多可累计入库 105 个；
- 超出时提示「…超出允许超收 / 超发后的数量…」；未设置超收比例时提示「…超出未完成数量…」；
- 超收后该行视为已完成，订单状态按入库情况变为「已完成」；超收部分同样生成应付单；
- 采购退货不受超收比例影响，最多退「已入库 − 已退货」。

在入库表单中，已经全部入库的订单行不再列出，因此超收需要在该行最后一次入库时一并录入。手机上的[扫码收货](../mobile/receive)不支持超收。

## 权限

| 操作 | 需要的权限 |
| --- | --- |
| 保存即审核（未开启先存草稿） | 「采购入库新增」/「采购退货新增」 |
| 保存草稿、修改草稿、删除草稿 | 「采购入库新增」/「采购退货新增」 |
| 审核草稿；开启先存草稿后不存草稿直接「审核」 | 「采购入库审核」/「采购退货审核」（开启先存草稿后直接审核同时需要新增权限） |

内置角色中，采购员、仓库管理员、会计有「采购入库审核」「采购退货审核」，见[角色管理](../system/role#内置角色)。

## 注意事项

::: warning 注意
入库、退货审核后（未开启先存草稿时即保存后）不能修改或删除。数量录多了，请做采购退货冲回；退货录错了，请重新入库。审核前的草稿可以修改、删除。
:::

::: tip 提示
有门户账号的供应商可以先在门户发起 [送货通知](./asn)，仓库按送货通知一键收货。使用手机 / PDA 时，也可以在「移动作业」的扫码收货中按采购订单扫码入库，见 [移动作业](../mobile/receive)。
:::

## 常见问题

**选择订单时找不到订单？** 入库只列出已审核、部分完成的订单；草稿、审批中的订单需要先审核；已选择供应商时只列出该供应商的订单；直接开单生成的订单不会出现。没有订单时也可以不选订单直接开单。

**提示「采购入库必须引用订单（业务参数未开启「允许直接开单」）」？** 管理员关闭了[业务参数](../system/biz-rule#允许直接开单)「允许直接开单」，请引用订单，或请管理员开启。

**提示「没有审核采购入库的权限，请保存为草稿，由有审核权限的人审核」？** 开启了「进销存单据先存草稿」，你没有「采购入库审核」权限，请点「保存草稿」，由有审核权限的人审核；或请管理员授权。

**审核草稿时提示库存不足、数量超出？** 草稿保存时不校验这些，审核时按当时的数据校验，可能其他单据已经入库、退货或出库了。审核失败不会改变任何数据，按提示修改草稿后再审核即可。

**提示数量超出未完成数量？** 订单剩余未入库数量不足，可能其他人刚刚入库了一部分。超出订单的数量需要先通过订单「变更」增加数量；经常有少量超收的，可以设置[业务参数](../system/biz-rule)中的采购入库超收比例。
