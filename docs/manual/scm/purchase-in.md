# 采购入库与采购退货

采购入库是仓库按采购订单收货入库的单据，采购退货是把已入库的货物退还给供应商的单据。两者可以引用采购订单（退货引用原入库单）录入，也可以不选订单[直接开单](#直接开单)：选择供应商和商品直接入库、退货，系统自动生成已审核的订单。单据**保存即确认**：立即生成仓库单据、更新库存，同时生成[应付单](../fin/ar-ap)（退货为红字应付单），并回写订单的已入库、已退货数量。

## 页面入口

- 供应链 → 采购 → 采购入库
- 供应链 → 采购 → 采购退货

也可以从 [采购订单](./purchase) 列表的「入库」按钮、订单详情的「采购入库」「采购退货」按钮直接打开，此时订单已固定，不能更换。

![采购入库列表](/images/manual/scm/purchase-in-list.jpg)

![采购退货列表](/images/manual/scm/purchase-return-list.jpg)

## 列表

两个页面的结构相同。

**查询条件**：单据号、订单号、供应商、仓库、业务日期范围。

**列表列**：单据号（点击查看详情）、订单号（来源采购订单号，直接开单的单据显示蓝色「直接开单」标签）、供应商（名称和编码）、仓库、业务日期、数量、价税合计（直接开单填写了整单优惠时下方显示「整单优惠 ¥…」，采购入库填写了运费时下方显示「运费 ¥…」）、仓库单据（自动生成的仓库[入库](../wms/in) / [出库](../wms/out)单号）、制单人、创建时间。

点击表格工具栏的下载图标可按当前查询条件**导出**列表（采购入库、采购退货各自导出）：供应商导出为「编码 名称」，仓库导出明细涉及的全部仓库，「价税合计」拆成价税合计、整单优惠两列（采购入库另有运费列），详见[通用操作 → 导出](../guide/common#导出)。

**工具栏**：「新增采购入库」或「新增采购退货」。

**行操作**：只有「查看」（显示为图标加文字）。入库、退货单据不能修改和删除。

## 新增采购入库

表单底部提示：「录入入库的库位、批次（序列号）。保存后立即生成仓库入库单并更新库存，同时生成应付单，单据不能修改，错误时请做退货冲回。」

### 表头

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 供应商 | 直接开单时必填 | 选择供应商（提示「请选择供应商」）。引用订单后自动填为订单的供应商，不能修改 |
| 仓库 | 是 | 引用订单时默认订单的收货仓库。更换仓库会清空各行已选的库位、序列号 |
| 业务日期 | 是 | 默认今天，即入库日期，应付单的单据日期和到期日从此计算；直接开单时也是自动生成的订单的日期，合同价、供货价格按此日期取价 |
| 备注 | 否 | |
| 运费 | 否 | 只在采购入库中显示，见下文[采购运费](#采购运费) |
| 引用订单 | 否 | 输入订单号搜索，只列出已审核、部分完成的订单（已选择供应商时只列出该供应商的订单，直接开单生成的订单不列出）。右侧提示当前方式：不引用时为「不引用时直接开单：选择商品、数量和单价，保存后自动生成已审核的订单」，引用后为「按订单明细录入，清空后改为直接开单」 |

[业务参数](../system/biz-rule#允许直接开单)关闭「允许直接开单」时，必须引用订单，提示「业务参数未开启直接开单，需引用订单」。

明细标题栏显示行数、合计数量和价税合计，右侧「推荐库位」按钮按仓库的[上架策略](../wms/label-putaway#上架策略)为还没有选库位的行推荐库位；直接开单时还有「添加商品」按钮。

### 直接开单的明细

不引用订单时，表单打开时就有一行空明细，点「添加商品」继续增加：

| 列 | 说明 |
| --- | --- |
| 物料 | 必填，搜索或扫码选择商品（提示「请选择商品」） |
| 库位、批次号 | 同下文「引用订单的明细」 |
| 数量 | 必填 |
| 含税单价 | 必填（提示「请填写单价」）。选择供应商和商品后自动带出默认价：采购合同价 → 供货价格 → 最近进价 → 参考成本，单价下方显示来源，见[开单默认价](./price-list#开单默认价)（同一商品多行时，每行按本行数量匹配供货阶梯价）；「价格参考」查看该商品的进货历史、各供应商价格对比，点击其中的价格即可填入单价，见[价格参考](./price-list#价格参考) |
| 税率 | 默认 13%，合同价、供货价格带出时同时带出税率 |
| 价税合计 | 数量 × 含税单价，下方显示税率 |
| 序列号 | 序列号物料扫码或输入 |

更换供应商或业务日期后，没有手工改过的单价重新取价。

**整单优惠**：明细下方的合计区可以填写「整单优惠」（含税金额），或用「抹零」抹去分、角分、个位，适合供应商送货单上的抹零、整单折让。保存时整单优惠记在自动生成的采购订单上，在内部按行金额比例分摊（尾差放在金额最大的一行），入库单的价税合计、应付单和入库成本都按优惠后的金额计算；明细的单价不变，详情、打印按优惠前的单价和金额显示，合计处列出「优惠前合计」「整单优惠」「优惠后合计」，[价格记忆、价格参考](./price-list#价格参考)和供货价格的采购历史也按优惠前单价记录。采购退货直接退货时同样可以填写。用法见[销售订单 - 整单优惠与抹零](./sales#整单优惠与抹零)。

![采购入库直接开单](/images/manual/scm/purchase-in-direct.jpg)

### 引用订单的明细

| 列 | 说明 |
| --- | --- |
| 物料 | 物料编码、名称、规格；启用批次 / 序列号管理的显示「批次」「序列号」标签 |
| 未完成数量 | 本行最多可入库的数量，下方显示订单单价（有整单优惠时为优惠前单价） |
| 库位 | 入库库位，可不选 |
| 批次号 | 批次管理的物料必填；同时可填写「生产日期」「有效期至」（用于临期提示和先到期先出） |
| 数量 | 必填，默认等于未完成数量，可改小（分批到货）。序列号物料只能为整数。允许超收时可以大于未完成数量，见下文「超收」 |
| 序列号 | 序列号物料扫码或输入，个数须与数量一致 |
| 操作 | 「拆分」：同一物料分多个库位 / 批次入库时，复制出一行分别填写；删除：本次不入库的行可删除 |

单价取订单单价，不能修改；外币订单按订单汇率折算为人民币。订单有整单优惠时，明细下方列出「合计」（优惠前）、「订单优惠分摊」和「优惠后合计」（按扣除优惠后的成交价估算，以保存后的单据为准），本单分摊的优惠记在入库单上。

### 采购运费

采购入库表单（直接开单和引用订单都可以）的明细下方有「运费」，提示「按各行不含税金额分摊计入存货成本，生成运费应付单」：

| 字段 | 说明 |
| --- | --- |
| 运费 | 选填，金额，最多 2 位小数；填写后才显示下面两项 |
| 运费付给 | 「供应商代垫」（默认）：运费由本单的供应商代垫，计入该供应商的应付；「本公司承担」：运费付给承运商 |
| 承运商 | 「本公司承担」时必填，选择一个供应商作为承运商（提示「请选择承运商（供应商）」） |

保存后：

- 运费按各行不含税金额的比例分摊到明细（全是赠品、金额为 0 时按数量分摊），计入这些物料的入库成本和月末[成本核算](../fin/cost)的采购金额；
- 生成一张来源为「采购运费」的[应付单](../fin/ar-ap)：供应商代垫时应付本单供应商，本公司承担时应付所选承运商，到期日按其账期；生成凭证为 借 存货（按物料分类）/ 贷 应付账款；
- 入库单详情显示「运费 ¥…」、付给方式标签和承运商，打印的合计处也列出运费；
- 采购退货按退货单价冲减应付，运费不退。

::: tip 提示
只有采购入库可以填写运费；销售发货的运费在[物流发运](./shipment#运费承担)中登记。

## 新增采购退货

表单底部提示：「从所选仓库的现有库存中选择库位、批次（序列号）。保存后立即生成仓库出库单并更新库存，同时生成应付单，单据不能修改，错误时请重新入库 / 出库冲回。」

退货有两种方式：

- **引用原入库单**：在「原采购入库单」中输入单据号搜索（已选择供应商时只列出该供应商的入库单），选择后带出该入库单的明细（单价、批次号沿用原单），按原订单回写退货数量；
- **直接退货**：不选原单，像直接开单一样选择供应商、商品、数量、含税单价（默认价规则同采购入库）、税率，保存后系统生成一张已审核的订单（标记「直接开单」），只用于记录这次退货。

从采购订单详情点「采购退货」进入时，引用的是该订单（「引用订单」），订单不能更换。

| 字段 / 列 | 说明 |
| --- | --- |
| 原采购入库单 / 引用订单 | 见上文，可不选 |
| 供应商、仓库、业务日期、备注 | 同入库；仓库为退货出库的仓库 |
| 退货后需要补收 | 引用原单或订单时显示（原订单是直接开单生成的除外）。勾选后订单恢复相应的未完成数量，可以继续入库；不勾选视为退款，订单不再补收。原订单已关闭时只能退款 |
| 可退数量 | 引用时显示：订单该行的已入库 − 已退货 |
| 库位 / 批次 | 必填，从所选仓库该物料的现有库存中选择，显示可用数量；包含冻结的库存（不合格、待检） |
| 数量 | 必填，退货默认不填，需逐行填写；不需要退的行可以删除 |
| 序列号 | 序列号物料从所选库位的在库序列号中选择或扫码 |

## 查看详情

详情显示单据号、订单号（直接开单的单据在订单号后显示「直接开单」标签，打印时显示为「订单号 (直接开单)」）、供应商、仓库、业务日期、仓库单据、退货方式（退货单：退货退款 / 退货补收）、价税合计和税额（外币订单另显示原币金额）、运费（填写时）、制单，以及明细（物料、库位、批次及生产 / 有效日期、数量、含税单价、价税合计和税率、序列号）。本单分摊了整单优惠时，明细为优惠前的单价和金额，表头显示「优惠前合计」「整单优惠」（退货单为「原单优惠分摊」）和「优惠后合计」（退货单为「退款金额」）。右上角「打印」按[打印模板](../system/print-template)打印。

## 直接开单

直接开单适合没有事先下采购订单的业务，例如门店临时进货、零星采购。保存直接开单的入库 / 退货单时，系统在同一次保存中：

1. 按单据的供应商、业务日期、仓库、备注、整单优惠和明细（一行对应一行订单明细）生成一张采购订单，**直接审核**，不走采购订单审批流程，审核人为制单人；
2. 再按这张订单入库 / 退货，后续处理与引用订单完全相同（库存、批次序列号、来料检验冻结、应付单、成本等）；入库时同样校验[最高采购价](./price-list#价格控制)，控制方式为「禁止保存」时超出不能保存；
3. 入库生成的订单随即为「已完成」；直接退货生成的订单视为已全部入库，只用于回写退货数量，库存按退货出库，应付按退货金额冲减。

自动生成的订单在[采购订单](./purchase#直接开单生成的订单)列表中显示「直接开单」标签，不能修改、反审核、关闭、变更，也不能「退货后需要补收」；入库录错时请做采购退货冲回。任何一步失败（如超出最高采购价、序列号重复），入库单和订单都不会保存。

## 保存时发生了什么

**采购入库**：

1. 校验订单仍为已审核或部分完成，各行数量不超过未完成数量（设置了超收比例时不超过允许超收后的数量；并发入库时也不会超出）。
2. 生成已确认的仓库「采购入库」单，库存、批次、序列号即时增加。
3. 需要来料检验的物料按入库数量冻结为「待检」，由质量模块的[来料检验](../qms/inspection#来料冻结与放行)放行或判定不合格。
4. 回写订单明细的已入库数量，重算订单状态（部分完成 / 已完成）。
5. 生成应付单：金额为价税合计，到期日 = 业务日期 + 供应商账期（订单行有整单优惠分摊时，完成该行的最后一批取「订单行金额 − 已入库金额」，各批累计正好等于订单行金额）；订单引用了约定付款天数的 [采购合同](./contract) 时按合同的付款天数。
6. 填写了运费时，运费分摊计入入库成本，另生成「采购运费」应付单，见上文[采购运费](#采购运费)。

**采购退货**：

1. 校验各行数量不超过可退数量。原订单有整单优惠时按扣除优惠后的成交价冲减应付，退货单的合计处显示「原单优惠分摊」和「退款金额」，规则同[销售退货](./sales-out#整单优惠与买赠)。
2. 先解冻本订单的不合格、待检库存（优先退冻结库存），再生成已确认的仓库「采购退货」出库单。
3. 回写已退货数量；勾选补收的同时增加待补收数量，订单恢复未完成。
4. 生成红字（负数）应付单冲减应付。

任何一行出错（库存不足、序列号不在库、超出数量等），整张单据不会保存，提示会指明是第几行、哪个物料。

## 超收

默认入库数量不能超过订单的未完成数量。供应商实际到货略多于订单（如按整包装发货）时，可以在「系统管理 → [业务参数](../system/biz-rule)」中设置「**采购入库超收比例（%）**」（0 ~ 100，默认 0 即不允许超收）：

- 每行累计入库数量最多为「订单数量 × (1 + 超收比例)」，再加上退货补收数量；
- 例如订单 100 个、超收比例 5%，最多可累计入库 105 个；
- 超出时提示「…超出允许超收 / 超发后的数量…」；未设置超收比例时提示「…超出未完成数量…」；
- 超收后该行视为已完成，订单状态按入库情况变为「已完成」；超收部分同样生成应付单；
- 采购退货不受超收比例影响，最多退「已入库 − 已退货」。

在入库表单中，已经全部入库的订单行不再列出，因此超收需要在该行最后一次入库时一并录入。手机上的[扫码收货](../mobile/receive)不支持超收。

## 注意事项

::: warning 注意
入库、退货保存后不能修改或删除。数量录多了，请做采购退货冲回；退货录错了，请重新入库。
:::

::: tip 提示
有门户账号的供应商可以先在门户发起 [送货通知](./asn)，仓库按送货通知一键收货。使用手机 / PDA 时，也可以在「移动作业」的扫码收货中按采购订单扫码入库，见 [移动作业](../mobile/receive)。
:::

## 常见问题

**选择订单时找不到订单？** 入库只列出已审核、部分完成的订单；草稿、审批中的订单需要先审核；已选择供应商时只列出该供应商的订单；直接开单生成的订单不会出现。没有订单时也可以不选订单直接开单。

**提示「采购入库必须引用订单（业务参数未开启「允许直接开单」）」？** 管理员关闭了[业务参数](../system/biz-rule#允许直接开单)「允许直接开单」，请引用订单，或请管理员开启。

**提示数量超出未完成数量？** 订单剩余未入库数量不足，可能其他人刚刚入库了一部分。超出订单的数量需要先通过订单「变更」增加数量；经常有少量超收的，可以设置[业务参数](../system/biz-rule)中的采购入库超收比例。
