# 供应链管理

供应链管理覆盖从「买进来」到「卖出去」的全部业务单据：采购员请购、询价、招标、签合同、下采购订单，仓库收货入库；销售人员报价、按价目表和促销下销售订单，仓库拣货出库、物流发运。出入库单据保存后自动生成仓库单据更新库存，同时生成应收 / 应付单交给财务，形成完整的业务闭环。

在顶部导航点击「供应链」进入本模块，左侧菜单分为「采购」「采购寻源」「销售」「往来单位」「进销存报表」五组。

## 功能清单

### 采购

| 菜单 | 用途 |
| --- | --- |
| [请购单](./requisition) | 部门提出物料需求，审批后按供应商合并生成采购订单 |
| [采购订单](./purchase) | 向供应商下单，审核（可接入审批）后入库、退货、变更 |
| [送货通知](./asn) | 供应商在门户发起的送货通知，仓库按实收数量收货 |
| [采购入库与采购退货](./purchase-in) | 按采购订单入库 / 退货，或不选订单直接开单，自动生成仓库单据和应付单 |
| [补货建议](./reorder) | 按再订货点计算需要补货的物料，一键生成请购单 |
| [采购返利](./purchase-rebate) | 供应商按期间采购额阶梯返利或按项目约定金额，结算生成红字应付单冲减应付 |

### 进销存报表

| 菜单 | 用途 |
| --- | --- |
| [销售报表](./jxc-sales) | 按类别、品牌、区域、客户、业务员、商品、日 / 月汇总销售出库和退货，净额、成本、毛利，汇总 → 明细 → 单据穿透并可导出 |
| [进货报表](./jxc-purchase) | 按类别、品牌、供货商、商品、日 / 月汇总采购入库和退货，穿透到明细和单据 |
| [经营状况](./jxc-business) | 销售及利润走势、资金流走势、员工销售情况、客户销售分布 |
| [资产状况](./jxc-assets) | 截至今天或任一过去日期的资金、库存、应收应付、票据、预收预付和净资产 |
| [商品分析](./jxc-goods) | 畅销、滞销、积压、缺货、周转 |
| [客户分析](./jxc-rfm) | 按 RFM 给客户打分，分为八类客户群并给出经营建议 |

报表的权限、统一口径以及与财务、商务智能等其他报表的区别见 [进销存报表概述](./jxc)。

其他通用能力：

- **多规格物料**：服装、鞋帽等按颜色、尺码管理的商品，采购、销售订单可以「按规格录入」，在规格矩阵中一次填写各 SKU 的数量，见[采购订单](./purchase#按规格录入)；
- **扩展字段**：客户、供应商、采购订单、销售订单（以及物料）可以通过「系统管理 → [自定义字段](../system/custom-field)」增加扩展字段，在表单中填写、在列表或详情中显示；
- **价格体系**：物料可维护零售价、批发价1～8（[商品价格](./goods-price)），客户可设置价格等级和执行价；销售订单、报价和直接开单按 客户执行价 → 价目表 → 等级价 → 零售价 → 最近价 带出[开单默认价](./price-list#开单默认价)，单价下方的「[价格参考](./price-list#价格参考)」可查看报价、销售、进货历史和各往来单位的价格对比；
- **历史成交价**：录入订单时显示该往来单位这个物料的上次成交价，没有其他价格时自动带出；
- **直接开单**：采购入库、销售出库及退货可以不选订单，直接选择往来单位和商品开单，系统自动生成已审核的订单；销售出库直接开单时买赠的赠品随单出库，见[销售出库](./sales-out#直接开单)、[采购入库](./purchase-in#直接开单)；
- **整单优惠 / 抹零**：采购 / 销售订单、销售报价和直接开单可以填写整单优惠或一键抹零，只在合计处扣减，明细单价、价格记忆和价格参考仍是优惠前的单价（内部在促销、返利之后按行金额比例分摊，用于部分出入库、退货、毛利）；退货按扣除优惠后的成交价退款；询价时供应商承诺的整单优惠在定标时带到采购订单；分批出入库的金额累计正好等于订单金额，部分出入库的订单关闭时几分钱的尾差自动生成应收 / 应付调整单，见[销售订单 - 整单优惠与抹零](./sales#整单优惠与抹零)。

## 单据状态总览

| 单据 | 状态流转 |
| --- | --- |
| 采购 / 销售订单 | 草稿 → （审批中）→ 已审核 → 部分完成 → 已完成；已审核、部分完成可关闭 |
| 采购入库 / 退货、销售出库 / 退货 | 保存即审核；开启「进销存单据先存草稿」时为 草稿 → 已审核，审核后不能修改 |
| 请购单 | 草稿 → （审批中）→ 已批准 → 已下单；草稿、已批准可关闭 |
| 询价单 | 询价中 → 已定标；询价中可关闭 |
| 招标 | 草稿 → 投标中 → 已开标 → 已定标；未定标前可取消 |
| 采购合同 | 草稿 → （审批中）→ 生效 → 已关闭 |
| 销售报价 | 草稿 → （审批中）→ 已批准 → 已成交；草稿、已批准可标记为已失效 |
| 发货通知 | 待拣货 → 已拣货 → 已出库；未出库前可取消 |
| 拣货波次 | 拣货中 → 已完成；拣货中可取消 |
| 物流发运 | 待发运 → 运输中 → 已签收；运输中可标记异常 |
| 送货通知 | 待收货 → 已收货；待收货时供应商可取消 |
| 销售返利 / 采购返利 | 执行中 → 已结算（可撤销结算） |
| 销售提成表 | 草稿 → 已确认（可取消确认） |

括号中的「审批中」只在流程中心发布了对应流程时出现，未发布时提交 / 审核后直接生效。

## 接入审批的单据

以下单据可以在流程中心的「[流程模型](../workflow/model)」中设计审批流程，发布后对应的「审核」「提交」按钮改为发起审批，审批通过后自动生效，拒绝或撤回后回到草稿。未发布或停用流程时直接生效。

| 单据 | 触发审批的操作 | 可用于条件分支的变量 |
| --- | --- | --- |
| 采购订单审核 | 采购订单「审核」 | 订单金额、整单优惠、订单号 |
| 销售订单审核 | 销售订单「审核」 | 订单金额、整单优惠、订单号 |
| 请购单审批 | 请购单「提交」 | 请购单号 |
| 销售报价审批 | 报价单「提交」 | 报价金额、最低折扣率（如 85 表示 85 折，含整单优惠的分摊）、整单优惠、整单优惠比例（%）、报价单号 |
| 订单变更审批 | 订单「变更」后「提交变更」 | 订单类型（采购 / 销售）、变更金额差额（增加为正）、变更后的整单优惠、整单优惠变化（增加为正）、订单号 |
| 采购合同审批 | 采购合同「提交」 | 合同金额、合同类型、合同编号 |

系统内置了这些流程模型（未发布），已按岗位设计好审批链，管理员按需调整审批人后发布即可。

## 典型业务流程

### 采购到付款

1. 需求部门在 [请购单](./requisition) 中提出需求并提交审批；或由 [补货建议](./reorder)、生产模块的 [MRP 运算](../mes/mrp) 自动产生需求。
2. 采购员按需要通过 [询价比价](./inquiry) 或 [招标采购](./tender) 选定供应商，必要时签订 [采购合同](./contract)。
3. 请购单批准后一键「生成采购订单」（按供应商合并），或手工新增 [采购订单](./purchase)，审核（或审批）通过。
4. 审核通过后系统通知供应商的门户账号，供应商在门户接受订单、填写承诺交期，并发起送货通知。
5. 仓库按 [送货通知](./asn) 收货，或直接在 [采购入库](./purchase-in) 中按订单入库（没有订单的零星采购可以不选订单直接开单）：自动生成仓库[入库单](../wms/in)、更新库存，生成[应付单](../fin/ar-ap)；需要[来料检验](../qms/inspection#来料冻结与放行)的物料先[冻结](../wms/hold)待检。
6. 质量问题可做采购退货（优先退冻结库存），退货生成红字应付单。
7. 财务对应付单[付款核销](../fin/settlement)、[生成凭证](../fin/voucher#业务生成的凭证)；与[供应商对账](../fin/statement)时，供应商在[门户](../portal/supplier)确认对账单。

### 销售到收款

1. 销售人员给客户做 [销售报价](./quotation)（单价按[开单默认价](./price-list#开单默认价)带出：客户执行价、价目表、价格等级等），审批后「转销售订单」；也可直接新增 [销售订单](./sales)，或由[经销商门户](../portal/dealer)下单、外部订单导入、[CRM 商机赢单](../crm/opportunity#赢单生成销售订单)生成。
2. 新增 / 修改销售订单时自动应用 [促销活动](./promotion)，可使用 [返利](./rebate) 余额抵扣。
3. 审核销售订单时校验客户信用额度（控制方式见[业务参数](../system/biz-rule)），通过后可[预留库存](../wms/reservation)。
4. 订单生成 [发货通知](./delivery)，仓库按[拣货建议](../wms/label-putaway#拣货建议与拣货路径)拣货（多张通知可合并为 [波次](./wave)），确认拣货后出库，自动生成 [销售出库单](./sales-out)、仓库[出库单](../wms/out)和应收单。也可以不走发货通知，直接在销售出库中按订单出库；门市零售等没有订单的业务可以不选订单直接开单，系统自动生成已审核的订单。
5. 出库单创建 [物流发运](./shipment) 单，发货、跟踪、签收；指定运费结算供应商时生成运费应付单。
6. 财务对应收单收款核销、生成凭证。
7. 月末按订单业务员计算 [销售提成](./commission)，确认后计入当月[工资表](../hr/payroll)。

### 订单与仓库、财务的联动

| 业务单据 | 自动生成 / 回写 |
| --- | --- |
| 采购入库 | 已确认的仓库「采购入库」单（更新库存、[批次、序列号](../wms/trace)）；应付单（到期日 = 入库日期 + 供应商账期，引用了约定付款天数的合同时按合同）；回写订单已入库数量和状态 |
| 采购退货 | 仓库「采购退货」出库单；红字应付单；回写订单已退货数量 |
| 销售出库 | 仓库「销售出库」单；应收单（到期日 = 出库日期 + 客户账期）；核销本订单的库存预留；回写订单已出库数量和状态 |
| 销售退货 | 仓库「销售退货」入库单；红字应收单；回写订单已退货数量 |
| 物流发运发货 | 指定了运费结算供应商时生成运费应付单（销售费用） |
| 销售返利结算 | 红字应收方式生成红字应收单 |
| 采购返利结算 | 红字应付单 |

入库、出库数量默认不能超过订单的未完成数量，可在「系统管理 → [业务参数](../system/biz-rule)」中设置采购入库超收比例、销售出库超发比例；客户信用额度的控制方式也在业务参数中设置。

销售出库、采购入库及退货默认可以不选订单直接开单（业务参数「允许直接开单」），销售出库的明细可以从多个仓库出库（业务参数「销售出库明细可选仓库」）。

出入库、退货单据都是 **保存即确认**，不能修改、删除，录错时通过反向单据冲回（入库错了做退货，退货错了重新入库 / 出库）。需要先录入、再确认的，可以开启业务参数「[进销存单据先存草稿](../system/biz-rule#进销存单据先存草稿)」，单据先存草稿，审核后才出入库，见[采购入库 - 草稿与审核](./purchase-in#草稿与审核)。库存不足、序列号不在库等错误会使整张单据保存失败，不会出现只成功一半的情况。

仓库模块的手工入库只能选「其他入库」「寄售入库」，手工出库只能选「其他出库」「报废出库」（其他类型在下拉中置灰并注明由哪种单据生成），采购、销售类型的仓库单据只能由本模块的业务单据生成，以保证应收应付和成本完整。

## 数据权限

订单、出入库单、发运单、请购单、询价单、报价单、发货通知按「制单人部门 + 制单人」控制数据权限；采购合同、招标按「创建人部门 + 创建人」控制。角色的数据范围在系统管理的「[角色管理](../system/role#数据权限页签)」中设置，例如只能看本部门的订单。

进销存报表按出入库单的「制单人部门 + 制单人」统计；资产状况和经营状况中的资金流汇总全公司数据，需要「全部数据」的数据范围，见[进销存报表概述](./jxc#权限)。
