# 销售出库与销售退货

销售出库是仓库按销售订单发货出库的单据，销售退货是客户退回货物重新入库的单据。两者可以引用销售订单（退货可以引用原出库单）录入，也可以不选订单[直接开单](#直接开单)：选择客户和商品直接出库、退货，系统自动生成已审核的订单。单据**保存即确认**：立即生成仓库单据、更新库存，同时生成[应收单](../fin/ar-ap)（退货为红字应收单），并回写订单的已出库、已退货数量。

销售出库单可以手工新增，也可以由 [发货通知](./delivery) 确认拣货后「出库」、[寄售结算](./consign) 自动生成。

出库、退货时可以登记[运费](#运费)：本公司承担的运费付给承运商（现付生成费用支出单，月结生成承运商应付单），代垫运费计入客户的应收，见下文。

需要「录单、确认」分开的企业，可以在[业务参数](../system/biz-rule#进销存单据先存草稿)中开启「进销存单据先存草稿」：手工新增的出库、退货单先保存为草稿，审核后才出库、入库，见[草稿与审核](#草稿与审核)。

## 页面入口

- 供应链 → 销售 → 销售出库
- 供应链 → 销售 → 销售退货

也可以从 [销售订单](./sales) 列表的「出库」、订单详情的「销售出库」「销售退货」按钮直接打开（订单固定，不能更换）。

## 列表

**查询条件**：单据号、订单号、客户、仓库、业务日期范围。

**列表列**：单据号（点击查看详情）、订单号（来源销售订单号，直接开单的单据显示蓝色「直接开单」标签）、客户（名称和编码）、仓库（按明细实际出库的仓库显示，涉及多个仓库时显示「多仓（N）」，鼠标悬停查看）、业务日期、数量、价税合计（优惠后的金额；直接开单填写了整单优惠时下方显示「整单优惠 ¥…」，登记了运费时下方显示「运费 ¥…」）、仓库单据、制单人、创建时间。

点击表格工具栏的下载图标可按当前查询条件**导出**列表（销售出库、销售退货各自导出）：客户导出为「编码 名称」，仓库导出明细涉及的全部仓库，「价税合计」拆成价税合计、整单优惠两列，另有运费列，详见[通用操作 → 导出](../guide/common#导出)。

**工具栏**：「新增销售出库」或「新增销售退货」。

**行操作**（行末操作栏中的图标，鼠标悬停显示名称；销售退货只有「查看」，显示为图标加文字）：

- 「查看」：打开详情，可打印。
- 「发运」（仅销售出库，需物流发运新增权限）：跳转到 [物流发运](./shipment) 并以该出库单新建发运单。一张出库单只能创建一张发运单。

出库、退货单据不能修改和删除。

开启「进销存单据先存草稿」（或关闭参数后还有未处理的草稿）时，列表上方有「**已审核**」「**草稿（N）**」两个页签，上面所说的是「已审核」页签；「草稿」页签见[草稿与审核](#草稿与审核)。

表单底部提示：「从所选仓库的现有库存中选择库位、批次（序列号）。保存后立即生成仓库出库单并更新库存，同时生成应收单，单据不能修改，错误时请做退货冲回。」开启「进销存单据先存草稿」时，底部按钮为「保存草稿」「审核」，见[草稿与审核](#草稿与审核)。

| 业务员 | 只在直接开单时显示，选填；为空时取客户的负责销售，没有时为制单人（提示「默认客户负责人或本人」）。用于[销售提成](./commission) |

**直接开单的明细**（点「添加商品」增加行）：

| 列 | 说明 |
| --- | --- |
| 物料 | 必填，搜索或扫码选择商品 |
| 仓库 | 见下文「[明细选择仓库](#明细选择仓库)」 |
| 库位 / 批次 | 必填，从该行仓库的现有库存中选择，显示可用数量；批次登记了生产日期时显示「生产 日期」，临期、过期的批次另有标注 |

| 税率、价税合计 | 新增行的税率默认为表头发票类型的税率，没有选择发票类型时为业务参数「[默认税率](../system/biz-rule#默认税率)」（默认 13%）；执行价、价目表带出时同时带出（选择了发票类型时以发票类型为准）。列头的编辑图标可以统一设置全部明细的税率 |

### 发票类型与税率

直接开单（包括直接退货、草稿）时，明细税率的规则与[销售订单](./sales#发票类型与税率)相同：

- 表头选择「发票类型」后，全部明细（赠品行除外）的税率统一调整为该类型的税率，提示「已将 N 行明细的税率调整为 X%」，之后仍可逐行修改；选了发票类型时，客户执行价、价目表带出的税率不再覆盖明细税率；
- 没有选择发票类型时，按客户执行价、价目表带出的税率，都没有时为业务参数「[默认税率](../system/biz-rule#默认税率)」；
- 不使用发票类型时，可以点「税率」列头旁的编辑图标「统一设置税率」，输入税率或点快捷选项（默认税率和各发票类型的税率）后「应用到全部明细」（赠品行除外）。

发票类型记在自动生成的销售订单上，出库单本身不另存：出库单的详情、打印显示所属订单的发票类型。引用订单（退货引用原出库单）时，表单中只读显示订单的发票类型，明细税率按订单。

### 整单优惠与买赠

![直接开单的赠品与整单优惠](/images/manual/scm/sales-out-direct.jpg)

**买赠**：客户和业务日期适用[买赠促销](./promotion)时（按业务日期、客户等级判断，满足「每买 N 个赠 M 个」），系统在明细末尾自动加入赠品行：

- 赠品行显示绿色「赠品」标签，单价列显示「赠品 ¥0（促销名称）」，物料、单价、税率不能修改；数量下方提示「按促销应赠 …」；
- 系统按先到期先出自动选择表头仓库中的库位 / 批次（已过期的除外），一个库位不够时拆成多行；库存不够时剩余数量留在最后一行、不选库位，需要手工处理（或换仓库）。库位、批次可以修改，也可以「拆分」后分别选择，同一赠品各行数量合计必须等于应赠数量；只剩一行时不能删除；
- 修改商品、数量、单价、客户或业务日期后重新计算赠品；更换表头仓库后赠品行重新按先到期先出选择库位；
- 序列号管理的赠品需要扫描序列号；
- 赠品随单出库、扣减库存，成本照常结转，应收不含赠品；出库单详情中赠品行标记「赠品」。

保存时系统按促销规则重新计算并核对赠品：没有适用的买赠促销时提示「本单没有适用的买赠促销，请删除赠品行」；数量不符时提示「赠品 … 按促销应赠 …，明细中为 …，请按促销规则调整」；不能只有赠品没有商品。

**整单优惠**：直接开单时明细下方有合计区，可以填写「整单优惠」或用「抹零」抹去分、角分、个位，合计为扣除促销优惠之后的金额。保存时整单优惠记在自动生成的订单上，在内部按行金额比例分摊（在促销之后），出库单的价税合计和应收单都是优惠后的金额；**明细的单价不变**，详情和打印按优惠前的单价、金额显示，合计处列出「优惠前合计」「整单优惠」「优惠后合计」，[价格记忆和价格参考](./price-list#价格参考)也记录优惠前单价。销售退货、采购入库和采购退货的直接开单同样可以填写整单优惠。

**引用有整单优惠的订单**：表单中不能再填写整单优惠，明细按优惠前单价显示；明细下方列出「合计」（优惠前）、「订单优惠」和「优惠后合计」（金额以保存后的单据为准）。鼠标停在「订单优惠」上提示「订单的整单优惠：明细单价保持与订单一致，不改单价；优惠作为整单减少应收金额，本次按各行金额比例计算对应的优惠（最后一批为订单剩余的优惠），金额以保存后的单据为准」。每张出库单记录本单分摊到的优惠，分批出库时各单的优惠合计正好等于订单的整单优惠。销售出库的订单优惠**不能修改**：给客户的优惠由销售订单（审批）确定，需要调整时做订单变更（采购入库可以按供应商实际给的优惠修改，见[采购入库 - 订单优惠](./purchase-in#订单优惠)）。

![引用有整单优惠的订单出库](/images/manual/scm/sales-out-ref-discount.jpg)

**退货的整单优惠**：退货按扣除整单优惠后的**成交价**退款，不按优惠前单价退。例如销售 ¥1,000、整单优惠 ¥100，全部退货退 ¥900；部分退货按 数量 × 成交单价（不超过剩余可退金额）。引用原出库单或订单退货时，明细按优惠前单价显示，明细下方列出「合计」「原单优惠分摊」和「退款金额」；退货单详情、打印同样显示「优惠前合计」「原单优惠分摊」「退款金额」。鼠标停在「原单优惠分摊」上提示「原单的整单优惠按各行金额比例分摊，退货按扣除优惠后的成交价退款：退款金额 = 优惠前金额 − 原单优惠分摊」。

**引用订单的明细**：

| 列 | 说明 |
| --- | --- |
| 未完成数量 | 本行最多可出库的数量（订单数量 − 已出库 + 退货补发），下方显示订单单价（有整单优惠时为优惠前单价） |
| 仓库 | 见下文「明细选择仓库」 |
| 库位 / 批次 | 必填，从该行仓库该物料的现有库存中选择，显示可用数量和批次的生产日期 |
| 数量 | 必填，默认等于未完成数量，可改小分批出库；允许超发时可以大于未完成数量，见下文「超发」 |
| 序列号 | 序列号物料从所选库位的在库序列号中选择或扫码 |
| 操作 | 「拆分」：同一物料从多个库位 / 批次出库；删除本次不出库的行 |

### 明细选择仓库

[业务参数](../system/biz-rule#销售出库明细可选仓库)「销售出库明细可选仓库」开启时（默认开启），销售出库的明细多一列「仓库」，一张出库单可以从多个仓库出库：

- 每行可以另选仓库，为空表示「同表头仓库」；更换某行的仓库会清空该行已选的库位、批次、序列号；
- 库位 / 批次、序列号从该行的仓库中选择；
- 保存后，与表头不同的仓库记录在明细上，出库单和自动生成的仓库[出库单](../wms/out)的详情、打印中多一列「仓库」；库存、库存流水、成本核算、库存预留的核销都按各行的仓库计算。

参数关闭后不显示该列，整张单据从表头仓库出库。销售退货、采购入库和采购退货只有表头仓库。

## 新增销售退货

![新增销售退货](/images/manual/scm/sales-return-form.jpg)

退货有两种方式：

- **引用原出库单**：在「原销售出库单」中输入单据号搜索（已选择客户时只列出该客户的出库单），选择后带出该出库单的明细（单价、批次号沿用原单），按原订单回写退货数量；原订单有整单优惠时按扣除优惠后的成交价退款，见上文[整单优惠与买赠](#整单优惠与买赠)；
- **直接退货**：不选原单，选择客户、商品、数量、含税单价（默认价规则同销售出库）、税率，保存后系统生成一张已审核的订单（标记「直接开单」），只用于记录这次退货。

从销售订单详情点「销售退货」进入时，引用的是该订单，订单不能更换。

| 字段 / 列 | 说明 |
| --- | --- |
| 原销售出库单 / 引用订单 | 见上文，可不选 |
| 客户、仓库、业务日期、备注 | 退货入库的仓库和日期 |
| 退货后需要补发 | 引用原单或订单时显示（原订单是直接开单生成的除外）。勾选后订单恢复相应的未完成数量，可以继续出库；不勾选视为退款，订单不再补发。原订单已关闭时只能退款 |
| 可退数量 | 引用时显示：订单该行的已出库 − 已退货 |
| 库位、批次号 | 退回入库的库位、批次；批次管理的物料必填批次号 |
| 数量 | 必填，默认不填 |
| 序列号 | 退回的序列号 |
| 运费 | 选填，在明细下方填写客户代垫的退货运费，见下文[销售退货的运费](#销售退货的运费) |

## 运费

销售出库、销售退货（直接开单和引用订单都可以）的明细下方有「**运费**」，填写金额（最多 2 位小数）后才显示其他字段。运费不是销售收入，不分摊到明细，不影响库存成本；向客户收取或冲减的运费单独生成一张应收单（不并入货款的应收单），收款时与货款的应收单一起勾选。

### 销售出库的运费

| 字段 | 说明 |
| --- | --- |
| 运费 | 选填，金额 |
| 运费承担 | 「**本公司承担**」（默认）：运费是本公司的销售费用；「**代垫运费（客户承担）**」：本公司先替客户付给承运商，再向客户收回 |
| 付给承运商 | 「**现付**」（默认）：当场用现金或银行付款；「**月结**」：记为欠承运商的款，以后付款核销 |
| 付款账户 | 现付时必填（提示「请选择付款账户」），只能选库存现金、银行存款下的末级科目 |
| 承运商 | 月结时必填（提示「请选择承运商（物流公司）」）；现付时可以不选（标题显示「承运商（可不选）」），选了作为费用支出单的关联单位。下拉只列出在[供应商](./supplier#物流公司)资料中勾选了「物流公司（承运商）」的供应商，还没有标记任何物流公司时列出全部供应商并在下拉顶部提示 |

填写运费后，下方按「运费承担」和「付给承运商」提示保存后怎么入账：

| 情况 | 表单提示 | 生成的单据与凭证 |
| --- | --- | --- |
| 本公司承担、现付 | 本公司承担、现付：生成一张费用支出单（类别「销售运费」，来源为本出库单，可互相联查），出纳确认后生成凭证 借 销售运费 / 贷 付款账户 | 一张待确认的[费用支出单](../fin/other-income#业务单据生成的费用支出单)，出纳确认后：借 销售运费 / 贷 付款账户 |
| 本公司承担、月结 | 本公司承担、月结：生成承运商的应付单（借 销售运费 / 贷 应付账款-承运商），以后付款核销 | 承运商的[应付单](../fin/ar-ap)（来源「销售运费」）：借 销售运费 / 贷 应付账款-承运商 |
| 代垫运费、现付 | 代垫运费：另生成客户的代垫运费应收单，客户应收 = 货款 + 代垫运费；付给承运商的运费生成费用支出单（类别「代垫运费」），两边在代垫运费科目冲平，不是销售收入 | 客户的代垫运费应收单（来源「销售运费」，不含税）：借 应收账款 / 贷 代垫运费；费用支出单（类别「代垫运费」）确认后：借 代垫运费 / 贷 付款账户 |
| 代垫运费、月结 | 代垫运费：另生成客户的代垫运费应收单，客户应收 = 货款 + 代垫运费；付给承运商的运费生成承运商应付单，两边在代垫运费科目冲平，不是销售收入 | 客户的代垫运费应收单：借 应收账款 / 贷 代垫运费；承运商的应付单（来源「销售运费」）：借 代垫运费 / 贷 应付账款-承运商 |

- **代垫运费**时，客户的应收合计 = 货款 + 代垫运费：出库单详情显示「**应收合计（货款 + 代垫运费）**」，[往来汇总](../fin/ar-ap#往来汇总)中该客户的欠款就是两者之和。代垫运费在「代垫运费」科目一借一贷冲平，不是销售收入，不影响毛利；
- **本公司承担**的运费计入销售费用，在[毛利分析](../fin/analysis#计算口径)、[销售报表](./jxc-sales#金额口径)中作为「本公司运费」从销售金额中扣除，毛利相应减少；
- **现付**生成的费用支出单金额与出库单一致，不能修改、删除，由出纳在[其他收支](../fin/other-income)中确认后生成凭证；出库单详情中点「费用支出单」可直接打开它，费用支出单的来源单号也能打开这张出库单；
- 「销售运费」「代垫运费」的科目在「财务 → [凭证科目设置](../fin/account-rule#运费科目)」中设置，默认分别为 6601 销售费用、1221 其他应收款；费用支出单按收支类别的科目入账，两个内置类别默认使用同样的科目；
- 运费单据与出库在同一次审核中生成，任何一张生成失败，出库单整体不保存。例如**单据日期所在的会计期间已结账**时，现付的运费无法生成费用支出单，审核失败并提示「… 年 … 月 已结账，不能再处理业务日期在该期间的其他收支单」，请改为未结账期间的日期；
- 出库后由这张出库单创建[物流发运](./shipment#运费承担)单时，发运单带出这里登记的运费（只读），发货时不再生成运费单据，运费只记一次；出库单没有登记运费的，仍可以在发运单上填写。

### 销售退货的运费

销售退货的运费只有一种：「**客户代垫（本公司承担）**」，固定显示，不能选择。例如因质量问题承诺客户不承担退货运费，客户先把退货运费付给了承运商，由本公司承担，退货时一并冲减客户的欠款。客户已经付过运费，所以没有「付给承运商」、付款账户和承运商。

表单提示「客户代垫：退货运费由客户先付、本公司承担，生成红字应收冲减客户欠款，应收 = −（货款 + 代垫运费），凭证 借 销售运费 / 贷 应收账款」。保存后：

- 生成一张红字[应收单](../fin/ar-ap)（来源「销售退货运费」），凭证 借 销售运费 / 贷 应收账款；
- 退货冲减的客户应收 = −（货款 + 代垫运费），退货单详情显示「**应退合计（货款 + 代垫运费）**」；
- 这笔运费计入销售费用，在毛利分析、销售报表中按退货单计入「本公司运费」，从销售金额中扣除。

::: tip 提示
开启「进销存单据先存草稿」时，运费的金额、承担方式、付给方式、付款账户和承运商都随草稿保存；现付的付款账户、月结的承运商在审核时才检查是否已填写，审核后才生成上述单据。
:::

## 直接开单

直接开单适合零售、批发门市等不事先下销售订单的业务。保存直接开单的出库 / 退货单时，系统在同一次保存中：

1. 按单据的客户、业务日期、表头仓库、业务员、发票类型、备注和明细（一行对应一行订单明细）生成一张销售订单，**直接审核**，不走订单审批流程，审核人为制单人；
2. 出库时与手工新建订单一样处理价格：校验[最低销售价](./price-list#价格控制)（控制方式为「禁止保存」时低于最低价不能保存），应用折扣、满减、买赠[促销](./promotion)（赠品随单出库），再分摊整单优惠，按[业务参数](../system/biz-rule#客户信用额度控制)在审核订单时校验客户信用额度；不能使用返利抵扣；
3. 再按这张订单出库 / 退货，后续处理与引用订单完全相同（信用额度、超发、库存、批次序列号、应收单、成本、提成、单据追溯）；
4. 出库生成的订单随即为「已完成」；直接退货生成的订单视为已全部出库，只用于回写退货数量，库存按退货入库，应收按退货金额冲减。

自动生成的订单在[销售订单](./sales#直接开单生成的订单)列表中显示「直接开单」标签，不能修改、反审核、关闭、变更、预留或生成发货通知，退货时也不能补发；出库录错时请做销售退货冲回。任何一步失败（如库存不足、超出信用额度），出库单和订单都不会保存。

## 草稿与审核

默认情况下销售出库、销售退货**保存即审核**。在「系统管理 → [业务参数](../system/biz-rule#进销存单据先存草稿)」的「供应链」页签中开启「**进销存单据先存草稿**」（默认关闭）后，单据分两步：先保存草稿，确认后再审核（记账）。例如门市开单员先开出库草稿，仓库备货核对后审核出库；或客户退货先登记，验货后再审核入库。引用订单和直接开单都可以存草稿。规则与[采购入库 - 草稿与审核](./purchase-in#草稿与审核)相同，要点如下：

- **表单按钮**：「保存草稿」（新增权限）保存为草稿，提示「草稿已保存，审核后才出入库」；「审核」（审核权限，同时需要新增权限）不存草稿直接保存并审核；
- **草稿不影响任何业务数据**：不扣库存、不回写订单、不生成应收单和凭证，不占用客户信用额度，也不计入销售报表、提成、库存成本；保存时就占用单据号，审核后的出库 / 退货单沿用这个单号；
- **保存时只检查单据是否完整**：引用订单时订单可见、明细属于该订单；直接开单时已选择客户、每行都选了商品；运费承担方式符合单据种类，赠品只能用于销售出库，直接退货不能勾选补发。库存、信用额度、最低销售价、促销（折扣、满减、买赠的赠品数量）、可出库 / 可退数量，以及运费现付的付款账户、月结的承运商都**在审核时校验**；草稿金额按订单单价或录入单价估算，列表显示为「金额（估算）」；
- **草稿列表**：「草稿」页签与「已审核」页签共用查询条件，列出单据号（「草稿」标签）、订单号（或「直接开单」）、客户、仓库、业务日期、数量、金额（估算）、制单人、修改时间；行操作为「编辑」「审核」「删除」图标，按权限显示。编辑时库位批次、明细仓库、退货引用的原单、直接开单的发票类型都按草稿回显（发票类型审核时记到自动生成的订单上），引用订单的按订单最新情况带出未完成数量、可退数量；
- **审核**：确认「审核草稿 单据号？审核后将按草稿出入库、回写订单并生成应收应付，销售出库不能再修改，错误时需做退货冲回。」后，按审核当时的数据执行与保存即审核相同的处理（见下文[保存时发生了什么](#保存时发生了什么)）。任何一项不通过（如库存不足、超出信用额度、低于最低售价）**整体回滚**，不出库、不生成订单和应收，草稿和订单保持原样，修改后可再次审核；
- **审核后**：草稿移到「已审核」页签，制单人、制单部门仍为草稿的制单人，审核人为点审核的人，详情显示「审核」一行；直接开单的销售出库没有指定业务员时，业务员取客户的负责销售，没有时为草稿的制单人（不取审核人）。审核后不能修改、删除，没有反审核，错误请做销售退货冲回；
- **关闭参数后**：不能再新建草稿，已有草稿仍可在「草稿」页签中修改、审核、删除。

从首页待办「销售出库草稿待审核」「销售退货草稿待审核」进入时直接打开「草稿」页签。

由[发货通知](./delivery)拣货后出库、[寄售结算](./consign)生成的销售出库单各自已有确认步骤，不经过草稿，仍直接审核。小程序[快速开单](../miniapp/sales#快速开单)在开启参数时可以「存草稿」，有「销售出库审核」权限的还可以「保存并审核」（见[保存方式](../miniapp/sales#保存方式)），草稿也可以在小程序的[单据草稿](../miniapp/sales#单据草稿)中审核记账。

## 保存时发生了什么

开启「进销存单据先存草稿」时，以下处理在**审核**时发生，保存草稿时都不发生。

**销售出库**：

1. 校验订单为已审核或部分完成；**校验客户信用额度**（应收余额 + 全部未完成订单金额超过额度时暂停出库；[业务参数](../system/biz-rule)「客户信用额度控制」设为「不控制」时不校验）。
2. 校验每行数量不超过未完成数量（设置了销售出库超发比例时不超过允许超发后的数量）。
3. 先核销本订单在出库仓库（明细另选了仓库时按该行的仓库）的[库存预留](../wms/reservation)（出库不受自己预留的限制），再生成已确认的仓库「销售出库」单，扣减库存、批次、序列号；库存不足、序列号不在库时整张单据失败。
4. 回写已出库数量，重算订单状态；订单出库完成后释放剩余的预留。
5. 生成应收单：金额为价税合计，到期日 = 业务日期 + 客户账期。订单行有整单优惠等分摊时，完成该行的最后一批取「订单行金额 − 已出库金额」，各批累计正好等于订单行金额，见[销售订单 - 分批出库与关闭时的尾差](./sales#分批出库与关闭时的尾差)。外币订单按订单汇率折算为人民币，保留原币金额。
6. 登记了运费时，按运费承担和付给方式生成费用支出单、承运商应付单或客户的代垫运费应收单，见上文[销售出库的运费](#销售出库的运费)。

**销售退货**：生成仓库「销售退货」入库单，回写已退货数量（补发时同时增加待补发数量），生成红字应收单；登记了客户代垫的运费时另生成一张红字应收单（来源「销售退货运费」）。

## 超发

默认出库数量不能超过订单的未完成数量。按整件、整卷发货等经常略多于订单数量的业务，可以在「系统管理 → [业务参数](../system/biz-rule)」中设置「**销售出库超发比例（%）**」（0 ~ 100，默认 0 即不允许超发）：

- 每行累计出库数量最多为「订单数量 × (1 + 超发比例)」，再加上退货补发数量；超出时提示「…超出允许超收 / 超发后的数量…」；
- 超发部分按订单单价生成应收单；
- 销售退货不受超发比例影响，最多退「已出库 − 已退货」；
- 出库表单中已经全部出库的订单行不再列出，超发需要在该行最后一次出库时一并录入。发货通知的通知数量不能超过可通知数量，按发货通知出库时不会超发。

## 详情

详情显示单据号、订单号（直接开单的单据显示「直接开单」标签）、客户、仓库、业务日期、仓库单据、发票类型（所属订单选择了发票类型时，直接开单为自动生成的订单）、退货方式（退货单：退货退款 / 退货补发）、价税合计和税额（外币另显示原币）、制单（制单人、创建时间）、审核（审核人、审核时间，即出库 / 退货并生成应收的时间；保存即审核的单据为制单人，由草稿审核的为审核草稿的人）、备注，以及明细（明细选择了其他仓库时多一列「仓库」；物料（赠品显示「赠品」标签）、库位、批次及其生产日期 ~ 有效期（出库单随批次带出入库时登记的日期）、数量、含税单价、价税合计和税率、序列号）。右上角「打印」，表头包括发票类型（所属订单选择了时），明细包括「税率」列。

本单分摊了订单的整单优惠时（直接开单或引用有整单优惠的订单），明细的含税单价、价税合计为**优惠前**的金额，表头依次显示「优惠前合计」「整单优惠」（引用订单的为「订单优惠」，退货单为「原单优惠分摊」）和「优惠后合计」（退货单为「退款金额」），打印的合计处相同；没有整单优惠时只显示「价税合计」。

登记了运费时，表头显示「运费 ¥…」及运费承担标签（销售出库还有「现付」或「月结」标签），下方为承运商、付款账户；现付生成了费用支出单的再显示「费用支出单」，有其他收支查看权限时点击跳转到[其他收支](../fin/other-income)并打开该单据。代垫运费（销售出库）、客户代垫（销售退货）时另显示「应收合计（货款 + 代垫运费）」或「应退合计（货款 + 代垫运费）」。打印的合计处同样列出「运费」「运费承担」和「含代垫运费合计」（只在代垫时），可在[打印模板](../system/print-template)中隐藏或改名。

## 注意事项

::: warning 注意
出库、退货审核后（未开启先存草稿时即保存后）不能修改或删除。出库多了请做销售退货冲回，退货录错了请重新出库。审核前的草稿可以修改、删除。
:::

::: tip 提示
需要按拣货建议拣货、装箱的业务，建议走 [发货通知](./delivery) 流程，确认拣货后一键出库，避免手工选库位批次。
:::

## 常见问题

**提示超出信用额度、暂停出库？** 客户的应收余额与未完成订单合计已超过信用额度。请先[收款核销](../fin/settlement)应收，或在 [客户](./customer) 中调整信用额度。

**选不到库位 / 批次？** 所选仓库中该物料没有可用库存（冻结、已被其他订单预留的不可用），请检查[库存](../wms/stock)或更换仓库；开启了明细选择仓库时，也可以只为这一行选择有库存的仓库。

**提示「赠品 … 应赠 …，所选仓库可出库的库存只有 …」？** 表头仓库中赠品的可用库存不够，请补货、更换仓库，或开启明细选择仓库后为赠品行另选仓库。

**审核时提示「运费现付时请选择付款账户」或「运费月结时请选择承运商（物流公司），生成承运商的应付单」？** 登记运费后，现付要选择付款账户，月结要选择承运商。草稿保存时不检查这两项，审核时才检查。

**审核时提示「… 年 … 月 已结账，不能再处理业务日期在该期间的其他收支单」？** 本单登记了现付的运费，要生成一张同日期的费用支出单，而业务日期所在的会计期间已经结账。请把业务日期改到未结账的期间，或请会计反结账。

**销售运费还要在发运单上再填一次吗？** 不用。出库单登记了运费的，发运单自动带出且不能修改，发货时也不再生成运费单据，见[物流发运 - 运费承担](./shipment#运费承担)。

**提示「销售出库必须引用订单（业务参数未开启「允许直接开单」）」？** 管理员关闭了[业务参数](../system/biz-rule#允许直接开单)「允许直接开单」，请引用订单，或请管理员开启。
