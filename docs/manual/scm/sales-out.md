# 销售出库与销售退货

销售出库是仓库按销售订单发货出库的单据，销售退货是客户退回货物重新入库的单据。两者都必须从销售订单出发，**保存即确认**：立即生成仓库单据、更新库存，同时生成[应收单](../fin/ar-ap)（退货为红字应收单），并回写订单的已出库、已退货数量。

销售出库单可以手工新增，也可以由 [发货通知](./delivery) 确认拣货后「出库」、[寄售结算](./consign) 自动生成。

## 页面入口

- 供应链 → 销售 → 销售出库
- 供应链 → 销售 → 销售退货

也可以从 [销售订单](./sales) 列表的「出库」、订单详情的「销售出库」「销售退货」按钮直接打开（订单固定，不能更换）。

![销售出库列表](/images/manual/scm/sales-out-list.jpg)

![销售退货列表](/images/manual/scm/sales-return-list.jpg)

## 列表

**查询条件**：单据号、订单号、客户、仓库、业务日期范围。

**列表列**：单据号（点击查看详情）、订单号、客户、仓库、业务日期、数量、价税合计、仓库单据、制单人、创建时间。

**工具栏**：「新增销售出库」或「新增销售退货」。

**行操作**：

- 「查看」：打开详情，可打印。
- 「发运」（仅销售出库，需物流发运新增权限）：跳转到 [物流发运](./shipment) 并以该出库单新建发运单。一张出库单只能创建一张发运单。

出库、退货单据不能修改和删除。

## 新增销售出库

表单提示：「从所选仓库的现有库存中选择库位、批次（序列号）。保存后立即生成仓库出库单并更新库存，同时生成应收单，单据不能修改，错误时请做退货冲回。」

| 字段 / 列 | 说明 |
| --- | --- |
| 销售订单 | 必填，只列出已审核、部分完成的订单，选择后带出有未出库数量的明细 |
| 仓库 | 必填，默认订单的发货仓库；更换仓库会清空已选的库位、序列号 |
| 业务日期 | 必填，默认今天；应收单日期和到期日从此计算 |
| 备注 | 选填 |
| 未完成数量 | 本行最多可出库的数量（订单数量 − 已出库 + 退货补发），下方显示订单单价 |
| 库位 / 批次 | 必填，从所选仓库该物料的现有库存中选择，显示可用数量 |
| 数量 | 必填，默认等于未完成数量，可改小分批出库；允许超发时可以大于未完成数量，见下文「超发」 |
| 序列号 | 序列号物料从所选库位的在库序列号中选择或扫码 |
| 操作 | 「拆分」：同一物料从多个库位 / 批次出库；删除本次不出库的行 |

## 新增销售退货

| 字段 / 列 | 说明 |
| --- | --- |
| 销售订单 | 只列出部分完成、已完成、已关闭（已有出库）的订单 |
| 仓库、业务日期、备注 | 退货入库的仓库和日期 |
| 退货后需要补发 | 勾选后订单恢复相应的未完成数量，可以继续出库；不勾选视为退款，订单不再补发 |
| 可退数量 | 已出库 − 已退货 |
| 库位、批次号 | 退回入库的库位、批次；批次管理的物料必填批次号 |
| 数量 | 必填，默认不填 |
| 序列号 | 退回的序列号 |

## 保存时发生了什么

**销售出库**：

1. 校验订单为已审核或部分完成；**校验客户信用额度**（应收余额 + 全部未完成订单金额超过额度时暂停出库；[业务参数](../system/biz-rule)「客户信用额度控制」设为「不控制」时不校验）。
2. 校验每行数量不超过未完成数量（设置了销售出库超发比例时不超过允许超发后的数量）。
3. 先核销本订单在该仓库的[库存预留](../wms/reservation)（出库不受自己预留的限制），再生成已确认的仓库「销售出库」单，扣减库存、批次、序列号；库存不足、序列号不在库时整张单据失败。
4. 回写已出库数量，重算订单状态；订单出库完成后释放剩余的预留。
5. 生成应收单：金额为价税合计，到期日 = 业务日期 + 客户账期。外币订单按订单汇率折算为人民币，保留原币金额。

**销售退货**：生成仓库「销售退货」入库单，回写已退货数量（补发时同时增加待补发数量），生成红字应收单。

## 超发

默认出库数量不能超过订单的未完成数量。按整件、整卷发货等经常略多于订单数量的业务，可以在「系统管理 → [业务参数](../system/biz-rule)」中设置「**销售出库超发比例（%）**」（0 ~ 100，默认 0 即不允许超发）：

- 每行累计出库数量最多为「订单数量 × (1 + 超发比例)」，再加上退货补发数量；超出时提示「…超出允许超收 / 超发后的数量…」；
- 超发部分按订单单价生成应收单；
- 销售退货不受超发比例影响，最多退「已出库 − 已退货」；
- 出库表单中已经全部出库的订单行不再列出，超发需要在该行最后一次出库时一并录入。发货通知的通知数量不能超过可通知数量，按发货通知出库时不会超发。

## 详情

详情显示单据号、订单号、客户、仓库、业务日期、仓库单据、退货方式（退货单：退货退款 / 退货补发）、价税合计和税额（外币另显示原币）、制单、备注，以及明细（物料、库位、批次和有效期、数量、含税单价、价税合计和税率、序列号）。右上角「打印」。

## 注意事项

::: warning 注意
出库、退货保存后不能修改或删除。出库多了请做销售退货冲回，退货录错了请重新出库。
:::

::: tip 提示
需要按拣货建议拣货、装箱的业务，建议走 [发货通知](./delivery) 流程，确认拣货后一键出库，避免手工选库位批次。
:::

## 常见问题

**提示超出信用额度、暂停出库？** 客户的应收余额与未完成订单合计已超过信用额度。请先[收款核销](../fin/settlement)应收，或在 [客户](./customer) 中调整信用额度。

**选不到库位 / 批次？** 所选仓库中该物料没有可用库存（冻结、已被其他订单预留的不可用），请检查[库存](../wms/stock)或更换仓库。
