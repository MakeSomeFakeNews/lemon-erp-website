# 商品分析

商品分析从五个角度看商品：**畅销**（卖得最好）、**滞销**（有货卖不动）、**积压**（库存够卖很久）、**缺货**（不够卖）、**周转**（库存周转快慢），帮助决定该多进什么、少进什么、哪些要促销清货。

## 页面入口

供应链 → 进销存报表 → 商品分析

需要「商品分析」菜单权限，内置角色中超级管理员、总经理、会计、普通用户、采购员、仓库管理员拥有，见[进销存报表概述](./jxc#权限)。

![商品分析 - 畅销](/images/manual/scm/jxc-goods.jpg)

## 查询条件

页面顶部的页签切换五种分析，下方的条件共用：

| 条件 | 说明 |
| --- | --- |
| 日期范围 | 默认本月，最长 366 天，用于统计期间销量。「缺货」与日期无关，不显示此条件 |
| 全部类别 / 全部品牌 | 物料分类、品牌；选择上级分类时包含其所有下级分类 |
| 全部仓库 | 选择后，销量和库存都只统计该仓库 |
| 商品编码 / 名称 | 模糊匹配 |
| 排序（仅畅销） | 「按销售额」（默认）、「按销量」、「按毛利」 |
| 销量不超过（仅滞销） | 默认 0 |
| 可销天数超过（仅积压） | 默认 90 天 |

修改日期或切换页签、排序后立即查询，其他条件修改后点「**查询**」。每个页签的表格上方有一行灰色说明，与下文口径一致。

共用的统计口径：

- **净销量 / 销售额**：期间内[销售出库](./sales-out)减销售退货的数量 / 不含税金额，按业务日期，口径同[销售报表](./jxc-sales)；销量、销售额、成本、毛利按你的数据权限统计。
- **库存**：当前库存数量，不含供应商寄售仓；不受数据权限限制。
- **库存金额**：库存 × 最新单位成本（物料的实时移动加权均价，见[实时库存成本](../wms/stock#实时库存成本)；没有时取最近一期成本核算的单价，再没有取参考成本价），同[资产状况](./jxc-assets)。
- 多规格物料只统计各个 SKU，不列出规格模板本身。

## 畅销

**期间净销量大于 0** 的商品，按所选依据从高到低排序。

列：商品、类别、品牌、净销量、销售额、成本、毛利、毛利率、库存（当前）。成本口径同销售报表：取出库时的实时库存成本（销售退货按原出库成本），没有实时成本的历史单据按所在月份的成本核算单价，再没有取参考成本价。

## 滞销

**当前有库存**，且**期间净销量不超过「销量不超过」设定值**的商品（默认 0，即期间没有卖出过），按库存金额从大到小排序，最占资金的排在前面。

列：商品、类别、品牌、库存、库存金额、净销量、销售额、最近销售。「最近销售」是截至结束日期最后一次销售出库的日期，从来没有销售过的显示「从未销售」。

## 积压

**当前有库存、期间有销售**，但库存按目前的销售速度要卖很久的商品：

- **可销天数** = 库存 ÷ 期间日均销量 = 库存 × 期间天数 ÷ 期间净销量；
- 可销天数**超过**「可销天数超过」设定值（默认 90 天）的列出，可销天数最长的排在前面。

列：商品、类别、品牌、库存、库存金额、净销量、可销天数。期间完全没有销售的商品不在积压中，请看「滞销」。

例如日期范围为 30 天，期间卖出 10 件，当前库存 50 件：日均销量 1/3 件，可销天数 = 50 × 30 ÷ 10 = 150 天，超过 90 天，列为积压。

## 缺货

当前**可用库存**不够的商品，与日期范围无关，满足以下任一条件即列出（只看启用的物料）：

- 设置了安全库存，且可用库存**低于安全库存**；
- 可用库存**不够未出库的销售订单**（待发）。

| 列 | 口径 |
| --- | --- |
| 可用库存 | 当前库存去掉不良品仓、客户寄售仓的库存和[冻结](../wms/hold)数量（供应商寄售仓本来就不计入） |
| 安全库存 | 物料档案上的安全库存 |
| 待发 | 已审核、部分完成的销售订单中还没有出库的数量（订单数量 − 已出库 + 退货待补发） |
| 缺口 | 安全库存 + 待发 − 可用库存，标红显示，缺口最大的排在前面 |
| 在途 | 已审核、部分完成的采购订单中还没有入库的数量，可用于判断是否已经在补货 |
| 库存 | 当前库存（含不良品等不可用部分） |

缺货列表按全部订单和库存计算，不受数据权限限制。需要补货时可以到[补货建议](./reorder)按再订货点生成请购单。

## 周转

![商品分析 - 周转](/images/manual/scm/jxc-goods-turnover.jpg)

按**数量**计算期间内的库存周转：

- **期初库存**：开始日期之前的库存数量；**期末库存**：截至结束日期的库存数量。都按库存流水所属单据的业务日期推算，不含供应商寄售仓；不选仓库时不计调拨（调拨不改变总库存）。
- **周转次数** = 期间净销量 ÷ 平均库存，平均库存 = （期初 + 期末）÷ 2。平均库存不大于 0 时显示「-」。
- **周转天数** = 期间天数 ÷ 周转次数，周转次数为 0 时显示「-」。

列：商品、类别、品牌、期初库存、期末库存、净销量、成本、周转次数、周转天数。**周转最慢的排在前面**：有库存但期间没有销售的最先列出，没有库存只有销售的排在最后。

例如 30 天内期初 100 件、期末 60 件、卖出 120 件：平均库存 80 件，周转次数 1.5，周转天数 20 天。

## 查看明细与导出

- 有「销售报表」权限时，商品名称显示为链接，点击打开该商品在当前日期范围（和所选仓库）内的销售明细，与[销售报表的商品明细](./jxc-sales#商品明细)相同，可以继续查看单据。商品分析本身按商品分行，一张单据中同一商品通常只有一行，单据列表与明细几乎相同，所以这里只提供商品明细，不提供单据穿透。
- 「**导出**」导出当前页签的查询结果（最多前 500 行），比表格多「编码」「规格」「单位」列。

::: tip 提示
- 积压、周转的结果与日期范围的长短关系很大：只看一个月时，季节性商品容易被误判为积压。建议用「近 12 个月」或与采购周期相当的期间来判断。
- 财务的[库龄分析](../fin/analysis#库龄分析)按入库时间分析库存存放了多久，可以与本页的滞销、积压结合使用。
:::
