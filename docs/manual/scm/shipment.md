# 物流发运

物流发运记录销售出库后的运输信息：承运商、运单号、收货人、运费及运费承担方，并跟踪物流动态直到客户签收。发运单由销售出库单生成，一张出库单只能创建一张发运单。指定了运费结算供应商时，发货后自动生成运费[应付单](../fin/ar-ap)；运费由客户承担时还生成客户的代垫运费应收单，见[运费承担](#运费承担)。

## 页面入口

供应链 → 销售 → 物流发运

也可以在 [销售出库](./sales-out) 列表点某张出库单的「发运」直接新建。

![物流发运列表](/images/manual/scm/shipment-list.jpg)

## 列表

**查询条件**：单号（发运单号、运单号或出库单号）、客户、状态、承运商（点「展开」显示）。

**列表列**：

| 列 | 说明 |
| --- | --- |
| 发运单号 | 点击打开详情 |
| 状态 | 待发运 / 运输中 / 已签收 / 异常 |
| 出库单 / 订单 | 销售出库单号，下方为销售订单号 |
| 客户 | |
| 承运商 / 运单号 | 未填写运单号时显示「未填运单号」 |
| 收货信息 | 收货人、电话，下方为地址 |
| 运费 | 客户承担的运费下方显示「客户承担」 |
| 发货 / 签收 | 发货日期和签收日期 |
| 创建时间 | |

**工具栏**：「新增发运单」，右侧有导出等。

**行操作**（行末操作栏中的图标，鼠标悬停显示名称；只有一个操作时显示为图标加文字）：「查看」；未签收的可「编辑」；待发运的可「删除」。

## 新增 / 编辑发运单

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 销售出库单 | 是 | 搜索出库单号；选择后自动带出客户的联系人、电话、收货地址 |
| 承运商 | 是 | 顺丰速运、京东物流、中通快递、德邦物流、自提 / 自送等，可在[业务字典](../system/biz-dict)中维护 |
| 运单号 | 否 | 发货时必填 |
| 收货人、收货电话、收货地址 | 否 | 默认取客户资料，可修改 |
| 运费 | 否 | |
| 运费承担 | 是 | 「本公司承担」（默认）或「客户承担（代垫）」，见下文[运费承担](#运费承担) |
| 运费结算供应商 | 客户承担且运费大于 0 时必填 | 选择物流公司对应的供应商后，发货时按运费生成该供应商的应付单（提示「发货时按运费生成该供应商的应付单（本公司承担计入销售费用，客户承担计入代垫运费）」）；本公司承担时可以不选，不选则不生成应付 |
| 备注 | 否 | |

已签收的发运单不能修改；已生成运费应付单或代垫运费应收单后，不能再修改运费、运费承担和运费结算供应商。

## 运费承担

「运费承担」决定发运运费由谁负担、怎样记账：

| 运费承担 | 表单提示 | 发货时生成的单据 | 凭证 |
| --- | --- | --- | --- |
| 本公司承担（默认） | 本公司承担：运费计入销售费用；选择运费结算供应商时生成其应付单，不选时请另行登记费用支出 | 选了运费结算供应商时，生成该供应商的运费应付单 | 借 销售运费 / 贷 应付账款 |
| 客户承担（代垫） | 客户承担（代垫）：须选择运费结算供应商，发货时生成承运商应付和客户的代垫运费应收，两者在代垫运费科目对冲；不计入销售收入，不影响毛利 | 运费大于 0 时必须选择运费结算供应商（承运商）：生成承运商的应付单，同时生成本单客户的代垫运费应收单（不含税） | 应付：借 代垫运费 / 贷 应付账款；应收：借 应收账款 / 贷 代垫运费，两边相抵 |

- 本公司承担的运费计入销售费用，在[毛利分析](../fin/analysis#销售毛利)、[销售报表](./jxc-sales)中作为「本公司运费」参与「扣坏账、运费后毛利」的参考口径；
- 客户承担的运费是替客户垫付、再向客户收回的款项，不是销售收入，毛利不受影响；代垫运费应收单与客户的其他[应收单](../fin/ar-ap)一样收款核销；
- 「销售运费」「代垫运费」用的科目在「财务 → [凭证科目设置](../fin/account-rule)」中设置，默认分别为销售费用、其他应收款。

![发运单表单的运费承担](/images/manual/scm/shipment-freight-bearer.jpg)

## 详情与物流跟踪

![发运单详情](/images/manual/scm/shipment-detail.jpg)

详情显示出库单、订单号、客户、承运商、运单号、运费（及结算供应商、是否已生成应付单；下方显示运费承担标签和说明，客户承担且已发货时显示「已生成代垫运费应收」）、收货人、发货 / 签收日期、收货地址，以及「物流动态」时间线（每次操作自动记录，如「创建发运单，出库单 …」「已发货，运单号 …」）。

有物流跟踪权限时，未签收的发运单底部有操作按钮：

| 按钮 | 显示条件 | 填写内容 | 结果 |
| --- | --- | --- | --- |
| 发货 | 待发运、异常 | 运单号（必填）、发货日期、备注（默认「已发货，运单号 …」） | 变为运输中；指定了运费结算供应商时生成运费应付单，客户承担运费时生成代垫运费应收单（只在首次发货时生成） |
| 添加物流动态 | 运输中、异常 | 物流动态（必填），如「已到达北京转运中心」 | 记录一条动态 |
| 标记异常 | 运输中 | 异常说明（必填），如「包裹破损、地址错误」 | 变为异常 |
| 签收 | 运输中、异常 | 签收日期、备注（默认「客户已签收」） | 变为已签收 |

## 单据状态

| 状态 | 说明 |
| --- | --- |
| 待发运 | 已创建，可编辑、删除、发货 |
| 运输中 | 已发货，可添加动态、标记异常、签收 |
| 异常 | 运输异常，可添加动态、重新发货（处理后继续运输）或直接签收 |
| 已签收 | 客户已签收，不能再修改 |

## 注意事项

::: tip 提示
有异常的发运单会计入[首页待办](../guide/home#待办事项)「发运异常」，提醒及时处理。只有发运权限的用户也能查看销售出库单，以便选择出库单创建发运。
:::
