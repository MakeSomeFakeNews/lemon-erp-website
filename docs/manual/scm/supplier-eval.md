# 供应商评估

供应商评估分两部分：**供应商绩效** 按业务数据自动统计每个供应商的订单数、入库金额、准时交货率、来料合格率、退货率和[质量索赔](../qms/claim)；**评估记录** 是采购、质量人员按期间（如季度）对供应商打分，系统加权算出综合得分和等级，并自动更新供应商档案的等级。

## 页面入口

供应链 → 往来单位 → 供应商评估

![供应商绩效](/images/manual/scm/supplier-eval.jpg)

右上角「新增评估」可随时发起评估。

## 供应商绩效

**筛选**：供应商编码或名称、开始日期 ~ 结束日期。说明：按入库业务日期统计；准时 = 入库日期不晚于订单明细交货日期。

| 列 | 说明 |
| --- | --- |
| 供应商 | 名称和编码 |
| 等级 | 当前等级 |
| 订单数 | 期间内的采购订单数 |
| 入库金额 | 期间内的采购入库金额 |
| 准时交货率 | 进度条和「准时行数 / 入库行数」，没有入库显示「无入库」 |
| 来料合格率 | [来料检验](../qms/inspection)合格批次比例（合格批次 / 检验批次）；有质量索赔时下方红字显示「质量索赔 N 次 ¥金额」 |
| 退货率 | 退货数量 ÷ 入库数量，下方显示「退 X / 入 Y」 |
| 最近评估 | 最近一次评估的得分和时间，没有显示「未评估」 |
| 操作 | 「评估」：以该供应商发起评估，并按绩效给出建议分 |

## 评估记录

![评估记录](/images/manual/scm/supplier-eval-records.jpg)

**筛选**：供应商、考核期间。

**列表列**：供应商、考核期间、各项得分（质量 · 交期 · 价格 · 服务）、综合得分、等级、评语、评估人、评估时间、操作「删除」。

## 新增评估

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 供应商 | 是 | |
| 考核期间 | 是 | 默认当前季度，如「2026-Q3」 |
| 质量（权重 40%） | 是 | 0 ~ 100 分 |
| 交期（权重 30%） | 是 | 0 ~ 100 分 |
| 价格（权重 20%） | 是 | 0 ~ 100 分 |
| 服务（权重 10%） | 是 | 0 ~ 100 分 |
| 评语 | 否 | |

对话框实时显示「综合得分 X，评定等级 Y」。

**从绩效点「评估」时的建议分**：

- 交期得分 = 准时交货率。
- 质量得分 = 来料合格率；没有来料检验记录时按退货率折算（100 − 退货率 × 5）；每次质量索赔再扣 5 分。
- 价格、服务需要手工打分。建议分都可以修改。

## 等级规则

综合得分 = 质量 × 40% + 交期 × 30% + 价格 × 20% + 服务 × 10%。

| 综合得分 | 等级 |
| --- | --- |
| ≥ 90 | A 优秀 |
| ≥ 75 | B 良好 |
| ≥ 60 | C 合格 |
| < 60 | D 待改进 |

保存评估后，供应商档案的等级更新为本次评定等级。删除评估记录后，按剩余的最近一次评估（期间最新）重新确定等级，没有评估时清空。

## 注意事项

::: tip 提示
等级为 D 的供应商在新增采购订单时会显示「该供应商评估等级为 D（待改进），请谨慎下单或更换供应商」的提醒。询价比价的比价表中也会显示各供应商的等级。
:::
