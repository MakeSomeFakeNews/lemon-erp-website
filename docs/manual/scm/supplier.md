# 供应商

供应商档案记录供应商的基本信息、账期和银行信息，并维护每个供应商可供应的物料和 **供货价格**。采购订单、请购、[MRP](../mes/mrp)、补货建议、采购入库[直接开单](./purchase-in#直接开单)都按供货价格带出单价、确定默认供应商。供应商的门户账号也在这里开通。

## 页面入口

供应链 → 往来单位 → 供应商

![供应商列表](/images/manual/scm/supplier-list.jpg)

## 列表

**查询条件**：供应商（编码、名称、联系人、电话，也可输入拼音首字母，规则同[搜索选择资料](../guide/common#搜索选择资料)）、等级、类型（物流公司 / 其他供应商）、状态。

**列表列**：供应商（名称，下方为编码；物流公司在名称旁显示「物流公司」标签；营运路线显示在编码后面，过长时省略，鼠标悬停看全文）、等级（A 优秀 / B 良好 / C 合格 / D 待改进）、联系人（下方为电话）、账期（为 0 显示「现结」）、地址、状态（启用 / 停用开关，有编辑权限时可直接切换）、备注，以及在「系统管理 → [自定义字段](../system/custom-field)」中为供应商定义并勾选了「列表显示」的扩展字段。

**工具栏**：「新增供应商」「导入」；右侧导出、刷新等。

::: tip AI 识别与数据整理
管理员开启 AI 功能后，工具栏中还有「AI 识别」：上传名片、营业执照或开票信息，由 [智能录入](../ai/extract) 识别后打开新增表单并填好，核对后保存。资料多了出现重复或写法不统一时，可以用 [数据整理](../ai/cleanse) 让 AI 找出疑似重复的供应商、统一名称、联系人、地址的写法。
:::

**行操作**：行末操作栏中「编辑」「供货价格」「删除」显示为图标（鼠标悬停显示名称），「资料」「门户账号」在最后的「更多」（三个点图标）中；没有门户账号权限时「资料」直接显示为图标。

| 操作 | 作用 |
| --- | --- |
| 编辑 | 修改供应商资料 |
| 供货价格 | 维护该供应商的供货价格，见下文 |
| 删除 | 确认后删除；已有采购订单等业务数据的供应商不能删除，提示改为停用 |
| 更多 → 资料 | 打开「附件 / 变更记录」：上传资质证书、合同等附件，查看档案的字段修改记录 |
| 更多 → 门户账号 | 开通、停用供应商门户账号，见 [开通门户账号](../portal/account) |

## 新增 / 编辑供应商

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 供应商编码 | 是 | 如 S001，只能包含字母、数字、下划线和短横线，最多 32 位，不能重复 |
| 供应商名称 | 是 | |
| 等级 | 否 | 供应商评估后自动更新为评定等级 |
| 账期 | 否 | 默认 30 天，0 ~ 365 天。[应付单](../fin/ar-ap)到期日 = 入库日期 + 账期 |
| 联系人、联系电话、邮箱 | 否 | 邮箱须为有效格式 |
| 纳税人识别号、开户行、银行账号 | 否 | |
| 类型 | 否 | 勾选「物流公司（承运商）」，提示「勾选后可在出入库单的运费（采购入库、采购退货、销售出库）和发运单中被选为承运商；应付、付款与其他供应商相同」，见下文[物流公司](#物流公司) |
| 营运路线 | 否 | 勾选物流公司后显示，多行文本框，最多 1000 个字符，可写完整的途经站点，如「青岛北—青岛西—诸城—青州—潍坊—淄博—济南」 |
| 地址、备注 | 否 | |

管理员在「系统管理 → [自定义字段](../system/custom-field)」中为「供应商」定义了扩展字段（如资质到期日、主营品类）时，表单末尾出现「扩展信息」分区，必填的扩展字段不填不能保存。

停用的供应商不能再下采购订单、签合同、邀请投标。

## 物流公司

物流公司（承运商）也建在供应商资料中，勾选「物流公司（承运商）」即可，不需要另建一种往来单位：

- [采购入库](./purchase-in#采购运费)「本公司承担」运费的承运商、[销售出库](./sales-out#销售出库的运费)和[采购退货](./purchase-in#采购退货的运费)运费的承运商、[物流发运](./shipment)的运费结算供应商，下拉只列出物流公司；还没有标记任何物流公司时列出全部供应商，并在下拉顶部提示去供应商资料中勾选；
- 物流公司的运费应付单、付款核销、对账、往来汇总、账龄与其他供应商相同；
- 既供货又帮忙送货的供应商也可以勾选，两种用途都能选到它；
- 从旧版本升级时，已经被用作承运商（采购入库的承运商、发运单的运费结算供应商）的供应商会自动标记为物流公司。

## 导入

点「[导入](../guide/common#导入-excel)」，「下载导入模板」后按模板填写：供应商编码*、供应商名称*、等级、联系人、联系电话、邮箱、地址、纳税人识别号、开户行、银行账号、账期(天)、备注。任何一行有错误时整批不导入，对话框按行号列出错误。

## 供货价格

点行末操作栏中的「供货价格」图标，打开「供货价格 - 供应商名称」页面：

![供货价格](/images/manual/scm/supplier-price.jpg)

列表显示：物料（默认供应商带「默认」标签）、含税单价（「¥单价 / 单位」，下方为税率，有阶梯价时显示「阶梯价」标签）、有效期（「起 ~ 止」或「长期有效」，已过期 / 未生效有标签）、提前期（天）、最小起订量、备注。可按物料编码或名称搜索，右上角「添加物料」。

每行的操作图标：「编辑」「删除」「价格历史」。

**添加 / 编辑供货价格**：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 物料 | 是 | 编辑时不能修改物料 |
| 含税单价 | 是 | 基本单位的单价 |
| 税率 | 否 | 新增时默认为业务参数「[默认税率](../system/biz-rule#默认税率)」（默认 13%），为空时按默认税率保存 |
| 采购提前期 | 否 | 0 ~ 365 天，MRP 用于倒推下单日期 |
| 最小起订量 | 否 | 采购订单低于此数量时提示；补货建议按此取整 |
| 有效期起、有效期止 | 否 | 为空表示不限；过期的价格不再带出，MRP 和请购不使用 |
| 阶梯价 | 否 | 点「添加阶梯」，每档填写「数量 ≥」和含税单价，最多 10 档，数量不能重复。采购数量达到阶梯数量时按阶梯单价 |
| 设为该物料的默认供应商 | 否 | MRP 按默认供应商生成采购订单；请购单、补货建议未指定供应商时也用默认供应商。同一物料只有一个默认供应商，设置后其他供应商自动取消默认 |
| 备注 | 否 | |

**价格历史**：按采购入库的成交价列出：入库日期、入库单号、供应商、数量、含税单价、税率；可切换「本供应商」或「全部供应商」，便于比价。单价为整单优惠前的单价（订单的整单优惠只在合计处扣减，不改变单价）。

[询价比价](./inquiry) 定标时也可以用中标价自动更新供货价格。

## 注意事项

::: tip 提示
评估等级为 D 的供应商在新增采购订单时会显示提醒。等级由 [供应商评估](./supplier-eval) 自动维护，也可以手工修改。
:::
