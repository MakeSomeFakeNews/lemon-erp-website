# 销售返利

销售返利是与客户（尤其是经销商）约定的阶梯返利协议：在一个期间内，客户的销售额达到某一档，就按该档返利率返还。期间结束后结算，返利可以「红字应收」直接冲减客户欠款，也可以「下次订单抵扣」计入客户的返利余额，在新的销售订单中抵扣。

## 页面入口

供应链 → 销售 → 销售返利

![销售返利列表](/images/manual/scm/rebate-list.jpg)

## 列表

**筛选**：关键字（协议号、客户）、状态（执行中 / 已结算）。

**列表列**：协议（协议号，下方为客户）、期间、兑付方式、返利（已结算时显示返利金额和「销售额 × 返利率」）、状态（已结算且为红字应收方式时，下方显示红字应收单号）、操作「查看」。

工具栏有「新增返利协议」。

## 新增 / 编辑返利协议

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 客户 | 是 | 不能选停用的客户 |
| 开始日期、结束日期 | 是 | 返利期间 |
| 兑付方式 | 是 | **红字应收**：结算后生成红字[应收单](../fin/ar-ap)冲减客户应收（借 主营业务收入、销项税额 / 贷 应收账款）；**下次订单抵扣**：结算后计入客户的返利余额，新建销售订单时抵扣 |
| 返利阶梯 | 是 | 每档填写「销售额达到」和「返利率」（0.01% ~ 100%），点「添加一档」增加，至少保留一档 |
| 说明 | 否 | |

表单中的说明：期间销售额（出库 − 退货，含税）达到的最高一档返利率 × 全部销售额。

**计算示例**：阶梯为「≥ 20,000 返 2%、≥ 50,000 返 3%」，期间销售额 29,996 元，达到第一档，返利 = 29,996 × 2% = 599.92 元。注意是按达到的档位乘以 **全部** 销售额，而不是分段累进。

只有执行中的协议可以编辑、删除。

## 协议详情

![返利协议详情](/images/manual/scm/rebate-detail.jpg)

详情显示客户、期间、状态、兑付方式、创建人和说明：

- **执行中**：按截至今天的数据显示「预估返利」（期间结束后为「应返利」）和「下一档」（如「再销售 ¥20,004.00 达到 3%」或「已达到最高一档」）。
- **已结算**：显示结算日期、返利金额（销售额 × 返利率）、红字应收单号。

「返利阶梯」表中，当前达到的一档标记「当前」。

**按钮**：

| 按钮 | 显示条件 | 作用 |
| --- | --- | --- |
| 删除、编辑 | 执行中 | |
| 结算 | 执行中；期间结束后才可点击（之前提示「期间结束后才能结算」） | 确认「按期间销售额 ¥… 结算返利 ¥…，确定？」 |
| 撤销结算 | 已结算 | 确认「撤销结算：删除红字应收单（须未核销、未生成凭证）或收回未使用的返利余额，确定？」 |

## 结算规则

- 期间销售额 = 该客户在期间内的销售出库金额 − 销售退货金额（含税、人民币）。
- 销售额没有达到任何一档时不能结算，提示「期间销售额 … 没有达到返利阶梯」。
- **红字应收**：由财务模块生成来源为「销售返利」的红字应收单，可生成凭证。
- **下次订单抵扣**：返利金额计入客户的返利余额。

撤销结算的条件：红字应收单还没有核销、没有生成凭证；或下次订单抵扣的返利余额还没有被使用（余额足够收回）。

## 在销售订单中抵扣返利

客户有返利余额时，[销售订单](./sales) 表单中显示「返利抵扣」字段，提示「可用返利余额 ¥…，按行金额分摊到单价」：

- 抵扣金额不能超过可用返利余额，也不能超过订单金额。
- 抵扣金额按非赠品行的金额比例分摊到各行单价，订单记录「返利抵扣」金额。
- 可用余额 = 已结算的「下次订单抵扣」返利 − 销售订单已抵扣的金额。

经销商在 [经销商门户](../portal/dealer) 订货时，也可以填写「使用返利」。

## 注意事项

::: tip 提示
返利期间与销售出库的业务日期对应，期间结束前可以随时查看预估返利，便于销售人员引导客户冲量。
:::
