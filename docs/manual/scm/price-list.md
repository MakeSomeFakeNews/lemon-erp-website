# 销售价目表

销售价目表是公司的标准销售价格，按「物料 × 适用客户（指定客户的专属价，或客户等级）× 起订数量 × 有效期」定价。销售报价、销售订单、[经销商门户订货](../portal/dealer#我要订货)、外部订单导入、[寄售结算](./consign)都从这里自动取价，销售人员只需关注折扣，不必记价格。页面上的「价格控制」还可以为物料设置最低销售价、最高采购价，防止低价销售、高价采购。

## 页面入口

供应链 → 销售 → 销售价目表

![销售价目表](/images/manual/scm/price-list.jpg)

## 取价规则

页面顶部提示：「销售订单、报价单选择物料后按客户、数量、日期匹配价目：客户专属价优先，其次指定等级，再其次全部客户，起订数量取满足条件的最高档。」具体为：

1. 只看在单据日期有效（有效期起 ≤ 日期 ≤ 有效期止，为空表示不限）、起订数量不超过本行数量，并且适用于该客户的价目：专属于该客户的、客户等级为该客户等级的、或适用「全部客户」的。其他客户的专属价不会被取到。
2. 优先级：该客户的专属价 → 该客户等级的价目 → 全部客户的价目。
3. 同一优先级中取起订数量最高的一档。例如全部客户起订 0 为 ¥6,800、起订 10 为 ¥6,500，买 12 台时取 ¥6,500。
4. 同时带出该价目的税率。

外币销售订单按订单汇率把人民币价目价折算为外币。

## 列表

**查询条件**：物料（编码或名称）、客户等级（只筛选按该等级定价的价目）。

**列表列**：

| 列 | 说明 |
| --- | --- |
| 物料 | 编码、名称，下方为规格 |
| 适用客户 | 客户专属价显示紫色「专属」标签和客户名称；按等级定价的显示客户等级；都为空显示「全部客户」 |
| 起订数量 | 为 0 显示「不限」，否则显示如「≥ 10」 |
| 含税单价 | 「¥单价 / 单位」，下方为税率 |
| 税率(%) | |
| 有效期 | 「起 ~ 止」或「长期有效」；已过期显示红色「已过期」，未到起始日显示橙色「未生效」 |
| 备注 | |

**工具栏**：「新增价目」、「价格控制」（见下文）、「批量删除」，右侧有导出等。新增、编辑、删除价目需要价目表修改权限。

**行操作**：「编辑」「删除」。

## 新增 / 编辑价目

点「新增价目」打开对话框：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 物料 | 是 | |
| 客户专属 | 否 | 选择客户后，该价目只适用这个客户，优先于客户等级的价目（表单提示「指定客户时只适用该客户，优先于客户等级」）；为空表示不指定 |
| 客户等级 | 否 | 重点客户 / 普通客户 / 潜在客户，为空适用全部客户。选择了客户专属时不可选 |
| 起订数量 | 否 | 为空表示不限（按 0 保存） |
| 含税单价 | 是 | 基本单位的单价 |
| 税率 | 否 | 默认 13% |
| 有效期起、有效期止 | 否 | 为空表示不限；有效期止不能早于有效期起 |
| 备注 | 否 | |

## 用法示例

| 物料 | 客户等级 | 起订数量 | 单价 | 说明 |
| --- | --- | --- | --- | --- |
| 工控主机 | 全部客户 | 不限 | 6,800 | 标准价 |
| 工控主机 | 全部客户 | ≥ 10 | 6,500 | 批量价 |
| 工控主机 | 重点客户 | 不限 | 6,300 | 重点客户专享价 |

| 工控主机 | 专属：深圳智造 | 不限 | 6,200 | 大客户协议价 |

客户「深圳智造」下单时取 6,200（专属价优先）；其他重点客户取 6,300（指定等级优先）；普通客户买 10 台以上取 6,500。

## 价格控制

点工具栏的「**价格控制**」，打开「价格控制」抽屉，为物料设置售价下限和采购价上限：

![价格控制](/images/manual/scm/price-control.jpg)

抽屉顶部提示：「手工录入的销售订单单价（含税、基本单位、折算本位币，促销按原价）不能低于最低销售价，采购订单单价不能高于最高采购价；「提示」只在订单页面提示，「禁止保存」不能保存订单。」

**列表**：物料、最低销售价、最高采购价（未设置显示「-」）、控制方式、备注、操作（「编辑」「删除」）。可按物料编码或名称搜索。

点「新增」打开对话框：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 物料 | 是 | 每个物料只能设置一条，编辑时不能更换物料 |
| 最低销售价（含税） | 二选一 | 按基本单位、人民币；为空表示不控制销售价 |
| 最高采购价（含税） | 二选一 | 按基本单位、人民币；为空表示不控制采购价。两个价格至少填写一个，否则提示「请至少填写最低销售价或最高采购价」 |
| 控制方式 | 是 | 「提示」（默认）：订单单价下方显示红字提示，仍可保存；「禁止保存」：保存订单时校验，超出时不能保存 |
| 备注 | 否 | |

新增、编辑、删除需要价目表修改权限。

控制的范围：

- [销售订单](./sales#价格控制)明细的单价（有促销时按促销前的原价，赠品不校验）低于最低销售价、[采购订单](./purchase#价格控制)明细的单价高于最高采购价时提示或禁止保存；外币订单按订单汇率折算为人民币、辅助单位按换算率折算为基本单位后比较；
- 只在手工新增、编辑订单时校验；报价转单、门户订货、外部导入、请购单 / MRP / 询价 / 招标生成的订单在生成时不校验；
- 销售报价、订单变更不校验。

## 注意事项

::: tip 提示
价目表只决定「原价」。限时折扣、满减、买赠请使用 [促销活动](./promotion)，按销售额返利请使用 [销售返利](./rebate)。经销商门户只能订购价目表中当天有效、适用其客户等级的物料，下单时按上面的取价规则（含专属价）计价。
:::
