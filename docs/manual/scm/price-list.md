# 销售价目表

销售价目表是公司的标准销售价格，按「物料 × 适用客户（指定客户的专属价，或客户等级）× 起订数量 × 有效期」定价。销售报价、销售订单、[经销商门户订货](../portal/dealer#我要订货)都从这里自动取价，销售人员只需关注折扣，不必记价格。销售报价、销售订单、出入库直接开单，以及外部订单导入、[寄售结算](./consign)不填单价时，还会结合客户执行价、[商品价格](./goods-price)（零售价、批发价）和历史成交价带出默认单价，见下文「[开单默认价](#开单默认价)」；录入单价时可以打开「[价格参考](#价格参考)」查看历史价格。页面上的「价格控制」还可以为物料设置最低销售价、最高采购价，防止低价销售、高价采购。

## 页面入口

供应链 → 销售 → 销售价目表

![销售价目表](/images/manual/scm/price-list.jpg)

## 取价规则

页面顶部提示：「销售订单、报价单选择物料后按客户、数量、日期匹配价目：客户专属价优先，其次指定等级，再其次全部客户，起订数量取满足条件的最高档。」具体为：

1. 只看在单据日期有效（有效期起 ≤ 日期 ≤ 有效期止，为空表示不限）、起订数量不超过本行数量，并且适用于该客户的价目：专属于该客户的、客户等级为该客户等级的、或适用「全部客户」的。其他客户的专属价不会被取到。
2. 优先级：该客户的专属价 → 该客户等级的价目 → 全部客户的价目。
3. 同一优先级中取起订数量最高的一档。例如全部客户起订 0 为 ¥6,800、起订 10 为 ¥6,500，买 12 台时取 ¥6,500。
4. 同时带出该价目的税率。

外币销售订单按订单汇率把人民币价目价折算为外币。

## 开单默认价

选择往来单位和物料后，系统按下面的顺序找到第一个有价格的来源作为默认单价（都是含税、基本单位、人民币；按辅助单位、外币录入时自动折算），并在单价下方以灰字显示来源，如「价目表」「等级价」。手工改过的单价不再被自动覆盖；更换往来单位、修改日期或数量后，没有手工改过的单价会重新取价。

取价**按行**进行：同一物料录了多行、数量不同时，每行按本行的数量分别匹配价目表的起订数量、供货价格的阶梯价。例如价目表中起订 0 为 ¥6,800、起订 10 为 ¥6,500，同一张单上一行 12 台、一行 2 台，分别带出 ¥6,500 和 ¥6,800。

**销售**（[销售订单](./sales)、[销售报价](./quotation)、[销售出库](./sales-out)和销售退货的直接开单）：

| 顺序 | 来源（单价下方显示） | 说明 |
| --- | --- | --- |
| 1 | 客户执行价 | 在[客户](./customer#价格等级与执行价)列表的「执行价」中为该客户维护的物料价格；填写了税率时同时带出税率 |
| 2 | 价目表 | 本页的价目，按上文「取价规则」匹配（专属价 → 客户等级 → 全部客户，有效期、起订数量），同时带出税率 |
| 3 | 等级价 | 客户的「价格等级」为某一档批发价、且该价格列启用并填写了价格时，取物料在[商品价格](./goods-price)中的这一列 |
| 4 | 零售价 | 零售价列启用并填写了价格时取零售价（价格等级为零售价的客户直接到这一步） |
| 5 | 最近价 | 该客户这个物料最近一次销售出库的单价（见下文「价格记忆」） |

**采购**（[采购入库](./purchase-in)和采购退货的直接开单）：

| 顺序 | 来源 | 说明 |
| --- | --- | --- |
| 1 | 合同价 | 该供应商在单据日期生效的[采购合同](./contract)中的价格，同时带出税率 |
| 2 | 供货价 | 供应商的[供货价格](./supplier#供货价格)，有阶梯价时按数量取档，同时带出税率 |
| 3 | 最近价 | 该供应商这个物料最近一次采购入库的单价 |
| 4 | 参考成本 | 物料的参考成本价 |

都没有时单价为空，需要手工填写。等级价、零售价、最近价、参考成本不带税率，沿用行上已有的税率（默认 13%）。

::: tip 提示
- 销售订单的单价下方仍会显示「上次 ¥…（日期）」，即该客户最近一次销售订单的成交价，点击即可使用；上表都没有价格时也会自动带出它。采购订单的取价不变：合同价 → 供货价格 → 上次成交价，见[采购订单](./purchase#单价从哪里来)。
- [外部订单导入](./sales#导入外部订单)、[客户寄售结算](./consign#客户寄售结算)不填单价时同样按上面的销售取价顺序（以下单日期 / 业务日期和本行数量匹配）。
- 经销商门户订货仍只按价目表取价，不使用客户执行价和价格等级。
- 「价目价」和折扣比例只在默认价来自价目表时显示。
:::

## 价格记忆

销售出库、采购入库保存后，系统按「往来单位 × 物料」记录成交价（含税、基本单位、人民币）：最新日期和最新价格（业务日期不早于已记录的最新日期时才更新）、最低价格及日期、最高价格及日期。直接开单、按订单出入库、发货通知出库等生成的出入库单都会记录；退货和单价为 0 的赠品行不记录。系统升级到包含此功能的版本时，会根据已有的出入库单补登记。

价格记忆用于开单默认价中的「最近价」，以及价格参考中的「客户对比」「供商对比」。

## 价格参考

在销售订单、采购订单、销售报价的明细中，以及出入库单直接开单的明细中，选择物料后单价下方有「**价格参考**」链接，点击打开「价格参考 - 物料」窗口，查看这个物料过去的报价、成交价：

![价格参考](/images/manual/scm/price-reference.jpg)

**筛选**：往来单位编号 / 名称、日期范围；单据已选择往来单位时有「只看当前单位」（默认勾选），只看与该客户（或供应商）相关的记录，另一方向的标签页不受影响。修改条件后点「搜索」。

**标签页**（标签上的数字为记录条数；销售单据先显示销售方面的标签页，采购单据先显示采购方面的）：

| 标签页 | 内容 |
| --- | --- |
| 销售历史 | 销售出库明细：日期、单号、客户编号、客户名称、数量、单价、金额、备注 |
| 报价历史 | 销售报价明细，列同上 |
| 客户对比 | 各客户购买该物料的价格记忆：最新日期、最新价格、最低日期、最低价格、最高日期、最高价格 |
| 进货历史 | 采购入库明细，列同销售历史（供应商编号、名称） |
| 进货数量 | 按供应商汇总：次数、数量、金额、均价、最新日期 |
| 供商对比 | 各供应商供应该物料的价格记忆，列同客户对比 |

窗口底部说明：「价格为含税单价（基本单位、人民币）；每个分区最多显示 200 条」。

在销售订单、采购订单、销售报价，以及出入库单直接开单（采购入库、销售出库及其退货）中打开时，表格中的价格可以点击（提示「使用此价格」），点击后窗口关闭，该价格填入当前行的单价（订单按当前行的单位、币种折算）。采购订单引用合同且物料在合同中时，单价锁定为合同价，不会被替换。选用的价格与手工修改的单价一样，不会再被自动取价覆盖。

**权限**：

- 报价历史、销售历史、客户对比需要销售订单、销售出库、销售报价中任意一个的查看权限；进货历史、进货数量、供商对比需要采购订单、采购入库中任意一个的查看权限；都没有时显示「没有可查看的价格信息」，没有相应权限的标签页不显示；
- 报价、销售、进货历史和进货数量按单据的「制单人部门 + 制单人」受[数据权限](../system/role#数据权限页签)限制，例如只能看本人数据的销售员只能看到自己开的单据；
- 客户对比、供商对比：数据权限为「全部数据」时取价格记忆；否则只按你有权查看的销售出库 / 采购入库单计算（统计口径同价格记忆），只列出这些单据的往来单位，价格也只来自这些单据，不会看到别人的成交价。这两个标签页下方都有说明「没有「全部数据」权限时，客户 / 供商对比只统计您有权查看的出入库单（只列出这些单据的往来单位），与报价、销售、进货历史的数据权限一致」。

## 列表

**查询条件**：物料（编码或名称）、客户等级（只筛选按该等级定价的价目）。

**列表列**：

| 列 | 说明 |
| --- | --- |
| 物料 | 编码、名称，下方为规格 |
| 适用客户 | 客户专属价显示紫色「专属」标签和客户名称；按等级定价的显示客户等级；都为空显示「全部客户」 |
| 起订数量 | 为 0 显示「不限」，否则显示如「≥ 10」 |
| 含税单价 | 「¥单价 / 单位」，下方为税率 |
| 税率(%) | |
| 有效期 | 「起 ~ 止」或「长期有效」；已过期显示红色「已过期」，未到起始日显示橙色「未生效」 |
| 备注 | |

**工具栏**：「新增价目」、「价格控制」（见下文）、「批量删除」，右侧有导出等。新增、编辑、删除价目需要价目表修改权限。

**行操作**：「编辑」「删除」。

## 新增 / 编辑价目

点「新增价目」打开对话框：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 物料 | 是 | |
| 客户专属 | 否 | 选择客户后，该价目只适用这个客户，优先于客户等级的价目（表单提示「指定客户时只适用该客户，优先于客户等级」）；为空表示不指定 |
| 客户等级 | 否 | 重点客户 / 普通客户 / 潜在客户，为空适用全部客户。选择了客户专属时不可选 |
| 起订数量 | 否 | 为空表示不限（按 0 保存） |
| 含税单价 | 是 | 基本单位的单价 |
| 税率 | 否 | 默认 13% |
| 有效期起、有效期止 | 否 | 为空表示不限；有效期止不能早于有效期起 |
| 备注 | 否 | |

## 用法示例

| 物料 | 客户等级 | 起订数量 | 单价 | 说明 |
| --- | --- | --- | --- | --- |
| 工控主机 | 全部客户 | 不限 | 6,800 | 标准价 |
| 工控主机 | 全部客户 | ≥ 10 | 6,500 | 批量价 |
| 工控主机 | 重点客户 | 不限 | 6,300 | 重点客户专享价 |

| 工控主机 | 专属：深圳智造 | 不限 | 6,200 | 大客户协议价 |

客户「深圳智造」下单时取 6,200（专属价优先）；其他重点客户取 6,300（指定等级优先）；普通客户买 10 台以上取 6,500。

## 价格控制

点工具栏的「**价格控制**」，打开「价格控制」抽屉，为物料设置售价下限和采购价上限：

![价格控制](/images/manual/scm/price-control.jpg)

抽屉顶部提示：「手工录入的销售订单单价（含税、基本单位、折算本位币，促销按原价）不能低于最低销售价，采购订单单价不能高于最高采购价；「提示」只在订单页面提示，「禁止保存」不能保存订单。」

**列表**：物料、最低销售价、最高采购价（未设置显示「-」）、控制方式、备注、操作（「编辑」「删除」）。可按物料编码或名称搜索。

点「新增」打开对话框：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 物料 | 是 | 每个物料只能设置一条，编辑时不能更换物料 |
| 最低销售价（含税） | 二选一 | 按基本单位、人民币；为空表示不控制销售价 |
| 最高采购价（含税） | 二选一 | 按基本单位、人民币；为空表示不控制采购价。两个价格至少填写一个，否则提示「请至少填写最低销售价或最高采购价」 |
| 控制方式 | 是 | 「提示」（默认）：订单单价下方显示红字提示，仍可保存；「禁止保存」：保存订单时校验，超出时不能保存 |
| 备注 | 否 | |

新增、编辑、删除需要价目表修改权限。

控制的范围：

- [销售订单](./sales#价格控制)明细的单价（有促销时按促销前的原价，赠品不校验）低于最低销售价、[采购订单](./purchase#价格控制)明细的单价高于最高采购价时提示或禁止保存；外币订单按订单汇率折算为人民币、辅助单位按换算率折算为基本单位后比较；
- 只在手工新增、编辑订单时校验；报价转单、门户订货、外部导入、请购单 / MRP / 询价 / 招标生成的订单在生成时不校验；
- 销售报价、订单变更不校验。

## 注意事项

::: tip 提示
价目表只决定「原价」。限时折扣、满减、买赠请使用 [促销活动](./promotion)，按销售额返利请使用 [销售返利](./rebate)。经销商门户只能订购价目表中当天有效、适用其客户等级的物料，下单时按上面的取价规则（含专属价）计价。
:::
