# 销售价目表

销售价目表是公司的标准销售价格，按「物料 × 客户等级 × 起订数量 × 有效期」定价。销售报价、销售订单、[经销商门户订货](../portal/dealer#我要订货)、外部订单导入都从这里自动取价，销售人员只需关注折扣，不必记价格。

## 页面入口

供应链 → 销售 → 销售价目表

![销售价目表](/images/manual/scm/price-list.jpg)

## 取价规则

页面顶部提示：「销售订单、报价单选择物料后按客户等级、数量、日期匹配价目：指定等级优先于全部客户，起订数量取满足条件的最高档。」具体为：

1. 只看在单据日期有效（有效期起 ≤ 日期 ≤ 有效期止，为空表示不限）、起订数量不超过本行数量、客户等级为该客户等级或「全部客户」的价目。
2. 指定了客户等级的价目优先于「全部客户」的价目。
3. 同一优先级中取起订数量最高的一档。例如全部客户起订 0 为 ¥6,800、起订 10 为 ¥6,500，买 12 台时取 ¥6,500。
4. 同时带出该价目的税率。

外币销售订单按订单汇率把人民币价目价折算为外币。

## 列表

**查询条件**：物料（编码或名称）、客户等级。

**列表列**：

| 列 | 说明 |
| --- | --- |
| 物料 | 编码、名称，下方为规格 |
| 客户等级 | 为空显示「全部客户」 |
| 起订数量 | 为 0 显示「不限」，否则显示如「≥ 10」 |
| 含税单价 | 「¥单价 / 单位」，下方为税率 |
| 税率(%) | |
| 有效期 | 「起 ~ 止」或「长期有效」；已过期显示红色「已过期」，未到起始日显示橙色「未生效」 |
| 备注 | |

**工具栏**：「新增价目」、「批量删除」，右侧有导出等。

**行操作**：「编辑」「删除」。

## 新增 / 编辑价目

点「新增价目」打开对话框：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 物料 | 是 | |
| 客户等级 | 否 | 重点客户 / 普通客户 / 潜在客户，为空适用全部客户 |
| 起订数量 | 否 | 为空表示不限（按 0 保存） |
| 含税单价 | 是 | 基本单位的单价 |
| 税率 | 否 | 默认 13% |
| 有效期起、有效期止 | 否 | 为空表示不限；有效期止不能早于有效期起 |
| 备注 | 否 | |

## 用法示例

| 物料 | 客户等级 | 起订数量 | 单价 | 说明 |
| --- | --- | --- | --- | --- |
| 工控主机 | 全部客户 | 不限 | 6,800 | 标准价 |
| 工控主机 | 全部客户 | ≥ 10 | 6,500 | 批量价 |
| 工控主机 | 重点客户 | 不限 | 6,300 | 重点客户专享价 |

重点客户下单时取 6,300（指定等级优先），普通客户买 10 台以上取 6,500。

## 注意事项

::: tip 提示
价目表只决定「原价」。限时折扣、满减、买赠请使用 [促销活动](./promotion)，按销售额返利请使用 [销售返利](./rebate)。经销商门户只能订购价目表中当天有效、适用其客户等级的物料。
:::
