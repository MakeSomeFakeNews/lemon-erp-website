# 进销存报表

进销存报表是面向老板、销售主管、采购主管和财务的一组「即开即看」的报表：卖了多少、进了多少、赚了多少、现在有多少钱和货、哪些商品好卖或积压、积压了多少、哪些客户最有价值。所有报表都**实时查询业务单据**，录入出入库单后刷新即可看到，不需要等待数据同步。

## 页面入口

在顶部导航点击「供应链」，侧边栏「进销存报表」分组下有七个页面：

| 菜单 | 用途 |
| --- | --- |
| [销售报表](./jxc-sales) | 按类别、品牌、区域、客户、业务员、商品、日、月汇总销售出库和退货，看货款、整单优惠、净额、销售金额、成本、毛利，汇总行可穿透到单据列表或商品明细，点击单据号查看单据 |
| [进货报表](./jxc-purchase) | 按类别、品牌、供货商、商品、日、月汇总采购入库和退货，同样可以穿透到单据列表、商品明细和单据 |
| [经营状况](./jxc-business) | 一段时间的销售及利润走势、资金流走势、员工销售情况、客户销售分布 |
| [资产状况](./jxc-assets) | 截至今天或选定日期的现金、银行存款、库存、应收应付、票据、预收预付和净资产 |
| [商品分析](./jxc-goods) | 畅销、滞销、积压、缺货、周转五个角度分析商品 |
| [客户分析](./jxc-rfm) | 按最近购买、购买频次、购买金额（RFM）给客户打分，分为八类客户群 |
| [积压分析](./jxc-overstock) | 截至某一天库存超过积压基数（库存上限、上个月销量或最近 N 天销量）的商品，积压数量、积压系数、在库天数和资金占用 |

## 权限

每个页面是一个独立的菜单权限，内置角色的默认授权如下（管理员可以在「系统管理 → [角色管理](../system/role)」中调整）：

| 角色 | 销售报表 | 进货报表 | 经营状况 | 资产状况 | 商品分析 | 客户分析 | 积压分析 |
| --- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 超级管理员 | 有 | 有 | 有 | 有 | 有 | 有 | 有 |
| 总经理 | 有 | 有 | 有 | 有 | 有 | 有 | 有 |
| 会计 | 有 | 有 | 有 | 有 | 有 | 有 | 有 |
| 普通用户 | 有 | 有 | 有 | - | 有 | 有 | 有 |
| 采购员 | - | 有 | - | - | 有 | - | 有 |
| 销售员 | 有 | - | - | - | - | 有 | - |
| 销售经理 | 有 | - | - | - | - | 有 | - |
| 仓库管理员 | - | - | - | - | 有 | - | 有 |
| 出纳 | - | - | - | 有 | - | - | - |

除菜单权限外，报表还受**数据权限**限制：

- 销售报表、进货报表、经营状况的销售部分、商品分析（缺货除外）、客户分析、积压分析的销量，按出入库单的「制单人部门 + 制单人」过滤，只统计你有权查看的出入库单。
- 经营状况的「资金流走势」和收款、付款、净流入卡片，以及整个资产状况页面，汇总的是全公司数据，只有数据权限为「全部数据」的用户才能看到。
- 经营状况、商品分析、客户分析中点击业务员、客户或商品查看单据、明细时，还需要「销售报表」权限，没有时名称不是链接，也没有穿透的操作列。

::: warning 注意
数据权限按出入库单的**制单人**判断，而不是按订单的业务员。数据权限为「仅本人」的销售员只能统计自己制单的出入库单；如果出库单通常由仓库人员录入，销售员会看不到自己客户的销售。需要按业务员查看业绩时，建议由数据范围更大的主管（如数据权限为「本部门及以下」的销售经理）在销售报表中按「业务员」汇总或筛选。
:::

## 统一的统计口径

各报表共用下面的口径，与报表页面上的灰色说明文字一致：

| 项目 | 口径 |
| --- | --- |
| 统计哪些单据 | 销售：[销售出库与销售退货](./sales-out)；进货：[采购入库与采购退货](./purchase-in)。出入库单保存即确认，所以录入后立即计入（开启「进销存单据先存草稿」时，草稿不计入，审核后才计入）。按订单出库、发货通知出库、[寄售结算](./consign)生成的出库，以及不选订单「直接开单」的出入库单都包含在内 |
| 按什么日期 | 出入库单的**业务日期**（不是创建时间）。退货计入退货单业务日期所在的期间，不回冲原出库所在期间 |
| 金额 | 本位币**不含税**金额 = 价税合计 − 税额（外币订单按单据上的汇率折算为本位币）。另有「价税合计」列显示含税金额（优惠后） |
| 货款、整单优惠、净额 | 货款为整单优惠**前**的金额：出库（入库）货款 − 退货货款；整单优惠为[整单优惠 / 抹零](./sales#整单优惠与抹零)分摊到各行的部分，按行税率折算为不含税；**净额** = 货款 − 整单优惠，即销售收入 / 进货金额，与记账一致。退货在明细中显示为负数 |
| 促销与赠品 | 货款取出入库单的行金额，已扣除促销、返利抵扣；买赠的赠品行数量计入销量、金额为 0。冲账单、返利结算、订单关闭的尾差调整只调整应收应付，不计入销售 / 进货报表 |
| 销售金额（仅销售） | 销售金额 = 净额 − 本公司承担运费 − 收款折让 / 抹零 − 坏账核销，客户代垫的运费不计入。收付款时的[折让 / 抹零](../fin/settlement#折让与抹零)、坏账核销按出入库单生成的应收应付单（多次收付款累计）、按不含税比例折算，跟随出入库单的业务日期；运费、折让、坏账按行金额比例分摊。进货报表另列「付款折让」「扣折让后净进货额」（= 净额 − 付款折让，只作参考，不冲减存货成本）。明细中这些调整项可以「汇总到底部」（默认）或「分摊到各行」，见[销售报表 · 商品明细](./jxc-sales#商品明细) |
| 成本（仅销售） | 取出库时的[实时库存成本](../wms/stock#实时库存成本)：销售出库按出库时的移动加权平均价，销售退货按原出库成本（即库存流水上这一笔的成本金额）；没有实时成本的历史单据（升级前）按单据业务日期所在月份[成本核算](../fin/cost)的单位成本，仍没有时取物料档案的参考成本价，并标注「参考成本」或「含参考成本」。财务[经营分析](../fin/analysis)的「销售毛利」按月末核算单价（用于记账），两者可能不同 |
| 毛利、毛利率 | 毛利 = 销售金额 − 成本；毛利率 = 毛利 ÷ 销售金额，销售金额为 0 时显示「-」。运费、折让、坏账在利润表中分别计入销售费用、财务费用、营业外支出，利润表的毛利 = 净额 − 成本，所以与这里的毛利不同 |
| 日期范围 | 必须选择。销售报表、进货报表、商品分析最长 366 天；经营状况、客户分析最长 731 天（两年）。资产状况、积压分析不选日期范围，而是选一个截至日期（不能晚于今天） |

::: tip 提示
成本在出库时就已确定，月末[成本核算](../fin/cost)前后查询结果相同；只有升级前没有实时成本的历史单据，才会在所在月份核算前按参考成本价估算、核算后按核算单价计算。实时成本与月末核算的区别见[成本核算 · 实时库存成本与月末核算](../fin/cost#实时库存成本与月末核算)。
:::

## 与其他报表的区别

系统中还有几类与销售、库存相关的报表，各自适合不同的问题：

| 报表 | 数据来源与特点 | 适合 |
| --- | --- | --- |
| **进销存报表**（本章） | 实时查询出入库单；按类别、品牌、区域、客户、业务员、商品、日 / 月汇总，汇总 → 单据 / 明细 → 单据详情层层穿透 | 日常看销售、进货、毛利，追查某个数字由哪些单据构成；商品畅滞销、客户分群 |
| 财务 → [经营分析](../fin/analysis) | 实时；销售毛利（按物料 / 客户 / 月份 / 单据明细）、存货对账、库龄分析 | 财务核对毛利与成本、存货账实核对、按入库时间分析库龄 |
| 商务智能 → [多维分析](../bi/olap) / [经营驾驶舱](../bi/cockpit) | 读取每天凌晨同步的**数据仓库**，不是实时的；可以自由组合行列维度、跨模块（生产、财务、人力等）分析，保存为报表或仪表盘 | 管理层看全公司趋势、同比环比，自助透视分析 |
| 客户关系 → [客户分析](../crm/analysis) | 实时；客户、线索、商机、赢单的经营指标，含一个固定统计近一年的 RFM 分层（与平均值比较） | 销售团队看客户经营和商机漏斗 |
| 仓库 → [收发存汇总](../wms/inout) | 实时；按物料统计期初、各类入库、各类出库、期末**数量**，包含所有仓库单据（生产领料、调拨、盘点、其他出入库等） | 仓库月末对账、核对库存进出数量 |

简单地说：想知道「卖给谁、卖了什么、赚了多少」用进销存报表；想核对财务成本和库龄用经营分析；想做跨模块、可保存的自助分析用多维分析；想看库存数量的进出平衡用收发存汇总。
