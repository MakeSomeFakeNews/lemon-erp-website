# 库存预警

库存预警按商品设置的[库存上下限](../wms/material#库存预警)，列出截至某一天各仓库的库存、销量和预警状态，并算出高于上限的商品**多压了多少、占用多少资金**，低于下限的商品**要补多少、需要多少资金**。页面分「仓库」「高于上限」「低于下限」三个标签页。

预警口径与[库存查询](../wms/stock)的「只看低于下限 / 高于上限」、首页待办一致：**按总库存预警**的商品比较所有仓库的库存合计与商品资料中的上下限，**分仓库预警**的商品按每个仓库的上下限分别判断。

## 页面入口

供应链 → 进销存报表 → 库存预警

需要「库存预警」菜单权限（`bi:jxc:stockAlert`），内置角色中超级管理员、总经理、会计、普通用户、采购员、仓库管理员拥有，见[进销存报表概述](./jxc#权限)。

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 截至日期 | 默认今天，不能晚于今天。鼠标移到文字上显示说明：「库存按该日期截止计算（当前库存减去业务日期在该日之后的出入库）」 |
| 全部仓库 | 选择后只列出该仓库的行，见各标签页的说明；不选为全部仓库 |
| 全部类别 / 全部品牌 | 物料分类、品牌；选择上级分类时包含其所有下级分类 |
| 编码 / 名称 / 规格 / 简拼 | 规则同[积压分析](./jxc-overstock#查询条件) |
| 库存 | 「全部」（默认）、「库存 > 0」「库存 = 0」「库存 < 0」「库存 ≠ 0」，按该行的库存数量筛选，三个标签页都可用 |
| 预警 | 只在「仓库」标签页显示：「全部」（默认）、「低库存预警」「高库存预警」「全部预警」（低于下限或高于上限） |

切换标签页时立即查询；修改条件后点「**查询**」。

## 三个标签页

### 仓库

**每个仓库 + 商品一行**，按仓库、编号排序。列出截至日在该仓库有库存或有过出入库的商品；分仓库预警的商品在设置了上下限的仓库、按总库存预警且设置了上下限的商品在其默认仓库，即使没有库存也列出（库存为 0）。

库存数量的颜色表示预警状态：**红色**为低于下限、**橙色**为高于上限。按总库存预警的商品，预警状态按所有仓库的合计判断，所以同一商品各仓库的行颜色相同；选了仓库时也按所有仓库的合计判断。

| 列 | 说明 |
| --- | --- |
| 登记日期 | 商品资料的创建日期 |
| 最新入库 | 截至日之前**该仓库**最近一次采购入库的日期，没有时显示「无」 |
| 最新销售 | 截至日之前**该仓库**最近一次销售出库的日期，没有时显示「无」 |
| 仓库 | — |
| 编号 | 有库存查询权限时为链接，点击打开该商品在该仓库的[经营历史](../wms/stock#经营历史) |
| 商品、类别、品牌、规格、单位 | — |
| 月销量 | 截至日往前一个月该仓库的净销量（销售出库 − 销售退货），见下文[月销量与订单数量](#月销量与订单数量) |
| 订单数量 | 该仓库当前未出库的数量，见下文 |
| 库存数量 | 截至日该仓库的库存（当前库存减去业务日期在截至日之后的出入库） |
| 库存金额 | 库存数量 × 库存均价，不含供应商寄售仓的货物 |
| 库存均价 | 实时移动加权平均成本，没有时取最近一期核算单价、参考成本价 |
| 参考进价 | 商品资料的参考成本价 |
| 零售价、批发价… | [价格列设置](../wms/material#价格列设置)中启用的价格列，列名为设置的名称 |
| 库存上限、库存下限 | 分仓库预警取该仓库的设置，按总库存预警取商品资料中的设置（针对所有仓库的合计） |
| 货位 | 商品资料中的默认库位，只在默认仓库的行显示 |
| 操作 | 有库存查询权限时显示「经营历史」（按该行的仓库）和「库存分布」 |

### 高于上限

库存数量高于库存上限的商品，按资金占用从大到小排序（没有「查看成本金额」权限时按积压数量）。

- **分仓库预警**的商品：每个设置了上限的仓库一行，库存、月销量按该仓库；选了仓库时只列出该仓库的行；
- **按总库存预警**的商品：一行，仓库显示「全部仓库（按总库存）」，库存、月销量为所有仓库的合计，上限为商品资料中的库存上限；选了仓库时只列出在该仓库有库存、有过出入库或默认仓库为该仓库的商品，库存仍为所有仓库的合计。

| 列 | 说明 |
| --- | --- |
| 编号、商品、类别、品牌、规格、单位 | 同「仓库」标签页 |
| 仓库 | 分仓库预警为该仓库；按总库存预警为「全部仓库（按总库存）」 |
| 月销量 | 截至日往前一个月的净销量 |
| 库存数量 | 截至日的库存 |
| 库存资金 | 库存数量 × 库存均价，不含供应商寄售仓的货物 |
| 积压基数 | = 库存上限 |
| 积压系数 | = 积压数量 ÷ 库存上限，保留两位小数；上限为 0 时显示「—」 |
| 积压数量 | = 库存数量 − 库存上限，加粗显示 |
| 资金占用 | = 库存均价 × 积压数量 |
| 操作 | 同「仓库」标签页 |

### 低于下限

库存数量低于库存下限（安全库存）的商品，按补货资金从大到小排序（没有「查看成本金额」权限时按补货数量）。分仓库预警、按总库存预警的行与「高于上限」相同。

| 列 | 说明 |
| --- | --- |
| 编号、商品、类别、品牌、规格、单位、仓库、月销量、库存数量、库存资金 | 同「高于上限」 |
| 补货基数 | = 库存下限 |
| 补货系数 | = 补货数量 ÷ 库存下限，保留两位小数；下限为 0 时显示「—」 |
| 补货数量 | = 库存下限 − 库存数量，加粗显示 |
| 补货资金 | = 库存均价 × 补货数量 |
| 操作 | 同「仓库」标签页 |

**示例**：某商品按总库存预警，库存上限 500，截至今天 A 仓 400、B 仓 200，合计 600：「仓库」标签页中 A 仓、B 仓两行的库存都显示为橙色；「高于上限」中一行，仓库为「全部仓库（按总库存）」，积压基数 500，积压数量 100，积压系数 0.20，资金占用 = 库存均价 × 100。如果改为分仓库预警、A 仓上限 300、B 仓上限 300，则只有 A 仓一行，积压数量 100。

## 月销量与订单数量

| 项目 | 口径 |
| --- | --- |
| 月销量 | 截至日往前一个月（截至日 − 1 个月 + 1 天～截至日，例如截至 11 月 15 日为 10 月 16 日～11 月 15 日）的销售出库 − 销售退货，按出库明细的仓库统计。表格上方的说明中写明实际期间，例如「月销量为 2026-10-16 ~ 2026-11-15 的净销量。」 |
| 订单数量 | **当前**未出库的数量，不随截至日期变化：已审核（含部分出库）的[销售订单](./sales)的未完成数量，仓库取订单的发货仓库，没有时取商品的默认仓库；加上没有引用订单的销售出库草稿（直接开单，开启「进销存单据先存草稿」时）。引用订单的草稿已计入订单的未完成数量，不重复计算。电商订单暂不计入，[导入外部订单](./sales#导入外部订单)生成的销售订单审核后才计入 |

## 金额与价格的权限

金额和价格按用户已有的查看权限显示，由服务器过滤（没有权限时系统不返回），不另设权限按钮：

| 列 | 需要的权限 |
| --- | --- |
| 库存金额、库存均价、库存资金、资金占用、补货资金 | 库存查询的「**查看成本金额**」按钮权限 |
| 参考进价 | 采购订单或采购入库的查看权限 |
| 零售价、批发价 | 销售报价、销售订单或销售出库的查看权限，或「商品价格」页面权限（同[商品速查](./quick-lookup#价格的查看权限)）；停用的价格列不显示 |

## 合计与导出

表格底部的**合计行**为全部符合条件的行（不只是当前页）的合计：第一列显示「合计 · N 行」，另有月销量、订单数量、库存数量、库存金额（库存资金）、积压 / 补货基数、积压 / 补货数量和资金占用（补货资金）的合计。

点表格右上角的「**导出**」，按当前标签页和条件导出全部行（最多 5000 行），列与表格一致，最后一行为合计行，文件名为「库存预警_标签页_截至日期」，例如「库存预警_高于上限_2026-11-15」。

## 与积压分析的区别

[积压分析](./jxc-overstock)的积压基数选「库存上限」时，与这里的「高于上限」相近，区别在于：

- **分仓库预警的商品**：积压分析不选仓库时，按各仓库上限之和与所有仓库的库存合计比较，得出一行；库存预警按仓库逐个比较，每个超过上限的仓库一行。例如 A 仓超出 100、B 仓低于上限 100，积压分析（不选仓库）没有积压，库存预警的「高于上限」列出 A 仓；
- 积压分析的库存不含供应商寄售仓；库存预警的库存数量与库存查询的预警一致，包含所有仓库，只有金额不含寄售仓的货物；
- 积压分析还可以按上个月或最近 N 天的销量判断积压，并显示在库天数；库存预警另有「低于下限」的补货数量和资金。

## 数据权限

- 月销量以及最新入库、最新销售日期来自出入库单，按出入库单的「制单人部门 + 制单人」过滤，见[进销存报表概述 · 权限](./jxc#权限)；
- 库存数量、上下限、订单数量不受数据权限限制。
