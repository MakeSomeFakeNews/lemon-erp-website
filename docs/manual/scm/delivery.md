# 发货通知

发货通知是销售部门通知仓库发货的单据。按销售订单的未出库数量生成，保存后系统按「先到期先出」自动给出[拣货建议](../wms/label-putaway#拣货建议与拣货路径)（从哪个库位、哪个批次拣多少）；仓库按实际拣货确认后，一键生成销售出库单。已拣货的通知还可以[装箱](../wms/label-putaway#装箱)、打印装箱单和箱标签。多张发货通知可以合并成 [波次](./wave) 一起拣货。

不使用发货通知时，也可以直接在 [销售出库](./sales-out) 中按订单出库。

## 页面入口

供应链 → 销售 → 发货通知

也可以在 [销售订单](./sales) 详情点「发货通知」直接以该订单新建。

![发货通知列表](/images/manual/scm/delivery-list.jpg)

## 列表

**查询条件**：关键字（通知单号、订单号或客户）、状态、仓库。

**列表列**：通知单号（点击打开详情）、销售订单、客户、发货仓库、发货日期、数量、状态（加入波次的下方显示「波次 …」）、拣货（拣货人和时间）、销售出库单、制单人、备注、创建时间。

**工具栏**：

- 「新增发货通知」。
- 「生成波次（N）」：勾选同一仓库的待拣货通知后生成拣货波次，见 [波次拣货](./wave)。
- 右侧有导出、刷新等。

## 新增发货通知

表单提示：「发货通知按销售订单的未出库数量生成，保存后按先到期先出自动生成拣货建议；仓库确认拣货后出库，自动生成销售出库单。」

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 销售订单 | 是 | 搜索订单号，只能选已审核、部分出库的订单 |
| 发货仓库 | 是 | 默认订单的发货仓库 |
| 发货日期 | 否 | |
| 备注 | 否 | |

选择订单后带出明细：

| 列 | 说明 |
| --- | --- |
| 物料 | |
| 可通知数量 | 未出库且未通知的数量；已有待拣货 / 已拣货通知的，下方显示「已通知未出库 …」 |
| 通知数量 | 必填，大于 0 且不超过可通知数量；默认等于可通知数量，可改小分批发货 |
| 备注 | |

本次不发的行可以删除，至少保留一行。发货通知保存后不能修改，如需调整请取消后重新通知。

## 发货通知详情

![发货通知详情](/images/manual/scm/delivery-detail.jpg)

详情显示通知单号、销售订单（可点击）、客户、发货仓库、发货日期、制单、拣货（人和时间）、销售出库单、备注。下方按通知明细分块，每块标题显示物料、批次 / 序列号标签，以及「通知 X，已拣 Y」，表格列出拣货明细：库位 / 批次、有效期、数量、序列号。

待拣货时提示：「已按先到期先出生成拣货建议（库存不足的部分没有建议），请按实际拣货调整后确认拣货；确认后才能出库。」

**按钮**：

| 按钮 | 显示条件 | 作用 |
| --- | --- | --- |
| 打印拣货单 | 有拣货明细时可用 | 按库位、批次列出拣货明细，签字栏为制单、拣货、复核 |
| 取消通知 | 待拣货、已拣货 | 取消后不能恢复，订单的未出库数量可以重新通知 |
| 重新建议 | 待拣货 | 按当前库存以先到期先出重新分配，覆盖现有的拣货明细 |
| 确认拣货 / 修改拣货 | 待拣货 / 已拣货 | 进入拣货编辑 |
| 出库 | 已拣货，有销售出库权限 | 选择业务日期，按拣货明细生成销售出库单 |

## 拣货

点「确认拣货」进入编辑，提示：「每个物料的拣货数量合计须等于通知数量；同一物料可从多个库位、批次拣货，序列号管理的物料需选择序列号。」

- 每个物料块可以「添加库位」，选择库位 / 批次（显示可用数量），填写数量；序列号物料选择或扫码序列号，个数须与数量一致。
- 点「确认拣货」保存，提示「已确认拣货，可以出库」，状态变为已拣货。
- 编辑中点「取消」会提示「放弃未确认的拣货？」。

**先到期先出**：拣货建议按批次有效期、批次号、库位顺序分配可用库存，不使用过期批次；库存不足的部分不生成建议，需要补货后点「重新建议」或手工调整。

## 出库

已拣货的通知点「出库」，提示「按拣货明细生成销售出库单并扣减库存，同时生成应收单，出库后不能修改。」选择业务日期后确定：

- 生成 [销售出库单](./sales-out)（备注「发货通知 + 单号」），扣减库存、生成[应收单](../fin/ar-ap)、回写订单进度，出库前同样校验客户信用额度。
- 通知变为「已出库」，弹窗可「查看出库单」。

## 装箱

已拣货、已出库的通知在详情下方显示「装箱」区域，标题显示箱数和总毛重，右侧显示各物料的装箱进度（如「已装 2 / 2」）：

- 「装一箱」（需要装箱权限，全部装完后不可用）：填写每个物料的装入数量（不超过剩余可装数量）、毛重（kg）、体积（m³）、备注。箱号自动生成为「发货通知号-两位序号」，如 FH202610150003-01。
- 每箱可「编辑」「删除」。
- 「装箱单」：打印装箱单（箱号、物料、数量、毛重、体积，总箱数、总毛重、总体积，签字栏为装箱、复核、客户签收）。
- 「箱标签」：打印每箱的条码标签，标签样式在系统管理「[打印模板 - 标签](../system/print-template#标签模板)」中设置。

每个明细的装箱合计不能超过通知数量。

## 单据状态

| 状态 | 说明 |
| --- | --- |
| 待拣货 | 已生成拣货建议；可确认拣货、重新建议、加入波次、取消 |
| 已拣货 | 已确认实际拣货；可修改拣货、装箱、出库、取消 |
| 已出库 | 已生成销售出库单；可装箱、打印 |
| 已取消 | 已取消 |

## 注意事项

::: tip 提示
仓库使用手机 / PDA 时，可以在「移动作业」的拣货功能中按发货通知的拣货建议逐库位扫码拣货，见 [移动作业](../mobile/pick)。
:::
