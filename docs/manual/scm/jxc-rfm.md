# 客户分析（RFM）

客户分析用经典的 **RFM 模型**给客户分群：R（Recency）最近一次订货距今多久，F（Frequency）每月订货几次，M（Monetary）平均每次订多少钱。把客户分成「重要价值」「重要挽留」等八类后，可以有针对性地维护、回访或挽回。

## 页面入口

供应链 → 进销存报表 → 客户分析

需要「客户分析」菜单权限，内置角色中超级管理员、总经理、会计、普通用户、销售员拥有，见[进销存报表概述](./jxc#权限)。

![客户分析](/images/manual/scm/jxc-rfm.jpg)

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 日期范围 | 默认近 12 个月（11 个月前的 1 日到今天），最长 731 天。RFM 需要一段较长的购买历史，期间太短时大部分客户只有一两次购买，分群意义不大 |
| 区域 | 客户档案上的区域，精确匹配 |
| 客户编码 / 名称 | 模糊匹配 |

修改日期后自动查询，其他条件修改后点「**查询**」或按回车。分群方式为「平均分」时，查询条件右侧显示全部客户的平均分「平均分 R … · F … · M …」。

## 分群参数

查询条件下方是分群参数条，决定 R、F、M 各项怎样算「高」：

| 方式 | 说明 |
| --- | --- |
| 固定阈值（默认） | 按三个阈值判断：「R 最近订货 □ 天之内」（默认 30 天）、「F 订货频率 ≥ □ 次 / 月」（默认 1 次）、「M 平均订货金额 ≥ □ 元 / 次」（默认 1000 元）。达到阈值的为「高」，标准固定，便于跨期间比较 |
| 平均分 | R、F、M 各按五分位打 1–5 分，不低于全体平均分为「高」，随客户整体水平自动调整（见下文[打分规则](#打分规则)） |

- 切换方式或修改阈值后立即重新计算，只对本次查询有效，不影响其他人；点「**恢复默认**」回到本公司的默认参数。
- 有业务参数修改权限的用户可以点「**保存为默认**」，把当前参数保存为本公司的默认值（即[业务参数](../system/biz-rule#客户分析)中「客户分析」分组的参数），本页和客户关系的[客户分析](../crm/analysis)都使用。
- 阈值要按企业的业务特点设置：例如订货周期长的工业品可以把 R 放宽到 90 天、F 设为 0.5 次 / 月；零售批发可以收紧。

## 统计哪些客户

日期范围内**至少有一张销售出库单**的客户（只有退货的不统计），按你的数据权限统计出入库单。三个指标：

| 指标 | 列名 | 计算 |
| --- | --- | --- |
| R 最近订货 | 最近购买、距今（天） | 期间内最后一张销售出库单的业务日期；距今天数 = 从该日期到「结束日期」的天数（结束日期晚于今天时到今天）。越小越好 |
| F 订货频率 | 每月次数（参考：频次（单）） | 每月订货次数 = 期间内销售出库单的张数（退货单不算）÷ 统计月数，统计月数 = 日期范围的天数 ÷ 30.4375。越大越好 |
| M 平均订货金额 | 平均每次金额（参考：金额） | 平均每次订货金额 = 期间内销售出库 − 销售退货的不含税金额 ÷ 销售出库单张数。越大越好 |

## 打分规则

无论哪种分群方式，三个指标都在全部参与统计的客户中**按五分位打 1–5 分**（列表中的「得分」，用于排序参考；按订货单数和净销售额打分）：

- 得分 = 向上取整（5 × 不优于该客户的客户数 ÷ 客户总数），最低 1 分；
- 「不优于」：R 是距今天数不少于该客户的，F、M 是数值不大于该客户的（含该客户自己）；取值相同的客户得分相同；
- 只有一个客户时三项都是 5 分。

例如共 10 个客户，某客户的金额在 10 个人中排第 3 高（有 8 个客户的金额不大于他），M 得分 = 向上取整（5 × 8 ÷ 10）= 4 分。

分群方式为「平均分」时，计算全部客户三项得分的**平均分**，某项得分**不低于平均分**记为「高」，否则为「低」；分群方式为「固定阈值」时，高低按阈值判断，与得分无关。

## 八类客户群

按 R、F、M 的高低组合分为八类，M 高为「重要」、M 低为「一般」：

| 分群 | R 最近订货 | F 订货频率 | M 平均订货金额 | 特征与经营建议 |
| --- | :---: | :---: | :---: | --- |
| 重要价值 | 高 | 高 | 高 | 最近买过、常买、金额高：重点维护，提供优先服务和专属政策 |
| 重要发展 | 高 | 低 | 高 | 最近买过、金额高但不常买：提高购买频次，例如推荐关联商品、签订年度协议 |
| 重要保持 | 低 | 高 | 高 | 常买、金额高但最近没买：及时回访，了解是否转向竞争对手或需求变化 |
| 重要挽留 | 低 | 低 | 高 | 金额高但很久没买、不常买：重点挽回，有流失风险，应尽快跟进 |
| 一般价值 | 高 | 高 | 低 | 最近买过、常买但金额不高：提升客单价，例如组合销售、满减 |
| 一般发展 | 高 | 低 | 低 | 最近买过但不常买、金额不高：培养新客，保持跟进 |
| 一般保持 | 低 | 高 | 低 | 常买但最近没买、金额不高：保持联系 |
| 一般挽留 | 低 | 低 | 低 | 很久没买、不常买、金额不高：低成本维护 |

页面上方的分群卡片显示每类的客户数和金额合计，鼠标悬停显示该类的经营建议。点击卡片只看该类客户，点「全部客户」恢复；没有客户的分群卡片显示为灰色，不能点击。

## 客户列表

列：客户（名称和编码）、最近购买、距今（天）、频次（单）、每月次数、金额、平均每次金额、得分（R、F、M 三项分数）、分群。「距今」「每月次数」「平均每次金额」三列按判断结果着色：绿色为高，灰色为低。默认按三项得分之和从高到低、同分按金额从高到低排列，「距今」「频次」「每月次数」「金额」「平均每次金额」列可以点击表头排序。

- 有「销售报表」权限时，客户名称是链接，点击打开该客户在当前日期范围内的销售明细，与[销售报表的明细](./jxc-sales#查看明细和单据)相同。
- 「**导出**」导出当前显示的客户（选中某个分群时只导出该分群），含编码、每月次数、平均每次金额、R、F、M 分数和分群名称。

::: tip 提示
- 得分是**相对**的：同一个客户在不同的日期范围、区域条件下，因为参与比较的客户不同，得分可能不同；「平均分」方式下分群也随之变化。「固定阈值」方式的分群只取决于客户自己的数据和阈值。
- 客户关系模块的[客户分析](../crm/analysis#rfm-客户分层规则)中也有一个 RFM 客户分层，与本页共用分群方式和默认阈值，金额口径相同（不含税，扣除退货），但固定统计近一年，适合销售团队快速查看；本页可以自选期间和区域，并能穿透到单据，期间不同时结果与之不完全相同是正常的。
:::
