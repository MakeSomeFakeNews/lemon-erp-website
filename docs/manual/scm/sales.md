# 销售订单

销售订单记录客户订购的物料、数量、含税单价和交货日期，是销售执行的起点。订单审核时校验客户信用额度（可在业务参数中调整控制方式），审核后可以[预留库存](../wms/reservation)、通知仓库发货、出库、退货，出库进度自动回写。

销售订单与 [采购订单](./purchase) 的列表、表单、详情、审核、变更、状态的操作方式基本相同，本页重点说明销售订单特有的功能：价格来源（客户执行价、价目表、价格等级、促销、返利、历史成交价）、[整单优惠与抹零](#整单优惠与抹零)、价格控制、业务员、信用额度、库存预留、可承诺量、发货通知和外部订单导入。

销售订单的来源包括：手工新增、[销售报价](./quotation) 转单、[经销商门户](../portal/dealer) 订货、外部订单导入、客户关系模块的[商机赢单](../crm/opportunity#赢单生成销售订单)、[寄售结算](./consign)；[销售出库、销售退货直接开单](./sales-out#直接开单)时系统也会自动生成已审核的订单（标记「直接开单」）。

## 列表

**查询条件**：订单号（同时匹配外部单号）、客户、状态、物料、订单日期范围。

**列表列**：订单号、客户、订单 / 交货日期、价税合计、状态、出库进度、发货仓库、制单人、备注、创建时间。订单号旁的标签：「V2」等版本号、「经销商」（经销商门户订单）、「导入」（外部订单导入，下方显示外部单号）、「寄售」（寄售结算）、蓝色「直接开单」（销售出库 / 退货直接开单自动生成）。

**工具栏**：「新增销售订单」「导入外部订单」「批量删除」（只能勾选草稿）。

**行操作**：「查看」；草稿「编辑」；已审核、部分完成显示「出库」（打开 [销售出库](./sales-out) 表单）。

::: tip AI 识别
管理员开启了[智能录入](../ai/extract)时，工具栏中还有「AI 识别」按钮：上传客户的采购单、订货单的图片、PDF、Excel 或粘贴文字，AI 识别后打开新增表单并填入往来单位、物料、数量、单价等（单据上写明的整单优惠、抹零或折让填入「整单优惠」，明细为优惠前的单价），匹配不上的资料在选择框下方显示「AI 识别：…」原文，核对后保存。
:::

## 新增 / 编辑销售订单

![新增销售订单](/images/manual/scm/sales-form.jpg)

### 表头字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 客户 | 是 | 选择启用的客户。更换客户后按新客户（执行价、专属价、客户等级、价格等级）重新取价，并重新读取返利余额 |
| 订单日期 | 是 | 默认今天；价目表有效期、促销期间都按订单日期判断 |
| 交货日期 | 否 | 明细未填写时使用 |
| 发货仓库 | 否 | 出库、发货通知、库存预留时默认使用 |
| 币种 / 汇率 | 是 | 同采购订单；外币订单的价目价按汇率折算 |
| 返利抵扣 | 否 | 客户有返利余额（或订单已抵扣过）时显示，见 [销售返利](./rebate) |
| 整单优惠 | 否 | 在明细下方的合计区填写，见下文[整单优惠与抹零](#整单优惠与抹零) |
| 备注 | 否 | |

管理员在「系统管理 → [自定义字段](../system/custom-field)」中为「销售订单」定义了扩展字段时，表单中还有「扩展信息」分区，必填的扩展字段不填不能保存；订单详情中同样显示这些字段。

业务员不在表单中填写：新建时自动取客户的负责销售，见下文[业务员](#业务员)。

### 明细

| 列 | 说明 |
| --- | --- |
| 物料 | 必填，选择后按[开单默认价](./price-list#开单默认价)带出单价（价目表、客户执行价还带出税率） |
| 数量 | 必填，可按辅助单位录入；修改数量后重新取价（价目表的起订数量；同一物料录了多行时，每行按本行数量分别匹配起订数量）。下方「可承诺量」链接查看该物料的可承诺量 |
| 含税单价 | 必填，按 **原价** 录入；自动带出的单价下方显示来源（客户执行价、价目表、等级价、零售价、最近价）；来源为价目表时显示「价目价」和折扣比例，有促销时显示「促销价 ¥…（促销名称）」；「上次 ¥…（日期）」为该客户这个物料最近一次的成交价，点击即改用该价格；「价格参考」打开该物料的历史价格，点击价格即可使用，见[价格参考](./price-list#价格参考)；低于最低销售价时显示红字提示 |
| 税率、价税合计、交货日期、备注 | 同采购订单 |

明细右上角的「按规格录入」用于多规格物料：选择款式后在规格矩阵（如颜色 × 尺码）中填写各 SKU 的数量，一次加入多行明细，用法同[采购订单](./purchase#按规格录入)。

### 价格来源

1. **开单默认价**：选择客户和物料后依次取 客户执行价 → [销售价目表](./price-list)（该客户的专属价优先，其次客户等级的价目，再其次全部客户的价目；同一优先级取满足数量的最高档）→ 客户价格等级对应的[商品价格](./goods-price)（等级价）→ 零售价 → 该客户最近一次销售出库的单价（最近价），详见[开单默认价](./price-list#开单默认价)。外币订单按汇率折算。手工改过的单价不再被自动覆盖。
2. **历史成交价**：以上都没有价格时，自动带出该客户这个物料最近一次的订单成交价（取已审核、部分完成、已完成、已关闭的销售订单，有促销的取促销前的原价，不含赠品；只在币种相同时自动带出）。都没有时需手工填写单价。
3. **促销**：手工新建 / 修改订单时，按订单日期和客户等级自动应用 [促销活动](./promotion)（折扣 → 满减 → 买赠）。表单上方绿色提示框实时预览「促销优惠 ¥…，成交价合计约 ¥…」以及各项促销说明、赠品，保存时按订单日期重新计算。
4. **返利抵扣**：填写的返利金额按行金额分摊到单价。
5. **整单优惠**：最后扣除，见下文。

### 整单优惠与抹零

![销售订单的整单优惠](/images/manual/scm/sales-form-discount.jpg)

有明细时，表格下方显示一行合计区：

| 项目 | 说明 |
| --- | --- |
| 合计 | 优惠前的价税合计。有促销、返利抵扣时为扣除它们之后的成交价合计 |
| 整单优惠 | 含税金额，不能为负数，也不能超过合计。鼠标停在「整单优惠」上提示「含税金额，保存时按各行金额比例分摊到明细（在促销、返利之后），应收 / 应付按优惠后的金额」 |
| 抹零 | 下拉选择「抹去分」「抹去角分」「抹去个位」，把优惠后合计向下取整到角、元或十元，差额累加到整单优惠；已有优惠时可「清除优惠」 |
| 优惠后合计 | 合计 − 整单优惠，即订单的价税合计 |

例如合计 ¥51,950.80，选「抹去个位」后整单优惠为 ¥0.80，优惠后合计 ¥51,950.00。

保存时的处理：

- 顺序为 **先促销 → 再返利抵扣 → 最后整单优惠**。整单优惠按各行金额占合计的比例分摊到各行（赠品金额为 0，不参与），每行少收的金额四舍五入到分，几分钱的尾差放在金额最大的一行，分摊后各行价税合计之和正好等于优惠后合计；
- 各行的含税单价变为 行金额 ÷ 数量（保留 4 位小数），同时保留原价；编辑草稿时单价恢复为原价，保存时重新分摊；[价格控制](#价格控制)按原价校验；
- 订单列表的价税合计下方、订单详情的「优惠」、打印中显示「整单优惠 ¥…」；
- 出库时各批次的金额、订单关闭时的结算都以分摊后的行金额为准，见下文[分批出库与关闭时的尾差](#分批出库与关闭时的尾差)；[应收单](../fin/ar-ap)、毛利、销售提成都按优惠后的金额计算。

采购订单、[销售报价](./quotation#整单优惠)和[直接开单](./sales-out#整单优惠与买赠)的整单优惠用法相同。发布了「销售订单审核」流程时，可以用流程变量「整单优惠」设置审批条件。

::: tip 提示
整单优惠记在订单上，适合下单时就谈好的优惠。收款时客户临时少付的零头不必改订单，在[收款核销](../fin/settlement)时填写折让即可。
:::

### 价格控制

在[销售价目表](./price-list#价格控制)的「价格控制」中可以为物料设置**最低销售价**（含税、按基本单位、人民币）。销售订单明细的原价（折算为基本单位和人民币后；有促销时按促销前的原价校验，赠品不校验）低于最低销售价时：

- 单价下方显示红字「低于最低销售价 ¥…」；
- 控制方式为「提示」的只提示，可以保存；为「禁止保存」的保存时提示「「物料」单价 … 低于最低销售价 …」，订单不能保存。

校验在手工新增和编辑订单时进行；报价转单、经销商门户、外部导入、商机赢单等生成的订单在生成时不校验，之后编辑保存时校验。

保存后订单明细的单价为促销、返利、整单优惠分摊后的成交价，同时保留原价；赠品行单价为 0、标记「赠品」。编辑订单时赠品行不显示，单价恢复为原价，保存时重新应用促销。

## 分批出库与关闭时的尾差

订单行有整单优惠的分摊（或促销、返利分摊）时，行金额不一定正好等于 数量 × 单价。为了让应收与订单金额一分不差，系统这样计算每次出库的金额：

- **分批出库**：完成该行的那一批（本次数量不少于未出库数量）取「订单行金额 − 已出库金额」，其他批次按 数量 × 单价，所以各批累计金额正好等于订单行金额；超发的部分按单价另加；
- **退货**：按 数量 × 单价（不超过该行剩余的已出库金额），退回全部已出库数量时取剩余金额；勾选「退货后需要补发」的，补发的最后一批取回差额；
- **订单变更**：已出库部分的数量和金额不变，未出库部分按变更后的单价计算，见[订单变更](./purchase#订单变更)。

**关闭订单时**，点「关闭」后确认框提示「关闭后不能再出库，已完成部分不受影响；部分出库的明细按 行金额 × 已出库数量 / 订单数量 结算，几分钱的尾差自动生成应收调整单。」

![关闭订单](/images/manual/scm/sales-close-confirm.jpg)

- 只处理部分出库的行（已出库数量大于 0 且小于订单数量），未出库的部分不结算；应得金额 = 行金额 × 已出库数量 ÷ 订单数量（四舍五入到分；生效过订单变更的订单为 行金额 − 未出库数量 × 单价），与已出库金额的差额就是尾差；
- 尾差通常只有几分钱，计入该行的已出库金额（之后的退货按调整后的金额退回），订单详情显示「关闭尾差调整 ¥…」和说明「部分出入库的明细关闭时按订单口径结算的差额，已生成应收 / 应付调整单」；
- 财务自动生成一张来源为「订单尾差调整」的[应收单](../fin/ar-ap)，正数为蓝字、负数为红字，到期日按客户账期，可以和其他应收单一样核销、生成凭证；没有尾差时不生成；
- 订单关闭后不能反关闭；关闭后的退货只能退款，不能勾选补发。

::: warning 注意
有尾差时，应收调整单的日期是关闭当天，当天所在的会计期间已结账时不能关闭订单。
:::

## 业务员

每张销售订单记录一个**业务员**，用于计算[销售提成](./commission)：

- 新建订单（包括报价转单、经销商门户订货、外部导入、商机赢单等）时，业务员自动取[客户](./customer)的「负责销售」；客户没有设置负责销售时为制单人；
- 订单详情的「业务员：…」后面点「修改」（需要销售订单修改权限），选择其他用户后点「保存」，提示「业务员已修改」；任何状态的订单都可以修改；
- 修改业务员只影响之后计算或重新计算的销售提成，已确认的提成表不变。

## 信用额度与账期

在 [客户](./customer) 中设置「信用额度」后，按「系统管理 → [业务参数](../system/biz-rule)」中「客户信用额度控制」的设置进行控制（默认「审核和出库时控制」）：

- **审核时**：应收余额 + 该客户其他未完成订单（审批中、已审核、部分完成）的金额 + 本单金额（外币折人民币）不能超过信用额度，否则提示「超出客户「…」的信用额度：额度 …，应收余额 …，未完成订单 …，本单 …」，订单不能审核。
- **出库前**：再校验一次（审核后客户可能新增了欠款）：应收余额 + 全部未完成订单金额超过额度时暂停出库，提示「客户「…」超出信用额度，暂停出库……请先收款或调整额度」。
- 「客户信用额度控制」设为「只在出库时控制」时，审核不校验，只在出库前校验；设为「不控制」时审核和出库都不校验。
- 没有设置信用额度的客户不限制。客户的信用占用（额度、应收余额、未完成订单）可在客户关系模块的[客户详情](../crm/customer#客户详情-客户-360)中查看。

客户的「账期」决定[应收单](../fin/ar-ap)到期日：出库日期 + 账期天数。

## 库存预留

已审核、部分完成的订单可以在「库存预留」页签为明细预留仓库的空闲库存，保证这些库存不会被其他订单、出库和调拨占用。页签说明：「预留不锁定库位批次，只保证其他订单、出库和调拨不能占用；销售出库时核销本订单的预留，订单完成、关闭或反审核时自动释放。」

- 「预留库存」：逐行选择仓库，显示空闲库存（可用 − 已预留），填写预留数量（不超过未出库且未预留的数量和空闲库存）。
- 「一键预留」：选择仓库（默认订单发货仓库），按明细顺序预留，库存不足的部分不预留。
- 「全部释放」：释放本订单的全部预留。

预留列表显示仓库、物料、预留数量、说明、预留人和时间。需要「库存预留」权限。

## 可承诺量

在订单或报价表单中点物料行下方的「可承诺量」，打开「可承诺量（ATP）」窗口：

- 顶部显示可用库存、已预留、空闲库存、可承诺量（指定了发货仓库时按该仓库，否则按全部仓库）。
- 有需求数量时提示「最早可承诺日期：…」，或「按现有库存和在途供应无法满足该数量」。
- 下方时间线列出采购在途、生产在制（供应 +）和销售待发、工单待领料（需求 −），以及每天的结余。

可承诺量 = 从空闲库存出发按日期累加供应、扣减需求后，今天及以后各日结余的最小值。

## 导入外部订单

电商、门店等外部渠道的订单可以按统一格式导入：

1. 点「导入外部订单」，在对话框中「下载导入模板」。
2. 按模板填写：外部单号*、客户编码*、下单日期*、交货日期、物料编码*、数量*、含税单价、备注、整单优惠（带 * 的必填）。整单优惠同一外部单号填一行即可，几行都填时必须相同，否则提示「同一外部单号的整单优惠必须相同（可以只在一行填写）」。
3. 拖入或选择 .xlsx 文件，点「导入」。

![导入外部订单](/images/manual/scm/sales-import.jpg)

导入规则：

- 同一外部单号的多行合并为一张销售订单（草稿，来源「外部导入」），同一外部单号的客户、下单日期必须一致。
- 含税单价为空时按价目表取价；物料没有价目价时提示「物料「…」没有价目表价格，请填写单价」。
- 外部单号已经导入过的整单跳过（防止重复导入），结果提示「生成 N 张销售订单（草稿），跳过已导入的 M 张：…」。
- 客户编码、物料编码不存在等其他错误时整批不导入，对话框中按行号列出错误。
- 导入的订单记录外部单号，在列表按订单号查询时也能搜外部单号。

外部系统也可以通过接口直接推送订单，规则相同。

## 与其他模块的联动

- **仓库**：发货通知生成[拣货建议](../wms/label-putaway#拣货建议与拣货路径)；出库、退货自动生成仓库单据；[库存预留](../wms/reservation)影响可用库存。
- **财务**：出库生成[应收单](../fin/ar-ap)（到期日按客户账期），退货生成红字应收单。
- **物流**：销售出库单可创建 [物流发运](./shipment) 单。
- **生产**：[主生产计划](../mes/plan#由销售订单生成)可由销售订单生成；已生成生产计划的订单不能反审核，关闭订单时未完成的生产计划一并关闭。
- **客户关系**：[商机赢单](../crm/opportunity#赢单生成销售订单)生成销售订单（来源「商机」）。
- **项目管理**：订单可一键[创建项目](../pm/project#从商机、销售订单创建项目)。
- **[首页待办](../guide/home#待办事项)**：交货日期已过仍未发货的订单计入「销售订单逾期未发货」。
- **销售提成**：按订单业务员统计出库、回款业绩，计算[销售提成](./commission)。

## 直接开单生成的订单

[销售出库、销售退货](./sales-out#直接开单)不选订单直接开单时，系统按单据的客户、业务日期、仓库、业务员和明细自动生成一张订单，直接审核（不走审批，审核人为制单人）。这种订单在列表中显示「直接开单」标签，详情顶部提示「该订单由直接开单（销售出库、采购入库或退货）自动生成并审核，不能修改、反审核、关闭或变更，错误请通过退货冲回。」：

- 出库生成的订单随即变为「已完成」，详情中没有反审核、关闭、变更、发货通知和库存预留，只能做销售退货；
- 退货时不能勾选「退货后需要补发」；
- 直接开单填写的整单优惠记在这张订单上，买赠的赠品是订单中单价为 0 的赠品行；
- 订单的业务员、促销优惠计入[销售提成](./commission)、报表等，与普通订单相同。

## 注意事项

::: warning 注意
经销商门户提交的订单为草稿，需要内部销售人员审核；审核前经销商可以在门户撤销。经销商在门户下单时不能自己填写优惠，需要时由内勤在审核前编辑草稿订单填写整单优惠，门户的订单列表、详情会显示整单优惠。
:::

::: tip 提示
订单变更、反审核、关闭、审批等规则与采购订单相同，详见 [采购订单](./purchase)。
:::
