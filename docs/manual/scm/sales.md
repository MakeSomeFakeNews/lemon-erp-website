# 销售订单

销售订单记录客户订购的物料、数量、含税单价和交货日期，是销售执行的起点。订单审核时校验客户信用额度，审核后可以[预留库存](../wms/reservation)、通知仓库发货、出库、退货，出库进度自动回写。

销售订单与 [采购订单](./purchase) 的列表、表单、详情、审核、变更、状态的操作方式基本相同，本页重点说明销售订单特有的功能：价格来源（价目表、促销、返利）、信用额度、库存预留、可承诺量、发货通知和外部订单导入。

销售订单的来源包括：手工新增、[销售报价](./quotation) 转单、[经销商门户](../portal/dealer) 订货、外部订单导入、客户关系模块的[商机赢单](../crm/opportunity#赢单生成销售订单)、[寄售结算](./consign)。

## 页面入口

供应链 → 销售 → 销售订单

![销售订单列表](/images/manual/scm/sales-list.jpg)

## 列表

**查询条件**：订单号（同时匹配外部单号）、客户、状态、物料、订单日期范围。

**列表列**：订单号、客户、订单 / 交货日期、价税合计、状态、出库进度、发货仓库、制单人、备注、创建时间。订单号旁的标签：「V2」等版本号、「经销商」（经销商门户订单）、「导入」（外部订单导入，下方显示外部单号）、「寄售」（寄售结算）。

**工具栏**：「新增销售订单」「导入外部订单」「批量删除」（只能勾选草稿）。

**行操作**：「查看」；草稿「编辑」；已审核、部分完成显示「出库」（打开 [销售出库](./sales-out) 表单）。

## 新增 / 编辑销售订单

![新增销售订单](/images/manual/scm/sales-form.jpg)

### 表头字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 客户 | 是 | 选择启用的客户。更换客户后按新客户等级重新取价，并重新读取返利余额 |
| 订单日期 | 是 | 默认今天；价目表有效期、促销期间都按订单日期判断 |
| 交货日期 | 否 | 明细未填写时使用 |
| 发货仓库 | 否 | 出库、发货通知、库存预留时默认使用 |
| 币种 / 汇率 | 是 | 同采购订单；外币订单的价目价按汇率折算 |
| 返利抵扣 | 否 | 客户有返利余额（或订单已抵扣过）时显示，见 [销售返利](./rebate) |
| 备注 | 否 | |

### 明细

| 列 | 说明 |
| --- | --- |
| 物料 | 必填，选择后按价目表带出单价、税率 |
| 数量 | 必填，可按辅助单位录入；修改数量后重新按价目表取价。下方「可承诺量」链接查看该物料的可承诺量 |
| 含税单价 | 必填，按 **原价** 录入；下方显示「价目价」和折扣比例，有促销时显示「促销价 ¥…（促销名称）」 |
| 税率、价税合计、交货日期、备注 | 同采购订单 |

### 价格来源

1. **价目表**：选择客户和物料后按 [销售价目表](./price-list) 取价（客户等级优先，取满足数量的最高档），带出单价、税率。没有匹配的价目时需手工填写单价。手工改过的单价不再被自动覆盖。
2. **促销**：手工新建 / 修改订单时，按订单日期和客户等级自动应用 [促销活动](./promotion)（折扣 → 满减 → 买赠）。表单上方绿色提示框实时预览「促销优惠 ¥…，成交价合计约 ¥…」以及各项促销说明、赠品，保存时按订单日期重新计算。
3. **返利抵扣**：填写的返利金额按行金额分摊到单价。

保存后订单明细的单价为促销、返利分摊后的成交价，同时保留原价；赠品行单价为 0、标记「赠品」。编辑订单时赠品行不显示，单价恢复为原价，保存时重新应用促销。

## 订单详情

![销售订单详情](/images/manual/scm/sales-detail.jpg)

基本信息与采购订单相同，另外显示「优惠」：促销优惠金额、返利抵扣金额。明细中有促销的行显示划线原价和促销名称，赠品行显示「赠品」标签。

**页签**：订单明细、销售出库记录、销售退货记录、库存预留、发货通知、单据追溯、附件、变更记录、修改历史。「单据追溯」除出入库、应收、收款、凭证外，还包括物流发运、生产计划、项目等下游单据。

**底部按钮**：

| 按钮 | 显示条件 | 作用 |
| --- | --- | --- |
| 编辑 | 草稿 | |
| 审核 | 草稿 | 先校验信用额度；发布了「销售订单审核」流程时发起审批，否则直接审核 |
| 撤回审批 | 审批中 | 回到草稿 |
| 反审核 | 已审核（没有出库） | 回到草稿；已生成生产计划的订单不能反审核 |
| 关闭 | 已审核、部分完成 | 不能再出库；未完成的生产计划一并关闭 |
| 变更 | 已审核、部分完成 | 订单变更，同 [采购订单](./purchase#订单变更)；数量减少的明细同时释放库存预留 |
| 销售退货 | 部分完成、已完成、已关闭 | 打开 [销售退货](./sales-out) 表单 |
| 销售出库 | 已审核、部分完成 | 打开 [销售出库](./sales-out) 表单 |
| 发货通知 | 已审核、部分完成 | 跳转到 [发货通知](./delivery) 并以本订单新建 |
| 创建项目 | 已审核、部分完成、已完成，有项目新增权限 | 跳转到[项目管理](../pm/project#从商机、销售订单创建项目)，以本订单的客户、金额、订单号新建项目（交付类订单） |

「打印」按「销售订单」[打印模板](../system/print-template)打印，签字栏为制单、审核、客户确认。

## 信用额度与账期

在 [客户](./customer) 中设置「信用额度」后：

- **审核时**：应收余额 + 该客户其他未完成订单（审批中、已审核、部分完成）的金额 + 本单金额（外币折人民币）不能超过信用额度，否则提示「超出客户「…」的信用额度：额度 …，应收余额 …，未完成订单 …，本单 …」，订单不能审核。
- **出库前**：再校验一次（审核后客户可能新增了欠款）：应收余额 + 全部未完成订单金额超过额度时暂停出库，提示「客户「…」超出信用额度，暂停出库……请先收款或调整额度」。
- 没有设置信用额度的客户不限制。客户的信用占用（额度、应收余额、未完成订单）可在客户关系模块的[客户详情](../crm/customer#客户详情-客户-360)中查看。

客户的「账期」决定[应收单](../fin/ar-ap)到期日：出库日期 + 账期天数。

## 库存预留

已审核、部分完成的订单可以在「库存预留」页签为明细预留仓库的空闲库存，保证这些库存不会被其他订单、出库和调拨占用。页签说明：「预留不锁定库位批次，只保证其他订单、出库和调拨不能占用；销售出库时核销本订单的预留，订单完成、关闭或反审核时自动释放。」

- 「预留库存」：逐行选择仓库，显示空闲库存（可用 − 已预留），填写预留数量（不超过未出库且未预留的数量和空闲库存）。
- 「一键预留」：选择仓库（默认订单发货仓库），按明细顺序预留，库存不足的部分不预留。
- 「全部释放」：释放本订单的全部预留。

预留列表显示仓库、物料、预留数量、说明、预留人和时间。需要「库存预留」权限。

## 可承诺量

在订单或报价表单中点物料行下方的「可承诺量」，打开「可承诺量（ATP）」窗口：

- 顶部显示可用库存、已预留、空闲库存、可承诺量（指定了发货仓库时按该仓库，否则按全部仓库）。
- 有需求数量时提示「最早可承诺日期：…」，或「按现有库存和在途供应无法满足该数量」。
- 下方时间线列出采购在途、生产在制（供应 +）和销售待发、工单待领料（需求 −），以及每天的结余。

可承诺量 = 从空闲库存出发按日期累加供应、扣减需求后，今天及以后各日结余的最小值。

## 导入外部订单

电商、门店等外部渠道的订单可以按统一格式导入：

1. 点「导入外部订单」，在对话框中「下载导入模板」。
2. 按模板填写：外部单号*、客户编码*、下单日期*、交货日期、物料编码*、数量*、含税单价、备注（带 * 的必填）。
3. 拖入或选择 .xlsx 文件，点「导入」。

![导入外部订单](/images/manual/scm/sales-import.jpg)

导入规则：

- 同一外部单号的多行合并为一张销售订单（草稿，来源「外部导入」），同一外部单号的客户、下单日期必须一致。
- 含税单价为空时按价目表取价；物料没有价目价时提示「物料「…」没有价目表价格，请填写单价」。
- 外部单号已经导入过的整单跳过（防止重复导入），结果提示「生成 N 张销售订单（草稿），跳过已导入的 M 张：…」。
- 客户编码、物料编码不存在等其他错误时整批不导入，对话框中按行号列出错误。
- 导入的订单记录外部单号，在列表按订单号查询时也能搜外部单号。

外部系统也可以通过接口直接推送订单，规则相同。

## 与其他模块的联动

- **仓库**：发货通知生成[拣货建议](../wms/label-putaway#拣货建议与拣货路径)；出库、退货自动生成仓库单据；[库存预留](../wms/reservation)影响可用库存。
- **财务**：出库生成[应收单](../fin/ar-ap)（到期日按客户账期），退货生成红字应收单。
- **物流**：销售出库单可创建 [物流发运](./shipment) 单。
- **生产**：[主生产计划](../mes/plan#由销售订单生成)可由销售订单生成；已生成生产计划的订单不能反审核，关闭订单时未完成的生产计划一并关闭。
- **客户关系**：[商机赢单](../crm/opportunity#赢单生成销售订单)生成销售订单（来源「商机」）。
- **项目管理**：订单可一键[创建项目](../pm/project#从商机、销售订单创建项目)。
- **[首页待办](../guide/home#待办事项)**：交货日期已过仍未发货的订单计入「销售订单逾期未发货」。

## 注意事项

::: warning 注意
经销商门户提交的订单为草稿，需要内部销售人员审核；审核前经销商可以在门户撤销。
:::

::: tip 提示
订单变更、反审核、关闭、审批等规则与采购订单相同，详见 [采购订单](./purchase)。
:::
