# 送货通知

送货通知（ASN）由供应商在 [供应商门户](../portal/supplier) 中按采购订单发起，告诉我方本次发了哪些货、多少数量、何时到货、物流单号。仓库人员在这里按送货通知收货，按实收数量一键生成采购入库单，不需要再逐行录入。

## 页面入口

供应链 → 采购 → 送货通知

![送货通知列表](/images/manual/scm/asn-list.jpg)

## 列表

**筛选**：状态（待收货 / 已收货 / 已取消）、关键字（送货单号、订单号、供应商、运单号）。

**列表列**：

| 列 | 说明 |
| --- | --- |
| 送货单号 | 下方显示对应的采购订单号 |
| 供应商 | |
| 日期 | 发货日期，下方为预计到货日期 |
| 物流 | 承运商和运单号 |
| 送货数量 | 本次送货的合计数量 |
| 状态 | 已收货的下方显示生成的采购入库单号 |

**行操作**：「查看」；待收货状态且有收货权限时显示「收货」。

## 查看送货通知

详情显示供应商、采购订单、状态、发货日期、预计到货、物流（承运商、运单号）、采购入库单号和收货时间（已收货时）、备注，以及明细（物料、批次、送货数量、备注）。待收货时右上角有「收货」按钮。

## 收货

1. 点「收货」，打开收货对话框，提示「按实收数量生成采购入库单（保存即入库），实收为 0 的明细不入库。序列号物料请在采购入库中收货。」
2. 选择 **收货仓库**（必填，默认采购订单的收货仓库）和 **收货日期**（必填）。
3. 每行显示物料、批次、送货数量，填写 **实收数量**（默认等于送货数量），可选择入库 **库位**。
4. 点「确定」，提示「已收货，已生成采购入库单」。

收货后：

- 自动生成一张 [采购入库单](./purchase-in)（备注「送货通知 + 单号」），保存即确认：更新库存、生成仓库[入库单](../wms/in)和[应付单](../fin/ar-ap)、回写订单进度，需要[来料检验](../qms/inspection#来料冻结与放行)的物料冻结待检。
- 送货通知变为「已收货」，记录入库单号和收货时间。

## 单据状态

| 状态 | 说明 |
| --- | --- |
| 待收货 | 供应商已提交，等待仓库收货；供应商可以在门户取消 |
| 已收货 | 已按实收数量生成采购入库单 |
| 已取消 | 供应商在门户取消 |

## 规则

- 供应商只能为已审核、部分完成且没有被其拒绝的采购订单发起送货；每个明细的送货数量不能超过「未收货且未通知」的数量。
- 收货时订单必须仍是已审核或部分入库状态（已关闭、已完成的订单不能收货）。
- 需要录入序列号的物料不能在这里收货，会提示「物料「…」需要录入序列号，请在采购入库中收货」，请到 [采购入库](./purchase-in) 中按订单入库。
- 批次管理的物料，供应商在送货通知中填写的批次号会带入入库单。

## 消息提醒

供应商提交送货通知后，系统给有收货权限的用户发送站内消息「供应商送货通知」，内容包含采购订单号和预计到货日期。

## 注意事项

::: tip 提示
没有[开通供应商门户](../portal/account#为供应商开通)的供应商不会有送货通知，仓库直接在 [采购入库](./purchase-in) 中按订单入库即可。
:::
