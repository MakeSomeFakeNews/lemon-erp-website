# 采购合同

采购合同记录与供应商约定的价格、期限、数量和金额上限，生效后采购订单可以引用合同下单：明细按合同价锁定，系统自动校验合同期限和数量、金额上限，并跟踪每个物料的下单和入库进度。支持两种合同类型：

| 类型 | 说明 |
| --- | --- |
| 框架协议 | 约定价格与期限，数量按订单执行（可设数量上限、金额上限） |
| 固定数量合同 | 每个物料约定数量，订单累计不超过合同数量 |

[招标采购](./tender) 定标时也可以自动生成固定数量合同（草稿）。

## 页面入口

供应链 → 采购寻源 → 采购合同

![采购合同列表](/images/manual/scm/contract-list.jpg)

## 列表

**筛选**：状态（草稿 / 审批中 / 生效 / 已关闭）、供应商、关键字（合同编号、名称、供应商）。

**列表列**：合同编号 / 名称（点击打开详情）、供应商、类型、期限（生效 ~ 到期；生效但已过到期日的显示「已到期」）、执行金额（已下单金额，下方为金额上限或「金额不限」）、状态。

工具栏有「新增合同」。

## 新增 / 编辑合同

只有草稿可以编辑。

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 合同名称 | 是 | 如「2026 年度包装材料框架协议」 |
| 供应商 | 是 | 不能选停用的供应商 |
| 合同类型 | 是 | 框架协议 / 固定数量合同，下方显示类型说明 |
| 签订日期 | 是 | |
| 金额上限 | 否 | 价税合计，为空不限 |
| 生效日期、到期日期 | 是 | 采购订单的订单日期必须在此期限内才能引用 |
| 付款天数 | 否 | 填写后，引用该合同的订单入库生成的[应付单](../fin/ar-ap)按此计算到期日（入库日期 + 付款天数），不填按供应商账期 |
| 付款条款 | 否 | 如「月结 30 天，承兑汇票」 |
| 备注 | 否 | |

**合同物料**（采购订单引用合同时按合同价下单）：

| 列 | 必填 | 说明 |
| --- | --- | --- |
| 物料 | 是 | 同一物料不能重复 |
| 合同单价（含税） | 是 | |
| 税率 | 否 | |
| 数量上限 | 固定数量合同必填 | 框架协议可不填（不限） |
| 备注 | 否 | |

## 合同详情

![采购合同详情](/images/manual/scm/contract-detail.jpg)

详情显示合同名称、状态、供应商、类型、签订日期、期限、金额（已下单 / 上限）、付款（天数和条款，未填写时显示「按供应商账期」）、来源招标、关闭原因、备注。

**页签**：

- **物料与执行**：每个物料的合同价和税率、执行进度（已下单 / 数量上限，进度条）、已入库数量、已下单金额。
- **采购订单（N）**：引用本合同的订单：订单号、订单日期、金额、入库 / 订单数量、供应商确认、状态。
- **附件**：合同扫描件等。

**按钮**：

| 按钮 | 显示条件 | 作用 |
| --- | --- | --- |
| 审批记录 | 发起过审批 | 查看审批流程和意见 |
| 编辑、删除 | 草稿 | |
| 提交 | 草稿 | 确认「提交合同？发布了审批流程时进入审批，否则直接生效」 |
| 关闭合同 | 生效 | 填写关闭原因（必填），提示「关闭后采购订单不能再引用该合同，已下单的订单不受影响」 |

## 采购订单如何引用合同

1. 在 [采购订单](./purchase) 中选择供应商后，如果该供应商有在订单日期有效的生效合同，表单出现「采购合同」下拉框。
2. 选择合同后，币种固定为人民币；合同中的物料按合同价带出，单价、税率不能修改（显示「合同价」），不在合同中的物料显示「不在合同中」，保存时会被拒绝。
3. 保存和审核订单时校验：
   - 订单日期在合同期限内；
   - 每个物料的累计下单数量不超过数量上限；
   - 累计下单金额不超过合同金额上限。

   「已下单」按引用该合同的非草稿订单计算，已关闭的订单按其已入库数量计算。超出时提示如「物料「…」超出合同数量上限 2000（其他订单已下单 1800）」。

## 单据状态

| 状态 | 说明 |
| --- | --- |
| 草稿 | 可编辑、删除、提交 |
| 审批中 | 已提交审批；拒绝或撤回后回到草稿 |
| 生效 | 采购订单可以引用（在期限内）；可关闭 |
| 已关闭 | 不能再被新订单引用 |

## 审批

在 [流程中心](../workflow/business#供应链) 发布「采购合同审批」流程后，「提交」改为发起审批，流程变量为合同金额、合同类型、合同编号。内置流程为：部门主管 → 合同金额 ≥ 10 万时总经理 → 抄送会计。合同金额取金额上限；没有金额上限时为各物料「数量上限 × 单价」之和。

## 注意事项

::: tip 提示
合同按创建人部门和创建人控制数据权限。合同到期后仍显示为「生效」并标注「已到期」，但订单日期超出期限的订单不能再引用，如需续签请新建合同。
:::
