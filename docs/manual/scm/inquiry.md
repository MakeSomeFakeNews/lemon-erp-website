# 询价比价

询价比价用于一次向多家供应商询价：列出要采购的物料和数量，录入各供应商的报价（含税单价、税率、交期），系统以矩阵方式比价并标出每个物料的最低价，采购员逐行选定中标报价后，可以一键更新供货价格、按中标供应商生成采购订单。

## 页面入口

供应链 → 采购寻源 → 询价比价

![询价比价列表](/images/manual/scm/inquiry-list.jpg)

## 列表

**查询条件**：关键字（询价单号或说明）、状态（询价中 / 已定标 / 已关闭）。

**列表列**：询价单号（点击打开详情）、询价日期、报价截止、状态、物料行数、报价供应商（已报价的供应商数）、制单人、说明、创建时间。

**工具栏**：「新增询价单」、「批量删除」，右侧有导出、刷新等。

**行操作**（行末操作栏中的图标，鼠标悬停显示名称；只有一个操作时显示为图标加文字）：「查看」；询价中且还没有任何报价时可「编辑」；询价中可「删除」。

## 新增询价单

![新增询价单](/images/manual/scm/inquiry-form.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 询价日期 | 是 | 默认今天 |
| 报价截止 | 否 | 过了截止日仍可录入报价，详情中会显示「已过截止日」标签 |
| 说明 | 否 | |

**询价物料**：点「添加物料」，每行填写物料（必填）、数量（必填）、需求日期、备注。

保存后自动打开详情，方便录入报价。录入过报价后物料明细不能再修改。

## 录入报价

在详情底部点「录入报价」：

1. 选择 **供应商**（必填）。
2. 为每个物料填写 **含税单价**（不报价的物料留空）、**税率**（默认为业务参数「[默认税率](../system/biz-rule#默认税率)」，默认 13%；修改报价时为原报价的税率）、**交期**（天，0 ~ 365）、**备注**。供应商的报价都是同一税率时，可以点「税率」列头旁的编辑图标「统一设置税率」，输入税率或点快捷选项（默认税率和各[发票类型](../system/biz-dict#发票类型)的税率）后「应用到全部明细」。
3. 需要时在报价明细下方填写 **整单优惠**（或用「抹零」），见下文[整单优惠承诺](#整单优惠承诺)。
4. 点「确定」，至少要有一行报价。

同一供应商再次录入时覆盖之前的报价和整单优惠承诺。

### 整单优惠承诺

供应商承诺「整单让利 ¥…」「抹零」时，在录入报价窗口的报价明细下方填写「整单优惠」，下方提示「整单优惠承诺按本次报价的合计计算；定标时全部中标带全额到采购订单，部分中标按中标金额比例折算」：

- 优惠按该供应商本次全部报价行的 数量 × 含税单价 合计计算，不能超过报价合计；
- 比价表的供应商列标题下显示「报价合计 ¥…」，有优惠承诺时后面显示「整单优惠 ¥…」，比价时可以把优惠一并考虑；
- 定标生成采购订单时，该供应商的报价全部中标的，优惠全额带到采购订单的[整单优惠](./purchase#整单优惠与抹零)；只中标一部分的，按 中标金额 ÷ 报价合计 折算（四舍五入到分）。

![比价表中的报价合计与整单优惠承诺](/images/manual/scm/inquiry-discount.jpg)

在比价表的供应商列标题上可以「修改报价」或删除该供应商的全部报价。

## 比价与定标

详情中的「比价」表：行是询价物料，列是各报价供应商（标题显示供应商等级），每格为「含税单价 / 交期」、税率和备注，**绿色为该物料的最低价**，没有报价的显示「未报价」。

询价中时，每格前有单选框，**默认选中最低价**，点击其他报价可改选中标报价；最右侧「采购订单」列显示定标后生成的订单号。

点「定标完成」，弹出确认框：

- 显示「已选择 X / Y 行的中标报价，未选择的明细不定标。定标后询价单不能再修改报价。」
- **用中标价更新供应商的供货价格**（默认勾选）：已有该物料的供货价格时更新单价、税率、提前期（阶梯价保留），没有时新建；物料还没有默认供应商时，同时设为默认供应商。
- **按中标供应商生成草稿采购订单**（默认勾选）：按中标供应商合并生成采购订单（来源「询价单」），可选「收货仓库」；供应商有整单优惠承诺时按上文规则带入订单的整单优惠。

完成后询价单变为「已定标」，提示「已定标，生成 N 张采购订单」。生成的采购订单需到 [采购订单](./purchase) 审核。

## 其他操作

- 「编辑」：还没有报价时显示。
- 「关闭」：关闭后不能再录入报价和定标。

## 单据状态

| 状态 | 可以做什么 |
| --- | --- |
| 询价中 | 录入 / 修改报价、定标完成、关闭、删除；没有报价时可编辑 |
| 已定标 | 查看比价结果和生成的采购订单 |
| 已关闭 | 只能查看 |

## 注意事项

::: tip 提示
删除由询价单生成的草稿采购订单后，询价明细恢复为未下单（询价单仍为已定标），可以在采购订单中重新下单。
:::

::: tip 提示
需要密封报价、供应商自行在线投标的场景，请使用 [招标采购](./tender)。
:::
