# 补货建议

补货建议按「再订货点法」检查物料的预计库存，列出低于再订货点、需要补货的物料和建议数量，采购员确认后一键生成请购单。适合常备的原材料、包材、备件等不经过 [MRP](../mes/mrp) 的物料。

## 页面入口

供应链 → 采购 → 补货建议

![补货建议](/images/manual/scm/reorder-list.jpg)

截图中没有数据，表示当前没有物料设置再订货点 / 安全库存，或都不需要补货。

## 计算方法

页面顶部的说明：

- **预计库存** = 可用库存 + 采购在途 + 在制净额（在制产出 − 工单待领料）− 销售待发
- 预计库存低于 **再订货点**（未设置时取安全库存）时建议补货。
- **建议补货数量** 取「再订货量」与「补足到再订货点所需数量」中的较大者，并按默认供应商的最小起订量取整。

再订货点、再订货量、安全库存、供应方式在仓库模块的「[物料管理](../wms/material#生产计划-需要生产计划属性修改权限)」中维护（物料的计划属性）。

## 列表

**查询条件**：物料（编码或名称）。

**工具栏**：

- 「生成请购单（N）」：勾选物料后可用，按勾选行生成请购单。
- 「需求日期（选填）」：生成的请购单明细的需求日期。
- 「只看需要补货」开关：默认打开，只显示需要补货的物料；关闭后显示全部设置了再订货点的物料。
- 右侧有导出（按当前数据导出）、刷新、密度、列设置。

**列表列**：

| 列 | 说明 |
| --- | --- |
| 物料、规格、单位 | |
| 供应方式 | 采购 / 自制 / 委外等 |
| 再订货点 | 下方显示安全库存 |
| 再订货量 | 每次补货的批量 |
| 可用库存 | 不含冻结、寄售仓库存 |
| 采购在途 | 已审核未入库的采购订单数量 |
| 在制净额 | 在制工单产出 − 工单待领料 |
| 销售待发 | 已审核未出库的销售订单数量 |
| 预计库存 | 低于再订货点时标红 |
| 建议补货 | 建议数量 |
| 补货数量 | 勾选后可修改，默认等于建议数量；自制件显示「自制件请在生产计划 / MRP 中安排」，不能生成请购单 |
| 供应商 | 默认显示物料的默认供应商和参考价，勾选后可改为其他供应商 |

## 生成请购单

1. 勾选要补货的物料（只有建议补货数量大于 0 且不是自制件的物料可以勾选）。
2. 按需修改补货数量和供应商，选择需求日期。
3. 点「生成请购单」。补货数量为空时提示「请填写「…」的补货数量」。
4. 生成一张草稿 [请购单](./requisition)（说明为「补货建议生成」），弹窗提示「已按 N 个物料生成请购单（草稿），提交审批后可转采购订单。」，可选择「查看请购单」或「留在本页」。

## 补货提醒

系统定时任务「补货提醒」每天检查一次，有需要补货的物料时，给有补货建议权限的用户发送站内消息「N 个物料低于再订货点」，点击消息进入本页。定时任务可在系统监控的「[定时任务](../monitor/job)」中启停和调整执行时间。

## 注意事项

::: tip 提示
补货建议只生成请购单，不直接下采购订单，请购单仍需提交审批后再「生成采购订单」。由 MRP 管理的物料（尤其是自制件）请在生产计划中统一运算，避免重复补货。
:::
