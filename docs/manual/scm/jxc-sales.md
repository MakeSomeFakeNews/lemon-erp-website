# 销售报表

销售报表把一段时间内的[销售出库与销售退货](./sales-out)按类别、品牌、区域、客户、业务员、商品、日或月汇总，按单据口径显示货款、整单优惠、净额、运费 / 折让 / 坏账、销售金额、成本和毛利。汇总行可以穿透到组成这个数字的**单据**（每张出库单、退货单一行，再看该单的明细），也可以直接穿透到**商品明细**（出入库单的每一行物料），最后点击单据号打开出入库单本身。

## 页面入口

供应链 → 进销存报表 → 销售报表

需要「销售报表」菜单权限，内置角色中超级管理员、总经理、会计、普通用户、销售员拥有，见[进销存报表概述](./jxc#权限)。

![销售报表](/images/manual/scm/jxc-sales.jpg)

## 查询条件

| 条件 | 说明 |
| --- | --- |
| 日期范围 | 必填，默认本月（月初到今天）；快捷选项有「本月」「上月」「本年」「近 12 个月」，最长 366 天。按出入库单的业务日期筛选 |
| 全部客户 | 选择一个客户 |
| 全部业务员 | 选择一个业务员，按销售订单上的业务员筛选 |
| 全部类别 / 全部品牌 | 物料档案上的物料分类、品牌；选择上级分类时包含其所有下级分类 |
| 区域 | 下拉选择客户的区域（业务字典「客户区域」） |
| 全部仓库 | 出库 / 退货的仓库；明细行单独选了仓库时按明细行的仓库，否则按单据表头的仓库 |
| 商品编码 / 名称 | 模糊匹配物料编码或名称，按回车查询 |

修改日期范围或「汇总方式」会立即刷新；修改其他条件后点「**查询**」。

## 汇总方式

页面中部的「汇总方式」决定按什么分行，默认按「客户」：

| 汇总方式 | 分组依据 | 说明 |
| --- | --- | --- |
| 类别 | 物料分类 | 按物料所在的分类分别汇总（下级分类单独成行，不并入上级），显示完整路径；点汇总行查看的明细也只含该分类本身的物料；物料没有设置分类时归入「未设置」 |
| 品牌 | 物料品牌 | 没有品牌时归入「未设置」 |
| 区域 | 客户的区域 | 客户没有填区域时归入「未设置」 |
| 客户 | 出入库单的客户 | |
| 业务员 | 销售订单的业务员 | 订单没有业务员时显示「未指定」。不选订单直接开单时，业务员取开单时选择的业务员，没有选择时取客户负责人，再没有时为制单人 |
| 商品 | 物料 | 显示「编码 名称」 |
| 日 | 业务日期 | 按日期从早到晚排列 |
| 月 | 业务日期所在月份 | 按月份从早到晚排列 |

日、月以外的汇总方式按净额从大到小排列。汇总行最多显示净额最大的 1000 行，超过时表格上方提示「汇总行数较多，只显示净额最大的 1000 行（合计为全部数据）」，此时合计行和顶部指标仍是全部数据的合计。

## 金额口径

单据是存放成本、销售金额、毛利的基本单元。金额都是不含税、本位币，退货为负数，从货款一路减到毛利：

| 步骤 | 计算 | 说明 |
| --- | --- | --- |
| 货款 | 出库货款 − 退货货款 | 整单优惠**前**的不含税金额 |
| 净额 | 货款 − 整单优惠 | 即销售收入，与记账的主营业务收入一致 |
| 销售金额 | 净额 − 本公司运费 − 收款折让 − 坏账核销 | 扣除本公司为这些单据付出的调整项后实际得到的金额 |
| 毛利 | 销售金额 − 成本 | 毛利率 = 毛利 ÷ 销售金额 |

客户承担（代垫）的运费不计入，不影响毛利。运费、折让、坏账在利润表中分别计入销售费用、财务费用、营业外支出，不在营业成本里，利润表的毛利 = 净额 − 成本，所以**与这里的毛利不同**；按期间也不一定一致，因为折让和坏账跟随出库单的业务日期归属（看每张单据的真实收益），不按收款 / 核销日期。口径与财务[经营分析 - 销售毛利](../fin/analysis#销售毛利)相同。

## 指标

顶部显示合计指标：**销售金额**、**毛利**、**毛利率**、**净额**、**价税合计**、**净数量**、**单据数**。鼠标悬停在「销售金额」上提示「销售金额 = 货款 − 整单优惠 − 本公司承担运费 − 收款折让 / 抹零 − 坏账核销（不含税），毛利 = 销售金额 − 成本；运费、折让、坏账在利润表中分别计入销售费用、财务费用、营业外支出，不在营业成本里，所以与利润表的毛利（净额 − 成本）不同」。表格的列：

| 列 | 口径 |
| --- | --- |
| 出库数量 / 退货数量 | 销售出库、销售退货的数量合计（退货为正数） |
| 净数量 | 出库数量 − 退货数量 |
| 出库货款 / 退货货款 | 整单优惠前的不含税金额，本位币 |
| 货款 | 出库货款 − 退货货款 |
| 整单优惠 | 直接开单或订单的[整单优惠 / 抹零](./sales-out#整单优惠与买赠)分摊到这些明细的部分，不含税（行上含税的分摊额按行税率折算）；退货为负数 |
| 净额 | 货款 − 整单优惠 |
| 本公司运费 | 本公司承担的运费，按单据各行金额比例分摊：[销售出库](./sales-out#销售出库的运费)单上「本公司承担」的运费；出库单没有登记运费时，其[物流发运](./shipment#运费承担)单中「本公司承担」的运费（已发货）；[销售退货](./sales-out#销售退货的运费)单上客户代垫的运费。出库单登记了运费时发运单不再计入，同一笔运费只算一次；客户承担（代垫）的不计入 |
| 收款折让 | 出库 / 退货单生成的[应收单](../fin/ar-ap)在[收款时给的折让 / 抹零](../fin/settlement#折让与抹零)（同一单据多次收款时累计，含该单客户代垫运费、退货运费应收单上的折让），按应收单的不含税比例折算，再按单据各行金额比例分摊；退货的红字应收单折让为负数（少退给客户） |
| 坏账核销 | 销售出库单的应收单上已做坏账核销的金额，按应收单的不含税比例折算，再按出库单各行金额比例分摊；退货为 0 |
| 销售金额 | 净额 − 本公司运费 − 收款折让 − 坏账核销 |
| 价税合计 | 含税金额（优惠后）的净额（出库 − 退货） |
| 成本 | 取[实时库存成本](../wms/stock#实时库存成本)：销售出库按出库时的移动加权平均价，销售退货按原出库成本（即[库存流水](../wms/flow)上这一笔的成本金额）；没有实时成本的历史单据（升级前）按所在月份的成本核算单价，仍没有时按参考成本价，并显示橙色「含参考成本」标签，鼠标悬停提示「其中 N 行没有实时出库成本且所在月份尚未核算，按参考成本价计算」 |
| 毛利 | 销售金额 − 成本，负数标红 |
| 毛利率 | 毛利 ÷ 销售金额 |
| 均价 | 净额 ÷ 净数量（不含税），净数量为 0 时为空 |
| 单据数 | 涉及的出入库单张数（出库单和退货单分别计数，同一张单据只算一次） |

数量按物料的基本单位相加，不同单位的物料相加只有参考意义；按「商品」汇总时数量、均价最有意义。

整单优惠按行分摊；运费、折让、坏账按单据归属、按行金额比例分摊，所以按类别、品牌、商品汇总时，每行只含所属明细分摊到的部分，各行相加等于整张单据。没有整单优惠、运费、折让、坏账时，货款 = 净额 = 销售金额。

## 查看明细和单据

汇总行有两种穿透方式，在表格最右侧的「操作」列中各有一个图标（中间竖线分隔）：

| 操作 | 去向 |
| --- | --- |
| **单据** | 进入「〈名称〉· 单据」子页，列出该汇总项下的销售出库单、销售退货单，每张一行；再点击单据查看该单的明细，见[单据列表](#单据列表) |
| **商品明细** | 进入「〈名称〉· 明细」子页，列出该汇总项包含的全部出入库明细，每行一种物料，见[商品明细](#商品明细) |

直接点击汇总行（或行首的蓝色名称）时，按汇总方式决定默认去向：

| 汇总方式 | 点击汇总行默认打开 | 原因 |
| --- | --- | --- |
| 类别、品牌、商品 | 商品明细 | 与商品直接相关，看是哪些商品行最直观 |
| 区域、客户、业务员、日、月 | 单据列表 | 与商品没有直接关系，先看由哪几张单据组成，再看单据里的商品 |

不想用默认去向时，点操作列中的另一个图标即可。汇总页表格上方的「**全部单据**」「**全部明细**」不限汇总行，按当前查询条件列出全部单据或全部明细。

两个子页的查询条件（日期范围、客户、业务员、类别、品牌、区域、仓库、商品）都与汇总页相同；汇总项为「未设置」「未指定」的行同样可以穿透。

### 单据列表

单据列表中每张出库单或退货单一行，顶部显示日期范围和口径说明，右上角「**导出**」：

| 列 | 说明 |
| --- | --- |
| 日期 | 业务日期 |
| 单据号 | 后面的标签显示单据类型（销售出库 / 销售退货） |
| 客户、业务员 | |
| 仓库 | 单据表头的仓库 |
| 行数 | 该单中属于本汇总项的明细行数 |
| 数量 | 这些明细行的数量合计，退货为负数 |
| 货款 | 整单优惠前的不含税金额 |
| 整单优惠 | 这些明细行分摊到的整单优惠，**不含税**（货款 − 整单优惠 = 净额）；退货单为负数 |
| 净额 | 货款 − 整单优惠 |
| 价税合计 | 含税金额（优惠后） |
| 本公司运费、收款折让、坏账核销 | 该单中这些明细行分摊到的金额，口径同汇总；收款折让为该单应收单的折让（多次收款累计）按这些明细分摊的部分，不按商品等筛选时即整张单据的折让 |
| 销售金额 | 净额 − 本公司运费 − 收款折让 − 坏账核销 |
| 成本、毛利、毛利率 | 毛利 = 销售金额 − 成本，口径同汇总；有按参考成本价计算的行时在成本后显示「含参考成本」标签 |
| 备注 | 单据备注 |

口径与汇总行完全一致：金额是该单中**属于本汇总项的明细行**合计，退货单的数量、金额为负数。按类别、品牌、商品汇总时，同一张单据只计入匹配的商品行，例如一张出库单有 A、B 两个类别的商品，在 A 类别的单据列表中只计 A 类商品的金额，两个类别加起来等于整张单据。表格底部的合计行是全部单据（不只是当前页）的合计，等于汇总页上这一行的数字；单据数等于汇总行的「单据数」。

![销售报表按客户汇总后的单据列表](/images/manual/scm/jxc-sales-docs.jpg)

- 点击单据（整行任意位置）或操作列的「商品明细」图标，进入「〈名称〉/ 〈单号〉· 明细」子页，列出这张单据中属于本汇总项的明细（按类别等汇总时只含匹配的商品），列同下文的商品明细；从「全部单据」进入时标题为「〈单号〉· 明细」。
- 操作列的「查看单据」图标直接打开出库单或退货单的详情。
- 「导出」导出全部单据（不只是当前页），比列表多「单据类型」列，最多 5000 行。

### 商品明细

商品明细中每行是出入库单的一行物料，退货行的数量、金额为负数。子页右上角可以切换整单优惠、本公司运费、收款折让、坏账核销这些**调整项**的显示方式（鼠标悬停提示「整单优惠、本公司运费、收付款折让、坏账核销的显示方式，两种方式合计相同」）：

| 显示方式 | 说明 |
| --- | --- |
| **调整项汇总到底部**（默认） | 明细行按单据上的原价显示，不分摊调整项；整单优惠、本公司运费、收款折让、坏账核销按类别汇总在表格底部，各占一行 |
| **分摊到各行** | 调整项按行金额比例分摊到每一行，每行列出从货款到毛利的全部金额 |

两种方式下明细的合计相同，都等于汇总行的销售金额与毛利。选择的方式记在本机浏览器，销售报表、[进货报表](./jxc-purchase)和财务[经营分析](../fin/analysis#销售毛利)的明细共用。日期范围后面显示当前方式的说明。

两种方式共有的列：

| 列 | 说明 |
| --- | --- |
| 日期 | 业务日期 |
| 单据号 | 点击打开单据详情，后面的标签显示单据类型（销售出库 / 销售退货） |
| 客户、业务员 | |
| 商品 | 编码、名称，下方显示规格 |
| 类别、品牌、仓库 | |
| 数量 | 带单位，退货为负数 |
| 成本 | 口径同汇总；按参考成本价计算的行（没有实时出库成本、且所在月份尚未核算）在成本后显示「参考成本」标签 |
| 备注 | 明细行备注 |

**调整项汇总到底部**时的金额列：

| 列 | 说明 |
| --- | --- |
| 优惠前单价 | 出入库单上的含税单价（整单优惠前） |
| 优惠前价税合计 | 优惠前的含税金额 |
| 销售金额 | 该行的货款（优惠前的不含税金额），行上不扣调整项 |
| 毛利 | 货款 − 成本 |

表格底部在合计行之前，按类别各列一行调整项（只列出有金额的类别），商品列显示类别名称：

| 调整行 | 含义 |
| --- | --- |
| 整单优惠 | 这些单据的整单优惠 / 抹零（不含税） |
| 本公司承担运费 | 本公司为这些单据承担的运费 |
| 收款折让 / 抹零 | 这些单据的应收单在收款时给的折让 / 抹零 |
| 坏账核销 | 这些单据的应收单上做的坏账核销 |

调整行的销售金额为负数、成本为 0、毛利等于销售金额（也为负数）；退货单方向相反，例如只看退货单时整单优惠一行为正数（少退的优惠）。合计行 = 明细行 + 调整行 = 单据口径的销售金额与毛利，与汇总行一致。调整行和合计行放在表格底部，每一页都能看到，分页总数只计商品行。

从单据列表点某张单据进入时，底部调整行就是这张单据的调整项。**按商品、类别、品牌、仓库筛选**（含按类别、品牌、商品汇总后穿透）只看到单据的一部分时，调整行按所选明细的比例计算：整单优惠取所选行的分摊额，运费、折让、坏账按所选明细占单据的金额比例。例如某商品占一张出库单金额的 60%，调整行就是该单整单优惠、运费、折让、坏账的 60%，与按商品汇总时该商品的行一致。

**分摊到各行**时的金额列：含税单价、货款、整单优惠、净额、价税合计、本公司运费、收款折让、坏账核销、销售金额、毛利，各项含义同汇总，运费、折让、坏账按行金额比例分摊；没有调整行，合计行即各行之和。

### 打开单据与返回

在商品明细中点击单据号，打开销售出库或销售退货的详情页，可以查看订单号、仓库单据、库位批次、序列号，并「打印」。

每一层都是一个子页，左上角有「返回」，逐层回到上一层，汇总页的查询条件和汇总方式保持不变：

- 经单据：汇总 →「客户A · 单据」→「客户A / 单号 · 明细」→ 单据详情；
- 直接看明细：汇总 →「类别A · 明细」→ 单据详情。

## 导出

- 汇总页「**导出汇总**」：把当前汇总表（含合计行）导出为 Excel，文件名包含汇总方式和日期范围。
- 明细子页「**导出明细**」：导出当前明细的全部行（不只是当前页），比明细表多「单据类型」「编码」「单位」列，列随显示方式变化；调整项汇总到底部时，明细行之后依次是调整行和合计行，与页面一致；最多导出 5000 行，超过时提示「数据较多，只导出了前 5000 行」，请缩小日期范围或增加筛选条件。
- 单据子页「**导出**」：导出该汇总项下的全部单据，每张一行，比单据列表多「单据类型」列，最后一行为合计；同样最多 5000 行。

## 注意事项

::: tip 提示
- 本报表实时查询，录入出库单后刷新即可看到；和[经营驾驶舱](../bi/cockpit)、[多维分析](../bi/olap)对不上时，先看它们的数据仓库是否已同步。
- 货款、净额、销售金额都是不含税的，与[应收单](../fin/ar-ap)（含税）不同；需要含税金额时看「价税合计」。
- 这里的毛利已扣除运费、收款折让和坏账，与利润表的毛利（净额 − 成本）不同，对账时用「净额」与利润表的主营业务收入核对。
- 成本和毛利用的是出库时的实时成本，财务「[经营分析](../fin/analysis)」的毛利按月末[成本核算](../fin/cost#实时库存成本与月末核算)的单价（用于记账），两者可能不同。
- 统计口径的完整说明见[进销存报表概述](./jxc#统一的统计口径)，数字对不上的常见原因见[常见问题](../faq/#进销存报表的数字和其他报表对不上)。
:::
