# 波次拣货

波次拣货把同一仓库的多张待拣货 [发货通知](./delivery) 合并成一个波次，拣货员按一张汇总拣货单沿[库位路径](../wms/label-putaway#拣货建议与拣货路径)走一遍，先拣出每个库位的合计数量，再按「分拣」分到各张发货通知，减少往返。完成拣货后，各发货通知一次性变为已拣货，可以分别出库。

## 页面入口

供应链 → 销售 → 波次拣货

![波次拣货列表](/images/manual/scm/wave-list.jpg)

## 生成波次

在 [发货通知](./delivery) 列表勾选 **同一仓库** 的待拣货通知，点「生成波次」。一个波次只能包含同一仓库的发货通知，已在其他波次中的通知不能再加入。生成时按当前库存重新生成各通知的拣货建议。

## 列表

**筛选**：状态（拣货中 / 已完成 / 已取消）、仓库、关键字（波次号、发货通知号）。页面提示「在「发货通知」中勾选同一仓库的待拣货通知生成波次」。

**列表列**：波次号（下方为创建时间）、仓库、发货通知（张数，下方为合计数量）、状态、备注、操作（拣货中显示「拣货」，其他显示「查看」）。

## 波次详情

![波次详情](/images/manual/scm/wave-detail.jpg)

顶部显示仓库、状态、发货通知张数、创建人。有库存不足时显示提示，如「库存不足（完成拣货时跳过）：FH… IPC-3000 缺 2 台。补货后点「重新生成建议」，或把通知移出波次」。

**页签**：

- **拣货单（N）**：按库位路径（区域 → 排序 → 编码）排列，每行为一个库位 + 物料 + 批次：序号、库位（及区域）、物料、批次（及有效期）、合计数量、分拣（各发货通知号 × 数量）。说明：先按行拣出合计数量，再按「分拣」放入各发货通知。
- **发货通知（N）**：波次中的通知：通知单号、销售订单、客户、数量、状态；拣货中时待拣货的通知可「移出」波次。

**按钮**（拣货中）：

| 按钮 | 作用 |
| --- | --- |
| 打印拣货单 | 打印「波次拣货单」：仓库、包含的发货通知、拣货明细和分拣，签字栏为制单、拣货、复核 |
| 取消波次 | 未拣货的发货通知移出波次，波次变为已取消 |
| 重新生成建议 | 库存变化后，按当前库存重新生成各通知的拣货建议 |
| 完成拣货 | 按拣货单确认各发货通知的拣货 |

## 完成拣货

点「完成拣货」，确认后：

- 按拣货建议确认波次中各待拣货通知的拣货，这些通知变为「已拣货」，可以出库。
- **库存不足** 的通知、**含序列号物料** 的通知会跳过，仍为待拣货：前者补货后可加入新波次，后者须在发货通知中单独录入序列号拣货。
- 结果提示「已完成 N 张发货通知的拣货」，有跳过时列出跳过的通知和原因。
- 波次变为「已完成」。

没有任何可以完成拣货的通知时，提示「没有可以完成拣货的发货通知：…」，波次保持拣货中。

## 单据状态

| 状态 | 说明 |
| --- | --- |
| 拣货中 | 可移出通知、重新生成建议、完成拣货、取消 |
| 已完成 | 已完成拣货 |
| 已取消 | 未拣货的通知已移出 |

## 注意事项

::: tip 提示
波次只负责拣货。拣货完成后，请到各张发货通知中「出库」生成销售出库单，并按需装箱。
:::
