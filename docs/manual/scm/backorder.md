# 欠交清单

欠交清单汇总所有还没有执行完的订单明细：客户欠交（销售订单未出库）和供应商欠交（采购订单未入库），显示未完成数量、交货日期、逾期天数。销售欠交同时显示已预留和可用库存，标出缺货的明细，方便销售、计划、采购人员每天跟单催货。

## 页面入口

供应链 → 销售 → 欠交清单

![欠交清单](/images/manual/scm/backorder-list.jpg)

## 查询与切换

**查询条件**：客户 / 供应商（随类型切换）、关键字（订单号、物料编码或名称）。

**工具栏**：

- 「客户欠交」/「供应商欠交」：切换欠交类型。
- 「只看逾期」：只显示交货日期已过的明细。
- 右侧导出 Excel，文件名分别为「客户欠交」「供应商欠交」。

## 列表列

| 列 | 说明 |
| --- | --- |
| 订单号、订单日期 | |
| 客户 / 供应商 | |
| 物料、单位 | |
| 订单数量 | 下方显示已出库 / 已入库数量 |
| 未出库 / 未入库 | 订单数量 − 已完成 + 退货补发 / 补收 |
| 交货日期 | 明细的交货日期（为空时同订单） |
| 逾期天数 | 已逾期显示红色「逾期 N 天」，未到期显示「N 天后到期」 |
| 已预留 | 仅客户欠交：该明细已预留的库存 |
| 可用库存 | 仅客户欠交：该物料的可用库存；可用库存不够发未预留的部分时显示红色「缺货」标签 |
| 制单人 | |
| 操作 | 仅客户欠交：「可承诺量」，查看该物料的可承诺量和最早可承诺日期，见 [销售订单](./sales#可承诺量) |

只统计已审核、部分完成的订单；已完成、已关闭的订单不会出现在清单中。

## 用法

- 销售人员：每天查看「客户欠交 + 只看逾期」，对缺货的明细查看可承诺量，回复客户新的交期；必要时 [预留库存](./sales#库存预留)。
- 采购人员：查看「供应商欠交 + 只看逾期」，联系供应商催货；有门户的供应商可在订单中查看其承诺交期。

::: tip 提示
欠交清单只读，处理欠交请到对应的订单中操作（出库、入库、变更交期或关闭订单）。
:::
