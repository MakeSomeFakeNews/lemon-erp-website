# 渠道库存

渠道库存用于查看经销商在 [经销商门户](../portal/dealer#库存销量上报) 中按月上报的「当月销量」（卖给终端客户的数量）和「月末库存」，并计算库存可售月数，帮助销售人员判断经销商是否压货、何时需要补货。本页面只读，数据由经销商上报。

## 页面入口

供应链 → 销售 → 渠道库存

![渠道库存列表](/images/manual/scm/channel-list.jpg)

## 列表

**筛选**：关键字（经销商、区域）、月份（全部月份或指定月份）。页面提示「经销商在门户按月上报的当月销量和月末渠道库存」。

**列表列**：

| 列 | 说明 |
| --- | --- |
| 经销商 | 客户名称，下方为授权区域 |
| 月份 | 上报的月份 |
| 产品数 | 上报的产品种数 |
| 当月销量 | 各产品销量合计 |
| 月末库存 | 各产品库存合计 |
| 上报 | 上报时间和上报人 |
| 操作 | 「查看」 |

## 上报详情

![渠道上报详情](/images/manual/scm/channel-detail.jpg)

详情标题为「经销商 + 月份 + 渠道上报」，显示经销商、授权区域、上报时间和人、当月销量、月末库存、说明，以及每个产品的当月销量、月末库存和 **库存可售**（月末库存 ÷ 当月销量，单位「个月」；当月没有销量时不显示）。

## 规则

- 只有销售渠道为「经销商」的客户才能开通经销商门户并上报，见 [客户](./customer)。
- 同一经销商同一月份重复上报时覆盖之前的数据；不能上报以后的月份。
- 经销商可上报的产品为其可订货清单（价目表中适用的物料），以前上报过但已不在清单中的产品也会保留。

## 注意事项

::: tip 提示
库存可售月数偏高说明经销商库存积压，可以暂缓推单或配合 [促销活动](./promotion) 消化库存；偏低则提示经销商及时补货。
:::
