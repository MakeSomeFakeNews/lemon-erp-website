# 寄售结算

寄售是「货先放过去，用了 / 卖了再结算」的业务模式，本页面处理两种寄售的结算：

| 页签 | 业务 | 结算后 |
| --- | --- | --- |
| 客户寄售结算 | 本公司把货物放在客户处（客户寄售仓），客户售出后再结算 | 生成已审核的销售订单（来源「寄售结算」）并从寄售仓销售出库，形成应收和销售成本 |
| 供应商寄售结算（VMI） | 供应商把货物放在本公司（供应商寄售仓），领用后再结算 | 生成已审核的采购订单（来源「寄售结算」），采购入库到自有仓库形成应付，同时寄售仓做寄售消耗出库 |

## 准备工作

1. 在仓库模块的「[仓库管理](../wms/warehouse#仓库类型)」中建立寄售仓：仓库类型选「客户寄售仓」并关联客户，或「供应商寄售仓」并关联供应商。寄售仓的库存 **不计入可用库存**。
2. 客户寄售：用仓库的[调拨单](../wms/transfer)把货物从自有仓库调拨到客户寄售仓，货物仍是本公司存货。
3. 供应商寄售：供应商的货物到货后在仓库模块做「[寄售入库](../wms/in)」到供应商寄售仓，不计入本公司存货成本。

## 页面入口

供应链 → 销售 → 寄售结算

![客户寄售结算](/images/manual/scm/consign-customer.jpg)

没有寄售结算权限的用户只能查看寄售仓库存，页面顶部提示「没有寄售结算权限（scm:consign:settle），只能查看寄售仓库存」。

## 客户寄售结算

页签提示：「客户寄售：先把货物调拨到客户寄售仓（仍是本公司存货），客户售出后在此结算，生成销售订单并从寄售仓出库（形成应收）。单价为含税单价，不填按销售价目表。」

1. 选择 **客户寄售仓**（必填）、**业务日期**（必填，默认今天），填写备注。
2. 下方「寄售仓库存」表列出该寄售仓的库存，可按物料编码或名称筛选：物料、库位 / 批次、寄售库存（有冻结时显示冻结数量）。
3. 在需要结算的行填写 **售出数量**（不超过寄售库存）、**含税单价**（空为价目表）、**税率**（空为默认）；序列号物料须录入与数量相同个数的序列号。标题处显示「已填 N 行，合计 …」。
4. 点「结算售出」，确认「共 N 行、数量 …，将生成销售订单及出入库单据。」。
5. 完成后显示「结算完成，已生成销售订单」，可点「查看销售订单」。

客户寄售生成的销售订单直接为已审核，不走审批、不校验信用额度，不应用促销。

## 供应商寄售结算（VMI）

![供应商寄售结算](/images/manual/scm/consign-supplier.jpg)

页签提示：「供应商寄售（VMI）：供应商的货寄售入库到供应商寄售仓（不计成本），领用后在此结算，生成采购订单、采购入库到自有仓库（形成应付），寄售仓做寄售消耗出库。单价为含税单价，不填按供货价格。」

1. 选择 **供应商寄售仓**（必填）、**转入仓库**（必填，结算后采购入库到该自有仓库，不能选寄售仓）、**业务日期**、备注。
2. 在寄售库存中填写 **领用数量**、含税单价（空为供货价格）、税率、序列号。
3. 点「结算领用」确认。
4. 完成后显示「结算完成，已生成采购订单」，以及「寄售仓已生成寄售消耗出库单」。

## 结算后的单据

| 业务 | 生成的单据 |
| --- | --- |
| 客户寄售 | 已审核的销售订单 → 从客户寄售仓的 [销售出库单](./sales-out) → [应收单](../fin/ar-ap) |
| 供应商寄售 | 已审核的采购订单 → 到自有仓库的 [采购入库单](./purchase-in) → 应付单；寄售仓的寄售消耗出库单 |

## 注意事项

::: tip 提示
寄售结算生成的订单和出入库单与普通业务一样可以查看、打印、退货，在订单列表中带「寄售」标签。
:::
