# 经营状况

经营状况用一页图表回答「这段时间生意怎么样」：销售和毛利按月怎么走、钱进来多少出去多少、每个业务员卖了多少、销售集中在哪些客户。

## 页面入口

供应链 → 进销存报表 → 经营状况

需要「经营状况」菜单权限，内置角色中超级管理员、总经理、会计、普通用户拥有，见[进销存报表概述](./jxc#权限)。

![经营状况](/images/manual/scm/jxc-business.jpg)

## 查询条件

页面顶部只有**日期范围**，默认本年（1 月 1 日到今天），快捷选项「本月」「上月」「本年」「近 12 个月」，最长 731 天。修改后自动刷新，也可以点「**刷新**」。

## 指标卡片

| 卡片 | 口径 |
| --- | --- |
| 销售净额 | 期间内销售出库 − 销售退货的不含税金额，同[销售报表](./jxc-sales)的「净额」合计 |
| 毛利 | 销售净额 − 成本，成本口径同[销售报表](./jxc-sales)：取出库时的实时库存成本（与财务月末核算的毛利可能不同） |
| 毛利率 | 毛利 ÷ 销售净额 |
| 收款 | 期间内已生效的[收款单](../fin/settlement)金额（按收款日期）+ [预收款](../fin/advance)金额（按预收日期） |
| 付款 | 期间内已生效的付款单金额（按付款日期）+ 预付款金额（按预付日期）。审批中、已拒绝的付款单不计入 |
| 净流入 | 收款 − 付款 |

金额以「万」为单位简写显示，鼠标悬停在图表上可看到具体值。销售净额、毛利、毛利率按你的数据权限统计；收款、付款、净流入是全公司数据，只有数据权限为「全部数据」的用户才显示这三张卡片。

## 图表

| 图表 | 内容 |
| --- | --- |
| **销售及利润走势** | 日期范围内每个月一组：柱为销售净额，折线为毛利；没有销售的月份显示为 0 |
| **资金流走势** | 每个月的收款（绿色柱）、付款（橙色柱）和净流入（折线），口径同上方卡片。数据权限不是「全部数据」时，此处显示「资金流汇总全公司数据，需要「全部数据」的数据权限」 |
| **员工销售情况** | 按销售订单的业务员汇总：条形图显示净额前 10 名的销售净额和毛利；下方表格列出全部业务员的净额、毛利、毛利率、单据数，订单没有业务员的显示为「未指定」 |
| **客户销售分布** | 环形图和表格列出净额前 10 名客户，其余合并为「其他客户」；表格列为客户、净额、占比（该客户净额 ÷ 全部销售净额）、毛利、毛利率。右上角显示「共 N 个客户，列出净额前 10 名」 |

## 查看单据和明细

「员工销售情况」「客户销售分布」的表格最右侧有「**单据**」「**商品明细**」两个图标，与[销售报表的两种穿透](./jxc-sales#查看明细和单据)相同：

- **单据**：该业务员 / 客户在当前日期范围内的销售出库单、销售退货单，每张一行，合计等于表格中这一行的净额、毛利；点击单据再看该单的明细，见[单据列表](./jxc-sales#单据列表)。
- **商品明细**：该业务员 / 客户的全部出入库明细，见[商品明细](./jxc-sales#商品明细)。

业务员、客户与商品没有直接关系，所以直接点击业务员或客户名称时默认打开单据列表。「其他客户」是合并行，不能穿透。可以继续点击单据号查看单据，单据列表、明细都可以导出。需要「销售报表」权限，没有时名称不能点击，也不显示操作列。

::: tip 提示
- 收款、付款统计的是实际收付的资金（含预收预付），与销售净额的口径不同：销售按出库确认，收款按收到钱的日期，两者在时间上不一一对应。需要查看具体收付款单时到[收款单与付款单](../fin/settlement)和[预收预付](../fin/advance)中查询。
- 本页面实时计算，录入单据后点「刷新」即可看到变化。
:::
