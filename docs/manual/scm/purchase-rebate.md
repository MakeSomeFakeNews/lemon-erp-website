# 采购返利

采购返利是与供应商约定的、**供应商给我方**的返利协议：在一个期间内，我方向该供应商的采购额达到某一档，供应商按该档返利率返还；也可以按品牌、系列或活动直接约定返利金额。期间结束后结算，生成红字[应付单](../fin/ar-ap)冲减欠供应商的货款，付款时勾选即可抵扣。采购员维护协议，会计、总经理结算。

给客户的返利请使用[销售返利](./rebate)，两者的协议格式和操作相同，区别见文末对照表。

## 页面入口

供应链 → 采购 → 采购返利

![采购返利列表](/images/manual/scm/purchase-rebate-list.jpg)

## 列表

**筛选**：关键字（协议号、供应商）、状态（执行中 / 已结算）。

**列表列**：协议（协议号，下方为供应商）、期间、计算方式、返利（已结算时显示返利金额，阶梯比例方式下方显示「采购额 × 返利率」）、状态（已结算时下方显示「红字应付 单号」）、操作「查看」。

工具栏有「新增采购返利协议」。

## 新增 / 编辑采购返利协议

![新增采购返利协议 - 按项目填写金额](/images/manual/scm/purchase-rebate-form.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 供应商 | 是 | 不能选停用的供应商 |
| 开始日期、结束日期 | 是 | 返利期间 |
| 兑付方式 | | 固定为**红字应付**：结算后生成红字应付单冲减对供应商的应付款，付款时勾选即可抵扣。采购返利不能在采购订单中抵扣 |
| 计算方式 | 是 | **阶梯比例**（默认）或**按项目填写金额** |
| 返利阶梯 | 阶梯比例时必填 | 每档填写「采购额达到」和「返利率」（0.01% ~ 100%），点「添加一档」增加，最多 20 档，各档金额不能重复 |
| 返利项目 | 按项目填写金额时必填 | 每行填写返利项目（如品牌、系列或活动名称）、品牌和物料分类（可选）、返利金额（大于 0），点「添加项目」增加，最多 100 项；右上角显示合计 |
| 说明 | 否 | |

计算方式：

- **阶梯比例**：期间采购额（入库 − 退货，含税）达到的最高一档返利率 × 全部采购额。与销售返利一样，按达到的档位乘以**全部**采购额，不是分段累进。
- **按项目填写金额**：直接填写各项目的返利金额，结算时按合计返利，不按公式计算；期间采购额只作参考。

只有执行中的协议可以编辑、删除。

## 协议详情

![采购返利协议详情](/images/manual/scm/purchase-rebate-detail.jpg)

详情显示供应商、期间、状态、兑付方式（红字应付）、计算方式、创建人和说明：

- **执行中**：按截至今天的数据显示「预估返利」（期间结束后为「应返利」）；阶梯比例方式显示「下一档」（如「再采购 ¥… 达到 3%」或「已达到最高一档」），按项目填写金额方式显示「期间采购额」供参考。
- **已结算**：显示结算日期、返利金额、红字应付单号。

下方为「返利阶梯」表（当前达到的一档标记「当前」）或「返利项目」表。

**按钮**：

| 按钮 | 显示条件 | 作用 |
| --- | --- | --- |
| 删除、编辑 | 执行中 | |
| 结算 | 执行中；期间结束后才可点击（之前提示「期间结束后才能结算」） | 确认「期间采购额 ¥…，结算返利 ¥…，确定？」 |
| 撤销结算 | 已结算 | 确认「撤销结算：删除红字应付单（须未核销、未生成凭证），确定？」 |

## 结算与财务处理

- 期间采购额 = 该供应商在期间内的采购入库金额 − 采购退货金额（含税、人民币）。阶梯比例方式没有达到任何一档时不能结算。
- 结算后由财务模块生成来源为「返利」的红字应付单，金额为返利金额的负数，税额按业务参数「[默认税率](../system/biz-rule#默认税率)」（默认 13%）价内计算。
- 红字应付单在[应付管理](../fin/ar-ap)中生成凭证：借 应付账款 / 贷 采购返利的对方科目（默认 6401 主营业务成本，冲减成本）、进项税额（进项税额转出）。对方科目可在[凭证科目设置](../fin/account-rule#折让与冲账科目)的「采购返利的对方科目（冲减成本）」中修改，例如改为在库存商品或其他业务收入下设的明细科目。
- 向该供应商付款时，在[付款单](../fin/settlement)中勾选这张红字应付单，即可与欠款相抵，少付相应金额。

撤销结算的条件：红字应付单还没有核销、没有生成凭证。

## 销售返利与采购返利对照

| 项目 | 销售返利 | 采购返利 |
| --- | --- | --- |
| 菜单 | 供应链 → 销售 → 销售返利 | 供应链 → 采购 → 采购返利 |
| 对象 | 客户 | 供应商 |
| 期间金额 | 销售出库 − 销售退货 | 采购入库 − 采购退货 |
| 兑付方式 | 红字应收，或下次订单抵扣 | 只能红字应付 |
| 财务结果 | 红字应收单（冲减收入、销项税额）或客户返利余额 | 红字应付单（冲减成本、进项税额转出） |
| 协议号 | FL 开头 | CFL 开头 |

::: tip 提示
没有签订返利协议、临时谈下来的供应商返利或赔偿，也可以登记[冲账单](../fin/offset)（应付冲账），复核后同样生成红字应付单。
:::
