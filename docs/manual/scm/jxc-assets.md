# 资产状况

资产状况显示**此时此刻**公司有多少钱、多少货、别人欠多少、欠别人多少，以及由此推算的净资产。它不按日期范围统计，打开即是当前时点的实时数据。

## 页面入口

供应链 → 进销存报表 → 资产状况

需要「资产状况」菜单权限，内置角色中超级管理员、总经理、会计、出纳拥有，见[进销存报表概述](./jxc#权限)。

资产状况汇总全公司数据，还要求数据权限为「全部数据」，否则打开时提示「经营驾驶舱、决策分析汇总全公司数据，需要「全部数据」的数据权限」。

![资产状况](/images/manual/scm/jxc-assets.jpg)

页面顶部显示「数据时点：今天的日期（实时）」和口径说明，点「**刷新**」重新计算。

## 指标卡片

| 卡片 | 口径 |
| --- | --- |
| 现金 | 编码以 1001（库存现金）开头的资金科目的当前余额 |
| 银行存款 | 其他资金科目（银行存款等）的当前余额合计 |
| 库存 | 当前库存数量 × 最新单位成本的合计。最新单位成本取该物料最近一期[成本核算](../fin/cost)的单价，从未核算过的取物料档案的参考成本价；不含供应商寄售仓（寄售货物属于供应商） |
| 应收账款 | 全部[应收单](../fin/ar-ap)未核销完的余额（金额 − 已核销金额）合计，红字应收单冲减。卡片下方显示「其中逾期 …」：到期日早于今天的部分 |
| 预付款 | 预付款中还没有冲抵应付的余额 |
| 应付账款 | 全部应付单未核销完的余额合计 |
| 预收款 | 预收款中还没有冲抵应收的余额 |
| 净资产 | 现金 + 银行存款 + 库存 + 应收账款 + 预付款 − 应付账款 − 预收款 |

::: warning 注意
这里的「净资产」是用经营数据快速估算的，只包含上面七项，不含固定资产、其他应收应付、借款、税费等，**不等于**资产负债表中的所有者权益。正式的财务数据请看[财务报表](../fin/report)。
:::

## 明细区域

| 区域 | 内容 |
| --- | --- |
| **资金** | 每个资金账户（科目编码 + 名称）的当前余额，负数标红。余额取自凭证，**包含未记账的凭证**，与[出纳管理](../fin/cashier)「资金日报」的余额一致；已生效但还没有生成凭证的收付款单不在其中 |
| **库存（按仓库）** | 各仓库库存金额的环形图，不含供应商寄售仓 |
| **库存（按类别）** | 按物料分类的库存金额环形图，没有分类的显示为「未设置」 |
| **应收余额前 10 名** | 应收余额最大的 10 个客户及金额（只列余额大于 0 的） |
| **应付余额前 10 名** | 应付余额最大的 10 个供应商及金额 |

::: tip 提示
- 库存金额用的是「最新单位成本」，与[成本核算](../fin/cost)的期末结存金额、[经营分析](../fin/analysis)「存货对账」中的科目余额可能不同：后两者是某个期间的核算结果，这里是当前数量乘最新单价的估算值。
- 资金余额来自凭证，收付款单要先生成凭证才会反映到资金余额中。
:::
