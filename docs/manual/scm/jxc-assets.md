# 资产状况

资产状况显示截至某一天公司有多少钱、多少货、别人欠多少、欠别人多少，以及由此推算的净资产。默认是今天的实时数据，也可以选择过去的**截至日期**，查看当天日终的状况（例如上月末、上年末），用来和当前比较。

## 页面入口

供应链 → 进销存报表 → 资产状况

需要「资产状况」菜单权限，内置角色中超级管理员、总经理、会计、出纳拥有，见[进销存报表概述](./jxc#权限)。

资产状况汇总全公司数据，还要求数据权限为「全部数据」，否则打开时提示「经营驾驶舱、决策分析汇总全公司数据，需要「全部数据」的数据权限」。

![资产状况](/images/manual/scm/jxc-assets.jpg)

## 截至日期

页面右上角的「**截至日期**」默认今天，不能选今天之后的日期；日期选择框中有「今天」「上月末」「上年末」快捷选项。选择后立即重新计算，点「**刷新**」可再次计算。

- 截至今天时页面顶部显示「截至 日期（实时）」，结果与各模块当前的余额（资金日报、库存查询、应收应付）一致；
- 选择过去的日期时显示「截至 日期 日终」：**业务日期晚于截至日的单据都不计入**，截至日之后发生的收付款核销、冲抵也不扣减。

页面顶部的灰色文字是口径说明，下面可能出现两种提示：

| 提示 | 含义 |
| --- | --- |
| 截至日有 N 笔已生效的收付款还没有生成凭证（收款 …、付款 …），资金余额不含这些收付款，生成凭证后计入。 | 资金余额来自凭证，请在[收款单 / 付款单](../fin/settlement)中生成凭证（票据业务生成的收付款不计入这个笔数） |
| 截至日早于实时库存成本上线，库存金额用到了升级前按成本核算单价 / 参考成本价回填的近似成本，仅供参考。 | 截至日较早，涉及系统升级到实时库存成本之前的历史流水，库存金额是近似值 |

## 指标卡片

| 卡片 | 口径 |
| --- | --- |
| 现金 | 编码以 1001（库存现金）开头的资金科目在截至日的余额 |
| 银行存款 | 其他资金科目（银行存款等）在截至日的余额合计 |
| 库存 | 截至日的库存金额，即库存流水成本的累计（按单据的业务日期）。计算时以当前库存 × 实时移动加权均价为基准，倒推减去截至日之后的流水，截至今天时与[库存查询](../wms/stock)的库存金额一致；不含供应商寄售仓（寄售货物属于供应商） |
| 应收账款 | 单据日期不晚于截至日的[应收单](../fin/ar-ap)金额（退货、冲账单、订单尾差调整等红字 / 蓝字单据直接增减）减去截至日之前的核销（收款核销、核销折让、预收冲抵、坏账核销）。卡片下方显示「其中逾期 …」：到期日早于截至日的部分 |
| 应收票据 | 截至日仍持有的应收票据票面金额（已收票，未贴现、托收、拒付，也没有背书转让）。没有票据时不显示 |
| 预付款 | 截至日之前支付的预付款减去截至日之前冲抵应付的金额 |
| 应付账款 | 口径同应收账款 |
| 应付票据 | 截至日已开出（付款已生效）、还没有兑付的应付票据票面金额。没有票据时不显示 |
| 预收款 | 截至日之前收到的预收款减去截至日之前冲抵应收的金额 |
| 净资产 | 现金 + 银行存款 + 库存 + 应收账款 + 应收票据 + 预付款 − 应付账款 − 应付票据 − 预收款 |

冲账单、返利结算、[订单关闭的尾差调整](./sales#分批出库与关闭时的尾差)等只调整应收应付，不改变出入库单金额，因此不影响销售、进货报表，只体现在这里的应收应付中。收付款时的折让、抹零同样冲减应收应付、不改变出入库单金额，销售额 / 进货额不变，[销售报表](./jxc-sales)、[进货报表](./jxc-purchase)另列收付款折让和扣除后的毛利 / 净进货额作为参考。订单上的[整单优惠](./sales#整单优惠与抹零)已经从出入库金额中扣除，应收应付本来就是优惠后的金额。

::: warning 注意
这里的「净资产」是用经营数据快速估算的，只包含上面几项，不含固定资产、其他应收应付、借款、税费等，**不等于**资产负债表中的所有者权益。正式的财务数据请看[财务报表](../fin/report)。
:::

## 明细区域

| 区域 | 内容 |
| --- | --- |
| **资金** | 每个资金账户（科目编码 + 名称）在截至日的余额，负数标红。余额取自凭证，**包含未记账的凭证**，与[出纳管理](../fin/cashier)「资金日报」的余额一致；已生效但还没有生成凭证的收付款单不在其中（见上文提示） |
| **库存（按仓库）** | 截至日各仓库库存金额的环形图，不含供应商寄售仓 |
| **库存（按类别）** | 按物料分类的库存金额环形图，没有分类的显示为「未设置」 |
| **应收余额前 10 名** | 截至日应收余额最大的 10 个客户及金额（只列余额大于 0 的） |
| **应付余额前 10 名** | 截至日应付余额最大的 10 个供应商及金额 |

::: tip 提示
- 库存金额按实时库存成本（移动加权平均）计算，与[成本核算](../fin/cost)的期末结存金额、[经营分析](../fin/analysis)「存货对账」中的科目余额可能不同：后两者是月末一次加权平均的核算结果。
- 资金余额来自凭证，收付款单要先生成凭证才会反映到资金余额中。
- 查看过去的截至日时，如果之后又补录了业务日期更早的单据，结果会随之变化。
:::
