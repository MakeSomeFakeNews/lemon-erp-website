# 请购单

请购单是业务部门向采购部门提出的物料需求，写明需要什么物料、多少数量、什么时候要，可以建议供应商。请购单提交审批，批准后由采购员一键按供应商合并生成采购订单。[补货建议](./reorder) 也会生成请购单。

## 页面入口

供应链 → 采购 → 请购单

![请购单列表](/images/manual/scm/requisition-list.jpg)

## 列表

**查询条件**：关键字（请购单号或说明）、状态。

**列表列**：请购单号（点击打开详情）、请购日期、状态、明细行数、请购部门、制单人、批准时间、说明、创建时间。

**工具栏**：「新增请购单」、「批量删除」（只能勾选草稿）；右侧有导出 Excel（按当前查询条件）、显示 / 隐藏查询区、刷新、密度、列设置。

**行操作**：「查看」；草稿状态另有「编辑」「删除」。

## 新增 / 编辑请购单

点击「新增请购单」，只有草稿可以编辑。

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 请购日期 | 是 | 默认今天 |
| 请购说明 | 否 | 如用途、项目，最多 255 字 |

**明细**（点「添加物料」增加行）：

| 列 | 必填 | 说明 |
| --- | --- | --- |
| 物料 | 是 | 选择物料 |
| 数量 | 是 | 最多 4 位小数，显示物料单位 |
| 需求日期 | 否 | 生成的采购订单明细交货日期 |
| 建议供应商 | 否 | 不填时生成采购订单使用物料的默认供应商 |
| 备注 | 否 | |

请购部门取制单人所在部门。保存后自动打开详情，方便接着提交。

## 请购单详情

![请购单详情](/images/manual/scm/requisition-detail.jpg)

详情显示请购单号、请购日期、请购部门、制单、批准时间、说明，以及明细（物料、数量、需求日期、建议供应商、已生成的采购订单号）。

- 审批中时提示「请购单审批中，可在「流程中心 → 我的申请」查看审批进度，审批通过后自动变为已批准」。
- 已批准时提示「生成采购订单时按建议供应商拆分，未指定建议供应商的明细使用物料的默认供应商」。

**底部按钮**：

| 按钮 | 显示条件 | 作用 |
| --- | --- | --- |
| 编辑 | 草稿 | 修改请购单 |
| 关闭 | 草稿、已批准 | 关闭后不能再生成采购订单 |
| 提交 | 草稿 | 发布了审批流程时发起审批，否则直接批准 |
| 生成采购订单 | 已批准，且有下单权限 | 弹出「生成采购订单」对话框，可选「收货仓库」（选填，入库时默认），确定后生成草稿采购订单 |

## 生成采购订单的规则

1. 一次处理全部还没有下单的明细。
2. 按供应商合并：明细的建议供应商为空时取物料的默认供应商；两者都没有时提示「物料「…」没有建议供应商和默认供应商，请先指定供应商」，需先编辑请购单或在供应商的供货价格中设置默认供应商。
3. 单价按该供应商的供货价格带出（有阶梯价时按数量取档），没有供货价格的单价为 0，需在订单中补填。订单日期为当天，交货日期取这些明细中最早的需求日期，备注为「请购单 + 单号」。
4. 生成的订单为草稿，来源为「请购单」，需到 [采购订单](./purchase) 审核。
5. 生成后请购单变为「已下单」，提示「已生成 N 张采购订单」。

删除由请购单生成的草稿采购订单后，对应明细恢复为未下单，请购单恢复为「已批准」，可以重新生成。

## 单据状态

| 状态 | 可以做什么 |
| --- | --- |
| 草稿 | 编辑、删除、提交、关闭 |
| 审批中 | 等待审批；拒绝或撤回后回到草稿 |
| 已批准 | 生成采购订单、关闭 |
| 已下单 | 已生成采购订单，只能查看 |
| 已关闭 | 只能查看 |

## 审批

在 [流程中心](../workflow/business#供应链) 发布「请购单审批」流程后，「提交」改为发起审批（流程变量：请购单号），通过后变为已批准。未发布时提交即批准。

## 注意事项

::: tip 提示
请购单只用于需求申请，不影响库存和财务。物料是否需要补货可以先看 [补货建议](./reorder)，那里可以直接按计算结果生成请购单。
:::
