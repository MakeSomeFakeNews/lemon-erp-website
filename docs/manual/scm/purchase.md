# 采购订单

采购订单是向供应商下达的正式订货单据，记录供应商、物料、数量、含税单价、交货日期和收货仓库。订单审核（或审批）通过后才能入库，入库、退货的进度自动回写到订单上。采购员日常在这里下单、跟踪到货，采购主管负责审核。

除手工新增外，采购订单还可以由 [请购单](./requisition)、[询价比价](./inquiry)、[招标采购](./tender) 定标、生产模块的 [MRP 运算](../mes/mrp)和[齐套分析](../mes/kit#缺料下单)缺料下单、[寄售结算](./consign) 自动生成。

## 页面入口

供应链 → 采购 → 采购订单

![采购订单列表](/images/manual/scm/purchase-list.jpg)

## 列表

**查询条件**：订单号、供应商、状态、物料（编码或名称，查找包含该物料的订单）、订单日期范围。点「展开」显示全部条件。

**列表列**：

| 列 | 说明 |
| --- | --- |
| 订单号 | 点击打开订单详情。订单变更过时显示版本标签（如「V2」）；由 MRP 生成的显示「MRP」标签，寄售结算生成的显示「寄售」标签 |
| 供应商 | 供应商名称，下方为编码 |
| 订单 / 交货日期 | 订单日期，下方为交货日期 |
| 价税合计 | 订单金额。外币订单显示币种符号，下方显示币种和汇率 |
| 状态 | 草稿 / 审批中 / 已审核 / 部分完成 / 已完成 / 已关闭 |
| 入库进度 | 进度条和「已入库数量 / 订单数量」 |
| 收货仓库、制单人、备注、创建时间 | |

**工具栏**：

- 「新增采购订单」：打开新增表单。
- 「批量删除」：勾选后删除，只有草稿订单可以勾选。
- 右侧为显示 / 隐藏查询区、刷新、表格密度、列设置。

**行操作**：

- 「查看」：打开订单详情。
- 「编辑」：草稿订单显示。
- 「入库」：已审核、部分完成的订单显示，直接打开以该订单为来源的 [采购入库](./purchase-in) 表单。

## 新增 / 编辑采购订单

点击「新增采购订单」，表单占满内容区。只有草稿状态的订单可以编辑。

![新增采购订单](/images/manual/scm/purchase-form.jpg)

### 表头字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 供应商 | 是 | 选择启用的供应商。选择后自动加载该供应商的供货价格和可引用的采购合同，已录入的明细按新供应商重新带出单价。供应商评估等级为 D 时显示提醒「该供应商评估等级为 D（待改进），请谨慎下单或更换供应商」 |
| 订单日期 | 是 | 默认今天。外币订单修改日期后按新日期重新带出汇率 |
| 交货日期 | 否 | 明细未单独填写交货日期时使用订单的交货日期 |
| 收货仓库 | 否 | 入库时默认使用的仓库，停用的仓库不能选 |
| 采购合同 | 否 | 该供应商在订单日期有效的生效合同存在时才显示。引用合同后按合同价下单，币种固定为人民币，并校验合同期限和数量、金额上限，详见 [采购合同](./contract) |
| 币种 | 是 | 默认人民币。选择外币后显示「汇率」 |
| 汇率 | 外币时必填 | 「1 外币 = ? 人民币」，默认取「[币种汇率](../fin/currency#汇率)」中订单日期所在月的汇率，可以修改；没有维护汇率时需手工填写 |
| 备注 | 否 | 最多 255 字 |

管理员在「系统管理 → [自定义字段](../system/custom-field)」中为「采购订单」定义了扩展字段时，表单中还有「扩展信息」分区，必填的扩展字段不填不能保存；订单详情中同样显示这些字段。

### 明细

点击「添加物料」增加一行，标题栏实时显示行数、合计数量和价税合计（外币订单同时显示折合人民币金额）。多规格物料可以点「按规格录入」批量添加，见下文。

| 列 | 必填 | 说明 |
| --- | --- | --- |
| 物料 | 是 | 搜索选择启用的物料，支持扫码。选择后自动带出单价、税率 |
| 数量 | 是 | 启用序列号管理的物料只能为整数。物料设置了辅助单位时，可以在数量右侧切换单位（如「箱」），下方提示折算后的基本单位数量。低于供货价格的最小起订量时显示黄色提示（只提示，不阻止保存） |
| 含税单价 | 是 | 按所选单位的单价。引用合同且物料在合同中时显示「合同价」并锁定不能修改；物料不在合同中时提示「不在合同中」。下方显示「上次 ¥…（日期）」：该供应商这个物料最近一次的成交价，点击金额即改用该价格。单价高于物料的最高采购价时显示红字提示，见下文「价格控制」 |
| 税率 | 否 | 默认 13%，随供货价格或合同带出 |
| 价税合计 | - | 自动计算：数量 × 含税单价，下方显示税额 = 价税合计 × 税率 ÷（100 + 税率） |
| 交货日期 | 否 | 为空时同订单交货日期 |
| 备注 | 否 | |

每行右侧的删除按钮删除该行。

### 单价从哪里来

1. **引用了采购合同**：合同中的物料按合同价（单价、税率锁定）。
2. **没有引用合同**：按供应商的 [供货价格](./supplier#供货价格) 带出，过期的价格不再带出；设置了阶梯价时，按采购数量取达到的最高一档。
3. 外币订单：供货价格按人民币维护，带出时按汇率折算为外币（保留 4 位小数）。
4. **历史成交价**：没有合同价和供货价格时，自动带出该供应商这个物料最近一次的成交价（取已审核、部分完成、已完成、已关闭的采购订单，不含赠品行；只在币种相同时自动带出）。有供货价格时也会在单价下方显示「上次 ¥…（日期）」供参考，点击即可使用。
5. 手工修改过的单价不会被自动覆盖；更换供应商时会按新供应商重新带出全部明细的单价。

### 按规格录入

采购[多规格物料](../wms/material#多规格物料与-sku)时，点明细右上角的「**按规格录入**」：

1. 在弹窗中搜索并选择款式（按编码或名称，只列出启用的款式）；
2. 款式使用两个规格属性时显示为矩阵（如行为颜色、列为尺码），在格子中填写各 SKU 的数量，右侧显示行合计；一个或三个属性时逐行填写；底部显示「合计数量」。该款式还没有生成 SKU 时提示「该款式还没有生成 SKU」；
3. 点「添加到明细」，数量大于 0 的每个 SKU 加入一行明细，并按普通添加物料的方式自动带出单价、税率。停用的 SKU 不会加入。

![按规格录入](/images/manual/scm/sales-matrix.jpg)

款式本身不能直接选作明细物料，订单中保存的都是具体的 SKU。

### 价格控制

在「供应链 → 销售 → [销售价目表](./price-list#价格控制)」的「价格控制」中可以为物料设置**最高采购价**（含税、按基本单位、人民币）：

- 明细的单价（折算为基本单位和人民币后）高于最高采购价时，单价下方显示红字「高于最高采购价 ¥…」；
- 控制方式为「提示」的只提示，可以保存；为「禁止保存」的提示后面加「，不能保存」，保存时提示「「物料」单价 … 高于最高采购价 …」，订单不能保存；
- 校验在手工新增和编辑订单时进行；由请购单、MRP 等自动生成的订单在生成时不校验，之后编辑保存时校验。

### 保存时的校验

- 供应商、仓库、物料必须是启用状态。
- 序列号物料数量必须为整数；选择的辅助单位必须是物料已维护的单位。
- 外币订单必须有汇率。
- 引用合同时：订单日期在合同期限内、物料在合同中、累计下单不超过合同数量上限和金额上限。
- 设置了「禁止保存」的价格控制时，单价不能高于最高采购价。

保存成功后自动打开订单详情，方便接着审核。

## 订单详情

点击订单号或「查看」打开详情，右上角有「打印」按钮和状态标签。

![采购订单详情](/images/manual/scm/purchase-detail.jpg)

**基本信息**：订单号（含版本）、供应商、订单日期、交货日期、收货仓库、来源（手工、MRP、生产缺料、请购单、询价单、招标、寄售结算等）、价税合计和税额、币种 / 汇率（外币）、采购合同（引用时）、供应商确认（审核后显示供应商在门户的确认结果：已接受及承诺交期、已拒绝及原因，或「未确认」）、制单、审核、备注。

审批中的订单显示提示「订单审批中，可在「流程中心 → 我的申请」查看审批进度，审批通过后自动变为已审核」。

**页签**：

| 页签 | 内容 |
| --- | --- |
| 订单明细 | 物料、数量（按辅助单位下单时显示如「2 箱（24 个）」）、含税单价和税率、价税合计、交货日期、执行进度（进度条、已入库、已退货数量） |
| 采购入库记录 / 采购退货记录 | 本订单的入库单、退货单：单据号、业务日期、仓库、数量、价税合计、仓库单据号、制单人 |
| 委外用料 | 订单中有委外件（物料属性为委外且有默认 BOM）时，可做委外发料、委外退料，查看加工商处结存；收货时按单位用量自动核销用料 |
| 单据追溯 | 列出由本订单产生的出入库、应收应付、收付款与凭证、来料检验等下游单据（按当前用户的权限显示），点击凭证号可查看凭证 |
| 附件 | 上传、下载订单附件（有编辑权限时可上传、删除） |
| 变更记录 | 订单变更单及其新旧值 |
| 修改历史 | 草稿阶段各次修改的字段变化 |

**底部操作按钮**（按状态和权限显示）：

| 按钮 | 显示条件 | 作用 |
| --- | --- | --- |
| 编辑 | 草稿 | 打开编辑表单，保存后回到详情 |
| 审核 | 草稿 | 确认后：发布了审批流程时发起审批（订单变为审批中），否则直接审核通过 |
| 撤回审批 | 审批中 | 撤销审批流程，订单回到草稿 |
| 反审核 | 已审核（还没有任何入库） | 订单回到草稿，可以修改 |
| 关闭 | 已审核、部分完成 | 关闭后不能再入库，已完成部分不受影响 |
| 变更 | 已审核、部分完成 | 打开订单变更，见下文 |
| 采购退货 | 部分完成、已完成、已关闭 | 打开以本订单为来源的采购退货表单 |
| 采购入库 | 已审核、部分完成 | 打开以本订单为来源的采购入库表单 |

**打印**：按「采购订单」打印模板打印，包含供应商、日期、收货仓库、金额、明细，以及制单、审核、供应商确认签字栏。打印模板可在系统管理的「[打印模板](../system/print-template)」中调整。

## 单据状态

| 状态 | 含义 | 可以做什么 |
| --- | --- | --- |
| 草稿 | 新建或被反审核、审批拒绝 / 撤回 | 编辑、删除、审核 |
| 审批中 | 已发起审批 | 撤回审批；等待审批 |
| 已审核 | 审核通过，还没有入库 | 入库、反审核、关闭、变更 |
| 部分完成 | 有明细部分入库 | 继续入库、退货、关闭、变更 |
| 已完成 | 所有明细都已入库 | 退货 |
| 已关闭 | 手工关闭 | 退货 |

状态由系统根据入库、退货自动计算：所有明细的未完成数量为 0 时为「已完成」，有过入库为「部分完成」，否则为「已审核」。未完成数量 = 订单数量 − 已入库 + 退货补收数量。退货选择「补收」时，订单恢复相应的未完成数量，状态可能从已完成回到部分完成；选择退款时不影响订单状态。

## 审核与审批

- 在 [流程中心](../workflow/business#供应链) 发布「采购订单审核」流程后，点「审核」改为发起审批，审批通过后订单自动变为已审核，审核人记为最后审批的人；拒绝或撤回后回到草稿。条件分支可以使用「订单金额」（价税合计），例如金额超过一定数额时增加总经理审批。
- 没有发布流程时，点「审核」直接审核通过。
- 审核通过后，系统给该供应商的门户账号发送站内消息「新采购订单待确认」，供应商在 [供应商门户](../portal/supplier) 接受或拒绝订单，结果会通知制单人，并显示在订单详情的「供应商确认」中。
- 引用了采购合同的订单在审核时再次校验合同的数量、金额上限。

## 订单变更

已审核、部分完成的订单不能直接编辑，需要通过「变更」修改：

1. 在订单详情点「变更」，打开变更页面，提示「修改未完成明细的数量、单价、交货日期，删除未执行的明细或新增明细……」。
2. 填写 **变更原因**（必填）。
3. 在「现有明细」中修改「新数量」「新含税单价」「新交货日期」，或勾选「删除」。新数量不能小于已完成数量（已入库 − 退货补收），已有出入库或退货的明细不能删除，只能改数量；修改后的行标记「已修改」或「删除」。
4. 在「新增明细」中点「新增明细」追加物料。
5. 点「提交变更」。发布了「订单变更审批」流程时进入审批，审批通过后生效；否则立即生效。

变更生效后订单版本加 1（列表和详情显示 V2、V3……），「变更记录」页签保留每次变更的新旧值。同一订单同时只能有一张审批中的变更单；订单已关闭时变更不能生效。

## 与其他模块的联动

- **仓库**：入库、退货自动生成已确认的仓库单据，见 [采购入库与采购退货](./purchase-in)。
- **质量**：需要[来料检验](../qms/inspection#来料冻结与放行)的物料入库后冻结为待检，检验合格放行；采购退货优先退冻结的不合格 / 待检库存。
- **财务**：入库生成[应付单](../fin/ar-ap)，退货生成红字应付单；应付单到期日按供应商账期，引用了约定付款天数的采购合同时按合同。
- **[供应商门户](../portal/supplier#我的订单)**：审核通过通知供应商确认；供应商按订单发起 [送货通知](./asn)。
- **生产**：[MRP 运算](../mes/mrp)按物料的默认供应商合并生成采购订单（来源 MRP）；[齐套分析](../mes/kit#缺料下单)缺料下单生成采购订单（来源 生产缺料）。
- **[首页待办](../guide/home#待办事项)**：交货日期已过仍未到货的订单计入「采购订单逾期未到货」待办。

## 注意事项

::: tip 提示
订单中只能删除草稿。已审核但还没有入库的订单，如需修改可先「反审核」回到草稿；已经有入库的订单请使用「变更」。
:::

::: warning 注意
反审核只能在还没有任何入库时进行；关闭订单不可恢复，关闭后只能做退货。删除由请购单、询价单生成的草稿订单后，请购单恢复为「已批准」、询价明细恢复为未下单，可以重新生成订单。
:::

## 常见问题

**选择物料后没有带出单价？** 该供应商没有维护这个物料的供货价格，或价格已过期、未生效。可在 [供应商](./supplier) 的「供货价格」中维护。

**审核时提示超出采购合同的数量或金额上限？** 合同已下单数量（非草稿的引用订单，关闭的订单按已入库数量计）加本单超过了上限，需调整数量或与供应商补签合同。

**外币订单的入库金额是多少？** 订单单价、金额为原币；入库单和应付单按订单汇率折算为人民币，同时保留原币金额，成本和凭证都按人民币。
