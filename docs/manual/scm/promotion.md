# 促销活动

促销活动在一段时间内对指定客户等级、物料或物料分类给予优惠，支持三种类型：**折扣**、**满减**、**买赠**。手工新建 / 修改销售订单、经销商在[门户](../portal/dealer#我要订货)订货时，系统按订单日期和客户等级自动应用，销售人员按原价录入即可，表单中实时预览促销价和赠品。

## 页面入口

供应链 → 销售 → 促销活动

![促销活动列表](/images/manual/scm/promotion-list.jpg)

## 列表

**筛选**：促销名称、类型、「只看今天有效的」。

**列表列**：

| 列 | 说明 |
| --- | --- |
| 促销 | 名称，下方为期间 |
| 类型 | 折扣 / 满减 / 买赠 |
| 规则 | 如「9.5 折（满 10 个）」「满 ¥20,000 减 ¥800」「每买 10 赠 防静电屏蔽袋 × 2」 |
| 适用 | 物料或「X 类物料」或「全部物料」，下方为适用的客户等级或「全部客户」 |
| 应用 | 已应用的订单数，下方为累计优惠金额或赠品数量 |
| 状态 | 已停用 / 已结束 / 未开始 / 进行中 |

**工具栏**：「新增促销」。

**行操作**：「查看」「编辑」「停用 / 启用」（需促销编辑权限）。

## 新增 / 编辑促销

![新增促销](/images/manual/scm/promotion-form.jpg)

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 促销名称 | 是 | |
| 类型 | 是 | 折扣 / 满减 / 买赠，切换后显示对应的规则字段 |
| 开始日期、结束日期 | 是 | 按销售订单的 **订单日期** 判断是否在促销期内 |
| 客户等级 | 否 | 不选适用全部客户 |
| 物料分类 | 否 | 选了物料时按物料，分类不可选 |
| 适用物料 | 否 | 不选按分类；物料和分类都不选时适用全部物料 |
| 说明 | 否 | |

**规则字段**：

| 类型 | 字段 | 说明 |
| --- | --- | --- |
| 折扣 | 折扣率（必填） | 成交价 = 原价 × 折扣率，如 90 为九折；须大于 0、小于 100 |
| | 起订数量 | 明细数量达到时才打折，不填不限 |
| 满减 | 满（必填） | 适用物料的金额（折扣后）达到该金额 |
| | 减（必填） | 减免金额，按行金额分摊到各适用明细的单价 |
| 买赠 | 每购买（必填） | 适用物料每买 N 个 |
| | 赠品（必填） | 赠送的物料 |
| | 赠送数量（必填） | 每 N 个赠送 M 个 |

## 应用规则

表单底部提示：「手工新建、修改销售订单时按订单日期自动应用」。一张订单的计算顺序：

1. **折扣**：每行取所有适用折扣中最低的成交价。
2. **满减**：适用物料（折扣后）金额达到门槛的满减中，只取减免最多的一个，按行金额分摊到单价。
3. **买赠**：按适用物料数量计算赠品数量，自动加入单价为 0 的赠品行（标记「赠品」）。
4. **返利抵扣**：如果订单填写了返利抵扣，按非赠品行金额分摊到单价，见 [销售返利](./rebate)。

订单明细保留原价和所应用的促销名称，订单记录「促销优惠」合计；促销活动记录每张订单的优惠金额和赠品数量，修改订单时重新计算。

自动应用的范围：手工新建 / 修改的销售订单、经销商门户订单。由销售报价转单、外部订单导入、[CRM 商机赢单](../crm/opportunity#赢单生成销售订单)、寄售结算生成的订单不自动应用促销。

## 促销详情

点「查看」打开详情：类型、期间、状态、规则、适用范围、应用订单数、优惠合计、赠品合计、说明，以及「应用记录」（订单号、客户、订单日期、订单状态、优惠金额、赠品数量）。详情右上角有「删除」「编辑」。

## 注意事项

::: warning 注意
已经应用到订单的促销不能删除（提示「促销「…」已应用到订单，不能删除，可以停用」），请改为停用。停用后新订单不再应用，已应用的订单不受影响，除非重新修改订单。
:::

::: tip 提示
在销售订单表单中录入原价即可，表单上方绿色提示框会显示「促销优惠 ¥…，成交价合计约 ¥…」及各促销说明，保存时按订单日期重新计算。
:::
