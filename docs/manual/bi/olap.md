# 多维分析

多维分析是一个自助式的透视分析工具：选择一个数据集（分析主题），指定按什么维度分行、分列，看哪些指标，限定日期范围和筛选条件，系统即时生成透视表和图表；点击行上的维度值可以逐级下钻。常用的分析配置可以保存为报表，供以后打开或组合到仪表盘。

## 页面入口

商务智能 → 多维分析

![多维分析](/images/manual/bi/olap.jpg)

页面打开时默认选择「销售分析」数据集、行维度「月份」、日期范围「近 12 个月」并自动查询一次。

## 分析配置

| 配置项 | 说明 |
| --- | --- |
| **数据集** | 分析主题，见下方「数据集与维度、指标」。切换数据集时会清空列维度、指标、筛选和下钻记录，行维度默认改为「月份」（库存分析为第一个维度） |
| **行维度** | 必选。透视表的每一行是该维度的一个取值，图表的横轴也是行维度 |
| **列维度** | 可选，默认「不分列」。选择后透视表按列维度的每个取值展开为多组列，最后一组为行合计；不能与行维度相同 |
| **指标** | 可多选，不选时显示该数据集的全部指标 |
| **日期范围** | 本月、本季度、本年、近 12 个月、全部、自定义；选择「自定义」时出现日期区间选择框。库存分析此处显示为「快照日期」 |
| 「查询」 | 按当前配置重新查询 |
| 「保存为报表」 | 把最近一次查询的配置保存为报表，需要先查询出结果，需要「报表新增」权限 |
| 「更新报表」 | 从报表打开时显示（仅限自己创建的报表），用当前配置覆盖原报表，需要「报表修改」权限 |

日期范围的含义：本月为本月 1 日至今天；本季度为本季度第一天至今天；本年为 1 月 1 日至今天；近 12 个月为 11 个月前的 1 日至今天；全部为不限日期。销售、采购按业务日期筛选；生产、财务、人力、客户经营、项目按月份筛选；库存按快照日期筛选。

::: tip 提示
库存分析选择「全部」日期且不按「快照日期」分行或分列时，只统计**最新一次**快照，页面会显示提示「库存分析不选日期且不按快照日期分组时，只统计最新一次快照」。要看库存变化趋势，请把「快照日期」设为行维度。
:::

## 数据集与维度、指标

| 数据集 | 维度 | 指标 |
| --- | --- | --- |
| **销售分析** | 年、季度、月份、客户、销售负责人、物料、物料分类、仓库、部门、客户等级、客户行业 | 数量、销售额、销售成本、毛利、毛利率、出库单数、客户数 |
| **采购分析** | 年、季度、月份、供应商、物料、物料分类、仓库 | 数量、采购额、平均单价、入库单数、供应商数 |
| **库存分析** | 快照日期、仓库、物料、物料分类 | 库存数量、库存金额、物料种数 |
| **生产分析** | 年、季度、月份、产品、物料分类、工单状态、部门 | 工单数、计划数量、完工数量、报废数量、报工工时、延期工单、完工率、报废率 |
| **财务分析** | 年、季度、月份、会计科目、科目类别、部门 | 借方发生额、贷方发生额、借贷差额 |
| **人力分析** | 年、季度、月份、部门、岗位类别 | 月末人数（按月累加）、入职、离职、离职率、应发工资、人工成本（含单位社保公积金） |
| **客户经营分析** | 年、季度、月份、负责人、部门 | 新增线索、跟进次数、新增商机、赢单、输单、赢单率、赢单金额 |
| **项目分析** | 年、季度、月份、项目、部门、项目经理 | 工时、人工成本、费用（含领料）、确认收入、结转成本、毛利、毛利率 |

指标口径要点：

- 销售额、采购额均为**不含税金额**，退货以负数冲减；销售成本按物料单位成本计算（见[经营驾驶舱](./cockpit)的口径说明）。
- 生产分析只统计已下达的工单（不含草稿）；**延期工单**指完工晚于计划完工日期，或未完工且已超过计划完工日期的工单。
- 财务分析只统计已记账[凭证](../fin/voucher)，不含[期末结转](../fin/period)损益凭证。
- 人力分析按月统计最近 24 个月：月末人数为每月月末在职人数，跨月汇总时是各月人数相加（因此标注「按月累加」）；工资只统计已确认、已发放的[工资表](../hr/payroll)。
- 项目分析的工时、人工成本只统计已审批的[工时](../pm/timesheet)，费用只统计已审批的[项目费用](../pm/cost)（含项目领料），收入与结转成本来自[项目月结](../pm/accounting#项目月结)。
- **比率指标**（毛利率、平均单价、完工率、报废率、离职率、赢单率）在汇总后按“分子合计 ÷ 分母合计”计算，不是各行比率的平均值；分母为 0 时显示「-」。毛利率、完工率等为百分比，平均单价保留 4 位小数。
- 出库单数、客户数、供应商数等计数指标在合计行中按去重计算，合计不一定等于各行相加。

## 图表

图表卡片的标题为「图表指标 · 按行维度」，右上角可切换「柱状图」「折线图」「饼图」。

- 图表只展示一个指标：选择了指标时取第一个，未选择指标时优先取第一个金额类指标。
- 设置了列维度时，柱状图 / 折线图中每个列维度取值为一个系列；饼图只按行合计显示。
- 点击柱子或折线上的点等同于点击对应行的维度值，会触发下钻。

## 透视表

透视表标题后显示本次查询的日期区间和行数。每一行是一个行维度取值，有列维度时按「列维度取值 × 指标」展开，最后一组「合计」为行合计；表格底部为合计行。维度值为空时显示「(空)」。

## 下钻

1. 在透视表右上角「点击行维度的值钻取到」中选择下钻的目标维度。系统会给出默认目标：年 → 季度 → 月份；其他维度优先钻取到「物料」，没有物料维度的数据集钻取到「月份」。
2. 点击透视表中行维度的值（蓝色链接），或点击图表中的柱子 / 数据点。
3. 系统把点击的值加入筛选（例如「客户：深圳智造」），行维度切换为目标维度并重新查询。

下钻后配置区下方会出现筛选标签：

| 操作 | 作用 |
| --- | --- |
| 点击筛选标签上的「×」 | 去掉这一个筛选条件并重新查询 |
| 「返回上一级」 | 恢复下钻前的行维度、列维度和筛选 |
| 「清除筛选」 | 清除全部筛选和下钻记录 |

## 保存为报表

![保存为报表](/images/manual/bi/olap-save.jpg)

1. 查询出满意的结果后，点「保存为报表」。
2. 填写表单：

| 字段 | 说明 |
| --- | --- |
| 报表名称 | 必填，最多 64 个字符，例如「近 12 个月销售趋势」 |
| 默认图表 | 柱状图、折线图、饼图、表格，默认为当前图表类型；预览和仪表盘中默认使用这个图表 |
| 共享给所有人 | 默认关闭。共享后其他用户可以查看、在仪表盘中使用，只有你可以修改 |
| 说明 | 选填，最多 255 个字符 |

3. 点「确定」，提示「已保存，可在「自定义报表」和「自定义仪表盘」中使用」。

报表保存的是**分析配置**（数据集、行列维度、指标、日期范围、筛选），不是查询结果。打开报表时按当前数据重新计算；日期范围为「本月」「近 12 个月」等相对范围时会随时间自动滚动。

从[自定义报表](./report)点「分析」打开报表时，配置区下方显示「报表：名称」标签；修改配置并查询后，可点「更新报表」覆盖保存。

## 数据权限

多维分析的结果按当前用户的[数据权限](../guide/permission#数据权限的-5-种范围)过滤（数据权限为「全部数据」时不过滤）：

| 数据集 | 过滤依据 |
| --- | --- |
| 销售分析 | 出库单的部门，或客户的负责人 |
| 生产分析、财务分析、人力分析 | 部门 |
| 客户经营分析 | 部门，或负责人 |
| 项目分析 | 部门，或项目经理 |
| 采购分析、库存分析 | 不区分部门 |

## 常见问题

**提示「暂无数据：调整条件后查询，或先在「数据仓库」中同步数据」？** 当前条件下没有数据，可以放宽日期范围、去掉筛选，或先到[数据仓库](./etl)同步。

**为什么刚审核的出库单没有统计进来？** 多维分析读取数据仓库，需要同步后才能看到新数据。
