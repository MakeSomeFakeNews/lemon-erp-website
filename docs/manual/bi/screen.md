# 数据大屏

数据大屏把生产、仓储、销售、质量的实时数据做成适合电视和大显示器观看的深色大屏，分为**生产车间**、**生产进度**、**仓储物流**、**销售经营**、**质量管理**五块。大屏可以全屏显示、多块轮播，生产车间、生产进度大屏还可以只显示某个工作中心。车间、仓库的电视可以通过**投屏链接**免登录打开大屏，开机即显示，不会因登录过期而退出。

## 页面入口

商务智能 → 数据大屏

![数据大屏](/images/manual/bi/screen.jpg)

页面分为两部分：上方「数据大屏」卡片区用来打开和轮播大屏；下方「投屏链接」用来管理电视使用的免登录链接（只有拥有「投屏链接管理」权限的用户能看到这一部分）。

## 权限

| 权限 | 说明 |
| --- | --- |
| 数据大屏 | 打开本页面，在浏览器中查看五块大屏 |
| 数据大屏：投屏链接管理 | 看到「投屏链接」区域，新建、编辑、重新生成、删除投屏链接 |

大屏汇总的是全公司的数据，不按部门或个人拆分，因此和[经营驾驶舱](./cockpit)一样，用户的角色还必须拥有「全部数据」的[数据权限](../guide/permission#数据权限的-5-种范围)，否则打开大屏、查看或维护投屏链接时会提示「数据大屏汇总全公司数据，需要「全部数据」的数据权限」。

内置角色的授权：

| 角色 | 数据大屏 | 投屏链接管理 | 说明 |
| --- | --- | --- | --- |
| 超级管理员 | 有 | 有 | 拥有全部权限 |
| 总经理 | 有 | 有 | 数据权限为「全部数据」，负责为车间、仓库开通投屏 |
| 仓库管理员 | 有 | 无 | 数据权限为「全部数据」，可在仓库办公室直接打开仓储物流等大屏 |

车间主管、生产计划员等角色的数据权限是本部门或本部门及以下，即使授权了菜单也无法打开大屏。车间的电视请由总经理（或管理员）创建投屏链接来显示，不需要给车间账号放开数据权限。

## 打开大屏

### 打开单块大屏

每块大屏一张卡片，卡片上有名称、内容简介和「**打开**」按钮。点击「打开」在浏览器新标签页中打开该大屏。

生产车间、生产进度卡片上还有工作中心下拉框（默认「全部工作中心」，两张卡片的选择是同一个，改一处另一处同步变化）。选择某个工作中心后再点「打开」，大屏只统计该工作中心的数据，标题显示为「生产车间 · 工作中心名称」或「生产进度 · 工作中心名称」，适合挂在对应车间。

### 轮播

1. 勾选卡片上大屏名称前的复选框，选择要轮播的大屏（默认五块全选）。
2. 在卡片下方「轮播：已选 N 个大屏，每 [ ] 秒切换」中填写切换间隔，范围 10 ~ 3600 秒，默认 60 秒。
3. 点击「**轮播打开**」（至少勾选 2 块才能点击），新标签页中按勾选顺序循环切换。

轮播时，工作中心的选择对生产车间、生产进度大屏同样生效。

### 大屏上的操作

大屏按 1920 × 1080 设计，打开后自动等比缩放铺满窗口（比例不同时四周留出背景色），适配各种尺寸的电视和显示器。

- **顶部标题栏**：左侧显示企业名称（SaaS 模式下为租户名称）和日期星期，中间是大屏名称，右侧是时钟和「数据更新于 HH:mm:ss」。
- **切换**：轮播时标题下方显示各大屏名称，点击可直接切换到该大屏，并从此处重新计时。
- **右下角按钮**：移动鼠标时出现，约 2.5 秒后自动隐藏：
  - 「**暂停轮播**」/「**继续轮播**」：只在多块轮播时显示；
  - 「**全屏**」/「**退出全屏**」：进入或退出浏览器全屏，也可以按 F11 键；
  - 「**返回**」：关闭大屏回到上一页（新标签页中打开时回到「数据大屏」页面）。投屏链接打开的大屏没有此按钮。

### 刷新与离线

- 当前显示的大屏**每 30 秒自动刷新一次数据**；轮播切换回某块大屏时，距离上次加载超过 30 秒也会刷新。
- 网络中断或服务器暂时不可用时，大屏**保留上次的数据**，右上角用红点提示原因，例如「● 网络连接中断，显示的是 10:25 的数据」；恢复后自动继续刷新，不需要人工处理。
- 大屏中的滚动列表在行数超过显示区域时会自动逐行向上滚动、循环显示。

## 生产车间

![生产车间大屏](/images/manual/bi/screen-factory.jpg)

数据来自生产工单的报工记录、设备台账和停机记录。选择了工作中心时，报工、工单、设备、停机都只统计该工作中心（工单按「有工序在该工作中心」判断）。

### 指标卡

| 指标 | 口径 |
| --- | --- |
| **今日报工合格** | 今天（按报工日期）所有报工的合格数量合计；下方显示今日报废数量 |
| **今日良品率** | 今日合格 ÷（今日合格 + 今日报废）× 100%，今天没有报工时显示「-」；下方显示本月良品率（口径相同，统计本月 1 日至今天）。颜色：98% 及以上为绿色，95% ~ 98% 为橙色，低于 95% 为红色 |
| **本月报工合格** | 本月 1 日至今天报工的合格数量合计 |
| **今日完工入库** | 显示全部工作中心时：今天业务日期、已完成的「生产入库」类型入库单的数量合计 |
| **本月良品率** | 选择了工作中心时代替「今日完工入库」显示（入库不区分工作中心） |
| **今日报工工时** | 今天报工填写的工时合计（小时） |
| **在制工单** | 状态为「已下达」「生产中」的工单张数；下方「今日完工」为今天完工的工单张数 |
| **逾期工单** | 在制工单中计划完工日期早于今天的张数。大于 0 时标红并提示「超过计划完工日期」，否则显示「全部按期」 |
| **设备运行率** | 状态为「运行」的设备台数 ÷ 设备总台数（不含已报废设备）× 100%；下方显示「运行 x / y 台」。没有设备时显示「-」 |

::: tip 提示
设备运行率按设备台账上的**当前状态**计算，不是按时间计算的利用率。设备的时间利用情况请看[设备 OEE](../mes/oee)。
:::

### 图表与列表

| 区域 | 内容 |
| --- | --- |
| **近 14 天产量趋势** | 最近 14 天（含今天）每天报工的合格（柱）、报废（柱）数量和良品率（折线），没有报工的日期补 0 |
| **在制工单进度** | 「已下达」「生产中」的工单，按计划完工日期从早到晚排列（没有计划完工日期的排在最后），最多 50 张。列：工单号、产品、当前工序（第一道合格 + 报废数量还未达到工单数量的工序，全部工序完成时显示「待入库」）、完成 / 计划（最后一道工序的合格数量 / 工单数量）、进度、计划完工。逾期的工单进度条和日期标红 |
| **设备状态** | 每台设备（不含已报废）一格，颜色表示状态：运行为绿色、闲置为橙色、维修中为红色，并显示该设备今日报工合格数量；右上角统计各状态台数 |
| **工作中心今日负荷** | 每个启用的工作中心一条：负荷 = 今日报工工时 ÷ 日产能（每日工时 × 资源数）。80% 以下为蓝色，80% ~ 100% 为橙色，超过 100% 为红色；悬停可看工时、合格、报废数量。最多显示 10 个 |
| **实时报工** | 最近 30 条报工记录：时间、工单、工序、操作员、设备、合格、报废（有报废时标红） |
| **本月停机原因** | 本月开始的设备停机记录按停机原因汇总的时长（环形图），右上角为合计小时数；本月没有停机时显示「本月没有停机记录」。停机记录来自[设备 OEE](../mes/oee)中登记的停机和[设备维护](../mes/maintenance)自动生成的停机 |

## 生产进度

![生产进度大屏](/images/manual/bi/screen-progress.jpg)

生产进度大屏与「生产制造 → [生产看板](../mes/board)」使用**完全相同的数据和统计口径**：在制工单走到哪道工序、还剩几道、按工作中心产能推演的预计完工日期与交期风险，各产线今天的运行状态，以及今天每小时的产出。指标、状态和预计完工的计算方法详见[生产看板](../mes/board)。选择了工作中心时，工单只列出有工序在该工作中心的，产线和今日产出只统计该工作中心。

### 指标卡

| 指标 | 说明 |
| --- | --- |
| **在制工单** | 已下达、生产中的工单数；下方「待开工 N」 |
| **生产中** | 今天有报工的工单数；下方有停滞工单（有过报工但今天没有）时显示「停滞 N」（橙色），否则显示「没有停滞」 |
| **运行产线** | 今天有报工的产线数 / 显示的产线数 |
| **今日合格** | 今天报工的合格数量；下方为报废数量 |
| **今日良率** | 合格 ÷（合格 + 报废）× 100%，今天没有报工时显示「-」；98% 及以上为绿色，95% ~ 98% 为橙色，低于 95% 为红色。下方为今日报工工时 |
| **今日完工** | 今天完工的工单数；下方「待入库 N」：工序全部完成、等待完工入库的工单数 |
| **交期风险** | 预计延期 + 已逾期的工单数，有风险时为红色；下方分别列出 |
| **预计全部完工** | 全部在制工单中最晚的预计完工日期；下方为距今天数和剩余工时。有工单产能不足无法估算时显示「-」 |

### 图表与列表

| 区域 | 说明 |
| --- | --- |
| **在制工单进度** | 交期有风险的在前，其余按预计完工排序。列：工单 / 产品、客户 / 订单、工序进度（每道工序一个色块，绿色已完成、蓝色进行中、灰色未开始，下方为当前工序「i/n 工序名」，工序全部完成时为待入库）、完成进度（预计延期为橙色、已逾期为红色）、预计完工（月-日和距今天数）、交期、交期风险（按期 / 预计延期 / 已逾期 / 无法估算）。行数超过显示区域时自动逐行滚动 |
| **产线状态** | 每个工作中心一张卡片：状态（运行中 / 待开工 / 空闲 / 休息）、今日合格、在排工单数、利用率进度条（今日报工工时 ÷ 今天可用工时，超过 100% 为红色）、今天正在做的工单和工序（今天还没有报工时显示「今天还没有报工」）、预计做完日期 |
| **今日每小时产出** | 今天报工的合格、报废数量按报工录入时间的小时汇总（堆叠柱状图），横轴至少显示 08:00 ~ 18:00，有更早或更晚的报工时自动延长 |

## 仓储物流

![仓储物流大屏](/images/manual/bi/screen-warehouse.jpg)

数据来自仓库的入库单、出库单、调拨单、库存，以及供应链的发货通知。出入库只统计**已完成**的单据，按单据的业务日期归属日期。

### 指标卡

| 指标 | 口径 |
| --- | --- |
| **今日入库** | 今天已完成入库单的合计数量；下方为单据张数 |
| **今日出库** | 今天已完成出库单的合计数量；下方为单据张数 |
| **待拣货** | 状态为「待拣货」的[发货通知](../scm/delivery)张数 |
| **待出库** | 状态为「已拣货」、还没有出库的发货通知张数 |
| **今日已发货** | 计划发货日期为今天、状态为「已出库」的发货通知张数 |
| **在途调拨** | 状态为「在途」（已调出、未调入）的[调拨单](../wms/transfer)张数 |
| **在库物料** | 库存数量大于 0 的物料种数；下方「合计」为全部库存数量之和 |
| **库存预警** | 低于安全库存的物料数 + 临期批次数。大于 0 时标红；下方分别显示「低于安全库存 x · 临期 y」 |

库存预警的口径：

- **低于安全库存**：启用状态、设置了安全库存（大于 0）的物料，全部仓库库存合计低于安全库存；
- **临期**：设置了有效期的批次，有效期在 30 天以内（含已过期）且仍有库存。

### 图表与列表

| 区域 | 内容 |
| --- | --- |
| **近 14 天出入库** | 最近 14 天每天已完成的入库、出库数量（柱状图） |
| **待发货** | 待拣货、已拣货的发货通知，按计划发货日期排列，最多 30 张。列：发货通知、客户、仓库、发货日期（已过计划日期的标红）、状态 |
| **各仓库库存** | 每个启用的仓库的库存数量合计（横向柱状图），悬停可看物料种数 |
| **本月出入库构成** | 本月已完成出入库单按入库类型、出库类型汇总的数量，左侧为入库、右侧为出库（环形图）；占比很小的扇区不显示标签，悬停可看 |
| **实时出入库** | 最近确认的 30 张出入库单和调拨单（含在途调拨）：时间、单号、入 / 出 / 调拨、类型、仓库、数量 |
| **库存预警** | 低于安全库存的物料（按库存 / 安全库存比例从低到高，最多 30 条，标「缺货」并显示库存 / 安全库存进度条），以及临期批次（按到期日先后，最多 30 条，标「临期」或「已过期」，显示批次号、到期日和库存） |

## 销售经营

![销售经营大屏](/images/manual/bi/screen-sales.jpg)

数据实时取自销售订单、销售出库 / 退货、收款和应收单，**不依赖数据仓库同步**。金额都是价税合计；一万元以上的金额以「万元」显示。

### 指标卡

| 指标 | 口径 |
| --- | --- |
| **今日订单** | 今天下单（按订单日期）、状态为「已审核」「部分完成」「已完成」的销售订单金额合计；下方为订单张数和今日出库金额 |
| **本月订单** / **本年订单** | 口径同上，统计本月 1 日 / 本年 1 月 1 日至今天 |
| **本月出库** | 本月[销售出库](../scm/sales-out)金额减去销售退货金额（按业务日期） |
| **本年出库** | 本年 1 月 1 日至今天的出库减退货金额；下方为**同比**：与上年 1 月 1 日至上年今天的出库金额相比的增长率，上年同期没有出库时显示「上年同期无出库」 |
| **本月回款** | 本月已生效的[收款核销](../fin/settlement)金额 + 本月登记的[预收款](../fin/advance)金额；下方为本年回款。预收款冲抵应收时不会重复计入 |
| **应收余额** | 全部[应收单](../fin/ar-ap)的「金额 − 已核销金额」合计 |
| **逾期未交订单** | 状态为「已审核」「部分完成」、交货日期早于今天的销售订单张数，大于 0 时标红；下方为本月新增的客户数 |

::: tip 提示
这里的「订单」「出库」口径与[经营驾驶舱](./cockpit)不同：驾驶舱的销售额来自数据仓库、按不含税金额计算；大屏是实时的价税合计金额。两者数字不一致属于正常情况。
:::

### 图表与列表

| 区域 | 内容 |
| --- | --- |
| **月度销售趋势** | 本年 1 ~ 12 月每月的订单金额（柱）、出库金额（柱）和上年同月出库金额（虚线），单位万元；本月以后的月份只显示上年数据 |
| **本年客户排行** | 本年出库减退货金额最高的 10 个客户 |
| **本年产品排行** | 本年出库减退货金额最高的 10 个物料 |
| **本月业务员排行** | 本月已审核及之后的销售订单按业务员汇总的金额，前 8 名；没有指定业务员的订单归为「未指定」 |
| **实时订单** | 最近创建的 30 张销售订单（所有状态）：日期、订单号、客户、金额、状态 |
| **执行中订单** | 状态为「草稿」「审批中」「已审核」「部分完成」的销售订单按状态分布（环形图），中间为合计张数，右上角为合计张数和金额 |

## 质量管理

![质量管理大屏](/images/manual/bi/screen-quality.jpg)

数据来自[质量检验](../qms/inspection)（只统计已确认的检验单，按检验日期）、生产报工和[不合格品处理](../qms/ncr)。

### 指标卡

| 指标 | 口径 |
| --- | --- |
| **本月检验** | 本月已确认的检验单数（批） |
| **综合合格率** | 本月检验结论为「合格」的批数 ÷ 检验批数 × 100%。「让步接收」不算合格 |
| **来料合格率** | 只统计来料检验 |
| **过程 / 成品合格率** | 来料检验以外的检验（过程检验、成品检验、首件检验） |
| **生产良品率** | 本月报工合格 ÷（合格 + 报废）× 100%，口径同生产车间大屏 |
| **本月报废** | 本月报工的报废数量合计 |
| **待处置不合格品** | 状态为「待评审」「审批中」的不合格品处理单张数（不限日期） |
| **本月不合格品** | 本月新建的不合格品处理单张数；下方「已处置」为本月处置完成的张数 |

合格率的颜色：98% 及以上为绿色，95% ~ 98% 为橙色，低于 95% 为红色；没有检验时显示「-」。

### 图表与列表

| 区域 | 内容 |
| --- | --- |
| **近 14 天检验合格率** | 最近 14 天每天的检验批数（柱）和合格率（折线） |
| **各类检验合格率** | 本月每种检验类型一个仪表盘，显示合格率和批数（最多 4 种） |
| **不良类型柏拉图** | 本月结论为「不合格」「让步接收」且填写了不良类型的检验，按不良类型统计次数（柱，从多到少，前 8 种）和累计占比（折线），用于找出主要不良原因 |
| **供应商来料质量** | 本月来料检验按供应商统计的合格率，按合格率从低到高排列，前 8 家；悬停可看检验批数和不合格批数（不合格批数包含让步接收） |
| **最近检验** | 最近确认的 30 张检验单：日期、检验单、类型、物料、不良数量、结论 |
| **待处置不合格品** | 「待评审」「审批中」的不合格品处理单，最近 30 张：处理单、物料、不良类型、数量、状态 |

## 投屏链接

投屏链接用于车间、仓库的电视或显示器：在电视的浏览器中打开链接，即可显示指定的大屏，**不需要登录账号**，也不会因为登录过期而退出。链接只能查看所选的大屏，不能进入系统的其他页面，也不能修改任何数据。

![新建投屏链接](/images/manual/bi/screen-share-add.jpg)

### 列表

「投屏链接」区域上方提示「车间、仓库的电视用浏览器打开投屏链接即可显示大屏，不需要登录、不会过期退出；链接只能查看所选的大屏。链接泄露时可停用或重新生成。」

| 列 | 说明 |
| --- | --- |
| 名称 | 链接的名称 |
| 大屏 | 链接中的大屏（标签） |
| 轮播间隔 | 选择了多块大屏时显示「N 秒」，只有一块时显示「-」 |
| 工作中心 | 生产车间、生产进度大屏显示的工作中心，没有指定时为「全部」 |
| 状态 | 「启用」「停用」；设置了有效期且已经过期的显示「已过期」 |
| 有效期至 | 没有设置时显示「长期有效」 |
| 最近访问 | 电视最近一次访问的时间，用于判断这台电视是否还在使用。为减少写数据库，同一链接最多每 5 分钟记录一次 |
| 链接 | 「**复制链接**」把链接复制到剪贴板（浏览器不允许复制时，在提示中显示完整链接，可手动复制）；「**打开**」在新标签页中预览 |
| 操作 | 「**编辑**」「**重新生成**」「**删除**」 |

链接按创建时间倒序排列，列出本企业的全部投屏链接（不只是自己创建的）。演示数据中没有投屏链接，列表为空。

### 新建投屏链接

1. 点击「**新建链接**」，打开「新建投屏链接」表单。
2. 填写字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 名称 | 是 | 最多 64 个字，例如「一车间电视」「成品仓大屏」，便于识别是哪台电视 |
| 大屏 | 是 | 勾选一块或多块大屏，默认「生产车间」。选择多个时轮播 |
| 轮播间隔（秒） | 是 | 10 ~ 3600 秒，默认 60 秒。只选一块大屏时不起作用 |
| 工作中心 | 否 | 生产车间、生产进度大屏只显示该工作中心，不选为「全部」 |
| 有效期至 | 否 | 精确到时分秒，过了这个时间链接自动失效；不填为长期有效 |
| 状态 | 是 | 「启用」或「停用」，默认启用 |

3. 点击「保存」（或按 Ctrl / ⌘ + Enter）。系统为链接生成一个随机的访问令牌。
4. 在列表中点击「复制链接」，把链接发送到电视上。

### 在电视上打开

1. 在电视、电视盒子或连接显示器的电脑上，用浏览器打开复制的链接。
2. 页面先显示「正在打开大屏…」，随后显示大屏；选择多块大屏时按设置的间隔轮播。
3. 按 F11 或移动鼠标点击右下角「全屏」进入全屏。可把链接设为浏览器主页或开机启动页面，电视开机后自动显示。

链接无效、已停用或已过期时，页面显示「无法打开大屏」和原因「投屏链接无效、已停用或已过期」；网络还没连上时显示「网络连接中断」。这两种情况页面都会**每 30 秒自动重试**，电视开机时网络较慢也能自动恢复。

投屏链接打开的页面没有语言切换按钮：大屏的标题、指标名称和图表文字使用这台设备的浏览器上次在系统中选择的语言，从没选择过时按浏览器语言（英文浏览器显示英文，其他显示中文）。需要英文大屏时，先在这台设备的浏览器中打开系统登录页切换为「English」，再打开投屏链接。物料、客户、工作中心等名称是业务数据，不会翻译。

投屏链接打开的大屏与登录后查看的数据完全相同，同样每 30 秒刷新、离线时保留上次数据。SaaS 模式下链接只显示创建它的企业（租户）的数据，标题栏的企业名称也是该租户的名称。

### 编辑、停用、重新生成与删除

| 操作 | 说明 |
| --- | --- |
| **编辑** | 修改名称、大屏、轮播间隔、工作中心、有效期和状态；可以清空工作中心和有效期。**停用**：编辑时把状态改为「停用」并保存，链接立即失效；改回「启用」后原链接恢复可用 |
| **重新生成** | 确认「重新生成后原链接立即失效，确定吗？」后生成新的令牌，原链接立即失效，需要把新链接重新发送到电视上 |
| **删除** | 确认「删除后链接失效，确定删除吗？」后删除，链接立即失效，无法恢复 |

::: warning 注意
已经打开的电视页面在链接停用、过期、重新生成或删除后，下一次刷新会失败，此时**页面仍显示最后一次取到的数据**，并在右上角红点提示「投屏链接无效、已停用或已过期，显示的是 HH:mm 的数据」，并不会清空画面。如需立即停止显示，请同时关闭电视上的浏览器。

修改链接的大屏、轮播间隔后，已经打开的电视页面不会自动应用新的设置，需要在电视上刷新一次页面。修改工作中心后数据会在下次刷新时按新的工作中心统计。
:::

### 安全注意事项

::: warning 注意
- 投屏链接本身就是访问凭证：**任何拿到链接的人都能在不登录的情况下查看所选大屏的数据**，包括销售金额、应收余额、客户和产品排行等经营数据。请只把链接发到需要的设备上，不要发到群聊或对外公开。
- 令牌是 128 位随机数，无法猜测；但链接一旦泄露（例如被拍照、转发），请立即「重新生成」或停用。
- 销售经营大屏包含敏感的经营数据，放在公共区域的电视建议只选择生产车间、生产进度、仓储物流、质量管理大屏。
- 临时使用（如参观、展会、会议）的链接请设置「有效期至」，到期自动失效。
- 定期查看「最近访问」，长时间没有访问的链接说明设备已不再使用，可以停用或删除。
- 新建、编辑、重新生成、删除投屏链接都会记录在[操作日志](../monitor/operlog)中。
:::

## 常见问题

**打开大屏提示需要「全部数据」的数据权限？**
请管理员在[角色管理](../system/role#数据权限页签)中把该用户所在角色的数据权限设为「全部数据」，或改为由总经理创建投屏链接给该用户使用。

**大屏上的数据和业务页面对不上？**
大屏是实时数据，最多有 30 秒延迟。请先对照本页的统计口径，例如出入库只统计已完成的单据、订单只统计已审核及之后的订单、合格率不把「让步接收」算作合格。

**电视上显示「网络连接中断」？**
检查电视能否访问系统地址。页面会每 30 秒自动重试，网络恢复后自动显示，不需要重新打开链接。

**能否只在车间电视上显示本车间的数据？**
可以：新建投屏链接时选择「生产车间」或「生产进度」大屏并指定工作中心。仓储物流、销售经营、质量管理大屏不支持按仓库或部门筛选，显示全公司数据。
