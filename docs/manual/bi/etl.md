# 数据仓库

数据仓库页面用于查看商务智能数据的同步状态：各类事实数据的行数、库存快照天数、最近一次成功同步的时间，以及每次同步的日志；有权限的用户可以手动「立即同步」。

## 页面入口

商务智能 → 数据仓库

![数据仓库](/images/manual/bi/etl.jpg)

## 同步状态

页面顶部「数据仓库」标题下显示同步状态：

- 「正在同步…」：当前有同步任务在运行；
- 「最近一次成功同步：日期时间」；
- 「尚未同步」：从未成功同步过。

| 按钮 | 作用 |
| --- | --- |
| 「刷新」 | 重新读取同步状态 |
| 「立即同步」 | 立即执行一次全量同步，完成后提示每类数据写入的行数，并刷新状态和日志。需要「立即同步」权限 |

## 同步内容

每张卡片显示一类事实数据的当前行数：

| 卡片 | 内容 | 来源 |
| --- | --- | --- |
| 销售事实 | 销售出库 / 退货明细，含成本与毛利（按存货单位成本） | [销售出库单、销售退货单](../scm/sales-out)，退货为负数；金额为不含税金额 |
| 采购事实 | 采购入库 / 退货明细，不含税金额 | [采购入库单、采购退货单](../scm/purchase-in) |
| 库存快照 | 每天按仓库、物料汇总的库存数量与金额，卡片上另外显示已保存的快照天数 | 同步当天的实时库存；库存金额 = 数量 × 物料单位成本 |
| 生产事实 | 已下达的工单：计划、完工、报废、工时、是否延期 | 状态不是草稿的[生产工单](../mes/wo) |
| 财务事实 | 已记账凭证按期间、科目、部门汇总（不含结转损益） | 已记账[凭证](../fin/voucher) |
| 人力事实 | 最近 24 个月按部门、岗位类别的月末人数、入职、离职、工资与人工成本 | [员工档案](../hr/employee)，已确认、已发放的[工资表](../hr/payroll) |
| 客户经营事实 | 按月份、负责人的新增线索、跟进、新增商机、赢单与输单 | [线索](../crm/lead)、[跟进记录](../crm/followup)、[商机](../crm/opportunity) |
| 项目事实 | 按月份、项目的已审批工时与人工成本、费用、月结确认的收入与结转成本 | [项目工时](../pm/timesheet)、[项目费用](../pm/cost)、[项目月结](../pm/accounting#项目月结) |

物料单位成本：取该月及以前最近一期[成本核算](../fin/cost)的加权平均单价，没有成本核算结果时取该物料全部采购入库的平均不含税单价。

## 同步方式

### 定时同步

系统定时任务「数据仓库同步」默认每天凌晨 1:30 自动运行。部署时可以通过配置项调整执行时间，设为「-」时默认停用定时同步；也可以在系统监控的[定时任务](../monitor/job)中调整、停用或立即执行该任务。SaaS 模式下按租户逐个同步。

### 手动同步

点「立即同步」立即执行。[经营驾驶舱](./cockpit)顶部的「立即同步」作用相同。

### 同步规则

- 每次同步**全量重建**销售、采购、生产、财务、人力、客户经营、项目事实数据，因此历史单据的修改、冲销也会在下次同步后体现。
- 库存快照只重建**当天**的快照，以前日期的快照保留，用于库存趋势分析（在[多维分析](./olap)的库存分析中按「快照日期」查看）。同一天多次同步只保留最后一次的结果。
- 同一时间只运行一个同步任务，同步进行中再次点「立即同步」会提示「数据同步正在运行，请稍后再试」。
- 同步在一个事务中完成：同步过程中分析页面看到的仍是旧数据；同步失败时数据保持同步前的状态，并提示「数据同步失败：原因」。

## 同步日志

| 列 | 说明 |
| --- | --- |
| 开始时间 | 同步开始时间 |
| 触发方式 | 「手动」或「定时」 |
| 状态 | 运行中、成功、失败 |
| 耗时 | 开始到结束的时间，不足 1 秒显示「< 1 秒」，运行中显示「-」 |
| 行数 | 每类数据写入的行数，例如「销售 4」「库存快照 18」 |
| 失败原因 | 失败时显示错误信息（红色） |
| 操作人 | 手动同步的操作人；定时同步显示「系统」 |

日志右上角可以按状态筛选。

## 常见问题

**分析页面看不到最新数据？** 查看最近一次成功同步时间，如在业务变化之前，点「立即同步」。

**库存快照只有几天？** 库存快照从首次同步开始每天累积，无法补出过去日期的快照。
