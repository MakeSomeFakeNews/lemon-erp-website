# 商务智能

商务智能（顶部导航「商务智能」）把各业务模块的数据定期汇总到**数据仓库**，在此基础上提供经营驾驶舱、多维分析、自定义报表、自定义仪表盘和决策支持，帮助管理层从全局掌握经营状况，也让业务人员可以自己拖选维度做分析，不需要开发报表。

## 数据从哪里来

商务智能的分析页面大多不直接查询业务单据，而是读取数据仓库中按分析主题整理好的“事实数据”：

1. **业务发生**：在供应链、仓库、生产、财务、人力、客户关系、项目等模块中录入和审核单据。
2. **同步到数据仓库**：系统每天凌晨 1:30 自动同步一次，也可以在[数据仓库](./etl)页面点「立即同步」。每次同步全量重建销售、采购、生产、财务、人力、客户经营、项目事实数据，并保存当天的库存快照（历史快照保留）。
3. **分析使用**：[经营驾驶舱](./cockpit)的趋势和排行、[多维分析](./olap)、[自定义报表](./report)、[自定义仪表盘](./board)、[决策支持](./decision)中的销售预测和 ABC 分析都读取数据仓库。

::: warning 注意
业务数据变化后，要等下一次同步才会反映到分析结果中。如果刚录入的单据在分析中看不到，请先到「数据仓库」页面确认最近一次成功同步的时间，必要时手动同步。
:::

少数指标是实时计算的，不依赖同步：驾驶舱中的应收应付余额、在途销售订单、在制工单、进行中项目、在职人数、商机储备、服务工单，决策支持中的呆滞物料和预警规则（本月毛利率除外）。

## 功能清单

| 菜单 | 用途 |
| --- | --- |
| [经营驾驶舱](./cockpit) | 一屏查看本月 / 本年销售、毛利、应收应付、生产、项目、人员、商机、服务等关键指标，近 12 个月销售与利润趋势，客户和产品排行，库存结构和触发中的预警 |
| [多维分析](./olap) | 选择数据集、行列维度、指标、日期范围和筛选，生成透视表与图表，可逐级下钻，结果可保存为报表 |
| [自定义报表](./report) | 管理在多维分析中保存的报表：预览、继续分析、修改名称和共享、删除 |
| [自定义仪表盘](./board) | 把多张报表组合成看板，设置每个组件的宽度和图表类型，可共享给所有人 |
| [决策支持](./decision) | 销售预测、ABC 分析、呆滞物料、经营预警及预警规则维护 |
| [数据仓库](./etl) | 查看各事实数据的行数和库存快照天数，手动同步，查看同步日志 |

## 典型使用流程

| 步骤 | 操作 | 页面 |
| --- | --- | --- |
| 1 | 首次使用或业务数据有较大变化时，执行一次同步 | [数据仓库](./etl) |
| 2 | 管理层每天查看经营概况和预警 | [经营驾驶舱](./cockpit) |
| 3 | 发现异常时按维度下钻分析原因（例如某月销售下降 → 按客户 → 按物料） | [多维分析](./olap) |
| 4 | 常用的分析口径保存为报表，并共享给团队 | [多维分析](./olap) → [自定义报表](./report) |
| 5 | 把多张报表组成部门看板 | [自定义仪表盘](./board) |
| 6 | 维护预警规则，系统每天 9:00 把触发的预警推送给有决策支持权限的用户 | [决策支持](./decision) |

## 相关角色与权限

| 权限 | 说明 |
| --- | --- |
| 经营驾驶舱 | 查看驾驶舱。驾驶舱汇总全公司数据，用户的角色还必须拥有「全部数据」的[数据权限](../guide/permission#数据权限的-5-种范围) |
| 多维分析 | 使用多维分析。分析结果按用户的数据权限过滤（详见[多维分析](./olap)） |
| 自定义报表：报表新增 / 报表修改 / 报表删除 | 保存报表、修改和删除自己创建的报表 |
| 自定义仪表盘：仪表盘新增 / 仪表盘修改 / 仪表盘删除 | 新建、修改、删除自己创建的仪表盘 |
| 决策支持 / 预警规则维护 | 查看决策支持；维护预警规则。销售预测、ABC 分析需要「全部数据」的数据权限 |
| 数据仓库 / 立即同步 | 查看同步状态和日志；手动同步 |

内置角色中，「总经理」可以查看全部业务数据和商务智能；「普通用户」可以打开商务智能的各个页面，但没有保存报表、同步等按钮权限。
