# 决策支持

决策支持提供四个分析工具：**销售预测**（按历史趋势和季节性预测未来销售额）、**ABC 分析**（按价值对物料分类，确定重点管控对象）、**呆滞物料**（找出长期没有出库的库存）和**预警**（按规则监控应收逾期、库存、毛利率、工单、项目、预算等经营指标）。

## 页面入口

商务智能 → 决策支持

页面分为「销售预测」「ABC 分析」「呆滞物料」「预警」四个页签，切换到某个页签时才加载对应数据。

::: warning 注意
销售预测和 ABC 分析汇总全公司数据，需要「全部数据」的[数据权限](../guide/permission#数据权限的-5-种范围)。
:::

## 销售预测

![销售预测](/images/manual/bi/decision-forecast.jpg)

### 操作

1. 选择物料分类（默认「全部物料分类」，可只预测某一类物料的销售额）。
2. 选择预测月数：「3 个月」（默认）「6 个月」「12 个月」。
3. 点「预测」。

### 结果

- 条件右侧显示预测方法和趋势斜率，例如「方法：线性趋势（最近 12 个月）；趋势斜率 1,200.00 元 / 月（基于数据仓库的月销售额，本月未结束不参与拟合）」。
- 折线图：实线为近 24 个月的实际销售额，虚线为预测值，竖虚线标出「本月」。
- 下方表格列出每个预测月份的预测销售额。

### 预测方法

1. 取数据仓库中近 24 个月的月销售额（不含税，扣除退货）。本月尚未结束，不参与计算。
2. 对最近 12 个完整月份做最小二乘线性回归，得到趋势线。
3. 如果前 12 个月中也有销售数据（即满两年数据），再乘以**季节指数**：某月的季节指数 = 前两年该月销售额的平均值 ÷ 两年的月均销售额。此时方法显示为「线性趋势 × 季节指数」。
4. 从本月开始预测指定月数；预测值小于 0 时按 0 处理。

::: tip 提示
数据仓库中有销售额的完整月份少于 3 个时，页面显示黄色提示「数据仓库中只有 N 个完整月份有销售数据，预测需要至少 3 个月的历史，当前结果仅供参考」。
:::

## ABC 分析

![ABC 分析](/images/manual/bi/decision-abc.jpg)

ABC 分析按近一年（今天往前一年）各物料的**销售成本**从高到低排序并累计占比（所有物料都没有成本时改用销售额），页面顶部注明本次使用的依据：

| 类别 | 规则 | 管理建议 |
| --- | --- | --- |
| A 类 | 累计占比 70% 以内 | 重点管控 |
| B 类 | 累计占比 70%-90% | 一般管控 |
| C 类 | 其余 | 简化管理 |

分类按“进入该物料之前的累计占比”判断，因此金额最高的物料总是 A 类。

页面内容：

- 三张汇总卡片：A / B / C 类物料的种数、金额和金额占比。
- 帕累托图：柱状为前 30 种物料的金额（A 类红色、B 类橙色、C 类灰色），折线为累计占比。
- 明细表：物料、分类、数量、金额、占比、累计占比、类别。

## 呆滞物料

![呆滞物料](/images/manual/bi/decision-slow.jpg)

### 操作

1. 在「超过 N 天没有出库（不含调拨）且有库存」中填写天数，默认 90 天，范围 0-3650。
2. 点「查询」。

### 判定规则与结果

- 呆滞物料 = 当前库存数量大于 0，且在指定天数内没有任何出库[流水](../wms/flow)（调拨不算出库）的物料。该页面读取实时库存，不依赖数据仓库同步。
- 右侧汇总「共 N 种，库存金额 ……（按最新库存快照）」。
- 列表按库存金额从高到低排列：物料、分类、库存数量（带单位）、库存金额（按最新一次库存快照）、最近出库时间（从未出库时显示「从未出库」）、呆滞天数。
- **呆滞天数**从最近一次出库算起；从未出库的从第一次入库算起。180 天及以上标红，90 天及以上标橙。

## 预警

![预警](/images/manual/bi/decision-alerts.jpg)

### 预警卡片

每条**启用**的预警规则显示为一张卡片：

- 规则名称；触发时显示级别标签（提示 / 警告 / 严重，卡片左侧有对应颜色的边框），未触发显示绿色「正常」。
- 当前值和单位。
- 预警条件，例如「应收账款逾期金额 大于 0.00元 时预警」。
- 触发时显示处理建议。

顶部的「重新计算」重新计算所有规则，右侧显示「触发 N 条 / 共 M 条启用的规则」。

### 可以监控的指标

| 监控指标 | 单位 | 计算口径 |
| --- | --- | --- |
| 应收账款逾期金额 | 元 | 未核销完、到期日早于今天的[应收单](../fin/ar-ap)余额合计 |
| 低于安全库存的物料数 | 种 | 启用且设置了[安全库存](../wms/material#基础信息)的物料中，全部仓库库存合计低于安全库存的种数 |
| 呆滞物料数（90 天无出库） | 种 | 有库存且 90 天内没有出库（不含调拨）的物料种数 |
| 本月销售毛利率 | % | 数据仓库中本月毛利 ÷ 本月销售额；本月没有销售额时无值，不会触发 |
| 超时未解决的服务工单 | 张 | 待处理、处理中且已超过处理时限的[服务工单](../crm/ticket) |
| 逾期未完成的项目任务 | 个 | 进行中项目里未完成、计划完成日期早于今天的末级[任务](../pm/plan) |
| 延期未完工的生产工单 | 张 | 已下达、生产中且计划完工日期早于今天的[工单](../mes/wo) |
| 本年累计超预算的科目数 | 个 | 本年 1 月至本月累计执行数超过累计[预算](../fin/budget)的预算科目数 |

### 内置预警规则

| 规则 | 条件 | 级别 | 处理建议 |
| --- | --- | --- | --- |
| 应收账款逾期 | 逾期金额大于 0 | 警告 | 催收逾期款项，必要时暂停发货 |
| 库存低于安全库存 | 物料数大于 0 | 警告 | 及时[补货](../scm/reorder)或运行 [MRP](../mes/mrp) |
| 呆滞物料 | 物料数大于 0 | 提示 | 90 天没有出库的物料，考虑促销或调拨 |
| 本月毛利率偏低 | 毛利率小于 15% | 严重 | 检查销售价格与采购成本 |
| 服务工单超时 | 张数大于 0 | 严重 | 超过处理时限未解决的工单 |
| 项目任务逾期 | 个数大于 0 | 警告 | 超过计划完成日期未完成的任务 |
| 生产工单延期 | 张数大于 0 | 警告 | 超过计划完工日期未完工的工单 |
| 预算超支 | 科目数大于 0 | 警告 | 本年累计执行超过预算的科目数 |

### 维护预警规则

页签下方「预警规则」列表显示全部规则（含停用的）：规则、监控指标、预警条件、级别、状态（启用 / 停用）、处理建议。需要「预警规则维护」权限才能看到「新增规则」「编辑」和删除按钮。

![新增预警规则](/images/manual/bi/alert-rule-form.jpg)

| 字段 | 说明 |
| --- | --- |
| 规则名称 | 必填，最多 64 个字符 |
| 监控指标 | 必选，见上表，选项后括号中为单位 |
| 比较 | 必选：大于（默认）、不小于、小于、不大于 |
| 阈值 | 必填，默认 0，输入框后显示指标单位 |
| 级别 | 必选：提示、警告（默认）、严重 |
| 启用 | 默认开启；停用的规则不计算、不推送 |
| 处理建议 | 选填，最多 255 个字符，触发时显示在卡片和消息中 |

操作步骤：点「新增规则」→ 填写表单 → 点「确定」。编辑同理；删除前需要确认。

### 预警推送与首页待办

- 系统[定时任务](../monitor/job)「经营预警推送」默认每天 9:00 运行，把触发的预警以站内消息发送给拥有「决策支持」权限的用户：「严重」「警告」级别作为预警消息，「提示」级别作为提醒消息，每条规则每天最多推送一次。点击消息进入决策支持页面。
- 拥有「决策支持」权限且数据权限为「全部数据」的用户，[首页待办](../guide/home#待办事项)中会显示「触发中的经营预警」数量。
- [经营驾驶舱](./cockpit)右侧「预警」卡片也会列出触发中的预警。
